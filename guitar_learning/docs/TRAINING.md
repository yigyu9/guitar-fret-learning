# 학습 안내의 읽는 순서

현재 기본은 GPU 왼손 압현 V5다. 실행 명령과 기본값을 여러 문서에 반복하지 않고 아래 문서를 기준으로 읽는다.

| 알고 싶은 내용 | 대표 문서 |
| --- | --- |
| 실행·초기 자세·제어·보상·종료 | [학습 README](../README.md) |
| 재개·평가·영상 | [저장·재개·평가](../README.md#저장재개평가) |
| 파일별 역할과 실행 흐름 | [코드 지도](CODE_STRUCTURE.md) · [상세 코드 해설](../../docs/2026-11-02/코드해설/README.md) |
| 로그 파일과 항목별 점수 | [로그 안내](LOGGING.md) |
| 실제 압현 가능성 진단 | [C1~C6 연속 목표](../../docs/2026-11-09/압현_v5_합성목표연결_v1/README.md) |
| 타현·전신·공용 진단 | [도구 안내](../tool/README.md) |

GPU 왼손은 v9에서 시작하고 손가락 목표각을 직접 지정한다. CPU·오른손·과거468상태·035/v14·누적 제어·R/F/J 단계의 계약은 현행 기본으로 사용하지 않는다.

이 문서에 함께 있었던 초기468상태 인터페이스와 구형 병렬 학습의 긴 설명은 [정리 전 원문](../../docs/archive/document_cleanup_20261030/before/guitar_learning/docs/TRAINING.md)에 보존했다. 당시 설명을 재현하려면 그 시점의 소스·입력 계약을 함께 사용해야 한다.
