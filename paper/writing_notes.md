# 논문 작성 메모

제목은 **From Audio to Full-Body Guitar Performance with a Freely Moving Instrument**다. 내용을충분히 작성한 뒤 기여와 근거에 맞춰 줄인다. 문제와 설계 이유를 먼저 설명하고수식과 구현 세부를 뒤에 둔다.

## 초록 합의 — 2026-10-27

- [초록](00_abstract.md)은 필요성 → 오디오 입력과 3D 동작 생성 → 연주 계획과 물리 기반 제어 → 활용 가능성의 현재 문안으로 확정했다.
- 평가 결과는 성능 개선 후 별도 평가로 검증되면 추가한다. 사용 모델·평가 조건·성공 기준·분모를 확인하고, 음악 수행과 악기 안정성을 구분해 핵심 결과를 간결하게 반영한다.
- 이번 합의는 초록 문안에 관한 것으로, 기존 실험 결과나 원고 전체의 자료 기준일을 갱신한 것은 아니다.

## 남은 작성과 검증

1. 저장한 전곡 모델을 별도로 평가하고 음별 성공·전환 실패·타이밍 오차와완료분모를 정리한다.
2. 타현 시각, 그 순간의clean 압현, 오른손 다른 현 통과·재무장과기타안전을동일 시간축으로 도식화한다.
3. 같은seed·초기 자세·목표·물리 조건의 초기화·구조·보상 비교를 마련한다.
4. 손별 성공이 공동 성공을 보장하지 않는 이유를 관측된 대표 사례로 설명한다.
5. 다중seed·조건·곡과 엄격50/100ms 결과를 확보한 뒤 기여 문장을 확정한다.

초기 자세의 외관, 접촉 횟수와 재생 영상은 실제 연속 음악 성공을 대신하지 않는다.전신이라는 표현에는Root 고정과 정책39축을 함께 설명한다. 사람 모션 자료나음향 모델이 없는 범위의 성능은 주장하지 않는다.

## 본격적인 원고 작성 전환 — 2026-11-02

교수님 요청에 따라 Overview·Model·Method의 상세 초안을 먼저 준비하고, 피드백을 반영하며 Experiment·Result를 채워 11월 전체 초안을 목표로 한다. 12월과 2027년 1월에는 추가 실험·구현·그림·표·데모·필요시 보충자료와 원고 수정을 진행한다.

현재 방법 절은 과거 두 Actor·500/563/1132상태를 설명하므로 최근 GPU 왼손 J33·557상태 및 새 613상태 진행 경로와 대조하여 갱신해야 한다. 새 613상태는 CPU 작동 검증 단계이며, 전곡 학습 성공이나 다중 압현 성공으로 서술하지 않는다. 단일 압현의 팔 지원·참조 재생·정책 학습 결과도 구분한다.

기존 제목과 원고 순서는 유지하고, Overview/Model은 방법 절의 하위 구성으로 먼저 잡는다. 기존 초록 합의·자료 기준일·실험 결과는 유지한다. Overleaf 프로젝트·ACM 템플릿 및 한국어 작성은 확인했으며, 초록·서론은 해당 프로젝트에 반영했다.
