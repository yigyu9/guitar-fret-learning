# Experiment

논문 제목: **From Audio to Full-Body Guitar Performance with a Freely Moving Instrument**

## 4.1 실험 목적과 단계

실험은 초기 자세의 기타 지지, 손별 목표 수행, 같은 장면에서의 양손 결합, 연속 목표 전환을 구분한다. CPU 검사는 관측·판정·초기화·예외 처리의 연결을 검사한다. Native 실행은 실제 물리 계산과 목표 제출을 검사한다. PPO 업데이트와 모델 저장은 학습 경로의 작동 근거이며 음악 성공과 분리한다.

## 4.2 공통 물리 조건

Root 고정·하체 유한 제어·105입력/97비영 범위/8원 영범위, 자유 기타·중력 ON·스트랩 OFF를 사용한다. 정책 출력 39축 외의 관절도 기존 유한 유지 제어를 받는다. 기타 직접 힘·부착·실행 중 상태 덮어쓰기는 사용하지 않는다. 기준 입력은 기존035 설정과v14 준비 상태다. 물리 240Hz와 정책 60Hz를 사용하고 네 하위 표본 모두에서 안전과 음악 조건을 평가한다.

초기 자세 선정에 사용한 긴 검증 스케줄과 학습 에피소드의 준비를 구분한다. 현재 native 정착 대기는 0초이며 정책이 처음부터 행동한다. 단음의 정책 준비 3초와 전체 7초, 전곡의 정책 준비 3초와 전체 32.8166667초는 각각의 계약이다.

## 4.4 평가 지표

음악은 목표별 clean 압현 유지 시간·충족 분율, 오압현·미압현 시간, 타현 현·방향·시각 오차, 중복·추가·누락, 타현 순간의 압현 결합으로 평가한다. 완화 시간창과 엄격한50/100ms 성공은 각각 보고한다. 분모가1개 목표인지67음인지, 완료 에피소드인지 부분 수집인지 명시한다.

안전은 기타 이동·회전·접지·관절 상태와 종료 원인을 보고한다. 가슴 접촉 저하만으로 실패를 정하지 않는다. 부위별 접촉 횟수나raw lambda를N단위 지지력 비중으로 변환하지 않는다. 소스 형상으로 재생한 영상과native 카메라 원본도 구분한다.

실행은 에피소드 완주, 수집 전이, 실제 PPO 반영, KL guard 재시도, 체크포인트 저장·복원, 장면 생성·종료, 소비 입력 불변을 별도로 확인한다. 긴 곡의 rollout 중간 상태는 전체 음악 성공의 분모로 사용하지 않는다.

## 4.5 통제 범위와 후속 실험

현재 결과는 같은 준비 상태·같은 단음의 소규모 검증이다. 다중seed·곡·초기 자세·교란에 대한 성공률이나 통계적 우월성을 주장하지 않는다.

후속 실험은 저장한 전곡 모델을 별도로 평가하고 음 전환·공동 타이밍·기타 안전을 함께 개선한다. 충분한 반복이 확보되면 Actor 공유·분리, 초기화, 이력, 음악·안정성 보상 등의 설계를 통제된 비교로 검증한다. 이 비교는 현재 수행한 ablation이 아니다.
