# Methodology

논문 제목: **From Audio to Full-Body Guitar Performance with a Freely Moving Instrument**

## 3.1 문제 정의

입력은 시각과 현·프렛·손가락·방향이 지정된 연주 목표다. 목표음은 `g_i=(현, 프렛, 손가락, 방향, 발음 시작, 발음 종료, 압현 준비 시각)`으로 표현한다. 현과 프렛은 누를 위치를, 손가락은 수행 주체를 정한다. 압현 준비와 발음의 시각을 분리하여 언제 접근하고 얼마나 접촉을 유지해야 하는지 명시한다.

목적은 움직이는 기타에 대해 이 목표를 수행하면서 기타 이탈·과도한 회전·접지 상실과 관절 안전 위반을 줄이는 것이다. 안정성을 유지하는 것만으로 음악 수행을 대신하지 않는다. 현재 정량 검증은 단음과67음 전곡의 학습 중 수집을 포함한다. 안전 완주와 음악적 연주 성공을 구분한다.

## 3.2 오디오 목표와 전곡 시간표

오디오 전처리는 음이 시작하고 끝나는 시각과 음높이를 추정한다. 운지 계획은 같은 음높이를 연주할 수 있는 현·프렛 가운데 위치와 손가락을 정한다. 현재 제어 평가는 등록된 곡 번들의 목표를 사용하므로 그 성능을 오디오 전사 정확도로 해석하지 않는다.

전곡 대상은 `05_BN2-131-B_solo`의 67음이다. 정본 66이벤트 중 한 묶음이 23.3ms 간격의 두 재타현을 포함한다. 이 두 음은 원 note-on으로 펼치고 묶음의 down 방향을 각각 상속한다. 두 번째 방향의 별도 근거가 없어 사용한 명시적 해석 규칙이다. 기존 release 상한을 보존하며, 모든 음이 압현음인 이번 범위를 열린현·특수 주법으로 일반화하지 않는다. 오디오 29.3063946초에 정책 준비 3초와 종료 후 0.5초를 더하고 제어 주기에 맞춰 올림하여 1969tick, 32.8166667초로 구성한다.

## 3.3 물리 장면과 관절 역할

휴머노이드의 Root만 고정하고 하체는 원 가동범위와 유한한 자세 유지 제어를 사용한다. 105개 입력 채널, 97개 비영 가동범위 축, 원래 영범위인 8축을 구분한다. 정책 출력은 왼팔·왼손 33개와 오른팔꿈치·손목 6개다. 몸통·오른어깨·상완·허벅지 등의 지지 목표와 오른손의 피크 파지 목표는 기존 유한 제어로 유지한다. 목표가 일정해도 실제 관절이 잠기는 것은 아니며 접촉과 구동에 따라 움직인다.

기타는 자유 강체·중력 ON·스트랩 OFF다. 지지 부위의 접촉 분담 변화와 짧은 접촉 이탈을 허용한다. 가슴 접촉 지속 자체를 학습 성공 조건으로 두지 않는다. 기타에 직접 보조 힘을 가하거나 강제로 부착하고 실행 중 상태를 덮어쓰지 않는다. 초기 상태 복원은 에피소드 경계에서만 수행한다.

## 3.4 움직이는 기타를 기준으로 한 관측

현재 기타 좌표계에서 손·피크와 목표의 상대 위치·속도를 계산한다. 기타가 움직여도 ‘이 현의 이 프렛’이라는 목표의 의미를 유지하기 위해서다. 기본 상태 468개에는 105관절의 각도 차·속도·목표 오차, 직전 39행동, 신체와 기타의 상대 운동, 접촉과 안전 이력, 음악 진행 및 검출 상태가 들어간다. 목표별 토큰은 각 24특징이며 유효 마스크와 두 개의 우선 토큰을 attention에 제공한다. Attention은 여러 목표 중 현재 행동에 필요한 정보를 선택하는 신경망 연산이다.

손별 단음 품질 경로는 기술·타이밍·품질 이력을 더해 563차원이다. 단음 joint는 두 손의 563관측과 공동 이력 6개를 합쳐 1132상태를 사용한다. 각 Actor는 자기 손의 563관측과 공동 이력 6개, 총 569입력을 받는다. 전곡에서는 단음 이력을 재사용하지 않고 기본 468과 곡 이력 32를 합친 500상태를 사용한다. 차원 수나 가중치 파일이 비슷하다는 이유로 두 계약을 동일하게 보지 않는다.

## 3.5 정책 초기화와 공동 학습

두 Actor는 왼손 33축과 오른손 6축의 명령을 각각 출력한다. 중앙 Critic은 미래 음악 보상과 안정성 비용을 별도로 예측한다. 기존 손별 Actor를 초기값으로 쓸 때 해당 Actor와 탐색 분산만 이전하며 공동 Critic과 Adam 최적화 상태는 새로 시작한다. 단음 joint의 추가 입력 6열은 0으로 초기화하여 원 관측에서 출력을 보존한다.

전곡은 관측의 의미가 달라 같은 이전 규칙을 사용할 수 없다. 기존 Actor에서 필드 이름과 scale이 동일한 460개 물리 입력 열, 토큰 encoder·출력 head·분산만 복사한다. 새 음악·곡 이력 40열은 0으로 두고 단음 이력 95열은 이전하지 않는다. 이는 특징 초기화이며 원 정책 출력이나 음악 성공을 보존한다는 주장이 아니다. 다른 계약의 checkpoint를 학습 상태 전체를 복원하는 strict resume로 읽지 않는다.

39개 정규화 명령은 원 관절 범위·목표 크기·평활화 계약을 거쳐 단일 제출 경로로 들어간다. 제어 주파수 60Hz의 각 목표를 240Hz 물리 계산 네 번에 걸쳐 평가한다. 두 Actor를 공동 PPO로 학습하며 별도의 출력 합성망은 두지 않는다.

## 3.6 압현·타현과 공동 판정

압현은 물리 접촉과 목표 기하의 증거를 사용한다. 원 목표 접촉 후보와 올바른 압현을 구분한다. 목표 현의 확인된 높은 프렛·잘못된 프렛·잘못된 손가락 배정이 있으면 clean 후보에서 제외한다. 다른 현의 부수 접촉이나 귀속이 불명확한 경계 접촉은 일괄 오압현으로 단정하지 않는다. 손끝과 목표의 거리는 접근 보상과 진단이며 압현 성공 자체가 아니다.

타현은 이전·현재 물리 표본의 피크 선분이 유한한 현 영역을 통과하는지 검사한다. 깊이·위치 구간·속도·방향·재무장 조건을 확인하고 고유 crossing ID로 중복을 방지한다. 이는 기하 사건이며 현의 반력·진동·소리를 계산하지 않는다.

단음 공동 성공은 양손 전체 품질 조건과 타현 순간의 압현 결합을 요구한다. 전곡 원장은 crossing 하나를 같은 현·방향·시간창에 속하는 최근접 미매칭 목표 하나에 배정한다. 전후 두 물리 표본의 clean 압현이 유지되면 협응을 기록한다. 반복 타현을 위해 연속 검출기를 재무장하고, 동일 현의 다음 정당한 음 전환에 완전한 손 해제를 강요하지 않는다. 완화된 ±0.5초 학습창과 원래 50/100ms 음악 판정은 별도로 보고한다.

## 3.7 보상·안전·검증

음악 보상은 clean 압현 유지·필요 유지량 달성·적시 타현·양손 결합과 오압현·미압현·누락·잘못된 타현을 구분한다. 접근 거리와 타현 가이드의 연속 보상은 성공 판정을 대신하지 않는다. 공유 행동 변화 항과 안정성 비용은 한 번만 적용하며 실패 tick의 모든 양성 항을 억제한다. 기타의 이동·회전, 실제 접지와 관절 안전을 240Hz에서 측정한다. 60Hz 끝점만으로 구간 최댓값을 주장하지 않는다.

각 worker는 물리 장면과 자산을 한 번만 만든 뒤 에피소드 경계에서 상태와 이력을 복원한다. PPO rollout 경계는 에피소드 종료가 아니며 곡 중간의 물리 상태를 유지한다. 소비한 소스·설정·자산은 사전/사후 SHA로 확인한다. 수집·로그·디스크 기록·PPO 반영·제외 전이를 분리하여 보고하며 엄격한 모델 불러오기는 관측·행동·목표·보상·물리·PPO 계약을 대조한다.
