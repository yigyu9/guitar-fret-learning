# 정면 전신 60fps 영상 제작 기준

사용자 요청: 높은 프레임률의 정면 전신 영상 한 편. 오른손 타현과 왼손의 넥 해제·재접촉이 보이게 한다.

원자료는 기존 035 설정·실용 V3에서 평가한 native_free_strike_v14 및 native_regrasp_v14다. 위치는 /home/ajou/yigyu/3/paper/initial_pose/lower_body_release_v1/front_facing_ready_v1/ 아래다. states240.json은 gzip 압축된 240Hz 실제 상태다.

- 구간 A: free_strike 17–40초. 준비 유지, 왼손 해제22–25초, 오른손 타현27–39초.
- 구간 B: regrasp 40–49초. 넥 접근·닫기·정착·준비 유지. 이 시험에는 타현이 없다.
- 두 시험의 편집본임을 화면의 구간 표기와 전환으로 분명히 한다. 같은 실행의 연속 성공으로 설명하지 않는다.
- 60fps, 원시240Hz의 4step 간격 실제 상태를 선택한다. 기존5fps의 반복 프레임이나 광학 보간으로 대체하지 않는다. 정상속도 재생.
- 정면에서 머리·기타·양손·발을 모두 보이게 한다. 1920×1080 또는1280×720. 자막은 화면 가장자리의 전용 공간을 사용해 신체를 가리지 않는다.
- 새 물리 실험·제어 변경·학습은 없다. 저장 자세를 화면에 재생하는 것은 영상 전용이며 물리 안정화를 위한 상태 덮어쓰기가 아니다.
- 원본 인체·기타·의자 배치와 모델을 유지한다. 원시 body pose를 사용하며 native renderer와 source proxy를 구분해 기록한다.
- 원자료와 직접 읽는 소스·helper·자산 SHA를 실행 전후 기록한다. 같은 렌더러의17초·타현 중·복귀 후 미리보기를 먼저 확인한다.

역할: Sol은 새 renderer 구현과 정확한 표본 선택 검증, Luna는 승인된 renderer/brief로 영상 산출물 작성, root는 실행 허용·시각 확인·최종 검증 및 자료 색인, change-reviewer는 독립 검수다. 기존 소비 파일은 바꾸지 않고 재시도는 새 출력 경로를 사용한다.
