# 정면 전신 60fps 영상 제작 기준 V2

기존 BRIEF.md의 동작 구간·60fps·정면 전신·두 개별 시험 표시·원본 보존·역할 분담을 유지한다. v5 preview와 restore_diagnostic_v1에서 native human rigid-body state setter가 관절값과 실제 몸체 위치/회전을 변경하는 문제를 확인했다. 원본 실험 자료는 변경하지 않았고 진단의 물리 진행은0이다.

## 영상 재생 방식

- 인체는 저장된 105축 DOF 위치·속도를 정확히 복원하고 native renderer의 운동학 계산으로 그린다. human rigid-body setter는 사용하지 않는다.
- 기타·의자는 저장된 body pose를 복원한다. 기타의 동역학을 다시 적분하거나 인체와 새로운 상호작용을 계산하지 않는다.
- 이는 **기록된 관절 상태를 이용한 시각 재생**이다. 원래 native의 모든 body state/velocity를 정확히 재현한 녹화나 새로운 물리 실험으로 설명하지 않는다.
- 모든 프레임에서 저장된 인체 body 위치/회전과 렌더러의 위치/회전 차이를 측정한다. 회전 차이는 정규화한 쿼터니언으로 계산한다. 최대 오차와 해당 body/시각을 기록한다.
- 영상 전용 허용 범위는 위치1mm, 회전0.1도다. 정면 전신 화면에서 작은 시각 차이로 제한하기 위한 기준이며, V3의 물리·source 형상·관절 건강 기준을 변경하는 것이 아니다. 임계값을 넘으면 출력을 중단한다.
- human DOF 복원 및 기타·의자의 native pose 복원은 기존1e-6 성분 오차 한도를 유지한다. 인체 body velocity는 동일성을 주장하지 않는다.
- 그래픽 갱신 전후 상태 불변과 simulate/fetch/force 차단을 유지한다.
