과거 고정 기타 타현: Strike-v2
    정리일: 2026-11-04
    대상: 2026-10-19에 보관된 G0 고정 기타 코드와 2026-09-20 Jazz1 학습의 저장 기록
    현재 guitar_learning의 자유 기타·right27 환경과는 별도 구현
    아래의 구조·기본값은 보관 코드를 기준으로 하며, 실제 Jazz1 실행에서 확인한 값은 마지막 절에 따로 표시


환경과 역할
    오른손의 준비, 목표 줄로 접근, 타현, 다음 타현을 위한 회복을 하나의 정책으로 학습
    single pick과 여러 줄 strum을 같은 정책에서 목표 종류에 따라 처리
    왼손 압현 성공이나 자유 기타의 전신 지지·균형은 이 정책의 학습 대상이 아님

    기타: 루트 고정(fix_base_link=True), 기타 중력 OFF
    신체: 골반 루트 고정, 신체 중력 ON
    하체: 관절 잠금과 매 물리 호출 뒤 잠긴 관절의 상태 복원 사용
        기타 루트를 매 프레임 덮어쓰는 방식과는 구분. 기타 고정은 자산의 fixed-base 설정으로 구현
    제어: 관절 목표각을 PD 제어로 추종하고 토크 상한을 적용
    시간: 환경·정책 제어 60Hz, 한 제어 step 안에 PhysX 내부 substep 4회
        내부 물리 적분 간격은 1/240초. 모든 판정·관측·로그가 240Hz 표본이라는 뜻은 아님
    피크: 검지 두 번째 마디에 붙은 RH:pick 가상 기준점
        피크와 현의 기하 교차를 판정하며, 실제 피크 파지력·현 진동·음향 성공은 별도 문제

        S3 곡 통합 단계에서 사용하며 다른 학습 단계에서는 0으로 입력

    동작 단계·검출기 상태 (29): O_phase_detector
        동작 단계 one-hot(3), 준비 유지 진행률(1), 사건 처리 완료 여부(1)
        통과 완료 줄(6), 재타현 허용 상태(6), 재무장 진행률(6), 최근 release 상태(6)
        동작 단계는 READY, APPROACH, RELEASE_RECOVER의 3개이며 아래의 9개 학습 단계와 구분

    회복 상태 (18): O_recovery
        유효 여부(1), 회복 모드 플래그(3), 진행률(1), 요구·가용 시간 비율(2)
        피크 분리 상태(3), 현재 회복 목표까지 벡터(3), 다음 진입점까지 벡터(3), 방향(2)
        시간 여유에 따른 완전 회복과 다음 목표로의 인계, 분리·재무장 조건을 표현

    동기화 문맥 (2): O_synchronizer
        release 허용 여부(1), 목표 시각 보정(1)
        두 값은 입력이며, 타현 정책의 별도 출력 명령이 아님

    이전 행동 (30): O_history
        지수이동평균(EMA)을 거쳐 직전에 실행한 행동30개

    입력은 RunningMeanStd로 정규화하고 ±5로 제한
    동일한 수집·PPO 갱신 안에서는 정규화 통계를 유지하고 갱신 종료 후 통계를 업데이트
    과거 v1의 327차원 관측과 현재 right27의 관측은 별도 계약


출력 (30)
    오른쪽 어깨 (3): R_Shoulder
    오른쪽 팔꿈치 (3): R_Elbow
    오른쪽 손목 (3): R_Wrist
    오른손 손가락 (21): 엄지5, 검지·중지·약지·소지 각4

    모든 정책 행동은 [-1, 1] 범위
    팔9축: 관절 범위의 중심과 반범위로 환산하는 절대 PD 목표각 요청
        이전 목표각에 계속 더하는 누적 증분 방식이 아님
    손21축: 기준 그립 자세 주변의 관절별 잔차
        엄지·검지9축은 기본 ±0.08rad, 나머지12축은 기본 ±0.22rad
        별도의 그립 폭 스칼라가 아니라 손가락 관절별 목표각을 출력
    행동을 EMA로 완만하게 적용하고 관절 범위로 제한
    A0 파지 학습에서는 팔 행동을 유지값으로 고정
    현재 구상한 타현27축과 달리, 과거 정책은 오른쪽 어깨3축까지 직접 제어


신경망
    모델 계약: strike.block_encoder_mlp.v1
    각 블록을 Linear -> ELU 한 층으로 인코딩

        관절 상태       60 -> 96
        팔 기준 상태    18 -> 48
        손·피크 기하    30 -> 64
        그립·안전        7 -> 16
        현재 목표       32 -> 64
        목표 기하       25 -> 48
        미래 목표       52 -> 64
        단계·검출기     29 -> 48
        회복 상태       18 -> 48
        동기화 문맥      2 -> 8
        이전 행동       30 -> 48

    11개 인코더 출력을 연결: 96 + 48 + 64 + 16 + 64 + 48 + 64 + 48 + 48 + 8 + 48 = 552

    Actor
        정규화된303 -> Actor 전용 블록 인코더 -> 552 -> 512 -> 256 -> 평균30
        학습 가능한 log_std30을 별도로 사용하여 독립 Gaussian 분포 구성
        학습 시 분포에서 표본을 뽑고 tanh를 적용. 결정적 평가에서는 tanh(평균)를 사용
        보관된 학습 설정의 초기 표준편차는 0.04, log_std 범위는 [-5, 1]
        초기 평균은 환경의 중립 행동을 반영하므로 모든 관절의 평균0을 가정하지 않음

    Critic
        정규화된303 -> Critic 전용 블록 인코더 -> 552 -> 512 -> 256 -> 가치1

    Actor와 Critic의 블록 인코더·결합 신경망은 서로 별도 파라미터
    입력 정규화 통계만 공유. 512·256 은닉층의 활성함수는 ELU이며 마지막 출력은 선형
    순환 신경망이나 attention을 사용하지 않는 전방향 MLP 구조
    단일 스칼라 보상과 가치1개를 사용하며 현재 압현의 reward/cost 분리 critic 구조와 다름


학습 구조
    목표 사건 생성 -> 목표 구간 샘플링 -> 정책 행동 -> PD·물리 진행
    -> 피크 교차·준비·회복 측정 -> 단계별 보상 -> rollout 수집 -> PPO 갱신
    -> 완료 episode의 평가 증거를 모아 커리큘럼 진행 -> 저장·별도 전체곡 평가

    보관 코드의 PPO 기본값
        병렬 환경 수: 512
        수집 길이: 환경당 32개 제어 step
        미니배치: 2,048개, PPO epoch: 5
        Actor 학습률: 3e-6, Critic 학습률: 3e-4
        최적화: Adam의 Actor·Critic별 학습률 그룹
        할인율 gamma: 0.95, GAE lambda: 0.95
        PPO clip: 0.2, 가치 손실 계수: 1, entropy 계수: 0.001
        최대 gradient norm: 1, target KL: 0.03
        행동 포화 정규화: 가중치0.002, 임계0.90. 환경 보상과는 별도의 PPO 손실 항
        계획 반복 수: 50,000. 계획 예산과 실제 완료 반복 수는 구분

    전체 구현된 학습 단계
        A0: 그립 자세
        A1: 피크 준비점 도달·유지
        A2: 준비 후 단일 줄 통과
        A3: 정해진 시각의 단일 타현
        A4: 스트럼 문맥과 회복
        S0: 두 줄 스트럼
        S1: 스트럼 범위 확대
        S2: 정해진 시각의 스트럼
        S3: 곡 통합

    단계가 바뀌어도 관측303·행동30은 유지하고 목표 샘플링, 보상 적용 항, 타이밍 조건을 변경
    승급은 최소 반복 수와 안전·그립·정확도 등의 조건을 만족한 연속3개 증거 묶음으로 판단
        증거는 완료 episode를 모으고 기본 묶음 크기는 병렬 환경 수와 동일
        A3에서는 허용창100 -> 67 -> 50ms, 대응 F1 기준0.80 -> 0.90 -> 0.95
        최대 반복에 도달했다는 이유만으로 성공 승급시키지 않음
    S3는 완화된 목표 시간축에서 원곡 시간축으로 보간하고 학습 구간도 점차 확대
        tempo_lambda는 0 -> 0.25 -> 0.5 -> 0.75 -> 0.9 -> 0.95 -> 0.975 -> 1
        0은 재생속도0배가 아니라 시간축 보간의 시작값
        정체 시 어려운 구간과 균등 구간을 기본 50:50으로 유지하며 승급 증거에는 균등 표본 사용


보상 구조
    하나의 스칼라 보상으로 합산하되 커리큘럼 단계마다 활성 항과 계수를 변경
    아래 수치는 보관된 설정의 S3 대표값이며 다른 단계에 동일하게 적용하지 않음
    연속 품질·진행량 항과 목표당 최초 완료 신호에 지급하는 항을 구분

    그립 유지
        엄지·검지와 나머지 손가락의 기준 자세 오차로 품질 Qg 계산
        Qg = 0.65 * exp(-(엄지검지 RMS 각도오차 / 20도)^2)
             + 0.35 * exp(-(나머지 RMS 각도오차 / 25도)^2)
        A0는 +Qg, S3는 -0.02 * (1-Qg)
        실제 피크를 잡는 힘이 아니라 기준 관절 자세의 품질

    목표 접근
        현재 동작 단계에 해당하는 목표점까지 거리 d로 품질 Phi = exp(-d / 준비 거리 기준)을 계산
        기본 준비 거리 기준은 0.01m, 진행량은 0.95 * 다음 Phi - 현재 Phi
        S3 유효 계수는 0.40: 기본 접근0.20과 단계별 접근0.20을 합산
        진행량은 [-1, 1]로 제한하고 첫 표본·목표 교체에서 생기는 가짜 진행 보상을 차단

    준비 품질·준비 완료
        준비점 거리 d로 Qr = 0.4 * exp(-(d/0.120m)^2) + 0.6 * exp(-(d/0.025m)^2)
        A1은 +0.75Qr, S3는 준비 획득 전 -0.02 * (1-Qr)
        준비점1cm 이내와 그립 성공을 기본6제어프레임 연속 충족하면 준비 완료를 기록
        S3 준비 완료 최초 신호에 +0.25. 설정 이름 completion_reward는 이 준비 완료 보너스
        준비를 획득한 뒤에는 준비 부족 감점을 계속 부과하지 않음

    유효 타현
        목표 줄·방향·깊이·속도·타이밍·재무장 등 교차 조건을 만족하고 준비도 획득했을 때 +1
        준비 없이 발생한 목표 교차는 성공 보상 없이 S3에서 -1
        단순히 줄 근처에 도착한 것과 실제 피크 선분이 줄을 통과한 것을 구분

    타이밍·대기·타현 구역
        타이밍 품질 q(e) = 1 / (1 + (타이밍 오차 e / core)^2)
        신규 승인 교차의 품질을 목표 현 수로 정규화하고 clean 사건·준비 획득 조건에서 S3 계수0.75 적용
        준비 후 접근 시작 전 대기는 +0.01Qr
        준비된 타현 시도의 구역 품질에는 계수0.20 적용
        구역 보상과 교차 성공 판정의 구역 제한은 별도 조건
        S3의 프로필 적용 후 타이밍 core는20ms, 스트럼 길이 core는25ms

    타현 후 회복
        피크 분리, 재타현 허용, 필요한 회복 시간, 다음 목표로의 인계 조건을 사용
        실제 보상에는 경로·시간에 맞춰 계산한 scheduled 회복 진행·완료를 연결
        S3는 최고 회복 진행률 증가분에0.30, 회복 완료 최초 신호에0.30
        회복 중 추가 release는 회복 진행을 초기화
        과속 감점: -0.10 * clip((회복 속도-0.20m/s) / 0.50m/s, 0, 1)^2
        단순히 타현을 한 번 성공한 것과 다음 타현이 가능한 상태로 돌아온 것을 별도 평가

    스트럼 전용 항
        준비된 스트럼의 순차 통과 진행률에 S3 계수1.0
