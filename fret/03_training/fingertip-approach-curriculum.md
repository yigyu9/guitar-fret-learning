# 손가락 접근 선행 커리큘럼 설계

> 상태: 2026-08-18 조합별 누적 증거와 schema 43 반영

## 1. 필요한 이유

초기 정책은 전체곡을 완주했지만 PRESS F1이 0이었다. 손끝도 목표에서 평균 10.22cm 떨어졌다.
이 실패를 해결하려고 손끝 접근 선행 커리큘럼을 추가했다.

기존 `coverage → integration → full_song` 커리큘럼은 곡의 시작 시점만 바꾼다. 처음부터 전체 보상을
동시에 켜기 때문에 정책은 어려운 PRESS 대신 손목·엄지·자세와 쉬운 NO_PRESS 점수를 먼저 학습할 수
있다. 따라서 곡의 시간 커리큘럼 앞에 **손끝 도달 능력을 먼저 획득하는 선행 커리큘럼**을 둔다.

## 2. 변하지 않는 원칙

- 새 목표를 만들지 않고 현재 곡에 실제로 존재하는 `(손가락, 줄, 프렛)`만 사용한다.
- 최종 압현 규칙은 접근 30%, 실제 압현 50%, 좋은 위치 20%를 유지한다.
- 바레는 현재처럼 사용하지 않으며 확장 필드만 보존한다.
- 관통, 손목 이탈, 손바닥 방향, 손가락 후면 이탈, 엄지 과압 등 안전 종료는 모든 단계에서 적용한다.
- 같은 정책을 단계별로 이어 학습하며 단계가 바뀔 때 Actor를 초기화하지 않는다.
- 단계 승급은 iteration 수만으로 하지 않고 deterministic 성능으로 결정한다.

## 3. 목표 표본 구성

곡의 연속된 PRESS 프레임을 이벤트로 묶고 각 이벤트에서 아래 정보를 만든다.

```text
(finger, string, fret, start_frame, end_frame, next_relation)
```

초기 세 단계에서는 한 episode에 이 중 하나를 고르고 목표를 고정한다. 표본은 프레임 수 비율로 뽑지
않는다. 현재 곡은 검지 550, 중지 73, 약지 323, 소지 19 PRESS-frame으로 불균형하기 때문이다.

1. 손가락 1~4를 균등하게 선택한다.
2. 선택한 손가락에 속한 고유 `(줄, 프렛)` 조합을 균등하게 선택한다.
3. 같은 조합의 이벤트가 여러 개면 이벤트를 균등하게 선택한다.

이렇게 하면 각 episode의 기준 손가락은 약 25%씩 선택된다. 실제 활성 frame 수는 코드 동시 압현과
이벤트 길이 때문에 달라질 수 있으므로 손가락별 성공률·거리·표본 수도 함께 기록한다. 곡에 특정
손가락 목표가 전혀 없으면 그 손가락은 분모에서 제외하고 이를 manifest에 기록한다.

## 4. 단계

### A0. Coarse Reach — 손끝을 기타 주변까지 이동

- 한 개의 실제 PRESS 목표를 2초(120 frame) 동안 고정한다.
- 선택된 지정 손가락과 목표 줄·프렛만 양의 보상을 낸다.
- 다른 줄은 학습 보상상 0이다. 단, 관통·과압 등의 안전 판정은 면제하지 않는다.
- 손목·엄지·근위관절·hover·slip·NO_PRESS·all-correct 양의 보상은 0으로 마스킹한다.
- 목표: 지정 손끝 표면과 20% 압점 사이 거리 `d ≤ 40mm`를 12 frame 연속 유지한다.

단계 전용 접근 보상은 멀리서도 기울기가 사라지지 않도록 구성한다.

```text
A(d) = clamp((250mm - d) / (250mm - 10mm), 0, 1)
P(t) = clamp((d[t-1] - d[t]) / 2mm, -1, 1)
r_A0 = 0.75 A(d) + 0.25 P(t)
```

`P(t)`는 가까워지는 동작에는 양수, 멀어지는 동작에는 음수를 준다. episode 첫 frame에서는 0이다.
이는 최종 30/50/20 규칙을 바꾸는 보상이 아니라, 접근 항만 임시로 100% 확대하는 발판이다.
25cm 바깥 경계는 균등 손가락 표본의 초기 p90 거리 17.7cm를 포괄하도록 GPU 스모크 결과에 맞춰
정했다.

### A1. Fine Reach — 올바른 줄·프렛 셀에 정렬

- 표본과 episode 길이는 A0와 같다.
- 손끝 축의 목표는 줄 중심에서 기타 바깥쪽으로 `pad 반지름 + 1.5mm` 떨어진 지점이다. 안쪽으로
  지나치는 자세도 다시 오차가 커진다.
- 목표는 손끝 중심 거리 `≤ 10mm`, 3축 정렬 품질 `≥ 0.8`이다.
- 12 frame 연속 만족해야 성공이다.
- 정렬 core는 목표 중심 거리 45%, 프렛 길이 방향 20%, 줄 가로 방향 20%, 현 바깥 높이 15%다.
  최종 A1 보상은 `0.80 × 정렬 core + 0.20 × 접근 진행량`이다.
- 일반 압현에서는 distal segment 전체가 아니라 실제 손끝 endpoint만 후보로 사용한다.
  바레 확장 경로만 segment 전체 후보를 보존한다.
- 나머지 보조 보상과 비활성 채널은 계속 0이다.

### A2-I. Isolated Press — 손가락 중심 압현

- 동일한 단일 목표를 3초(180 frame) 동안 고정한다.
- 준비 1초 동안은 왼팔 전체로 목표 근처까지 이동할 수 있다.
- 이후에는 엄지·지정 손가락·손목만 새 action을 받고, 팔꿈치·어깨와 비활성 손가락은 직전 명령을
  유지한다.
- MCP/PIP/DIP는 하나의 고정 각도가 아니라 넓은 soft range의 아치 품질로 평가한다.
- PIP의 soft shoulder는 초기 중립 자세(약 0도)까지 이어져, 처음부터 굽힘 방향 학습 신호가 생긴다.
- 기존 정렬 checkpoint에서 시작할 때 MCP/PIP/DIP action의 초기 탐색 표준편차만 0.08로 넓힌다.
  손목·팔꿈치·어깨의 탐색 폭은 0.02로 유지해 상체 안정성을 훼손하지 않는다.
- 기존 checkpoint에서 하한에 포화된 PIP/DIP 출력 행만 각각 15도/10도의 약한 아치로 다시 초기화한다.
  다른 손가락 축과 손목·팔의 학습 가중치는 그대로 보존한다.
- `30/50/20` 중 좋은 위치 20%는 프렛 위치 10%, 손끝 법선 방향 5%, 아치 품질 5%로 구성한다.
- 실제 압현, 복합 위치 품질 0.5, 아치 품질 0.65를 12 frame 연속 만족해야 성공한다.
- 로그에는 MCP/PIP/DIP 평균 굽힘각, 아치 품질, endpoint 접촉률, 비손끝 접촉률과 action-mask
  활성률을 기록한다.
- 목표점에 가까울 때만 아치 품질 신호를 강화한다. 멀리서 손가락만 구부려 점수를 얻을 수 없으며,
  최종 과제의 30/50/20 압현 점수 체계는 유지한다.
- 엄지 실제 접촉률은 보상·진단값으로 남기지만 승급을 막지 않는다.

### A2-G. Integrated Press — 전체 왼팔 압현 통합

`isolated_press`를 통과하면 손목·팔꿈치·어깨를 한꺼번에 연다. 관절을 하나씩 잠그는 인위적인
중간 단계를 없애고, 기존의 손가락→손목→팔꿈치→어깨 움직임 비용으로 불필요한 큰 동작을 억제한다.

- 동일한 단일 목표를 3초(180 frame) 동안 고정한다.
- 지정 손가락 보상은 원래 규칙인 `접근 30% + 실제 압현 50% + 좋은 위치 20%`로 되돌린다.
- `press_success`와 위치 품질 `≥ 0.5`를 12 frame 연속 유지하면 성공이다.
- NO_PRESS의 양의 점수는 아직 주지 않는다. 오압현이 생기면 해당 PRESS 점수를 0으로 만드는 기존
  규칙과 모든 안전 종료는 유지한다.
- 엄지 지지는 손끝 거리 80mm부터 열리고 25mm 안에서 최대 10%가 된다. 손끝 목표 점수보다 먼저
  얻을 수 없도록 선택 PRESS 채널에만 결합한다. 손끝이 가까운데 지지가 없으면 PRESS 점수를 최대
  25% 낮춘다.
- 승급에는 실제 접촉률 대신 넥 뒤 목표까지 평균 거리 15mm 이하를 사용한다. 현재 접촉 판정은
  `thumb3` net link force 기반의 희소 proxy이므로 검증 전까지 hard gate로 사용하지 않는다.

### A2-C. Stable Chord — 지속되는 동시 압현

- 0.2초(60Hz 기준 12 frame) 이상 유지된 다중 손가락 상태만 정적 코드로 사용한다.
- 짧은 손가락 겹침은 정적 코드에서 제외하고 Goal Pair·Transition 단계에는 보존한다.
- 같은 손가락 조합 안에서는 원곡 지속시간에 비례해 자세를 표집한다. 조합 사이에는 균형 표집을
  유지해 드문 손가락을 잊지 않게 한다.
- 안정 코드가 없는 곡은 `chord_reach`, `chord_fine_reach`, `static_chord`를 자동으로 건너뛴다.
- 목표 근처 15mm에 도착하고도 누르지 않으면 0.20을 감점한다. 압현 후 이탈은 0.25를 감점한다.
  오압현은 해당 줄 점수 0점과 기존 0.35 감점을 유지한다.

### A3. Goal Pair — 놓기·이동·유지 연결

- 곡에서 실제로 연속하는 두 목표 이벤트를 사용한다.
- 단일 pair는 전환 전·후 목표를 각각 0.75~1초 제시한다.
- `KEEP / MOVE / REST`는 곡에 존재하는 관계만 사용한다.
- 실제 동시 압현이 있는 frame은 그대로 사용하여 최대 두 손가락을 함께 학습한다.
- PRESS 규칙과 NO_PRESS 판정을 모두 켜되, 초기에는 Actor가 받는 양의 점수의 최소 80%가 PRESS
  목표에서 오도록 제한한다. DONT_CARE는 항상 0점이다.
- `retention → mixed 0 → mixed 1 → mixed 2 → full` 순서로 곡 문맥 비율을 늘린다.
  mixed의 연속 구간 비율은 각각 40%, 50%, 60%다. 구간은 최대 8→12→16 이벤트로 늘리고,
  full에서는 최대 16 이벤트와 전곡 표본을 섞는다.
- 연속 구간은 목표 이벤트 뒤가 아니라 목표 직전의 최대 12초를 재생한다. 약한 손가락이 등장하기
  전의 손 모양과 전환을 함께 학습하며, 선택한 incoming 이벤트는 항상 구간 끝에 남긴다.
- 손가락별 다음 이벤트 시간은 2초 범위로 정규화한다. 1.5초 lookahead 밖의 이벤트는 MOVE 보상과
  release 게이트를 활성화하지 않으며, 범위 안에 들어온 뒤에만 접근을 시작한다.
- 손가락별 PPO action 라우팅 훅은 구현했지만 기본값은 껐다. 물리 제어까지 제한하면 F1이
  약 0.55→0.19로 급락했고, 확률항만 제한해도 약 0.20으로 떨어졌다. 상태마다 확률 차원이 바뀌는
  방식보다 고정 action 공간과 국소 성공 action 복습이 현재 정책에는 안전하다.
- pair와 연속 구간은 전환 종류와 incoming 손가락을 계층적으로 균형 표집한다. 흔한 음이나 한
  손가락이 batch를 독점하지 않는다.
- retention은 한 frame을 복제하지 않는다. 손가락별로 균형 선택한 압현 상태에서 실제 곡의
  두 연속 구간을 재생한다. 미래 goal·손가락 이벤트·보상은 모두 같은 원곡 시간대를 가리킨다.
- 기본 표본은 네 손가락을 매 batch에서 함께 학습한다. mixed 단계에서는 실제 곡 성공률과
  전환 오압현률이 가장 낮은 손가락에 pair·prefix 표본의 25%를 우선 배정하되 나머지 손가락의
  복습 표본은 유지한다.
- mixed 0/1/2의 손가락별 실제 곡 압현 gate는 10%→30%→50%이고, 전환·실제 곡 오압현 상한은
  10%→8%→6%다. 단독 rehearsal를 통과해도 실제 곡 gate를 통과하지 못하면 숙달로 처리하지 않는다.
- 회복 episode는 sequence 50%, 정적 rehearsal 25%, pair 25%가 되도록 구성한다. sequence의 20%는
  전곡이고 나머지는 취약 incoming 전환 직전의 원곡 구간이다.
- 새 숙달은 press 성공률 80%, 평균 목표 거리 10mm, hold 품질 80%, dropout 12% 이하를
  모두 만족해야 한다. 이미 숙달한 손가락은 각각 70%, 20mm, 75%, 15% 기준으로 감시한다.
- 성능 회귀가 두 평가 window 이어지거나 phase가 제한 시간을 넘기면 같은 phase에서 회복 모드로
  들어간다. 회복 종료는 최종 목표 절댓값이 아니라 해당 phase 기준선의 회복 여부로 판정한다.
  회복 중에도 네 손가락을 균형 표집하며 특정 손가락에 편향하지 않는다.
- 회복 episode에서는 모든 손가락과 손목·팔꿈치·어깨를 허용한다. 최신 실패 정책의 MCP 기준 국소 도달 여유가
  손가락별 약 -11cm였으므로 손목만 허용하면 일부 목표가 사실상 도달 불가능했다.
- hold·위치·엄지 지지가 모두 좋은 실제 압현 자세는 goal 상태별 cache에 저장한다. 이후 reset의
  35%에서 같은 goal의 성공 자세를 사용하고 나머지는 기존 초기 자세를 사용한다.
- 성공 순간 정책이 실제로 낸 손가락 action도 같은 goal별 cache에 저장한다. 위치 품질 0.70 이상인
  국소 압현 구간에서만 PPO 평균 action에 가중치 0.05의 복습 손실을 준다. 드문 손가락 action이
  batch 빈도에 묻히지 않도록 action 차원별로 평균한다.
- 성공 action으로 손목·팔꿈치·어깨까지 직접 유도하는 방식은 안전 종료와 전곡 성능을 악화시켜
  비활성화했다. 현재 보조 교사는 손가락 관절에만 적용한다.
- 사람 왼손 scale 모션은 정답 궤적으로 강제하지 않는다. 비활성 손가락과 엄지가 사람 자세 분포에서
  크게 벗어날 때만 최대 0.03을 감점한다. 활성 압현 손가락은 이 prior에서 제외한다.
- 일반 기타 관통은 2.5~5mm에서 부드럽게 감점하고 5mm 이상 3 frame이면 종료한다. 엄지 체인은
  지지 접촉과 겹치므로 이 판정에서 제외하고 엄지 전용 접촉 위치·압축·과힘 규칙으로 처리한다.
- 회귀 기준은 이전 Frozen Context가 아니라 현재 `retention`, `mixed 0/1/2`, `full`에서 처음
  수집한 4,096 episode window다. 난이도가 달라질 때 기준선도 새로 만든다.
- 회복은 최소 100 iteration 뒤 현재 phase 기준선의 품질을 정상 gate 2개 window에서 회복하면 끝난다.
  손가락별 최종 mastery는 phase 승급 조건이며 회복 종료 조건으로 중복 사용하지 않는다.
  600 iteration 안에 복구하지 못하면
  `full → mixed 2 → mixed 1 → mixed 0 → retention → frozen_context`
  방향으로 한 단계 rollback한다.
- mixed 회복 뒤에는 전환 성능을 다시 검증한다. phase·기준선·회복·rollback 상태는 checkpoint에
  저장하며 현재 schema는 42이다.
- 오압현은 실제 금지 프렛에 접촉한 손가락별로 기록한다. pair 표본은 유입 손가락별 오압현률과
  이전 손가락→다음 손가락 5×4 전환 행렬을 함께 저장한다. 0행은 이전 압현이 없는 상태다.

### A4. Song Timeline — 기존 곡 커리큘럼

```text
coverage(random start 100%)
  → integration(random start 100%→0%)
  → full_song(frame 0 start)
```

A4에서는 전체 규칙과 보조 보상을 사용한다. 다만 DONT_CARE는 행동과 무관한 1점 baseline이 아니라
0점이어야 하며, 보조 보상이 모든 6개 줄에 복제되어 PRESS보다 커지지 않도록 활성 PRESS/NO_PRESS
채널에만 배분한다.

## 5. 자동 승급과 실패 처리

자동 승급은 준비·이동 구간을 제외한 각 연습 episode의 마지막 30 frame(0.5초)에서만 평균·p90 거리와
정렬률을 집계한다. 완료 episode 성공률은 손가락별로도 계산하며, 평가 표본이 있는 최근 3개 window가
모두 조건을 만족할 때만 다음 단계로 넘어간다. 전체곡 최종 판정은 기존처럼 별도의 deterministic
평가로 수행한다.

| 단계 | 최소 학습 | 최대 학습 | 승급 조건 |
|---|---:|---:|---|
| A0 | 100 iter | 1,000 iter | 전체·손가락별 성공률 ≥ 80%, p90 거리 ≤ 40mm, 엄지 거리 ≤ 50mm |
| A1 | 200 iter | 1,500 iter | 전체·손가락별 성공률 ≥ 80%, p90 거리 ≤ 10mm, cell 정렬률 ≥ 90%, 엄지 거리 ≤ 25mm |
| A2-I | 300 iter | 2,000 iter | 전체·손가락별 성공률 ≥ 80%, 위치 품질 ≥ 0.5, 아치 품질 ≥ 0.65 |
| A2-G | 300 iter | 2,500 iter | 전체·손가락별 성공률 ≥ 80%, 위치 품질 ≥ 0.5, 엄지 거리 ≤ 15mm |
| A3 | 400 iter | 8,000 iter | phase별 손가락 보존·전환 gate와 전체 bridge gate 통과 |
| A4 | 기존 설정 | 별도 실험 한도 | 최종 전체곡 gate 사용 |

평균만 통과하고 특정 손가락이 실패하면 승급하지 않는다. Goal Pair는 최대 iteration에 닿아도
PRESS F1 0.75, 손가락별 성공률 0.70, NO_PRESS 0.90, 오압현 0.05 이하, sustain 0.70,
event 성공률 0.40, 실패 종료율 0.03 이하를 모두 만족해야 강제 전환할 수 있다. 회귀 중에는
강제 전환하지 않는다. 안전 실패는 모든 단계에서 계속 기록한다.

단계가 바뀌면 모든 환경을 새 목표 분포로 함께 리셋하되 Actor·Critic·관측 정규화·optimizer 상태는
그대로 유지한다. 단계, 단계 내 iteration과 강제 전환 횟수는 checkpoint에 저장된다.

## 6. 구현 위치

| 파일 | 변경 내용 |
|---|---|
| `tab2body/learning/curriculum.py` | `A0~A4` 상태기계, 성능 기반 승급과 미통과 중단 구현 |
| `tab2body/env/goals.py` | PRESS 이벤트 색인, 손가락·전환 균형 sampler, 이벤트 수 기반 연속 구간 구현 |
| `tab2body/env/rewards/fret.py` | 단계 mask, 3축 정렬, endpoint 접촉, 도달 여유와 자세 prior 결합 |
| `tab2body/env/rewards/reference_posture.py` | 사람 모션에서 비활성 손가락·엄지 자세 분포 추출 |
| `tab2body/env/tasks/task_fret.py` | action mask, 성공 자세 cache/RSI, stage 진단값 노출 |
| `tab2body/train_fret.py` | 승급·checkpoint 상태, policy warm-start, 종료 후 자동 영상 구현 |
| `tab2body/learning/checkpoint_contract.py` | 커리큘럼 버전·단계·sampler 설정을 재개 계약에 포함 |

현재 관측은 428차원, action은 33차원이다. 기존 353차원 관측의 의미와 순서는 유지하고 끝에
30·60·90 frame 뒤의 goal 문맥 75차원을 붙였다. 정책은 현재 목표뿐 아니라 0.5·1.0·1.5초 뒤의
줄·프렛·손가락 관계를 볼 수 있다. 이전 353차원 checkpoint는 새 입력 가중치를 0으로 초기화해
기존 출력을 보존한다. 커리큘럼 단계 자체는 관측에 넣지 않는다.

`chord_fine_reach`의 조합별 성공 증거는 한 PPO iteration 안에서 256 episode를 요구하지 않는다.
여러 iteration의 완료 episode를 조합별로 누적하고, 각 조합이 최소 표본을 채웠을 때만 승급 창에
반영한다. mixed 구간이 제한 시간에 도달하면 영구 정지하지 않고 조합 집중 학습을 다시 순환한다.

정적 코드 이후 단계는 raw 충돌 힘 대신 연속적인 엄지 후면 정렬·지지 준비도 0.35 이상을 요구한다.
solver force 접촉률은 에셋 보정 전까지 진단값으로 유지한다.

## 7. 검증 항목

- 이벤트 추출이 동일 PRESS run을 하나로 묶고 release 경계를 보존하는지 단위 검사
- 손가락 균형 sampler의 장기 빈도가 의도한 비율인지 검사
- A0~A2에서 선택하지 않은 줄 reward가 정확히 0인지 검사
- DONT_CARE가 reward와 actor advantage에 상수 baseline을 만들지 않는지 검사
- 진행 보상이 가까워질 때 양수, 멀어질 때 음수, 정지 시 0인지 검사
- 안전 종료가 모든 stage에서 동일하게 동작하는 GPU runtime 검사
- checkpoint 재개 후 stage, 평가 누적값, sampler RNG가 정확히 복원되는지 검사
- A0 본 학습에서 평균 거리와 p90 거리가 함께 감소하는지 확인

위 항목은 CPU 단위검사와 GPU 실행검사에 포함한다. 기존 장기 학습은 엄지 접촉률 80% gate 때문에
`finger_articulation`에 정체됐으며, 이 결과를 근거로 현재 구조로 교체했다.

## 8. 첫 구현 후 판단 기준

첫 목표는 곧바로 PRESS F1을 올리는 것이 아니다. A0 100 iteration 후 평균 목표 거리가 현재
10.22cm에서 줄고, 각 손가락의 p90 거리도 함께 감소해야 한다. 이 변화가 없다면 더 오래 학습하지 않고
reset 자세, 손끝 body 정의, action-to-joint mapping, 목표 좌표계를 먼저 다시 감사한다.

구현 직후 검증에서는 8환경 PPO 갱신, A0 episode 종료·자동 리셋, 60-frame 준비 구간, 기존 실패 종료
계약을 GPU PhysX에서 통과했다. 균등 손가락 초기 분포는 평균 15.9cm, p90 17.7cm였으며 이 값을
포괄하도록 선형 접근 보상의 바깥 경계를 25cm로 확정했다.

## 9. Schema 40 기준선과 Schema 41 개선

v20에서 schema 40으로 마이그레이션해 1024환경 200 epoch를 추가 학습하고, 마지막 checkpoint를
64개 전체 곡 episode로 평가했다.

- 학습 마지막 20 epoch의 F1은 0.630, curriculum 성공률은 0.880이었다.
- 결정론적 전체 곡 F1은 0.693으로 v20의 0.671보다 높았다.
- 검지는 85.0%, 약지는 16.7%였다. 중지와 소지는 여전히 0%다.
- 리허설 소지는 20.6%에서 69.6%로 늘었지만 실제 곡 전환으로 이어지지 않았다.
- NO_PRESS 정확도는 0.755, 오압현률은 0.135로 v20보다 나빠졌다.
- 완주율은 98.4%였고 엄지 과힘 종료가 1/64회 발생했다. 엄지 지지율은 90.7%였다.
- 긴 문맥·prefix·정확한 이벤트 시간·국소 action 복습은 전체 F1을 높였지만, 드문 중지·소지의
  장거리 전환과 오압현을 해결했다고 판단하지 않는다.

검증 run은 `fret/training/runs/goal_pair_timing_fix_v24`에 저장했다. 안전한 비교 기준은 완주율 100%인
`goal_pair_safe_long_prefix_v20`이며, v24는 다음 구조 개선을 위한 진단 checkpoint로 취급한다.

Schema 41은 위 실패를 직접 겨냥한다. 손가락별 rehearsal뿐 아니라 실제 곡 압현률과 전환 오압현률을
mixed 숙달·유지·최종 승급에 사용하고, 취약 손가락을 25% 우선 재표집한다. 기존 0.5·1.0·1.5초
미래 문맥과 현재 압현 보존 보상은 의미를 바꾸지 않았다. 새 계약은 단위검사와 GPU smoke를 통과한 뒤
기존 schema 40 checkpoint에서 `--migrate-contract`로 재개해 비교한다.
