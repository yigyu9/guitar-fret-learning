# 손가락 접근 선행 커리큘럼 설계

> 상태: 2026-07-29 압현 단계를 두 단계로 단순화하고 엄지 접촉 hard gate를 진단 전용으로 전환

## 1. 필요한 이유

초기 정책은 전체곡을 완주했지만 PRESS F1이 0이었다. 손끝도 목표에서 평균 10.22cm 떨어졌다.
이 실패를 해결하려고 손끝 접근 선행 커리큘럼을 추가했다.

기존 `coverage → integration → full_song` 커리큘럼은 곡의 시작 시점만 바꾼다. 처음부터 전체 보상을
동시에 켜기 때문에 정책은 어려운 PRESS 대신 손목·엄지·자세와 쉬운 NO_PRESS 점수를 먼저 학습할 수
있다. 따라서 곡의 시간 커리큘럼 앞에 **손끝 도달 능력을 먼저 획득하는 선행 커리큘럼**을 둔다.

## 2. 변하지 않는 원칙

- 새 목표를 만들지 않고 현재 곡에 실제로 존재하는 `(손가락, 줄, 프렛)`만 사용한다.
- 최종 압현 규칙은 접근 30%, 실제 압현 50%, 좋은 위치 20%를 유지한다.
- 바레는 현재처럼 사용하지 않으며 확장 필드만 보존한다.
- 관통, 손목 이탈, 손바닥 방향, 손가락 후면 이탈, 엄지 과압 등 안전 종료는 모든 단계에서 적용한다.
- 같은 정책을 단계별로 이어 학습하며 단계가 바뀔 때 Actor를 초기화하지 않는다.
- 단계 승급은 iteration 수만으로 하지 않고 deterministic 성능으로 결정한다.

## 3. 목표 표본 구성

곡의 연속된 PRESS 프레임을 이벤트로 묶고 각 이벤트에서 아래 정보를 만든다.

```text
(finger, string, fret, start_frame, end_frame, next_relation)
```

초기 세 단계에서는 한 episode에 이 중 하나를 고르고 목표를 고정한다. 표본은 프레임 수 비율로 뽑지
않는다. 현재 곡은 검지 550, 중지 73, 약지 323, 소지 19 PRESS-frame으로 불균형하기 때문이다.

1. 손가락 1~4를 균등하게 선택한다.
2. 선택한 손가락에 속한 고유 `(줄, 프렛)` 조합을 균등하게 선택한다.
3. 같은 조합의 이벤트가 여러 개면 이벤트를 균등하게 선택한다.

이렇게 하면 드문 소지도 반드시 전체 표본의 약 25%를 차지한다. 곡에 특정 손가락 목표가 전혀 없으면
그 손가락은 분모에서 제외하고 이를 manifest에 기록한다.

## 4. 단계

### A0. Coarse Reach — 손끝을 기타 주변까지 이동

- 한 개의 실제 PRESS 목표를 2초(120 frame) 동안 고정한다.
- 선택된 지정 손가락과 목표 줄·프렛만 양의 보상을 낸다.
- 다른 줄은 학습 보상상 0이다. 단, 관통·과압 등의 안전 판정은 면제하지 않는다.
- 손목·엄지·근위관절·hover·slip·NO_PRESS·all-correct 양의 보상은 0으로 마스킹한다.
- 목표: 지정 손끝 표면과 20% 압점 사이 거리 `d ≤ 40mm`를 12 frame 연속 유지한다.

단계 전용 접근 보상은 멀리서도 기울기가 사라지지 않도록 구성한다.

```text
A(d) = clamp((250mm - d) / (250mm - 10mm), 0, 1)
P(t) = clamp((d[t-1] - d[t]) / 2mm, -1, 1)
r_A0 = 0.75 A(d) + 0.25 P(t)
```

`P(t)`는 가까워지는 동작에는 양수, 멀어지는 동작에는 음수를 준다. episode 첫 frame에서는 0이다.
이는 최종 30/50/20 규칙을 바꾸는 보상이 아니라, 접근 항만 임시로 100% 확대하는 발판이다.
25cm 바깥 경계는 균등 손가락 표본의 초기 p90 거리 17.7cm를 포괄하도록 GPU 스모크 결과에 맞춰
정했다.

### A1. Fine Reach — 올바른 줄·프렛 셀에 정렬

- 표본과 episode 길이는 A0와 같다.
- 손끝 축의 목표는 줄 중심에서 기타 바깥쪽으로 `pad 반지름 + 1.5mm` 떨어진 지점이다. 안쪽으로
  지나치는 자세도 다시 오차가 커진다.
- 목표는 손끝 중심 거리 `≤ 10mm`, 3축 정렬 품질 `≥ 0.8`이다.
- 12 frame 연속 만족해야 성공이다.
- 정렬 core는 목표 중심 거리 45%, 프렛 길이 방향 20%, 줄 가로 방향 20%, 현 바깥 높이 15%다.
  최종 A1 보상은 `0.80 × 정렬 core + 0.20 × 접근 진행량`이다.
- 일반 압현에서는 distal segment 전체가 아니라 실제 손끝 endpoint만 후보로 사용한다.
  바레 확장 경로만 segment 전체 후보를 보존한다.
- 나머지 보조 보상과 비활성 채널은 계속 0이다.

### A2-I. Isolated Press — 손가락 중심 압현

- 동일한 단일 목표를 3초(180 frame) 동안 고정한다.
- 준비 1초 동안은 왼팔 전체로 목표 근처까지 이동할 수 있다.
- 이후에는 엄지·지정 손가락·손목만 새 action을 받고, 팔꿈치·어깨와 비활성 손가락은 직전 명령을
  유지한다.
- MCP/PIP/DIP는 하나의 고정 각도가 아니라 넓은 soft range의 아치 품질로 평가한다.
- PIP의 soft shoulder는 초기 중립 자세(약 0도)까지 이어져, 처음부터 굽힘 방향 학습 신호가 생긴다.
- 기존 정렬 checkpoint에서 시작할 때 MCP/PIP/DIP action의 초기 탐색 표준편차만 0.08로 넓힌다.
  손목·팔꿈치·어깨의 탐색 폭은 0.02로 유지해 상체 안정성을 훼손하지 않는다.
- 기존 checkpoint에서 하한에 포화된 PIP/DIP 출력 행만 각각 15도/10도의 약한 아치로 다시 초기화한다.
  다른 손가락 축과 손목·팔의 학습 가중치는 그대로 보존한다.
- `30/50/20` 중 좋은 위치 20%는 프렛 위치 10%, 손끝 법선 방향 5%, 아치 품질 5%로 구성한다.
- 실제 압현, 복합 위치 품질 0.5, 아치 품질 0.65를 12 frame 연속 만족해야 성공한다.
- 로그에는 MCP/PIP/DIP 평균 굽힘각, 아치 품질, endpoint 접촉률, 비손끝 접촉률과 action-mask
  활성률을 기록한다.
- 목표점에 가까울 때만 아치 품질 신호를 강화한다. 멀리서 손가락만 구부려 점수를 얻을 수 없으며,
  최종 과제의 30/50/20 압현 점수 체계는 유지한다.
- 엄지 실제 접촉률은 보상·진단값으로 남기지만 승급을 막지 않는다.

### A2-G. Integrated Press — 전체 왼팔 압현 통합

`isolated_press`를 통과하면 손목·팔꿈치·어깨를 한꺼번에 연다. 관절을 하나씩 잠그는 인위적인
중간 단계를 없애고, 기존의 손가락→손목→팔꿈치→어깨 움직임 비용으로 불필요한 큰 동작을 억제한다.

- 동일한 단일 목표를 3초(180 frame) 동안 고정한다.
- 지정 손가락 보상은 원래 규칙인 `접근 30% + 실제 압현 50% + 좋은 위치 20%`로 되돌린다.
- `press_success`와 위치 품질 `≥ 0.5`를 12 frame 연속 유지하면 성공이다.
- NO_PRESS의 양의 점수는 아직 주지 않는다. 오압현이 생기면 해당 PRESS 점수를 0으로 만드는 기존
  규칙과 모든 안전 종료는 유지한다.
- 엄지 지지는 손끝 거리 80mm부터 열리고 25mm 안에서 최대 10%가 된다. 손끝 목표 점수보다 먼저
  얻을 수 없도록 선택 PRESS 채널에만 결합한다. 손끝이 가까운데 지지가 없으면 PRESS 점수를 최대
  25% 낮춘다.
- 승급에는 실제 접촉률 대신 넥 뒤 목표까지 평균 거리 15mm 이하를 사용한다. 현재 접촉 판정은
  `thumb3` net link force 기반의 희소 proxy이므로 검증 전까지 hard gate로 사용하지 않는다.

### A3. Goal Pair — 놓기·이동·유지 연결

- 곡에서 실제로 연속하는 두 목표 이벤트를 사용한다.
- 첫 목표와 두 번째 목표를 각각 1.5초씩 제시한다.
- `KEEP / MOVE / REST`를 균등 표본화하되 곡에 존재하는 관계만 사용한다.
- 실제 동시 압현이 있는 frame은 그대로 사용하여 최대 두 손가락을 함께 학습한다.
- PRESS 규칙과 NO_PRESS 판정을 모두 켜되, 초기에는 Actor가 받는 양의 점수의 최소 80%가 PRESS
  목표에서 오도록 제한한다. DONT_CARE는 항상 0점이다.
- 성공 조건은 두 목표 모두 유효 압현, 유지 구간 성공률 90% 이상, 오압현 1% 이하이다.

### A4. Song Timeline — 기존 곡 커리큘럼

```text
coverage(random start 100%)
  → integration(random start 100%→0%)
  → full_song(frame 0 start)
```

A4에서는 전체 규칙과 보조 보상을 사용한다. 다만 DONT_CARE는 행동과 무관한 1점 baseline이 아니라
0점이어야 하며, 보조 보상이 모든 6개 줄에 복제되어 PRESS보다 커지지 않도록 활성 PRESS/NO_PRESS
채널에만 배분한다.

## 5. 자동 승급과 실패 처리

자동 승급은 준비·이동 구간을 제외한 각 연습 episode의 마지막 30 frame(0.5초)에서만 평균·p90 거리와
정렬률을 집계한다. 완료 episode 성공률은 손가락별로도 계산하며, 평가 표본이 있는 최근 3개 window가
모두 조건을 만족할 때만 다음 단계로 넘어간다. 전체곡 최종 판정은 기존처럼 별도의 deterministic
평가로 수행한다.

| 단계 | 최소 학습 | 최대 학습 | 승급 조건 |
|---|---:|---:|---|
| A0 | 100 iter | 1,000 iter | 전체·손가락별 성공률 ≥ 80%, p90 거리 ≤ 40mm, 엄지 거리 ≤ 50mm |
| A1 | 200 iter | 1,500 iter | 전체·손가락별 성공률 ≥ 80%, p90 거리 ≤ 10mm, cell 정렬률 ≥ 90%, 엄지 거리 ≤ 25mm |
| A2-I | 300 iter | 2,000 iter | 전체·손가락별 성공률 ≥ 80%, 위치 품질 ≥ 0.5, 아치 품질 ≥ 0.65 |
| A2-G | 300 iter | 2,500 iter | 전체·손가락별 성공률 ≥ 80%, 위치 품질 ≥ 0.5, 엄지 거리 ≤ 15mm |
| A3 | 500 iter | 3,000 iter | PRESS F1 ≥ 0.85, NO_PRESS ≥ 0.99, 오압현 ≤ 0.01, 엄지 거리 ≤ 15mm |
| A4 | 기존 설정 | 별도 실험 한도 | 최종 전체곡 gate 사용 |

평균만 통과하고 특정 손가락이 실패하면 승급하지 않는다. 각 단계의 최대 iteration을 설정하고 이를
넘기면 `curriculum_forced_advance=true`와 이전 단계 이름을 기록하고 다음 단계로 이동한다. 따라서
보조 지표 하나 때문에 전체 학습이 수만 iteration 동안 정체되지 않는다. 안전 실패는 별도로 계속
기록하고 모든 단계에서 같은 종료 규칙을 적용한다.

단계가 바뀌면 모든 환경을 새 목표 분포로 함께 리셋하되 Actor·Critic·관측 정규화·optimizer 상태는
그대로 유지한다. 단계, 단계 내 iteration과 강제 전환 횟수는 checkpoint에 저장된다.

## 6. 구현 위치

| 파일 | 변경 내용 |
|---|---|
| `tab2body/learning/curriculum.py` | `A0~A4` 상태기계, 성능 기반 승급과 미통과 중단 구현 |
| `tab2body/env/goals.py` | PRESS 이벤트 색인, 손가락 균형 sampler, static/pair goal 모드 추가 |
| `tab2body/env/rewards/fret.py` | 단계 mask, 3축 정렬, endpoint 접촉, MCP/PIP/DIP 아치 품질 구현 |
| `tab2body/env/tasks/task_fret.py` | isolated action mask, 마지막 0.5초 진단 gate와 stage 성공값 노출 |
| `tab2body/train_fret.py` | 승급·checkpoint 상태, policy warm-start, 종료 후 자동 영상 구현 |
| `tab2body/learning/checkpoint_contract.py` | 커리큘럼 버전·단계·sampler 설정을 재개 계약에 포함 |

현재 관측은 353차원, action은 33차원이다. 353차원은 기존 관측에 thumb geometry 12차원을
추가한 현재 계약이며, 커리큘럼 단계 자체를 관측에 넣지 않아 정책이 단계별
편법을 만들지 않게 하고, 최종 A4와 같은 goal 관측을 처음부터 사용한다.

## 7. 검증 항목

- 이벤트 추출이 동일 PRESS run을 하나로 묶고 release 경계를 보존하는지 단위 검사
- 손가락 균형 sampler의 장기 빈도가 의도한 비율인지 검사
- A0~A2에서 선택하지 않은 줄 reward가 정확히 0인지 검사
- DONT_CARE가 reward와 actor advantage에 상수 baseline을 만들지 않는지 검사
- 진행 보상이 가까워질 때 양수, 멀어질 때 음수, 정지 시 0인지 검사
- 안전 종료가 모든 stage에서 동일하게 동작하는 GPU runtime 검사
- checkpoint 재개 후 stage, 평가 누적값, sampler RNG가 정확히 복원되는지 검사
- A0 본 학습에서 평균 거리와 p90 거리가 함께 감소하는지 확인

위 항목은 CPU 단위검사와 GPU 실행검사에 포함한다. 기존 장기 학습은 엄지 접촉률 80% gate 때문에
`finger_articulation`에 정체됐으며, 이 결과를 근거로 현재 구조로 교체했다.

## 8. 첫 구현 후 판단 기준

첫 목표는 곧바로 PRESS F1을 올리는 것이 아니다. A0 100 iteration 후 평균 목표 거리가 현재
10.22cm에서 줄고, 각 손가락의 p90 거리도 함께 감소해야 한다. 이 변화가 없다면 더 오래 학습하지 않고
reset 자세, 손끝 body 정의, action-to-joint mapping, 목표 좌표계를 먼저 다시 감사한다.

구현 직후 검증에서는 8환경 PPO 갱신, A0 episode 종료·자동 리셋, 60-frame 준비 구간, 기존 실패 종료
계약을 GPU PhysX에서 통과했다. 균등 손가락 초기 분포는 평균 15.9cm, p90 17.7cm였으며 이 값을
포괄하도록 선형 접근 보상의 바깥 경계를 25cm로 확정했다.
