# 2. 물리 압현 — 정해진 운지를 실제 손으로 수행하기

> **상태: HISTORICAL Fret-v1 상세 기록.** 아래 425D 보상·관측 설명은 현재 기본 Fret-v2 계약이 아니다.
> 현재 420D named-block 관측과 역할은 [`master_plan/03_fret.md`](../../master_plan/03_fret.md),
> 실행 방법은 [`03_training/README.md`](../03_training/README.md)를 따른다.

> 현재 계약 갱신: 2026-09-01

## 이 단계가 하는 일

운지 결정 단계의 `presses`를 받아 전신 휴머노이드가 **정해진 시각에, 정해진 손가락으로, 정해진 줄·프렛을** 누르도록 제어한다. 현재 범위는 월드에 고정된 기타를 연주하는 왼손 단독 태스크다.

## 제어 계약

| 항목 | 현재 값 |
|---|---:|
| 제어 DOF | 30: 왼쪽 어깨·팔꿈치·손목 9 + 엄지 5 + 네 손가락 16 |
| 고정 부위 | `L_Thorax`·몸통·머리·오른팔·오른손·하체는 초기 PD 자세 유지 |
| 엄지 | 프렛 음에는 사용하지 않지만 넥 뒤 지지를 위해 정책 제어 |
| 관측 | 425차원: 기본 180 + 목표 128 + 직전 EMA action 30 + thumb geometry 12 + 미래 goal 75 |
| 정책 action | `tanh`-squashed bounded policy v1, `[-1,1]`을 관절 hard range에 1:1 대응(`scale=1.0`), EMA α=0.5 |
| 룩어헤드 | 현재, 0.1초 뒤, 0.25초 뒤 |
| 보상·가치 채널 | 기타 줄별 6채널 |

## 규칙을 목적별로 보면

### 정확히 누르기

- 현재 S0 일반 압현은 목표 손가락의 끝마디 pad를 평가한다. 바레용 mask·표식은 확장 계약에만 남아
  있고 기본 로더에서는 활성화하지 않는다.
- 줄별 압현 점수는 `30% 접근 + 50% 실제 지정 손가락 press + 20% 위치 품질`이다.
- 접근은 목표 프렛의 나무 구간 20% 지점을 향하지만, 실제 press는 올바른 프렛 칸 전체에서 인정한다.
- 좋은 위치 20%는 프렛 위치 10%, 손끝 법선 방향 5%, MCP/PIP/DIP 아치 품질 5%다. 프렛 위치는
  10~30%가 만점이고 뒤로 갈수록 완만히 감소하므로 같은 프렛의 화음 손가락이 서로 앞뒤로 어긋나도
  압현 성공은 유지한다.
- 일반 압현은 실제 손끝 endpoint 접촉만 인정하고, segment 전체 접촉은 명시적 바레 확장에만 남긴다.
- 손끝이 목표 5.5cm 안으로 들어오면 손가락→손목→팔꿈치→어깨 순서의 움직임 비용을 켜며,
  손목 목표 오차 때문에 이 비용이 꺼지지 않도록 손끝 거리로 gate한다.
- 다른 손가락이 대신 눌러도 정답으로 인정하지 않는 **명시 운지 감독**을 사용한다.
- 같은 손가락의 여러 줄 동시 목표는 S0에서 오류다. 이후 바레 단계에서만 명시적 검지 바레를 켠다.

### 누르지 말아야 할 줄 보호하기

- 매 프레임 각 줄의 1~22프렛을 PRESS / NO_PRESS / DONT_CARE로 해석한다.
- 목표 프렛보다 낮은 프렛은 음에 영향이 없어 자유, 목표 프렛은 지정 손가락 PRESS,
  높은 프렛은 어느 손가락도 누르면 안 되는 NO_PRESS다.
- 개방현 목표는 1~22 전체 NO_PRESS, 사용하지 않는 줄은 전체 DONT_CARE다.
- DONT_CARE는 음향·정확도 판정만 자유이며 관통·관절 안전·과압 규칙은 그대로 적용된다.
- NO_PRESS 프렛을 실제로 누르면 해당 줄의 압현 task 점수는 즉시 0이 된다.
- 추가 음수 페널티와 누르기 직전 회피 보상은 오압현율이 높을 때 켤 수 있도록 기본 비활성 상태로 준비돼 있다.

### 자연스럽고 안전한 자세 만들기

- 엄지는 끝마디 capsule이 넥 뒷면으로 접근하도록 30%, 실제 `thumb3` 충돌이 넥 뒤 영역에서
  감지되면 70%를 받는다. 접촉 점수는 목표 손끝이 80mm 안으로 접근할 때 열려 25mm에서 완전히
  활성화되며, 과도한 엄지 순접촉력은 부드럽게 감점한다. raw 순접촉력 5,000 초과가 3프레임
  지속되면 편법 고정으로 종료한다. 전체 보상 비중은 10%다. 목표 손끝이 가까운데 엄지 지지가
  없으면 해당 PRESS 보상을 최대 25% 낮춘다.
- R12는 손목이 목표에서 멀 때 팔 전체 이동을 허용하고, 목표에 도착할수록 실제 관절 속도 비용을
  `손가락0.05 < 손목0.20 < 팔꿈치0.50 < 어깨1.00` 순으로 적용한다. 전체 비중은 2%다.
- 손목 박스 이탈과 지판 뒤 접근은 에피소드 종료 조건이다. 비엄지 distal segment는 기타 로컬
  `z_g=-35mm`부터 부드럽게 감점하고 `-50mm`를 3프레임 넘으면 종료한다. proximal segment는
  `-60mm` 종료 경계를 사용한다. R14 해석적 관통이 5mm를 넘은 상태가 3프레임 지속돼도 종료한다.
- 정상 압현 접촉과 기타를 뚫는 관통을 구분해야 한다.
- 모든 제어 관절 hard limit을 지키고, 손가락끼리의 관통·유지 중 과도한 미끄러짐·비정상 지지·과압은
  진단한 뒤 정상 압현 분포를 기준으로 단계적으로 활성화한다.
- R22의 6mm capsule 겹침은 현재 보정 전 진단값이다. 보상·종료나 최종 평가 통과 여부를 바꾸지 않는다.

### 다음 음을 미리 준비하기

- 정책은 현재 목표뿐 아니라 0.1초·0.25초 뒤 목표도 본다.
- 1초 준비구간에는 goal frame을 고정하되 룩어헤드 dt와 손가락별 13D time-to에 남은 준비 지연을
  더해, 정책이 곡 시작까지 남은 시간을 관측할 수 있게 한다.
- 같은 위치 재타현은 PRESS를 계속 유지한다.
- 다른 프렛으로 이동할 때는 `t_release`부터 다음 `t_press`까지 NO_PRESS가 되어 먼저 손을 떼게 한다.
- 다음 목표가 시작되면 높은 옛 프렛은 NO_PRESS, 낮은 옛 프렛은 DONT_CARE로 자동 해석된다.
- 같은 줄의 다음 목표가 없으면 마지막 `t_release` 뒤는 DONT_CARE다.
- 재타현 병합 구간에서는 같은 손가락을 계속 유지한다.
- 각 손가락은 `[다음 줄 mask(6), 다음 프렛, 다음 목표까지 시간, valid, 현재 상태 변경까지 시간,
  KEEP/MOVE/REST]`의 13차원 벡터를 추가로 본다.
- S0는 한 손가락이 한 프레임에 여러 줄을 맡으면 같은 프렛이어도 로딩을 중단한다. 6줄 mask 형식은
  유지하므로 이후 `allow_barre=true`에서 같은 프렛의 연속 줄에 명시한 검지 바레만 확장할 수 있다.
- 눌렀던 손가락이 해제되면 마지막 성공 압현 자세를 기억하고 0.3초 동안 편한 대기 자세
  `(PIP 25°, DIP 10°)`로 완만하게 이완한다.
- 목표가 없는 REST와 다음 이동까지 0.25초 이상 남은 MOVE에서만 적용한다. 손끝은 줄에서 12mm까지
  자유롭게 hover하며, 바깥 방향 속도는 0.03m/s까지 허용하고 그 이상만 부드럽게 억제한다.
- R18 release 보상 2%는 손끝 위치 55%, 해제 자세 30%, 바깥 방향 속도 15%로 구성한다.
  실제 접촉이 남아 있거나 다음 이동이 임박하면 해제 자세 항목을 끈다.
- 인접 손가락의 자연스러운 동조는 관절 속도 보상과 작은 action 연동을 함께 사용한다. 검지–중지 0.15,
  중지–약지 0.20, 약지–소지 0.25의 비율을 사용하며 PRESS 보상 안에서 0.5%만 혼합한다.
  압현 중인 손가락, 다음 목표로 곧 이동할 손가락, 실제 접촉 중인 손가락은 따라 움직이지 않는다.
  하나라도 목표 압현이 풀리거나 오압현이 생기면 동조 보상은 0이므로 압현을 희생해 얻을 수 없다.
  추가로 비활성 인접 손가락의 MCP/PIP/DIP 목표에 10%/15%/18%의 작은 변화를 전달한다.
  한 제어 step에서 전달되는 변화는 최대 1.5°이며, 활성 PRESS와 임박한 MOVE 손가락은 수정하지 않는다.
- 같은 목표를 3프레임 연속 정확히 누른 뒤에는 손끝의 기타 로컬 x/y 위치를 유지한다. 누적 2mm까지는
  자유이고 초과 미끄러짐만 전체 0.5%로 약하게 감점하며, 목표가 바뀌거나 접촉을 잃으면 기준점을 지운다.
- 엄지의 명백한 과도 순접촉력은 감점한다. 그 밖의 손가락 각 마디·손바닥·손목·팔꿈치 힘과 30개
  제어관절 실제 토크는 계속 진단 전용이며, 정상 압현 분포에서 문제가 확인된 뒤 임계값을 정한다.

## 반드시 구분할 것

운지 알고리즘의 교차·스팬 검사와 별개로 goal 로더도 배열 길이 6, 정수 fret `−1/0/1..22`,
PRESS 손가락 `1..4`, 시간축 단조성, S0 암묵 바레 금지를 fail-fast 검사한다. 물리 환경은 그 goal을
실제 관절로 수행하면서 발생하는 **관통, 역꺾임, 도달 실패, 비제어 부위 드리프트**를 별도로 검증해야 한다.

### step과 reset 안전 계약

- 성공적인 전체곡 완료에는 벌점을 주지 않는다. 조기 timeout, 비유한 상태·관측·보상, 속도 폭주,
  R7·R8·R13 같은 실패 종료에만 M2 `−25`를 여섯 보상 열에 적용한다.
- 자동 reset이 일어난 step의 반환 관측은 다음 episode의 reset 관측이다. 끝난 episode의 관측과 종료
  원인은 `info["terminal_observation"]`, `terminal_env_ids`, `episode_*`에 따로 보존한다.
- reset noise를 더한 자세는 hard limit을 지키며, 정책 제어 관절은 경계 포화를 피하려고 각 hard
  range의 안쪽 2%로 한 번 더 clamp한다. EMA 상태 `prev_action`은 그 reset PD target의 역변환으로
  초기화한다. 초기 정책 표준편차는 0.02다.
- DOF 위치·속도, root/body state, contact force, action/PD/torque와 reward·observation의 NaN/Inf는
  이름 있는 실패 원인으로 기록하고 유한값으로 정리한 뒤 종료한다. 특히 reward 계산 뒤 만든 goal·EMA
  결합 관측도 같은 step에서 다시 검사하므로, 파생 관측의 비유한값이 한 transition 늦게 종료되지 않는다.
- 체크포인트는 425D 관측, 30개 제어 DOF의 정확한 순서, 위 action/reset 설정과 자산·goal 지문이 모두
  일치할 때만 물리 환경에 로드된다. 이 계약이 없는 구 체크포인트는 재개·평가하지 않는다.

현재 보상은 30/50/20 규칙과 signed-depth 판정을 사용한다. 단위검사와 GPU PPO 배관을 통과했으며,
기존 33-action 정책은 action head와 actuator-state 관측이 달라 재개하거나 초기화에 사용하지 않는다.
구 341D/37-action 결과도 현재 계약의 성능 근거로 사용하지 않는다.

R11 상체 안정성 단기 점검에서는 8환경으로 5회 PPO update한 정책을 전체 14.37초 재생했으며,
몸통·머리 비제어 관절 최대 편차 2.25°(RMS 0.93°), 우측 비제어 관절 최대 1.32°(RMS 0.27°),
조기 reset 0이었다. 영상에서 뒤로 꺾이는 누적 붕괴는 보이지 않았지만 충분히 학습된 정책의 장시간
검증은 별도로 남아 있다. [상체 영상](../renders/r11_upperbody_probe_5iter.mp4) ·
[프레임 비교](../renders/r11_upperbody_probe_5iter_contact_sheet.png)

## 프렛 위치 시각화

[실제 학습환경 프렛 캡처](../renders/fretboard_reference.png)는 기타 에셋의 `G:fretN` rigid-body
위치를 직접 투영한다. 자홍선은 20% 접근점, 노란 영역은 10~30% 최적 구간, 초록 영역은
30~85% 완만 감점 구간, 청록선은 실제 프렛 와이어다. 시각화는 카메라 이미지에만 그려져 물리에는 영향이 없다.
여섯 줄의 실제 중심선과 `1 high-e`부터 `6 low-E`까지의 라벨을 함께 보려면
[줄 표시 버전](../renders/fretboard_reference_with_strings.png)을 사용한다.

## 현재 남은 핵심 검증

1. PRESS F1 0.90, NO_PRESS 0.99, 오압현율 0.01 기준 통과
2. 모든 sustain 이벤트의 안정적 유지
3. 지정하지 않은 손가락의 대조 자세 검증
4. 엄지 접촉력과 비제어 부위의 장기 분포 점검
5. 향후 바레 데이터의 복수 줄 검지 감독
