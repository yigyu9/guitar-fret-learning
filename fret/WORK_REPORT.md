## 목표

한 곡을 반복 학습해 정확하고 자연스러운 왼손 연주 모션을 만든다. 새 곡에 즉시 일반화하는 정책은
현재 목표가 아니다.

## 구현 현황

- 목표를 줄별 `PRESS / NO_PRESS / DONT_CARE`로 구분한다.
- 압현 보상은 접근 30%, 실제 누름 50%, 좋은 위치 20%다.
- 정책은 현재 목표, 룩어헤드와 손가락별 다음 목표를 관측한다.
- 왼쪽 어깨 띠부터 다섯 손가락까지 33개 관절을 제어한다.
- 엄지 지지, 손목·손가락 영역, 손바닥 방향과 관통 종료를 구현했다.
- 자연스러움 기준이 부족한 항목은 진단값으로만 기록한다.
- 커리큘럼은 접근, 정렬, 분리 압현, 통합 압현, 목표 전환, 전체곡 순서다.
- 학습 산출물은 실행별로 체크포인트, 로그, 평가, 영상으로 분리한다.

현재 코드의 Fret 계약은 `actions=33`, `observations=353`, `reward/value=6`이다.
현재 호환 실행 기록은 다음 두 실행이며, 둘 다 `02_Jazz1-200-B_solo`를 대상으로 한다.

- [`20260803_1327_02_Jazz1-200-B_solo`](training/runs/20260803_1327_02_Jazz1-200-B_solo/):
  1,024 환경, 500 iteration
- [`20260803_1352_02_Jazz1-200-B_solo`](training/runs/20260803_1352_02_Jazz1-200-B_solo/):
  1,024 환경, 500 iteration

이 실행들은 현재 환경·체크포인트 계약을 확인하기 위한 호환 실행이다. 장기 학습의 공식 품질
지표는 아직 확정하지 않았으므로, 현재 판단은 각 실행의 `run_manifest.json`, 로그, 평가 JSON을
기준으로 갱신해야 한다. 운영 절차는 [`fret/training/README.md`](training/README.md)와
[`tab2body/TRAINING.md`](../tab2body/TRAINING.md)에 기록했다.

## 과거 결과의 의미

- 구 거리 판정 모델의 F1 0.9175는 현재 signed-depth 기준에서 유효하지 않다.
- 초기 signed-depth 학습은 PRESS F1 0이었다.
- 이후 접근·관절 커리큘럼을 추가해 당시 F1이 0.598까지 올랐다.

과거 실행은 비교 근거로만 보존한다. 현재 판단은 최신 실행의 체크포인트와 평가 JSON을 기준으로 한다.

## 코드 상태

2026-07-22에 프렛 보상과 태스크 코드를 정리했다. 이후 관측에 엄지 기하 상태 12차원이 추가되어
현재 관측은 `180 + 128 + 33 + 12 = 353`차원으로 변경됐다. 미사용 함수와 구버전 호환 분기를 제거했다.
중복된 표본 선택, 압현 hysteresis와 활성 줄 평균 계산도 통합했다. 보상과 관측 계약은 유지했다.

CPU 단위검사와 GPU PhysX 종료·자동 재설정 검사를 통과했다. 코드 지문이 바뀌었으므로 정리 전
체크포인트는 strict resume 대상이 아니다. 구 `341` 관측 또는 `37-action` 체크포인트도 현재
계약과 호환되지 않는다.
