# 보류 항목

현재 규칙을 단순하고 검증 가능하게 유지하기 위해, 학습 결과를 보기 전에는 확정하기 어려운 기능을
이곳에 모은다. 보류는 폐기가 아니며 아래 재검토 조건이 충족될 때만 다시 논의한다.

| 항목 | 현재 처리 | 보류 이유 | 다시 볼 조건 |
|---|---|---|---|
| R3 오압현 추가 페널티·회피 보상 | 가중치 0으로 비활성 | 오압현이면 해당 줄 압현 점수를 이미 0으로 만듦 | 재학습 후 `wrong_press_rate`가 높을 때 |
| R6 엄지 접촉력 임계값 보정 | 임시 0.5N ON / 0.1N OFF | 실제 접촉 정책의 힘 분포가 아직 없음 | 새 정책이 넥 뒤 접촉을 만들기 시작할 때 |
| R6 엄지 과이탈 조기 종료 | 미구현 | 정상 이동과 과이탈의 거리 분포가 아직 없음 | 엄지 거리·접촉 rollout을 확보했을 때 |
| R9 손가락 각도 강제 | 전체 보류 | 단음은 세운 손끝, 바레는 눕힌 검지가 필요해 단일 임계값이 정상 자세를 해칠 수 있음 | 학습 결과에서 반복적인 비정상 각도나 옆줄 간섭이 관찰될 때 |
| R10 빠른 이동·떨림 억제 | 가중치 0으로 비활성, 기존 단순 hook 유지 | 정확한 압현의 핵심 조건이 아니며 현재 방식은 필요한 프렛 이동도 억제할 수 있음 | 압현 정책이 안정된 뒤 자연스러운 모션을 다듬을 때 속도 허용구간+가속도 떨림 방식으로 교체 |
| R21 관절 soft range | hard limit만 강제 | 정상 단음·코드·바레 자세 분포가 없어 선호범위가 정상 동작을 막을 수 있음 | 각 단계의 정상 정책 자세 분포를 확보했을 때 |
| R22 손가락 상호관통·방해 강제 | self-collision OFF, capsule 쌍별 진단만 구현 | 전체 self-collision은 좌식 안정성을 해치며 보상·종료 기준은 아직 없음 | 학습 rollout에서 2mm 초과 겹침이 반복될 때 |
| R24 과압·비정상 지지 강제 | 부위별 순접촉력·제어 토크 진단 구현, 보상/종료 없음 | net force가 접촉 상대를 구분하지 못하고 정상 힘 분포가 없음 | 학습 정책 감사에서 비정상 부위 힘이나 지속 과압이 확인될 때 |
| R25 ChordReady 연속 유지 | `all_correct` 단일 프레임만 유지, 별도 streak 없음 | 현재 S0는 단일 압현 중심이고 60Hz goal에 strike timing 채널이 없어 타현 전 준비를 정확히 판정할 수 없음 | dyad·코드 시작 전 strikes 래스터화 후 3프레임(50ms) 유지 진단부터 추가 |
| R28 pressed drag 강제 | MOVE별 candidate/confirmed 접선 이동 진단만 구현 | 정상 빠른 lift/repress와 실제 dragging의 제어 프레임 분포가 없고 slide 계열 주법은 향후 예외가 필요함 | 학습 rollout에서 confirmed 3mm 초과 move가 반복되고 영상에서도 dragging으로 확인될 때 |
| 명시적 바레 학습 | 6줄 mask·`allow_barre` 확장 흔적만 유지, S0는 암묵/명시 바레를 fail-fast 거부 | 현재 검증곡은 단음이고 바레 pad·힘·자세 검증이 없음 | 바레가 포함된 별도 단계에서 검지·연속 줄·동일 fret 계약과 물리 판정을 함께 검증할 때 |

R7 손목 영역과 R8 손가락 `z<-5cm`는 보류 항목이 아니라 구현·검증된 최소 안전 조기 종료 규칙이며,
R26은 보류가 아니다. 한 곡의 모든 goal과 규칙을 유지한 채 random-start coverage에서 전체곡 시작으로
전환하는 곡별 반복 커리큘럼으로 구현됐다. 곡에 없는 주법을 인위적으로 추가하지 않는다.
