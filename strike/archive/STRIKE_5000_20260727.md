# Strike 5,000-iteration 학습 결과 (historical, 2026-07-27)

> 이 문서는 당시 실행의 historical record입니다. 현재 코드와 checkpoint 계약이 바뀌었으므로
> 수치와 checkpoint를 현재 공식 성능 결과로 사용하지 않습니다.

## 결론

오른손 virtual-pick strike 정책을 `5,000 iteration`, `81,920,000 environment samples`까지
학습했다. 커리큘럼은 A0부터 A4까지 모두 완료했고 학습·체크포인트·평가·그래프·두 카메라
영상 저장도 정상 종료했다.

다만 5,000 체크포인트는 엄격한 42-event deterministic 최종 인증을 아직 통과하지 못했다.
자세, 준비, 타현 위치, 시간 오차, 전체 episode 완주, 안전은 통과했다. 남은 핵심 문제는
한 목표에서 한 번만 통과하지 못하고 불필요한 crossing을 추가로 만드는 것과 일부 타현 누락이다.

## 실행

- 최종 run:
  [`strike_5000_20260727_v2_fixed_a1`](../training/runs/strike_5000_20260727_v2_fixed_a1/)
- 최종 checkpoint:
  [`strike_005000.pt`](../training/runs/strike_5000_20260727_v2_fixed_a1/checkpoints/strike_005000.pt)
- 병렬 환경: 512
- PPO rollout horizon: 32
- 총 학습량: 5,000 iteration / 81,920,000 samples
- GPU: NVIDIA GeForce RTX 4070 Ti
- 물리: GPU PhysX / GPU pipeline
- 방향 계약: `down_only_v1`
- 최종 시간 허용 오차: `±50 ms`

최초 실행 `strike_5000_20260727`은 A1에서 정책이 `10 mm` ready 경계 바로 밖에 머무르며 dense
reward를 반복 수집하는 문제를 발견해 715 iteration에서 안전하게 중단했다. 해당 실행 폴더는
정리되어 현재 제공하지 않으며, 상세 비교는 아래 보존된 `v2_fixed_a1` 산출물과 이 문서의 역사
기록을 기준으로 한다.

수정판에서는 A1을 180-frame 고정 길이 episode로 만들고, 최초 ready 성공만 한 번 latch하며,
성공하지 못한 timeout에만 miss를 기록하도록 바꿨다. 또한 curriculum gate가 겹치지 않는
완료 episode cohort를 사용하도록 보강한 뒤 처음부터 다시 학습했다.

## 5,000 체크포인트 최종 평가

평가는 random 8-event 학습 episode가 아니라 원래 곡의 42개 event 전체를 deterministic하게
실행했다. 64 episode에서 총 `TP 2,589 / FP 272 / FN 99`가 기록됐다.

| 항목 | 결과 | 최종 기준 | 판정 |
|---|---:|---:|---|
| Grip success | 1.000 | ≥ 0.90 | 통과 |
| Tip-ready success | 1.000 | ≥ 0.85 | 통과 |
| Precision | 0.9062 | ≥ 0.99 | 실패 |
| Release recall | 0.9632 | ≥ 0.99 | 실패 |
| False-positive rate | 0.0900 | ≤ 0.01 | 실패 |
| Strike F1 | 0.9336 | ≥ 0.99 | 실패 |
| Timing p95 | 31.03 ms | ≤ 50 ms | 통과 |
| Zone success | 1.000 | ≥ 0.99 | 통과 |
| Full-episode completion | 1.000 | 필수 | 통과 |
| Safety | PASS | 필수 | 통과 |

64 episode 모두 timing과 zone 조건을 통과했지만, 모든 episode에 최소 한 번의 FP가 있었다.
따라서 현재 결과는 “적당한 영역에서 목표 시간에 가깝게 타현하는 능력”은 얻었지만
“각 목표마다 정확히 한 번만 타현하는 능력”은 아직 부족하다고 해석한다.

## 체크포인트 비교

A4를 처음 완료한 `strike_003027.pt`도 같은 64-episode 전체곡 조건으로 별도 평가했다.
그 시점 정책은 grip/ready는 모두 1.0이었지만 deterministic 동작에서 유효 hit를 만들지 못해
F1과 zone success가 0이었다. 그러므로 현재 full-song 동작 기준으로는 5,000 체크포인트가
3,027 체크포인트보다 명확하게 낫다.

학습 중 grip quality는 iteration 3,027의 약 `0.979`에서 iteration 5,000의 약 `0.941`로
서서히 낮아졌다. 성공 gate는 계속 통과했지만 자연스러운 피크 그립을 더 엄격히 보존하려면
향후 보상 가중치 또는 posture constraint를 다시 조정해야 한다.

## 다음 개선 우선순위

1. A4 학습 분포를 random 8-event 조각만이 아니라 42-event 전체곡 또는 점진적으로 길어지는
   sequence와 섞어, 장기 실행에서의 중복 crossing을 직접 학습한다.
2. 한 target의 최초 유효 release 뒤 recovery/re-arm이 끝날 때까지 같은 target의 재통과를
   강하게 벌점 처리하고, FP를 곡 위치·줄·방향·release 직후 재통과로 분해하는 진단을 추가한다.
3. 최종 인증과 curriculum의 precision/FPR 기준 차이를 줄이고, full-song validation을
   주기적으로 수행해 짧은 episode 지표만 좋아지는 것을 막는다.
4. grip quality 하락을 제한하는 posture regularization 또는 constrained checkpoint selection을
   적용한다.

다음 학습은 단순히 iteration을 더 늘리기보다 위 네 항목을 먼저 구현한 뒤 5,000 체크포인트를
기준선으로 비교하는 것이 적절하다.
