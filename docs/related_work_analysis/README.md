## 우리 노벨티 = 네 가지의 **조합**

**전신 + 물리 + 오디오 단독 + 명시 운지.** 각 선행연구는 이 중 하나 이상이 빠진다:

- **GPS** — 전신 없음(왼손만), 오른손 학습 없음(IK), 운지=그리디, 입력=타블라처.
- **guitar (Xu)** — 전신 없음(손만), 입력=타블라처(오디오 아님), 운지=암묵. *(← 우리가 이식하며 이 셋을 바꿈)*
- **ELGAR** — **물리 없음**(kinematic), 탭 경유 없음(오디오 직접이나 물리 제어 아님), 첼로.

## 핵심 관찰 (분석에서 도출)

- **ELGAR의 "물리 없음" 대가 = 우리 기여**: 저자 스스로 보고한 한계 5종(보우가 현에서 떨어짐·관통은 아치브리지
  데이터해킹+soft loss로만·압현력 binary·역학적 타당성 무보장·정적 악기)이 물리 시뮬로 구조적으로 해결됨.
  ELGAR는 **물리-RL과의 정량 비교를 제시하지 않으며(구조상 불가)** — 물리적 정확성은 우리 접근만의 영역.
- **Xu 논문 부록 D-2(5노트 미리보기 한계) = 우리 명시운지 노벨티의 직접 근거** (선행적 운지 계획 부재).
- **논문↔코드 불일치가 여러 곳** — 이식/비교 시 **코드값 신뢰** 원칙(각 분석서 §4-4/미해결 목록 참조). 예:
  Xu not-press 지수 코드⁴ vs 논문², 세로손가락 0.0872 vs 주석 10°, N_FRETS 22 vs 24; ELGAR 표현 309 vs 312,
  AWL 7-way 의도 vs 단일합 축소.
