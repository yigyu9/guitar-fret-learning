새 진입점은 `stability-support-hold`이며, 아직 미검증 S0 후보이므로 명시적 smoke 모드를 사용한다.

- [x] seed14, 8환경, 48iteration fresh 진단 학습 실행.
- [x] 전체 로그의 수치 유효성, PPO 갱신, 종료별 자세·속도·지지 결과 확인.

있으므로 성공0을 정책 학습 실패율로 해석하지 않는다. 이전 진단과 seed/환경 수가 달라
단순 수치 차이를 학습 개선으로 주장하지 않는다.
