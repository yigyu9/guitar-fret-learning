# 강체 접촉을 고려한 지지 학습 구조

사용자가 지지 방식 보상, 과도한 압박 방지 및 접촉 진단 실험 구현을 승인했다.
기존 v6/hold-v1/wide8 원본은 보존하고 명시적인 support 실험 진입점을 추가한다.
골반 고정, 수동 스트랩, 97축 및 최종 복원/저속/유지 성공 기준은 유지한다.

- [x] 자산 표면 기반 지지 영역 거리·상대 속도 proxy 구현 및 CPU 경계 검사.
- [x] 접촉 접근 시 완만한 목표 변화, 보조 비용, 관측과 로그를 새 실험에 연결.
- [x] 왼손/오른팔/양팔 접근 및 몸통 지지 관측 진단과 GPU 짧은 학습·평가·재개 검사.
- [x] 독립 변경 검수 및 날짜별 설계·사용법·실측 결과·한계 문서 작성.

근거 없는 힘 기준은 실측값으로 주장하지 않는다. 합산 접촉력은 접촉 쌍별 힘이나
압박력으로 해석하지 않는다. 실제 접촉 확보 여부와 복원 성공은 별도로 보고한다.
접촉 보조 항목은 음의 bounded cost로 구성해 접촉만 유지하는 보상 수확을 막는다.
기존 손가락/손목 소유권 통합 계약은 유지하며 Full 연주 통합 완료를 주장하지 않는다.

완료: CPU37개+진입점, GPU2환경220프레임 초기화/속도제한 검사,
8환경8iteration→자동 평가→2환경에서12iteration 재개, 접근 비교7회 통과.
접근 비교는 실제 하중 접촉을 확보하지 못했으므로 힘/강성 최적값은 결정하지 않았다.
8iteration 평가0/1성공은 배관 검사이며 수렴 검증이 아니다.
