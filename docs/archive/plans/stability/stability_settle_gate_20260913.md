# StabilityAdapter 제어 시작 기준 분리

사용자가 제안한 설계의 적용을 승인했다. 현재 학습 프로세스와 기존 run은 변경하지 않는다.

- [x] 시작 기준 0.10m/s·0.50rad/s·15 frame과 성공 기준 0.05m/s·0.25rad/s·30 frame 분리
- [x] WAIT 조건별 차단 비율·연속 유지 최대값·timeout 원인을 기록하고 부분 reset 검증
- [x] 정책 없는 반복 낙하 비교와 CPU/GPU 검사; 실행 가능한 자원 범위 명시
- [x] v4 계약·현재 사용 안내·docs/2026-09-14 설명 갱신 및 변경 검수

스트랩 안전·1N 지지·최소 60 frame 대기와 목표 위치/회전 기준은 유지한다.
대기 시간 초과를 무조건 RECOVER로 넘기지 않는다. 시작 수치는 검증할 후보이며
구현만으로 정착 실패 원인이 해결됐다고 판단하지 않는다. 관측 323·행동 97·Full43 권한은 유지한다.
