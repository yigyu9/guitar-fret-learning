# 몸통을 적게 쓰고 팔·손을 우선 사용하는 제어 선호

사용자 요청에 따라 현재 stability-support-hold에 적용한다.
몸통은 Torso/Spine/Chest, 팔에는 어깨 띠 L/R_Thorax와 어깨·팔꿈치·손목·손가락을 포함한다.
골반 고정과97축 권한은 유지한다. 팔 움직임 자체에 양의 보상을 주지 않는다.

- [x] 관절군별 비용 가중치와 몸통의 작은 자세 허용 폭·실제 속도 비용 구현.
- [x] 체크포인트 계약 및 관절군 진단 로그에 선호를 기록.
- [x] CPU54개·GPU7개 통과,4환경8회 학습 연결 검사, 독립 검토.
- [x] 수치의 의미·검증 범위·새 학습 시작 조건 문서화.

팔의 기존 충돌 접근 속도·PD·힘 제한은 유지한다. 이번 값은 사용자 제어 선호의 초기값이며
인간 계측값이나 물리 지지 검증 결과가 아니다. 이미 학습된 정책의 행동이 개선됐다고 주장하지 않는다.
