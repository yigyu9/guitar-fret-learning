# Stability 단일 학습 환경 통합

사용자 요청: adapter/support/hold를 하나의 목적으로 통합한다.
공개 이름은 `stability-adapter`, 목표는 자연스러운 기타 자세로 접근·복원·유지다.
지지/유지는 이 환경의 기능·학습 단계로 두고 별도 실험 선택을 없앤다.

- [x] 단일 학습·평가·설정 진입점 및 이전 명령의 명확한 전환 처리.
- [x] 최신 단계 학습·몸통 억제·좌우 팔 역할·목표/지지 계약을 같은 runtime에 연결.
- [x] 초기 작은 위치 교란과 단계별 실제 구현/미검증 상태 명시. 현재 실제 노이즈0.
- [x] 새 계약/기존 checkpoint 혼용 차단, CPU64개·GPU5개,24→32학습/재개·S1/S4평가.
- [x] 독립 검토와 문서·실행 안내 정리.

물리 검증이 실패한 S0를 성공으로 바꾸지 않는다. Fret·Strike의 실제 정책 결합이나 엄지 압현
성공을 가짜 값으로 채우지 않는다. 현재 구현 가능한 지지·접근 목표와 후속 연주 계약을 분리해
기록하며, 연주 중 관절 소유권43축은 유지한다. 과거 실험 데이터는 삭제하지 않는다.

S0 지지 자세 검증·별도 손바닥 지지·실제 압현과 연주 결합·자연스러운 복원 정책 학습은 후속 과제다.
