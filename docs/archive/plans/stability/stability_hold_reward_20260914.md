# 목표 근처 감속·유지 보상 개선

사용자의 개선 진행 요청에 따라 직전 제안의 첫 단계부터 수행한다. 목표 접근·회전 가중치,
명령 변화 페널티, 탐색 설정은 통제하고 hold 항의 형태만 비교한다. 기존 실행을 중단하지 않는다.

- [x] 위치·회전 허용 범위와 완만한 속도 비용을 분리한 hold-v1 수식 및 CPU 검사.
- [x] 학습·평가에 같은 보상을 연결하고 새 보상 계약과 기존 v6 계약을 엄격히 구분.
- [x] 기존 기록의 동일 frame에 구/신 보상을 적용해 신호 차이를 계측.
- [x] GPU 짧은 학습·자동 평가·checkpoint 재개 검증과 변경 검수.
- [x] 결과·한계·실행 방법을 `docs/2026-09-14`에 기록.

성공 기준: WAIT/전환/수치 오류 frame에 새 보상을 부여하지 않고 기존 성공·물리 실패·timeout
보너스/페널티를 보존한다. 새 유지 비용은 0~0.5/600, 모든 일반 비용은 비양수로 유지한다.
허용 위치·회전 범위 안에서 두 속도가 허용치일 때 hold 품질은 기존 exp(-4) 대신 0.5다.
속도가 낮아질수록 비용이 감소하고, 멀리 떨어져 멈추는 것보다 목표에서 멈추는 상태를 우대한다.
신규 fresh 학습은 hold-v1, 명시적 `--reward-profile legacy`로 대조군 실행을 제공한다.
기존 checkpoint를 resume하면 저장된 보상을 따른다. 다른 보상으로 자동 이어 학습하지 않는다.
원본 v6 fingerprint 파일을 유지해 진행 중인 기존 학습의 정기 평가도 계속 가능하게 한다.
