# 초기 대기의 장력 하한 제거

사용자가 승인한 변경: 초반 WAIT에서 장력1N 이상을 요구하지 않고 최소 대기 시간,
선속도·각속도 기준의 연속 충족, 기존 안전 제한으로 제어 시작을 결정한다.

- [x] 장력 하한 설정·차단 진단을 제거하고 task/checkpoint를 v6로 구분한다.
- [x] 장력0에서도 정상 진입하며 속도·안전 위반·실패 시 진입하지 않는 회귀 검사를 수행한다.
- [x] GPU 실제 진입·초기화 및 짧은 PPO의 새 진단·저장을 확인한다.
- [x] 검수와 문서 갱신을 완료한다.

관측323·제어97, 장력 관측, 스트랩 상한/늘어남 제한, 추락 종료, 성공 기준,
WAIT 및 전환 frame의 PPO 제외는 유지한다. 실행 중인 v5 학습은 변경하지 않는다.
