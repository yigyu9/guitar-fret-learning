# StabilityAdapter 환경 설정 반영

사용자의 환경 반영 요청에 따라 학습용 StabilityAdapter를 대상으로 진행한다.
목표·낙하·길이 분리는 이미 v5 물리에 적용돼 있다. 이번에는 환경을 직접 생성할 때도
학습·평가와 같은 설정 파일을 읽게 해 설정 적용 경로를 통일한다.

- [x] 공통 파일 로더를 연결하고 명시적 config의 우선순위를 유지한다.
- [x] 파일 변경·검증·경로와 실제 GPU 기본 생성·reset을 확인한다.
- [x] 변경 검수와 문서 갱신을 마친다.

성공 기준: config를 생략한 환경도 `stability_adapter/config.json`을 읽고,
명시적으로 받은 설정은 그대로 사용한다. 기본 물리 수치·안전 기준·97축/323D는 유지한다.
진단에서 실패한 +5°를 허용 범위로 넣거나 기존 실행 프로세스에 새 설정을 주입하지 않는다.

검증: CPU27+7개, GPU2환경 기본 생성·부분 reset·97축 제어, 문법 검사 통과.
별도 change-reviewer 검수에서 문제없음. 결과는
[환경 반영 기록](../../../2026-09-14/archive/STABILITY_SIMULATION_PARAMETERS.md#7-후속-요청-실제-환경의-기본-설정-경로-통일)에 있다.
