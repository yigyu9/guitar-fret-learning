# 여유 있는 신경망과 8프레임 관측 이력

사용자가 4070 Ti SUPER/4070 Ti 환경을 밝히고 신경망 확대와 최근 8프레임 입력을 함께
적용하도록 선택했다. Actor/Critic 각각 1024→512→256, 323×8=2584 입력을 기본으로 한다.
60Hz 최근 관측 8개는 현재부터 7/60초 전까지이며, 행동 97D·물리·보상은 유지한다.

- [x] 관측 이력 wrapper 구현: WAIT 포함, reset 패딩, 부분 reset·terminal 이력 보존 검사.
- [x] 큰 MLP와 명시적 모델/이력 계약을 학습·평가에 연결. 기존 모델 계약은 보존.
- [x] CPU 검사·변경 검수와 4070 Ti에서 메모리·속도·PPO/평가/이어 학습 검증.
- [x] 모델 구조, GPU 운용, 검증 결과와 한계를 날짜별 문서에 기록.

기존 v6 및 hold-v1 fingerprint 파일은 수정하지 않는다. 새 실행기·정책 모듈을 추가해
기존 모델은 저장된 크기·입력으로 재개/평가한다. 다른 크기·이력으로 자동 변환하지 않는다.
새 모델은 새 학습으로 시작한다. 현재 접속 장비에서는 12GB 4070 Ti 1장이 보이며,
두 GPU는 독립 실험에 사용하는 방식을 안내한다. 자동 분산 학습이나 GPU 메모리 합산은 없다.

완료: CPU53개·dispatcher·변경 검수 통과. 1024환경×8회 GPU PPO와 자동 평가,
8→12 이어 학습 및 model/optimizer 갱신 확인. 부모 PyTorch peak allocated1747.1MiB,
단일 model.act 평균1.01ms(물리 제외). 기존 모델 원본 소스 지문 유지 확인.
짧은 학습의 성공은0/1이며 수렴·성능 개선을 주장하지 않는다.
