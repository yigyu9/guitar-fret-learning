# Fret 제어 관절 한계 시각화

> 역사적 스냅샷: 이 결과는 2026-08-19 당시 33-DOF 계약으로 생성됐다. 2026-09-01부터
> `L_Thorax`를 제외한 30-DOF 계약을 사용하며 새 렌더는 `docs/2026-09-01/fret_joint_limits/`에 저장한다.

2026-08-19 당시 fret 정책이 제어하던 33개 DOF를 기타 없이 확인한 결과다. 사람은 학습과 같은 앉은
초기 자세이며 의자는 유지했다. 각 이미지에서는 한 DOF만 바꾸고 나머지는 초기 자세로 고정했다.

## 이미지 읽는 법

- 왼쪽: 현재 hard lower limit
- 가운데: fret 환경의 초기 자세
- 오른쪽: 현재 hard upper limit
- 위쪽 행: front view
- 아래쪽 행: side view
- `target`: simulator에 지정한 각도
- `rendered`: 한 물리 스텝 뒤 실제 관절 각도

현재 `action_scale=1.0`이므로 정책의 PD 목표 범위는 아래 hard limit 전체다. 다만 tanh 정책은
정확히 `-1` 또는 `+1`을 출력하지 않으므로 수학적으로 경계 그 자체보다 경계에 매우 가까운 값을
사용하게 된다.

## 파일

- `individual/`: 33개 DOF별 최소·초기·최대 비교 이미지
- `overview/`: 흉곽·어깨·팔꿈치·손목·각 손가락 그룹별 요약 이미지
- `joint_limit_ranges.csv`: 분석하기 쉬운 각도표
- `joint_limit_ranges.json`: 렌더 조건과 실제 렌더 각도를 포함한 전체 기록

## 바로 확인된 문제

`L_Elbow_x`와 `L_Wrist_x`의 범위가 특히 지나치게 넓다.

- `L_Elbow_x`: 지정 범위는 -180°~+180°지만 -180° 자세는 한 물리 스텝 뒤 약 +99°로 바뀐다.
- `L_Wrist_x`: 지정 범위는 -180°~+90°지만 -180° 자세는 한 물리 스텝 뒤 약 +90°로 바뀐다.

두 축은 회전 표현의 경계와 PhysX 관절 해석이 겹친다. 자연스러운 연주 범위를 정할 때 가장 먼저
좁혀야 할 후보이며, 단순 soft penalty보다 XML hard limit과 정책 target 범위를 함께 재정의하는
편이 안전하다.

손가락도 MCP 굽힘이 -40°~+90°, PIP/DIP 굽힘이 대체로 0°~90°로 넓다. 다만 손가락은 기타
압현에 큰 굽힘이 필요하므로 영상과 성공 자세 분포를 함께 본 뒤 좁혀야 한다. 특히 DIP의 -5°는
약한 과신전을 허용하기 위한 값이므로 바로 0°로 없애기보다 실제 학습 사용률을 먼저 확인한다.
