## 실제 검수 범위

전역 Git 변경에는 다른 작업이 포함되어 있으므로, 변경 전 보관본의 manifest와 현재 문서를 비교했다. 기존 설명 12개 Markdown의 갱신과 새 `11_v24학습구조와보상.md`를 읽었으며, 이 보고서를 포함한 최신 Markdown 14개의 내부 경로를 확인했다. 이번 검수에서 수정한 파일은 이 보고서뿐이다. 보상·제어·모델·설정·Python 파일은 수정하지 않았다.

기본 `song`의 v22·552상태·incremental과 선택 `finger-skill-v24`의 557상태·R17/F16/J33축을 구분해 현재 코드와 대조했다. 선택 음과 부분곡 분모, 고정 음악 progress0, R의 네 보상 항 필터, 원곡/로컬 시계, 단계별 독립 평가, 실제 결정 지속시간 할인·GAE·padding 제외 설명이 구현과 일치한다. 같은 단계의 strict resume와 Actor만 이전하는 phase transfer도 구분되어 있다.
