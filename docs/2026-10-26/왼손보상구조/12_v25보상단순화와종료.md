## 접근·추종 통합

기존 손가락별 단일 목표 선택기, 지정 finger3 패드와 압현면 거리를 공유한다. 진행도는 거리 `exp(−d/.03)`에 악보 tracking weight와 균형 계수를 곱한다.2cm 안에서 방향 품질을 최대20%로 부드럽게 반영한다. 하중이나 candidate를 접근 gate로 요구하지 않는다.

목표 교체에도 같은 상태 함수의 Phi를 계산하며 과거 Phi를 임의로0으로 초기화하지 않는다. 정상/실패 terminal의 다음 Phi는0, H32 경계는 계속 상태다. 같은 거리에 머무는 별도 양성 추종 rate는 없고 접촉 후 올바른 정지는 압현 유지에서 보상한다.

## 오압현 판정 v2

현재 `finger-skill`만 아래 두 조건으로 판정한다. 기본 `song`과 `finger-skill-v24`의 기존 판정은 유지한다.

1. **담당 패드 오류:** 현재 연주할 목표가 있는 손가락의 finger3 굽힘 안쪽 패드가 허용되지 않은 줄·프렛을 누른다. 같은 프렛 번호라도 다른 줄이면 오류다. 같은 손가락의 동시에 활성화된 선택 목표 셀은 모두 허용한다.
2. **다른 손가락의 방해:** 엄지를 포함한 다른 손가락의 finger2/3 표면이 현재 목표와 같은 줄에서 더 높은 번호의 프렛을 누른다. 올바른 담당 패드 접촉이 함께 있어도 오압현이다.

담당 패드에 올바른 목표 접촉이 있으면 같은 패드의 다른 부수 표본은 담당 오류로 세지 않는다. 올바른 접촉이 없을 때만 담당 패드의 잘못된 위치를 판단하며, 손가락2·손등의 단순 근접을 담당 패드 오류로 대체하지 않는다. 다른 손가락의 높은 프렛 방해는 독립적으로 남는다.

담당 패드는 **동일 표본**의 유한 압현면 줄 거리≤3mm·높이−1~+3mm·법선cos≥0.1·같은 finger3 접촉합력≥0.01N을 요구한다. 줄 배정은 유일한 최근접 줄이고 프렛은 양 경계 안쪽2mm의 명확한 셀만 인정한다. 무하중·방향 반대·프렛 경계·목표 부재는 오압현의 근거가 아니다. 다른 손가락 방해는 기존 full-surface/가상현/합력 기준과 명확한 프렛 셀을 사용한다. 두 경우 모두 접촉쌍이나 실제 현 압력·음향의 인증은 아니다.

다른 손가락이 목표와 같은 프렛을 대신 누르면 오압현은 아니지만 담당 패드의 최초 접촉·압현 유지·압현 달성도 인정하지 않는다. 다른 손가락의 낮은 프렛 접촉은 감점하지 않는다. 다음 음을 준비하는 접촉도 현재 음의 높은 프렛 방해라면 면제하지 않는다.

감점은 선택된 음의 onset~end에서만 발생한다. 순간 기하 판정은 창 밖에서도 계산하며, 240Hz 양끝 wrong 값의 평균에 실제 audible 중첩 시간만 곱한다. 이렇게 해야 음 경계가 물리 표본 사이에 있어도 가장자리 시간을 절반씩 잃지 않는다. 창 밖 시간은 적분하지 않고 60Hz 학습 단계에 전달한다. 최종 감점은 기존 `−0.15×b×wrong_time/D`이며 여러 원인·손가락이 같은 음을 방해해도 중복 합산하지 않는다.

진단의 원인 순서는 `other_higher`, `own_wrong_fret`, `own_wrong_string`이다. 원장v8의 시간 키도 이 이름에 `_time`을 붙인다. 원인별 `wrong_source_time`은 목표×10몸체×3원인이며 담당 패드 오류는 해당 finger3에 기록한다. 모든 유효 원인이 명확한 셀에 있어 `wrong_ambiguous_time`은0이다. `wrong_next_preparation_time`은 방해 표본이 다음 목표에 해당하는지를 별도 기록하며 감점 면제가 아니다.

접촉 계약은 `gpu_distal_pad_geometry.v2`, 보상 계약은 `simplified_finger_reward.v2`다. 기존 판정 checkpoint와 동일 계약으로 재개하지 않는다. 변경 전 소스·문서는 `guitar_learning/archive/20261026_before_wrong_press_v2/manifest.json`에 보관했다. [판정 구현](/home/ajou/yigyu/3/guitar_learning/gpu/wrong_press.py) · [수용 검사](/home/ajou/yigyu/3/guitar_learning/tests/test_simplified_wrong_press.py).

## 누락·미달성 통합

```text
부족률 = max(clamp(missing_time/D,0,1), 1−clamp(best_clean_streak/required,0,1))
최종 감점 = −0.10b × 부족률
```

audible 중 missing 증가분으로 예산 일부를 지불하고 음이 끝날 때 부족률에 필요한 차액만 정산한다. paid/settled 원장으로 음 끝 반복과 동일 실패의 이중 정산을 막는다. 달성 뒤 누락은 유지되며 서로 다른 음이나 선택하지 않은 음의 분모를 섞지 않는다.

조기 종료 이후의 미관측 시간을 원장에 가상 적분하지 않는다. 남은 음은 평가 고정 분모에서 실패로 남고 그 미관측 감점 예산은 종료 cost가 담당한다. 종료 전 지불한 부분은 다시 차감하지 않는다.

## 종료 판정과 비용

기타 변위/회전·발 변위·지지 상실·관절 속도·제어 무효의 기존 물리 실패 기준을 유지한다. 손목은 별도 조건이다.

- 초기3초에는 일반 손목 이탈을 유예한다.
- 안내 상자 밖 추가3cm 초과 시 일반 이탈 상태를 켜고 시간을 누적한다. 손목 종료v2의 누적 문턱은1.5초다.
- 활성 상태에서 추가2~3cm로 복귀하면 누적 시간을 초당1초씩 줄인다(최소0). 짧은 복귀로 즉시 전부 초기화하지 않으며, 이 구간에서 시간이 더 쌓이지 않는다.
- 모든 축이 추가2cm 이내로 복귀하면 상태와 timer를 해제한다.
- 추가10cm 이상 심각 이탈이0.10초 지속하면 준비 중에도 종료한다.
- 음/프렛 전환·PPO 갱신·다른 환경 reset은 이 timer를 지우지 않는다.

일반 이탈 상태·경과시간·준비 유예 잔여·심각 이탈 경과의4열을 actor/critic 모두 관측한다. 기존557에서561상태로 늘며 시간 scale은1.5/3/0.10초다. 일반 elapsed는 복귀 시 줄어드는 순누적 이탈 시간이며, 상태 차원561은 유지한다. 최초 임곗값이 모든 목표에 최적이라고 주장하지 않으며 실제 검증 결과를 별도로 읽는다.

정상 연속 물리 cost와 별도 reward 실패−2를 제거한다. 물리·손목 원인이 겹쳐도 다음 cost를 한 번 부과한다.

```text
C = 5 + 2×remaining_local_seconds + remaining_negative_note_budget
```

마지막 항은 선택된 미정산 음의 미관측 wrong 최대0.15b와 미지불 수행 부족 최대0.10b다. 물리 제어/PD/중력 보상/하체 유지는 제거하지 않는다. 정상 곡 끝은 비용0이다. 입력 오류·비유한값·저장/자원 실패는 학습 에피소드 실패와 다른 실행 보호 중단이다.

PPO는 `A_reward−A_cost`를 합친 후 정규화하며 cost weight는1로 고정한다. 보상/비용은 기존 별도 할인과 critic을 사용하므로 하나의 동일 scalar return으로 표현하지 않는다. 과거 방식보다 원시 비용 숫자가 더 커졌다는 뜻은 아니다.

## 2026-10-27 일반 손목 복귀 보정

손목 종료 계약은 `wrist_termination.v2`다. 이전 영상에서 안내 상자가5.2초경 넥 길이 방향으로26.52mm 이동하며 타이머가 시작됐고, 종료 시에는 초과29.57mm로3cm 아래였지만 기존2cm 복귀 문턱 때문에 시간이 계속 쌓였다. 60Hz 끝점 분석이며 성공 압현 자세를 검증한 자료는 아니다.

일반 문턱 .75→1.5초와2~3cm 복귀 시1:1 시간 차감을 적용했다. 영역 위치/크기·3cm진입/2cm해제·초기유예·심각이탈·물리종료·실패비용·9개 보상은 유지한다. 종료 원장에는 최종 기타좌표 손목 위치·영역 경계·축별 초과·현재/준비 음·현재 패드 거리/clean 후보를 추가했다. 이 값들은 종료 끝점이며240Hz 전체 최대나 실제 음향을 뜻하지 않는다.

계약/관측 scale이 달라 이전 저장본 strict resume는 거부하며 검증을 완화하지 않는다. [보정·검증 기록](/home/ajou/yigyu/3/docs/2026-10-27/guitar_learning_wrist_recovery_v2/README.md)을 따른다.

## 학습과 검증 범위

R/F 준비 관문 없이 첫 tick부터 팔·엄지·네 손가락33축을 함께 학습한다. 정책 분리 구조는 유지한다. 최초 계획 전이 예산25%는 원곡 연속 구간, 이후 실제 reset부터67음 전곡이며 전환 문턱은 재개 때 고정 복원한다. 준비 상태·제어·positive 패드 조건·연속 달성 문턱은 유지한다. 오압현v2가 candidate 배제에 반영되므로 clean 성과를 이전 판정 결과와 동일 기준으로 간주하지 않는다.

원래 song/CPU/오른손과 구버전557상태 checkpoint의 성과를 상속하지 않는다. 새로운 자연스러운 압현이나 장기 성능 향상은 단기 구현 검사와 구분한다. 검증 근거는 [v25 검증 문서](/home/ajou/yigyu/3/docs/2026-10-26/guitar_learning_reward_simplification_v25/VERIFICATION.md)에 기록한다.

오압현v2 변경 전 검증은 CPU565개·24구간 shadow·large1024 저장/재개·large128 단기64회·전곡16평가·native 손/전신 영상까지 완료했다. 당시 비용/원장/재개 검산과 독립 검수는 통과했지만, 전곡16개 모두 손목 종료이고 평균 달성은0/67음이다. 이 결과는 새 오압현 판정의 성능이나 구동 검증으로 상속하지 않는다.

오압현v2 변경 후에는 새 수용 검사14개를 포함한 관련11모듈 CPU130검사를 통과했다. 담당 패드/다른 손가락 규칙, 실제 표면 기하 연결, 비정렬 음 경계의 정확한 audible 적분, 중복 감점 방지, 원인별 원장, 부분 reset 및 기존song/v24 경로를 확인했다. 실제 GPU/native 실행·학습 성능은 이번에 검증하지 않았다. [변경·검증 체크리스트](/home/ajou/yigyu/3/docs/plans/guitar_learning_wrong_press_v2_20261026.md).
