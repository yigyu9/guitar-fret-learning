# 왼손 손가락 사이 충돌 감사

`prepared035`, 설계 B, 기존 실제 Isaac Gym B 최종 자세에서 서로 다른 손가락의 물리 segment 90쌍에 1μm 초과 source convex 교차는 없었다. 따라서 이 세 자세를 근거로 초기 자세나 B 자세를 바꿀 필요는 발견되지 않았다.

기존 A500 원영상 마지막 자세에서는 아래 6쌍에 교차가 있었다. 이 수치는 source convex 두 형상 교집합에 들어가는 구의 반지름이며, PhysX가 조리한 형상의 관통 깊이나 실제 접촉 힘을 뜻하지 않는다.

| 원영상 마지막 자세의 형상 쌍 | 교집합 내접구 반지름 |
| --- | ---: |
| 엄지2–검지1 | 3.435mm |
| 엄지2–검지3 | 0.721mm |
| 엄지2–중지1 | 6.426mm |
| 엄지3–검지3 | 4.533mm |
| 엄지3–중지1 | 3.470mm |
| 검지1–중지1 | 0.497mm |

## 필터 변경

기존 왼손 15개 물리 segment는 공통 filter128 때문에 서로 충돌하지 않았다. 새 helper는 엄지·검지·중지·약지·소지에 각각 미사용 bit20~24를 배정한다. 팔꿈치·손목·손바닥과 비물리 엄지 pad에는 이 다섯 bit를 함께 넣어 기존 제외 관계를 보존한다.

- 서로 다른 손가락 90쌍만 충돌 가능으로 바꾼다.
- 같은 손가락 내부, 손바닥·팔 연결, 오른손을 포함한 나머지 모든 human shape 쌍은 기존 허용/제외 관계를 보존한다.
- 실제 GPU 기타는 filter4096의 89개 형상, 의자는 filter0을 사용한다. 이들과의 관계도 동일하다. 원래 guitar logical 자료의 두 proxy는 현 GPU compound asset에 물리 형상이 없다.
- 마찰·접촉 offset·형상·질량·PD·관절 한계는 변경하지 않는다.
- GPU 오른손과 CPU 실행의 물리 설정은 변경하지 않는다.

전체 허용/제외 행렬은 `filter_matrix.json`, 자세별 90쌍의 결과와 입력 SHA는 `geometry.json`에 있다. `support/audit.py`는 정적 감사 도구이며 학습 환경을 진행하거나 초기 상태를 변경하지 않는다.

새 helper 관련 CPU 검사 6개를 통과했다. 실제 native 제출과 readback 결과는 통합 실험 기록에서 확인해야 한다. 이 정적 감사만으로 동적 안정성이나 학습 성능을 주장하지 않는다.
