# 왼손 접촉·대기 복귀 v21

2026-10-26. 승인한 순서인 원인 분리 → 선별 충돌 → 원인별 대응 → 음 사이 B 복귀 → 엄지 안내를 구현했다. **통합1024 저장·재개와 네 조건의 짧은 비교 학습·평가를 완료했다. 엄지 기하 보상만으로는 실제 하중 없이 떠 있는 문제가 확인되어 현행은 [v22 접촉 후보 보완](/home/ajou/yigyu/3/docs/2026-10-26/guitar_learning_hand_contact_v22/README.md)으로 이어간다. 이 폴더는 v21 당시 실행을 보존하며 장기 학습 채택을 뜻하지 않는다.**

## 적용 내용

- 왼손 실제15개 마디의 서로 다른 손가락90쌍만 충돌을 활성화했다. 같은 손가락·손바닥 연결부 및 기타·팔·오른손과의 기존 필터 관계는 보존하고 native 역조회로 확인한다.
- 누적 제어 계산·반전·H32 연속성·reset은 정상이다. 정책이 극단 목표를 계속 요청한 것이 관측되어 PD·가동범위·4rad/s·LH21 움직임 비용0은 유지했다. 극단 조합의240Hz 진단을 추가했다.
- B는 손가락별 악보 유지 구간을 보호하고, 음 끝 뒤50ms 여유와100ms 증가, 다음 압현350ms 준비와100ms 감소를 사용한다. 250ms 이하 간격은 직접 전환,250–600ms는 부분 복귀다. 잔여 접촉·오압현·4cm 근접이 복귀를 계속 막지 않는다. 손가락 추종과 동일한 단계 가중치를 사용하고 손목·팔의2초 선행 안내는 유지한다.
- 엄지 끝마디의 실제 길이축−x·굽힘축+z에 맞는 안쪽−y 패드128점으로 측정한다. 넥 뒷면 중앙50%·작업 프렛 중심±4cm, 간격0–3mm와 방향 품질을 함께 사용해 손 전체 최대0.02/초를 준다. 같은 점의 위치와 법선을 사용하며 깊은 침투·반대 방향은 지급하지 않는다. 강제 부착·기타 보조 힘·압현 자세 고정은 없다.
- 관측551(기존544+엄지7), 우선8·토큰24·손가락 직접20·curriculum3331. 보상v21/14합산슬롯·19로그키다. 과거v20 이하의 strict resume는 거부한다. CPU 왼손·오른손은 이전 경로를 유지한다.

독립 코드 검수에서 처음에는 비엄지 좌표로 엄지 패드를 선택한 오류를 발견했고, 엄지의 source 축을 확인해 수정·재검사했다. 학습 전 초안은 `support/thumb_patch_draft_v1/`에 보존한다. 현재 실행은 수정된 패드를 사용한다.

[엄지 패드와 목표 영역의 정적 기하 설명](thumb_patch_initial.png)도 저장했다. 파란점은 수정된 엄지 안쪽 패드이며, 실제 물리 카메라 영상과 구분한다.

## 비교 예산과 해석

동일 새551모델·seed7·large·128환경/H32·100업데이트를 조건마다 사용했다. 세 조건은 선별 충돌+이전 B 시간 설계, 새 B/추종 전환, 여기에 엄지 안내 추가다. 새 초기화의72개 모델 tensor 동일성을 확인했다. 이전 checkpoint의 성과는 상속하지 않는다.

각 모델의 첫 종료곡128개를 고정 정책으로 평가했고 실패도 분모에 포함했다. 최종 통합판의 사전 지정env0에서 실제 Gym 손 근접·전신 영상을 저장했다. 한 학습 seed의 짧은 진단 비교이며 독립 seed의 통계적 성능 검증이 아니다. 복귀 고정 평가창은 `음끝+0.05초+1초`부터 `다음압현−0.35초`까지이며0.5초 이상 창에서80% 점유를 평가한다.1초는 잠정 진단 예산이며 모든 자세의 복귀 보장이 아니다.

## 완료한 비교와 남은 문제

[비교 결과](COMPARISON_RESULTS.md): 충돌만/이전 시간창은1.141/67·안전30/128, 새 B/추종은5.602/67·안전49/128, 엄지 기하 안내 포함 통합은5.148/67·안전128/128였다. 단일 seed의 짧은 시험으로 구성별 인과 효과를 확정하지 않는다.

통합판의 고정 B 점유율은 네 손가락 모두0%이며, .04/초로 높인 조건도10.0/0/0/0%와 평균0.344/67에 그쳐 기본 .02/초를 유지한다. [직접 B 복귀 검사](support/B_RETURN_RESULTS.md)는 실제 명령 뒤 약.37초에 네 손가락이 B 대역에 도달함을 확인했다. 직접 명령 도달과 정책의 자발적 복귀 학습은 별개다.

통합판은 엄지 기하 근접6.34%였지만 엄지3 결과력 평균·최대0N이었다. 0–3mm 근접에 최대 보상을 주는 설계가 떠 있는 상태도 허용했으므로 v22에서 기하 절반·접촉 후보 절반으로 나눴다. v21 실행 원자료와 소스는 고치지 않는다.
