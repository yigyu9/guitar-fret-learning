# 선별 충돌의 실제 GPU 검증

다른 손가락의15개 실제 마디 사이90쌍만 새로 충돌하도록 바꾼 물리 입력을 읽어, 원물리 기준 시험과 같은16초 명령을 단일 GPU 환경에서 실행했다. 실제 native 필터 설정/역조회는1환경에서 일치했다. 입력 SHA 변경 없이 정상 종료했고, 240Hz 원자료3,840개와 실제 Gym 카메라480프레임/30fps 영상을 저장했다.

- LH21 목표 누적식 오차0, H32 경계29개 물리 시계 연속.
- 마지막 경계 reset에서 실제 준비 q, 제어 목표, 물리 시계의 복원 오차0.
- 모든 환경·모든 물리 표본의 q/qd/몸체 상태/결과력이 유한함.
- 최대 관절 한계 초과0.000115rad(약0.0066도), 최대 qd0.331rad/s.
- 기타 최대 이동2.277mm, 회전0.349도.
- 인체·기타·의자를 포함한 몸체 결과력 최대184.66N. 손가락만의 부하는 `analysis.json` 각 구간에 따로 기록했다.
- 최종 검지 벌림 잔차6.30도는 원필터6.31도와 비슷했다. B 자세의 검지 부하가 새 손가락 충돌만으로 해결되지는 않았다.

`native_oblique.mp4`는 실제 GPU 카메라 영상이고, `final.png`는 그 마지막 화면이다. 일부 기타 시각용 geom6개 로드 경고는 기존 장면에서도 발생했으며, 물리 collision shape 실패와 구분한다. 기타와 손은 실제 렌더됐지만 현/프렛 표시가 불완전할 수 있다.

이 시험은 초기/B 이동 중 새 필터가 큰 초기 반발을 만들지 않는다는 제한된 확인이다. 손가락 관통 방지 효과와 음악 성공은 별도 행동 재생/학습 평가에서 확인해야 한다.
