# 원물리 관절 제어 기준 시험

학습이나 관절 상태 강제 주입 없이 기존 GPU PhysX와 기존 유한 하체/상체 제어를 실행했다. 단일 환경에서 16초, 정책 주기 960회와 실제 240Hz 끝점 3,840개를 측정했다. 원자료는 `physics_env0000.npz`, 모든 정책 주기 요청은 `controls_env0000.npz`, 실제 카메라 영상은 `native_oblique.mp4`다.

1초 초기 유지 → 굽힘 +0.04/−0.04 각 1초 → 벌림 +0.04/−0.04 각 1초 → 4초 동안 B 이동 → B 유지 1초 → 동일 반전 → 최종 유지 2초 순서다. 동시 요청은 검지·중지·약지·소지에만 주며 엄지 정책 행동은0이다. 다른 정책 행동도0이지만 기존 하체 IK와 유한 지지 제어는 작동한다. 기타는 자유 강체이고 중력은 켜져 있다.

## 확인한 내용

- 매 주기 LH21 전체에서 `다음 목표 = native 범위로 제한한(직전 목표 + 행동×4/60)`과 실제 제출 목표의 최대 오차는 정확히0이었다.
- H32 표본 경계29개에서 물리 시계는 계속 증가했다. 이 진단은 PPO를 실행하지 않으며, H32를 지나면서 reset이나 목표 초기화를 하지 않았다. 전체 학습 경로의 H32 계약 검증과 별도다.
- 작은 요청 반전은 다음 정책 주기부터 목표에 반영되며 실제 관절도 반대 방향으로 움직였다. 초기 소지 MCP는 이미 native 상한 근처여서 양의 요청은0.47도만 반영됐지만 음의 반전은−9.17도로 즉시 반영됐다. 정상적인 목표 제한이다.
- 초기 굽힘 양의 구간에서 목표 변화 +9.17도에 대해 검지 MCP 실제 변화는+7.07도였다. B 구간의 같은 요청에서는+3.29도였고, 중지·약지·소지는 각각+8.08/+8.08/+8.03도였다. B 양의 굽힘 구간의 손가락 몸체 결과력 최대는37.40N이었다. 명령 변화 자체와 하중이 걸린 실제 관절 반응을 구분해야 한다.
- 최종 검지 벌림은 목표−14도, 실제−7.69도로6.31도 잔차가 남았다. 중간/끝관절은 B 목표를 잘 따랐다. 기존 B 시험의 검지 벌림 잔차와 부하를 다시 확인했다.
- 모든 표본은 유한했고, 실행 중 입력 SHA 변경이 없었으며, 마지막 경계 reset에서 물리 시계와 제어 목표가 복원됐다.

이 결과는 원영상의 극단적인 목표가 누적 제어 오류로 저절로 생성됐다는 근거를 제공하지 않는다. 기존 A500 자료에서 정책이 오랜 시간 같은 방향의 행동을 낸 증거와 함께 보면, 목표 선택·보상과 손가락 충돌 차단을 우선 수정하고 확인되지 않은 PD 변경은 피하는 것이 타당하다. 작은 시험으로 전체 작업 공간의 구면 관절 동역학을 검증한 것은 아니다.

## 측정 한계와 보존

몸체 결과력은 접촉 상대나 실제 줄 압력이 아니다. 초기/B 명칭은 명령한 자세 구분이며 무접촉 상태라는 인증이 아니다. 물리 표본에 q·목표뿐 아니라 실제 손바닥 상대 회전 quaternion/회전벡터를 따로 저장했다. 영상은480프레임/30fps이며 첫 프레임은 물리1/30초다.

`report.json`의 초기 이름 `prepared_q_max_error=0.053143rad`는 복원한 실제 q와 준비 목표 q의 차이다. 준비 상태 자체가 실제 q와 목표 q의 차이를 포함하므로 이를 복원 실패로 해석하면 안 된다. 후속 도구에서는 처음 복원한 실제 q를 별도로 저장해 `prepared_q_restore_max_error`로 직접 대조한다. 이 실행 원본 도구와 SHA는 `support/hand_contact_probe.py`, `support/source_archive.json`에 보존했다.

이 시험은 원물리 기준을 보존하며, 뒤의 선별 충돌이나 새 보상 성과를 포함하지 않는다.
