# 실제 물리에서 B 대기 자세로 돌아오는 시간

두 조건 모두 **12초에 B 목표를 직접 보내면 모든 비엄지 손가락이 0.371초 안에 B 범위로 들어왔고, 0.567초 안에 0.2초 연속 유지가 확인됐다.** 13.05~15초의 고정 평가 구간에서는 손가락별·네 손가락 동시 점유율이 모두 100%였다. 따라서 현재의 **복귀 예산 1초는 이 직접 제어 시험에서는 충분하다.** 이 결과가 약한 대기 보상을 받은 정책의 실제 복귀 성능을 보장하지는 않는다.

## 시험과 측정 기준

- 기존 A500 행동 기록의 첫 12초를 실제 GPU PhysX에서 재생한 뒤, 비엄지 16개 제어 채널을 기존 속도 4 rad/s를 통해 B 목표로 보냈다. 물리 상태나 실제 관절 각도를 덮어쓰지 않았다.
- `held`는 엄지의 12초 시점 목표를 유지한다. `return_initial`은 엄지 목표도 초기 준비 상태의 목표로 돌린다. 다른 행동 채널에는 직전 행동을 계속 보낸다.
- 각 조건 1개 환경, 15초, 240 Hz 실제 물리 표본 3,600개다. 두 조건 모두 종료까지 완료됐으며 실패·원자료 변경이 없었다. 이것은 학습이나 압현 성공 시험이 아니다.
- 실제 몸체의 부모·자식 quaternion을 `finger_posture_reward`와 같은 방식으로 투영해 MCP/PIP/DIP 각도를 계산했다. 네이티브 구면 관절 좌표와 다른 기하학적 각도다.
- B 판정은 MCP/PIP/DIP 세 값이 모두 유효하고 각각 B 중심 ±15도에 들어오는 경우다. 중심은 검지 25.490/35/12°, 중지 28.024/38/14°, 약지 31.027/41/16°, 소지 34.325/44/18°다.
- 첫 진입은 12초 이후 첫 물리 끝점이다. 0.2초 유지는 48개 연속 240 Hz 끝점으로 판정한다. 첫 끝점부터 마지막 끝점의 시각 차이는 47/240초이며, 48개 물리 틱에 해당한다.
- 고정 평가 구간은 정책 행동과 무관하게 13.05~15.00초다. 물리 끝점 469개, 틱 기준 약 1.954초다. 13.05초는 복귀 시작 12초 + 이완 여유 0.05초 + 복귀 예산 1초다.

## 엄지와 기타 움직임

아래 엄지 값은 실제 thumb3 몸체의 합력과, 같은 시점 실제 자세에서 구한 유한 넥 뒷면·엄지 패치 기하를 함께 보고한 것이다. **합력만으로 넥과의 접촉 쌍이나 압력을 확정하지 않는다.** 기하 근접 판정은 같은 선택점의 간격 0~3 mm, 목표 영역 내부, 방향 조건을 사용한다.

| 13.05초 이후 측정 | held | return_initial |
|---|---:|---:|
| thumb3 합력 평균 / 최대 | 0 / 0 N | 4.371 / 5.268 N |
| 넥 뒷면 바깥 법선 방향 하중 평균 | 0 N | 4.370 N |
| 기하 근접 비율 | 0% | 10.661% |
| 기존 선택점의 최소 부호 간격 | 52.090 mm | 0.620 mm |
| 같은 점의 간격 −1~0.5 mm·영역·방향·하중 후보 비율 | 0% | 0% |
| 최종 넥 뒷면 간격 / 영역 벗어남 | 52.102 / 72.199 mm | 1.595 / 35.570 mm |
| 최종 유한 목표 영역까지 패치 거리 | 89.035 mm | 35.606 mm |

초기 엄지 목표로 되돌리면 넥 뒷면에 가까워지고 엄지에 실제 하중이 나타난다. 다만 현재 작업 위치를 따르는 목표 영역의 중앙에는 계속 머물지 못했다. 특히 **0.5 mm 이하 간격의 접촉 후보가 0이라는 이유로 실제 하중까지 없다고 해석하면 안 된다.** 원본 메시의 패치 간격, PhysX 충돌 표면, 부하가 나타나는 시점이 서로 같은 측정량이 아니기 때문이다. 이 합력은 엄지가 어디에 닿았는지까지 알려주지 않는다.

**v22 초안의 선택 방식으로 같은 원자료를 사후 재측정한 결과도 구분해 확인했다.** v21은 기하 품질이 가장 높은 점을 고르는 반면 v22 초안은 기하·접촉 증분을 합한 보상이 가장 높은 한 점과 그 점의 법선을 함께 고른다. 이 방식에서는 `return_initial`의 후보가 12~15초 표본의 20%, 13.05초 이후의 10.661%에서 검출됐다. 최초·최후 검출은 12.658333초·13.254167초였다. `held`는 여전히 0%다. 따라서 앞 표의 기존 선택점 후보 0%를 v22 후보의 결과로 인용하면 안 된다. 이 수치는 기록된 자세에 대한 사후 측정이며 v22 물리·정책 실행 성과가 아니다. 움직이는 작업 영역에 초기 엄지 목표가 계속 머무르지 못한다는 한계도 남는다.

| 기타 실제 움직임 | held | return_initial |

두 조건에서 기타는 비슷하게 안정적이었다. 한 번의 직접 명령 시험과 매우 작은 차이만으로 엄지가 기타를 더 잘 지지했다고 결론 내릴 수 없다. 기존 하체·가슴·오른손 지지도 함께 작용한다.

## 적용 판단과 한계

- 복귀 평가에 사용하는 **고정 1초 예산을 유지**할 근거는 확보했다. 이 시험의 동시 유지 확인까지 약 0.567초였으므로 여유가 있다. 임의로 예산을 더 짧게 줄일 필요는 없다.
- 이 시험은 실제 12초 시점의 한 자세에서 출발한 직접 명령 결과다. 모든 곡 구간·부하·초기 자세의 최악 시간을 측정한 것은 아니다. 곡 사이 간격이 짧을 때 반드시 B를 거쳐야 한다는 근거로 사용하지 않는다.
- 대기 보상만으로 정책이 같은 행동을 학습하는지, 압현을 방해하지 않는지, 벌어짐과 손가락 사이 충돌이 자연스러운지는 별도 학습·진단에서 확인해야 한다.
- 엄지의 초기 목표는 움직이는 작업 영역을 추종하는 지지 방식과 다르다. 엄지 패치의 위치·방향·하중을 함께 검증하고, 실제 원본/충돌 표면 차이에 따른 접촉 후보 누락도 확인해야 한다.

숫자와 입력 SHA-256은 [b_return_analysis.json](b_return_analysis.json)에 저장했다. 원본 `controls_env0000.npz`, `physics_env0000.npz`, 두 `report.json`, 행동 테이프는 수정하지 않았다.
