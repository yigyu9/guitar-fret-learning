# 합의한 넓은 손목 안내 영역

2026-10-23. 사용자가 동의한 확대 범위를 고정 초기 자세의 시각화에 반영했다. 학습 보상/관측/준비판정, 실제 휴머노이드·기타 자세는 변경하지 않았다.

| 방향 | 직전 보정안 | 합의한 확대안 |
|---|---|---|
| 길이 | 작업 프렛 묶음 중심 ±4cm | 같은 중심 ±6cm, 총12cm |
| 높이 | 넥 아래2~6cm | 넥 아래1~8cm, 총7cm |
| 깊이 | 지판 뒤3~9cm | 지판 뒤 연주자쪽2~11cm, 총9cm |

작업 중심은 직전 보정안과 동일하게 곡의 `allowed_fret_range`에 속하는 전체 셀의 실제 양끝 경계 중점이다. 기타 로컬 좌표를 사용한다. 높이 기준은 anchor 프렛 셀 중심에서 구한 실제 넥 아래 테두리, 깊이 기준은 지판면이다.

첫 포지션은 작업4~9프렛이며 중심이 기준5프렛보다 바디쪽3.335cm다. 따라서 길이는 기준5프렛에서 너트쪽2.665cm~바디쪽9.335cm다. 고정 초기 손목은 영역의 바디쪽 경계 밖에 있고, 영역에 들어가려면 너트쪽으로 최소2.832cm 이동해야 한다. 초기손목을 포함시키기 위해 중심을 다시 이동하지 않았다. 9프렛 포지션은 작업8~13프렛이고 길이는 기준9프렛에서 너트쪽3.353cm~바디쪽8.647cm이며, 고정 초기 손목이 영역 안에 있다. 이는 정지한 초기손목과의 기하 비교이며 실제 압현 시 손목 움직임은 아니다.

이미지의 초록은 넓힌 부피, 파랑 테두리는 직전 보정안, 노랑은 작업 프렛 범위와 중심, 주황은 현재 음 목표, 흰 원은 초기 손목이다. 부피는 가림 없이 표시하고, 흰 선은 초기손목에서 영역까지의 최소변위를 나타내며 목표점이나 궤적이 아니다. 단면 그래프의 정면 넥은 개략 표시이고 오른쪽은 실제 source hull 단면이다.

학습에 적용할 때의 의도는 넓은 영역 안 위치 패널티0, 밖에서만 초과 거리에 따른 약한 패널티, 영역 중심이나 초기 회전을 강요하지 않는 방식이다. 이번 작업에서 그 보상은 구현하지 않았다. 이 범위는 넓은 시작 후보이며 자연스러운 압현 자세·손가락 도달성·충돌을 검증한 영역이 아니다. 실제 성공한 압현 자세의 손목 분포를 확인한 뒤 범위를 조정한다.
