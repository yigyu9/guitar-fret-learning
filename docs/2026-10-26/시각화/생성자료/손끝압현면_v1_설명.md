초록은 정상 접근·접촉에 사용하는 끝마디 면, 진초록 점은 그 면 위의 128개 샘플이다. 붉은색은 끝마디의 제외 부위이며 회색 첫·중간마디도 이 정상 압현 선택에서 제외된다. 물리적 충돌과 오압현을 무시한다는 뜻은 아니다.

## 정확한 모델 기준

검지·중지·약지·소지의 `finger3` STL에 원래 mesh scale과 geom 위치·회전을 적용한다. source 몸체 연결에서 원위 방향은 로컬 `−y`이고 `+x` 굽힘은 해당 방향을 `−z`로 회전시킨다. 그에 따라 **모델 굴곡 안쪽과 연결된 원위 끝부분**을 허용한다. 원본 메시에는 피부·손톱의 해부학적 라벨이 없으므로 이 색상은 해부학적 분할을 주장하지 않는다.

정의는 `u=(ymax−y)/(ymax−ymin)`일 때 다음 조건이다.

```text
z ≤ 0, u ≥ 0.25
그리고
normal_z ≤ −0.25
또는 (u ≥ 0.75, normal_y ≤ −0.4, normal_z ≤ 0)
```

법선은 scale·geom transform 적용 후 실제 삼각형 외적을 정규화한다. 삼각형 중심만으로 채택하지 않고 최종 위치 조건으로 삼각형을 잘라 실제 메시 면 위에서 샘플링한다. 면적 누적분포를 128개 등면적 구간으로 나누고 결정적 barycentric 위치를 사용한다. 엄격한 균일 간격 배치나 접촉 누락 없음은 보장하지 않는다.

실제 허용 면적은 손가락마다 약 **373mm²**, 128점 중 원위 1/4에는 **43~45점**이 배치된다. 위치·단위 법선·원본 삼각형 번호와 barycentric·source SHA·면적 및 간격 진단은 [수치 자료](/home/ajou/yigyu/3/docs/2026-10-26/시각화/생성자료/fingertip_pad_v1.json)에 저장한다. 그림용 clipped 면적을 production 계약의 면적과 대조한다.

## 그림 해석과 한계

첫 그림 왼쪽은 source의 중립 체인을 옆에서 본 것이다. 실제 학습 준비 자세는 아니다. 오른쪽은 끝마디만 굴곡 안쪽에서 확대해 허용 면의 빈틈과 제외 범위를 확인한다. 깊이에 가려지는 점도 겹쳐 표시하므로 영상에서 보이는 표면만 표시한 것은 아니다.

둘째 그림은 source의 몸체 연결 위치와 실제 메시를 사용한 설명용 FK 예제다. 네 손가락에 MCP/PIP/DIP 예시 굽힘 각도 `[0,0,0]`, `[25,35,15]`, `[55,65,30]`도를 적용하고 별도 예제에서 벌림 `[-12,-4,5,15]`도 및 손 전체 y축 180도 회전을 적용했다. source 로컬 표면에 같은 샘플을 붙인 뒤 몸체 회전만 적용한다. **native 관절 적분·접촉·학습 결과나 자세의 자연스러움을 증명하는 그림이 아니다.** 엄지·손바닥은 생략했다.

그림을 만들기 위해 몸체나 충돌 메시를 바꾸지 않았고 native 물리를 실행하지 않았다. 기존 시각화 파일은 보존했다. 생성 코드·수치 자료·설명·SHA manifest는 모두 이 단일 `생성자료` 디렉토리에 있다.
