## 정확히 어떤 표면인가

64개의 고정 구면 방향과6개의 좌표축 방향에서 메시의 가장 바깥 정점을 뽑고 중복 인덱스를 제거한다. 따라서 마디마다 최대70개 후보이며 모든 메시 삼각형/피부 표면을 연속 탐색하는 것은 아니다. 유효 mask가 없는 padding 점은 제외한다.

중간마디와 끝마디의 둘레 전체가 후보이고, 손바닥 쪽 살집이나 손끝 패드만 선택하는 필터는 없다. 손등 쪽·옆면 정점도 들어간다. 목표와 자세가 바뀌면 후보점들의 실제 위치와 최근접 선택점도 달라진다. 현재 예시에서 중지가 실제로 중간마디 점을 선택하므로 항상 끝마디/손끝에서만 접근 거리를 계산하는 것도 아니다.

첫마디(finger1)는 접근 거리 후보에 포함하지 않는다. 공용 샘플 버퍼에는 엄지2/3도 들어 있지만 네 손가락 압현 목표의 접근 함수는 엄지를 선택하지 않는다. 해당 버퍼 인덱스·유효 mask·기타 로컬 좌표 전체는 `finger_surface_samples.json`에 저장했다.

정면 확대는 기존 실제 모델 렌더를 사용하고 가려진 표면점도 겹쳐 표시했다. 상세 그림은 실제 source STL의 scale·geom transform·고정 몸체 transform을 적용한 메시의 정면/깊이 투영이다. 상세 좌표는 각 손가락 첫마디 메시 정점 평균을 원점으로 하는mm 표시다. 바깥쪽/뒤쪽 점도 보이도록 가림을 적용하지 않았다. 점의 화면상 겹침은 실제 접촉을 뜻하지 않는다.

각 선택점에서 유한 목표 선분까지의 거리를 모든 유효 후보에 대해 별도 NumPy 계산으로 확인했다. 이 시각화에는 접촉 하중 조건을 적용하지 않으며 압현 성공·압력·피부 변형·새 학습 성능을 판정하지 않는다.

생성 소스는 같은 폴더의 `visualize_finger_surface.py`, 수치와 입력 SHA는 `finger_surface_samples.json`이다. 학습 소스나 이전 시각화 파일을 덮어쓰지 않았다.
