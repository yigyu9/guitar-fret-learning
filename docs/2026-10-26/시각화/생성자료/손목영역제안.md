# 손목 점 안내를 자유 영역으로 바꾸는 제안

2026-10-23 작성. 현재 학습 모델·보상·기존 점 안내 영상에는 적용하지 않은 제안이다.

## 권장 시작 범위

기타와 함께 이동·회전하는 기타 로컬 좌표에서 손목 몸체의 원점이 다음 세 범위를 동시에 만족하면 위치 패널티를 0으로 한다. 영역의 중심이나 특정 회전을 따라갈 필요는 없다.

| 방향 | 기준 | 허용 범위 |
|---|---|---|
| 넥 길이 | 현재 손 포지션의 기준 프렛 셀 중심 | 기타 바디 쪽 5~13cm |
| 높이 | 해당 기준에서 실제 넥의 아래 테두리, 1번 현 쪽 | 아래로 2~6cm |
| 앞뒤 깊이 | 실제 지판면 | 지판 뒤, 연주자 쪽으로 3~9cm |

허용 부피는 길이 8cm × 높이 4cm × 깊이 6cm다. 각 경계도 허용한다. 높이·깊이는 화면이나 세계 좌표가 아니라 기타 기준이다. 현재 기타에서는 로컬 +X가 넥 아래, -Y가 바디 쪽, -Z가 지판 뒤다.

여기서 기준 프렛은 곡의 `anchor_fret`이며 현재 누를 음의 프렛과 다를 수 있다. 예를 들어 첫 압현 목표는 7프렛이지만 손 포지션은 5프렛이다. 프렛 셀 중심은 해당 프렛 철사와 그 앞 철사 사이의 중앙이다. 분수 anchor는 인접 셀 중심을 선형 보간한다. 넥 아래 테두리는 그 기준 단면의 실제 source hull과 지판면 교차에서 구한다. 이 테두리를 기준으로 만든 직육면체이며, 길이 전체에서 넥 테두리를 매번 따라가는 곡면은 아니다.

## 이 범위로 시작하는 이유

현재 초기 손목은 기준 포지션 5프렛에 대해 바디 쪽 12.17cm, 넥 아래 4.18cm, 지판 뒤 7.48cm에 있다. 제안 영역 안이므로 초기 자세를 바꿀 필요가 없다. 높이는 초기 손목 위아래로 약 2cm, 깊이는 손목이 지판 쪽으로 접근하거나 뒤로 물러날 여유를 주었다. 길이 8cm 폭은 동일 포지션에서도 손가락의 뻗음·굽힘을 이용할 여유를 주기 위한 실험 시작값이다.

현재 점 안내는 초기 손목의 높이와 깊이를 유지하고 넥 길이 방향으로만 이동한다. 화면에서 몸에서 바깥쪽으로 나가는 것처럼 보이더라도, 코드에는 지판 앞뒤로 점을 이동시키는 항이 없다. 다만 점 주위 2cm 안에 들어가야 위치 점수가 최대라서, 포지션 변화가 큰 구간에서 손목을 많이 옮기도록 유도할 수 있다.

곡의 기준 포지션 9프렛 시점(시각화 13.683초)에 초기 손목에서 계산하면 다음과 같다. 이 수치는 정지한 초기 손목에서의 기하 비교이며 학습 궤적 측정은 아니다.

| 비교 | 필요한 거리 |
|---|---:|
| 기존 안내점 중심까지 | 9.60cm |
| 기존 위치 만점 구(반지름 2cm)까지 최소 거리 | 7.60cm |
| 새 허용 부피까지 최소 거리 | 2.72cm |

손목의 자유도가 늘어난다는 뜻이며 압현 성공이나 손가락의 도달성을 증명하지는 않는다. 특히 영역 가장자리와 모든 현·손가락의 조합은 아직 확인하지 않았다.

## 영역 밖 패널티 제안

영역 안에는 위치 보너스도 패널티도 없다. 밖에서는 각 축에서 경계를 벗어난 거리만 사용한다. 손목을 고정하거나 강제로 되돌리지 않는다.

기타 로컬 축 순서 X/Y/Z, 단위 m에서:

```text
e = max(lower - wrist, wrist - upper, 0)   # 성분별
q = sum((e / [0.02, 0.03, 0.03]) ** 2)
penalty_rate = -weight * q / (1 + q)
```

높이 2cm, 길이·깊이 3cm를 벗어났을 때 각 축의 정규화 오차가 1이다. 경계에서는 연속적으로 0이고, 더 벗어날수록 부드럽게 증가하며 벌점 크기는 weight보다 작다. 여러 축을 벗어나면 오차를 합산한다.

기존 GPU 왼손 손목 항의 단계별 계수 크기인 0.20 / 0.10 / 0.05를 우선 유지하되, 양성 점수 대신 이 음성 위치 항에 적용하는 후보로 제안한다. 초당 보상 단위이며 물리 240Hz에서는 매 스텝 `penalty_rate / 240`을 누적한다. 예를 들어 초기 단계에서 높이만 1cm 벗어나면 -0.04/초, 길이 또는 깊이만 3cm 벗어나면 -0.10/초다. 이는 기존 보상과 동일한 학습 효과를 보장한다는 뜻이 아니다.

학습 적용 시 준비 판정도 `영역 안` 기준으로 바꾸고 기존 점 거리·초기 손목 회전의 준비 조건을 남기지 않는다. 관측에 제공하는 위치 오차도 경계까지의 부호 있는 초과 거리로 맞춰 영역 안에서는 0이 되도록 한다. 위치 안내에 새 회전·행동·속도 비용은 추가하지 않는다. 압현·오압현 판정과 실제 손가락 목표, 물리 관절 제한은 별개로 유지한다.
