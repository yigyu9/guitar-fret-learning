초록은 현재 모델의 실제 넥 충돌 소스 메시 뒷면을 따른 제안 영역이다. 넥 폭의 가운데 50%, 첫 작업 프렛 범위 4~9의 바깥 셀 경계 중점에서 넥 길이 방향 ±4cm다. 영역 중심 Gy는 약 41.12mm이고 길이 범위는 약 1.12~81.12mm다. 넥 뒷면은 약간 기울어져 있으므로 고정 Gz 평면으로 대체하지 않았다.

주황은 엄지, 노랑은 끝마디 원본 메시의 굴곡 안쪽을 기하로 잘라 정한 실험적 패드 후보, 빨강은 그 후보 위의 정지 예시 근접점이다. 모델에 해부학 표면 label은 없으므로 노랑을 인증된 해부학적 패드로 해석하지 않는다. 이 면은 넥을 향하므로 뒤쪽 시점에서 일부가 가려진다. 넥을 향한 같은 면의 위치와 법선을 확인했다. 빨간 점은 고정 목표가 아니며 초록 영역 안에서 같은 보상을 주자는 제안이다.

v16 준비 상태를 읽고 엄지 체인만 관절 한계 안에서 바꾼 정지 예시다. 비엄지 몸체·기타는 그대로다. 엄지 원본 메시의 모든 꼭짓점이 넥 뒷면 평면 바깥에 있고, 예시 근접 간격은 약 0.124mm다. 아직 원본 소스 hull을 기준으로 한 기하 검증이며 cooked PhysX 접촉쌍·압력·연주 성공·동적 도달성을 인증하지 않는다.

0~3mm는 앞으로 사용할 최대 근접 보상 대역의 제안이다. 이 예시 관절각으로 강제하거나 초기 상태를 교체하지 않으며, 보상도 아직 구현하지 않았다. `render.py`는 자유도 0인 정지 MuJoCo 렌더러로 자세만 설치하고 물리를 적분하지 않는다. 오른쪽 간격 그림의 엄지 모양은 도식이며 실제 메시 크기의 단면이 아니다.

재현 도구·입력/결과 SHA·정지 상태는 이 디렉토리의 `render.py`, `verification.json`, `candidate_state.json`에 모았다. 독립 검수는 `independent_review.json`에 기록한다.
