# 손가락 준비 자세 후보

압현 사이에 거쳐갈 수 있는 손 모양을 비교하는 정적 이미지다. 학습·보상·초기 자세는 변경하지 않았다. 현재 모델의 실제 손 메시를 사용하고 엄지·손바닥·팔·기타는 준비 상태 035/v14 그대로 두었다.

손 모양의 시각적 후보로 **B(중간 굽힘)**를 우선 추천한다. 사용자가 이미지를 보고 선택하기 전에는 적용하지 않는다. 이 추천은 물리 안정성이나 압현 가능성을 검증한 결과가 아니다.

| 손가락 | A 얕게 | B 중간 | C 조금 깊게 | MCP 벌림 z |
|---|---|---|---|---:|
| 검지 | 15 / 25 / 8 | 25 / 35 / 12 | 35 / 45 / 18 | −14 |
| 중지 | 18 / 28 / 10 | 28 / 38 / 14 | 38 / 48 / 20 | −3 |
| 약지 | 21 / 31 / 12 | 31 / 41 / 16 | 41 / 51 / 22 | +3 |
| 소지 | 24 / 34 / 14 | 34 / 44 / 18 | 44 / 54 / 24 | +10 |

단위는 도, 각 셀 순서는 MCP x / PIP x / DIP x 설계 입력이다. MCP는 현재 GPU 명령 참조인 `Exp([x,0,z])`로, PIP/DIP는 source body의 +x 회전으로 배치했다. MCP 값은 벌림과 결합한 회전 입력이므로 해부학적으로 측정한 굴곡각과 같다는 뜻이 아니다. native MuJoCo의 순차 힌지를 적분한 결과도 아니다. 모든 입력은 source XML 및 실제 native PD 관절 한계 안이다.

서로 다른 손가락의 source convex hull 사이에는 1µm보다 큰 양의 공통 내접구 반경이 검출되지 않았다. 이 검사는 손바닥 충돌, 관절 인접부, 실제 물리엔진 접촉 또는 도달성을 검증하지 않는다. **기존 손목 위치에 후보를 그대로 넣으면 검지와 기타 넥이 겹친다.** 기타 맥락 그림에 이를 표시했다. 손 모양을 선택한 뒤 손목 위치와 전환 동작을 함께 맞춰야 한다.

MuJoCo의 정적 표시 기능과 CPU OSMesa를 사용했다. 렌더 장면 자유도는 0, 시뮬레이션 시간은 0초, 물리 step은 0회다. `finger_preparation_candidates_v1.json`에 각도·body 변환·관절 한계·입력 SHA·겹침 진단을 기록했다. 겹침 진단의 수치는 공통 내접구 반경이며 침투 깊이가 아니다.
