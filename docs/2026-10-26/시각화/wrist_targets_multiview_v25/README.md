# 곡 압현 목표와 손목 영역: 세 각도 영상

합의한035/v14의 실측 body pose와 source 기하를 고정하고, 원곡67개 목표와 학습 코드의 손목 영역 수식만 시간에 따라 표시했다. 사람과 기타는 움직이지 않는다. 초기 자세를 여러 방향에서 점검하기 위한 영상이며 학습 동작·압현 성공·도달성의 인증은 아니다.

세 영상은1280×720·30fps·985프레임·32.833초다. 원곡의 준비3초 포함32.8167초를30fps 프레임으로 표현해 마지막 표시 길이에0.0167초 차이가 있다.67개 목표 모두 실제 압현 구간과 다음 목표 표시 구간에 한 프레임 이상 포함되는지 검사했다.

## 표시

| 표시 | 의미 |
| --- | --- |
| 초록 상자 | 안내 영역: 작업 프렛 중심±6cm·넥 아래1~8cm·지판 뒤2~11cm |
| 빨간 상자 | 종료 경계 후보: 안내 영역에서 각축3cm 확장（넥 길이18×높이13×깊이15cm） |
| 흰 점 | 움직이지 않는 초기 손목의 실제 위치 |
| 주황 | 현재 press~end 구간의 압현 목표·담당 손가락/줄/프렛 |
| 노랑 | 다음0.5초 안에 압현을 시작할 목표 |
| 파란 숫자/선 | 현재 기타의 프렛 셀 번호와 경계 |

상자는 화면 가림과 무관하게 겹쳐 표시한다. 빨간 경계 밖이라고 즉시 종료하는 것은 아니며 학습에서는 준비·전환 유예와 .75초 지속 조건을 함께 적용한다. 심각한 이탈 기준은 영상의 빨간 상자보다 더 바깥이다.

렌더러는 실측 Isaac 초기 자세를 정확히 배치한 source mesh의 MuJoCo 정적 렌더링이다. 물리 시뮬레이션·정책·IK를 실행하지 않았다. 몸체 변환 불변·시뮬레이션 시간0·자유도0·카메라 상하 방향·동영상 인코딩을 검사했다.

필요한 생성 파일·고정 배경·카메라·영역 트랙·검증 보고서는 [생성자료](생성자료/)에 모았다. 첫 측면 후보는 바닥 아래 시점이라 제외했고, 최종 위쪽 측면으로 교체했다. 이전 후보는 생성자료 하위에 보존했다.
