# 원영상 마지막 왼손 자세 확인

사용자가 지정한 A500 원영상의 마지막 저장 자세만 읽어 소지 관절 조합, 검지–중지 및 엄지–중지의 겹침, 엄지–넥 뒷면 거리를 확인한다. 이전 결과·현재 학습 코드는 수정하지 않는다. 추가 학습이나 물리 재실행 없이 원영상과 동일한 저장 몸체 자세를 색으로 구분해 재표시한다.

- [x] 마지막 관절각·목표·정책 명령과 현재/동결 보상 경로 대조 → 소지90/90/−5, 전용 엄지 넥뒤 유도 보상 없음
- [x] 엄지 유한 뒷면 거리와 원본 convex 교차 확인 → 마지막14.092mm, 엄지–중지·검지–중지 교차; 관통 깊이와 구분
- [x] 새 원인 경로 확인 → 물리 손가락 마디15개의 공통 filter128, 서로 다른 손가락 조합90개가 필터로 충돌 억제
- [x] 색상 구분 이미지·RESULTS.md·JSON·독립 검수 → 입력/초안 SHA와 기하 독립 재계산 통과, 분석 산출물 Critical/Warning 없음. 기존 필터 문제는 별도 진단 결과로 보존

원본 convex hull의 교차 여부는 PhysX cooked 충돌·접촉 쌍·실제 압력을 인증하지 않는다. 원영상은 마지막 프레임의 물리 시계32.816667초와 영상 PTS32.8초를 구분한다.
