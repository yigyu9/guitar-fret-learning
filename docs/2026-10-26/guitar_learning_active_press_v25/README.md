# v25 준비 관문 제거·팔/손가락 동시 학습

요청한 구조 변경을 명시적인 새 실행 경로로 구현했다. 기존495개 Python과 이전 결과는 수정하지 않았다. 새 Python5개를 더한500개 소스로 검증했다. **기존 `guitar_learning.train`의 기본 동작은 유지하므로 새 v25 진입점을 사용한다.**

[실행 명령과 계약](/home/ajou/yigyu/3/guitar_learning/tool/experiments/active_press_v25/README.md) · [손목 영역 다각도 영상](/home/ajou/yigyu/3/docs/2026-10-26/시각화/wrist_targets_multiview_v25/README.md)

## 구현

1. **R 관문 제거**: 연속 곡 구간에서 팔·손목·엄지17축과 손가락16축을 첫 결정부터 함께 학습한다. 정책 인코더/출력부 분리는 유지한다. 준비 상태 복원은 에피소드 경계에 한 번만 수행한다.
2. **팔 탐색**: 기존 위치 제어와 native 한계를 유지한다. 초기 팔 latent std는약.05→.10, 명령은 최대3tick 공동 유지다. 이벤트·실패·H32 경계에서는 짧게 확정하며 가변 d PPO로 계산한다.
3. **엄지 누적 편향 제거**: 엄지5축만 준비 참조각 기준 전체 native 범위 위치 요청으로 바꿨다. 같은 작은 명령을 오래 내도 계속 누적되지 않는다.0은 준비 참조 목표를 요청한다. 네 손가락16축은 기존 누적 제어·움직임 비용0·독립4rad/s다.
4. **손목 종료 조건**: 기존 안내 영역은 관측·진단으로 유지하며 연속 손목 보상은0이다. 안내 상자를 각축3cm 확장한 영역에서 .75초 지속 이탈하면 해당 에피소드를 종료한다. 초기3초·목표 영역 중심1cm 이동 뒤 .35초 유예와 타이머 입력2개를 추가했다. 심각한 추가10cm 이탈은 준비3초 뒤 즉시 종료한다.
5. **기존 실패 처리 유지**: 물리 실패와 `wrist_region_exit`를 이유별로 기록한다. 실제 종료의 bootstrap0·양성 억제·남은 구간 실패 비용·고정 목표 분모를 유지한다.

상태는559, 행동은39（활성왼손33·오른손6은0）다. Root/의자·하체 유한 제어·자유 기타/중력ON/스트랩OFF·105/97/8·48POSITION/57EFFORT·PD와 힘 상한을 유지한다. 기타 부착·직접 보조 힘·학습 중 상태 덮어쓰기는 없다.

## 검증

- **CPU80개 검사 통과**: all33 학습/gradient, 엄지 위치·손가락 누적 구분, 공동 행동 유지·할인합, 종료/부분reset/H32, 타이머 관측, 기존 경로 회귀. [검사 로그](support/cpu_checks.log)
- **최종 large128/H32/seed7·16회**:65,536개 실제60Hz 전이, 정상 완료. support 텐서18개와 finger 텐서32개가 갱신돼 손가락 학습이 실제로 켜졌음을 확인했다.
- **최종 large1024**: 새2회65,536전이와 동일 모델의 추가1회32,768전이를 정상 완료했다. 최소 관측 GPU 여유는약5.230GiB다. 이는 짧은 자원 검사이며 장시간 메모리 안정성 인증은 아니다.
- **엄격 재개**: 초기 저장본에서 모델·두 Adam·업데이트·RNG가 이전 최종과 정확히 일치했다. curriculum을 복원하고 sampler를 복원한 뒤 새 준비 에피소드로 시작했다.
- **결정 기록 대조**: 최종128환경의 모든 원시 전이가 정확히 한 결정에 포함되는지와 실제 d의 보상/비용 할인합을 원시 로그에서 다시 계산했다. [검증 JSON](support/verification.json)

## 팔 탐색 후보 비교와 남은 한계

처음 시도한 std.25는 기타 이탈이 많아 기본으로 채택하지 않았다. 같은 seed·128환경·16회·65,536 실제 전이에서 .10으로 줄였다. 두 조건은 종료 시점이 달라 완결 에피소드와 선택된 음 노출 수가 다르다.

| 초기 팔 std | 시간축 완주 | 실패 종료 | 완결 에피소드 합계 |
| --- | ---: | ---: | ---: |
| .25 첫 후보 | 94 | 152 | 246 |
| .10 최종 | 137 | 23 | 160 |

최종23개 실패 중 기타 변위16건·기타 회전3건·손목 이탈7건이 기록됐다. 이유는 겹칠 수 있으므로 합산하지 않는다. **실패가 없어졌다는 결과는 아니다.** 이 비교는 한 seed의 짧은 탐색 크기 점검이며 .10의 일반적 최적성이나 자연스러운 압현 학습 향상을 입증하지 않는다. 학습 중 달성은 .25 후보1음/1454기회, .10 최종9음/907기회였으나 고정 평가가 아니므로 성능 향상 점수로 채택하지 않는다.

지금까지는 새 구조의 작동·저장/재개·측정 일관성을 검증했다. 새 모델의 장기 학습, 전곡 고정 성능 평가, 손 모양의 자연스러움 검증은 실행하지 않았다. 이번에 제공한 다각도 영상은 학습 동작이 아니라 **고정 초기 자세에서 곡 목표와 손목 영역을 보는 검증 영상**이다.
