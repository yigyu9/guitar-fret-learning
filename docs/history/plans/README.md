현재 로컬 코드·실험 봉인·문서에서 참조하지 않는 완료 계획을 작성 시기별로 모았다. 본문·체크 상태·파일 바이트는 그대로 보존했다. 새 학습 계획이나 현행 실행 명령으로 해석하지 않는다.

현재 계획을 찾을 때는 [plans 안내](../../plans/README.md), 전체 문서는 [문서 색인](../../DOCUMENT_INDEX.md)을 따른다. 날짜별 실험·봉인 입력이 참조하는 계획은 이동하지 않았다. 기존 `docs/archive/plans/`의 별도 원문도 그대로 남겨 두었다.

Git의 일반 archive 제외 정책과 구분해, 공유 가능한 과거 계획은 `history/` 아래 보존한다. 이번 이동 목록·원래 경로·SHA는 [이동 기록](../../maintenance/organization_20261031/moves.json)에 있다. 과거 정리 inventory의 경로는 당시 위치이며 이 이동표와 함께 해석한다.
