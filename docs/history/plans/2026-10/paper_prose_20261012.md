# 논문 본문 서술로 개정

사용자의 2026-10-12 요청에 따라 기존 한국어 초안을 실제 논문처럼 읽히도록 개정한다. 제목과 여섯 장의 순서는 유지한다. 이번 요청을 기존 초안의 서술 개정에 대한 승인으로 적용한다.

## 작업 순서와 검증

1. 장별 논지를 연결하고 연구 메모형 표현을 학술적 서술로 개정한다. 검증: 연구 문제 → 방법 → 실험 → 결과의 대응과 용어 일관성.
2. 작성용 메모와 후속 실험 체크리스트를 본문 밖으로 모은다. 검증: 중요한 조건·실측 수치·출처가 소실되거나 성능 주장이 강화되지 않았는지 확인.
3. 독립 검수 후 링크와 핵심 수치·범위를 점검한다. 검증: 전신 모델/상체 제어, 오디오 전처리/실제 평가 입력, 정적 안정/음악 성공의 구분.

## 체크리스트

- [x] Introduction과 Related Work를 연구 동기와 차별점 중심의 본문으로 개정.
- [x] Methodology를 정의·수식·설계 근거가 연결된 본문으로 개정.
- [x] Experiment와 Result를 평가 절차·관측·해석 중심의 본문으로 개정.
- [x] 부록·작성 메모·목차의 역할을 정리.
- [x] change-reviewer 검수와 링크·핵심 내용 점검 완료.

## 담당 범위

- root: Introduction, README, 부록, 작성 메모, 계획.
- 관련 연구 담당: Related Work.
- 방법 담당: Methodology.
- 실험 담당: Experiment, Result.
- change-reviewer: 최종 읽기 전용 검수.

연구 코드와 실험 원자료는 수정하지 않는다. 실제 성능을 새로 측정하거나 미실행 실험을 수행한 것으로 서술하지 않는다.

## 완료 기록

2026-10-13 완료. 여섯 장을 학술적 서술로 개정하고 작성 지침·후속 실험·그림 및 과거 아이디어를 paper/writing_notes.md로 모았다. 주요 방법 수치와 12개 실험군, 표·근거·실측 실패 및 평가 범위를 보존했다.

change-reviewer는 여섯 장을 검수했다. 지적된 등록 목표 대비 평가와 원음 대비 전사 오류의 구분, 안전 종료 시 현재 tick 보상의 대체를 보완했고 중복 조사를 수정했다. 새 방법 수식은 실제 구현과 대조했으며 λ 계수의 반감기와 실제 GAE 가중치도 구별했다. 로컬 링크·줄 번호·수식 및 코드 구분자를 검사했다. 새 연구 실험은 수행하지 않았다.
