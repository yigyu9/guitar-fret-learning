# GPU 왼손 손가락의 움직임 비용 제거

사용자가 손가락 움직임 비용을 아예 없애도록 승인했다. 현재 GPU 왼손만 대상으로 LH21(엄지 포함)의 명령 크기·변화 비용과 실제 표면 속도에 따른 추종 보상 감소를 제거한다. 목표 거리/접촉/자세·성공/물리안전·제어·관절범위/PD·PPO는 유지한다. 팔/손목의 기존 명령 변화 비용은 기존 축당 계수를 유지한다. CPU/오른손·과거 결과는 변경하지 않는다. 보상v7로 분리해 v6 저장본의 strict resume를 거부하며 새 계약끼리3331상태 복원은 유지한다.

- [x] 변경 전 구현·검사·현재4문서를 SHA와 함께 보관하고 범위/성공 기준을 기록한다.
- [x] 추종 보상을 거리/후보만의 함수로 만들고 LH21 명령 변화를 공통 감점에서 제외한다. 보상 계약과 curriculum 식별을 갱신한다.
- [x] 명령·표면속도 불변성, 엄지/각손가락 변화 무감점, 팔/손목 기존 계수·오른손 회귀, v7재개/v6거부·3331 복원 및 관련 CPU 검사를 통과한다.
- [x] 독립 변경 검수 후 현재 문서·실행 한계를 갱신하고 원본 봉인 보존을 확인한다. 추가 장기학습은 이번 요청에 포함하지 않는다.
