# 손가락 목표각 직접 지정 전환

사용자 요청: 손가락을 직접 위치 제어로 바꾸고 정상 동작을 검증한 뒤 기존 누적 제어를 활성 코드에서 제거하거나 보관한다. 이미 전환과 정리를 승인받았으므로 아래 순서대로 수행한다.

## 범위와 기준

GPU 왼손 LH21의 기존 position codec을 기본이자 유일한 손가락 제어로 사용한다. 행동0은035/v14 준비 기준각, -1/+1은각관절native하한/상한 요청이다. 전체 가동범위와4rad/s 목표변화 제한, 손가락 움직임비용0, 보상9개·물리·종료조건을 유지한다. 팔/손목의 위치 보정·하체제어·로그의 증분집계는 손가락 행동누적과 다른 기능이므로 유지한다.

- [x] 변경 전 활성 소스·검사·문서 원문과 SHA를 archive에 보존하고 CPU 기준검사 기록.
- [x] 학습/환경/계약/진단 도구를 직접 위치 제어로 연결. 이전 제어 checkpoint는 strict 거부하며 조용히 재개·호환시키지 않음.
- [x] 명령 반복이 같은 위치로 수렴함, 반전/0복귀/가동범위/속도제한/부분reset과 다른 제어 보존 CPU 검사.
- [x] 비참여 change-reviewer 검수, 실제 GPU 제어·짧은 학습·동일계약저장/평가 검증. 학습성과와 구현 정상 여부를 구분.
- [x] 검증 후 누적 손가락 코드·관련 선택 옵션·전용 검사를 archive로 보관하고 활성 경로에서 제거. 현재 문서와 명령 갱신 후 재검증.
