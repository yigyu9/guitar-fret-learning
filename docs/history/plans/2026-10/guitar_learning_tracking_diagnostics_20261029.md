# 손가락 제어·압현 진단 로그 추가

사용자가 로그 도구 추가를 승인한 범위에서 진행한다. 보상·제어·물리는 바꾸지 않는다.

- [x] 기존 기록 확인 및 변경 전 원문·SHA 보관
- [x] 목표 요청/실제 전달 목표/실제각·속도/힘·접촉 기록 연결
- [x] 전체 환경 요약과 용량 제한 대표환경 상세 기록 구현
- [x] CPU 검사 및 가능한 GPU 짧은 작동 확인
- [x] 독립 검수·로그 문서 갱신

검증: 기존 진단과 중복하지 않고 선택 reset/H32 수명, 표본 주기, 실제 힘과 계산 명령 구분, 로그 용량 제한을 검사한다.
