# clean 유지와 연속 달성

사용자가 유지 보상 보존·달성 조건 개선을 승인했다. GPU 왼손만 누적clean40% 대신 onset~end 안에서 연속clean이 `min(D,max(50ms,0.4D))`를 처음 충족하면 기존0.5점×손가락/단계계수 보너스를 음별 한 번 지급한다. clean 유지 보상 `2×누적정상시간/D`, 연속최초접촉v11 동작, 물리·제어·PPO·CPU/오른손을 유지하며 학습은 실행하지 않는다.

- [x] 변경 전 v11 코드·검사·관련 문서462개 원문을 보관하고 SHA를 확인했다. 이전v11 보고서472개 파일도 그대로다.
- [x] clean_streak로 onset~end 연속달성을 적용하고 유지 보상·누적진단을 보존했다. event11과원장v5에연결하고보상v12/관측v4로의미를구분했다. 길이0음은GPU왼손초기화에서거부한다.
- [x] 관련23모듈229개 CPU검사(새14개), 최종guard 관련8모듈82개재검사와독립75개검사·1152표본scalar대조를통과했다. 현행문서와검증기록을갱신하며실제학습은수행하지않았다.

완료 기준: 예컨대1초음의0.2초접촉→이탈→0.2초접촉에는 달성보너스가 없고, 한 번 연속0.4초에는 기존보너스를 한 번 지급한다. 두 경우의 유지 보상은 각각 실제 누적정상시간에 비례한다. 연속40%는 학습용 중간 달성 기준이며 전곡음향품질의 입증이 아니다.
