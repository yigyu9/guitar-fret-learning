## 조사 결과와 구체적 정리 범위

두 탐색자가 native와 나머지 활성 코드를 각각 조사했다. native65개는 현재 출처 검증/pin 대상이며 버전명45개 중42개는 현행 runtime 상속·호출 체인,3개는 렌더·solver가 사용한다. 나머지 활성 버전 코드도 GPU/CPU·전문·검사 경로가 사용한다. Python 소스 이동은0개다. 비권장 과거 재현 설정 long_B_16env_v1.json만 원문·SHA를 보관한 뒤 활성 configs에서 제거하고 안내 링크를 보관본으로 바꿨다.

기존 로컬 이전 버전 보관본18개(6,864파일)와 이번 설정/문서 정리 보관본1개를 외장 guitar_project_archives_20261023_v1/guitar_learning/archive/의 같은 이름으로 검증 이동하고 원래 경로를 링크로 유지한다. 현재 별도 개발 작업에서 새로 생성한 20261026_before_finger_skill_v24와 gpu/environment.py 등의 사용자 변경은 그대로 둔다. 정리 전6개 모듈32개 CPU 검사가 모두 통과했다.
