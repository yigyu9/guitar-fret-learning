## 로그 저장 오류 복구

첫 실행은308회 기록 후 SIGFPE, 300회 저장본으로 복구한 두 번째 실행은 global485회 기록 후 같은 신호로 종료했다. GDB는 유한 실수의 JSON 변환(format_float_short)에서 FE_INEXACT가 trap으로 전달된 것을 확인했다. FP환경을 바꾼 native 호출의 출처는 미확인이다. JSON 쓰기 동안만 해당 thread의 FE_INEXACT를 가리고 전체 기존 FP환경을 복원하는 최소 수정과 독립 검수를 진행했다. 물리·보상·성공·PPO는 유지한다.

최종 경로는 원본300 + 두 번째150 + 수정 후1550 =2000회로 구성한다. 미저장8+35회는 실행 이력으로 보존하되 최종 모델 경로 통계에서 제외한다. 재개는 물리 상태까지 복원하는 연속2000회 실행이 아니다. 수정 후 소스429개를 새 결과 디렉토리에 동결한다.

첫 JSON보호 후에도 global820회에서 동일SIGFPE가 재발했다. 800회 저장본을검산했고 보호충분성을철회했다. 과거transition runtime_v2의 Dragon4 JSONEncoder가 같은CPython실수변환경로를 피하고100k float표기·canonicalSHA·bit roundtrip검증을갖춘것을확인했다. 이번에는global FP변경없이 core의JSON 쓰기에해당최소인코더를적용한다. 네구간의최종모델경로는300+150+350+1200=2000회,미저장8+35+20=63회는별도이력이다.

## 최종 결과

마지막1200회는 정상 종료했다. 고정1024환경 평가의 평균 달성은3.861328→8.300781/67음, 안전 완주는1024→1020곡이다. 최종 달성의98.6235%가 검지에 집중됐으며 중지·67음 전체 성공은0이다. CPU831개 테스트와 독립 최종 검수는 통과했다. x87 상태 변경의 근본 원인은 미확인으로 남긴다.

결과·로그 분석은 `docs/2026-10-21/guitar_learning_surface_training_json_v2/README.md`, 최종 모델은 같은 디렉토리의 `resume1200/final.pt`, 실제 GPU 자세를 재생한 전신영상은 `final_video/final_fullbody_60fps.mp4`에 보존한다. 최종 문서 snapshot과 전체 SHA256 manifest를 작성해 해당 phase를 봉인하며, 기존 세 실패 phase는 수정하지 않는다.
