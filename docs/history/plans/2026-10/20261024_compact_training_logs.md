# 학습 저장·로그 정리

사용자가 제안된 작업 수행과 이전 버전의 큰 로그 삭제를 승인했다.

- [x] 기본 체크포인트 간격250, 저장 시간 전체 집계
- [x] GPU 업데이트 통합 로그만 저장, 에피소드 상세 한 곳·고정 메타데이터 분리, 독자 호환
- [x] 손가락별 B gate·실제 각도, 손목 영역, 엄지 후면 접근 요약 추가
- [x] 이전 GPU 학습의 큰 원시 로그를 명시적 목록으로 삭제; 최신v17·checkpoint·영상·분석·계약은 보존
- [x] 관련 CPU 검사·저장/독자 통합검사·독립 변경 검수

보상·물리·제어·성공 정의는 바꾸지 않는다. 실행 중인 학습/평가가 없는지 확인 후 작업한다. 이전 원문은 guitar_learning/archive/20261024_before_compact_logging_v1 에 보관했다.
