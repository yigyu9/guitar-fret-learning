# 초기 자세 과거 자료를 한곳으로 이동

사용자가 initial_pose의 과거 자세·영상 등을 한 디렉토리로 모으도록 요청했다. 기존 정리의 원본 보존을 유지하면서 실제 디렉토리를 이동한다.

- [x] 과거 margin_only 자료·experiments_v1·history·하체 해제 실험 원본을 archive 아래에 모은다.
- [x] 현재 설정의 절대 경로에 필요한 lower_body_release_v1 호환 링크를 유지하고 영상 링크를 검증한다.
- [x] 현재/보관 안내와 종전 문서의 열람용 링크를 갱신한다. 수정 전 원문과 경로 대응표를 보존한다.
- [x] 이동 전후 파일의 inode·크기·수정시간, 링크 대상과 최신 자료 SHA를 검증하고 독립 검수를 받는다.

하체 해제 실험 트리에는 최신 v14 원자료도 있으므로 archive의 실험 원본이라는 이름으로 구분한다. 현재 후보의 정확한 설정과 자료는 current_v3에서 제공한다. 새로운 물리 실험·학습이나 원자료 삭제는 없다.

이동 결과: 328,116 파일/링크 항목의 inode·크기·mtime·mode·링크 원문 일치. 최신 원본 72개 SHA·사본 16개·영상 링크 15개 유지. 안내 링크 173개 정상. 옛 initail_pose 오타 링크를 열람용 사본에서 보정했으며 원문은 보존했다. 독립 검수 완료: 문제없음.
