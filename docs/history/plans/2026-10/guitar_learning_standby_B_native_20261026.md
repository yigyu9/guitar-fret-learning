# B 대기 자세의 실제 Isaac Gym 도달 검증

사용자 요청: 새 환경에서 왼손이 B 대기 자세로 이동하는 과정을 보여 주고, 자세의 적절성을 점검한다. 학습된 정책 평가와 구분하는 직접 관절 목표 시험이다.

산출물: `docs/2026-10-26/시각화/standby_B_native_v1/`. 실행·분석 도구는 그 아래 `support/`에 모은다. 기존 학습 코드·checkpoint·이전 산출물은 수정하지 않는다.

- [x] 단일 GPU PhysX 환경과 기존 035/v14 초기 상태·유한 제어를 재사용했다. 기타 자유·중력·충돌·PD·팔 유지·하체 안정화 제어를 보존했고, 초기 reset 이후 상태 setter를 사용하지 않았다.
- [x] 검지~소지 B 16축을 기존 누적 행동으로 요청했다. 엄지 목표 유지·다른 정책 행동 0이며, 하체 안정화 제어는 발목 목표를 조정한다. 초기 1초/이동 4초/유지 3초를 완료했다.
- [x] 실제 240Hz 물리 끝점 1920개와 native 카메라 3방향 각 240프레임을 기록했다. native 목표 추종과 기하 B 대역을 구분했다.
- [x] 영상·사진·RESULTS.md·측정 JSON을 저장했다. 3.741667초부터 모두 B 대역이나, 검지 벌림 오차 6.29도·중간 마디 약20.11N의 접촉 결과력이 남아 자연스러움·무간섭 성공으로 확대하지 않았다.
- [x] CPU 4검사·실제 GPU 573개 입력 SHA 유지·영상 240프레임/30fps/8초 전체 디코딩·독립 검수를 완료했다. 인코더 실패 정리와 하체 제어 문구를 보완했고 검수 Critical/Warning 없음이다.

판정: B 참고값에 관절 목표를 보냈다는 이유만으로 실제 도달 성공이라 하지 않는다. B 대역 진입도 충돌 없는 자연스러운 자세의 인증이 아니다. 접촉 결과력은 접촉 쌍·현 압력·메시 침투를 인증하지 않는다. 기타 이탈이나 관절 추종 실패도 결과에 그대로 남긴다.
