# V5 이전 압현 연구의 간단한 기록

현재 새 압현 구현은 [V5](../../guitar_learning/README.md)다. 아래는 문제·변경·결과를 이해하기 위한 이력이며, 구형 실행 명령은 현재 권장하지 않는다.

| 문제 | 시도한 변경 | 확인된 결과와 남은 점 |
| --- | --- | --- |
| 손가락 관절이 끝범위에 머물거나 끝마디에 역할이 몰림 | 대기 자세·실제 기하각 진단, 손가락 움직임 비용 제거, 직접 목표각 제어 | 제어·물리 반응을 따로 확인할 수 있게 됨. 자연스러운 압현 전체가 해결됐다는 뜻은 아님 |
| 전곡 학습에서 압현 경험이 매우 드묾 | 한 목표의 정렬·접근·압현을 분리하여 검증 | 정렬된 지원 조건의 단일 압현은 성공. 자유 팔·전곡·새 목표의 일반화와 구분 |
| 단단한 정렬 단계에서 멈춤·손가락 벌어짐 | 목표 노출과 부드러운 준비→하강 연결 | 일부 단일음과 전환이 개선됐으나 먼 목표의 발견에 많은 학습량 필요 |
| 목표 전환에서 다음 프렛·다른 줄 접촉 부족 | 역할별 탐색·학습률·긴 병렬 학습 비교 | 일부 전환은 장기 학습 뒤 나타났지만 정시 시작·전체 유지·해제는 별도 문제 |
| 상태·목표 의미와 음악 완료 기준이 불명확 | 인코더 분리, 손가락별8슬롯, 진행·대기 맥락과 유지·해제 평가 | V5의 상태464/473·목표26×8·Actor33 기준으로 정리 |

이전 압현 전용 실행기·비교 조건은 활성 구현에서 제거했다. 공용 물리·접촉·기록·타현·전신 기능과 필요한 입력은 유지한다. 원래 경로와 SHA는 [이번 정리](../maintenance/v5_project_cleanup_20261104/), 이전 코드 해설의 SHA·검증은 [역사 근거](../2026-11-02/코드해설/역사근거_20261031/)에서 확인한다. 모델 재현에는 그 모델이 봉인한 원문을 사용하며 입력·identity 검증을 우회하지 않는다.
