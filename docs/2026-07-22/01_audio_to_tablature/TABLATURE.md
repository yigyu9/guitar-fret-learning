# 오디오 → tablature

## 입력과 출력

대표 입력은 `04_Jazz2-187-F#_solo_mic.wav`다. 전사 단계는 오디오에서 다음 형태의 note event를 만든다.

```text
string,start,end,pitch
5,0.0000,0.4180,74
5,0.5341,0.6502,73
5,0.6734,0.7779,74
5,0.8359,0.9636,73
5,0.9636,1.1494,71
```

- `string`: 모델 관례의 기타 줄. 0은 low-E, 5는 high-e다.
- `start`, `end`: 음의 시작·종료 시각(초)
- `pitch`: MIDI 음높이

전체 결과는 [notes.csv](04_Jazz2-187-F%23_solo_mic.notes.csv)에 있다.

## 결과 요약

| 항목 | 값 |
|---|---:|
| 길이 | 20.21초 |
| note event | 68 |
| 사용 줄 | 3, 4, 5 |
| MIDI 범위 | 61~76 |
| 코드 트랙 | `N` 1구간 |

코드 추정은 이 사례에서 명시 코드 대신 `N`으로 남았다. 따라서 finger mapping은 note의 줄·음높이·시간 관계를 중심으로 처리했다.

## 현재 평가 범위

이 폴더의 CSV는 **오디오 전사 파이프라인 출력 예시**다. 반면 현재 fret 제어 환경의 대표 학습 bundle은 제어 규칙 자체를 먼저 검증하기 위해 GuitarSet JAMS 정답 tablature를 사용한다. 즉 현재 결과에는 다음 두 평가가 섞이지 않도록 구분되어 있다.

1. 오디오가 tablature로 얼마나 정확히 변환되는가
2. 주어진 tablature와 운지를 왼손 정책이 얼마나 정확히 수행하는가
