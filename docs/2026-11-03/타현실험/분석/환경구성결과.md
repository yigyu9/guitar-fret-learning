# 타현 환경 구성·실제 진단 결과

2026-11-03. 사용자 승인한 구조로 타현 환경·입력·설정·실행기·평가·GPU 유휴 가드를 구현했다. 실제 타현 준비·접근·통과·회복을 검사하는 환경 구성은 완료했다. **타현 성공 경로는 아직 확보하지 못했으며 PPO 학습은 실행하지 않았다.**

## 구현과 보존

학습 환경은 guitar_learning/gpu/right_strike_environment.py, 실행 코드는 guitar_learning/tool/experiments/right_strike/와 분리된 수정·비교 패키지에 있다. 입력은 data/diagnostic_inputs/right_strike_v1, 모든 모델·원시 로그·장면·촬영 원본은 runs/right_strike_v1에 저장한다. docs에는 결과·검토·대표 영상만 둔다.

기존 TensorSongEnvironment, SpecialistPolicy(right6), GPU 장면·제어, 공용 PPO를 재사용한다. 환경 추가 사항은 준비→한 번의 유효 타현→회복을 측정하는 별도 품질 원장이다. 기존 관측·보상·stage_success·PD·힘·관절 범위·물리·원래 타현 판정을 바꾸지 않았다. 손목·팔꿈치6축만 명령하고 오른손 그립은 기존 유한 제어로 유지한다. 왼손 clean은 오른손 단독 품질 성공의 조건이 아니다.

공통 초기 상태에서 실제0.5초 도착 후 몸체·관절·기타 상태를 읽고 FK를 재보정한다. 사전 선언한 타현 y=-0.35/-0.32/-0.29 세 위치에서 각각 pre/post/lift 후보를 유한 탐색한다. 원래 reset-reference±0.25rad와 native범위의 교집합을 유지하고 기하상 나머지99축은 실제 도착각을 보존한다. 실제 물리에서는 몸체가 기존 유한 제어 아래 계속 움직인다. 중간 상태 setter는 사용하지 않는다.

## CPU 검증

신규39개 검사가 통과했다. 입력 오염·목표 시계·방향·인덱스, 관절 범위 확대 거부, 실제 상태 FK 재현·후보의 비담당축 보존, 준비/타현/회복·부분reset·실패·원판정과의 정합성, GPU 점유 시 실행 거부, 저장 실패에도 장면 정리, 원 오른손 정책/공식PPO의 저장·엄격 load/다른 계약 거부, 실제 NumPy 계약 JSON왕복·비유한값 거부·교차 시간 비교를 검증했다. CPU 검사와 기하 후보는 실제 타현 성공의 근거가 아니다.

## 세 번의 실행 기록

| 실행 | 분류 | 실제 결과 |
|---|---|---|
| native_probe_v1 | 검사 오류 | 0.5초 도착 상태의 NumPy 배열 JSON 저장 오류. 타현 평가 이전 종료. 30제어/120물리 tick과15프레임 보존, 장면 정상 정리 |
| native_probe_io_v2 | 단일 타현 실패 | 저장 처리만 별도 버전으로 수정. 5초/300제어/1200물리 tick·150프레임 안전 완주. 목표 줄의 XY 통과는 있으나 속도 기준 미달 |
| native_probe_protocol_v3 | 단일 타현 실패 | 교차 구간만0.20→0.12초로 줄인 명시적 비교. 같은5초 안전 완주. 속도 증가했으나 여전히 기준 미달 |

첫 오류 뒤 v1 봉인 소스를 수정하지 않았다. IOv2는 별도 패키지에서 NumPy를 유한한 일반 JSON 값으로 바꾸어 원래 exclusive writer에 전달한다. protocol_v3도 별도 패키지에서 원래 경로의 교차 시간만 재매핑한다. 부모 source pin은 전부 그대로 계승하고 새 파일만 추가했다.

## 실제 통과와 유효 타현을 구분한 결과

240Hz 연속 원시 위치를 이용해 모든 교차를 재계산했고 독립 검토와 일치했다.

| 항목 | IOv2 | protocol_v3 |
|---|---:|---:|
| 교차 구간 | 2.90~3.10초 | 2.94~3.06초 |
| 목표3번 줄 통과 시각 | 3.094014초 | 3.091665초 |
| 통과 방향 | down | down |
| 실제 통과 속도 | 0.040645m/s | 0.044457m/s |
| 원래 속도 하한 | 0.05m/s | 0.05m/s |
| 교차 깊이 | 4.038mm | 3.990mm |
| 허용 깊이 | 1~15mm | 1~15mm |
| 타현 구간·시각 허용 | 통과 | 통과 |
| 준비 달성 시각 | 2.133333초 | 2.133333초 |
| 원시 목표 XY 교차 / 유효 타현 | 1 / 0 | 1 / 0 |
| 원래 오타현 / 중복 원장 | 0 / 0 | 0 / 0 |
| 전체 에피소드 안전 | 참 | 참 |

속도 하한을 낮추거나 기하 통과만 성공으로 처리하지 않았다. 회복=false는 유효 타현이 수락되지 않아 후속 회복 측정을 시작하지 않은 결과이며 회복 동작의 물리 불가능을 뜻하지 않는다. 개별 현의 압력·변형·진동·소리는 측정하지 않았다.

## 다음 작업과 학습 조건

현재 단순 시간 단축만으로 실제 속도 하한을 통과하지 못했다. 다음에는 기존 범위 안에서 교차 후 목표 위치·스트로크 길이를 바꿔 피크가 목표 줄을 지나는 순간의 실제 속도를 확보할 수 있는지 기하·추종을 함께 검사한다. 인접 줄의 오타현도 함께 확인한다. 제어 이득·힘·타현 기준 변경은 계획하지 않는다. 원래 기록과 소스는 보존하고 새 조건으로 분리해야 한다.

PPO 실행기는 성공한 실제 진단 report를 요구한다. 현재 두 정상 실행의 실패 report를 주면 거부한다. 따라서 학습 연결 코드는 준비됐지만 성공 진단을 확보한 후에 새 학습을 시작한다. 한 줄 한 방향의 타현을 확인한 뒤 반복·업/다운·줄 전환·양손 결합으로 확장한다.

현재 조건 재현 명령은 아래와 같다. 원래 출력 경로를 덮어쓰지 않는다. 이것은 **속도 미달 조건의 재현**이며 개선된 성공 조건을 실행하는 명령은 아니다. GPU 사용 중이면 대기한다.

```bash
PYTHONDONTWRITEBYTECODE=1 /home/ajou/miniconda3/envs/rl38/bin/python3.8 -B -m guitar_learning.tool.experiments.right_strike_protocol_v3 queue-probe --manifest /home/ajou/yigyu/3/data/diagnostic_inputs/right_strike_execution_protocol_v3.json --out /home/ajou/yigyu/3/runs/right_strike_v1/reproduce_protocol_v3 --queue-out /home/ajou/yigyu/3/runs/right_strike_v1/queue_reproduce_protocol_v3
```

실행 위치는 /home/ajou/yigyu/3이다. 현재 세 진단 큐는 모두 종료됐고 추가 학습·검사 프로세스는 예약하지 않았다.
