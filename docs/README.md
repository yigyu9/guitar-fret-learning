# 문서 입구

현재 필요한 문서는 [목적별 색인](DOCUMENT_INDEX.md)에서 찾는다. 새 압현 구현의 기준은 V5다.

| 구분 | 대표 위치 | 읽는 기준 |
| --- | --- | --- |
| 현재 실행 | [학습 안내](../guitar_learning/README.md) · [현재 상태](../CURRENT_STATUS.md) | V5 설정과 실제 진행 상태 |
| 코드 설명 | [V5 해설](2026-11-02/코드해설/README.md) | 상태·목표·정책·환경·PPO·로그 |
| 현재 입력 | [assets](../guitar_learning/assets/README.md) · [팀원 전달](TEAM_HANDOFF.md) | 실행 입력과 진단 자료 구분 |
| 실험 결과 | 날짜별 연구 폴더 | 당시 소스·계약·지원 조건·성공 기준으로 해석 |
| 이전 압현 과정 | [간단한 이력](history/press_before_v5.md) | 현행 명령과 구분한 과거 결과 |
| 계획 | [plans](plans/README.md) | 완료·진행·제안의 구분은 각 상태 확인 |
| 정리와 보존 근거 | [maintenance](maintenance/README.md) · [이번 정리](maintenance/v5_project_cleanup_20261104/) | 원래 경로·SHA·삭제·검증 |
| 논문 | [paper](../paper/README.md) | overview·model·method와 실험 근거 |

날짜별 기록과 봉인 runtime·입력·checkpoint는 보존한다. 과거 문서의 ‘현재’·‘기본’·실행 명령을 새 V5 지시로 해석하지 않는다. 삭제된 구형 구현은 활성 경로에 복원하거나 import하지 않는다.
