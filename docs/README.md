# 문서 안내

문서 탐색은 [`DOCUMENT_INDEX.md`](DOCUMENT_INDEX.md)에서 시작한다. 현재 연구 구조의 설계 정본은 [`master_plan`](../master_plan/README.md)이고, 실행·코드 계약은 [`tab2body/TRAINING.md`](../tab2body/TRAINING.md)와 [`tab2body/STRUCTURE.md`](../tab2body/STRUCTURE.md)에 있다.

현재 모듈 허브는 [`fret/README.md`](../fret/README.md), [`strike/README.md`](../strike/README.md), [`full/README.md`](../full/README.md)다. 과거 설계와 실험 문서는 각 모듈의 `archive/`와 `docs/archive/dated/`에 보존하고, 날짜별 `2026-*`에는 미팅 기록 `정리.txt`와 영상·렌더·JSON 산출물을 유지한다. 자세한 경로는 [`DOCUMENT_INDEX.md`](DOCUMENT_INDEX.md)를 따른다.

실험 변경 전에는 [`TRAINING_IMPROVEMENT_PROCESS.md`](TRAINING_IMPROVEMENT_PROCESS.md)와 해당 환경의 누적 이력을 먼저 읽는다.
