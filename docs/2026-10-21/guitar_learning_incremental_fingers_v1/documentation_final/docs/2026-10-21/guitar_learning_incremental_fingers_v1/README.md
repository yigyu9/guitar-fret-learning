# GPU 왼손 손가락 누적 제어 구현·검증

GPU 기본 왼손21축의 누적 제어 구현과 검증을 완료했다. 명령에 따른 실제 굽힘·펴짐은 확인했지만, 100회 학습의 압현 성과와 물리 안정성은 회귀했다. 짧은 검증 통과가 선행조건이었던 fresh2000회 장기 학습은 실행하지 않았다. 현행 구현을 학습 성능이 개선된 권장 모델로 해석하지 않는다.

## 구현 범위

- 엄지5축·검지~새끼 각4축: `target_next = clamp(target_previous + action × 4/60, native_lower, native_upper)`.
- 행동0은 직전 목표 유지, 반대 행동은 다음60Hz틱부터 목표 반전, 한계 밖 누적 없음. LH21 위치평활화는 우회한다. 실제 관절은 기존 PD와 접촉을 따라 추종한다.
- 초기035/v14는 종료 환경만 복원한다. H32 PPO 경계에서는 목표·곡 시계·원장을 이어간다.
- 기존 POSITION·K/D·힘·관절 한계, 자유 기타·중력ON·스트랩OFF, 보상·성공·안전·PPO/std는 유지한다. CPU·오른손·팔/손목도 기존 제어다.
- 관측512/행동39는 같지만 행동 의미가 달라 이전 위치제어 checkpoint의 strict resume를 거부한다. 새 계약끼리는 실제 GPU 재개를 확인했다.
- 실제/목표 관절 범위·행동 방향/변화·한계·추종오차를 에피소드별로 기록한다. 범위는 초기 자세와60Hz끝점 기준이며240Hz극값이 아니다.

## 고정 정책 초기/100회 평가

각 checkpoint를 별도 GPU1024환경에서 결정적 행동으로 평가했고 환경별 첫 에피소드만 집계했다. 모두1969tick까지 관측하며 먼저 물리 종료된 환경의 후속 reset 결과를 첫 곡에 합치지 않았다. 두 평가의 단계 진행도는0이다.

| 지표 | 초기0회 | 최종100회 |
|---|---:|---:|
| 전체 첫 곡 평균 달성 음 /67 | 4.2002 | 0.9775 |
| 안전 시간축 완료 /1024 | 1023 | 311 |
| 물리 종료 /1024 | 1 | 713 |
| 안전 완료곡 평균 달성 음 /67 | 4.2014 | 0.9678 |
| 양쪽 안전인 동일311환경 평균 달성 음 /67 | 4.4920 | 0.9678 |
| 67음 전체 성공 곡 | 0 | 0 |

최종 전체 첫 곡 달성은 검지0·중지879·약지122·새끼0이다. 중지/약지 사용은 발생했지만 기존 검지 성과와 전체 성과는 낮아졌다. [평가 분석](smoke_evaluation_analysis.json) · [환경별 종료 원인 분석](fixed100_diagnosis.md).

같은100회 예산의 이전 위치제어 **학습 중 수집**과도 비교했다. 첫1024곡 안전1008→855, 전체 안전곡 평균3.331→2.241음이다. 이는 계속 변하는 확률적 정책들의 수집 결과로, 위 고정 최종 정책 평가와 분모·행동 방식이 다르다. [같은 예산 비교](smoke_comparison.md). 이전2000회 모델의8.301음은 다른 학습 예산의 과거 결과이며 새100회 성과로 상속하지 않는다.

관측된 회귀만으로 GPU 좌표 오류나 특정 손가락의 인과성을 확정하지 않는다. 누적 제어에서는 작은 지속 행동도 장시간 목표 이동으로 쌓일 수 있지만, 엄지·다른 손가락·팔의 기여를 분리한 실측 근거는 아직 없다. 보상·탐색폭·PD를 몰래 바꾸어 이번 결과를 대체하지 않았다. 다음 개선에서는 안정적인 목표 유지/복귀를 학습하는지와 압현 보상·추종을 분리해 확인해야 한다.

## 실패 시도와 남은 한계

전체 CPU 첫 시도는 SIGFPE136으로 중단됐고 정확한 원인은 미확정이다. 첫 GDB 재실행은 의도된 IPC 오류 검사의 SIGPIPE를 디버거가 중단시켜141로 끝났다. SIGPIPE를 정상 전달한 전체 재실행은843개 통과했으며, 최초 SIGFPE의 근본 해결을 인증하지 않는다. 로그·별도 결과를 보존했다.

GPU probe 첫 시도는 PATH/Ninja 확인에서 물리0step으로 종료했다. 다음 시도는70tick 뒤 검증 도구의 NumPy 정수 JSON 저장 오류로 종료했다. 도구 원본과 원자료를 보존하고 스칼라 변환·roundtrip 검사 후84시험 전체를 새 디렉토리에서 다시 통과했다. 활성 제어 소스는 이 도구 수정에서 바꾸지 않았다.

단일 곡·준비 자세·seed7의 짧은 검증이다. 환경1024개는 독립 학습seed1024개가 아니며, 기하 접촉 후보의 달성은 실제 현 압력·진동·음향 성공이 아니다. 제어 기능은 확인됐으나 학습 성과 회귀가 남아 있어 장기 학습 준비 완료로 판정하지 않는다.
