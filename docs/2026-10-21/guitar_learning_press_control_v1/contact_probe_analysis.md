# 압현면·원시 접촉 기록 독립 감사

이번 N4 무행동 검사는 **준비 자세의 검지에서 실제 native 몸체 하중과 기존 음 후보가 함께 관측될 수 있음**을 확인했다. 네 환경 모두 32.8167초 안전 완주하고 같은 5음을 달성했다. 학습된 actor를 사용하거나 손가락을 목표로 이동시킨 시험이 아니므로, 다른 손가락의 학습 도달성·새 보상의 개선 효과를 입증하지 않는다.

원자료는 [contact_probe_n4/report.json](contact_probe_n4/report.json), 상세 독립 검산은 [contact_probe_analysis.json](contact_probe_analysis.json)에 있다. 원자료·동결 소스 변경이나 새 GPU/GL 실행 없이 CPU로만 분석했다.

## 무결성과 시계

- report의 정상 완료·cleanup 오류 없음·GPU PhysX/CUDA tensor pipeline·실제 close를 확인했다. native 시뮬레이터는 1개, 환경은 4개, 물리는 7,876회, 제어는 1,969회다. 원 report는 PPO/정책 추론 0회를 기록한다.
- 4개 NPZ의 SHA와 필드별 shape·유한성을 확인했다. 각 7,876표본, 총 **31,504표본**이며 각 행의 episode/global 물리 시계가 모두 1..7,876이다. 가짜 t0 표본이나 reset 이후 보충 구간은 없다.
- 입력 582개와 source manifest의 Python 435개 SHA가 일치했다. 읽은 report/metadata/input manifest/source manifest/NPZ의 SHA는 분석 JSON에 기록했다.
- LH21의 실제 기록 목표는 전체 표본에서 준비 reference와 정확히 같다. 행동은 동결된 도구의 zero39 명령이며 별도 action tensor는 캡처하지 않았다. 실제 q의 작은 물리 움직임은 남아 있으므로 목표 고정과 상태 덮어쓰기를 혼동하지 않는다.

## 누를 면과 현 중심선의 구분

각 표본에서 `selected_surface_G + surface_delta`로 목표를 재구성했다. 목표는 source neck 평면 **z=9.3mm** 위에 있으며 평면 잔차 최대는 **9.66×10⁻¹⁰m**였다. 같은 y에서 원래 논리 현을 다시 투영하면 현−목표 z 간격은 **2.999952..3.000090mm**다. 현 중심선 12.3mm와 새 접근 목표가 분리되어 있음을 실제 기록으로 확인했다.

이 평면은 pin된 원본 mesh의 convex hull에서 추출한 목표다. 실제 PhysX cooked 충돌면이나 특정 접촉점의 좌표를 직접 읽은 결과는 아니다. 기존 candidate의 현 ±3mm 기준은 바뀌지 않았다.

## 원시 하중과 시간 동시성

`surface_sample // 70`을 finger10 몸체로 매핑하고 `selected_body`와 대조했다. 모든 표본에서 지정 손가락의 2/3번 몸체가 올바르게 선택됐다. 그 몸체의 **원시 native 순힘 벡터 norm과 0.01N load flag**도 일치했다. 문턱 근처 float32 norm 차이에는 10⁻⁷N 허용오차를 사용했다.

후보가 참인데 지정 손가락 2/3 어느 몸체에도 하중이 없는 표본은 **0건**이다. 이번 기록에서는 후보가 참인데 최근접 선택 몸체의 하중 flag가 꺼진 표본도 0건이었다. 이는 이번 원자료의 결과이며, 일반적으로 후보는 어떤 유효 표면 샘플로도 성립할 수 있으므로 최근접 샘플의 몸체 하중과 항상 동치인 것은 아니다.

원시 힘이 양성이었던 finger10 몸체는 검지2·검지3뿐이다. 전체 표본의 최대 norm은 각각 **8.53175N·7.49612N**이고, 엄지·중지·약지·새끼의 기록된 2/3 몸체 8개는 벡터 성분 모두 0이었다. 기타 root 순힘은 지지 등 다른 접촉을 포함하므로 손가락 압현력으로 해석하지 않는다.

아래 시간은 음별 **press..end와 실제 240Hz 구간의 교집합**으로 가중했다. 서로 겹치는 음은 각각 세므로 벽시계 시간이 아니다. 검지에는 환경마다 25음·누적 창 19.2817초가 배정됐다. 중지18음, 약지12음, 새끼12음도 전체 67개 원장을 검산했다.

특히 **선택 표면점이 넥 평면 ±1mm 이내인 시간과, inward 압현 선분에서 1mm 이내인 시간은 네 환경·모든 press 창에서 0초**였다. 성공한 5음의 선택점은 넥 평면보다 약 **4.347..4.377mm 위**, 새 목표 선분에서는 약 **4.652..4.831mm 거리**에 있었다. 그래도 원래 허용 현 기하와 검지 몸체 하중은 동시에 참이었다. 최근접 선택 source 샘플은 실제 접촉 witness가 아니며, 다른 표면 위치·프렛 또는 cooked 형상에서 하중이 생길 수 있다. 이 기록에는 접촉쌍·접촉 위치가 없어 어느 경우인지는 확정할 수 없다. 새 목표에 1mm 이내여야만 기존 후보가 나오는 구조라고 가정하면 원자료와 어긋난다.

## 67음 성공 문턱 재검산

현재 후보와 직전 후보가 모두 참인 표본만 사용하여 onset..end의 `clean`, press..end의 `contact_time`을 독립 재구성했다. t0 후보는 기록되지 않았으나 실제 음 창은 t0 이후에 시작하므로 첫 후보 sentinel은 이 검산에 영향을 주지 않는다. 원장의 clean/contact/geometry/선택 body-load 시간과의 최대 차이는 **1.14×10⁻¹³초**였다.

각 67음에 대해 `required_clean=min(duration,max(0.05,0.4×duration))`과 `required_contact=min(0.05,end−press)`를 적용해 left/contact_done bool을 모두 재현했다. 성공은 네 환경 모두 아래 **동일한 검지·3번 현·6프렛 5음**이다. 첫 다섯 음이 성공한 것이 아니라 원장 index 41/52/62/63/64가 성공했다.

## 해석 한계

현재 기록은 준비 자세에서 검지 하중과 기존 성공 기준이 실제 동작함을 보여준다. 원시 접촉 순힘은 접촉 상대·국소 압력·현 진동·소리를 인증하지 않는다. 네 환경은 같은 준비 자세·무행동 조건의 한 실행이며 독립 학습 표본이 아니다. 나머지 손가락의 도달 불가능성이나 목표·감속 보상의 학습 개선 효과, N1024 안정성으로 확대할 수 없다. 새 보상의 유효성은 별도 학습100회 및 고정 정책 평가 결과로 판단해야 한다.
