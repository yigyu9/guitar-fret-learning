# 현재 v8 StabilityAdapter 학습: 체크포인트 영상 비교

2026-09-15 오후 진행 중인 `20260915_005904_adapter` 실행을 읽었다. 학습 설정은 1024환경,
총 50000회 예정, 정책 97축, 최근 8프레임 관측이다. 이 자료를 만들 때 학습은 11167회까지
계속 진행 중이었다. 학습 프로세스는 중단하지 않았다.

모든 경우 11.25초의 시간 제한으로 종료되었다. 손바닥 방향의 아래접근 신호는 나타나지만,
넥을 엄지와 손가락이 양쪽에서 감싸는 물리적 대향 접촉이 없다. 10000회에서는 엄지
간격이 줄었으나 손가락 간격이 여전히 크다. 11000회에서는 두 간격 모두 다시 커졌다.
영상의 HUD에 남은 “palm sensing not implemented”는 오래된 표시 문구다. 현재 환경과
JSON 로그에는 손바닥 방향·위치 측정값이 포함돼 있다.

## 전체 로그 판독

11100회까지 저장된 정기 평가 111개를 확인했다. 각 평가가 64 episode이므로 총 7104
episode에서 그립 획득 0회, 최종 성공 0회였다. 마지막 100회 학습 구간의 평균 위치
오차는 약 26.6cm, 회전 오차는 약 59.3°로, 앞선 구간보다 결정적으로 개선됐다고 보기
어렵다. 그립 최초 획득·접촉 운반 거리·그립 성공 지표는 계속 0이다.

마지막 100회에서는 PPO가 회차당 평균 1회만 업데이트했고 조기 중단 비율이 100%였다.
업데이트 전 KL 평균 약 0.077은 목표 0.03보다 높다. 이것은 학습 업데이트가 자주
제한된다는 신호이나, 그립 실패의 단독 원인으로 단정할 수 없다. 영상과 접촉 로그가
가리키는 직접 병목은 넥 가까이 오기와 실제 대향 그립 사이의 간극이다. 현재 상태에서
같은 설정으로 더 오래 학습해도 그립 획득이 자연히 나타날 것이라는 근거는 부족하다.
