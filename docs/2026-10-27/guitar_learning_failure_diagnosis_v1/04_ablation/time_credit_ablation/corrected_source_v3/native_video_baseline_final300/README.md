# 교정 기준선 최종300회 실제 영상

사전 지정한 env0의 첫 시도를 원래128환경 배치에서 촬영했다. 고정 기타·팔 안내·중지4축1음 학습의 정책 영상이다. 이번 촬영 시도는 달성·압현 유지100%·오압현0%·실패0이었다. 전체128평가는127개 달성이며 이 영상만으로 전체를 대표하지 않는다.

- `hand.mp4`: 손 확대
- `fullbody.mp4`: 전신

두 영상은1280×720·30fps·109프레임·3.633초다. native240Hz/제어60Hz를 유지하고 재학습하지 않았다. 입력677개 SHA, 정책 불변, 장면 종료, 두 인코더와 외부 실행 종료코드0을 확인했다. `qa/`에는 실제 프레임과 파일 검증이 있다. 화면은 바로 서 있으며 전신은 머리부터 발끝까지 포함한다. 영상과 달성 판정은 자연스러움·적정 압력·자유 기타 성공의 증명이 아니다.
