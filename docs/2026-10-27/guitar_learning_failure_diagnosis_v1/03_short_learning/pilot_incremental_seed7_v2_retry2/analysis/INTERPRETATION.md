# 증분 제어 seed7: 300회 뒤 학습 성능 후퇴

고정 기타·중지 한 음·고정 손목 teacher·나머지 손가락 B 조건의 첫 비교다. 전체 곡 또는 자유 기타 성과가 아니다. 각 평가는 사전 지정한 128환경의 첫 시도이며 실패를 분모에서 제외하지 않았다.

학습 300회/1,228,800전이는 1,446.37초에 완료됐다. 학습 완료 에피소드 5,632개, 물리·손목 종료는 각각 0개다. 입력 674개의 전후 일치와 모든 11개 단계의 정상 종료를 검증했다. 이전 retry1은 호스트 재부팅으로 중단됐으며 부분 원자료를 보존하고 retry2를 동일 조건 fresh로 시작했다.

저장된 정책 중 최고는 50회: 달성 85/128(66.41%), clean66.30%, wrong5.88%다. 100회20/128 뒤 150·200·250·300회는0/128이다. 150/200회의 wrong은100%/96.33%, 250/300회는0%로 바뀌었다. 초기policy/zero는0/128, random은6/128, scriptedreference는108/128이다. reference wrong14.13%이므로 완벽한 대조가 아니며 정책 학습 성과로 계산하지 않는다.

계획의 연속 두 평가 달성≥80%·clean≥70%·wrong≤10%·물리실패≤5% 기준은 통과하지 못했다. 최고 정책도 달성·clean 기준에 미달한다.
