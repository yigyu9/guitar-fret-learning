# 실제 손목 위치·방향 안내 사전검사

CPU56개 검사와 독립 검수14개를 통과한 뒤 실제 GPU에서 검사했다. 네 개 환경의 첫 시도만 사용했다.

| 제어 방식 | 정해진 손가락 자세 reference | 출력0 | 초기 무작위 | 물리·손목 실패 |
| --- | ---: | ---: | ---: | ---: |
| incremental | 3/4달성, clean75%, wrong25% | 0/4 | 0/4 | 0 |
| position | 3/4달성, clean75%, wrong25% | 0/4 | 0/4 | 0 |

reference는 봉인한 손가락4축을2초간 유한 이동한 대조이며 정책 성과가 아니다. 출력0/무작위에서는 팔 안내만으로 달성되지 않았다. 선택 손가락이 해결할 수 있는 실제 과제가 확인됐으므로 fresh300회 비교로 진행한다. reference에 남은1/4오압현과 손목 추종 오차는 한계로 유지한다. 고정 평가의80%채택 기준이나 자유 기타 전곡 성과를 통과한 것은 아니다.

최초 position 시도는 호스트 CPU14의 응답 지연으로 장면 생성 전에 중단 신호를 보냈다. 해당 빈 출력/로그는 보존하고 별도 cpu14_excluded 경로에서 재검사했다. 이후 본 비교에서는 양 조건 모두 CPU0~13만 사용한다.
