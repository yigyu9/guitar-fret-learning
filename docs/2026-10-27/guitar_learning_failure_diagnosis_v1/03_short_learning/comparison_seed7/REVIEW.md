# 독립 CPU 분석 검수

`/root/review_reward_objective`의 검수 결과: 수정이 필요한 문제 없음.

- CUDA를 숨긴 CPU 환경에서 두 분석 스크립트를 쓰기 없이 재실행했다. 두 `policy_drift.json`의 각각 7개 checkpoint, `comparison.json`, `RESULTS.md`가 정확히 재현됐다.
- 중지 `finger=2`의 std 인덱스 `[4:8]`, clamp와 exp, env0 행동 평균의 180/8/30개 표본을 확인했다. env0 관측과 전체 128시도의 관절 통계가 구분돼 있다.
- native 한계 ±1e−6rad 기준과 실제/명령 체류 분모, 각 평가의 고유 환경 128개 첫 시도, 각 학습의 완료 5,632개와 실패 0개를 확인했다.
- 달성 80%·clean 70%·wrong 10% 이하·물리 실패 5% 이하·연속 2회 기준을 독립 계산했으며 두 방식 모두 미통과였다.
- reference의 실제 반응 차이와 원인 미확정, 한 순간 RMS 교정이 장기 탐색·물리 동등성을 보장하지 않는다는 제한이 적절하다.
- 입력 SHA와 비교 그림의 축·범례를 확인했다. 검수 중 활성 소스·GPU·기존 파일은 변경하지 않았다.
