## 근거와 고정 조건

현행 `02_contact_reward/current_ring_precheck_v1`의 독립 실제검수 PASS를 선행 근거로 사용한다. row16/source54/event53(3번현)의 기준동작4/4, 선택 무행동·무작위 각0/4, 실패0이다. 기존 teacher/reference 수치, 현행557/Jv3 관측, 기타 고정, 유한 팔·손목 보조, 비선택 손가락 B, 선택 약지4축 incremental, 비엄지16축 effort 0.25Nm를 유지한다. 기타 고정/보조 조건은 진단 한정이며 전곡 성과가 아니다.

새 large 정책·seed7·128환경·H32·300회(1,228,800전이), 기존 initial_std=0.1711710544767014, save_every50을 사용한다. 과거 checkpoint 전이, 지도학습, 가치망 보정, 비용망 초기화 변경을 넣지 않는다. 원9보상·성공/오압현/실패 기준·PPO를 그대로 사용한다. 원 `short_finger_learning.runner.run`을 재사용하고 새 wrapper는 scoped 힘 상한/직접readback/실행입력 봉인만 담당한다. 생산 소스와 과거 봉인 코드는 수정하지 않는다.

과거 근거에 포함된 상위 진행계획은 갱신되는 문서이므로 새 실행 입력에서 현재 경로를 읽지 않는다. 갱신 전 원문은 `progress_review/document_snapshots/before_20261029_resume/guitar_learning_failure_diagnosis_20261027.md`에 보존했으며 원 SHA `705495b4a1a076bdb73881ea75d750d4a7a537d14c0c1d62531d8069a080d79f`와 동일하다. 새 검증에서는 이 문서 하나의 경로만 해당 snapshot으로 연결하고 나머지 모든 근거의 원 SHA 검증을 유지한다. 기존 봉인·검수·실행 소스는 수정하지 않는다.

- [ ] 최소 wrapper와 CPU 검사: 현행 teacher strict검사, 128환경 설정, 정확한16축 effort 변경, scoped 교체 복원, 실패 후 정리/원오류 보존, checkpoint 입력 봉인.
