# 제한 과제의 손·전신 영상

증분 제어의 평가 최고 저장본50회, 마지막300회와 위치 제어의 마지막300회를 실제 Isaac Gym GPU 장면에서 촬영했다. **기타 고정·유한 손목 안내·중지4축 정책·다른 손가락 B 안내**인 원인 분리 조건이며 자유 기타 전곡 성능이 아니다. 각 영상은 사전에 정한 env0의 첫 시도다. 성공 여부로 촬영 환경을 골라내지 않았다.

| 저장본 | 손 영상 | 전신 영상 | 촬영 시도의 달성 |
| --- | --- | --- | --- |
| 증분50회 | [손](incremental_best_50/hand.mp4) | [전신](incremental_best_50/fullbody.mp4) | 미달성 |
| 증분300회 | [손](incremental_final_300/hand.mp4) | [전신](incremental_final_300/fullbody.mp4) | 미달성 |
| 위치300회 | [손](position_final_300/hand.mp4) | [전신](position_final_300/fullbody.mp4) | 미달성 |

증분50회의 별도128환경 평가에서는85개가 달성했지만 env0는 미달성이었다. ‘최고’는 저장한 정책 평가의 달성 수 기준이며 영상 속 성공·자연스러움을 뜻하지 않는다. 영상 원장에서도 세 시도 모두 clean 비율0이다. 증분 마지막 모델의 중지 펼침과 위치 제어의 작은 움직임을 비교할 수 있다. 모델이 아닌 유한 안내로 움직이는 다른 관절을 정책이 학습했다고 해석하지 않는다.

각 영상은1280×720·30fps·109프레임·3.634초다. 원 물리는240Hz, 정책60Hz로218tick이며 프레임만30Hz로 기록했다. 세 실행의 장면 종료·입력/모델 불변·인코더 종료0·상위 실행 종료0을 확인했다. 각3초 프레임을 직접 확인했으며 영상은 정방향이고 전신 프레임에 머리와 발이 들어온다. 이는 자연스러움이나 압현 성공의 인증은 아니다.

각 하위 디렉토리의 `report.json`, `capture_metadata.json`, `episode_env0000.json`, `poses_env0000.npz`에 조건과 실제 관절·시계·원장을 보존했다. [CPU 검증 결과](verification.json)는6영상과 원자료 SHA·입력677개 재검사·미디어 정보를 기록한다. 검증기는 결과 루트의 `support/verify_native_videos.py`이며 활성 학습 코드는 바꾸지 않는다.
