# 다음 악구 전환 진단: 원곡 중지 3음

현재 실행의 원래 시간척도 기준선·독립 비교·하중 진단을 마치고, 활성 소스를 새 버전으로 보관한 뒤 구현한다. 현재는 실제 원곡을 읽어 후보·경계와 최소 변경 범위를 정한 단계이며 GPU 도달이나 학습 성공을 주장하지 않는다.

## 목표와 선정

원곡 SongTask67음과 음별 press/onset/end를 유지하고, 중지의 연속 세 이벤트53→56→59를 선택한다. 물리 위치는3현7프렛→2현8프렛→동일 위치 재타현이다. 서로 다른 이벤트3개와 위치2개를 구분한다. 원곡의 중간 중지 이벤트를 삭제하지 않았지만 다른 손가락 이벤트를 투영에서 제외하므로 전곡 연속 악구와 같은 과제가 아니다.

첫 onset만local3초에 맞추는 공통 offset을 쓴다.283control=4.7167초이며 마지막 음 뒤 원래0.5초 tail을 유지해도 다음 중지 press 전에 종료한다.56과59는 동일 press를 공유한다. 두 audible 사이의0.3831초를 강제 해제/B복귀 구간으로 바꾸지 않는다. 같은 프렛 재타현은 왼손 유지가 정상일 수 있다. 다른 현 전환에서 고정된 한 자세가 계속 보상받는지 확인한다.
