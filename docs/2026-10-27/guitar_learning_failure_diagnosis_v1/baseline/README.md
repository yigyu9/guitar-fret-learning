# 기존 학습의 제어 기준 추적

2026-10-27 단계0 결과. 기존 소스·체크포인트·학습 원자료는 수정하지 않았다. 구버전 GPU 추적은 11:24:39 KST에 모두 끝났으며 이후 분석은 저장된 자료만 사용한다.

## 재사용과 추가 수집

- 기존 초기/최종 128환경 평가, 보상 분석, 최종 native 영상을 참조한다. 원본 경로·SHA는 `reference_manifest.json`에 있다.
- 기존 최종 영상 NPZ에는 action/q/qd/target/body/physics clock가 모두 있다. 초기 상세 NPZ와 정책 latent 평균·표준편차·본인 대기 gate가 없어 같은 소규모 조건에서 초기/최종을 각각 한 번 추적했다.
- 새 평가: GPU8환경·전곡67음·deterministic 정책·환경별 첫 에피소드. 상세 저장은 실행 전 고정한 env0~3만 사용하고 실패를 분모에서 제외하지 않는다.
- 새 초기 평가는 8환경 모두5음·정상, 새 최종 평가는 8환경 모두1음·정상이다. 기존128환경 평가(1.586→1.195음)와 다른 별도 장면이므로 대표 성능을 새8환경 숫자로 대체하지 않는다.

## 정책 출력과 관절 추종

새 초기 추적 env0~3의 모든1969tick×39축에서 정책 latent 평균·latent·tanh 행동·실제 제출 행동이 정확히0이다. 그러므로 LH21/활성33축도0이다. 유한 지지 제어는 계속 작동하고 실제 관절 속도도0이 아니므로 인체 전부가 고정됐다는 뜻이 아니다. 이번 초기 모델은 정책 출력0으로 준비 자세를 유지하는 대조군이며, 학습 전 일부 음 판정을 만족할 수 있음을 직접 확인했다.

아래는 최종 env0의 완결60Hz 끝점 통계다. 한계는 native 상·하한에서1e-6rad 이내인 **목표각**이며 실제각 한계와 구분한다. 평균은 해당 손가락 관절×시점의 평균이다.

일부 축은 연속으로 거의 전곡 동안 한계에 머물렀다: `LH:ring3`32.82초, `LH:pinky1_x`32.80초, `LH:ring1_z`32.57초, `LH:index1_z`32.03초. 처음 준비 자세 자체가 일부 한계에 가까운 경우도 있어 근접2° 점유와 정확한 한계 점유를 따로 기록했다.

LH21의 `clip(previous_target + action×4/60, native_lower, native_upper)` 재구성은 초기/최종 모든 저장 환경에서 관측 목표각과 최대5.96e-8rad 오차로 일치한다. 실제 native 드라이브나 접촉의 인과 성능을 이것만으로 증명하지는 않는다. 약지/소지에서는 목표−실제 오차도 남으므로 목표 누적 편향과 접촉/구동 추종 문제를 분리해야 한다.

## 본인 대기 구간

최종 env0의 본인idle 구간에서 B gate 평균은 검지0.986·중지0.984·약지0.986·소지0.993이다. gate가 열려도 목표각 한계 점유는68.6/72.8/78.7/79.5%이며 바깥 방향 명령이 이어진다. 이 사례에서 대기 복귀가 안 되는 이유를 gate 폐쇄로 설명할 수 없다. B 보상을 강화해야 한다는 인과 결론도 아직 아니다.

현행 contact/near 필드는 비활성 진단값으로 둘 다false이고 실제 B gate와 score idle weight는 정확히 일치했다. 그래프에서 실제 gate와 raw 진단을 구분했다. 초기 준비·audible·본인idle·준비/전환을 분리한 수치는 `summary.json`의 `phase_metrics`에 있다. 분류는 완결 제어 끝점 기준이다.

## 산출물과 한계

- `source_capture_complete.json`: 구버전 추적 완료 시각, 소스/체크포인트 SHA, 장면 종료 검사.
- `trace_initial/`, `trace_final/`: strict 평가 원장·보고서, env0~3 NPZ·t0 상태·추적 메타데이터.
- `initial_zero_policy_check.json`: 초기39축 실제 출력0 검산.
- `summary.json`: 관절별 연속 한계 체류, 동일 부호 명령 적분, 목표−실제 오차, 손가락/phase 지표.
- `plots/initial_final_joint_summary.png`: 초기/최종 관절 비교.
- `plots/{initial,final}_env0_control.png`: 행동→목표각→실제각.
- `plots/{initial,final}_env0_standby_gates.png`: 본인 대기 gate.

이 추적은 deterministic 평균 실행이다. latent가 mean과 일치하고 실제 행동이 tanh(mean)과 일치하는지 검산했지만, 과거 stochastic 훈련 표본 행동을 복원한 자료는 아니다. 60Hz 끝점에서 저장한 각도/속도를240Hz 극값으로 해석하지 않는다. 몸체 순힘·기하 후보는 실제 현 압력·음향 인증이 아니다. 기존 최종 native 영상은 아래를 재사용한다.
