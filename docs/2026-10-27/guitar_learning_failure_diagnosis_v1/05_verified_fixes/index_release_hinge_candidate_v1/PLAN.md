# 실제 첫마디 자세를 기준으로 한 유한 해제 후보

원FK 검산에서 MCP2의 노출되지 않은 실제 회전성분 변화를 발견했다. 노출된2축만으로 검지 전체 자세를 예측하지 않는다. 다음은 원자료를 변경하지 않는 CPU 후보 설계이며 실제 도달·성공 검증은 아니다.

- 입력은 원 reference/noisy_reference env0의 phase3(3.2703초 초과~3.712초)의 native 실제 첫마디 pose, 실제q105, 기타pose, 원안쪽128표본이다. 두 조건을 모두 포함하며 다른 환경과 미저장240Hz를 추정하지 않는다.
- source full_fk의 downstream index1→index2→index3 hinge만 재사용한다. 매행 실제 index1 pose로 강체 정합한 뒤 actual PIP/DIP에서 distal/128점이 native와 0.01mm·1e-4rad 이내 맞는지 확인한다. 이 정합은 MCP2를 q로 복원하거나 실제 상태를 수정하는 작업이 아니다.
- **사전지정 후보는 PIP40°/DIP10° 한 개**다. 원N(약51.90°/20.75°)보다 유한하게 펴며 MCP2 목표·엄지·나머지손가락·팔목표·보상/판정/분포를 바꾸지 않는 후속 실험을 염두에 둔다. 이번CPU에서는 실제 도달을 가정한 정적 후보만 계산한다. 다른각도 grid/최적화/계수검색은 하지 않는다.
- 한계 내 여부와 원4rad/s에서 N→후보의 목표변화 최소시간을 보고한다. 모든 source-valid128점의 press-plane signedheight가5mm 이상인지 검사한다. 5mm는 새 압현/음악 성공기준이 아니라 기존 상단3mm 밖으로2mm 여유를 요청하는 **후보 설계 기준**이다. 음수높이를 양의 여유로 합치지 않는다.
- 고정한 실제index1·기타pose에서의 조건부 예측이며, 목표 변경 뒤의 충돌/부하/MCP2변화/추종 lag를 예측하지 않는다. 통과해도 native검증 전에 실제 해제 개선이라 하지 않는다. 미통과면 자동 다른각도를 검색하지 않고 결과를 기록한다.

산출물: 입력SHA before/after, CPU자체검사, 조건별기하요약·그림·한글결과. root만 추후 실제GPU실행을 수행한다. 현재PPO/fit/모델생성/새native실행0.
