# 후퇴 로그의 CPU 분리 감사

root의 완료 통보와 기본 실제 분석 독립 PASS 이후 수행한다. 소유는 이 새 폴더뿐이다. 원자료·source·기존 분석·봉인·학습 설정 변경 및 GPU 실행은 없다.

- [x] 기본 실제 review와 입력 SHA를 검증하고 전체 300 metrics/5504 종료 원장을 읽는다. 실제 실패비용과 cost GAE/critic 추정값을 구분한다.
- [x] 고정 평가 50/100/150/200의 전체 128 분모와 env0 60Hz 상세를 분리한다. 선택4의 원 누적 codec 재귀, 상한 최초 도달, 상한에서 양의 명령, 음중 target−actual을 확인한다.
- [x] 현재 원판정 helper로 env0 candidate/wrong 및 any-sample 원인과 현/프렛을 CPU 재구성한다. nearest scalar는 판정 witness로 간주하지 않는다.
- [x] 표·작은 그림·한국어 해석을 저장한다.
- [ ] 기존 reviewer의 독립 검수는 별도 review.json/REVIEW.md에 기록한다(요청 후 이 파일 동결).

추정 비용의 영향과 bounded target memory/추종차이는 독립 증거로 보고한다. 로그 집계만으로 비용 단일원인, 접촉쌍, 압력 또는 다른127의 상세 원인을 확정하지 않는다. 향후 위치/유한 목표오차 완화 대조는 계약과 strict 저장/평가 일치를 새로 검증해야 하는 후보일 뿐 이번에 구현하지 않는다.
