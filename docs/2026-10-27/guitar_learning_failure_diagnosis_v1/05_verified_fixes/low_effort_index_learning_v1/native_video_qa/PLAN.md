# 검지 학습 모델 실제 영상 확인

기존 학습·평가·영상 원자료와 source는 수정하지 않는다. root는 이 새 QA 폴더만 소유한다.

1. 실제 두 render 종료0, 동일128환경/선정150·최종300/모델·입력 불변·장면닫기·원 native report를 확인한다.
2. 네 MP4의 ffprobe와 전체 디코딩, 60Hz 실제 trace의 유한값/시계·고정평가 env0와 수치차이를 기록한다. 새로운 영상 장면이 과거 평가와 같다고 가정하지 않는다.
3. 각 영상의 초기/중간/음중/마지막 프레임을 추출하고 contact sheet로 방향과 구도를 확인한다. env0 첫 시도 영상과 전체128 결과를 구분한다.
4. root가 이미지를 직접 보고 별도 reviewer가 원 MP4/trace/모델·SHA 및 보고서를 확인한다. 실제 완료 뒤 이 폴더도 동결한다.
