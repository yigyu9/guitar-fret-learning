# 목표각 지도학습의 오차 단위를 실제 각도로 맞추는 비교

2026-10-28. 앞선 목표각1000회 NN은 음악126/128로 개선됐지만 A해제73/128로 미달했다. 종료기록 NameError와 별도 재사용 감사·평가는 원문대로 보존한다. 이번도 기본 학습이나9개 RL 보상을 바꾸는 작업이 아니다.

## 근거·변경 하나

기존 손실은 정규화 목표4열의 동일 MSE다. 같은 정규화 오차라도 원035 기준 affine 변환의 각도 기울기는 관절/부호별로 다르다. Ref 부근 양의 MCPz는5.132도/raw지만 DIP는69.249도/raw다. 같은 raw오차가 같은 실제 각도 오차를 의미하지 않는다.

기록한4환경의 해제창24행에서 DIP guard는열기요청을막지않았다. 마지막 해제창의 목표DIP는검증된N보다약2.2도더굽혀졌고, env0의PIP목표도약1.7도더굽혀졌다. 이것이 단독 원인이라는 뜻은 아니다. **예측 정규화 목표를 기존decode로 각도로 바꾼 뒤, 예정desired와의 rad² MSE를 사용한다.** 학습량/시간표/관측/물리/제어를 동시에 바꾸지 않는다.

원 reference heldout의 해제 PIP/DIP raw RMS는.001630/.001147이지만 새 NN 자체 상태에서는.025309/.018066으로 커졌다. 손실 단위 보정이 상태 분포/피드백 문제까지 해결한다고 확정하지 않는다. 이번에는 출력 단위별 물리각 오차의 불균형만 통제하며, 음악/해제 성과가 하락하면 채택하지 않고 예산을 자동 확장하지 않는다.
