# 성공 참고 동작의 목표각 잡음 민감도

2026-10-28. 원 목표각 NN의 평균은 전체126/128·A해제73/128, 후보std 확률평가는 전체10/128이었다. DIP 보호만 꺼도 확률 전체10/128로 같았다. 보호 단독 제거는 채택하지 않는다. 신경망의 근사 오차와 접촉·독립 목표각 잡음의 결합을 더 구분하기 위해 **성공한 원 reference에 같은 후보 분포의 잡음만 넣는 한 조건**을 추가한다. NN만의 단독 인과를 식별하는 실험으로 표현하지 않는다.

## 순서와 검증

1. CPU 준비와 독립 검수. 원 reference/goal codec/128 첫시도 evaluator를 재사용하고, 원 reference_action이 제공하는 선택4축 raw goal에만 `tanh(atanh(raw_reference) + sigma * epsilon)`을 적용한다. 현재 후보sigma4와 float32/원 Gaussian 방식·난수 소비 범위를 실제 정책 코드와 맞추고, pool 준비 뒤 평가 직전 seed7을 설정한다. 사전 mean은 원 encode 결과이며 매 호출 유한성과 `abs(raw)<1`을 검사한다. round-trip 오차를 숨기거나 clamp로 label을 바꾸지 않는다. sigma0 fixture는 허용오차 내 원목표 재현, noise로 바꾸는 선택4 외35행동열 불변과 원DIP filter 자체의 다른104목표열 보존을 구분한다. noise4 개입전체가104목표열을 고정한다고 주장하지 않으며 K1·range/rate/guard·실제 before/after callback 보존을 확인한다.
2. root가 검수된 정확한 한 명령으로 새128환경 native 평가를 실행한다. 참고 기준은 원 reference의 음별/전체/해제128/128 결과를 출처별로 재사용하고 다시 실행하지 않는다. 신경망·모델 load·fit·PPO는0이다. 보상/성공·해제/곡·기타 고정·유한 손목·다른손가락B·엄지035·비엄지0.25Nm·105/90쌍·종료는 그대로다. 원 gate에서 증거용으로 pin하는 checkpoint와 실제 모델 로드를 구분한다.
3. 실제 분석·독립 검수. 원128분모/384음·음악/해제90%·AND·A달성×해제·9항·실패를 보고한다. 실제 호출·선택4 표준정규 표본·RNG 전진과 원 raw reference/잡음 raw goal/변환 요청/guard 결과를 분리한다. 통계를 위한 first mask로 표본을 압축하거나 draw 수를 줄이지 않는다. 원 evaluator의 종료를 바꾸지 않고 정상354호출 여부를 실제 감사한다. 사전 지정 env0 및 기존 bounded4 관측만 상세 저장한다. 원 모형/RNG 동결 감사의 reference 분기 진리값을 새 탐색 RNG 검증으로 사용하지 않는다.

단일 seed의 고정기타 참고 잡음 비교다. 실패해도 보상이나 물리 엔진 오류로 단정하지 않고, 성공해도 신경망 근사 하나를 단독 원인으로 확정하지 않는다. 새 K/공간·시간 상관/관절범위/std 후보 검색/예산 확장은 섞지 않는다. 원 자료·준비·실패 기록은 보존하며 새 source와 산출물은 이 디렉토리에만 둔다. 현재 진행문서와 후속 analysis는 실행 입력에 pin하지 않는다.
