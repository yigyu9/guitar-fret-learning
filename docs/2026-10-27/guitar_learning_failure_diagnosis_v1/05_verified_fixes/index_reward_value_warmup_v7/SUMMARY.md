# V7 비교 결과와 남은 문제

외장 저장소 원본3개를 다시 읽어 기존 SHA와 일치함을 확인했다. 가치망만 보정하는 단일 비교를 실제 GPU에서 끝냈다. 배우 지도1000회·가치망 보정1000회·PPO300회는 서로 다른 단계이며, PPO의 전이 예산은 V6와 같은1,228,800이다.

## 결론

초기 reward 가치망 오차를 줄이면 이 단일seed 조건의 마지막 확률수행은 개선됐지만, 평균행동 정책의 퇴행과 오압현을 해결하지 못했다. **생산 기본 설정에는 채택하지 않는다.** 가치망 초기화만으로 문제가 해결되거나 보상/물리환경 중 어느 하나가 유일한 원인이라고 결론내리지 않는다.

| 비교 | 세음 모두달성 /128 | 달성+첫음해제 /128 |
| --- | ---: | ---: |
| 공통 초기 평균행동 | 98 | 22 |
| 공통 초기 확률행동 | 14 | 12 |
| V6 마지막 평균행동 | 0 | 0 |
| V6 마지막 확률행동 | 0 | 0 |
| V7 마지막 평균행동 | 13 | 5 |
| V7 마지막 확률행동 | 58 | 30 |

V7의6개 중간/마지막 평균행동 평가는 세음달성2·0·6·1·4·13이며 안정적 개선이 아니다. 마지막 평균행동의 뒤두음 오압현 판정 시간비율은각약0.74219지만 확률행동은약0.0234다. 따라서 평균행동과 작은 확률적 행동 변화 사이의 접촉 판정 차이를 다음에 분리해야 한다. 이는 실제 줄 압력이나 음향을 직접 측정한 결과는 아니다.

가치망 보정의 별도32환경 MSE는0.317608→0.026550으로 줄었다. 단, 마지막tail의 오차는 악화했다. 배우·탐색·costhead·4종 난수·빈PPO optimizer 경계를 유지했고 초기128평가의 전체 원장·9보상과 env0 실제 관절·목표·후보·NNgoal은 V6와 같았다.

PPO중 완료3456episode의 달성1132회/동시달성+해제685회는 계속 바뀐 정책으로 수집한 수치이며 고정평가 성공률로 사용하지 않는다. 완료episode 전이1,223,424와 열린episode5376전이를 합쳐 전체1,228,800을 검산했다. 물리/손목실패 비용과 cost advantage/value/target/loss는 전구간0, KL재시도는첫회2번·실제actor LR1.875e-6으로 V6와 같다.

## 다음 분기

추가 장시간 학습보다 마지막 모델을 고정한 진단을 우선한다. 물리 초기화 조건을 동일하게 두고 정책 잡음만 달리한 반복 수행으로 평균/확률 차이의 재현성을 검사하고, 뒤두음 오압현의 현재v2출처(other_higher/own_wrong_fret/own_wrong_string)·발생구간을 실제 로그로 확인한다. V6의 기울기 충돌을 V7에도 그대로 가정하지 않는다. 그 결과를 바탕으로 보상·목표 전환 중 개입 하나를 정해 비교한다. 이 다음 비교는 아직 구현·실행하지 않았다.

범위는 고정기타·검지4축·원3음view354tick·seed7이다. 다른 손가락/seed·자유기타/J33·원곡67음·실제negative 접촉/엄지부하 검증은 남아있다. 생산 학습 코드281개와 기존 봉인 소스·모델·자료는 수정하지 않았다.
