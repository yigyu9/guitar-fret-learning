# 같은 목표각의 낮은 구동 상한 재확인

원본으로 보존한 유한 grid·수집기·설정·관절 범위·음 시계·손목 v3 제어·압현 판정을 재사용한다. 장면을 만드는 동안 검지~소지16축의 effort 상한만20→0.25Nm인 별도 사본을 전달한다. 원래 입력 검증을 먼저 수행하고 제어기 생성 전에 원래 로더를 복원한다. 실제135/180환경의105축 속성과90충돌쌍을 확인한다. 기존4환경 전용 검증을 우회하거나 환경 수를 속이지 않는다.

사전 선언한450행 중 범위 내315목표를 각1회 실행한다. 범위 밖 사유·실패 포함 분모·상세 기록 행·최소 각도 변경 순위를 유지한다. 새 native 속성 기록과 진단 계약에 변경된 상한을 명시한다. 같은 요청 각도라도 실제 관절각과 손목 추종이 달라질 수 있다. 고정 명령의 도달 가능성 진단이며 정책 학습·실제 압력 인증·기본 설정 채택의 근거와 구분한다.

CPU 검사는 이 디렉토리에서 `CUDA_VISIBLE_DEVICES='' /home/ajou/miniconda3/envs/rl38/bin/python -B probe.py --self-test`로 실행한다. 기존 cap 실제 결과의 독립 검수 뒤 `--prepare`로 입력을 봉인한다. 준비 검수 뒤 root만 `--execute --finger index`, `--execute --finger middle`을 직렬 실행한다. 기존 출력·상위 심볼릭 링크를 거부한다. NN·체크포인트를 만들지 않고 기존 소스·봉인·원자료를 보존한다.

통과 후보가 있으면 원래 순위로 선정한 목표 하나만 새4환경에서 재현한 뒤 다음 학습을 판단한다. 없으면 이 grid를 확대하지 않고 손목 도달 범위·팔 관절 한계·손가락 간 간섭을 분리한다. 이 고정 장면 진단으로 자유 기타·전곡 성공을 주장하지 않는다.
