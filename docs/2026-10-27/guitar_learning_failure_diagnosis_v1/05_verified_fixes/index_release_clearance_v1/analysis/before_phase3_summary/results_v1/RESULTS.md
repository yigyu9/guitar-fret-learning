거리·signedheight·cos·셀/방향·말단부하·candidate는 분리했다. 원native released latch는 연속무접촉 인증이 아니다. 표본법선이 불리하거나 height가 음수인 상태를 이격으로 합치지 않는다. nearest 표본과 any-sample witness가 다를 수 있다.

valid_snapshot은 producer의 네 distal13 상태 유한성 검사를 재사용한다. 저장된 index3/guitar7의 유한성과 reset 제외를 확인했으며 미저장 다른 distal13 상태의 판정을 역복원하지 않았다. 몸체 순힘은 접촉쌍·현 압력이 아니며, 전체피부·다른마디·다른124환경의 기하·240Hz 연속성은 미확인이다. 실패 끝점은 보존하고 사건 집계에서는 실패 시점부터 제외했다.
