**엄지 안내가 실제 넥 뒷면보다 약5mm 뒤에 잡힌 오류를 수정했다.** 사용되지 않는 OBJ 정점을 제외하고 연주용 neck1의 실제 face 참조 정점만 사용한다. 보상 예산·거리/방향/하중 문턱·관절 범위·PD·물리·코덱은 유지했다. 이 변경은 엄지를 강제로 붙이는 제어가 아니다.

## 구현과 검증

- 공유 엄지 지원 계약v3, episode 진단 계약v6. 이전517Python/README/AGENTS519파일과 SHA는 새 archive에 보존했다.
- 수정 전48검사·수정 후 관련101검사가 통과했다. 현재128패드 점/normal/valid/후면 꼭짓점/plane은 실제 native A/B에서 통과했던 B의 사전 봉인 배열과 exact동일하다.
- 이전 checkpoint 입력을 기존 strict 검사에 넣으면 변경4Python 경로를 명시하며 거부한다. 이전 성과나 optimizer를 자동 이식하지 않는다.
- 별도 change-reviewer의 생산 소스·wrapper·실제 native 산출물 검수를 통과했다. 원자료는 수정하지 않았다.
