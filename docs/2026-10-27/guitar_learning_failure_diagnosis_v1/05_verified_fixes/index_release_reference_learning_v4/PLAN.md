# 수정 참고 동작 기반 새557 정책의 짧은 학습

V2 참고 동작의 세 음124/128·잡음34/128, V3 한 축 잡음 제외5/128 및 접촉 하중 감사에 근거한다. 축 제거/추가 std 검색·접촉 문턱 완화는 채택하지 않는다. 원 목표는 자유 기타·다른 손가락·원곡67음까지이며 이 고정기타/검지3음은 학습 실패를 분리하는 중간 단계다.

1. capture는 검수된 V2 mean을 그대로 실행해 env0..3의 제어 전557관측/원목표1416행만 수집한다. 원128회 원장과 필수 관절/접촉 관측 동일성을 검증한다. native 목표/상태/보상/PD/.25Nm/원가동범위/시간표는 바꾸지 않는다. 수집과 NN 성과를 구분한다.
2. 현행 FingerSkillPolicy/DecisionCollector/DecisionPPOTrainer를 재사용한다. 진단 정책은 선택17:21의 정규화 절대 목표·4성분 likelihood를 새 계약에 명시한다. production J33·R/F·과거 checkpoint는 변경하지 않는다. 선택4축의 평가 입력은 NN만 만들며 V2 참고 함수 호출을 거부한다. 다른 손가락·엄지·팔/손목의 기존 지원은 그대로 명시한다.
3. seed7·large·정규화 목표 MSE·1000회×192행의 사전 예산이다. env0..2 학습/env3 진단 내 확인, 기존6시간 구간 균형을 따른다. 과거 후퇴한 angle-rad² 손실은 섞지 않는다. 새 checkpoint strict-load/핀/정책·optimizer 무변경 검증을 유지한다.
4. fit 직후 고정/확률128평가 뒤 shortPPO300/H32/128환경(1,228,800전이)을 수행한다. 탐색 또는 fit90%성공을 새로운 PPO 선행조건으로 추가하지 않는다.50간격 평가용checkpoint·보상9항·streak·해제/오압현·실패를 기록한다. 학습에서354행 first-control 기록만 끄며 실제 guard와 제어 검사는 유지한다.
5. 단계별 CPU검사·독립검수·입력봉인 뒤 순차 실행한다. 실패/원자료를 보존하고 실패를 분모에서 빼지 않는다. 학습 결과와 실제 전신/손 영상·문서로 판단하며 보상/전곡 전환 채택은 실제 증거에 따른다.

완료 체크는 봉인된 이 파일을 고치지 않고 상위 계획/status와 단계별 검증에 기록한다. capture는 별도 봉인해 이후 학습 파일 편집이 수집 입력 핀을 바꾸지 않도록 한다.
