# V6 비용 초기값 비교 분석

승인된 V6 계획의 최종 분석만 담당한다. V5 봉인 helper의 순수 검증·요약 함수를 재사용하고 원자료와 학습 소스는 수정하지 않는다. Python3.8, CUDA_VISIBLE_DEVICES=''에서 checkpoint 텐서 읽기만 허용한다.

- [x] 최소 비교 프로그램과 CPU 음성 fixture: 모드 누락, 원장 누락, env 중복, 0 비용 신호 위반을 거부한다.
- [ ] 양쪽 PPO300 완료 보고 및 각 9평가가 모두 준비된 뒤만 최종 실행한다.
- [ ] 원128/384, 실패 포함, 9보상, 정산 원장, schema·핀·동결, 초기69+2 차이와 실제 신호·최종 head를 검사한다.
- [ ] 성과·9보상·cost advantage/value/target와 KL/LR, A env0 관측을 보고하고 3개 그림을 시각 검증한다.
- [ ] 소스와 산출물을 봉인한 뒤 독립 검수에 전달한다. 봉인된 소스는 이후 확장하지 않는다.

V6의 최초 update부터 차이가 가능하다. 학습률/KL 차이는 개입 이후 경로이며 수동 설정 차이로 간주하지 않는다. 공유 value encoder 때문에 reward critic 표현도 바뀔 수 있어 actor만의 격리 실험으로 해석하지 않는다. 실제 비용이 양수가 되면 신호가 계속 0이라고 가정하지 않는다. 다른 seed·손가락·자유 기타·전곡으로 확대하지 않는다.
