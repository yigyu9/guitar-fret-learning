# 직접 시각 확인

CPU QA 뒤 `view_image`로 손/전신 비교 contactsheet 두 장(각각 기존4+신규4칸, 총16칸)과 신규 음중 hand/fullbody 원해상도 PNG 두 장을 직접 확인했다. 대표프레임은0/36/92/109이며 각 native frame n은 control endpoint2(n+1)이다.

- 바닥·몸체·기타가 정상 방향으로 보인다. 신규 전신 대표프레임 모두 머리와 양발이 프레임 안에 있고, 음중 원해상도에서도 머리 위/발 아래 여백이 있다.
- 손 카메라는 손가락 마디와 굽힘 변화를 보여준다. 색은 엄지 빨강·검지 파랑·중지 초록·약지 주황·소지 보라다. 기존 B300과 guard의 음중/마지막 손모양 차이가 보이며 실제 각도 수치는 원 guard 분석을 따른다.
- 넥이 패드/접촉부와 손목 일부를 가리고, 검지 일부는 다른 손가락에 가려진다. 특히 후반 손가락 전체 윤곽은 이 화면에서 명확하게 확인하기 어렵다. DIP/PIP 각도 정합은 원시 수치로 검증했고, 이 한 시점 카메라로 접촉쌍·실제 압력·해부학적 자연스러움·해제 성공을 판정하지 않는다. 전신 카메라의 손은 작으므로 세부 관절은 손 카메라/원시 각도를 함께 본다.

새 영상의 env0 221끝점 q/target/body/gate/action/wrist는 guard 원평가와 exact였다. 몸체합력만 최대3.814697265625e−6N 차이가 있어 그대로 보존했다. 전128 scalar sidecar의 모든 공통필드와 env0 compact 원장도 원평가와 exact다. 원256평가 음악성과와 영상 env0 범위는 구분한다.

신규2MP4 총220프레임을 CPU로 전체 디코딩했고, 신규8PNG와 기존 B300에서 이미 검수된8PNG의 출처/SHA를 비교sheet에 보존했다. 기존 영상을 중복 렌더하지 않았으며 GPU/native 추가실행은 하지 않았다. 독립 코드·수치·시각 검수 결과는 이 디렉터리의 review.json/REVIEW.md에서 확인한다.
