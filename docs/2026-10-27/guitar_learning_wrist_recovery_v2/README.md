# 일반 손목 종료 복귀 보정 v2

안내 영역이 다음 프렛으로 이동해 발생한 일시 이탈과 복귀 중 상태를 기존 일반 손목 종료가 너무 빨리 끊을 수 있어 타이머를 보정했다. 보정은 현재 기본 finger-skill에 적용한다.

## 변경

| 항목 | 이전 | 현재 |
|---|---|---|
| 일반 종료 시간 | .75초 | 순누적1.5초 |
| 안내 영역 밖 추가3cm 초과 | 시간 증가 | 시간 증가 |
| 활성 상태에서 추가2~3cm 복귀 | 계속 시간 증가 | 초당1초씩 차감, 최소0 |
| 추가2cm 이내 | 상태/시간 초기화 | 동일 |
| 초기 일반 종료 유예 | 3초 | 동일 |
| 심각 이탈 | 추가10cm 이상 .10초 연속 | 동일 |
| 물리 종료·보상9개·종료 비용 | 기존 기준 | 동일 |

2~3cm 구간에서 짧게 복귀했다고 타이머가 즉시 없어지지는 않는다. 예를 들어 추가3cm 밖 .8초 뒤 복귀 구간 .2초라면 누적 .6초가 남는다. H32·음/프렛 전환·다른 환경 reset은 해당 타이머를 초기화하지 않는다.

1.5초는 보정 시작값이며 모든 곡·자세에 최적인 값으로 검증한 것은 아니다. 성공 압현 자세가 안내 영역 밖에 있다는 근거가 없어 이번에는 영역 위치/크기를 바꾸지 않았다. 압현 성공을 이유로 일반 종료를 무기한 면제하지도 않는다. 종료 비용·시간 할인 조정은 이 보정에 포함하지 않았다.

## 근거

기존 최종 영상에서5.200→5.217초 안내 영역의 Gy중심이26.52mm 이동한 반면 손목 자체는−.054mm 이동했다. 영역 초과는28.42→54.99mm가 되며 타이머가 시작됐다.5.95초 종료 때는 안내 영역이 복귀하여 초과29.57mm였으나, 기존2cm해제 조건 때문에 .75초 누적이 유지됐다.

기록은60Hz 몸체 끝점과 저장된240Hz 누적 타이머다. 끝점 사이 최대값이나 종료 이후 동작을 추정하지 않는다. 해당 영상의 압현 접촉/clean 누적은0이라 정상 압현 자세의 유효성을 입증한 자료는 아니다. [재구성](recorded_episode_analysis.json) · [분석 코드](support/recorded_episode_analysis.py).

## 로그·호환성

종료 에피소드의 wrist_termination에 마지막240Hz 표본 기준 손목 기타좌표·영역 경계·축별 복귀 방향·최대 초과 축·현재/준비 목표 인덱스·현재 패드거리/clean 후보를 기록한다. 전체 궤적 최대나 실제 현 압력·음향 판정으로 해석하지 않는다.

종료 계약은 wrist_termination.v2, 진단은 wrist_termination_diagnostics.v2다. 상태 차원561과 필드 이름을 유지하되 일반 타이머 scale을 .75→1.5로 바꾸었다. 구v1계약 저장본은 모델을 바꾸기 전에 strict load에서 거부한다. 소스 SHA 검증도 유지한다.

## 검증

관련11모듈100개 CPU 검사를 통과했다. 일반/심각 문턱·준비 유예·복귀 차감·음 전환·부분reset·노출·단일비용·보상·새진단·관측·구계약저장거부를 포함한다. [CPU 결과](cpu_checks.json) · [로그](cpu_checks.log).

실제 GPU24구간의 동일 무행동 궤적에서240Hz로 세 판정을 함께 비교했다. shadow는 손목 종료만 적용하지 않고 기존 물리 종료를 유지했다.

| 판정 | 일반 손목 종료 예상 |
|---|---:|
| 기존 .75초·복귀띠 누적 |5/24|
| 시간만1.5초로 연장 |2/24|
| 시간1.5초＋복귀띠 차감v2 |0/24|

심각 손목 종료와 물리 실패는0/24였고,24개 모두 구간 끝까지 진행했다. 기존 종료 예상5개 중3개는 그 시점에 이미2~3cm 복귀띠에 있었다. 이후2cm 이내 완전복귀는5개 모두 관측되지 않았으므로 이 결과를 안내영역 도달이나 압현 성공으로 표현하지 않는다. 두 구간은 시간만 늘려도2~3cm에 있는 채 계속누적되어 종료됐지만 복귀보정은 이를 막았다. 나머지 일부는1.5초 전에 구간이 끝나므로 전곡 장기효과를 추정하지 않는다.

새 조건을 실제 적용한 별도24구간 smoke도 정상끝24/손목0/물리0, 종료비용0이었다. GPU PhysX/tensor pipeline·1simulator/24환경·유한 관측/보상/비용·장면close·새진단v2를 확인했다. 이 실행에는 실제 실패가 없어 새 문턱의 native 실패 발동·단일 실패비용은 확인하지 않았고, 그 경계/중복 검증은 CPU 검사 결과다.

활성 Python510개 SHA는 실행 전후와 사후에 동일했다. shadow68.75초·active65.98초가 걸렸으며 새 정책 학습·checkpoint 생성·영상 렌더는 실행하지 않았다. 초기실행은 PATH의ninja 누락으로 장면생성 전 실패했으며 로그를 보존하고 conda bin을 PATH에 넣어 재실행했다.

[전체 native 결과](native_checks.json) · [동일궤적 비교](native_shadow/report.json) · [실제 적용](native_active/report.json) · [실행 코드](support/native_check.py) · [실행 로그](support/native_check.log). 세 비교 타이머는240Hz이며 저장trace는60Hz 끝점이다. 새 정책 학습이나 연주 성능 개선을 주장하지 않는다.
