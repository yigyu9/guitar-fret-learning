# 왼손 보상 구조 요약

**GPU 왼손 v16 기준, 행동변화감점 구현·CPU 검증 완료, 2026-10-23.** 지정 손가락으로 목표를 찾아 접촉하고 필요한 시간 동안 유지하도록 학습한다. 손가락의 굽힘·펴짐 요청에는 움직임 비용을 부과하지 않는다.

## 한 음의 흐름

목표 확인 → 표면 접근 → 준비 접촉 → onset 이후 clean 유지 → 연속 달성 → 다음 목표로 전환한다. 준비 창은 press−2초, 접촉 진단 누적과 연속 streak는 press부터, audible clean은 onset부터다. 달성은 onset~end의연속clean `min(음 길이,max(50ms,40%×음 길이))`이며끊기면streak는0이다. clean/held진단과유지보상은누적이다. 40%는학습용중간달성이며음끝까지완전유지조건이아니다. 달성 뒤 오압현이나 누락이 생겨도 달성 플래그는 취소되지 않는다.

b는3장의기존손가락균형계수다. 오압현 감점은 별도 기존 contact 계수 0.15/1/1, 누락·미달성 감점은 timing 계수 0.10/0.35/1을 사용한다. b=1인한음전체가wrong이면단계0의최종감점은−.15이며초당값이아니다. 전체missing은−.05,최장streak0인미달성도−.05다. 미달성문턱400ms중399ms면원시−.00125b로단계계수를별도곱한다. 최근 256종료곡에서 안전 완주 90%와 모든 등장 손가락의 접근 또는 접촉 달성 평균 각 20%가 진급 조건이다. 단계 0에서도 압현 보상은 유효하다.

이전 v11은 관련22모듈215개 CPU검사(새 전용13개 포함), 독립61개 검사와 비정렬 시간창640개 substep-target의 scalar대조를 통과했다. 당시 GPU학습·장기 실행은 수행하지 않았다. 이전v12는관련23모듈229개CPU검사·guard이후8모듈82개재검사·독립75검사·1152substep-target scalar대조를통과했으며GPU/native·실제학습은미실행이다.

## PPO와 최근 확인된 한계

물리 240Hz·정책 60Hz·H32를 사용한다. reward/cost advantage를 각각 정규화한 뒤 결합하고 다시 정규화한다. GAE λ=0.98, reward γ=0.99, cost γ=1이다. 손가락 범위·독립 누적제어·PD·안전 기준은 유지한다.
