## 사전 확인

실제 GPU에서 새 구동 12업데이트·393,216전이와 재개 1업데이트·32,768전이를 정상 완료했다. 재개 시 누적 optimizer update는 13이다. 모델·두 Adam·RNG 등의 전체 비metadata 상태를 정확히 복원했고 3331값 단계 이력 재생 오차는 0이었다. 사전 검사 모델을 장기 학습 초기 모델로 사용하지 않는다.

CPU에서 실제 smoke/resume 기록의 입력 SHA·gzip CRC/EOF·에피소드 대응·저장본을 검증하고 smoke 분석·그래프 생성을 확인했다. 독립 검수에서도 도구 9개 SHA 및 CPU helper/mock 검사 37개가 통과했다. 이는 구동·저장·후처리 연결 검증이며 장기 성능·자연스러움·물리 무실패의 증거가 아니다.

학습과 후처리는 별도 프로세스로 실행한다. 정상 학습 종료 후 로그·저장본·입력 동일성을 검증하고 초기/500/1000/1500/2000업데이트 모델을 고정 1024환경의 첫 종료곡으로 평가한다. 물리 실패도 평균 달성음의 분모에 포함한다. 평가한 학습 모델 중 평균 달성음, 안전 완주 수, 최신 순서로 대표 모델을 정한다. 초기 모델은 별도 기준이다.

이후 전체 학습 수집 로그의 보상·PPO·단계·손가락별 달성 및 오압현 원인을 분석한다. 마지막 모델의 전신·손 영상을 저장하고 대표 모델이 다르면 그 모델의 영상도 저장한다. 영상은 실제 GPU 평가에서 기록한 자세를 CPU OSMesa로 재생하며 새 물리를 적분하지 않는다. 사전 지정 env0~7 중 안전한 최소 ID, 없으면 가장 긴 에피소드를 택하며 가장 잘된 연주 장면을 골라내지 않는다.

모든 후처리가 성공하면 `RESULTS.md`에 고정 평가 비교표와 분석·영상 링크를 생성한다. `analysis_final/analysis.md`, `checkpoint_evaluation.json`, `training_verification.json`, 최고·마지막 영상 폴더도 함께 저장한다. 오류가 생기면 `pipeline_status.json`에 실패 단계와 원인을 남기고 완료로 표시하지 않는다.

현재는 학습 진행 중이다. 최종 성능·영상 완료는 아직 확정되지 않았다. 대기 보상 합계는 기록되지만 240Hz의 실제 손가락별 gate·quality는 원장에 없어, 합계나 60Hz 자세만으로 각 손가락이 언제 보상받았는지는 인증하지 않는다. 표면 후보와 달성음은 실제 접촉쌍·현 압력·음향 성공을 뜻하지 않는다.
