# Fret 캐시 복원·접촉 유지 진단

기준 모델은 35,000 checkpoint다. 이전 FRET-018/019에서 준비 시간 증가와
자세 PD 유지로 중지 실패가 개선되지 않았다.

- [x] 캐시 관절각과 저장된 행동을 함께 사용하는 복원 평가.
- [x] 실제 접촉 재현과 정책 전환 후 유지 여부 분석.
- [ ] 복원이 성공하면 필요한 유지 학습 변경 구현·검증.
- [ ] 같은 checkpoint에서 약 2,000 iteration 비교 학습 후 전체곡 평가.

복원이 실패하면 후속 학습을 무작정 실행하지 않고 복원 원인을 먼저 기록한다.
캐시에는 관절각과 EMA 행동은 있지만 완전한 PhysX 접촉 상태·속도는 없다.
따라서 저장 행동 적용은 원래 성공 순간의 완전한 복원이 아니다.

## 실행과 결과

실행일: 2026-09-12. 사용자 요청에 따라 이 디렉터리에 보관한다.
기준 run: `20260911_1710_02_Jazz1-200-B_solo`, checkpoint `fret_035000.pt`.
중지 목표 499~514 frame, seed42, 기본 준비1초, 1환경으로 평가했다.

`record_fret_rollout.py`에 `--cached-preparation-action`을 추가했다.
첫 시험은 저장 EMA 값을 원시 입력처럼 넣어 다시 필터링되는 문제를 확인했다.
정식 시험에서는 매 준비 step의 prev_action도 저장값으로 복원했다.
입력과 이전 EMA가 같으므로 EMA 값은 그대로이며 synergy 유도 변화도 발생하지 않는다.
`cached_ema_error`로 실제 적용값과 저장값 차이를 검증했다.

이전 정책 준비 시험은 3/60 frame의 순간적 성공이 있었다.
저장 행동을 고정해도 성공 접촉이 재현되지 않아, 단순 행동 필터 복원만의 문제는 아니다.
낮은 접근 거리는 올바른 줄 접촉을 증명하지 않는다.

## 판정과 후속 단계

유지 학습 수정과 2,000 iteration 재학습은 **아직 실행하지 않았다**.
선행 조건인 재현 가능한 성공 시작 상태가 확보되지 않았기 때문이다.
실패 자세를 성공 자세로 간주해 유지 보상을 강화하면 잘못된 자세를 강화할 수 있다.

확인된 제약:

- 현재 진단은 캐시 제어 관절각을 초기화한 뒤 물리 안정화를 거친다.
  캐시 각도와 안정화 결과는 앞선 시험에서 최대4.87도 달랐다.
- 캐시에는 전체 관절 속도·actor root·접촉 해석 상태가 저장되지 않는다.
- cache slot은 fret/finger/barre만으로 묶인다. 손목 목표·저장 당시 stage·source frame은
  동일성 확인에 충분히 남지 않는다. 이것이 이번 실패 원인이라고 확정한 것은 아니다.
- 학습과 평가의 기본 press_success 판정은 공유하지만, 이 실험이 학습 전체 상태의
  동일 복원을 검증한 것은 아니다.

다음에 필요한 구현은 **성공 순간의 출처와 물리 상태를 포함하는 재현 검사**다.
기존 cache 성공 플래그만 믿지 않고, 복원 뒤 실제 PRESS가 연속 유지되는지 확인한
상태만 유지 학습 시작점으로 사용해야 한다. 그 전에는 장기 학습을 권장하지 않는다.

### 구현한 출처 기록

새 성공 캐시가 갱신될 때 `source_metadata`를 저장한다.

- 원본 goal frame, 저장 당시 curriculum stage, source environment index
- 원본 fret/finger와 실제 평가 active/assignment mask
- 모든 DOF 속도, actor root 위치·방향·속도, 전체 PD target

기존 q·EMA action 저장은 유지한다. 추가 정보는 진단용으로만 사용하며 보상과
캐시 선정 기준을 바꾸지 않는다. root는 source simulator 좌표이므로 다른 환경에
직접 복사하면 안 된다. PhysX contact solver 내부 상태까지 저장하는 기능은 아니다.
오래된 checkpoint에는 이를 소급 생성할 수 없어 빈 정보로 명시한다.

  이 검증 전에는 q만 복원한 실패 상태를 유지 학습의 성공 시작점으로 취급하지 않는다.

환경 코드 지문이 바뀌므로 기존 checkpoint 학습 재개 시 계약 migration 검토가 필요하다.

## FRET-022: 출처가 있는 성공 상태 확보

기존35,000에서 별도 `20260914_cache_provenance_probe` run으로 50 iteration,
1,024환경만 재개한다. 보상 변경 없음. 진단용으로 자동 영상은 끄고 checkpoint를 남긴다.
실행은 계약 migration을 사용하므로 재개 단계 시계가 초기화될 수 있다.
이 짧은 실행의 학습 F1을 전체곡 개선으로 해석하지 않는다.

`--restore-source-state`를 추가했다. 원본 source frame과 같은 목표이며
active mask가 원본 전체 PRESS와 같은 경우만 검사한다. q/속도/root/PD/EMA를 복원하고
기타 위치를 기준으로 source 환경의 평행이동을 제거한다.
rigid-body transform 갱신을 위해 한 physics substep을 진행한다.
이는 solver 내부 warm-start나 정확한 bitwise 재생이 아니다.
전체 상태 복원은 별도 진단 옵션이며 기본 학습 초기화를 변경하지 않는다.

### 성공 표본 수집 결과

50 iteration(35,000→35,050)은 정상 종료했지만 새 metadata는0개였다.
최고 품질이 갱신될 때만 기존 캐시를 저장하기 때문이다.
그래서 `diagnostic_probes`를 별도로 추가해 전체목표 성공의 최초 표본을 slot별로
한 번씩 기록했다. 최고 캐시 선정과 teacher/RSI 사용에는 관여하지 않는다.
마스킹된 목표의 성공은 진단 표본에 넣지 않는다.

추가5 iteration(35,050→35,055)에서18개 slot의 성공 표본을 확보했다.
원래 최고 캐시 q는 수집 전후 torch.equal=True로 보존을 확인했다.
중지 source frame은677,732,759에 포함됐다.

### 전체 상태 복원 결과

35,055 모델의677 중지 표본으로 source q/속도/root/PD/EMA를 복원했다.
source stage는 goal_pair이며 전체 목표 active와 일치한다.

- 준비 중 정밀 압현: **22/60 frame**.
- 준비 첫 frame부터 성공. 고정 EMA 복원 오차0.
- 한 물리 갱신 뒤 q와 source q의 최대 제어각 차이0.534도.
- 준비가 끝난 source677 한 frame도 압현 성공.
- 이어지는732 중지 목표는 실패. 전체곡 정확도 개선을 입증한 실험이 아니다.

이제 성공 접촉이 재현된다는 증거를 확보했다. 반면 고정 행동을 계속 적용하면
접촉이 끊어지므로 저장 행동이 안정적인 정적 지지 해답은 아니다.
이전 q-only 실험 실패로부터 압현 불가능이나 캐시 오판정을 추론하면 안 된다.
다음 변경은 전체 물리 상태를 쓰는 **진단용 접촉 유지 실험**을 기반으로 설계해야 한다.
긴 준비시간/일괄 고정/단순 캐시 가중치 증가를 같은 방식으로 반복하지 않는다.

실행 결과:

- `fret/training/runs/20260914_cache_provenance_probe`: 50 iteration.
- `fret/training/runs/20260914_cache_success_capture`: 추가5 iteration와35,055 checkpoint.
- 후자의 `videos/source_probe_middle677.*`: 전체 상태 복원 영상과 JSON.

학습 보상·승급 기준은 변경하지 않았다. 2,000 iteration 유지 학습은 아직 미실행이다.
CPU9개·GPU 수집/복원 실행을 검증했다. reviewer의 마스킹 표본 영구보존 지적을
전체목표 성공만 수집하는 조건으로 수정했다.

### 두 번째 표본: 안정 유지 재현 성공

같은35,055 모델의759 중지 표본을 전체 상태로 복원한 결과:

- 준비 중 물리 압현 및 precise 성공 **60/60 frame**.
- 실제 source759 목표 frame도 성공.
- 곡 나머지 구간 완주. 영상/JSON은 `videos/source_probe_middle759.*`.

따라서 재현 가능한 안정 성공 상태를 적어도 하나 확보했다.
677(22/60)과759(60/60)의 차이는 같은 성공 캐시라도 지속 안정성이 다름을 보여준다.
단일 seed/두 표본의 결과이므로 모든 목표에서 재현된다는 뜻은 아니다.
다음 유지 학습은 모든 캐시가 아니라 **복원 후 연속 유지 검사를 통과한 표본**에서
시작하고, 정책 전환·일반 자세 접근·곡 연속 전환은 각각 별도 평가해야 한다.
