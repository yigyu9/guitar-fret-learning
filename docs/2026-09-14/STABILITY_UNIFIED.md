# StabilityAdapter 단일 환경

## 목적

Fret·Strike를 아직 연결하지 않은 상태에서 수동 스트랩에 걸린 기타를 왼손 아래그립과
오른팔·몸의 지지로 목표 위치와 회전까지 자연스럽게 가져와 유지한다.

## 한 episode의 내부 흐름

| 단계 | 진입 조건 | 학습 신호 |
|---|---|---|
| 낙하·안정 대기 | 최소 60프레임 경과 후 선속도 0.10m/s·각속도 0.50rad/s 이하가 15프레임 지속 | 정책 출력과 보상 차단, 수동 스트랩과 물리만 작동. 스트랩 안전값은 해제 조건이 아니라 진단값 |
| 아래 접근 | 손바닥이 넥 중심선보다 5mm 아래, 손바닥 방향 내적 0.50 이상을 0.15초 유지 | 손바닥·엄지·손가락 거리와 방향 개선 |
| 그립 | 엄지와 두 손가락 이상의 대향 접촉, 안전 힘·미끄럼 조건을 0.20초 유지 | 최초 그립 보너스, 충격·관통·과한 힘 비용 |
| 운반 | 그립 이후 접촉을 유지하며 위치 오차를 15mm 이상 실제로 개선 | episode 최고 오차 개선에만 1회성 진행 보상 |
| 유지 | 위치 20mm·회전 8°·속도 0.05m/s·각속도 0.25rad/s 안에서 0.50초 유지 | 최종 자세·속도·왼손 접촉 성공, 오른팔·몸 지지는 약한 선호 비용 |

리셋 때 왼손을 넥 근처에 배치하지 않는다. 안정 대기 종료 후 약 11cm 떨어진 기준 자세에서
팔과 손목이 접근하며, 손바닥이 넥에서 5cm 안에 들어오기 전에는 손가락 제어를 차단한다.
접근 관절 목표 속도는 먼 곳 0.50rad/s에서 근처 0.25rad/s로 줄어든다.

그립만으로 성공 처리하지 않는다. 아래 접근, 실제 대향 접촉, 접촉 상태의 운반, 목표 자세
유지를 모두 통과해야 학습 성공이다. 오른팔·몸 지지는 향후 Strike 자유도를 남기기 위해
필수 gate로 고정하지 않고 접근·미끄럼 비용으로 유도한다. 손바닥 방향 오류, 작업영역 이탈, 상체 과굴곡,
비정상 기타 운동 등은 종료 원인별로 기록한다. 스트랩 장력 한계는 진단값으로 남기며
그 자체로 조기 종료하지 않는다.

## 고정 학습 계약

- 입력: 551차원 상태 × 최근 8프레임 = 4408차원
- 출력: 골반/root를 제외한 전신 97축 목표 속도
- 네트워크: actor/critic 각각 1024–512–256
- 물리: 자유 기타, 중력, 수동 고정 길이 스트랩, 부착 제약·목표 방향 보조력 없음
- 실행 이름: `--task stability-adapter` 하나
- 제거된 선택: support/hold 별칭, `--stage`, `--level`, `--config`,
  grasp/transport lesson, `--initialize-policy`

## 장기 학습 저장 정책과 재개

1024개 환경의 모든 종료 episode를 원문으로 남기면 로그가 환경 수에 비례해 증가한다.
실제 1382회 실행에서는 `recovery_episodes.jsonl` 하나가 1.8GB가 되어 디스크가 찼다.
회차별 집계인 `stability_metrics.jsonl`은 전부 유지하되, episode 원문은 매 회차 대표 1개와
100회마다 최대 16개만 저장한다. 체크포인트는 최근 3개와 5000회 단위 이정표를 보존한다.
따라서 50000회 장기 실행에서도 진단 가능성을 유지하면서 저장량이 제한된다.

기존 1300·2100회 체크포인트는 잘못된 즉시 그립 시작을 학습했으므로 새 환경에 사용할 수 없다.
재개는 새 v8 실행에서 생성된 체크포인트끼리만 허용한다. `--iterations`는 재개 후 추가 회차 수다.
