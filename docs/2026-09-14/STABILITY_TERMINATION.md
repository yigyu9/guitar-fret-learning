# StabilityAdapter 종료 조건

목적은 복구 가능성이 없는 상태를 빨리 제거하면서, 짧은 접촉 흔들림이나 정상적인 팔 조정은 학습 기회로 남기는 것이다. 모든 새 물리 실패는 기존 최강 종료 페널티 `-20`을 사용한다. 스트랩 장력·신장 한계는 성공 안전 조건과 진단값으로 유지하며 종료시키지 않는다.

## 적용 기준

| 저장되는 원인 | 원시 조건 | 지속시간 |
|---|---|---:|
| `failure_palm_down` | 왼손 손바닥 방향과 바닥 방향의 내적 ≥ 0.5이고 손바닥 기반 아래그립 유지 조건도 아님 | 활성화 후 15프레임 유예, 이후 12프레임 |
| `failure_underhand_lost` | 한 번 실제 그립을 획득한 뒤 손바닥 중심이 넥 단면보다 z축으로 -5mm 미만이거나 손바닥→넥 방향 내적이 0.25 미만 | 12프레임 |
| `failure_left_hand_far` | 그립 전 손–넥 거리 > 0.20m, 그립 후 > 0.12m | 그립 전 18프레임, 그립 후 12프레임 |
| `failure_guitar_workspace` | 목표 위치 오차 > 0.35m 또는 목표보다 0.30m 아래 | 12프레임 |
| `failure_guitar_flipped` | 목표 회전 오차 > 120도 | 12프레임 |
| `failure_trunk_bent` | 상체 9축 RMS > 20도 또는 한 축 > 30도 | 12프레임 |
| `failure_guitar_motion` | 기타 선속도 > 2.5m/s 또는 각속도 > 12rad/s | 3프레임 |

접촉 합력 200N 초과는 `termination_contact_force_limit_exceeded`로 기록하지만 종료에는 사용하지 않는다. GPU 파이프라인에서 제공되는 값은 사람–기타 접촉쌍의 힘이 아니라 강체별 합력이므로, 의자·바닥 접촉을 오인하거나 반대 방향 힘의 상쇄를 놓칠 수 있기 때문이다. 접촉쌍을 신뢰할 수 있는 측정 경로가 마련된 뒤 종료 후보로 다시 검토한다.

손바닥·아래그립·손–넥 거리 조건은 아래그립 초기화를 사용하는 S4 pinch 학습에 적용된다. S1–S3 및 일반 StabilityAdapter에는 해당 접촉 기하가 없으므로 적용하지 않는다. 기타 영역·회전·상체·운동 조건은 전체 StabilityAdapter에 적용된다. 자세와 운동 조건은 정책 제어가 활성화된 동안만 누적하고, 초기 대기에는 수치 오류와 기타 작업 영역·회전 이탈만 검사한다. 손바닥이 바닥 쪽을 잠시 향하더라도 손바닥 중심·방향이 완화된 아래그립 유지 범위 안에 있으면 종료하지 않는다.

기존의 NaN/Inf, 50rad/s 초과 관절 속도 폭주, 심각한 기타 낙하와 시간 제한도 유지한다. 시간 제한은 물리 실패와 구분된다.

## 사후 검증 데이터

매 스텝의 `info`에는 각 `failure_*`와 같은 이름의 `terminal_failure_*` 마스크가 들어간다. 현재 측정값과 누적 프레임은 `termination_*`, `termination_streak_*`에 기록된다.

`logs/recovery_episodes.jsonl`의 완료 에피소드에는 다음 필드가 보존된다.

- `termination_reason`: 대표 종료 원인
- `termination_reasons`: 같은 프레임에 함께 성립한 모든 원인
- 모든 `failure_*`: 원인별 참/거짓
- 종료 당시 `termination_palm_down_dot`, 손–넥 거리, 상체 RMS·최대각, 접촉력과 조건별 누적 프레임

평가 JSON도 고정된 세 실패 항목 대신 실행에서 제공되는 모든 `failure_*`를 자동 수집한다. 종료 설정 전체는 체크포인트 계약의 `stability.termination`에 저장되므로 어떤 기준으로 학습했는지 나중에 대조할 수 있다.

## 검증 결과

- Stability 관련 CPU 검사 328개 통과, GPU 전용 26개 제외
- Isaac Gym GPU 수명주기 검사 3개 통과: 종료 페널티, `info`, 완료 에피소드 원인 목록, 2환경 작업영역 판정과 부분 리셋 격리 확인
- 현재 손바닥 기준 GPU 2환경·60프레임: 초기 유지 범위 진입과 엄격 기준 0.15초 충족 뒤 단계 전환 확인
- 현재 기준 1환경·최대600프레임 진단: 구 제어기는 엄격 진입을 통과하지 못해 집기 성공0, 263프레임에 높이 유지 경계 이탈로 `failure_palm_down`과 `failure_underhand_lost`가 함께 기록되며 종료
- 기존 1환경·10초의 아래그립 8.13초 결과는 구 팔꿈치 판정 자료이며 현재 손바닥 기준의 성공 근거로 사용하지 않음

기준값은 실물 측정치가 아니라 첫 시뮬레이션 공학 기준이다. 새 PPO 실행의 정상·실패 분포를 수집한 뒤 정상 궤적의 상위 분위수와 영상 판정을 함께 사용해 조정한다.
