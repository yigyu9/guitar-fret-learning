# 압현 V5 코드 해설

새 압현 구현의 유일한 기준인 V5를 설명한다. 이전에 여러 장으로 나누었던 기본 구조 설명은 한 문서로 통합했다.

1. [코드 지도](../../../guitar_learning/docs/CODE_STRUCTURE.md)에서 담당 파일을 찾는다.
2. [V5 학습 코드 해설](V5_학습코드해설.md)에서 상태·목표→정책→물리·접촉→보상·종료→PPO→로그·평가 순서로 읽는다.
3. 실행은 [학습 안내](../../../guitar_learning/README.md), C1~C6는 [합성 목표 안내](../../2026-11-09/압현_v5_합성목표연결_v1/README.md)를 따른다.

V5는 기본 상태464/선택473, 목표26×8, Actor768→512→256→33과 독립 보상·비용 Critic을 사용한다. 이전 버전 이름이 남은 내부 계약은 공용 측정·로그의 식별자이며 구형 실행기가 아니다.

2026-10-28~31의 소스 SHA·검증 JSON·검수 원문은 [역사 근거](역사근거_20261031/README.md)로 이동해 바이트를 보존했다. 구형 상세 해설은 제거했으며 [짧은 연구 이력](../../history/press_before_v5.md)으로 대체했다. 원래 경로·SHA와 삭제·이동 목록은 [이번 정리](../../maintenance/v5_project_cleanup_20261104/)에 남긴다.
