# 초기 자세 미확보 9조합의 원인과 이동 준비 방식

2026-11-02. study_v1의 원시47회 native probe, 후보 catalog, native 끝점 관절/몸체/접촉 기록과 현재 reset·제어·종료 코드를 읽어 분석했다. 기존 소스·학습 모델·원장·입력과 진행 중 영상 복구는 변경하지 않았으며 새 GPU 실험을 수행하지 않았다. 수치별 원시 경로·SHA는 초기자세_검사집계.json에 있다.

## 결론과 범위

9개는 모두 학습0회다. 학습이 수렴하지 않은 문제가 아니라 이번 손목지원 실험의 시작 조건을 확보하지 못한 것이다. 이9개 중7개는 최신 전체기타 CPU 후보 탐색 미달,2개는 CPU 통과 뒤 native에서 미달이었다. fallback 후보의 실제 실패는 각각 별도 근거다. 이 결과로 프렛 자체가 연주 불가능하거나 GPU FK가 틀렸다고 결론내리지 않는다.

| 구분 | 조합 | 확인된 근거 |
| --- | --- | --- |
| CPU 후보 미확보 5개 | 검지S1F22·검지S6F22·약지S1F22·중지S3F22·중지S6F22 | 목표 패드 정렬과 손목/손바닥/엄지 등의 기타 몸통 회피를 함께 만족하는 후보를 이번 국소 탐색에서 찾지 못했다. fallback native에서 여러 조합이1~6 제어tick 안에 종료했고 큰 접촉력이 기록됐다. |
| CPU 후보 미확보 2개 | 중지S1F12·검지S3F12 | 고정 대기각의 비목표 약지/소지 간섭을 피하지 못했다. 원본10mm fallback에서 중지S1F12는 약지3이13프렛, 검지S3F12는 약지2/3이15프렛 오압현을 일으켰다. |

여기서 CPU 미확보는 탐색 제한 아래 미발견이다. 팔은 v1 후보 주변 최대±.35rad 이내의 제한된 탐색을 했고, 담당·비담당 손가락 대기각과 엄지는 유지했다. 이 손 모양 자체가 특정 프렛에서 충돌을 유발할 수 있다. 더 넓은 팔 자세, 다른 손가락의 작은 회피, 다른 손목 방향까지 포함한 전역 가능성을 검사한 결과가 아니다.

12프렛의 구체적인 fallback 근거는 다음과 같다.

- 중지S1F12의 원본 후보: 약지3이13프렛에 오압현,첫 native 끝점 약지3 합력127.9N.
- 검지S3F12의 원본 후보: 약지2/3이15프렛에 오압현,각1875.6/1607.4N,2tick 종료.
- 중지S3F12의 원본 후보: 소지3이14프렛에 오압현,첫 합력145.2N. 전체기타 후보에서는 이 선접촉을 피했지만 실제 정렬이 남았다.

위 힘은 native 몸체 합력 표본이며 사람이 줄을 누르는 힘이나 접촉쌍별 힘을 측정한 값이 아니다. 큰 값은 초기 간섭의 증거로만 사용한다.

## 실제로 목표 위치를 유지하지 못한 사례

중지S3F12의 전체기타 후보는 CPU에서 목표 높이12.261mm였지만 실제3초 유지 끝점은26.521mm였다. 팔 유지 목표 보정1/2회 뒤에도27.608/27.861mm,접선오차17.474/18.173mm로 개선하지 못했다. 기본 후보의 마지막 실제각−요청각 잔차는 L_Thorax_z 약2.92도,L_Shoulder_z 약2.01도였다. 보정2회 뒤는 각각4.51/2.76도다.

실제 관절각으로 계산한 FK와 native 손가락 위치는 매우 가깝다. 원하는 각도로 reset한 것이 실제 제어 하에서 같은 위치의 평형을 보장하지 않는다는 증거다. 중력·관절 제약·힘 상한·상한에 걸린 명령·다른 몸체 접촉 중 무엇이 주원인인지까지 현재 기록만으로 분리하지 않는다. 팔 관절각 오차를 일괄 더하는 보정이 이 후보에서 유효하지 않았다는 결과도 보존한다.

## 현재 시작 방식이 생략하는 과정

NaturalScene.reset는 목표별 DOF 상태를 에피소드 경계에서 재배치하고, 그 상태의 CPU FK 몸체 스냅샷을 첫 관측으로 사용한다. NaturalPool.reset는 유지 목표도 즉시 설정한다. 이후 물리와 유한 PD는 정상 실행되지만 공통 준비자세→이동→접근→안정화의 물리 경로는 없다.

따라서 손·기타가 실제로 이동하며 간섭을 피한 이력과 하중 아래 정렬 보정을 검증하지 않는다. 반대로 바로 배치하는 방식 자체가 잘못된 것은 아니다. 충돌 없는 정렬 상태의 손가락 압현을 분리하는 실험에는 쓸 수 있으나, 이번처럼 그 상태의 실제 유지가 불안정하면 시작 조건이 성립하지 않는다.

## 권장 변경: 안전한 공통 출발에서 실제로 이동

다음 순서가 타당하다. 이번에는 구체 구현보다 이 경로의 실현성을 먼저 확인한다.

1. 사용자 확인을 받은 v9 등의 후보 중 실제 물리에서 안정·무압현이 확인된 공통 준비자세 하나를 출발점으로 고정한다. 이미 압현된 성공 프레임을 출발점으로 삼지 않는다.
2. 팔의 유한 제어로 손을 기타에서 떨어진 안전 영역으로 이동한다.
3. 기타 몸통 외곽을 지나 목표 프렛 방향으로 이동한다.
4. 목표 위 hover로 접근하고 실제 손목·패드 위치와 속도를 보고 안정화한다.
5. 손목이 허용 영역에 안정적으로 들어오면 담당 손가락 정책을 시작한다. 압현 중에도 실제 손목 영역 이탈에는 팔의 제한된 피드백을 적용한다.

이동 끝에 관절각 명령만 고정하면 같은 정렬 잔차가 다시 나타날 수 있다. 준비 중에는 실제 pad/wrist 오차를 사용하고, 압현 단계에서는 손목의 허용 위치/방향을 유지한다. 압현 중 손가락 패드를 hover 높이에 계속 맞추면 손가락 굽힘을 팔이 상쇄할 수 있으므로 그 피드백은 끈다. 손가락의 접촉/압현 여부를 운반기가 대신 성공시키지 않는다.

공통 출발이 순간 초기 충돌을 줄일 수는 있지만 최종 자세나 경로가 기타를 관통하는 문제를 자동 해결하지는 않는다. 두 끝 자세가 안전해도 관절각 직선 보간의 중간 궤적은 손/전완이 기타 몸통을 통과할 수 있다. 모든 기타 충돌 조각·손·전완·몸통을 포함한 경유점 검사와 자유 기타 native 재생이 필요하다. 고정 축으로 항상 같은 방향을 택하지 않고 실제 기타 형상과 팔의 위치로 경유점을 정한다.

비담당 손가락을 한 각도에 완전히 묶으면12프렛의 약지/소지 간섭이 재발할 수 있다. 먼저 같은 대기각으로 경로를 확인하고, 그 조건으로 기하가 안 맞는 조합은 비담당 손가락을 사용자가 정한 대기 허용 범위 안에서 조금 조절하는 별도 조건으로 분리한다. 기준 완화나 조용한 변경으로 동일 실험에 합치지 않는다. 엄지 후면 지지는 별도 후속 조건이다.

## 구현에서 빠뜨리면 안 되는 것

- 현재 손목의 심각 이탈 종료는 첫3초 유예와 별개로10cm/.1초에 적용된다. 1프렛 출발부터22프렛 최종 안내 영역을 바로 적용하면 정상 이동 중에도 종료될 수 있다. 운반 구간에는 경로를 따라 이동하는 손목 안내 영역을 정의하고,정렬 이후에는 원래 최종 영역으로 연결한다. 물리 실패 보호를 끄는 방식은 사용하지 않는다.
- 운반 시간이 항상3초 안에 끝난다고 가정하지 않는다. 물리 시간과 음표/정책 학습 시작 시계를 명시적으로 분리한다. 실제 이동 중 상태 재주입·기타 고정·추가 지지력은 사용하지 않는다.
- 우선 팔 운반은 비학습 제어로 한다. 운반 프레임을 손가락 PPO가 선택한 행동처럼 저장하지 않는다. 운반 성공률,운반 후 손가락 성공률,출발부터의 전체 성공률을 따로 기록한다. 운반 실패도 전체 분모에 남긴다.
- 담당 손가락은 실제 압현 학습 구간에서 기존 전체 허용 범위와 움직임 비용0을 유지한다. 팔 운반 성공을 팔 정책 학습 성공으로 보고하지 않는다.
- 기존 ShortPool은 기타 고정 진단이므로 통째로 가져오지 않는다. 실제 q-position Jacobian과 bounded_wrist_target 같은 수학만 자유 기타 경로에 연결해 검증한다. 과거 봉인 코드도 읽기 참고만 하고 import하지 않는다.

## 가장 작은 다음 비교

먼저 세 목표에서 정책 없이 운반만 검사한다.

- 검지S1F1: 이미 정렬·압현 성공한 대조군.
- 중지S3F12: 충돌 없이도 실제 정렬이 남은 사례.
- 소지S3F22: 기하 후보는 있었지만 기타 이동으로 종료한 사례.

공통 시작→안전 경유→hover→최소.5초 안정 유지의 native 재생을 비교한다. 준비 최대6초는 첫 시험 예산으로 두고,위치·속도 허용치와 전체 충돌·물리 조건은 실행 전에 별도 계약으로 고정한다. 이번 분석에서 그 예산의 성공은 검증되지 않았다.

실험조건은 순서대로 (A)현재 정렬reset+고정 유지,(B)공통 시작+매끄러운 운반+같은 고정 유지,(C)공통 시작+운반+실제 손목 피드백으로 나눠 원인을 분리한다. B만으로 나아지면 순간 배치/접촉 이력의 영향,C가 있어야 나아지면 실제 유지 오차의 영향이라는 근거가 된다. 이는 단일 사례의 비교이며 일반 인과로 확대하지 않는다.

통과하면 그 운반기를 새 단음 실험에 연결하여 담당 손가락4축만 짧게 학습한다. 그 다음 비담당 손가락 회피,마지막으로 팔 운반 자체의 정책 학습을 다룬다. 현재 실패한9조합을 곧바로 장시간 재학습하는 것은 권장하지 않는다.
