# 중지 두 줄의 이웃 프렛 CPU 탐색 결과

이미 확보한 중지 1번 줄 12프렛과 중지 3번 줄 12프렛의 최종 관절각을 정확히 재현한 뒤, 각 줄에서 13~22프렛을 순서대로 탐색했다. 기준 12프렛은 2/2 재현했고, 이후 20개 조합 중 5개에서 소스 기하 후보를 찾았다.

결과의 `string`은 0부터 세는 실행기 번호로 0=표준 1번 줄, 2=표준 3번 줄이다. `physical_string`은 표준 1부터 세는 번호이며 1과 3이다. 아래 표는 `physical_string`을 사용했다.

| 프렛 | 중지 1번 줄 | 중지 3번 줄 | 발견 수 |
|---:|---|---|---:|
| 12 | 기준 후보 재현 | 기준 후보 재현 | 2/2 |
| 13 | CPU 후보 발견 | CPU 후보 발견 | 2/2 |
| 14 | CPU 후보 발견 | CPU 후보 발견 | 2/2 |
| 15 | CPU 후보 발견 | 제한된 탐색에서 미발견 | 1/2 |
| 16 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 17 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 18 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 19 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 20 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 21 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |
| 22 | 제한된 탐색에서 미발견 | 제한된 탐색에서 미발견 | 0/2 |

12프렛 기준은 2/2, 13·14프렛은 각각 2/2, 15프렛은 1/2, 16~22프렛은 각각 0/2였다. 이 조건에서 연속으로 찾은 구간은 중지 1번 줄 12~15프렛, 중지 3번 줄 12~14프렛이다.

각 목표는 직전 성공 후보를 seed로 사용했다. 미발견이면 원래 가까운 v5 후보를 두 번째 seed로 사용해 각각 최대 20회 탐색했다. 모든 손가락과 엄지의 대기각, 기존 팔 12축 행동 범위는 유지했다. 전체 시간은 82.41초였다.

## 다음 연구의 운영 구역

| 구역 | 프렛 | 운영 방법 |
|---|---|---|
| 우선 후보 | 1~14 | 개별 목표의 native 준비 검사를 통과한 경우에만 기본 학습 허용 |
| 경계 | 15~16 | 준비 자세와 운반을 별도로 검사한 뒤 개별적으로 학습 여부 판단 |
| 우선 보류 | 17~22 | 현재 방식의 기본 학습에서 제외하고 자세·지지·경로를 별도 연구 |

이 분류는 다음 실험의 우선순위다. 1~14프렛의 모든 손가락과 줄을 검증했다는 뜻이 아니다. 이번 이웃 탐색은 중지와 1·3번 줄만 대상으로 했으므로 검지, 다른 손가락, 6번 줄에 같은 경계를 일반화할 수 없다.

CPU 후보 발견은 소스 기하 조건만 만족했다는 뜻이다. 실제 native 물리, 운반 경로, 기타 지지, 준비 유지와 압현 성공은 별도 검사해야 한다. CPU 미발견도 고정 대기각, 팔 행동 범위, 선택한 seed와 제한된 탐색 횟수에 따른 결과이며 보편적인 물리적 또는 해부학적 불가능의 증명이 아니다.

별도 정적 점 검사에서는 12~22프렛의 1·3·6번 줄 압현점과 hover점이 모두 기타 몸통 내부가 아니었다. 손목·손바닥·엄지의 몸통 간섭과 목표점 자체의 침범은 구분해야 한다.

`baseline_reproduction.json`은 기준 2개 재현을, `endpoint_goals.json`은 학습 bundle 없는 목표 정의를, `results.json`은 각 seed, 최종 관절각, 기하 수치와 원본 SHA를 보존한다. 기존 36개 단일 seed 탐색은 기준 재현이 빠져 해석 가치가 제한적이므로 중단된 원문 그대로 보존했다. 이 보고서는 기준을 재현한 뒤 수행한 새 연속 탐색을 근거로 한다.
