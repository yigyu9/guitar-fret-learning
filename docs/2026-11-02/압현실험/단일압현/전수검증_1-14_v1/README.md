# 1~14프렛 단일 압현 전수 검증

검지·중지·약지·소지 × 6줄 × 1~14프렛의 **336조합**을 검사한다. 엄지는 지지 관절이며 압현 대상에서 제외한다.

이번 검사는 정책 학습이 아니라 현재 제어 범위에서 압현할 수 있는 동작을 찾는 진단이다. 공통v9에서 실제 팔 운반 → 실제 도착 상태의 손가락 후보 계산 → 담당 손가락4축 이동 →1.5초 음 구간 유지 순서다. 기타 고정·중간 상태 재주입·힘 상한 증가는 사용하지 않는다.

결과는 준비 도달/압현 달성/유지율/오압현/물리 실패를 구분한다. 준비 실패나 국소 탐색의 후보 미발견은 해당 조합의 물리적 불가능 증명이 아니다. 성공도 현행 접촉 합력·표면 기하 기준이며 실제 음향·줄 장력 측정과 구분한다. 각 조합의 최초 시도·재시도 분모를 보존한다.

- `설계/cases.json`: 중복 없는336조합 원장
- `도구/`: 새 검사기와 CPU 후보 생성 도구. 기존 봉인 연구의 소스·모델은 보존
- `입력/`: 후보·곡 입력
- `로그/`: 실제 물리 관측과 조합별 결과
- `분석/`: 줄×프렛 결과표와 요약
- `video/`: 대표 영상만 보관

현재 상태: 336조합 CPU 준비 탐색 완료(후보259/미해결77), 중지·1번 줄·12프렛 실제 물리 pilot에서1.5초 clean 유지 성공 재현. 336조합의 실제 물리 전수 검사를 순차 실행 중이다. pilot은 전수검사 결과에 상속하지 않는다. 모든 검사는 동일 고정 초기 자세에서1회 시도하며 여러 초기 조건의 안정적 성공률 검증은 별도다.

- [자동 갱신 결과표](분석/전수검증_결과.md)
- [현황 그림](분석/전수검증_현황.png): 12조합마다 갱신
- [실행 상태와 예상 잔여 시간](로그/sweep_v1/state.json): finished/remaining/estimated_remaining_s/current 확인
- [기존 실험 근거](분석/기존근거색인.md)

원장은 조합마다 갱신하며 검사 오류는 최대2회 기록 후 다음 조합으로 넘어간다. 물리적인 과제 실패는 재시도해 성공만 골라내지 않는다. 원본 소스·입력 봉인이 달라지면 전체 검사를 멈춘다. 완료 전에는 모든 조합의 압현 가능 여부가 확인되었다고 해석하지 않는다.
