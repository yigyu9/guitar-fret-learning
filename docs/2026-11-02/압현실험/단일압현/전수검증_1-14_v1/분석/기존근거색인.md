# 기존 단일 압현 근거 색인

새 전수검증 대상은 검지·중지·약지·소지 × 6줄 × 1~14프렛 = 336조합이다. 아래는 과거 실험의 참고 근거이며 새 전수검증의 성공으로 상속하지 않는다.

기존 18조합 중 범위 내 조합은 12개다. 이 중 정책 학습·평가까지 진행한 것은 9개, 초기 준비 미확보는 3개다. 과거 어떤 seed·체크포인트에서라도 음 달성이 관측된 조합은 6개이고, 과거 연구의 강화된 확인 기준으로 passed인 조합은 4개다. 이 둘은 다른 수치다.

|---|---:|---:|---|---|---|---|

검지 1번 줄 1프렛과 소지 6번 줄 12프렛은 seed7 확인 평가 32/32였다. 중지 1번 줄 1프렛과 약지 3번 줄 1프렛은 seed17 확인 평가 32/32였다. 약지는 평균 clean 비율 약 0.912, hold90 31/32이므로 전 구간 완전 유지를 뜻하지 않는다. 나머지 과거 달성 관측 2조합은 소지 3번 줄 1프렛과 소지 1번 줄 12프렛이다.

공통 출발 재실험에서 중지 1번 줄 12프렛은 100회 정책 학습 후 고정32 평가에서 준비 32/32, 압현 달성 0/32였다. 같은 목표의 알려진 손가락 각도 진단은 별도 1회 실행에서 clean 1.5초, 과제 달성 1/1이었다. 후자는 학습된 정책의 성공이나 반복 신뢰성 검증이 아니다.

이 색인에서 과거 자료가 있는 고유 조합은 12/336개이고 나머지 324개에는 해당 연구의 직접 검증 근거가 없다. 프로젝트의 다른 전환 연구나 CPU 후보 탐색까지 모두 없었다는 의미는 아니다. 새 전수검증의 상속 성공 수는 0이다.

과거 정렬 초기화와 새 공통 출발 운반은 초기 분포가 다르다. 초기 자세에 따라 가능한 동작·접촉·물리 안정성이 달라지므로 과거 passed도 재검증 대상이다. 실제 판정은 현행 하중을 동반한 패드 기하 기준이며 줄의 진동·음향·실측 압력을 보증하지 않는다.

원시 대조: 과거 모든 기록된 평가와 확인 평가에서 episodes.jsonl의 에피소드 수·stage_success 수·평균 clean 비율을 state.json의 metrics와 비교했다. 보고서 completed, failure=null, changed_inputs=[]도 확인했다. 각 원시 보고서·에피소드 파일의 SHA는 JSON 색인에 기록했다. 체크포인트 SHA는 기존 보고서 값을 기재했으며 이 색인 작성에서 모델을 읽거나 해시를 다시 계산하지 않았다.
