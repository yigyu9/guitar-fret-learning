## 1. 현재 어디까지 왔나

**정렬된 팔을 지원한 단일음 압현은 네 손가락 대표 목표에서 확인했다. 팔과 손가락을 함께 학습하는 안정적인 목표 전환은 아직 미달이다. 다른 손가락으로의 전환과 동시 압현은 앞으로 검증해야 한다.**

| 항목 | 현재 판단 |
|---|---|
| 검지·중지·약지·소지의 단일 목표 | 지원 조건에서 학습한 대표 모델의 성공 확인. 모든 줄·프렛의 성공은 아님 |
| 팔·손가락 전체 공동 학습 | 같은 목표에서도 최고 모델과 마지막 모델, 난수에 따라 성능이 달라짐 |
| 같은 중지의 6→7프렛 전환 | 참조 제어로 수행 가능. 평균 정책은 첫 음만 달성하고 두 번째 음 실패 |
| 탐색 포함 전환 | 일부 실행에서 달성하지만, 두 음 전체 길이 유지와 안정적 재현이 부족 |
| 엄지 후면 지지 | 기존 전환 실험에서는 엄지 제어가 제외됨. 새 별도 제어·학습 비교 중 |
| 다른 손가락으로 전환 | 확정된 학습 성공 자료 없음. 다음 연구 단계 |
| 두 손가락 이상 동시 압현 | 확정된 학습 성공 자료 없음. 합성 영상이나 손가락별 성공을 동시 압현으로 해석하지 않음 |

아래 기존 전환 연구는 **large 정책·GPU 64개 병렬 환경**을 사용했다. 현재6→8 실험은 별도 환경 수 비교를 거쳐1024환경을 선정했다. large는 신경망 크기이며 환경 수와 구분한다.

## 2. 결과를 읽기 위한 용어와 기준

| 용어 | 의미 |
|---|---|
| 기하 명령 재생 | 찾아 둔 관절 목표각을 제어기로 실행. 강화학습 정책의 성공과 구분 |
| 정렬·팔 지원 | 압현하기 좋은 초기 자세 또는 팔 목표 유지가 주어진 조건. 팔 정렬을 정책이 배운 성과와 구분 |
| 평균 동작(mean) | 매 시점 정책 분포 중심을 실행. 성공 궤적 여러 개를 평균낸 영상이 아님 |
| 탐색 포함(sampled) | 같은 정책에서 관절 명령에 확률적 변화를 포함하여 실행 |
| 기대 관절각 | 확률 분포를 비대칭 관절 범위까지 변환한 요청각의 기댓값. 실제 물리 응답의 기댓값은 아님 |
| clean, 올바른 압현 유지 | 담당 손가락 패드의 위치·방향·몸체 하중과 오압현 제외 조건을 만족한 시간 |
| 음 달성 | 정해진 연속 clean 시간을 채움. 누적 clean 시간이 길어도 자주 끊기면 미달성 가능 |
| AB 달성 | 첫 음 A와 다음 음 B를 모두 달성한 에피소드. 두 음 전체 길이 유지와는 별도 |
| 실패 포함 32/128회 | 환경별 첫 에피소드를 분모로 사용하고 중도 실패도 제외하지 않음 |

판정 기준은 연구 과정에서 달라졌다. 초기 단일음 학습은 **연속 1초**, 전환 v2/v3는 **연속 0.6초 달성**, **각 음 전체 1.5초 유지**, **시작 시각 준수**를 구분한다. 서로 다른 기준의 성공률을 하나로 합치지 않는다.

이 연구의 접촉·clean은 **유한 표면 표본과 몸체 하중에 기반한 판정**이다. 특정 손가락과 줄 사이의 접촉쌍별 압력이나 실제 음향을 직접 측정한 결과는 아니다. 영상은 보통 환경0 한 회이므로 집계 성공률을 대신하지 않는다.

## 3. 완료한 실험과 배운 점

### 3.1 기하 후보 재생: 목표 자체의 가능성 확인

새 초기 자세에서 네 손가락×4목표, 총16개를 자유 기타의 세 제어 조건×두 실행으로 검사했다. 총96개 실행에서 물리 안전 실패는 없었고, 두 번 반복 성공한 목표는 **5/16개: 검지 1개, 소지 4개**였다.

이는 학습 정책의 성공이 아니다. 손가락의 능동 굽힘보다 손 전체 이동이 큰 사례가 있어 실제 학습을 따로 진행했다. 예전 고정 기타에서의 성공도 현재 자유 기타·초기 자세·학습 구조에 자동으로 이전된다고 보지 않는다.

근거: [기하 후보 재생 해석](../압현성공/analysis/INTERPRETATION.md), [전체 결과](../압현성공/analysis/RESULTS.md).

### 3.2 실제 PPO 단일음: 초기 구조의 실패 확인

16목표마다 **large·64환경·H32·100회·seed7**로 새 정책을 학습했다. 최종 목표별16환경, 총256회 평가에서 **달성·접촉·clean 모두 0**이었다. 이 예산의 실패는 목표의 물리적 불가능을 증명하지 않는다.

이어 대표4목표에 기준군, 탐색 확대, 학습률 보정, 두 변경 조합, 순차 구조를 비교했다. 최종 **640회 평가에서 달성·clean 모두 0**이었다. 순차 구조는 패드 정렬 gate를 통과하지 못해 굽힘 단계에 들어가지 못했다. 탐색과 학습률을 높이는 것만으로 해결되지 않았다.

근거: [16목표 PPO 결과](../압현성공/analysis/learning/RESULTS.md), [탐색·학습률·순차 구조 비교](../압현성공/experiments/exploration_lr_sequence_v1/analysis/FINAL_ANALYSIS.md).

### 3.3 지원 조건부터 확장: 단일음 학습의 성공 확인

검지3번줄·4프렛은 정렬된 A 초기 자세에서 팔·비목표 손가락의 적용 목표를 유한 PD로 유지하고 검지4축을 학습했다. 100회와200회 모델 모두 **32/32 안전 달성**이었다. 더 좋은 유지율의100회 모델을 영상으로 남겼다. 이 렌더에서 검지 MCP 굽힘/PIP/DIP의 실제 변화 범위는 약26.2°/21.6°/5.6°로, 손가락이 전혀 움직이지 않은 성공은 아니었다.

### 3.6 목표 전환 v1: 잘못된 동시 성공 판정 발견

중지 하나로 같은 줄6·7프렛을 전환하는 연구에서, 같은 손가락의 높은 프렛 간섭을 놓쳐 두 목표가 동시에 유효 후보로 인정되는 문제가 발견됐다. 당시 확률 실행의4음 달성3/32는 실제 전환 성공의 근거로 사용하지 않는다.

같은 줄에서 높은 프렛을 유효하게 누르면 낮은 목표를 차단하도록 보정했다. 낮은 프렛의 부수 접촉이 남았다는 이유만으로 높은 목표를 막지는 않는다. 판정 오류를 수정한 뒤 참조와 학습을 다시 진행한 것이 v2다.

근거: [v1 해석 정정](../압현성공/experiments/virtual_transition_v1/runs/comparison_v1/review/PHYSICAL_FEASIBILITY.md).

### 3.7 목표 전환 v2: 수행 가능하지만 안정적 학습은 미달

목표는 **중지·3번줄·6프렛 A → 7프렛 B**, 각 음1.5초, 휴지0.75초다. 자유 기타와 기존 제어기로 실행한 참조 동작은 **6→7→6의 정시 시작·전체 유지**를 통과했다. 휴지1초도 통과했고0.5초는 해당 경로에서 실패했다. 모든0.5초 전환이 불가능하다는 뜻은 아니다.

학습은 large64/H32, 팔12+중지4축, 두 seed 각300회였다.

| seed / 실행 | A 달성 | B 달성 | AB 달성 | B 평균 clean /1.5초 | 두 음 전체 유지 |
|---|---:|---:|---:|---:|---:|
|7 평균|32/32|0/32|0/32|0초|0/32|
|7 탐색 포함|30/32|18/32|16/32|1.215초|1/32|
|17 평균|32/32|0/32|0/32|0초|0/32|
|17 탐색 포함|23/32|14/32|10/32|0.870초|0/32|

물리·손목 종료는 모두0이었다. 평균 정책은100/200/300회 모두 B0이었다. 탐색 포함 AB는 seed7 0→1→16, seed17 0→3→10으로 증가했지만 **전체 음 길이 유지까지 안정적으로 배운 것은 아니다.**

## 5. 엄지: 무엇을 확인했나

기존 전환 v2는 팔12+중지4축만 학습했다. **엄지5축은 초기각 유지여서 엄지를 독립적으로 굽혀 접촉하는 학습은 할 수 없었다.** 기본 전체33축 학습과는 다른 조건이다.

- 최종 두 seed×평균/확률×32회, 총128회에서 후면 거리 평균48.0~50.1mm였다.
- 후면10mm/3mm 이내 시간, 접촉 후보 시간, thumb3 후면 법선 합력은 모두0이었다.
- 엄지 안내 보상은 있었지만, 약0.005~0.006/에피소드의 먼 거리 기하 안내였고 접촉 성공 보상이 아니었다.

후속으로 다른100개 관절을 유지하고 엄지5축만 조절하는 기하 후보를 찾았다. CPU 계산의 간격은 약0.20mm였으나 실제 자유 기타에서 유한 제어로 재생하면 약5mm가 남았다. 실제 관측을 기준으로 두 번 더 보정해도 기존 판정의 접촉 후보는0초였고, 최소 간격 약2.71mm·후면 법선 합력 최대3.17N을 기록했다.

**힘이 관측된 것과 정해진 후면 패드의 접촉 조건을 만족한 것은 구분해야 한다.** 이 결과를 엄지 지지 성공이나 물리적 불가능으로 단정하지 않는다. 자유 기타 움직임, 선택 표본·안내 영역, 실제 충돌 형상과 판정의 관계를 추가 점검할 근거다. 현재 엄지21축 비교는 우선 제어 허용 여부만 바꾸고 보상을 한꺼번에 증폭하지 않는다.

근거: [엄지128회 분석](../압현성공/experiments/transition_diagnosis_v3/thumb_analysis.json), [실제 유한 제어](../압현성공/experiments/transition_diagnosis_v3/validation/thumb_native/report.json), [실제 관측 후 두 번 보정](../압현성공/experiments/transition_diagnosis_v3/validation/thumb_feedback/report.json).

## 7. 이후 계획: 손가락 전환에서 동시 압현·곡으로

현재 실험의 성능을 확인한 뒤 순서대로 범위를 넓힌다. 아래는 연구 로드맵이며 아직 실행·성공한 결과가 아니다.

| 순서 | 과제 | 먼저 시험할 범위 | 판단할 내용 |
|---|---|---|---|
|1|같은 손가락의 목표 전환 안정화|현재 중지6→7프렛, 이후 복귀7→6과다른줄/프렛|이전 음 유지→해제→새 목표 정렬→정시압현|
|2|다른 손가락으로 전환|검지↔중지 대표 쌍부터, 이후 약지·소지 포함|다음 손가락 준비와 이전 손가락 해제가 서로 방해하지 않는가|
|3|두 손가락 동시 압현|실현성 확인한 서로 다른 두 줄의 쉬운 운지부터|두 목표가 같은 시간에 각각 유효하고 오압현·충돌이 없는가|
|4|일부 유지·일부 전환|두 손가락 중 하나는 유지하고 다른 하나만 목표 변경|유지 음을 끊지 않고 독립 전환하는가|
|5|복합 운지와 짧은 구절|세 손가락 이상, 반복 운지, 여러 전환 간격|협응·대기 복귀·엄지 지지를 반복해 유지하는가|
|6|실제 곡|검증된 운지를 포함한 짧은 곡 구간부터 전곡으로|달성 음 수뿐 아니라 길이·시작·오압현·전환 품질이 유지되는가|

같은 줄의 서로 다른 프렛을 동시에 눌렀을 때 두 음을 동시에 낸 것으로 평가하지 않는다. 높은 프렛의 실제 음 우선 관계를 유지한다. 손가락별 독립 영상 네 개를 나란히 놓은 합성본도 동시 압현 실험의 근거가 아니다.

각 단계는 다음 순서로 진행한다.

1. 목표·운지·전환 시간이 물리적으로 가능한지 자유 기타의 유한 제어로 확인한다.
2. 대표 목표를 짧게 학습해 실패 위치를 찾는다. 모든 목표를 처음부터 장기 학습하지 않는다.
3. 한 번에 한 조건을 바꾸고 두 seed와 동일한 평가 분모로 비교한다.
4. 다른 목표·반대 전환 방향에서 재확인한 뒤 긴 학습과 복합 운지로 확장한다.
5. 결과 표·대표 손/전신 영상·진단을 남기고 의미가 확인된 조건만 기본값 반영 후보로 삼는다.

공통 기록은 음별 연속·누적 유지, 정시 시작, 이전 음 해제, 오압현, 패드 위치/방향/하중 탈락, 요청각/실제각, 손가락 간 충돌, 엄지 후면 간격/하중, 종료 원인, 보상 항별 값이다. 새로운 목표에서는 초기 자세부터 오압현·접촉이 없는지도 확인한다.
