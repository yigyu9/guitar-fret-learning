# 6→7프렛 전환 영상의 프렛 영역 표시

사용자가 지정한800회 최고모델 손 확대 영상 위에4~9프렛 셀과 숫자,6프렛(하늘색),7프렛(노랑),3번 줄 목표 구간을 표시했다. 물리 재실행·새 학습·프레임 보간·재생속도 변경은 없다.

원본과 실제 렌더 원본의 SHA가 같고, 렌더 당시 renderer/기타 manifest SHA도 현재와 같다. 저장된 매60Hz 실제 기타 몸체 자세 중 원본30fps와 동일한 끝점(row=2*(frame+1)-1)을 사용해 이동하는 기타에 표시를 붙였다. 카메라 위치·방향·55도 수평 시야각은 검증한 렌더 코드와 같다. 셀은 너트/프렛 실제 마커와 압현면 Gz=9.3mm를 사용한다.

실험 시각3~4.5초는6프렛,4.5~5.25초는 전환 구간,5.25~6.75초는7프렛 목표다. 이는 예정 목표 표시이며 개별 프레임의 실제 압현 성공 판정 표시가 아니다. 셀과 경계는 손에 가려져도 보이는 보조 겹침 표시이므로 물리 접촉·가림을 재렌더한 영상과 구분한다.

원본/제작 코드 SHA와 모든 프레임의 투영 좌표는 overlay_manifest.json, 검수용 이미지는 preview_104/142/172.png에 보존한다. 출력은 상위 동영상 디렉토리의 원본 이름에 _프렛영역표시를 덧붙였다.
