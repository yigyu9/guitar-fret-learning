# 실제 시뮬레이션 환경 영상

완료된 검지–중지/표준3·2번 줄/6·6프렛 pilot의20업데이트 최종 모델을 실제 GPU PhysX 환경에서 결정론적으로 다시 실행했다. 사용자가 요청한 실제 환경 영상은 아래 두 파일이다. 앞선 그래프 영상은 보조 측정 시각화이며 이 촬영 결과와 구분한다.

- [손 확대 원본](../../video/인접2지_실제시뮬_손확대_v1.mp4)
- [전신 원본](../../video/인접2지_실제시뮬_전신_v1.mp4)

두 영상 모두1280×720·30fps·165프레임·실시간5.5초다. 공식 native 카메라가 실제 시뮬레이션을 실행하는 동안 촬영한 원본이다. 보간·반복·속도 변경·구간 선별·영상 합성은 없다. 손가락 색상은 검지 파랑, 중지 초록, 약지 주황, 소지 보라, 엄지 빨강이다.

## 관측 결과

사전 지정한1환경의 최초1에피소드를 촬영했다. 입력된 두 목표의 공통[3.30,4.80]초1.5초 창을 모두 관측했으나 동시clean0초·개별두목표달성false/false였다. unsafe0초·full_safe=true이고 물리 실패는 없었다. 따라서 동시 압현 성공 영상이 아니라 현재 모델의 실제 미달성 동작 영상이다. 이는 정식32환경 평가나 물리적 불가능의 증거가 아니다. 현 접촉 합력·표면 기하 기준과 실제 현 압력·음향 성공도 구분한다.

추가 학습은0업데이트다. 원래 render_finger_skill.render와 PairEnvironment 공식 hook을 사용했고 metadata·575개 입력pin·trainer.load 검증을 유지했다. 모델 가중치/버퍼 불변, 기존 보상·PD·관절/힘 범위·물리 유지, 장면 정상 종료와 lifecycle 검증을 모두 통과했다.

촬영 중 실제240Hz 물리와60Hz 정책 행동을 수행했다. 저장된330개 제어 끝점의 physics_step은4,8,…,1320으로 연속이며 두 카메라의 프레임n은제어끝점2(n+1)에 대응한다. 대표4초 프레임에서 손·기타·전신을 확인했다. [손 프레임](hand_4s.png), [전신 프레임](fullbody_4s.png).

## 기존 검사와 원본 보호

촬영 실행기 전체 약73.35초, 실제 renderer 약68.22초였다. 같은GPU에서 기존 검사를 중단하지 않고 수행했으며 시작106완료→종료107완료였다. 새 비교가능1건67.657초/기준중앙값63.766초로비율1.061(+6.10%)이고 새 검사 오류는 없었다. 비교 목표·준비/CPU비용·부분겹침이 달라 인과 효과를 단정하지 않는다. 이1회 결과가 이전42%지연으로 보류한 병행 확대를 취소하지 않으며4환경시험이나정식병행학습은 재개하지 않았다.

촬영 이후 정식6과제 대기열은 기존336검사완료와GPU유휴를 기다리는 상태를 유지한다. 기존 단일 검사·정식 대기열·봉인소스/입력/모델에는 쓰기나중단을 하지 않았다. queue_v1의548pins,queue_v2의553pins,parallel_v1의571pins,후속정식명세556pins,새촬영명세575pins 모두불변이다.

python -B docs/2026-11-02/압현실험/다중압현/도구/native_video_v1.py
