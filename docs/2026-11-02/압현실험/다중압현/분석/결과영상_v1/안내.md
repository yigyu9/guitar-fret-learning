# 결과 영상 안내

[대표 MP4](../../video/인접2지_실제학습기록_v1.mp4), [대표 프레임](대표프레임.png), [출력 검증](../../로그/결과영상_v1/report.json).

이 영상은 학습 중 환경0의 첫 완료 에피소드(5.35초)를0.5배속으로 보여주는 실제 측정 기록의 시각화다. 앞2초 안내와뒤3초 결과를 더해15.708초·1280×720·24fps·377프레임이다. 카메라 촬영·전신 동작·최종20업데이트 모델의 결정론적 물리 재생 영상은 아니다. 학습 중 해당 에피소드는최종업데이트보다앞서수집됐다. 영상에 전체학습예산20업데이트·1,280전이를표시하지만표시된에피소드가최종정책평가를뜻하지않는다.

원본 finger_control_trace.jsonl.gz의환경0/episode0,240Hz연속1,284표본을사용했다. 원시321정책tick×4와일치한다. 관절그래프는검지·중지MCP/PIP/DIP의첫실제표본대비실제각도변화이고, 거리그래프는패드와목표구간의기하거리다. 거리없는구간은결측으로보존했다. 현재커서는가장최근의실제표본에대응하고보간은없다. 전체궤적을미리보이는그래프이며카메라화면이아니다.

공통창[3.30,4.80]초에패드거리는대략5cm이며굽힘관절변화도작았다. 학습중완료2에피소드의동시성공0/2는원시job report를그대로표시했다. 실제현압력·음향판정이나물리적불가능의증거로해석하지않는다.

CPU만사용했다. 기존GPU단일검사·정식학습대기열·봉인소스·입력·모델은수정하지않았다. checkpointSHA를원시job report와대조했고trace/report/episodes/checkpoint/renderer의전후SHA불변을확인했다. 출력길이·프레임수·해상도·프레임대응을기계검사하고대표프레임의한글·축·상태문구배치를눈으로확인했다.

재생성도구는도구/render_training_record_v1.py이며이미출력이있으면중복실행하지않는다. 영상만video에보관하고도구·보고·대표이미지는분리했다.
