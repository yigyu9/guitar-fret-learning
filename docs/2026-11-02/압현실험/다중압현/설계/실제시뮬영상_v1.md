# 실제 시뮬레이션 촬영 v1

사용자의 실제 시뮬레이션 영상 요청에 따라 완료된2환경20업데이트pilot final.pt를그대로평가하고native손/전신카메라를촬영한다. 앞선그래프영상은이요청의결과물이아니었다.

- [x] 기존단일검사·GPU·원본571개pin·checkpointSHA확인.
- [x] 기존native render_finger_skill.render와공식PairEnvironment hook을사용하는독립wrapper작성·검토. 원래metadata/pins/trainer.load를그대로통과한다.
- [x] 기존승인된짧은병행범위안에서1환경·최초1에피소드만촬영. 학습업데이트0·결정론적정책·실제240Hz물리/60Hz행동·30fps카메라. 5.5초상한과별도실행시간상한을둔다.
- [x] 기존single identity/여유4GiB를실행전확인. 실행중2GiB미만·새검사오류·50%이상지연·실행시간상한이면새촬영프로세스그룹만종료. 4환경시험/정식병행학습을재개하지않고기존대기열은그대로둔다.
- [x] 실제render완료·lifecycle·policy/입력불변·실제성공/실패·카메라프레임/메타데이터확인. 손과전신대표원본을video에저장,도구/npz/로그/분석은별도.

최종20업데이트모델의별도1회시각검사다. 최초32환경정식평가나성공영상선별이아니며실패도그대로제공한다. 예상준비/검토5~10분,실제native촬영1~3분. 같은GPU인기존검사에일시적부하가능성이있어영향을기록한다.
