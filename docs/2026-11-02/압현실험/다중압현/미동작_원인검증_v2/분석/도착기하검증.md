# 실제 도착 상태의 두 손가락 기하 검증

2026-11-02. **현재 촬영된 실제 팔·손목을 고정해도 검지·중지 8축만 움직여 두 목표에 함께 접근하는 FK 후보를 찾았다.** 따라서 이번 20업데이트 모델의 미동작을 이 도착 자세의 손가락 가동범위 부족으로 설명할 근거는 없다. 이 후보는 충돌·하중·관절 추종·실제 동시 압현 성공을 검증한 결과가 아니다.

## 원시 자료와 신원 검증

- 자료: `다중압현/로그/실제시뮬영상_v1/capture/poses_env0000.npz`와 같은 폴더의 metadata, training contract, episode, settings, report, 입력 SHA 목록.
- 영상에서 선택된 env0 첫 에피소드의 t=3.30초, control endpoint 198, physics step 792, 원시 배열 index 197을 사용했다. 가장 성능 좋은 순간을 재선택하지 않았다.
- 관절 105개 및 human 66 + guitar 39 + chair 1 = 106개 몸체의 이름·순서가 준비 계약과 정확히 일치하는지 확인했다. 논리 기타 표식은 원시 캡처의 기타 강체에 연동된 표식이며 별도의 39개 물리 강체로 해석하지 않는다.
- 원시 xyz / xyzw / 선속도 / 각속도의 13개 성분을 순서대로 보존했다. q와 DOF state의 pos 일치, 모든 실제 몸체·단위 quaternion, 60Hz endpoint와 240Hz 물리 step의 일치를 검사했다.
- 실제 canonical 목표는 `event-000000/string-3/note-0` = 검지·표준3번줄·6프렛, `event-000001/string-2/note-1` = 중지·표준2번줄·6프렛이다.
- 엄격한 기존 `multi_press.arrival.v1` 입력으로 `입력/arrival_native_t3p30.json`, `입력/arrival_case.json`을 새로 작성했다. 실제 시뮬레이터에 재주입하지 않았다.

실제 q 및 몸체 상태로 기존 `CommonPose`/`full_fk`를 보정한 뒤 모든 실제 사람 몸체를 재현했다. 최대 위치 오차는 2.67e-16m, 최대 회전 오차는 8.84e-16rad였다. 이는 그 실제 기준점의 재현 검사다. 큰 관절 변화 뒤에도 native 동역학이 동일하게 실현된다는 증거로 확대하지 않는다.

거리는 현재 실제 압현면에 투영된 현의 프렛 셀에서 양쪽 2mm를 제외한 유한 선분과, 담당 손가락의 유효 끝마디 패드 표본 사이 최근접 거리다. 기존 `contact.pad_target_geometry`를 CPU에서 실행한 값과 1e-12m 허용오차로 일치했다. 단순 손끝 원점 거리를 대신 사용하지 않았다.

8축 탐색은 실제 팔·다른 손가락·오른손·몸통·하체 97개 관절을 고정했다. 실제 q에서 시작해 `max_nfev=60` 중 38회 평가로 두 목표 후보를 얻었다. 검지 14개·중지 20개 패드 표본이 기존 CommonPose의 위치·법선·유일한 최근접 현 기준을 만족했다. 선택 표본의 법선 cosine은 각각 약 0.942, 0.943이다. 목표 중심 잔차 최소화를 위해 지정한 높이는 압현면 아래 0.5mm이며, 기존 후보 허용 범위 [-1,3]mm 안이다. 접촉력이나 관통 해소를 계산한 것은 아니다.

20축 공동 탐색은 8축 결과를 warm start로 사용했고 2회 평가로 같은 후보를 유지했다. 따라서 새로운 팔 자세가 필요하다는 결과도, 새로운 독립 팔 자세를 광범위하게 찾았다는 결과도 아니다. **이 기록의 실제 공통 팔 자세에서 손가락 굽힘과 벌림만으로 기하 접근이 가능하다는 유한 후보**다.

## 현재 탐색 폭과 필요한 명령의 차이

캡처된 20업데이트 체크포인트의 담당 8개 latent 표준편차는 0.049784~0.049820로 거의 초기 0.049787 수준이다. 다음 수치는 실제 관절에서 후보까지의 변화와 현재 기록 행동에서 후보 직접 위치 행동까지의 latent 차이를 함께 나타낸다.

| 관절 | 실제→후보 Δrad | 후보 정규화 행동 | 기록 행동 대비 latent 차이 / 현재 σ |
| --- | ---: | ---: | ---: |
| 검지 MCP 굽힘 index1_x | +0.6231 | +0.5759 | 13.21 |
| 검지 MCP 벌림 index1_z | +0.2501 | +0.8244 | 23.51 |
| 검지 PIP index2 | +0.1815 | +0.2450 | 5.03 |
| 검지 DIP index3 | +0.0602 | +0.0452 | 0.93 |
| 중지 MCP 굽힘 middle1_x | +0.5577 | +0.5025 | 11.11 |
| 중지 MCP 벌림 middle1_z | -0.5647 | -0.8745 | 27.14 |
| 중지 PIP middle2 | +0.1802 | +0.3331 | 6.90 |

모든 후보값은 현행 관절·행동 범위 안이다. σ는 축별 분포상의 거리 비교이며 동시 성공 확률, 시간에 걸친 경로 확률, 필요한 최종 정책평균 변화량의 유일한 해로 해석하지 않는다. 작은 평균 주변의 K1 독립 탐색이 이 특정 후보처럼 큰 굽힘·벌림을 우연히 함께 발견하기 어렵다는 가설과 양립한다. 이 후보가 유일한 방법이거나 기존 보상만으로 학습할 수 없다는 증거는 아니다.

## 개선안과 확인 범위

1. 먼저 별도 native 진단에서 실제 도착 상태를 다시 측정하고 손가락 목표를 재계산한다. 부드러운 요청 → 유지 → 복귀에서 관절 실제 변위·추종·오압현·안전·두 목표 동시 clean을 관찰한다. 기존 촬영 상태나 후보 q를 물리 상태에 덮어쓰지 않는다.
2. native에서 목표각 접근이 확인되면, 기존 제어·물리·범위를 유지한 별도 학습 실험에서 접근 후보를 참고하는 초기 정책 또는 명시적인 진단 교사 자료를 검토할 수 있다. 이는 현재 모델·보상·대기 정식 학습의 변경 승인이 아니다.
3. 초기 탐색 폭만 크게 만드는 안은 실제 목표 방향·접촉 신호·추종 검증과 분리해 비교해야 한다. 이번 CPU 결과만으로 무작위 std 증가가 개선이라고 선언하지 않는다.
