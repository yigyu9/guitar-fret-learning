# 손가락 미동작 검증 결과와 개선 방향

**손목 단계에서 멈춘 것도, 손가락 구동이 잠긴 것도 아니었다. 현재 파일럿 정책이 거의0인 평균 명령을 내고 있었다. 같은 물리·제어기에 충분한 목표각을 요청하자 두 손가락이 실제로 약15도 움직였다.** 원시 기록과 코드를 CPU에서 대조하고 별도1환경 native 구동 검사를 실행해 확인했다.

## 실제 구동 비교

새실험은정책평가가아니라구동기진단이다. 처음0.5초기준유지→검지MCP/PIP/DIP각15도smoothramp→중지동일ramp→둘유지→기준복귀의5.5초다. 상태재주입은시작전preparedreset뿐이며움직이는동안관절·몸체상태를덮어쓰지않았다. 4rad/s원래속도상한보다작은최대약0.491rad/s의요청을사용했다. 팔행동12축은0이다.

## 왜 평균 명령이 작게 남았는가

직접원인은작은평균명령이며,그배경에서다음병목을정량확인했다. 이들중어느요인이실패를유발한비율인지는아직대조학습으로분리하지않았다.

1. **아주짧은학습예산.** 환경당640tick/10.667초다. 완료에피소드는총2개이고다음에피소드의환경당319tick도PPO에사용됐다. 업데이트를했지만압현행동을습득하기에충분한예산이라고검증된것은아니다.
2. **작고빠르게반전하는독립위치탐색.** 학습행동std약0.05,lag1상관약−0.059~0.074,부호반전약50%였다. 위치요청이므로증분이누적되지않는다. 실제팔고정기하후보는최대0.6231rad(35.7도)의큰굽힘과벌림이필요했다. 특정후보까지의축별latent차이가현재std의약11~27배인축도있다. 이것이유일한해이거나전체도달확률이라는주장은아니다.
3. **초기준비신호시간차.** 일반목표는처음부터관측하지만자기tracking목표는1초부터이고접근가중치는2.55초까지0,2.55~2.65초fade다. 그동안담당손가락대기자세보상이유지된다. 초기접근을학습시키는신호를늦출수있는구조는확인됐으나이파일럿하나로보상결함이라고단정하지않는다.
4. **접촉성공신호미발견.** 20업데이트전체접촉/clean/개별달성보상이모두0이다. 접근potential등다른신호는있었다. 음수접근보상합계를그대로거리가멀어진증거로해석하지않는다.

## 어떻게 개선할 것인가

우선힘·PD·가동범위를키울필요성을뒷받침하는증거는없다. **실제도착상태에서두손가락목표각을찾아일관된접근경로를물리로확인한뒤그자료로정책초기접근학습을돕는것을우선한다.** 고정팔기하후보는확보했고,작은명령보다큰연속목표각이실제구동되는것까지확인했다. 이제목표별벌림을포함한실제접촉경로검증이남았다.

학습에서는원래설정기준선과동일예산으로(1)검증된교사초기화만추가,(2)기존natural_preparation E4를별도fresh조건으로쓴초기신호개선을나눠비교한다. E4가효과있을때E1/E2/E3를분해해어떤요소가기여했는지확인한다. **학습시간·std·학습률을크게늘리기만하면해결된다는결론은내리지않는다.** [구체적인조건·예산·성공기준](../설계/개선비교안.md).

이번에검증된개선은진단명령으로구동과목표접근이실제로발생한다는점이다. 개선된학습정책의동시압현성공은아직검증하지않았다. 원래6과제정식대기열은그대로보존하며새학습조건을암묵추가하지않았다.
