# 개선 순서와 대조 실험안

## 우선할 개선

현 제어기와 물리는 15도 굽힘에 실제로 응답했다. 힘 상한·PD·관절 범위를 늘려 미동작을 해결할 근거는 없다. 우선 **목표 방향으로 충분한 각도를 유지하는 접근 경로를 실제 물리에서 검증한 후, 정책이 그 경로를 학습하도록 초기 학습 신호를 개선**한다. 현재 작은 평균 정책의 장시간 반복을 굽힘 증분으로 바꾸지 않는다.

1. 실제 초기 자세에서 공통 팔 자세에 도착한 뒤 q/몸체 상태로 FK를 다시 맞춘다. 이번 CPU8축 후보는 다음 실행의 검색 seed일 뿐이며, 과거 q나몸체 상태를 시뮬레이터에 주입하지 않는다.
2. 담당 손가락 MCP 굽힘뿐 아니라 벌림도 포함해 두 목표에 접근하는 각도를 재탐색한다. 실제 목표각을 부드럽게 요청하고 공통1.5초 clean, 관절 추종·오압현·안전을 측정한다. 이번15도MCP/PIP/DIP pulse는 구동 응답 검사이며 이8축 후보의 물리 재생이 아니다.
3. 위 접근·접촉 경로가 확인되면 해당 조건의 실제 관측/행동 자료를 별도 진단 교사로 만들고 새 정책 초기화와 무초기화 대조를 검토한다. 기하 후보나15도구동 영상만을 성공 교사로 쓰지 않는다. 단일12프렛 성공을 이번6프렛 두 목표에 상속하지 않는다.

## 학습 신호를 분리하는 비교

| 조건 | 초기화/신호 | 분리할 질문 |
|---|---|---|
| B0 | 현행J33·K1·현행준비보상, fresh | 원래설정의충분한예산기준선 |
| B1 | 같은정책·제어·물리, native검증교사초기화만추가 | 목표방향초기탐색의부족을줄이는가 |
| B2 | fresh정책, 별도PairEnvironment subclass에서기존natural_preparation.v3 E4 | 초기자기목표/대기보상/접근potential시간차를정리하면향상되는가 |

B1은 성공 교사 경로가 확보된 뒤에만 실행한다. B2는 활성 소스를 편집하지 않고 기존 E0~E4 hook의 별도 조건으로 만든다. reward/input 계약이 달라지므로 기존 체크포인트를 암묵 재개하지 않고 새 source pins·출력·초기 모델을 기록한다. E4가 효과 있으면 E1(자기 목표 조기 노출), E2(담당 손가락 초기 대기 보상 해제), E3(hover 접근potential)를 나눠 어떤 요소가 기여했는지 비교한다. E2만 적용해도 접근 가중치가 조기에 켜지는 것은 아니다.

첫 비교는 검지–중지/3·2번줄/6·6프렛 한 과제에 한정한다. 입력 목표·3초pre-roll·공통평가창[3.30,4.80]·안전·물리·PD·힘·범위·직접 위치 codec은 일치시킨다. 예산은 원래 정식 기준과 같은64환경/H32/100업데이트(과제당204,800전이), 같은 seed7로 pilot를 맞춘 뒤 여러seed에서 확인한다. B0의20업데이트2환경 결과와 B2의100업데이트64환경 결과를 보상 변경의 인과 비교로 쓰지 않는다.

학습량 효과는 B0와같은설정에서20/100업데이트를동일환경수로별도비교한다. 업데이트수만맞추고전이/완료에피소드/목표노출이달라진비교를피한다. 완료에피소드뿐아니라PPO에들어간partial에피소드도예산에포함한다.

현재 정식6과제 대기열은 B0기준선으로 보존한다. 새로운 B1/B2실행기를 자동으로 추가하거나 기존 큐·모델·소스를 교체하지 않았다. 장시간같은GPU병행확대는보류상태를유지한다. 기존단일검사완료후새조건의구체적입력/계약과검토를확정한뒤실행한다.

## 평가와 중단 기준

평가의 주요결과는 최종정책의결정론적32환경·최초1에피소드에서두목표의공통1.5초전체clean이다. 개별달성/동시유지/실패·불완전/검사오류를분리한다. 부차지표는평균정책의명령크기, 실제굽힘·벌림, 목표거리감소, 최초접촉발견시각,안전·오압현이다. 큰움직임만생겨도압현성공으로집계하지않는다.

같은예산에서도평균행동이0근처이고contact신호가0이면그상태를기록하고조건을추가한다. 성공장면선별·무제한재시도·힘/범위/PD임의변경은하지않는다.

시간 상관이 있는 탐색도 후속 후보지만 현재 K1독립Gaussian likelihood와 다르다. 행동을몇tick임의고정하면서원래PPO확률을그대로쓰는방식은사용하지않는다. 별도수집/확률/재개계약부터설계해야하므로,검증된목표방향자료와초기신호조건을우선한다. std나학습률만크게키우는수정은확인된개선안이아니다.
