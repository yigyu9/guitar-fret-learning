# 손가락 미동작 원인 검증과 개선 v2

2026-11-02. 사용자가 원인 검증과 개선 방법을 요청했다. 기존단일검사·활성학습·봉인소스/입력/모델·정식대기열은수정하지않는다. 원인분석은관측된사실·재계산검증·가설을구분한다.

## 가정과 범위

현재20업데이트모델의행동평균이작은것은확인했다. 이제왜작은지와실제구동능력을분리한다. 20업데이트모델을학습성공으로취급하지않고, 단순증량이개선을보장한다고가정하지않는다. 원래J33정책/보상/관절범위/힘/PD/물리는그대로유지한다. 개선안은별도후속실험으로제안하고현재대기정식학습을암묵교체하지않는다.

1. [x] CPU: 목표노출·보상/접촉신호·학습갱신·초기/최종모델·탐색과시간상관을대조. 검증:원시로그/체크포인트재계산과입력SHA불변.
2. [x] CPU: 실제도착팔상태에서의두손가락FK/목표거리·가동범위·현재/필요명령차이를평가. 검증:실제기록FK대조후유한후보탐색,미확보를불가능으로단정하지않음.
3. [x] native: 필요시1환경의짧은진단목표각펄스로두손가락의실제구동응답을확인. 검증:초기상태에서부드러운요청→유지→복귀,관절변위/추종/안전/목표거리기록. 정책학습성공으로주장하지않음.
4. [x] CPU/필요시실제물리: 개선전후조건을명시하고결과분류·한계·다음실행명령을저장. 구현독립검토·적절한회귀검증·모든봉인SHA재확인.

예상CPU검증15~30분,필요한1회native10초이하물리/실행1~3분,검토/정리5~10분. 현재GPU1대는기존단일검사사용중이므로기존승인범위의짧은1환경진단만가드하에실행한다.4환경확대·장시간병행학습은없다.여유4GiB전제,실행중2GiB미만/검사오류/50%이상지연/실행시간상한이면이진단자식그룹만종료한다.

성공기준은(1)직접원인과근거있는학습병목을분리,(2)구동응답의유무를정량화,(3)최소한의구체적개선안과검증된범위/미확인범위를명시하는것이다. 활성보상/PD/힘/범위를바꿔움직임만키우는것은개선검증으로취급하지않는다.
