# 목표 접근 개선의 실제 물리 결과

2026-11-02. 검지·3번 줄·6프렛과 중지·2번 줄·6프렛을 동시에 검사했다. 첫 nominal 조건 한 번에서 공통 음 구간 1.5초 전체의 동시 clean을 확인했다. **진단용 목표각 제어의 성공이며 학습 정책의 성공은 아니다.** 다른 손가락·프렛 조합이나 전환으로 성공을 확장하지 않는다.

## 무엇을 바꿨는가

기존 짧은 학습 정책은 평균 행동이 거의 0이어서 손가락 이동도 약 0.1°에 머물렀다. 준비 단계가 다음 단계로 넘어가지 못한 상태는 아니었다. 기존 제어·물리 설정을 유지한 새 진단에서, 공통 v9 상태를 실제 물리로 0.5초 진행한 뒤 당시 관절·몸체·기타 상태를 읽었다. 이 상태에서 팔을 고정한 공통 기하 모델로 검지·중지 8축을 함께 탐색했다. 0.5~2.5초에 부드럽게 굽히고 4.85초까지 유지한 뒤 풀었다. 에피소드 도중 관절·몸체 상태를 재주입하지 않았다.

관절 이동과 기존 재료점 운동 분해는 손가락 굽힘으로 접근했음을 뒷받침한다. 손목의 작은 변위만으로 접촉 힘의 기여도를 계산하지는 않는다. 목표 유지 구간에서 요청 각도와 실제 각도의 차이는 축별 RMS 약 1.25~20.40°였고, 특히 검지·중지의 첫 옆굽힘 축은 12.02°·20.40°였다. 실제 제어 목표와 요청 목표는 같았으므로 단순 목표 잘림으로 설명되지 않는다. 접촉 성공이 기하 후보의 정확한 각도 추종을 뜻하지 않는다. 기록은 `goal_nominal_v1/evidence_audit.json`에 저장했다.

성공 기준은 담당 손가락 말단 표면 기하와 몸체 접촉 합력이다. 개별 현의 압력, 접촉 상대, 진동·소리는 측정하지 않았으므로 실제 음향 성공으로 해석하지 않는다. 1회 재현은 정적 두 손가락 한 조합의 초기 근거다.
