# 손가락 미동작 개선 결과

검지·3번 줄·6프렛과 중지·2번 줄·6프렛에서, **교사 동작을 학습한 새 정책이 실제 물리에서 스스로 손가락을 움직여 1.5초 동시 clean을 유지했다.** 고정한 400 step 최종 모델의 첫 결정론적 평가 1회 결과다. 긴 PPO 학습, 다른 조합 일반화, 현 압력·음향 성공은 아직 검증하지 않았다.

## 원인과 개선

이전 2환경·20업데이트 정책도 5.5초 에피소드를 완주했고 실제 팔로우 제어가 동작했다. 손목 준비 단계에서 다음 단계로 넘어가지 못한 문제는 아니었다. 평균 행동이 거의 0이어서 실제 손가락 이동도 약 0.1°에 머물렀다. 물리 제어는 같은 설정의 15° 요청에서 실제 약 15° 움직였다. 따라서 이번 개선은 PD·힘·관절 범위를 바꾸는 대신 목표까지 가는 동작을 정책에 제공하는 데 집중했다.

1. 같은 초기 자세에서 실제 0.5초 도착 상태를 읽고 공통 팔 아래 검지·중지 8축 목표를 함께 계산했다. 부드러운 접근·유지·해제 동안 중간 상태 재주입은 없었다. 첫 진단 조건에서 두 목표가 1.5초 함께 clean이었다.
2. 이 실제 성공 경로의 행동 직전 관측 330행과 실행 행동으로 fresh 정책의 actor만 CPU에서 400 step 학습했다. 기존 정책 가중치, std·critic, PPO optimizer·RNG는 가져오지 않았다.
3. 새 actor를 전체 E0 계약이 정확히 맞는 실제 시뮬레이터에서 평가했다. 실행 중에는 매 tick 관측→정책 결정→물리 계산만 수행했다. FK 목표 탐색이나 교사 행동의 시간표 재생은 사용하지 않았다.

## 보호한 실험과 남은 작업

기존 단일336 검사의 소스·입력·모델·출력·실행 상태를 바꾸거나 중단하지 않았다. 기존 정식 6과제 큐도 그대로 대기한다. 새 단기 검사들은 전용 프로세스 그룹으로 실행했고 종료했다. 두 번째 정책 검사 동안 기존 작업의 비교 가능한 완료 표본이 없어서 지연 비율은 **미측정**이다. 이를 0% 지연으로 간주하지 않고 추가 병행 검사는 진행하지 않는다.

별도 E4 초기 접근 신호 조건 B2의 100업데이트/64환경 학습과 최초 32에피소드 평가는 독립 검토·봉인 후 대기 큐로 가동했다. 기존 단일 검사와 기존 정식 6과제 큐의 완료, GPU 유휴를 모두 확인한 뒤 시작한다. 아직 장시간 PPO 학습 성능을 보고할 수 없다. 한 과제·한 seed·한 결정론적 초기 상태의 성공은 반복·교란·인접 프렛·다른 손가락 조합으로 일반화하지 않는다. 전환·세 손가락 확장은 이 정적 정책의 재현 범위를 확인한 후 진행한다.

전체 신규 CPU 검사 35개가 통과했고 독립 검토를 거쳤다. 현재 접촉 기준은 표면 기하와 몸체 접촉 합력이며, 현별 압력·진동·소리는 측정하지 않았다.
