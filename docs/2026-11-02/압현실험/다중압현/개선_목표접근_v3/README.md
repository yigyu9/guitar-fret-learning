# 손가락 목표 접근·학습 개선 v3

검지·3번 줄·6프렛과 중지·2번 줄·6프렛에서 진단 제어에 이어 **학습한 새 정책도 1.5초 동시 clean**을 확인했다. 자율 정책의 손가락 첫 굽힘 관절은 약 40°·39° 움직였다. 기존 20업데이트 정책의 미동작은 구동 불능이나 손목 단계 정지로 설명되지 않는다.

## 진단 동작의 실제 시뮬레이션 영상

[손확대](../video/두손가락_목표접근_동시성공_v3_손확대.mp4) · [전신](../video/두손가락_목표접근_동시성공_v3_전신.mp4). 각 5.5초·165프레임의 native 카메라 촬영이다. 이 영상은 진단 목표각 제어이며 학습 정책의 영상과 구분한다.

## 진행 범위

기존 단일 336검사, 기존 6과제 학습 큐, 원래 봉인 소스·입력·모델과 활성 제어·물리는 보존한다. 짧은 새 진단만 자원·지연 가드 아래 실행했다. B2의 장시간 GPU 학습은 기존 검사와 정식 큐가 끝난 뒤 실행되도록 별도 대기 중이다.

성공은 현재 접촉 합력·표면 기하 기준이다. 개별 현 압력이나 소리는 측정하지 않았다. 한 조합의 정적 성공을 다른 조합·전환·세 손가락의 성공으로 상속하지 않는다.
