# 다중 압현 연구

## 현재 결과: 학습 정책 개선 v3

검지·3번 줄·6프렛과 중지·2번 줄·6프렛에서 **CPU 교사 초기화로 학습한 새 정책이 실제 1.5초 동시 clean을 유지**했다. 진단 성공 경로로 actor만 학습한 뒤 첫 자율 평가에서 확인했다. 한 조합·한 상태의 초기 결과이며 긴 PPO 학습·일반화·음향 성공과 구분한다.

[개선 정책의 실제 결과·한계](개선_목표접근_v3/분석/개선결과.md) · [새 실행 계획](개선_목표접근_v3/설계/실행계획.md) · [학습 정책 손확대](video/두손가락_학습정책_B1_v3_손확대.mp4) · [전신](video/두손가락_학습정책_B1_v3_전신.mp4)

확인된 경로를 사용하는 CPU 교사 초기화 B1은 학습·실제 평가를 완료했다. 초기 목표 접근 신호 E4의 별도 학습 B2도 준비했다. B2 대기 큐는 기존 단일 검사·기존 정식 6과제 큐가 끝난 뒤 GPU 유휴에서 실행되도록 가동했다. 세부 상태는 v3 기록을 따른다.

## 이전 단계의 기록

아래의 “아직 미확인”은 해당 v1/v2 당시 결과다. 실제 물리 성공 여부의 최신 판정은 위 v3 결과를 따른다.

[손가락 미동작 원인 검증·개선 방향](미동작_원인검증_v2/분석/종합결과.md): 같은물리에서15도요청→실제약15도구동/복귀를확인했다. 정책의작은평균명령과구동능력을분리했으며동시압현성공은아직미확인이다.

[실제 시뮬레이션 손 확대 영상](video/인접2지_실제시뮬_손확대_v1.mp4) · [전신 영상](video/인접2지_실제시뮬_전신_v1.mp4). 20업데이트 모델의 실제1회 재실행이며 동시 clean0/1.5초다.

정책 학습 전에 **공통 팔 자세에서 두 손가락의 동시 압현**을 찾는다. 단일 압현 성공은 후보 선택 참고이며 동시 성공으로 상속하지 않는다. CPU 감사·탐색·측정기 검증 및 독립 검토를 완료했다. 8/8개 기하 후보, 새16개 CPU 검사 통과. 이 공통 자세 진단의 실제 물리 검사는 아직 실행하지 않았고 native 실행기·충돌/경로 검증이 남아 있다. 별도 정책 학습의 실제 촬영 결과는 위 영상 링크를 따른다.

[현재 결과·제한·다음 명령](분석/진행상황.md) · [성공 기준과 예상 시간](설계/연구계획.md) · [독립 검토](분석/독립검토.md)

후속 정책 학습 요청: [인접 두 손가락 6과제 학습](학습_인접2지_v1/README.md). 새 학습 대기 실행기를 가동했으며 기존 단일 검사 완료와 GPU 유휴를 확인한 뒤 순차 실행한다. 2환경20업데이트 병행 학습을 완료했으나 기존 검사 지연으로 확대를 보류했다. 현재 정식 학습 진행은 해당 연구의 로그/queue_after_parallel_v1/state.json을 따른다.

[실제 학습 기록 대표 영상](video/인접2지_실제학습기록_v1.mp4) · [영상의 범위와 검증](분석/결과영상_v1/안내.md). 관절·거리 기록의 시각화이며 카메라 촬영이나 최종 정책의 전신 재생 영상은 아니다.

- `설계/연구계획.md`: 범위, 성공 기준, 시간 추정, 단계별 체크리스트
- `설계/cases.json`: 같은 프렛 → 인접 프렛 → 두 프렛 간격의 8개 대표 목표
- `도구/`: CPU 공통 자세 탐색기, 240Hz 동시 유지 측정기, 회귀검사
- `입력/`: 읽은 단일 검사 상태 사본·SHA, 보호 대상 SHA, 실제 도착 상태의 입력 계약
- `로그/`: CPU 실행과 검사 결과. 합성 검증을 물리 결과와 구분
- `분석/코드검토.md`: 관측·접촉·오압현·원장의 현행 동작
- `분석/진행상황.md`: 결과, 제한, 다음 명령
- `video/`: 대표 영상만 저장. 측정 기록 시각화와 실제 native 카메라 영상의 범위를 구분

기존 단일 검사·활성 학습 코드·봉인 자료를 수정하지 않는다. 이 디렉토리의 CPU 도구는 Isaac Gym 장면이나 CUDA를 생성하지 않는다. CPU 기하 후보에는 접촉 하중·동역학·음향 성공을 부여하지 않는다.
