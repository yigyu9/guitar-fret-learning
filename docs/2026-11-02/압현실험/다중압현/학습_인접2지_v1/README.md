정식 학습은 medium/64환경/H32/100업데이트/seed7, 과제별 결정론적 32환경 최초 에피소드 평가다. 현행 J33 보상·제어·물리·관절 범위·힘 상한을 유지하고 별도 240Hz 동시 유지 지표만 추가했다. 짧은 병행 학습 중 완료된 2에피소드의 동시 성공은 0건이며, 정식32환경 최종 정책 고정 평가는 아직 수행하지 않았다. 별도1환경 native 촬영 평가에서는 동시clean0/1.5초·개별달성false/false를 확인했다.

기존 입력기의 검증을 유지하기 위해 음 시작은 60ms 차이가 있다. 두 음 모두가 활성인 [3.30,4.80]초 1.5초 전체를 함께 유지하는지 평가하며 정확한 동시 발음·실제 현 압력·음향 성공을 주장하지 않는다.

현재 대기 실행기는 PID2297852다. 기존 단일 336검사 완료와 해당 GPU compute 프로세스 종료를 모두 확인한 후 정식 작업을 순차 실행한다. 채팅이 끝나도 호스트와 실행기가 유지되면 계속 대기한다. 호스트 종료·프로세스 종료·입력 변경 시에는 계속된다고 보장하지 않는다. 검사 오류나 무결성 실패는 원시 로그를 남기고 자동 재시도 없이 중단한다. 이전 queue_v2 대기 실행기는 승인된 병행 시험 전 종료했고 새 대기열로 대체했다.
