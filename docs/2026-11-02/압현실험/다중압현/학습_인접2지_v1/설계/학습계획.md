## 범위와 해석

"하나 떨어진 프렛"은 이번1차에서1프렛 차이(6/7프렛)로 해석한다. 인접 손가락은 검지–중지, 중지–약지, 약지–소지이며, 표준3번/2번 줄(인접한 G/B현)에 각각 하나의 목표를 배정한다. 각 손가락 쌍의6/6프렛과6/7프렛으로 총6과제다. 바레·동일 줄 복수 목표·전환은 제외한다. 이 대표6과제의 결과를 모든 줄·프렛의 일반화로 해석하지 않는다.

## 실험과 성공 기준

각 과제는 공통 v9에서 새 정책을 만들고 현행 J33 공동 제어로 학습한다. 팔·손목 이동과 두 손가락 접근을 포함한 정책 시도이며, 사전 기하/단일 성공을 학습 성공으로 상속하지 않는다. 별도의 수송 목표각·교사·중간 물리 상태 재주입은 사용하지 않는다.

기존 곡 compiler를 그대로 통과하는 별도 bundle을 만든다. 실제 원시 음 시작은0.24초와0.30초(60ms차이), 두 음 끝은1.85초, 오디오는2초의 무음 시계다. 정책 pre-roll3초·tail0.5초를 유지한다. 기존 make_task의 내부 B 단계가 동일 onset의 두 음 chord를 거부하므로, 검증을 완화하지 않고 두 single event를 사용했다. 실제 정책 음 구간은[3.24,4.85]와[3.30,4.85]초이며, 두 음이 모두 활성인 **고정 공통 구간[3.30,4.80]초1.5초**를 평가한다. 창이 실제 두 음 구간에 포함되지 않는 입력은 거부한다. 정확한 동시 발음·오른손 타현 학습은 이번 목적이 아니다.

현행 보상9항·J33 position·물리240Hz/정책60Hz·K1·원래 범위/힘/PD를 사용한다. 보상을 동시 보너스로 바꾸지 않는다. 원래 개별 달성/전체 성공도 보존하고, 두 목표의 인접 물리 끝점 clean AND를 적분한 동시 clean 시간·유지율·최장 연속 구간을 추가 보고한다. 두 개별 latch만으로 동시 성공을 선언하지 않는다.

동시 성공은 공통 구간1.5초 전체 clean, 최장 연속1.5초, 오압현0, 물리/손목 실패0, 정상 완료다. 평가 실패와 준비·접근 실패도 전체 분모에 포함한다. 학습에서는 팔 이동 전용 준비 gate가 없으므로 정책이 접근하지 못한 결과도 실패로 기록한다. 접촉 합력·표면 기하 성공은 실제 현 압력·음향 성공과 구분한다.
