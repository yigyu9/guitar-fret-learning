# 압현 전환 연구의 진행 순서

2026-11-01 사용자 지정 순서다. 현재 실험의 실행 코드·보상·제어·봉인 입력을 변경하지 않고 후속 방향을 기록한다.

| 순서 | 실험 | 핵심 확인 |
| --- | --- | --- |
| 1. 현재 | 같은 손가락의 서로 다른 목표 전환: 중지 3번줄 6→8프렛 | 이전 음을 끝까지 유지하고, 이동한 뒤 다음 음을 정시에 압현하는가 |
| 2. 다음 | 특정 손가락에서 다른 손가락으로 전환 | 이전 손가락이 적시에 해제되고, 다음 손가락이 준비·압현하며, 오압현이나 손가락 충돌 없이 역할을 넘기는가 |
| 3. 이후 | 동시 압현 후 다음 목표로 전환 | 여러 목표를 동시에 유지하고, 다음 목표에 맞춰 유지할 손가락·해제할 손가락·새로 누를 손가락을 구분해 움직이는가 |

## 단계별 확장

1단계는 현재 [6→8프렛 실험](중지6에서8프렛_환경수비교_20261101/README.md)의 두 난수 학습·반복 평가·영상을 분석해 마무리한다. 실행 완료와 안정적인 전환 성공은 구분한다.

2단계는 우선 두 손가락의 단순한 A→B 교대 한 가지부터 검사한다. 목표 거리와 휴지 시간을 통제해 손목 이동 문제와 손가락 역할 교대 문제를 구분한다. 이후 역방향 교대와 다른 목표 조합으로 확장한다. 구체적인 손가락·줄·프렛·예산은 1단계 결과와 물리 실현성 검사를 바탕으로 정한다.

3단계는 우선 서로 다른 줄의 두 음을 동시에 누르고 유지하는 것을 확인한 뒤, 단음→두 음, 두 음→단음, 두 음→다른 두 음 순으로 복잡도를 높이는 것을 제안한다. 같은 줄의 서로 다른 프렛을 두 개의 독립된 동시 발음으로 세지 않는다. 실제로 유지해야 하는 음과 해제해야 하는 음을 명확히 정의한다.

## 공통 기록

- 목표가 같은 초기 조건·기존 유한 제어·자유 기타 물리에서 가능한지 먼저 확인한다. 참조 동작 성공과 학습 정책 성공을 구분한다.
- 각 음의 연속 달성, 전체 음 길이 유지, 정시 시작, 해제 시점, 전환 중 불필요한 공백·오압현을 따로 집계한다. 동시 압현은 모든 목표를 동시에 만족한 시간도 기록한다.
- 최초 에피소드와 중도 실패를 평가 분모에 포함하고, 평균 정책·탐색 포함 정책·여러 난수·반복 평가를 구분한다.
- 최고·마지막 모델, 손 확대·전신 영상, 실제 관절 변화와 충돌·엄지 지지 진단을 남긴다. 영상 디렉토리에는 영상만 저장한다.
- 공개 영상은 같은 손가락 전환·다른 손가락 전환·동시 압현 전환 등 카테고리별 대표 손 확대1개·전신1개만 남긴다. 최고·마지막 모델과 비교 수치는 보존하되 모든 조건의 영상을 공개 모음에 쌓지 않는다. 실제 촬영의 성공 여부를 확인하고, 실패 진단을 성공 영상으로 표시하지 않는다.
- 보상·탐색·학습률·제어를 한꺼번에 바꾸지 않는다. 이전 단계에서 확인한 동작이 후속 변경으로 무너지지 않았는지도 재확인한다.

이 문서는 후속 연구의 순서와 확인 항목이다. 2·3단계는 아직 실행하지 않았으며 현재 실험의 자동 실행기에 추가하지 않았다.
