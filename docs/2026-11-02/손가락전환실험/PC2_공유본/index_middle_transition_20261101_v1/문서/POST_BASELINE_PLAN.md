# 기준군 완료 후 진단 및 최종 검증

기준군은 두seed각300회 완료. 평균AB는둘다0/32, 탐색AB는2/32·3/32. 사전학습후속 narrow(두seedAB차≥4)와broad(B접촉<16)분기는둘다미충족이므로새학습프로파일을실행하지않는다. 분기나원래90%채택문턱을사후완화하지않는다.

원인진단으로같은300회저장정책에서 **평가표본화std배율만1→0.5**로바꾼각seed최초32episode를비교한다. 이는재학습·평균정책변경·추천설정이아니다. 모델·소스·보상·초기·PD·목표·평가분모는동일. 두모델의평균B실패가단순노이즈감소로해결될지에대한제한적진단이며계획된평균정책90%채택을대체하지않는다.

최종자료용최고가용모델은seed별mean AB수→안전→두음최소clean→전체clean→onset→동점시더이른업데이트로선택한다. 적격개선후보가아니면그사실을명시하고최고가용(실패진단)모델로부른다. 두seed선정모델을mean/sample최초128episode로확인한다. 선정과128은같은초기분포의확장평가이며독립일반화검증이아니다.

선정seed7모델과seed7마지막300회모델의mean네이티브손/전신영상을각각저장한다. 기본학습미채택. 안정된전환이확인되지않으면반대전환·동시압현확장과더긴학습은보류하고이유를기록한다.
