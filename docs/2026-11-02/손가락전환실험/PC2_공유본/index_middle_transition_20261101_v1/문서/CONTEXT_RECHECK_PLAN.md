# 확장평가 문맥 재확인

선정seed17·200회checkpoint의원래32평균AB0과128평균AB12의차이를확인한다. 128에서B성공은추가환경ID71이후에있으며앞32의B성공은0이다. 초기첫physics관측의앞32패드거리차이는최대약3.13um, env0요청각차이는약5.96e-8rad였다. 이는단독으로차이의원인을입증하지않는다.

같은checkpoint와SHA·판정·초기·정책mean을유지하여32와128평가를각한번만추가반복한다. 학습없음,채택90%문턱변경없음. 환경개수/배치·공간위치/물리수치문맥에대한민감도와반복재현을구분한다. 출처가다른물리환경성과로합산하지않으며성공12/128을학습개선으로주장하지않는다.
