# 최종 결과 독립 검수

검수 대상: 연구 루트 `RESULTS.md`, `summary.json`, `문서/ADOPTION.json`, `문서/REPRODUCE.md`, 기존 평가·원장·참조 검증 JSON과 후속 분석기. 이 단계에서는 파일 읽기와 이 문서 작성만 수행했으며 CPU 검사·학습·물리·GPU·영상 디코딩을 추가 실행하지 않았다. 영상 디코딩과 프레임 시각 검수는 연구 수행자의 기록이며 독립 재실행하지 않았다.

## 판단

**최종 원수치와 미채택 판단에서 필수 수정 오류를 발견하지 못했다.** 안정적인 학습 전환을 확인하지 못했다는 결론, 새 학습 프로파일 미실행, 기본 코드 미채택과 조건부 후속 실험 보류는 사전 계획 및 관측 결과와 일치한다. 완료 처리는 독립 검수 이후 수행자가 기록하며 기존 `study.publish()`로 최종 보고서를 다시 생성하지 않는다.

## 대조 내용

- 기준군 12개 평가 행의 A/B 달성·누적 clean·AB·이전 끝 유지와 정시 B·실패 수가 원자료와 일치한다. 두 seed 각각 300업데이트·614,400전이, 합계 600업데이트·1,228,800전이와 actor/critic 각 1,200 승인 step도 일치한다. 학습 중 완료 episode의 손목 실패와 결정적 평가의 실패를 구분했다.
- 최종 32 mean은 두 seed 모두 AB 0/32와 B 달성 0이다. 300회 sampled AB는 2/32·3/32이며 B 접촉은 24/32·22/32이므로 사전 narrow/broad 추가 학습 분기를 충족하지 않는다.
- 실행 std 배율 0.5 진단의 AB는 2/32·4/32이며 B 평균 clean은 각각 약 0.1945·0.5535초다. 원래 sampled의 0.7716·0.8939초와 구분되며, 이 진단을 재학습 또는 안정 전환 개선으로 채택하지 않았다.
- 선정 200회 모델의 128 mean은 seed7 A125/B0/AB0, seed17 A89/B32/AB12다. seed17 추가 반복은 32에서 A32/B0/AB0, 128에서 A79/B6/AB5다. 최초 32와 128, 동일 128의 추가 반복을 합산하거나 동일한 결과로 취급하지 않았다.
- 두 128 평가의 동일 설정·checkpoint SHA를 확인하는 비교 분석기는 입력 trace·report 경로와 SHA, 분석기 SHA 및 1e-6rad 검출 문턱을 기록한다. 약 0.15833/0.17083/0.20417초의 관측 순서를 PhysX 단독 원인의 증명으로 해석하지 않았다. 환경 수 하나의 효과라고 단정하지 않는 표현도 타당하다.
- 참조 v2의 clean 각 1.5초, 최초 clean 3.00/5.25초, 달성 3.60/5.85초, FK 관측 최대 0.2508mm/0.00709rad와 안전 종료가 보고서와 일치한다. 이를 학습 정책 성공으로 합산하지 않았다.
- B구간 중지 적용 목표 대 실제 RMS, 선정 128 mean의 엄지 gap·합력, 두 distal 패드 표본 최소 간격도 기재 반올림 수치와 일치한다. 최근접 표본과 same-sample 후보, 합력과 접촉 쌍, 접촉 후 해제와 단순 부재, 누적 유지와 연속 달성을 구분했다.
- summary 및 ADOPTION의 기본 변경 없음·추천 설정 없음은 본문과 일치한다. 비목표 전체 줄의 무압현, 모든 손가락/마디 충돌, 압력·음향, 일반화와 원인 분리는 인증하지 않은 범위로 명시했다.
