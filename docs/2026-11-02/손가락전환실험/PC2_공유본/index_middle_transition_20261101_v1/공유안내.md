먼저 공유상태.json의 ready=true와 공유검증.json을 확인한다. 원래 완료 보고는 RESULTS.md, 최신 원시 로그 분석은 로그분석/REPORT.md와 FINDINGS.md다. 원래 학습·평가 로그·모델·영상·보존 자료를 전부 포함한다. 로그분석/runs는 추가 평균32/128 각3회 평가다. 다른PC_검토프롬프트.md는 검토 요청문이다.

모델 metadata의 원래 PC2 절대 경로는 보존했다. 상대 폴더 구조로 자료를 읽되 실행 입력을 현재 /3의 다른 버전으로 치환하지 않는다. 읽기용코드/는 원래 봉인에 맞는 활성 코드와 AB 입력의 참고 사본이며 전체 실행환경이 아니다. 공유파일목록.json의 SHA는 복사 전 원문 및 참고 코드 검증에 사용한다.

앞으로 공유할 결과는 이 PC2_공유본 아래 현재 연구 폴더의 새 하위 디렉토리 또는 구분되는 연구 버전으로 추가한다. 확정 복사본의 원문·manifest는 덮어쓰지 않는다. 후속 검토는 새 이름의 디렉토리에 기록한다. 공유 소스·자산·다른 PC의 진행 중 학습 출력·봉인 파일을 수정하지 않는다.
