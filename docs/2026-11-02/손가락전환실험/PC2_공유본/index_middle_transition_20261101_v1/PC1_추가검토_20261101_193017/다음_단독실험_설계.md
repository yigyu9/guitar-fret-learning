## 우선순위 3 — 최종 근접 potential의 기하 정밀도만 변경

### 가설과 변경 범위

PC2 평균 B의 프렛 초과2.4–3.7mm 정체와30mm 거리 척도 사이의 차이를 시험한다. 초기 bias·LR·초기분포·phase·접촉 판정·보상 계수는 기존 기준군과 같다. **2순위 변경과 조합하지 않는다.**

현재 목표패드 접근 potential의 press 표면 branch만 새 계약으로 분리한다. 기존 E4 hover와 press 전0.2초 전환 일정은 유지한다. 별도 보상 항을 추가하지 않는다.

구체적인 출발안:

- 기존 접근 거리 r≥20mm이면 기존 Phi를 정확히 유지한다.
- r≤5mm에서 기하 혼합률 beta=0.70,5–20mm에서는 smoothstep으로0.70→0을 연속 연결한다. 기존 거리 기여는 최소30%다.
- 새 기하 성분은 각 usable pad sample마다 **같은 sample**의 셀 초과·횡오차·높이·normal을 결합해 계산한 뒤 joint 품질의 최댓값을 선택한다. 각 축을 따로 최적화한 서로 다른 sample의 값을 조합하지 않는다.
- positive 판정 문턱은 셀 내부·횡3mm·높이−1..3mm·normal0.1 그대로다. 문턱 밖 초과량에 대한 완만한 품질의 출발 척도는 프렛3mm·횡3mm·높이2mm·normal0.2로 둔다. 이것은 실험 수치이며 검증된 최적값이 아니다.
- 기하 품질은0..1로 정규화하고 기존 potential의 목표별 가중치·scope/목표수 정규화·최대 스케일을 그대로 적용해 Phi_geom으로 변환한다. 혼합 때문에 보상 크기까지 추가 변경하지 않는다.
- Phi_new=(1−beta)Phi_old+beta Phi_geom으로 두고 geom의 선택 sample을 기록한다. 거리 성분의 기존 표본과 geom의 joint 표본이 다를 수 있다는 사실은 명시하며, 혼합 보상을 단일 물리 접촉 witness로 해석하지 않는다.
- shaping의 gamma0.99·terminal nextPhi0·기존 contact/clean/achievement/wrong/deficit 계산은 유지한다. 완결 할인 합 증가가 아니라 중간 TD/critic 근사와 위치 학습 개선을 검증하는 실험이다.

### 선행 검사·예산·판정

먼 거리 수치 동치,20/5mm 경계 연속성, unusable 표본 배제, 같은 표본 결합, terminal potential 할인 정산, 항별 합 보존을 합성 fixture와 관련 CPU 검사로 확인한다. 다음 native 소규모 검증도 원래 자유 기타·중력·힘 상한 아래 별도로 수행해야 하며 이번 문서에서 통과했다고 쓰지 않는다.

## 이번에 우선하지 않는 변경

- 탐색량 일괄 확대/축소: latent std 붕괴 증거가 없고 PC2 축소 진단이 안정적으로 개선되지 않았다. 특정 포화 축의 실제 요청각 탐색과 전체 latent std를 구분한다.
- LR 추가 변경: PC1 보존 실험은 전체 유지 개선 관측은 있지만 모든지표/난수에서 일괄우위가 아니며 PC2 fresh 전환과 조건도 다르다. 현재 결과를 보존하고 새 비교의 고정 조건으로 사용한다.
- 검지 강제 해제·목표 중지 대기 보상 제거: 평균300 B의 검지 잔류가 없고 실제 중지 대기 지급도0이다. 탐색 A 간섭은 별도 관측·시점 문제로 남긴다.
- 엄지 보상/축 추가·하중 상한 증가·손목 기준 변경·학습 길이/H128/GAE 동시 변경: 현재 확인한 원인과 분리되지 않아 이번 세 단독 비교에 섞지 않는다.

## 향후 공유 방식

새 승인 후 실험을 수행한다면 PC2_공유본 아래 구분되는 연구/버전 디렉토리에 확정 공유본을 추가한다. 원문·기존 manifest를 덮어쓰지 않고 ready 상태·복사 SHA·모델 식별·평가 원장·새 코드 버전을 함께 기록한다. 이번 추가 검토 디렉토리도 원 PC2 연구와 구분된 읽기 검토 기록으로 유지한다.
