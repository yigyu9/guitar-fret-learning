# PC2 원시 수행·접촉 원장 독립 검산

원문·모델·봉인을 변경하지 않고 Python 표준 JSON/gzip/hash와 NumPy CPU 연산만 사용했다. 학습 코드 import, Torch 체크포인트 역직렬화, GPU·물리·평가·학습 실행은 하지 않았다. 공유상태 ready=true를 확인했다.

## 동일 모델 반복 민감도

seed17/u200의 기존 두128평가 및 신규6평가, 총8조건에서 실제 `portable_checkpoint_ref.path`가 가리키는 모델 파일 SHA를 계산해 report의 SHA와 대조했다. 모두 `29afaa304ed71b3fa998035831e3065e246b86c08819680baa362a8cd755f405`다. report settings는 num_envs를 제외하면 정확히 같으며, 각 `inputs_before.json`의 settings 파일 자체를 제외한 pin 사전도 8조건에서 정확히 같다. `action_mode.json`은 모두 mean, evaluation_seed=17이다.

이는 기록된 설정·pin·모델 일치 검산이다. 원래 절대경로의 모든 실행 입력을 현재 프로젝트로 대체해 실행하거나, checkpoint 내부 identity를 다시 역직렬화 검증한 것은 아니다. 나머지 공유 파일 전체 무결성 검토와 범위를 구분해야 한다.

기존128 AB12→5, 신규128 AB1/28/56, 신규32 AB0/0/0을 재확인했다. 신규128 각각 앞32의 AB는0이며 56/128의 전체유지는55/128, 28/128의 전체유지는27/128이다. 반복 결과 중 좋은 실행만 선택해 학습 개선으로 해석할 수 없다.

기존128 두 trace를 원시 gzip에서 시간 정렬해 1740행 비교했다. 저장된 모든 환경 거리에서 1e−9m 초과 최초 차이는 **0.008333333초, env100, 목표A, 2.975575626μm**다. 두 episode ID는1로 일치했다. 두 값은0.008227996528m와0.008225020953m다. env0 관절 차이보다 이른 전체 환경 관측 차이라는 PC2 주장을 독립 재현했다. 이것은 숨은 초기 상태/힘/관찰 동기화/환경 배치/물리 중 어느 것이 원인인지 증명하지 않는다.

## 300회 평균 정책의 실패 위치

양 seed의 모든32환경에서 첫 episode ID에 맞는 B 발음 [5.25,6.75) 원시240Hz 끝점은 각각11,520개다. 두 경우 모두 position_geometry=0, facing_geometry=0, raw_candidate=0, effective=0, assigned_loaded=11,520, wrong=11,520, A_raw_in_B=0이다. 끝점 노출을 초로 환산한1.5초와 원장 overlap 적분의1.5초는 계산이 다르지만 이 전구간 조건에서는 결론이 일치한다.

`facing_geometry`는 위치 조건을 포함한다. facing=0을 독립적인 방향 실패로 해석하면 안 된다. assigned_loaded는 몸체 합력 boolean이며 목표 현 압력·접촉 상대를 뜻하지 않는다.

## 오압현의 출처와 검지 해제

평균300회 B에서는 모든32환경의 `wrong_press_sources.values.wrong_source_time`이 중지 끝마디 `human/LH:middle3`의 own_wrong_fret=1.5초, own_wrong_string=1.5초다. 두 cause는 겹치므로 합쳐3초라고 하지 않는다. body_all_causes 프렛 범위는 seed7=5..5, seed17=5..6이다. 이 범위에 cause 축/시점/줄 witness가 없어 각 cause의 정확한 프렛을 지정할 수 없다.

env0 검지 A raw는 휴지 중 마지막 관측 seed7=5.129166667초, seed17=4.579166667초로 보고와 일치한다. B 발음 중에는 전체 환경 A raw=0이고 검지 other_higher 출처가 없다. 검지 해제가 평균300회 B 실패의 주원인이라는 설명은 이 자료가 지지하지 않는다.

반면 seed17/u300/sample A 구간에서 중지 other_higher 출처20/32, 모든 환경 평균0.076432292초, 소지 other_higher 출처8/32, 평균0.034505208초를 확인했다. 실제 audible overlap 누적 원장이므로 탐색 중 조기 중지 간섭과 비목표 소지 간섭은 확인 사실이다. 정확한 발생·종료 시각은 누적 원장에서 역산하지 않았다.

## 검토 결론·범위 제한

- 원보고 핵심 수행·패드 정렬·자기 오압현·평가 민감도 수치는 독립 재계산과 일치한다.
- 이 수치로 상한 초기화가 인과적 주원인, 기하 shaping이 해결책, 학습률이 원인이라고 확정할 수 없다. 다음 단독 비교의 가설이다.
- 이번 분담은 episode/source 원장과 평균300회240Hz 접촉·관절 및 기존128 최초거리차에 집중했다. 신규60Hz 보상 지급·potential 할인 정산·PPO gradient·정책 초기화 코드의 검수는 별도 코드 검토 범위다. 원분석의 전 수치·전 파일을 재검증했다고 확대하지 않는다.

원시 출처: `진단/<조건>/report.json`, `episode_metadata.json`, `episodes.jsonl`, `action_mode.json`, `inputs_before.json`, `finger_control_trace.jsonl.gz`; `로그분석/runs/<조건>/`의 동명 파일. 입력별 실제 SHA와 세부환경ID·누적 출처·대표 통계는 이 폴더의 `raw_audit.json`, 재실행 가능한 읽기 전용 도구는 `tools/audit_raw.py`다.
