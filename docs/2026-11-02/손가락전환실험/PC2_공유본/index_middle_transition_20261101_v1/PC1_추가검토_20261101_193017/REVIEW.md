## 독립 재확인

1. 원시 `episodes.jsonl`을 다시 읽어 PC2 21조건의 n/A/B/safe AB/전체1.5초 유지를 재계산했다. `raw_audit.json`과 차이는 0이다. 실패 환경도 safe AB의 분모에서 제거하지 않았다.
2. PC1 20평가의 실제 원장을 다시 읽어 safe AB와 전체 유지 값을 재계산했다. `pc1_comparison_snapshot.json`과 차이는 0이다. 같은 저장 모델의 두128평가에서 control AB63→57, conservative89→94도 기록되어 있다.
3. `tools/audit_raw.py`는 episode metadata 병합·환경 ID·첫 episode·완료/lifecycle·입력 변경·실제 모델 파일 SHA를 대조한다. 기록된 설정과 pin 일치 검산을 전체 실행환경 검증으로 오해하지 않도록 문서에 범위가 명시되어 있다.
4. `tools/audit_reward.py`의 첫 episode 필터, 60Hz 항 합/반환값/완료 counter 대조, gamma0.99 순서별 할인, terminal Phi=0 정산과 env0 endpoint 검사 절차를 읽었다. 초기 Phi가 직접 t0 관측이 아닌 첫 전이에서 추정됨을 구분한다. 비할인 음수 합이나 raw advantage 표준편차를 gradient 지배로 바꾸어 해석하지 않는다.
5. 읽기용 `guitar_learning/gpu/contact.py:622`에서 최근접 접근 표본은 거리로 선택하지만 positive는 동일 표본의 위치·방향 동시 통과를 전체 패드에서 검색하고 loaded를 결합함을 확인했다. `facing_geometry=0`을 위치와 독립인 방향 실패라고 해석하지 않는 설명이 맞다.
6. 읽기용 `guitar_learning/gpu/finger_skill_environment.py:337`의 reward gate와 관측 gate 분리, `:500`의 실제 9항 지급, `gpu/environment.py:1253`의 종료 potential 정산이 검토 문서의 설명과 일치한다.
7. PC1 LR 비교는 18:31:04에 완료됐다는 읽기 스냅샷과 PC2와 다른 목표/실험 runtime/활성축/초기 catalog/학습 시작 조건을 분리해 비교해야 한다. 읽기용 296개 Python 소스가 현재 PC1과 같다는 사실만으로 두 실험의 전체 실행 계약이 같다고 할 수 없다.

## Suggestion

`PC2_코드보상검토.md:55`의 평가 반복 최초 차이 분리 → fresh 단일 축 bias → 근접 기하 potential 단독 비교 순서는 관측된 불확실성을 줄이는 순서에 맞는다. 성능 채택 전에 평가 변동 범위와 직접 기전 수치를 확인하고, 기존 성공/실패 기준은 유지해야 한다.

## 검수의 한계

이 검수는 보고서와 독립 도구의 논리 및 원장 핵심 수치에 집중했다. 전체 원시 trace를 또 한 번 모두 재생하거나 원래 13,943개 PC2 입력을 모두 확인한 것은 아니다. 학습 로그의 모든 업데이트 수치·영상의 모든 프레임·정확한 source witness는 별도 확인 범위이며 없는 자료를 재구성하지 않았다. 최종 종합 `REPORT.md`와 `다음_단독실험_설계.md`도 추가 검수했다. 아래 최종 확인 내용을 함께 적용한다.

## 최종 종합 문서 추가 검수

- `REPORT.md`의 PC2 수행/오압현/보상 수치, PC1 비교표 및 양방향 AB 변화가 앞선 독립 재계산과 일치한다. 원래13,943개 봉인 중 공유 대응325개만 현지 확인했다는 한계, Python296개 일치와 실험 runtime/입력/관측/학습이력의 차이, 대표 env0 포화와 인과 미확정을 모두 구분했다.
- PC1 성공800회에서도 같은 대표 축 요청 포화가 존재했다는 사실을 PC2 인과의 반증으로 쓰지 않았다. “포화만으로 모든 과제 실패를 설명할 수 없음”이라는 한정은 타당하다.
- `다음_단독실험_설계.md`의 R0 6회/R1 6회/R2 3회는15회로 일치한다. 관찰기 CPU 패리티가 GPU 동기화 무영향을 보장하지 않음과 추론 분할 자체가 새로운 평가 방식임을 명시했다. 신규 실행은 계획이며 이번에 시행했다고 쓰지 않는다.
- fresh bias 비교 2조건×2seed×300회=1,200회,64환경×H32×1,200=2,457,600전이 예산이 맞다. 기존 실제 초기 q와 다른 가중치를 고정하고 단일 bias만 바꾸는 계획이다. 기존 모델 identity를 고쳐 재개하는 절차가 없다.
- 근접 potential은 별도 단독 비교이고, 같은 표본의 기하 품질·기존 최대 스케일/가중치·gamma/종료정산·먼거리 동치와 기존 성공 판정을 유지하도록 설계돼 있다. 실제 개선이나 인과 확정으로 쓰지 않았다.
- 원래 최종90%/실패1% 기준과 반복범위2/128·선별개선16/128의 운영 문턱을 분리했다. 원문 전체가 모든 문제의 인과를 확정했다고 과장한 문장은 찾지 못했다.
