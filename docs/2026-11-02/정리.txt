기존 요약은 핵심 8개 주제만 적은 것이며 실제로는 아래 작업들을 진행함
    성공한 작업뿐 아니라 실패한 실험과 아직 해결하지 못한 문제도 포함
    동영상은 주간작업_대표동영상에 작업별 하나씩 모으고 출처와 결과는 주간작업_영상목록.txt에 기록

곡의 목표와 손목 안내를 눈으로 확인하기 어려움
    몸체를 고정한 채 프렛 영역과 현재 목표, 손목 안내를 시각화
    학습 목표가 어디에 표시되는지 확인할 자료 확보

손목 안내가 점 기준이고 자세가 한쪽으로 치우침
    안내를 영역으로 바꾸고 위치와 크기를 보정
    영역 안에서는 허용하고 심한 이탈은 종료 조건으로 처리

손등이나 잘못된 손가락 표면이 압현으로 인정될 우려
    실제 끝마디의 굽힘 안쪽 패드 표면을 샘플링해 접근과 접촉에 사용
    접근 거리와 방향, 위치, 하중을 구분해 진단 가능

보상이 많고 역할이 중복됨
    접근과 추종, 누락과 미달성 항목을 합쳐 보상 9개로 정리
    보상별 점수와 실패 비용을 로그에서 따로 추적하도록 정비

물리 실패와 손목 이탈의 처리 기준이 불명확함
    종료 조건과 통합 실패 비용을 정리하고 손목 복귀 타이머 보정
    정상 복귀와 반복 이탈을 구분하고 실패 원인을 기록

손가락이 과하게 펴지거나 꼬이고 마지막 관절만 꺾임
    대기 자세를 손가락별로 적용하고 관절 분담과 손가락 사이 충돌을 개선
    제어와 자세는 개선했으나 자연스러운 압현 동작은 완전히 해결되지 않음

엄지가 넥 뒷면에 제대로 닿지 않음
    엄지 안내면을 실제 연주용 넥의 표면 기준으로 보정하고 접촉 후보 재생
    안내면 위치 오차는 보정했지만 안정적인 엄지 지지는 아직 미해결

누적 명령이 쌓이며 손가락 목표각과 실제각 차이가 커짐
    누적 제어와 직접 제어를 비교하고 직접 목표각 제어로 변경
    제어와 저장 및 재개는 검증했으나 학습 성공은 별도 문제로 남음

관절 힘과 끝마디 제어가 압현을 방해하는지 불명확함
    힘 상한과 추가 굽힘 억제, 목표각 출력방식을 고정 기타 조건에서 분리 비교
    일부 참고 동작은 가능했지만 안정적인 정책 학습 해결로 이어지지는 않음

보상과 가치함수 중 무엇이 학습 퇴행에 영향을 주는지 불명확함
    보상별 기울기와 비용 예측 초기값, 보상 가치망 사전 보정을 진단
    일부 확률 수행은 개선됐지만 평균 정책의 퇴행과 오압현은 해결되지 않음

장시간 학습해도 성과가 정체되거나 마지막 모델이 나빠짐
    학습률과 탐색, 수집 길이, 초기 분포와 실행방식을 따로 비교
    평균 정책과 탐색 포함 정책의 차이를 확인했으며 보편적인 해결책은 미확정

곡 전체 학습만으로는 압현 실패 원인을 구분하기 어려움
    손가락별 단일 목표와 가상 목표 전환을 분리해 짧게 학습
    찾아둔 동작의 재생과 실제 강화학습 성과가 다름을 확인

초기 손 자세가 넥에 가깝거나 방향이 부자연스러움
    어깨와 팔꿈치, 손목을 조절하고 손가락을 벌린 초기 자세 제작
    검토한 자세를 초기 상태로 반영하고 손가락 시작 관절의 대기 여유 확보

손 전체로 누르거나 정렬 중 멈추고 손가락이 다시 펴짐
    손목 이동과 정렬, 굽힘의 단계를 정리하고 목표 사전 노출과 준비 보상 개선
    팔 지원 조건의 단일 압현과 자연스러운 준비 동작은 개선됐으나 범용 학습은 미완성

첫 음을 누른 뒤 다음 음으로 넘어가는 해제와 굽힘 준비가 어려움
    해제 참고 동작과 굽힘 준비 시점, 달성 보상 정산을 분리 비교
    일부 참조 동작은 성공했지만 학습 후반의 첫 음 퇴행이 남음

같은 손가락의 인접 프렛 접촉이 잘못된 동시 성공으로 잡힘
    높은 프렛이 낮은 목표를 방해하는 오압현 판정을 보정
    과거 일부 성공 수치는 제외하고 새 판정으로 다시 학습 및 평가

중지의 6프렛에서 7프렛 전환이 불안정함
    학습 길이와 보수적인 학습률을 비교하고 중간 및 마지막 모델 반복 평가
    800회 모델에서 전환 성공 사례가 나왔지만 이후 퇴행과 모델 간 차이는 남음

목표가 가까워 실제 이동을 배웠는지 판단하기 어려움
    목표를 6프렛에서 8프렛으로 벌리고 large 1024환경으로 새로 학습
    첫 음은 배웠으나 둘째 음 달성은 0이며 목표 방향 이동 부족을 확인

전환 시간 문제인지 단일 이동 자체의 문제인지 불명확함
    같은 초기 자세에서 8프렛만 목표로 학습
    목표 거리는 줄었지만 유효 압현이 없었고 사용자 요청으로 학습 중단

탐색을 해도 팔의 일부 축이 거의 움직이지 않음
    초기 정책 출력의 포화를 발견하고 해당 축의 초기값만 완화
    기술 검증은 통과했지만 두 모델의 짧은 비교 학습에서는 압현 달성 0으로 단독 해결되지 않음

전체 위치에서 단일 압현이 가능한지 확인할 기준이 없음
    4손가락과 6줄, 22프렛의 528조합 검증 목록 작성
    아직 전체 검증 전이며 단일 압현 기반을 확보한 뒤 전환과 곡 학습으로 확대할 계획

GPU 자원을 효율적으로 쓰는 환경 수가 불명확함
    256개와 512개, 1024개 환경의 처리량과 메모리, 물리 실패를 비교
    해당 조건에서 1024환경을 선택했으며 처리량 향상과 학습 수렴은 별도로 평가

학습 코드와 문서가 많고 과거 구현이 섞여 있음
    유사 파일과 중복 코드를 통합하고 역할별로 정리했으며 과거 구현과 R 및 F 단계를 보관 또는 제거
    J 공동 학습 중심으로 정리하고 한글 주석과 코드 해설, 보상 문서를 갱신

외부 파일과 미공유 자료 때문에 다른 PC에서 재현하기 어려움
    필수 입력을 프로젝트 내부로 모으고 전달 자료와 공유 실험 로그를 검토
    원격 저장소만으로 기본 GPU 학습과 저장, 재개, 평가를 검증했으나 최신 실험 파일의 추가 공유는 별도 필요

실험 로그와 체크포인트, 문서와 영상이 과도하게 쌓임
    오래되거나 중복된 자료를 정리하고 보존 기준과 gitignore를 정비
    원본 증거와 대표 결과를 구분하고 작업별 대표 영상 모음을 추가
