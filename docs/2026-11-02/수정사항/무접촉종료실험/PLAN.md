## 판정의 정확한 의미

초기 준비와 휴지 구간에는 무접촉 기회 수를 늘리지 않는다. 선택된 목표 음이 종료된 뒤 그 음의 audible 구간에 올바른 접촉 적분값(clean)이 양수였는지 판정한다. 달성 기준보다 짧은 접촉도 시도로 인정한다. 준비 중 접촉만 있고 발음 구간에는 전혀 접촉하지 않았다면 무접촉이다. 같은 종료 시각의 음들은 기회 하나로 묶고 하나라도 접촉했으면 연속 횟수를 리셋한다. 따라서 화음을 동시에 여러 번 실패한 것으로 세지 않는다. 학습 초기부터 조건을 적용하는 독립 실험이며 자동으로 종료 문턱을 강화하지 않는다.

이 기준은 최소 한 번의240Hz 유효 구간 적분을 요구한다. 단일 순간의candidate나 실제 음향 성공과 같지 않다. 미선택 음, 아직 종료되지 않은 음은 세지 않는다. 에피소드 리셋 때만 횟수를 초기화하며 H32 수집 경계에서는 유지한다.

연속 횟수와 종료 문턱을 정책 상태에 추가한다. 종료 OFF 기준군에도 같은 관측 형태를 제공한다. 기존 물리·손목 종료 및 통합 실패 비용을 재사용하고, 별도 큰 누락 감점을 더하지 않는다. 기존 음 수행 부족 항은 유지한다. 이 실험은 종료 기준 하나의 추가 효과를 비교한다.

## 평가와 채택

평가 시 새 무접촉 종료만 해제하고 기존 물리·손목 종료는 유지한다. 학습 계약은 명시적 평가 view에서 신규 종료를 끈다고 선언하며 strict load를 완화하지 않는다. 학습의 조기 종료로 짧아진 분모를 성능 향상으로 보지 않는다.

전곡 평균 달성 음이 기준군보다0.25음 이상 늘고,128환경 물리+손목 조기 종료 증가가2회 이하인 후보를 초기 선별한다. 최선 후보만 seed17에서 같은 기준으로 재확인한다. 두 seed 단기 선별 결과이며 통계적 유의성·장기 수렴의 보장이 아니다. 검증 통과 후보가 없으면 채택하지 않는다. 추천이 생겨도 기본 코드·원래 보상은 자동 변경하지 않는다.

학습 중 신규 종료 비율, 물리/손목 종료, 목표 노출과 각 보상 평균을 기록해 곡 앞부분 반복에 갇혔는지 살핀다. 시작 구간 샘플링 개선은 이번 실험에 섞지 않는다.

진행: status.json / progress.md. 결과: results.json / RESULTS.md. 현재 연구 실패 또는 효율 검증 실패 시 자동 진행하지 않고 사유를 기록한다.
