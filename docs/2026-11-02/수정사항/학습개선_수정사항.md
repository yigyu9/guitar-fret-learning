# 왼손 학습 개선: 기존 방식 → 변경안

작성일: 2026-10-29. 요청한 `docs/2026-11-02/수정사항`에 기록한다.

**상태: 변경 제안 문서. 아직 코드에 적용하거나 새 학습을 시작하지 않았다.** 아래 수치는 비교 검증을 위한 시작값이며 최적값으로 확인된 수치가 아니다.

8시간 학습은1,626회·약5,328만 전이를 진행했으며 최종 전곡 달성은7.93/67이었다. 원인 후보는 학습률의 영구 감소, 좁은 탐색, 접근에서 접촉으로 넘어가는 안내 부족, 보상·실패 비용의 신호 크기 차이다. 한 번의 실행으로 각 원인의 기여도를 확정하지 않는다.

## 먼저 바로잡을 점

- **학습률:** 학습 도중 실제로 크게 낮아졌다. 174번째 업데이트에서 초기의1/16이 되었고 끝까지 유지됐다.
- **탐색:** 학습 도중 크게 낮아진 것은 아니다. 초기의 작은 표준편차 약0.05를 끝까지 거의 유지했다.
- 현재 둘 다 압현 성과를 확인해 자동으로 낮추는 방식이 아니다. 따라서 “학습이 충분히 됐으니 낮춘 것”은 아니다.

## 1. 학습률: 한 번 낮춘 뒤 계속 느리게 학습하는 문제 수정

학습률은 정책을 한 번에 얼마나 바꿀지 정하는 값이다. 현재 시작값은`3e-5`다. 정책 변화량(KL)이 제한`0.02`를 넘으면 갱신 전 상태로 되돌리고 학습률을 줄여 재시도한다. 두 번의 재시도로`1.875e-6`까지 떨어졌고, 전체 업데이트의89.4%를 이 값으로 진행했다.

**변경안**

- 시작값·상한은`3e-5`로 유지한다.
- 재시도 때는 현재 시도 학습률에서`0.5배`씩 줄인다. 재시도 횟수에 따라 감소 폭을 추가로 키우지 않는다.
- 모든 정책 갱신이 승인되고 재시도가 없으며, 최종 전체 수집분 KL이`0.005 미만`인 상태가10업데이트 연속이면 학습률을`1.2배` 회복한다. 회복 후 연속 횟수는 새로 센다.
- 제안 하한은`3e-6`이다. 하한에 도달해도 KL 검사를 강제로 통과시키지 않는다. 정해진 재시도로 통과하지 못하면 기존 오류 처리에 따른다.
- KL 제한`0.02`, 갱신 전 정책·optimizer 복원, 경사 제한은 유지한다. 학습률·시도별 감소·회복 이유·연속 안정 횟수를 기록한다.

압현 성과가 낮다고 무조건 학습률을 올리지는 않는다. **정책 변화의 안정성을 보고 학습 속도를 회복하는 것**이 목적이다. 낮은 학습률이 성능을 얼마나 제한했는지는 비교 실험으로 확인한다.

## 2. 탐색: 손가락이 더 다양한 목표각을 시도하도록 수정

현재 정책은 목표각의 평균과 탐색 표준편차를 학습한다. 매60Hz tick에 독립 Gaussian 표본을 뽑아 직접 위치 목표로 변환한다. 표준편차는 초기0.0498에서 최종에도 약0.0493~0.0500이었다. 후반에 탐색이 사라진 모습은 아니지만, 소지 MCP 굽힘의 최종 목표각 범위는 평균0.016도로 작았다.

**우선 변경안**

- 비엄지 손가락16축은 초기 표준편차`0.10`, 학습 중 하한`0.07`로 둔다. 이 값은 각도 단위가 아니라 tanh 이전 정책 분포의 값이다.
- 몸통·팔·손목·엄지가 속한 지지17축은 기존 초기값 약`0.05`와 기존 제약을 유지한다. 전신 탐색을 함께 키우지 않는다.
- 비엄지 탐색은 학습 시간만을 이유로 줄이지 않는다. 이 비교에서는 하한을 유지한다. 나중에 낮추는 별도 일정은 접촉 성과를 확인한 뒤 결정한다.
- 실제 목표각 변화, 실제 관절 변화, 속도 제한에 잘린 정도, 접촉 달성률을 함께 기록한다. 분포 값만 커지고 실제 움직임은 늘지 않으면 개선으로 판단하지 않는다. 탐색 확대가 이미 누르던 음의 유지를 깨뜨릴 수 있으므로, 접촉률과 최종 달성률을 함께 확인하고 유지가 악화되면 하한을 재검토한다.
- 직접 위치제어·native 관절 범위·4rad/s 제한·PD·힘 상한·손가락 움직임 비용0을 유지한다.

**시간 상관 탐색은 이번 우선 변경에서 제외한다.** 같은 방향의 탐색을 짧게 이어가는 방법은 후보지만, 단순히 난수를 재사용하거나 행동을 반복하면 기존 PPO의 확률 계산·K1 결정 계약과 맞지 않을 수 있다. 우선 탐색 폭만 바꿔 효과를 분리하고, 부족하면 확률 계산·관측 상태까지 일치하는 시간 상관 탐색을 별도 설계한다.

## 3. 접근 → 접촉: 더 일찍 준비하고, 가까운 곳에서 정확한 자세를 안내

최종 목표의84.6%가 최초 접촉 문턱을 넘지 못했다. 반면 최초 접촉을 달성한 경우 약77%는 최종 달성까지 이어졌다. 가장 큰 손실은 접촉 획득 전이다.

현재 접근은 거리 중심이다. 가까운 곳에서도 방향 불량의 반영은 최대20%이고, 접근 활성화가 대기 시간표와 연결되어 통상 압현0.35초 전부터 준비가 시작된다. 관측에서2초 전 목표를 제공하는 것과2초 동안 접근 보상을 주는 것은 다르다.

**변경안 A — 준비 안내를 앞당긴다**

- 통상 완전한 준비 안내 시점을`0.35초 전 → 1.0초 전`으로 앞당긴다. 전환은 그보다0.2초 이른1.2초 전부터 부드럽게 시작하는 것을 제안한다.
- 이전 음을 누르는 동안에는 그 음의 유지가 우선이다. 짧은 음 간격에1초 창을 무조건 덮어쓰지 않고, 기존 현재 음 보호·짧은 간격 처리 규칙을 기준으로 조정한다.
- 접근 보상과 대기 보상이 **같은 손가락별 시간표**를 사용한다. 압현 준비가 시작됐는데 대기 자세도 함께 요구하는 상황을 만들지 않는다.

**변경안 B — 접근 보상 하나 안에서 접촉 자세를 안내한다**

- 먼 곳에서는 기존처럼 목표 패드와 목표 영역 사이 거리를 줄이도록 한다.
- 목표2cm 안에서는 줄 중심과의 옆방향 오차, 프렛 내부 영역, 압현 면 높이, 패드 방향을 부드러운0~1 기하 품질로 묶는다.
- 가까운 곳의 품질 반영 폭은 기존 최대20%에서 **제안 최대70%**로 늘린다. 방향·위치가 좋지 않아도 거리 안내를 완전히 잃지 않도록 최소30%는 남긴다.
- 같은 패드 표본의 위치와 방향을 함께 평가한다. 서로 다른 점의 좋은 거리와 좋은 방향을 섞어 가짜 품질을 만들지 않는다. 기하 품질에는 실제 하중을 넣지 않아 접촉 전에도 안내가 이어지게 한다.
- 별도 추종 보상을 추가하지 않는다. 기존 **목표 패드 접근** 항의 potential만 개선하고, 지급은 기존`gamma × 다음 potential − 현재 potential`, 종료 시 다음 potential0을 유지한다.
- 최초 접촉·압현 유지·압현 달성의 실제 판정과 지급 예산은 우선 유지한다. 보상을 받기 쉽게 성공 판정을 완화하지 않는다.

A와B는 따로 비교한다. 준비 시간을 늘린 효과와 기하 안내를 바꾼 효과를 구분하기 위해서다. 접근 항의 음수 합계가 커졌다는 사실만으로 오류라고 판단하지 않는다.

## 4. 보상과 실패 비용: 안전을 유지하면서 압현 신호가 묻히지 않게 수정

현재는 보상과 실패 비용의 advantage(해당 행동이 예상보다 유리했는지 나타내는 값)를 먼저 빼서 합친 뒤 크기를 맞춘다. 마지막100회의 표준편차는 보상0.175, 비용0.694로 약4배 차이였다. 이것은 신호 규모 차이이며, 비용이 실제 정책 경사를4배 지배했다는 증거는 아니다.

**변경안**

- `기존: 크기 맞춤(보상 신호 − 비용 신호)`
- `변경: 크기를 맞춘 보상 신호 − 가중치 × 크기를 맞춘 비용 신호`
- 기존 PPO가 가진 분리 정규화 계산을 검증해 재사용하고, 기본 J 설정에서 비교한다. 비용 가중치는 우선`1`로 두어 정규화 효과부터 분리한다.
- 원래 실패 비용`5 + 2 × 남은 시간 + 남은 미관측 음 감점 예산`과 물리·손목 조기 종료 조건은 유지한다.
- 단, **원래 비용을 유지해도 정책 갱신에서의 상대 영향은 바뀐다.** 이것이 의도한 변경이다. 안전 영향이 없다고 미리 단정하지 않는다.
- 분산이0인 경우의 처리·유한값을 검사하고, 보상/비용 정규화 전후 크기·최종 결합 신호·손가락/지지 출력부별 경사를 기록한다.
- 같은 전곡 평가에서 달성 증가와 조기 종료율을 함께 확인한다. 종료 증가가 보이면 먼저 가중치와 정책 갱신 범위를 재검토한다. 종료 문턱을 완화해서 결과를 맞추지 않는다.

## 적용·검증 순서

1. 학습률 회복만 적용해 비교한다.
2. 비엄지 탐색 폭을 늘려 추가 비교한다.
3. 분리 정규화를 추가 비교한다.
4. 준비 시간을 늘리고, 그 다음 근접 기하 안내를 별도로 비교한다.
5. 접촉 획득이 개선되는 것을 확인한 뒤 장기 학습을 진행한다.

각 비교는 같은 초기 조건·곡·환경 수·업데이트 수로 평가한다. 최종 확인에는 복수 seed를 사용한다. 초기·중간·최종의 같은 전곡 평가에서 다음을 함께 본다.

- 약지·소지를 포함한 손가락별 접근/최초 접촉/압현 달성률.
- 목표각과 실제각의 변화 범위, 관절 추종 오차, 힘·접촉 기록.
- 물리·손목 종료율, 학습률·KL·탐색 표준편차, 보상/비용 신호 크기.

보상·탐색·학습 설정이 바뀌는 실행은 새 계약으로 구분한다. 과거 checkpoint를 바뀐 의미로 암묵 재개하지 않는다. 이번 문서에서는 H32·곡 단위 J 학습·보상9개 이름·관절 범위를 변경하지 않는다.
