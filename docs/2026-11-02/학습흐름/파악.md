중앙 학습 반복을 짧게 표현하면 다음과 같습니다.

```python
환경과 정책 생성
initial.pt 저장

for 학습 반복:
    buffer = collector.collect(horizon)  # 움직이며 경험 수집
    metrics = trainer.update(buffer)     # 모은 경험으로 모델 학습
    진행도와 로그 갱신
    필요하면 checkpoint 저장

final.pt 저장
```

**실제로 어떻게 움직이는지**는 [gpu_pool.py의 `step()`](/home/ajou/yigyu/3/guitar_learning/training/gpu_pool.py:81) 안에서 따라가세요.

- [control.py의 `targets()`](/home/ajou/yigyu/3/guitar_learning/gpu/control.py:399): 정책 행동 → 관절 목표각

정책 행동은 **60Hz**, 물리는 **240Hz**이므로 행동 한 번마다 물리가 네 번 진행됩니다.

**보상과 종료**는 두 파일을 함께 봐야 합니다. [environment.py의 `substep()`](/home/ajou/yigyu/3/guitar_learning/gpu/environment.py:972)에서 기본 값을 누적하고, 현재 기본 환경인 [simplified_finger_environment.py의 `_reward_components()`](/home/ajou/yigyu/3/guitar_learning/gpu/simplified_finger_environment.py:227)가 최종 9개 보상항과 계수를 구성합니다. 손목 종료는 같은 파일의 [`_safety()`](/home/ajou/yigyu/3/guitar_learning/gpu/simplified_finger_environment.py:185), 실패 비용은 [`_apply_failure_cost()`](/home/ajou/yigyu/3/guitar_learning/gpu/simplified_finger_environment.py:214)를 보면 됩니다. **부모 환경의 보상 코드만 읽으면 현재 실제 계수를 잘못 이해할 수 있습니다.**

**H32와 에피소드는 다릅니다.** H32는 행동 32회, 환경당 약 0.533초의 경험을 모은 뒤 모델을 한 번 갱신한다는 뜻입니다. 곡이 끝나거나 종료 조건에 걸리지 않았다면, 다음 학습 반복에서도 같은 에피소드가 이어집니다.

최근 진행한 **고정 기타·단음 진단 학습**은 별도 실행 경로입니다. 그것을 따라가려면 [short_finger_learning/runner.py의 `_train()`](/home/ajou/yigyu/3/guitar_learning/tool/experiments/short_finger_learning/runner.py:149)과 [runtime.py의 `ShortPool.step()`](/home/ajou/yigyu/3/guitar_learning/tool/experiments/short_finger_learning/runtime.py:160)을 보세요. 후자는 정책 행동 중 선택 손가락만 사용하고 팔·나머지 손가락에는 진단용 기준 제어를 적용하는 부분입니다.
