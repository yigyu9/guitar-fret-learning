# 압현 진단용 왼손 대기 초기 자세

요청 범위: 기존 준비 상태에서 왼손 손가락만 변경해 넥에서 떨어진 대기 초기 자세를 만든다. 현행 학습 기본값과 기존 실험 원자료는 보존한다.

- [x] 기존 실제 준비 상태에서 손가락만 B대기 중심으로 변경하고, 팔·손목·몸통·오른손·기타 상태 동일성 검사
- [x] 손가락 전체 메시와 넥·줄의 간격을 확인하고 필요한 손가락 각만 최소 보정. 우선 10mm 간격 목표이며 불가능하면 실제 수치를 보고
- [x] 새 파일로 관절값·초기 상태·재현 도구·정면/사선/전신 이미지 저장
- [x] 실제 물리에서 짧게 유지하고 초기 간섭·움직임·자세 추종 확인, 독립 검수

엄지 변경 범위는 사용자 답변을 반영한다. 초기 상태 변경은 새 환경의 경계에서 한 번만 하며 물리 중 상태를 덮어쓰지 않는다. 소스 운동학은 반드시 원실제각과 원몸체 자세로 보정한 뒤 사용한다. 기타와의 간격은 시각용 선이나 패드 점만이 아니라 손가락 마디 메시를 포함해 확인한다.

완료:5초60Hz기록기준모든손가락간격하한14.08mm이상,비손가락초기q오차0,전후비교그림저장.엄지포함사용자답변반영.
