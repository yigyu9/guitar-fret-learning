# 손바닥 위·손가락 뿌리 정면·전완 정면 대기 자세

정면=인체월드+Y,위=+Z. 손바닥면의 방향은 손가락 굽힘이 향하는 palmar쪽(로컬−Z에 가까운 쪽)으로 정의한다. 이전 보고의 로컬+Z는 손등측 축이므로 사용하지 않는다.

- [x] 실제 MCP배치로 손의 길이방향/손바닥 평면을 정의하고 세 방향 목표를 함께 적용
- [x] 어깨·팔꿈치·손목12축을 조정하고 손가락대기21축·나머지상태 보존,팔/손가락넥간격확인
- [x] 방향오차·전체관절값·동일카메라/측면이미지저장,독립검수

원모델FK 시각화 후보로만 만들며물리유지/학습성공과구분한다. 기존초기상태/학습기본값을바꾸지않는다.

완료:손바닥위0.0135도/손길이정면0.0304도/전완정면1.411도.어깨~손이미지와손확대저장.손높이상승과넥15~20cm간격을README에명시.물리미검증.
