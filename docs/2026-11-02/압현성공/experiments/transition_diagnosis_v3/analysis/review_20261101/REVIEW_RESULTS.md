# 학습 결과·재평가 독립 검수

수치 검수 판정: **문제없음**. 기존 모델·소스·입력은 읽기 전용으로 확인하고 이 검수 문서만 추가했다.

## 원장과 요약의 일치

128환경 재평가 세 건의 에피소드 원장을 각각 직접 읽어, 환경 ID 128개와 실패 포함 분모·음 달성·전체 유지 시간을 재계산했다.

|모델|A|B|AB|두 음 전체 유지|물리·손목 종료|
|---|---:|---:|---:|---:|---:|
|seed7·800회|113|116|107|100|0|
|seed7·1000회|111|19|5|2|0|
|seed17·900회|82|25|0|0|0|

`SUMMARY.json` 및 사용자용 결과 문서와 일치한다. 기존 32환경 평균 평가도 seed7 800회 AB32→900회26→1000회0, seed17 100~900회 B0으로 확인했다. 32환경과128환경 결과는 병렬 물리 실행 규모가 다른 재평가이며 새 목표·곡·초기 자세 일반화의 증거가 아니다.

## 기대 요청각 D0

고정밀 평가 두 건 모두 실제256/128점 적분을 각각448회 호출했고, 수렴 기준1mrad를 통과했다. seed7 최대 차이는0.176668mrad, seed17은0.210166mrad다. 각32환경 최초 에피소드의 AB는0이며 평가 completed/lifecycle_verified는 true다. 기존 저해상도 적분의 미수렴 결과와 구분해300회 저장 모델에 한정한 결론을 기록한 것이 적절하다.

## 중단과 저장 모델

원래 감독 실행은 실패 상태를 유지하며 소스·입력488개 SHA 불일치가 없다. seed17은 누적942회 갱신 후 다음 갱신에서 KLGuardError로 중단됐고, 마지막 정상 저장 모델은900회다. 실패 블록의 initial.pt만을942회 모델로 읽지 않는다. 직전 정상 KL0.0119743과 실패 KL을 구분해야 한다.

Warning: 검수 당시 사용자용 문서의 “물리 실패·NaN·소스 변경과 구분”에서 NaN 배제까지 읽힐 수 있는 부분은 한정하도록 전달했다. PPO는 KL이 비유한 값인 경우에도 같은 KLGuardError를 발생시키며, 실패 KL 진단값은 로그에 저장되지 않았다. 따라서 실패 KL의 크기와 유한성은 현재 자료로 확정할 수 없다.

후속 실행기의 KL-only 예외는 입력 누락·변경·정리 오류가 없고 native lifecycle 검증이 성공한 경우만 허용한다. 관련 회귀5개가 통과했고, 다른 오류를 계속 진행시키는 기존 지적은 수정됐다. 원본 실패 결과를 성공으로 변경하지 않고 독립 H/I/T를 새 출력에서 실행하는 설계다.

## 영상 검수 범위

800회 모델 native 렌더는 completed/native_pixels/policy_unchanged가 true이며 환경0의 원장 clean은[1.5,1.5]초다. 공개 손·전신 MP4 두 개는 원본과 SHA 및 하드링크 inode가 일치한다. 이 한 에피소드는128환경 집계 성공률을 대신하지 않는다.

1000회 마지막 모델 렌더는 이 검수 시점에 진행 중이므로 검수 완료로 표시하지 않았다. 실제 렌더 보고서와 공개 파일 생성 후 별도로 확인해야 한다. 손 모양·접촉쌍별 압력·실제 음향·엄지 지지의 완성을 인증한 결과는 아니다.
