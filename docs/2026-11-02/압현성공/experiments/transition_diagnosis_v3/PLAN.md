# 중지 목표 전환·엄지 진단 계획

사용자 요청: 학습 시간 부족, 학습 구조, 그 밖의 원인을 구분하고 엄지 후면 접촉을 점검한다. 기존 자료의 읽기 전용 분석부터 진행한다. 과거 봉인 소스·체크포인트·실험 기준은 변경하지 않는다.

- [x] 기존 두 seed·100/200/300회 평균/확률 평가와 PPO 지표를 비교한다. 검증: 원본 파일과 집계 수치 연결.
- [x] 전환 전후 목표 노출·요청각·실제각·접촉을 비교한다. 검증: 대표 env0와 전체32환경 자료의 범위를 구분.
- [x] 엄지 제어 가능 여부·보상·접촉 판정을 확인한다. 검증: 실험16축과 기본33축 구분, 측정되지 않은 실제 접촉력은 단정하지 않음.
- [x] 원인별 통제 실험 수치·평가 기준·중단 기준을 기록한다. 새 GPU 학습과 구현 변경은 계획 승인 후 진행한다.
- [x] 독립 검수 후 결과와 남은 불확실성을 보고한다.

성공 기준: 확인된 사실과 가설을 구분하고, 단순 장기학습/행동 해석/신용 할당/목표 노출/엄지 제어 문제를 각각 판별할 비교를 제시한다.

추가 GPU 학습·구현 변경은 아직 시작하지 않았으며 위 설계 승인 대기다. 기존 기록 분석과 검수는 완료했다.
