# 최초 사전 검증 경로 오류

GPU 생성/PPO 수행 전 입력 봉인 단계에서 중단. 사본이 원 프로젝트 하위에 있을 때 이미 사본 내부인 입력을 원 루트 기준으로 다시 접두해 경로가 중복됐다. 모든 조건에 공통으로 격리 사본 native/paths.py에서 현재 ROOT 아래 경로를 먼저 그대로 처리하도록 수정했다. 생산 파일과 물리/보상/제어는 수정하지 않았다. 이전 seal과 실패 산출물을 이 폴더에 보존한다.

최종 조치: native/paths.py의 임시 수정은 원문으로 복원했다. 신규 연구 모듈의 문맥 안에서 provenance에 등록한 입력은 원래 매핑을 따르고, 이미 사본 내부인 그 외 입력의 중복 재배치만 막는다. 모든 기존 사본 파일은 snapshot_before의 SHA와 다시 일치하며 CPU9개와 v9 전체 초기화·출처 검증을 통과했다.
