# 탐색·학습률·순차 구조 비교

[수치 계획](PLAN.md) · [진행상황](progress.md) · [누적 결과](analysis/RESULTS.md)

기준군→손가락 탐색 확대→학습률 보정→조합→순차 구조를 순서대로 비교한다. large/64환경/H32, 손가락별 대표4목표에 각100회씩 새 정책을 학습하고 초기·최종32환경 평가를 남긴다. 조건 변경은 별도 runtime 사본에만 적용하며 생산 기본값은 자동 변경하지 않는다.

상위 후보가 사전 기준을 통과하면 seed17로 재확인하고, 통과 시 다른12목표로 확장한다. 결과가0이거나 후보가 재현되지 않으면 그 사실도 기록하고 끝낸다. 기존16목표 결과는 [원래 실험 결과](../../analysis/learning/RESULTS.md)와 구분한다.

`runtime/`은 고정 소스·자산·목표, `runs/`은 모델·로그·평가, `analysis/`는 집계·선정 근거, `video/`는 MP4, `rendering/`은 촬영 원시자료다. 최초 입력 경로 오류와 그 당시 봉인은 `preflight_failures/`에 보존한다. 실험 구현 검수는 [검수 기록](review.json), 실제 실행 입력은 시작 전에 생성한 seal.json에 기록한다.

단계 진단의 `press_research_stages`는 실제 policy act의 손가락·환경 합산 시간이며 실제 경과 시간이 아니다. 평가기는 H32 수집을 마무리하며 선택된 첫 에피소드 뒤의 부분 tick도 수집할 수 있어 이 값에 포함된다. 따라서 선택한 평가 에피소드만의 정확한 체류 시간으로 해석하지 않는다. 달성·clean 통계는 선택된 첫 에피소드만 사용한다.
