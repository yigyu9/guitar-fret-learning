# 자연스러운 압현 준비 v3 구현 검증

2026-10-31. 신규 구현의 작동·정산·조건 분리를 검증한 기록이다. 자연스러운 압현이 학습됐다는 결과가 아니다.

## 구현 확인

- 첫 목표 선택과 관측 노출, 보상 준비 마스크를 구분했다. E1이 E2/E3에 암묵적으로 적용되지 않는다.
- E2는 실제 대기 보상 지급 gate만 분리했다. 관측의 기존 gate·idle·접근 가중치는 그대로다. 동일 물리 끝점에서 E0/E2의 전체 관측과 접근 potential이 정확히 같은지 검사했다.
- 준비 영역4~8mm/가로±3mm는 같은 유효 패드 표면점으로 계산한다. 내려가기0.2초의 quintic 보간 끝점은 기존 표면 potential과 같다.
- 손가락 행동 잠금, 관절 범위 축소, 움직임 비용, 접촉 원장 변경을 추가하지 않았다.
- v9+goal4는 물리 초기 상태만v9이며 팔은 정렬 IK 고정 요청으로 이동한다. 비목표 손가락은 초기 유지이고 팔을 학습한 결과로 해석하지 않는다. arm16에서 팔 출력을 활성화하며 phase별 clamp는 없다.

## CPU 검사

신규19개 검사가 통과했다. [최종 로그](new_tests_sealed.log). 목표 선택·현재 음 우선·동시음 focus 동률, E0 기존 동등, E2 전체 관측 동등, 준비 기하·방향, 접근 연결 끝점·할인 소거, H32/실제 종료 구분, 부분 reset, onset 이전 최초 접촉0과 최종 접촉/유지/달성 예산0.25/1/0.25, 활성축·관측·탐색, factory 복구, 두 Adam과 난수 상태 복원을 포함한다.

관련 회귀112개가 통과했다. [집계](regression_summary.json) · [로그](regression_tests.log). 과거 SpecialistPolicy의 엄지 관측 계약을 사용하는3개 검사는 현재 소스에서도 실패했고, 수정 전 보관 원문을 별도 프로세스에서 로딩해 동일 오류를 재현했다. 이번 변경과 무관한 해당3개는 제외 목록에 명시했다. [수정 전 재현](preexisting_contract_failures.log). 관련 없는 정책·검사를 이번 구현에 맞춰 고치지 않았다.

독립 코드 검수에서 발견한 focus 동률과 E2 관측 혼선을 수정했다. 수정본 재검수와 관측 동등 회귀에서 추가 지적은 없었다.

## GPU 검사

RTX4070Ti, GPU PhysX·CUDA 텐서 경로로 한 작업씩 실행했다. 로컬 Isaac Gym runtime의 SHA는 `gpu_probe.json`에 있다.

| 검사 | 실제 조건 | 결과 |
|---|---|---|
| 기본 GPU 실행 | 자유 강체120물리 tick | 유한 상태, 장면 정상 종료 |
| 새 보상 학습 | E4/정렬 시작/목표4축/large/8환경/H32/2반복 | 정상 완료, 체크포인트 저장,256물리 tick |
| 실제 저장본 재개 | 같은 조건에서2반복 추가 | 누적 optimizer4, 추가2 확인,256물리 tick |
| 에피소드 끝·원장·종료 | 위4반복 모델/정렬/결정론적32환경 최초 에피소드 | 32/32끝까지 완료, 물리·손목 실패0, 압현 달성0 |
| 이동 시작 조건 | E4/v9/목표4축/large/8환경/H32/1반복 | 정상 완료, 체크포인트 저장,128물리 tick |
| 지원 제거 평가 | 가중치만0업데이트로 v9/full33 전환 후32환경 평가 | 0업데이트·0물리 tick 이전 확인, 32/32끝까지 완료, 물리·손목 실패0, 압현 달성0 |

정렬 평가의 첫 대표 환경에서는 약3초 준비 중 준비 영역 진입0초·조기 접촉 후보0초였다. 이는4반복 작동 검사에서 아직 압현 기술을 학습하지 못했다는 기록이다. 작동 성공을 준비 자세·자연스러움 개선으로 해석하지 않는다. 실제 효과는 동일 예산100→200회·seed7/17 대조와 영상으로 판단해야 한다.

GPU의 기존 `finger_control_trace.jsonl.gz`에 목표 ID/시각/준비 상태/같은 표본의 기하/실제 보상 gate/관측 gate/potential을 기록한 것도 확인했다. 항별 총보상과 음 원장은 기존 파일에 남긴다. [실행 집계](gpu_smoke_summary.json).

최종 검증 종료 뒤 GPU 실행 프로세스가 남아 있지 않음을 확인했다. 구현 SHA도 최종 GPU 실행 전후 일치했다.

## 보존과 해석 한계

- [이전 runtime 검사](previous_runtime_integrity.json): 기존 봉인 파일3148개의 SHA가 모두 일치했다. 이전 모델과 결과를 덮어쓰지 않았다.
- [이번 구현 SHA](implementation_sources.json). 수정 전 활성 소스는 프로젝트 `guitar_learning/archive/20261031_before_natural_preparation_v3/manifest.json`에 있다.
- 최초 작동 검사 `smoke/aligned_E4_train2`는 검수 중 E2 관측 혼선을 수정하기 전 소스의 자료다. 성공 여부와 무관하게 최종 검증 집계에서는 제외했다. 당시 바뀐 파일은 `before_reward_gate_separation/`에 보존했다. 최종 자료는 `final_` 접두어만 사용한다.
- 기본 `guitar_learning.train`의 보상을 자동 전환하지 않았다. 새 조건은 `guitar_learning.tool.experiments.natural_press`에서 명시적으로 실행한다. 기존 checkpoint 호환이나 성능 개선을 선언하지 않는다.
