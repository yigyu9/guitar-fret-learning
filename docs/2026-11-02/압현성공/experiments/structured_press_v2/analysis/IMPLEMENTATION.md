# 구조 v2 구현·실행 검증 — 2026-10-31

구현과 소규모 실행 검증을 완료했다. 정식 A/B/C 장기 학습은 아직 시작하지 않았다. 생산 코드와 이전 비교 실험은 보존했다. [검증 요약 JSON](../validation/implementation.json) · [학습 방법](../README.md).

## 실제 변경

- 정렬된 초기 자세에서 목표 손가락4축만 배우는 A, 팔12축을 더하는 B, 전체33축과 v9 분포를 복구하는 C50/C75/C100을 연결했다.
- 이동·정렬·압현 구분을 추가하되 목표 손가락4축은 모든 구간에서 활성이다. 단계 미달 때문에 v9 목표로 잠그지 않는다.
- 기존 v9 정규화 목표각 의미를 유지하고, 지원 구간은 실제 적용된 팔 목표를 따로 유지한다. 숨은 유지 목표·타이머·단계를44열 관측으로 추가했다.
- 활성 축만 표본화·logp·entropy·KL에 포함한다. 실제 q 복원은 에피소드 경계에서만 한다. 유한 PD·힘/속도 상한·자유 기타·기존9보상·종료·곡 시계는 유지했다.
- 같은 단계의 엄격 재개와 다음 단계로 가중치만 이전하는 절차를 구분했다. 원본 입력·정책 계약·checkpoint SHA를 검증한다.
- `evaluate-free-v9`는 원래 v9에서33축과 팔 제약을 풀어 평가한다. 실패도 분모에 포함하고 환경마다 첫 에피소드만 집계한다.
- 자동 실행 도구가100회 단위로 학습·평가하고 서로 다른 checkpoint로 두 번 연속 통과해야 승급한다. 최대 예산에서 실패하면 해당 목표를 보류한다.

## 초기 자세 보정

모든 손가락 각도는 v9 그대로다. 팔·어깨·팔꿈치·손목만 조정했다. 검지·소지는 목표 패드 약10mm, 중지·약지는 약14mm에서 시작한다.

첫 중지·약지 후보에서는 소지가 목표보다 높은 프렛에 선접촉했다. 중지는 팔을 조금 높였고, 약지는 높이 조정만으로 부족해 팔 방향도 바꿨다. 최종 약지는 목표 패드14mm를 유지하면서 소지 패드를 최소14mm 띄웠다. 이 보정 후 실제 초기화 검사를 통과했다.

B는 위치 각 축±10mm 모서리8개와 방향 각 축±5도 끝점6개를 검사한 뒤 선접촉·물리/손목 실패 후보를 제외했다. **전체 오차 상자의 균일 분포나 모든 연속 자세의 안전성을 확인한 것은 아니다.** 실제 사용하는 후보별 수치·자세 식별값·검증 환경은 [catalog 검증](../validation/catalog_validation.json)에 남겼다.

## 성과와 남은 판단

이번12회 smoke의 지원 평가 달성은 **0/8**이다. 실행 경로와 손가락 제어를 검증한 결과이며 압현 학습 성공을 선언하지 않는다. B/C50의 각1회 실행은 연결 검사로서 승급 판정에 사용하지 않는다.

다음 정식 실행은 A에서 목표별100회마다 평가한다. A 기준 미달이면 B/C 장기 학습을 진행하지 않는다. 최종 채택에는 지원 없는 v9 성과, 새 seed17, 같은 총 전이 예산의 J33 대조군과 자연스러운 관절 사용의 영상 확인이 필요하다.

구현 검증용 짧은 학습의 손·전신 영상은 2026-11-04 저장 공간 정리에서 제거했다. 성공 영상이 아니며, 위 실행 검증 수치·원본 소스·보고서는 보존했다. [정리 기록](../../../../../maintenance/storage_cleanup_20261104/REPORT.md)과 [보존 대표 영상](../../../../../maintenance/storage_cleanup_20261104/REPRESENTATIVE_VIDEOS.md)을 따른다.
