# A 정책의 원래 v9·자유 33축 평가 분석

결론: 네 A 정책 모두 원래 v9에서 팔을 실제로 이동시킨 뒤 목표 손가락으로 압현하는 실행에 성공했다. 다만 팔의 이동 목표는 학습 전에 넣은 목표별 IK 정렬 bias이며, A에서 팔 보정을 학습한 결과는 아니다. 현재 가장 직접적인 학습 병목 근거는 작은 탐색 잡음만 추가해도 연속 압현이 끊긴다는 점이다. 봉인 runtime은 수정하지 않았고 GPU 실행도 하지 않았다.

## 1. 실제 자유 평가 결과

각 결과는 해당 모델의 평균 행동으로 평가한 고유한 첫 에피소드 32개다. 검지는 A100 모델, 나머지는 A200 모델이다. 모든 결과가 동일 학습 예산인 것은 아니므로 손가락 간 우열 비교에 사용하지 않는다.

| A 모델 | 자유 v9 달성 | 실패 | 자유 v9 clean 평균 / 2.5초 | 같은 모델의 지원 A clean | 실제 손목 초기→최종 상대 위치 이동 |
|---|---:|---:|---:|---:|---:|
| 검지 3줄4프렛 | 32/32 | 0 | 2.4965초 | 2.4401초 | 55.50mm |
| 중지 3줄6프렛 | 32/32 | 0 | 2.5000초 | 2.5000초 | 34.90mm |
| 약지 2줄7프렛 | 32/32 | 0 | 2.5000초 | 2.5000초 | 52.07mm |
| 소지 3줄9프렛 | 32/32 | 0 | 2.5000초 | 2.5000초 | 30.61mm |

손목 이동량은 v9 reset의 손목 기타 로컬 좌표와 완료 에피소드 `wrist_termination.wrist_G_m` 평균의 차이다. 실제 상대 끝점 변위이며 경로 길이·최대 이동량이 아니다. 기타 자체가 움직이므로 월드 좌표에서 손목만 움직인 양과도 다르다.

네 평가 합계는 128/128이지만 각 정책은 **서로 다른 단일 고정 목표**를 별도로 학습했다. 한 정책이 네 목표를 처리한 성과, 새로운 줄·프렛 일반화, 무작위 초기 분포 일반화로 표현하지 않는다. 성공은 현행 실제 GPU net body load와 source pad 기하의 clean 대리지표이며 개별 접촉점 압력·진동·실제 소리의 증거가 아니다.

## 2. free_v9에서 남는 지원과 없어지는 지원

`evaluate_free_v9`는 원 checkpoint 원본 identity/SHA를 검증한 뒤 가중치만 명시 이전한다. 초기화는 `v9_fraction=1`, 활성 마스크는 왼손 33축이다. optimizer를 재개하거나 이 평가에서 새로 학습하지 않는다.

`StructuredPool.step`의 팔 hold/clamp 지원은 `stage != 'free_v9'`일 때만 적용된다. 따라서 이 평가에서는 A의 고정 팔 실행과 press 단계 ±0.05 팔 보정 제한이 모두 해제된다. 활성 33축의 행동을 그대로 공용 유한 제어에 전달한다. 원래 PD·평활화·속도/관절/힘 한계와 발 IK는 남아 있다. 이 물리 제어는 원래 환경의 일부다.

phase 전환과 `hold_action` 값 자체는 관측·로그에 계속 남으며 press 진입 때 latch도 갱신된다. 그러나 free_v9에서는 그것을 팔 강제 유지 명령으로 적용하지 않는다. 따라서 로그의 `final_hold_action`이 있다는 이유로 숨은 팔 지지가 남았다고 판단하면 안 된다.

한편 **초기화 때 생성한 IK 정렬 bias는 checkpoint 가중치로 남아 있다.** 이 부분은 제거된 지원과 구분해야 한다.

## 3. 팔이 움직이는 방식: 학습한 정렬 피드백이 아니라 상수 목표각

네 checkpoint와 해당 `initial.pt`를 CPU에서 직접 비교했다.

- `core.support_head.weight`의 팔 12행은 네 모델 모두 정확히 0이다.
- `actor_extra` 최종 출력의 팔 12행 weight와 bias도 모두 정확히 0이다.
- 이 네 파라미터의 팔 부분은 학습 전 `initial.pt`와 학습 후 checkpoint에서 완전히 같다.
- 비영(非零) `core.support_head.bias`는 기하 catalog의 정렬 유지 목표를 같은 v9 codec으로 역변환한 값이다. `tanh(bias)`와 catalog 정규화 목표의 최대 차이는 약 1.02e-6 이하다.
- 완료 에피소드의 팔 12축 `executed_action_max−executed_action_min`은 네 모델 모두 정확히 0이다.

따라서 네 자유 평가의 팔 **정책 평균 명령은 전체 에피소드 동안 관측과 무관한 상수**다. 원래 v9와 다른 이 고정 관절 목표를 첫 tick부터 요청하고, 평활화·속도 제한·유한 PD와 실제 물리를 거쳐 팔이 정렬 근처로 이동한다. 목표별 최대 팔 요청각 변화는 v9 대비 검지 5.01°, 중지 3.70°, 약지 7.51°, 소지 3.42°다.

학습된 손가락 정책은 그동안 바뀌는 상태·접촉·음 시계를 보고 손가락 행동을 낸다. 그러므로 실제 팔 이동과 능동 손가락 압현 실행은 성과다. 그러나 ‘정책이 목표를 보고 어깨·팔꿈치·손목 정렬을 학습했다’거나 ‘학습 중 팔을 자유롭게 탐색해 이 경로를 발견했다’고 표현할 근거는 없다. A에서는 팔 encoder/head를 동결했고, 최종 팔 출력은 미리 계산한 목표별 IK bias 그대로다. 관절각 오차를 줄이는 PD 피드백과, 관측에 따라 목표각을 바꾸는 학습된 피드백도 구분한다.

또한 free_v9의 모든 33축이 실행 가능해도, 엄지·비목표 손가락 평균 출력은 A 학습에서 갱신하지 않은 0 행동으로 남는다. 실제 비목표 17축의 최대 관절 이동폭은 검지 모델 약 0.35°, 중지 0.35°, 약지 0.24°, 소지 0.04°였다. 전체 손가락 제어를 학습한 증거는 아니다.

## 5. 실제 궤적에 관해 알 수 있는 범위

free-v9 평가에는 모든 105축·body pose 전 시계열 `poses_env0000.npz`가 저장되지 않았다. `gpu_scene_initial/final.json`도 상태 궤적이 아니라 장면 진단 metadata다. 따라서 원시 실제 팔 12축의 시간 곡선이나 손목 경로 곡률을 이 기록으로 복원할 수는 없다.

대신 다음 근거는 남아 있다.

- 팔 정책의 상수 실행 명령: 완료 에피소드의 action min/max.
- 실제 손목 상대 끝점: `wrist_termination.wrist_G_m`와 v9 reset body pose.
- 실제 손목 허용 영역 이탈의 240Hz 평균·최대 및 inside 비율: `left_episode_diagnostics.wrist`.
- 실제 손가락 21축의 240Hz env0 trace, 32개 완료 에피소드의 60Hz min/max/range·추종 오차.

free 평가에서 전체 6초의 wrist-box inside 평균 비율은 검지 45.4%, 중지 60.1%, 약지 2.7%, 소지 100%였다. 이는 곧 손목 실패율이 아니다. box 경계 밖이어도 현행 종료의 2~3cm 누적/복귀 조건 아래면 계속 진행한다. 약지의 좁은 box 점유와 압현 32/32는 모순이 아니며, 향후 안내 영역을 실제 성공 자세와 비교할 별도 근거다.

관측 phase의 평균 move/align/press 체류는 검지 0.29/0.81/4.90초, 중지 0.32/2.26/3.42초, 약지 2.39/0.15/3.46초, 소지 0.08/0.12/5.80초다. free_v9에서는 이 phase가 팔 제한을 적용하지 않으므로 순서에 따라 잠금 해제된 학습의 증거로 사용하지 않는다.

## 6. 다음 실험의 우선순위

### 즉시 병목 확인: 잡음 감소의 한 요인 비교

동일 검지 A100 모델에서 지원·초기 분포·평균 정책을 유지하고 잡음만 바꾼 평가가 직접적인 근거다. 현재 확인된 값은 다음과 같다.

| 잡음 배율 | 달성 | 물리·손목 실패 | clean 평균 |
|---|---:|---:|---:|
| 0, 평균 행동 | 32/32 | 0 | 2.4401초 |
| 0.25 | 0/32 | 0 | 0.6491초 |
| 0.50 | 0/32 | 0 | 별도 report/metrics 참조 |

평균 정책은 이미 안정적으로 누르는데 작은 독립 탐색만 추가해도 1초 연속 clean을 만들지 못한다. 따라서 지금 ‘학습에서 압현 경험이 부족한 이유’에는 탐색 분산·시간적 잡음이 더 직접적인 실험 대상이다. 목표로 더 이동하지 못해서만 실패한다는 설명은 위 A/free 평균 정책 결과와 맞지 않는다.

권장 한 요인 학습 비교는 같은 A checkpoint에서 두 분기를 만들고 동일 새 optimizer·seed·64환경/H32·100업데이트로 추가 학습하는 것이다. 현행 목표 finger std/floor를 유지한 분기와, 그 두 수치를 동일 0.1배로 한 분기를 비교한다. 즉 약 0.15/0.10 대비 약 0.015/0.010이다. 학습 전 평균 정책은 동일하게 두고, 실제 likelihood·entropy·KL도 변경한 분포를 일관되게 사용해야 한다. checkpoint 파라미터만 바꾸고 숨은 floor를 남겨 놓으면 비교가 성립하지 않는다. 평가에서는 지원 A와 free_v9를 구분하며 평균 성과·탐색 중 clean·연속 유지·관절 범위를 함께 기록한다. 낮은 탐색의 새 목표 학습 능력은 이 미세조정 실험이 검증하지 않는다.

### 별도 질문: full33 fresh 200 대조

A 교육과정이 필요한지를 묻는다면 full33 fresh 200은 의미가 있다. 그러나 목적은 잡음 원인 확인과 다르다. 정확한 비교를 위해 다음을 명시한다.

1. 중지·약지·소지의 A200 중 같은 목표·같은 seed·같은 누적 전이 409,600개를 기준으로 한다. 검지 A100과 full33 200을 직접 교육과정 효과로 비교하지 않는다.
2. 같은 모델 구조·초기 손가락 평균·std/floor·보상·시계·물리·원래 v9 평가 분모를 유지한다.
3. **미리 계산한 IK 팔 bias를 동일하게 사용할지 반드시 명시한다.** 현행 `StructuredPolicy`는 fresh `free_v9`에서도 catalog 정렬 bias를 넣는다. 이것을 사용한 full33 fresh는 ‘팔 정렬 선지식이 같은 조건에서 A의 초기분포/활성 축 제약이 필요한가’를 검사한다.
4. 팔 bias를 0(v9)으로 바꾼 fresh 조건은 ‘IK 정렬 선지식까지 제거한 상태에서 팔 이동을 배울 수 있는가’라는 추가 실험이다. 이를 A 지원 효과 하나의 차이로 해석하면 안 된다.
5. 현재 IK bias의 일부 팔 축은 normalized action |a|>0.99다. 검지·중지·소지에서는 L_Thorax_y, 약지에서는 L_Thorax_y와 z다. `tanh` 포화 부근은 같은 latent std라도 물리 목표각 탐색이 매우 작다. ‘33축 활성’만으로 팔을 충분히 탐색했다고 판단하지 않는다.

우선순위는 현재 진행 중인 잡음 진단을 마친 뒤 감소 잡음 학습 비교다. full33 fresh matched 200은 교육과정의 필요성과 IK 사전 지식의 역할을 판정하는 독립 대조로 남긴다. 현재 성과는 ‘목표별 사전 팔 정렬각 + 학습된 손가락 제어가 v9에서 실행 가능함’까지로 정확히 표현한다.
