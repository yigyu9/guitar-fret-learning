# 병렬·장기 학습 안내

현재 GPU 왼손 기본은 하나의 GPU 시뮬레이터 안에 여러 환경을 배치한다. H32의 수집 경계는 진행 중인 장면·곡 시계·접촉 원장을 초기화하지 않는다.

실행 예시·기본값·저장 간격은 [학습 안내](../README.md), 출력과 자원 기록은 [로그 안내](LOGGING.md)를 따른다. 환경 수는 GPU 메모리뿐 아니라 해당 장면의 처리 속도와 실패율을 확인해 정한다. 1024환경 예시나 현재 단음 실험의64환경을 모든 장면에 적용할 최적값으로 해석하지 않는다.

[효율 비교의 당시 결과](../../docs/2026-11-02/수정사항/연구환경효율검증/RESULTS.md)는 그 실험의 설정과 함께 읽는다. 예전 CPU 물리의 N8/H256 권고는 현행 GPU 환경 수 선정 근거가 아니다.

이 문서의 구형 CPU 병렬·메모리·전문 실행 설명은 [정리 전 원문](../../docs/archive/document_cleanup_20261030/before/guitar_learning/docs/PARALLEL_TRAINING.md)에 보존했다. 그 명령은 해당 시점의 소스와 계약을 복원할 때만 사용한다.
