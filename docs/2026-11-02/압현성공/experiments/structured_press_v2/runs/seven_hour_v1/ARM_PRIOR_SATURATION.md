# 초기 팔 정렬 prior의 포화 진단

2026-10-31. CPU 읽기 분석과 CPU 표본 검사만 수행했다. GPU·봉인 runtime·학습 구현을 변경하지 않았다.

결론: 초기 출력 12축 중 L_Thorax_y 한 축이 tanh≈0.999999로 포화되어 있다. 이 축의 물리 탐색 폭은 매우 작다. 그러나 actor gradient가 0이거나 PPO의 replay가 잘못되었다는 근거는 아니다. 실제 학습 가중치는 변했고 나머지 팔 축도 움직였다. 포화가 전체 실패의 원인인지는 아직 검증하지 않았다.

## 초기 12축과 두 종류의 경계

12축은 **왼쪽 L_Thorax/Shoulder/Elbow/Wrist 각각 xyz**다. 양팔 전체가 아니다. 정책 bias는 무작위 scratch 팔 목표가 아니라 catalog hold_target105를 v9 reference 기준으로 역변환한 사전 IK 정렬 prior다. 초기 support_head.weight norm=0이므로 이 표의 bias가 초기 해당 mean이다. 학습 후에는 관측별 encoder/extra 출력이 더해지므로 bias만으로 전체 mean을 대신할 수 없다.

controller는 양수와 음수에 서로 다른 span을 쓴다: q_target=reference+a×(action_upper−reference), a≥0; 음수면 reference+a×(reference−action_lower). action 범위는 native 범위와 v9±0.35rad의 교집합이다. 따라서 action 끝이 항상 native 끝은 아니다.

## 물리 탐색 폭과 PPO replay 확인

현재 축의 latent 표준편차는 exp(−3)=0.0497871이다. seed902의 CPU float32 200,000개 표본을 실제 초기 μ/std로 뽑았다.

| 초기 조건 | normalized action 표준편차 | 물리 목표각 표준편차° | 표본 action 최솟값/최댓값 |
|---|---:|---:|---|
| original | 1.03208357e-07 | 1.03208386e-07 | 0.999998391 / 0.999999344 |
| cap099 | 0.000999276179 | 0.000999276462 | 0.984345078 / 0.993639469 |

비교 표본은 같은 noise를 사용했으며 원래와 .99 cap 모두 exact action=1인 표본 비율0이다. 위 값은 정책 한 축의 CPU 표본이며 물리 rollout의 힘/접촉 결과가 아니다. 부드러움·rate limit을 거치면 실제 관절 탐색은 추가로 달라진다.

PPO는 score-function 방식이므로 actor mean의 log-probability gradient가 단순히 tanh 미분과 같지 않다. 작은 tanh 미분은 물리 출력 민감도와 탐색의 압축을 설명한다. 그것만으로 optimizer gradient가 0이라고 하면 틀리다.

현재 FingerSkillPolicy.act는 action과 별도로 **원래 pre-tanh latent**를 반환한다(policy.py:549~561). rollout은 그 latent/logp/old_mean/std를 그대로 복사 저장한다(rollout.py:250~266). PPO는 저장된 latent로 evaluate한다(ppo.py:289). log_probability는 안정적인 softplus Jacobian을 사용한다(policy.py:533~537). atanh(clipped action)로 역산하는 replay 경로가 없다. 실제 해당 method로 위200,000개 latent의 수집/재평가 logp를 비교한 최대 오차는0, 전부 finite다. 따라서 제기된 inverse-clamp replay 불일치 가설은 현재 경로에서 지지되지 않는다.

## 인과 해석과 최소 후속안 — 미구현

모든 팔 bias12개를0으로 지운 실험의100회 훈련은 완료706 episode 중 안전성공0, guitar_displacement314개이고, 평균 정책 평가도0/32다. 초기 모델 차이가 bias12개뿐이며 CPU/CUDA RNG가 같다는 직접 증거를 별도 NO_ALIGNMENT_PRIOR_ANALYSIS에서 확인했다. 그러나 이것은 **한 포화 축만 완화한 실험이 아니다**. 필요한 사전 정렬 목표를 전부 제거한 변화이므로 ‘포화를 해제하면 실패한다’거나 ‘포화가 필수다’라고 결론내리면 안 된다.

가장 작은 향후 비교는 다른11축·초기 상태·RNG·모든 가중치/설정을 유지하고, 초기 normalized prior를 ±0.99로 cap하는 것이다. 현 초기12축 중 바뀌는 것은 포화된 axis1뿐이다. μ는7.247733→atanh(.99)=2.646653, tanh 미분은2.0266e−6→0.0199로 약9,819배다. 물리 목표 차이는 **약0.009999°**로 아주 작다(.1° 아님). cap 전후 초기 실제 q는 바꾸지 않는다.

이 경우에도 현재 std에서 양수 목표각 탐색 표준편차는 약0.001°에 불과하므로 충분한 탐색이라고 미리 가정하지 않는다. 먼저 동일 원본 모델/RNG에서 단일 bias 변경을 직접 검증하고 초기 짧은 물리 안정성·실제 q/hold·물리 접촉·실패를 확인한 후 같은100회 예산을 비교한다. baseline과 cap을 같은 시작 상태로 대조하고 목표 줄의 clean·wrong_string·실제 팔 목표 변화 및 actor 분포를 함께 본다. 개선을 원인 확정으로 확대하거나 CPU 수치만으로 native 성공을 예상하지 않는다.

이 후속안은 **제안만 했으며 구현·학습·GPU 검사하지 않았다**. 현재의100회 성공→200회 오압현 붕괴는 다른 팔 축/손가락 출력과 접촉 전략 변화도 함께 보아야 한다. 이번 자료는 한 축의 탐색 부족 가능성을 좁히며 전체 원인 판정은 아니다.
