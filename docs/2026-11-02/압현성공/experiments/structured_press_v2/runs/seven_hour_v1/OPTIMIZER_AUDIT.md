# PPO 최적화 상태 비교

집계 시각: 2026-10-30T23:19:38.646652+00:00

완료된100회 블록16개와0회 반영 실패 smoke1개를 검토했다. 진행 중인 fresh100/200은 pending으로 남겼다. 서로 다른 손가락·목표·활성축·A/B/free 조건은 같은 난이도 비교가 아니다. 모든 평균은 별도 표기가 없으면 **완료 PPO update별 요약값의 단순 평균**이다. 원시 데이터 전체의 합동 표준편차·전체 minibatch 분포로 확대 해석하지 않는다.

## 직접 확인한 결론

현재 로그에서는 “학습률이 바닥에 내려가 학습이 멈췄다”는 공통 원인이 확인되지 않는다. 검지 A100과 소지 A100/200은3e-5를 유지했고, 원래 full33의100/200회 블록도7.5e-6 하한에 머문 update가0개다. 반면 더 낮은 실제 LR을 사용한 분산0.1 B가 학습 중 안전 성공은 크게 높았다. LR만 따로 바꾼 대응 실험이 아니므로 작은 LR의 독립 효과는 아직 미입증이다.

actor는 거의 매 update의 마지막 minibatch에서 gradient clipping을 받았다. 기본 검지 B의 clipping 전 norm 평균7.01, 분산0.1 검지 B23.23, 기본 소지 B7.28, 분산0.1 소지 B31.63이다. 작은 sigma에서 평균 변화에 대한 KL과 logp 기울기가 민감해진 증거와 일치한다. 그러나 clipping 빈도만으로 이것이 실패 원인이라고 단정할 수 없다. 작은 sigma 조건이 실제 수행은 더 좋았기 때문이다.

학습 중 Gaussian entropy는 각 조건 안에서 거의 일정했다. 예를 들어 full33 약−47.76, B 기본 약−20.88, B sigma0.1 약−30.09이다. 활성축4/16/33의 합산 entropy는 직접 크기를 비교하면 안 된다. 같은 B 축수에서 목표4축 sigma를0.1배로 줄이면 entropy가 약4·ln(0.1)=−9.21만큼 낮아지는 것은 설계된 변화다. 시간 경과에 따른 급격한 탐색 붕괴/annealing은 이 구간 로그에서 보이지 않는다.

팔 초기 정렬 prior를 제거한 조건은100/200블록에서 종료 실패314/706,303/706으로 초기 정렬을 유지하는 조건보다 훨씬 어렵다. 이 실패는 물리 실패와 손목 영역 종료의 합집합이며, 각각의 원시 count는 JSON에 분리했다. 원시 결합 advantage std 평균1.046/1.116은 기존 full33 0.083/0.082보다 크고, cost critic post-update MSE1.520/1.393도 기존0.00334/0.00601보다 크다. 정규화 후 advantage std가 모두1에 가깝다는 사실은 이 차이가 없다는 뜻이 아니다. 실패·비용 신호와 어려운 상태 분포가 현재 로그에서 직접 드러나는 병목이다.

`clip_grad_norm_` 반환값을 코드에서 확인했다. actor_grad_norm은 **clipping 전 전역 actor norm**이며 최상위 항목은 마지막으로 수용된 actor minibatch의 값이다. 표의 빈도는 모든 minibatch의 clipping 비율이 아니다. `diagnostics.minibatches.actor_accepted.sample_weighted_mean.grad_norm_pre_clip`도 JSON에 따로 담았다. actor/value optimizer는 각각 같은0.5 한도를 적용한다.

KL<0.005·재시도0이10회 연속이면 다음 LR×1.25, 상한3e-5다. full rollout analytic KL guard는0.02이며 성공 update들의 KL 평균은 모두 그 이하다. 분산0.05 smoke는 최초 update에서 KLGuardError로 종료되어 optimizer0·committed0이었다. 이 실행의 learning_metrics는0행이므로 그 실패를 “평균 KL0/재시도0”으로 해석하면 안 된다. 실패 보고서와 traceback만 유효한 증거이며 수용 update 표에는 넣지 않았다.

EV는 매 update 후 같은 rollout의 유효 결정에서 현재 critic과 GAE return target을 비교한 explained variance다. 음수는 그 target 분산 기준으로 평균 예측보다 오차 분산이 크다는 뜻이며 실제 곡 성공률이나 독립 검증 성능이 아니다. 평균 EV가 낮거나 음수인 조건이 여럿 있지만, 이것이 모든 실패의 원인이라는 인과 검증은 없다. 예를 들어 분산0.1 소지 B는 reward EV0.174로 기본 B0.640보다 낮아도 학습 성공은 훨씬 높았다. cost target 분산이0이면 EV는 None이며, 없는 값을0으로 채우지 않았다.

entropy는 물리 손가락 운동량이 아니라 활성 latent Gaussian 분포의 미분 entropy다. actor loss는 PPO clipped objective이며 코드상 별도 entropy bonus를 더하지 않는다. 이 표는 실제 관절 이동·접촉 성공을 대신하지 않는다.

## 미입증 가설과 다음 검증

- **독립적인 LR 효과:** sigma 변경은 같은 LR 규칙 아래 실제 재시도/LR 경로도 바꾼다. 낮은 LR만 고정한 대응 비교가 없으므로 sigma 효과와 학습률 매개 효과를 분리해 단정하지 않는다.
- **공유 gradient clipping의 역할 배분:** 대부분의 마지막 actor minibatch가 clipping되므로 팔/손가락 gradient의 상대적 기여가 중요한 후보지만 현재 로그에는 그룹별 norm이 없어 확인할 수 없다. 한도를 즉시 높이는 근거도 부족하다.
- **critic 신뢰도:** 여러 조건의 낮은 EV와 초기 정렬 제거 시 큰 cost MSE는 점검 대상이다. 독립 rollout의 값 보정이나 critic만 변경한 실험 없이 reward/critic 구조를 원인으로 확정하지 않는다.
- **평균/표본화 수행 차이:** 동일 체크포인트를 고정한 stochastic probe로 정책 갱신 요인을 제거한 뒤 비교한다. 현재 evolving 학습과 deterministic 평가만으로 잡음 효과를 완전히 분리하지 않는다.
- **fresh sigma0.1:** 진행 중이므로 결과와 초기/재개 감사가 끝나기 전에는 개선을 주장하지 않는다.
