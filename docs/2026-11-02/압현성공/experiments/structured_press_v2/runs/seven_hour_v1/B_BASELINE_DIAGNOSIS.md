# 같은 초기 상태에서 B0/B100/B200의 압현 유지 차이

결론: B100은 압현 자체를 못 하는 정책이 된 것이 아니라, **접근·접촉 시작이 늦어지고 접촉 후 담당 손가락의 하중도 끊기면서 유지 시간이 줄었다.** 오압현과 법선 방향 실패는 주원인으로 관측되지 않았다. B200은 일부 회복했지만 B0보다 유지가 짧다. 이 결과만으로 탐색 잡음이 평균 정책을 악화시켰다는 인과까지 확정하지 않는다.

## 비교가 성립하는 조건

reset seed 4242, 같은 환경 번호별 실제 초기 q105·hold target·body 상태가 일치한다. 세 평가의 초기 조건 SHA는 `57a7b84458298b1236c80c881c39d9f78c62b89fe8f64d3531d61b3ebe74669b`로 같다. 각 조건은 같은 첫 에피소드 32개, 목표 검지3줄4프렛, 3.0~5.5초 음 구간, 평균 행동으로 평가했다. B0는 A100 가중치를 B로 이전한 뒤 추가 학습 전 정책이다.

| 지표 | B0 | B100 | B200 |
|---|---:|---:|---:|
| 안전 달성 | 32/32 | 32/32 | 32/32 |
| 물리/손목 실패 | 0/0 | 0/0 | 0/0 |
| 평균 누적 clean | 2.43385초 | 1.88867초 | 2.26367초 |
| 평균 최장 연속 clean | 2.43385초 | 1.78529초 | 2.20690초 |
| 오압현 | 0초 | 0초 | 0초 |
| missing 적분 | 0.06406초 | 0.59557초 | 0.22982초 |
| 복수 clean 구간이 있는 에피소드 | 0/32 | 32/32 | 32/32 |

B100과 B200 모두 32개 **각각** B0보다 clean이 짧았다. 하지만 최장 연속 clean이 전부 1초를 넘으므로 달성률은 그대로 100%다. 현재 성공 기준을 실험 도중 바꾸지 않되 유지 시간을 함께 봐야 이 회귀가 보인다.

후보 ID 3/9/11의 표본 수는 각각 8/12/12개로 세 조건에서 같다. 후보별 평균 clean은 B0 2.426/2.435/2.438초, B100 1.886/1.884/1.895초, B200 2.250/2.265/2.272초다. B100 저하는 특정 초기 후보 한 개에 국한되지 않는다.

## 1. 무엇이 clean 시간을 빼앗았나

이 가상 목표에서는 press=onset=3초다. 아래 geometry/facing/load 시간은 3~5.5초의 적분이다. near 시간만 준비를 포함하는 1~5.5초이므로 같은 분모의 점유율로 섞지 않는다.

| 평균 시간 | B0 | B100 | B200 |
|---|---:|---:|---:|
| 접촉 위치 기하 유효 | 2.47214초 | 2.19518초 | 2.32721초 |
| 위치+법선 유효 | 2.47214초 | 2.19518초 | 2.32721초 |
| 지정 패드 기하+담당 body 하중 유효 | 2.43802초 | 1.90651초 | 2.27227초 |
| 양쪽 물리 끝점에서 연속 유효한 clean | 2.43385초 | 1.88867초 | 2.26367초 |
| 준비 포함 1cm 근접 시간 | 2.68073초 | 2.29792초 | 2.36107초 |

세 조건 모두 위치 기하 시간과 법선 포함 시간이 정확히 같다. 따라서 위치 조건은 통과했는데 facing 문턱 때문에 추가로 떨어진 시간은 없다. own wrong fret/string와 other higher, supported/ambiguous wrong도 모두 0이다.

B0 대비 B100의 clean 손실 **0.54518초**는 다음처럼 정확히 분해된다.

- 위치 기하 유효 시간 감소: **0.27695초**.
- 위치·방향은 유효하지만 담당 body 하중이 부족한 시간 증가: **0.25456초**.
- 현재 끝점은 유효해도 이전 끝점과 연결되지 않는 보수적 연속 판정 손실 증가: **0.01367초**.

이는 같은 시간 창의 게이트 적분을 이용한 분해다. 서로 다른 물리 원인이 각각 이 비율로 발생했다는 힘의 인과 분해는 아니다. B200의 B0 대비 잔여 손실 0.17018초는 같은 순서로 0.14492/0.02083/0.00443초다. B200에서 하중 부족 시간은 상당히 회복됐지만 기하 유효 시간이 아직 짧다.

B100의 최소 패드 거리는 평균 약 0.020mm로 B0의 0.194mm보다 작았다. 하지만 이는 에피소드 전체 중 가장 가까웠던 한 순간이다. 더 오래 안정적으로 가까웠다는 뜻은 아니며 접촉 시간 감소와 모순되지 않는다.

## 2. 시작 지연과 접촉 끊김을 구분할 수 있나

32개 전체의 누적값만으로는 둘을 분리할 수 없다. 다만 저장된 **env0·첫 에피소드의 실제 240Hz trace**에서는 다음을 직접 확인했다. env0는 세 조건 모두 후보 ID 11이다.

| env0 실제 기록 | B0 | B100 | B200 |
|---|---:|---:|---:|
| 3.0초 패드 거리 | 5.26mm | 36.08mm | 36.25mm |
| 최초 candidate | 3.0625초 | 3.3458초 | 3.1958초 |
| 양수 clean streak 최초 기록 | 3.0667초 | 3.3500초 | 3.2000초 |
| 눈에 보이는 clean 구간 수 | 1 | 5 | 2 |

B100은 최초 접촉부터 B0보다 약 0.283초 늦었다. 3.35~3.48초 사이 짧은 clean 구간 세 개가 생겼고, 이후 약 3.48~3.72초에는 3.708초의 1/240초 짧은 구간 외에 계속 유지되지 못했다. 3.60초에는 패드 거리 2.64mm, 위치 기하 true, 법선 cos 0.9998인데 담당 body loaded=false여서 candidate=false였다. 방향이 틀어져 끊긴 장면과 다르다. 약 3.72초 이후에는 끝까지 긴 clean을 만들었다.

B200은 최초 접촉 지연이 약 0.196초로 줄고 첫 짧은 clean 뒤 약 3.29초부터 긴 연속 clean을 만들었다. 이것이 회복의 env0 예다. 이 시각을 다른 31개 에피소드의 실제 시각으로 확대하지 않는다.

trace의 5.5초 행은 목표 선택이 사라지면서 목표별 clean 항목이 생략된다. 따라서 trace에서 보이는 최장 streak는 원시 완료 에피소드의 정확한 최장값보다 마지막 1/240초가 덜 보일 수 있다. 32개 성과와 clean 길이는 완료 에피소드 원장을 기준으로 하고, trace는 사건 시각을 확인하는 데만 사용했다.

## 3. 어떤 움직임이 달라졌나

env0의 3초 실제 검지 각도는 다음과 같다.

| 실제 관절 | B0 | B100 | B200 |
|---|---:|---:|---:|
| MCP 굽힘 | 27.72° | 12.69° | 16.71° |
| PIP | 47.27° | 34.93° | 38.43° |

B100은 음 시작 시 MCP가 약 15°, PIP가 약 12° 더 펴져 있었다. 같은 시각 적용 목표도 MCP 13.39°/PIP 35.71°로 펴진 쪽을 요청했다. 즉 큰 굽힘 명령을 내는데 관절이 전혀 못 움직인 상황만으로 설명할 수 없다. 평균 정책 자체가 더 펴진 준비 상태를 만들고, 음 시작 뒤 큰 이동을 해야 했다. 동시에 팔 행동도 바뀌므로 거리 증가의 전부를 손가락에만 배분할 수는 없다.

32개 평균 MCP/PIP 실제 이동폭은 B0 26.13/21.47°에서 B100 31.09/25.87°, B200 32.70/26.30°로 커졌다. MCP 벌림 이동폭도 1.77→8.99→11.10°로 커졌다. 실제/목표 native 한계 체류와 바깥쪽 명령 비율은 목표 네 축 모두 0이므로 관절 한계에 걸려서 생긴 실패라는 근거는 없다.

추종 오차도 커졌다. 완료 6초의 관절별 RMS 평균은 다음과 같다.

| 목표−실제 RMS | B0 | B100 | B200 |
|---|---:|---:|---:|
| MCP 굽힘 | 2.15° | 3.31° | 3.48° |
| PIP | 1.64° | 2.63° | 2.71° |
| DIP | 0.58° | 0.68° | 0.74° |

더 큰/빠른 목표 변경과 지연이 함께 발생했다. 다만 B200은 추종 RMS가 더 큰데 clean은 회복했으므로 ‘추종 오차 하나가 clean 손실 전부의 원인’이라고 할 수 없다.

## 4. phase·팔 지원은 어떻게 바뀌었나

| 6초 평균 누적 시간 | B0 | B100 | B200 |
|---|---:|---:|---:|
| move | 0.083초 | 0.083초 | 0.083초 |
| align | 0.544초 | 1.937초 | 3.095초 |
| press | 5.372초 | 3.979초 | 2.821초 |
| wrist 준비 조건 미달 | 0초 | 0.0375초 | 0.1010초 |
| tangent 준비 조건 미달 | 0.0865초 | 3.0234초 | 2.5786초 |
| height 준비 조건 미달 | 2.5880초 | 5.4891초 | 5.6516초 |
| normal 준비 조건 미달 | 0초 | 0초 | 0초 |

phase 시간은 준비·말미까지 합친 값이며 음 구간의 clean 시간과 다르다. 특히 준비 height 조건은 2~20mm인데 실제 접촉은 −1~3mm에서 유효하다. 성공한 접촉의 높이<2mm도 height blocked로 기록된다. 따라서 위 height blocked 전체를 접근 실패 시간이라고 해석하면 안 된다.

B0에서도 팔 정책 평균은 A의 상수 정렬 bias이지만, B 실행의 phase 기반 latch/보정 제한 때문에 적용 전 단계의 executed action은 일부 축에서 시간 변화가 생겼다. 32개 중 팔 normalized action의 최대 시간 변화는 B0 약 0.0900, B100 0.1265, B200 0.2342였다. B100은 대부분의 팔 축에서 평균 action 범위가 커졌다. B200은 더 커졌는데 clean이 회복했으므로 팔 이동 증가 자체를 악화 원인으로 단정할 수 없다.

손목 안내 상자 내부 비율은 오히려 44.7→67.8→78.0%로 개선됐다. 손목이 넓은 안내 영역에 들어오는 것과 손가락 패드가 정확히 닿는 것은 다르다. 실제 음 시작의 패드 거리와 더 펴진 손가락 상태가 이 차이를 보여준다.

## 5. 보상과 원인 가설

32개 평균 목표 패드 접근 항은 −1.48848→−1.46110→−1.47099로 B100에서 약간 좋아졌지만, 압현 유지 보상은 0.97354→0.75547→0.90547로 나빠졌다. 최초 접촉·달성 보상은 모두 0.25씩으로 이미 포화했고, 대기 자세 항도 약 0.1027로 같다. 행동 변화 비용은 약 1e-6 수준이다. 이번 clean 감소를 오압현 비용이나 손가락 움직임 비용 탓으로 설명할 수 없다.

현재 근거로 강한 설명은 **더 멀고 펴진 준비 자세에서 늦게 진입하고, 접촉 초기에 하중을 안정적으로 유지하지 못했다**는 것이다. 그 평균 정책이 왜 그렇게 갱신됐는지에는 다음 가설이 남는다.

1. 확률적 학습의 큰 탐색 아래 좋은 A 평균을 보존하지 못했을 수 있다. 현재 별도 잡음 축소 학습 비교가 이를 검증하는 더 직접적인 실험이다. 이 문서의 비교만으로 원인을 확정하지 않는다.
2. 새로 학습한 팔과 기존 손가락 출력이 서로 보상하며, 넓은 손목 안내를 만족하는 과정에서 손끝 초기 거리를 늘렸을 수 있다. 같은 모델의 팔/손가락 실행 블록을 각각 A/B로 바꾸는 명시적 진단 개입이 있어야 역할을 분리할 수 있다.
3. 접촉 초반의 실제 힘 여유가 부족하거나 유한 PD·동역학으로 하중이 떨어졌을 수 있다. loaded=false는 0.01N 문턱 미달이라는 게이트 증거지만, 현재 trace에는 실제 distal body force 크기와 방향이 없어 여유를 수치로 계산할 수 없다.
4. phase latch 시점/팔 보정 clamp가 필요한 정렬을 제한했을 수 있다. 현재 누적 phase 시간만으로 어느 시점의 어떤 명령이 잘렸는지 증명하지 못한다.

## 다음에 남기면 원인을 분리할 최소 로그

기존 대용량 전 시계열을 모두 늘리는 대신, clean의 시작/끊김·phase 전환 때 진단 사건 행을 남기고 음별 요약을 저장하는 편이 적절하다.

- **32개 각각의 음 수행 시각:** 최초 candidate·최초 clean·최장 run 시작/끝·run 수. 그래야 시작 지연과 중간 끊김을 평균만으로 추정하지 않는다.
- **끊김의 실제 게이트:** 동일 유효 표본의 signed height, 현 lateral, fret 양쪽 inset 여유, normal cosine, distal net force norm−0.01N. 거리 하나는 −1~3mm 높이·3mm lateral·셀 조건의 여유를 대신하지 못한다. nearest 표본과 실제 positive 증인 표본도 구분해야 한다.
- **팔 지원이 명령을 자른 양:** raw arm action, latch 기준, clamp 뒤 명령, rate-limit 뒤 목표, 실제 q·손목G, phase/전환 시각. 전부가 부담되면 최대 차이·축과 이벤트 시점만 남긴다.
- **명시적 역할 분리 평가:** 같은 paired 초기32에서 A팔+B100손가락 / B100팔+A손가락의 두 실행을 비교한다. 이것은 원래 정책의 성능이 아니라 결정론적 실행 개입 진단으로 별도 표기하고, checkpoint 원본과 성공 기준은 바꾸지 않는다.

현재는 예정된 잡음 축소 B100의 paired 비교를 먼저 수행하고, clean·longest·기하·하중·첫 접촉 시각을 이 baseline과 비교하는 것이 가장 직접적이다. 평균 정책 악화가 줄어드는지 확인한 뒤 다음 요인으로 넘어간다.
