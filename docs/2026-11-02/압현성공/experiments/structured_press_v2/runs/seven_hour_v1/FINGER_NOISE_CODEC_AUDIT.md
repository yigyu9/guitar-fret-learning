# 손가락 탐색의 물리 각도 단위와 비대칭 codec 감사

2026-10-31. **CPU 요청각 분포 진단이며 실제 관절 운동·접촉·실패 원인 검증이 아니다.** native rate limit·smoothing·PD·물리는 적용하지 않았다. decoder나 보상·학습 구현은 변경하지 않았다.

같은 latent 표준편차라도 관절별 실제 요청각 탐색 폭이 다르며, μ=0일 때도 비대칭 reference 기반 변환 때문에 평균 요청각이 reference와 다를 수 있다. 현재 초기 검지 DIP는 mode14.15°지만 실제 저장 σ=.15의 요청각 평균은 약17.50°다. 이는 학습 이전부터 생길 수 있는 분포 성질이며 DIP 과사용·충돌의 원인으로 확정한 결과가 아니다.

용어: 이 문서와 표의 `mode`는 Gaussian latent mean을 결정적으로 실행한 요청각 `θ(tanh μ)`를 뜻한다. 비선형 변환 후 요청각 분포의 통계적 최빈값을 뜻하지 않는다.

## 정확히 읽은 초기 모델과 변환

원본 full33 seed7 초기 체크포인트의 support/finger 최종 출력 weight와 extra actor 출력 weight/bias norm은 모두0이다. 검지·중지·약지·소지4축과 엄지5축의 초기 latent mean bias는0이다. 팔12축은 사전 IK bias이며0이 아니므로 별도로 저장했다. 따라서 손가락에 대해 μ=0이라는 가정은 실제 초기 tensor로 확인했지만 학습 후100/200의 관측별 mean을 bias만으로 재구성하지는 않았다.

control.py:446~455의 실제 변환과 저장 target_contract를 사용했다. `a=tanh(z)`이며 양수는 `θ=reference+(upper−reference)×a`, 음수는 `θ=reference+(reference−lower)×a`다. 표의 경계는 이 저장 action/native 계약에서 읽었고 임의의 MCP/PIP/DIP 각도 범위를 가정하지 않았다.

## PPO와 원인 해석의 한계

원본 policy는 Gaussian의 pre-tanh latent를 저장하고 같은 latent로 likelihood를 다시 평가한다. 이 감사에서 log-probability/Jacobian/학습 목적을 변경하지 않았다. 결정적이고 관절별 비대칭인 물리 decoder 자체가 PPO likelihood 오류를 뜻하지 않는다. PPO는 normalized action 분포의 likelihood를 사용하며 같은 고정 decoder의 추가 Jacobian은 동일 행동의 이전/새 정책 비율에서 상쇄된다. reference의 kink도 평균 요청각 편향과 별개다.

입증한 내용은 탐색 단위·초기 요청각 평균 편향·현재 goal4 축소 범위다. 실제 마지막 관절 과사용이 이 요인 때문에 생겼다는 결론, 새 decoder가 더 낫다는 결론, 실제 학습 성능 향상은 입증하지 않았다. 그러한 판단에는 목표/비목표 실제 q·요청/적용각·접촉·오압현의 frozen stochastic 대조가 필요하다.
