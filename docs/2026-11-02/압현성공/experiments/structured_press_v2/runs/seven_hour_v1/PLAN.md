# 7시간 추가 압현 연구 계획

사용자가 실험·분석·개선을 자율 진행하도록 승인했다. 기존 성공 결과와 생산 코드는 보존한다.

## 목표와 고정 조건

대표 목표는 검지3번줄4프렛, 중지3번줄6프렛, 약지2번줄7프렛, 소지3번줄9프렛이다. 손가락마다 목표가 다르므로 손가락 자체의 난이도 차이로 단정하지 않는다.
large/64환경/H32/seed7, 정책60Hz·물리240Hz, 기존9보상/실패 기준/자유 기타/직접 목표각 제어를 유지한다. A는 목표 손가락4축만 학습, B는 팔12축을 추가한다.

## 순서와 판정

1. 현재 실행 환경에서 기존 검지100회 모델을32환경 재평가한다. 앞선32/32 재현 여부를 확인한다.
2. 중지·약지·소지 A를 각각100회씩 학습·평가한다. 목표별 최대300회, 서로 다른 checkpoint에서 안전달성24/32 이상을 연속2회 얻으면 통과한다.
3. 검지 A 최고 모델을 B로 명시 이전한다. B는 검증된 도달 가능한 정렬 오차 후보에서 시작한다. 최대300회, 안전달성22/32 이상·실패1회 이하를 연속2회 얻으면 통과한다.
4. A를 통과한 다른 손가락에도 B를 적용하고, 통과한 대표 목표는 C50으로 확장한다. C는 지원 없는 v9 평가로 판정한다. 원래 시작조건과 지원 조건의 성과를 섞지 않는다. C50 최대300회·100회마다 도움 없는 v9 고정32평가, 안전달성16/32 이상·실패1회 이하를 서로 다른 checkpoint에서 연속2회 확인해야 다음 비율로 승급한다. C75/C100도 같은 예산/규칙이며 이번 시간 내 완료하지 못하면 미완료로 남긴다.
5. 막힌 목표의 접촉/접근/정렬/오압현/관절 추종/종료/학습률을 분석한다. 개선은 실패 원인과 연결한 한 요인만 바꾸고 동일 출발 checkpoint(또는 동일 fresh seed)·동일 누적 전이·동일 평가 초기분포/지원 여부의 paired 대조 실험으로 확인한다. 성공 기준 완화로 성공을 만들지 않는다. 새 초기화/제어가 필요하면 새 연구 버전에 구현·검사하고 봉인한다.
6. 우수한 A/B 모델의 seed17 재현 또는 불안정 조건의 동일 seed 후속 실험을 남은 시간에 수행한다. best 모델 선택은 안전달성→실패를0점 처리한clean유지→실패수→최신 순이다.
7. 실제 정책 손/전신 영상을 생성하고 관절 움직임·오압현·성공 여부를 검토한다. 영상 디렉토리에는 MP4만 저장한다.

## 예산과 중단

시작 시각부터 약7시간, 마지막35분은 분석·렌더에 우선 배정한다. GPU 실험은 하나씩 실행한다. 완료 블록을 덮어쓰지 않고 소스/입력SHA·checkpoint·고정32 첫에피소드 평가를 보존한다. 예산 종료·오류는 완료와 구분해 기록한다. 추가 의미 있는 조건을 검증할 수 없다면 시간 채우기용 학습은 하지 않는다.
