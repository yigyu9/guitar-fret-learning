# 학습 코드의 계보

현재 실행 경로와 파일 역할은 [코드 지도](CODE_STRUCTURE.md), 상세 함수 설명은 [코드 해설](../../docs/2026-11-02/코드해설/README.md)을 기준으로 읽는다. 계보 문서는 과거 코드와 현행 코드 사이의 관계를 기록하는 자료이며, 현재 학습의 선행 단계나 실행 명령을 정의하지 않는다.

- [구형 fret/full/strike/adapter/tab2body 보관](../../archive/legacy_guitar_20261019/README.md)
- [전문 환경·실험·CLI 보관](../archive/20261028_before_legacy_retirement_v1/ARCHIVE_INDEX.md)
- [이 문서의 정리 전 전체 계보](../../docs/archive/document_cleanup_20261030/before/guitar_learning/docs/CODE_LINEAGE.md)

원본 경로·SHA·당시 성과는 보관 기록을 따른다. 과거536/563상태·RFJ·035/v14·누적 제어의 성공을 현행 J33·v9·직접 목표각 제어의 성공으로 상속하지 않는다. 활성 코드에서 보관본을 import하지 않으며 구형 checkpoint를 현재 계약에 암묵 변환하지 않는다.
