# full33 fresh100은 어떤 관절로 압현했나

결론: full33 fresh100도 평균 정책 평가에서 32/32·clean 2.5초를 달성했지만, A100 자유 실행과 같은 손가락 사용을 배운 것은 아니다. **검지 MCP·PIP 움직임은 훨씬 작고 팔 정책은 학습 후 시간에 따라 변한다.** 팔 보정과 작은 손가락 굽힘을 결합하는 전략으로 보이지만, 원시 전신 자세가 없는 이번 평가 기록만으로 ‘압현 대부분이 팔의 힘’이라고 확정할 수는 없다.

## 공정하게 비교한 범위

- 같은 검지3줄4프렛·seed7·100업데이트·204,800전이를 비교했다. 양쪽 최종 평가는 원래 v9, 자유33축, phase 팔 지원 해제, 평균 행동의 첫32에피소드다.
- `full33_initialization_audit.json`에 따라 초기 model tensor는 active mask를 제외하고 모두 같고 CPU/CUDA RNG도 같다. 양쪽 모두 사전 계산 IK 팔 bias를 가진다.
- 학습 절차는 다르다. A는 정렬 초기 자세·목표 손가락4축 학습, full33은 v9·33축 학습이다. 초기 분포와 학습 권한이 함께 바뀌므로 한 요인만 바꾼 실험으로 표현하지 않는다.
- 비교 대상은 `probes/free_index_A`와 `index_full33_seed7_v1/100/evaluate_final`이다. 아직 full200 영상의 실제 전신 시계열을 이 문서에 섞지 않았다.

## 실제 손가락 이동

32개 완료 에피소드의 평균 실제 관절 이동폭이다.

| 검지 관절 | A100 자유 | full33 fresh100 |
|---|---:|---:|
| MCP 굽힘 | 25.99° | **3.61°** |
| MCP 벌림 | 1.82° | 1.06° |
| PIP | 21.47° | **1.27°** |
| DIP | 5.39° | 3.40° |

A의 큰 범위에는 준비 중 펴짐도 들어 있으므로 초기보다 최대 얼마나 더 굽혔는지도 비교했다.

| 초기 v9보다 최대 굽힘 증가 | A100 자유 | full33 fresh100 |
|---|---:|---:|
| MCP | +12.95° | **+3.61°** |
| PIP | +10.91° | **+1.27°** |

full100의 검지 평균 최소/최대는 MCP 28.19~31.79°, PIP 47.60~48.87°, DIP 14.15~17.55°였다. 즉 MCP·PIP는 거의 초기 손 모양을 유지하면서 조금 굽혔다. 손가락이 잠겨 움직이지 못한 구현이라는 증거는 아니며, 그 정책이 작은 움직임을 선택한 것이다. 실제 목표각 범위도 MCP 약5.00°/PIP1.92°로 작았다. 큰 목표를 내는데 관절이 완전히 못 따라간 상황과 다르다.

두 모델 모두 목표 손가락의 실제/목표 native 한계 체류와 바깥 방향 명령 비율은 0이다. full100은 DIP가 약3.4° 움직이고 PIP가1.3°여서 역할 분담이 A와 다르지만, 마지막 마디가 극단적으로 꺾였다는 증거는 없다. 작은 손가락 굽힘이 효율적인 미세 압현일 수도 있으므로 큰 각도 자체를 자연스러움의 필수 기준으로 삼으면 안 된다.

## 팔과 다른 손가락

A100은 팔 support-head 가중치와 추가 관측 branch의 팔 출력 가중치가 정확히0이고, 자유 실행의 팔 행동도 상수다. 정렬 bias는 학습 전후 동일하다.

full100은 팔 support-head 가중치 최대 절대값 약0.001878, 추가 branch 팔 가중치 약0.001469로 갱신됐다. 실제 실행의 팔 normalized action도 시간에 따라 바뀌며, 평균 축별 시간 범위 중 최대는 약0.0851이다. A의0과 다르다. 이번에는 `free_v9`여서 phase clamp가 이 변화를 만들지는 않았다. 다만 팔 이동 목표의 기반에는 여전히 학습 전에 넣은 IK 정렬 bias가 있으므로 운반 전체를 처음부터 학습했다고 볼 수 없다.

실제 손목의 초기→최종 기타 상대 위치 변화도 양쪽에서 관측된다. 이것만으로 손가락과 팔의 압현 힘 기여율을 계산할 수는 없다. full100에는 실제 q105/body pose 전 시계열이 저장되지 않아, 접촉 직전/후 팔 이동량·손바닥 대비 패드 이동·기타 반응을 복원하지 않았다.

비목표 관절도 조금 더 움직였다. 각 그룹의 최대 실제 이동폭은 A의 엄지0.04°/중지0.01°/약지0.01°/소지0.35°에 비해 full100은 엄지2.83°/중지0.79°/약지0.65°/소지1.40°였다. 전체 손가락의 native 한계 체류는 두 모델 모두0이다. 이 움직임이 유용한 지지인지 불필요한 움직임인지는 영상과 접촉을 함께 봐야 한다.

## 같은 clean 점수가 같은 동작을 뜻하지 않는다

- A 자유 clean 평균은 2.4965초, full100은2.5000초이며 물리·손목 실패는 모두0이다. 오압현도0이다.
- full100의 near 시간은 전체 노출1~5.5초의4.5초다. A는 평균 약2.86초다. full은 일찍부터 목표 주변에 놓이는 전략과 일치하지만, 정확한 첫 접촉/압현 시점은 이 누적값으로 단정하지 않는다.
- 손목 안내 상자 내부 비율은 A 약45.4%, full100 약0.56%였다. 상자에서 조금 벗어나도 종료 문턱 이하이면 성공할 수 있다. 이것은 실패율이 아니며, 압현 성공과 손목 안내가 서로 다른 조건이라는 증거다.
- phase move/align/press도 양쪽 모두 로그에 있지만 `free_v9`는 phase 기반 팔 지원을 적용하지 않는다. phase 비율로 손가락 압현 역할을 판정하지 않는다.

현재 보상은 유효 접촉과 유지를 평가하며, 같은 결과를 어떤 관절 조합으로 만들었는지를 별도로 요구하지 않는다. 손가락 움직임 비용이0이라고 해서 큰 손가락 굽힘을 선택해야 하는 것도 아니다. 따라서 전체33축의 자유도가 더 작은 손가락 변화와 팔 보정을 결합하는 대안을 제공했을 가능성이 있다. 정확한 역할 분담은 아직 미확인이다.

## 채택 전 확인할 품질 기준

성공률만 보고 A를 full33으로 대체하지 않는다. 사용자가 요청한 능동 손가락 압현을 확인하려면 full200의 실제 native pose/video를 A와 나란히 본다.

1. 목표 패드의 움직임을 손바닥/손목 기준과 기타 기준으로 나눠, 접촉 직전 손가락 굽힘으로 접근한 부분을 확인한다.
2. 팔·손목이 음 구간에 계속 목표를 바꾸어 손 전체로 누르는지, 충분히 정렬한 후 손가락의 작은 굽힘으로 유지하는지 실제 시계열로 구분한다.
3. 필요하면 기록한 팔 자세에서 손가락만 v9로 놓는 CPU 기하 개입을 먼저 한다. 이는 ‘손가락 변형 없이도 목표 기하가 되는가’의 진단이며 실제 압력의 증명이 아니다.
4. 힘의 역할까지 판정하려면 별도의 명시적 실행 개입이 필요하다. 원래 checkpoint 성능과 혼합 정책/고정 관절 진단을 구분한다.

사용하지 않아도 되는 관절을 시각적으로 많이 움직이게 만들거나 임의 최소 굽힘 각도를 보상으로 강제하는 변경은 권하지 않는다. 작아도 목표 손가락이 실제 접촉을 만들고 유지하는 움직임이면 유효할 수 있다. 반대로 거의 초기 손 모양 그대로 팔로 접촉 위치를 만드는 동작이면 A가 학습한 손가락 역할과 다르다는 사실을 분명히 기록한다.

## 고정 재료점의 손 전체 운반·상대 손가락 운동 분해 — CPU 방법 검증

기존 A100 free의 실제 body pose 기록에서 방법을 검증했다. 아직 full100/full200의 실제 pose 파일은 없어 두 조건의 수치는 pending이다. 새 학습·native 실행·봉인 소스 수정은 하지 않았다.

검지 끝마디 원본 STL의 안쪽 패드에 놓인 **고정 재료 표본0** 하나를 모든 프레임에서 추적했다. 표본은 실제 삼각형 위의 결정적 barycentric 점이며 메시 vertex나 실제 native 접촉점이라고 주장하지 않는다. body-local 좌표는 [3.70359, −9.58122, −5.75754]mm다. 매 시점 가장 가까운 candidate 표본을 고르지 않으므로 vertex 전환에 따른 가짜 이동이 없다.

손바닥 `LH:palm`을 운반 기준으로 삼았다. 각 시점의 실제 검지3 body pose에 같은 local 점을 적용하여 world 위치를 얻고, 실제 palm pose로 inverse transform하여 상대 점 r(t)를 계산했다. guitar pose도 각 시점 실제 값을 사용했다.

- 손 전체 운반: `p_palm(t)+R_palm(t)r(t0) − p_point(t0)`.
- 상대 손가락 운동: `R_palm(t)[r(t)−r(t0)]`.
- 두 **벡터**의 합은 실제 점 변위다. guitar 좌표에서도 palm/guitar의 상대 transform으로 같은 식을 적용했다.

각 분석 구간 시작점에서 별도로 기준을 잡았다. 이 선택에 따라 분해는 구간 의존적이다. 두 norm을 더하거나 이를 압현 기여율로 바꾸면 안 된다. 상대 항에는 굽힘뿐 아니라 벌림과 finger chain의 모든 상대 운동이 포함되고, guitar 기준 운반에는 기타 운동도 포함된다. 실제 힘·마찰·접촉 원인을 분해한 값이 아니다.

| A100 실제 구간 | 점의 최종 변위 norm(G) | palm rigid 운반 norm(G) | 상대 손가락 norm(G) |
|---|---:|---:|---:|
| 첫 기록0.0167초→3초 | 64.17mm | 63.06mm | 1.41mm |
| 3초→5.5초 audible | 8.73mm | 23.20mm | 19.59mm |

이 표는 **양 끝점 차이**이며 누적 이동거리나 최대 굽힘량이 아니다. 첫 구간의 상대 최종 변위가 작아도 준비 중 펴졌다 다시 굽힌 움직임이 없었다는 뜻이 아니다. 기록이0.0167초부터여서 완전 reset t=0의 분해도 아니다.

특히 audible 구간의 Gz 성분은 palm rigid 운반 +22.79mm와 상대 손가락 −19.25mm가 상쇄되어 실제 재료점은 +3.54mm 이동했다. A에서도 손 전체 위치 변화와 손가락 운동이 함께 발생한다는 정량 근거다. 하지만 A의 팔 정책 출력은 상수였으므로 이 palm 이동을 학습된 팔 교정으로 부르면 안 된다. 유한 제어·접촉 반작용과 구별하지 못한다.

world/G 두 좌표계의 모든 프레임에서 벡터 합 복원 오차는 약1e−16m 이하로 단위·좌표 변환을 확인했다. 원시 부동소수점 계산의 대수적 일치이며 물리 모델의 정확도라는 뜻은 아니다. 고정 표본·원본 메시 SHA·실제 body 기록 SHA·각 구간 벡터와 최대 변위는 동명 JSON의 `fixed_material_point_transport`에 저장했다. full100/full200의 같은 실제 자료가 생긴 뒤 같은 표본·같은 기준 구간으로 비교할 수 있다. 현재 이 방법으로 full 모델의 압현 방식이나 힘 분담을 추측하지 않는다.

### 해석과 한계

full200의 확률 실행에서 실제 검지 각 평균은 mean보다 MCP+0.702°/벌림−0.687°/PIP+0.309°/DIP+2.161°다. DIP의 요청 평균 차이는+3.374°지만 적용 평균 차이는+1.992°이며 실제 차이는+2.161°다. 현재 LH21의 alpha=1, rate=4rad/s이므로 요청과 적용의 차이는 이 구간에서 native rate 제한을 반영한다. 적용과 실제의 차이는 유한 제어·동적 지연·접촉 반작용을 포함하며 단순한 PD 설정 결함으로 해석하지 않는다.

이 결과는 비대칭 decoder와 rate 제한 이후에도 실제 평균 손가락 모양 차이가 남는다는 근거다. 그러나 확률/mean 실행은 관측 궤적과 팔 동작·다른 손가락 움직임·접촉 이력도 달라진다. 차이 전부를 decoder 하나의 인과 효과라고 부르지 않는다. 요청각 기댓값을 결정적으로 실행하는 후속 진단은 한 부분을 검사할 수 있지만 확률 실행의 평균 적용각이나 평균 실제 궤적과 동일하다고 예상하면 안 된다.

21개 손가락 관절 전체의 평균/std/최소/최대, 요청−적용·적용−실제 gap, 동일 timestep 검증과 raw gzip/report/episodes·소스 SHA는 동명 JSON `native_mean_vs_frozen_sampling_control_trace`에 저장했다. 본 분석은 실제 pose 영상의 palm transport 분해를 대체하지 않는다. GPU·봉인 소스 수정 없음.
