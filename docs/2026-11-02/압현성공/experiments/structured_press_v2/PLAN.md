## 1. 이번 결과가 요구하는 변경

대표4목표×5조건×32평가에서 최종 압현은0/640이었다. 탐색 확대의 학습 중 최장 clean은0.642초였지만 고정 정책으로 재현하지 못했다. 학습률 복구는 작동했다. 순차 조건의 최종 평가에서는 유효 목표 관측 모두 정렬 단계였고, PIP/DIP 굽힘 허용은0회였다.

따라서 다음 구조는 ‘접촉을 만드는 손가락 기술을 먼저 익히고, 목표까지 이동하는 범위를 점차 넓히는 교육과정’으로 바꾼다. 실제 동작에는 이동→정렬→압현 구분을 두되, **목표 손가락의 MCP/PIP/DIP를 정렬 전에도 자유롭게 움직일 수 있게 한다.** 이전 gate처럼 행동0을 보내 v9로 되돌리는 동작은 제거한다.

근거: [최종 분석](../2026-11-02/압현성공/experiments/exploration_lr_sequence_v1/analysis/FINAL_ANALYSIS.md).

- clean/오압현/연속1초 달성·물리 실패·손목 종료 판정은 그대로 둔다.
- 보상9개를 유지하고 단계 통과 보너스를 추가하지 않는다. 단계가 바뀌어도 접근 potential을 임의로0으로 초기화하지 않는다.
- 목표 손가락의 준비·압현 중 B 대기 보상 제외, 손가락 움직임 비용0을 유지한다. 비목표 손가락은 기존 약한 대기 보상을 사용한다.
- 새 연구 사본에서 구현하고 기존20실행·checkpoint·생산 코드는 보존한다. 과거 R/F 실행기를 되살리지 않고 하나의 새 정책·명시적 교육과정으로 구현한다.
- 엄지와 비목표 손가락의 움직임도 관측·평가한다. 기타 고정이나 엄지 강제 부착으로 성공을 만들지 않는다.

## 3. 학습을 쉽게 시작하는 방법

### 단계 A — 정렬된 위치에서 손가락 압현

팔·손목을 목표 근처에 둔 별도 초기 분포에서 시작한다. 목표 손가락은 눌린 상태가 아니라 압현면 위5~15mm, 접선 오차5mm 이내를 목표로 한다. 정확한 초기 관절각은 네 목표 각각 실제 물리에서 검증한 뒤 고정한다. 이를 만족하는 자세를 못 찾으면 목표 준비 실패로 기록하고 학습 성능0으로 섞지 않는다.

정렬 자세는 팔·어깨·팔꿈치·손목을 함께 조정하고, 손가락은 가능한 한 합의한 v9의 열린 모양을 유지한다. 팔만으로 패드 조건을 만들 수 없는 목표에서 손가락 각을 조정해야 한다면 그 차이와 초기 거리를 별도로 기록한다. 목표 finger3의 안쪽 패드가 유효하며 초기 clean/candidate가 없어야 한다. 다른 손가락·엄지의 선접촉으로 대신 누르고 있으면 제외한다.

팔은 정렬 때의 **적용된 목표각**을 기존 유한 PD로 유지한다. 행동0을 보내 v9 팔 자세로 돌려놓거나, 실제 q를 매 tick 덮어쓰지 않는다. 기타가 움직이면 실제 물리 오차가 생기므로 성공을 보장하지 않는다. 이 조건에서 목표 손가락4축의 압현을 먼저 학습한다. 목표 외 손가락·엄지는 기존 목표 유지로 시작하며, 이 제약은 A 전용 진단 조건으로 명시한다.

이는 정식 J33 성과가 아니라 ‘정렬된 조건에서 해당 손가락으로 누르고 유지할 수 있는가’를 확인하는 학습이다. 정식 평가에서는 원래 자유 관절 조건을 별도로 사용한다.

### 단계 B — 작은 정렬 오차에서 접근·압현

A의 정책을 명시적으로 이전하고, 검증한 정렬 자세 주변에서 초기 손목 위치 오차를 각 축±10mm, 방향 오차를 각 축±5도까지 준다. 임의로 손목 root를 옮기지 않고 팔 관절의 도달 가능한 자세 집합을 사용한다. 목표 범위를 실제로 만족한 초기 표본의 분포와 실패율을 기록한다.

팔·손목의 유한 보정과 목표 손가락을 함께 학습한다. 손가락은 모든 구간에서 자유롭다. 팔의 작은 보정 권한을 주더라도 목표각 범위와 PD는 유지한다. ‘정렬이 끝나야 굽힘이 가능하다’는 게이트를 넣지 않는다.

### 단계 C — v9에서 이동·정렬·압현

검증된 정렬 근처 초기화와 원래 v9 초기화를 섞다가 v9 비중을 늘린다. 초기 혼합50:50 →25:75 →0:100을 사용하며, 비율은 학습 난이도일 뿐 평가 분모를 바꾸지 않는다. 최종 목표는 원래 v9·자유 기타·전체 J33 제어·고정 곡 시계에서 성공하는 것이다.

목표 외 관절도 점진적으로 원래 학습 권한으로 복구한다. 마지막 비교는 사전 고정한 전체33축 자유 조건에서 수행한다. 초기 단계의 팔 유지·도움이 남은 결과를 정식 성공으로 보고하지 않는다.

## 4. 실제 동작의 이동·정렬·압현 구분

이 구분은 새 관측에 명시하고 손가락을 잠그는 규칙으로 사용하지 않는다.

| 동작 구간 | 역할 | 전환 판단의 초기 제안 |
| --- | --- | --- |
| 이동 | 목표 프렛 주변으로 팔·손목을 운반 | 손목 안내 영역 밖 각 축 초과≤10mm를0.10초 유지 |
| 정렬 | 패드가 목표 셀 위에 접근하도록 손목·손가락을 함께 조절 | 패드 접선 오차≤10mm, 높이2~20mm, 법선cos≥0.1을0.10초 유지 |
| 압현 | 목표 손가락4축으로 접촉·유지, 팔은 정렬 위치를 지지 | 실제 clean을 확인하고 기존 연속1초 달성 판정 |

수치는 시작 제안이며 초기 자세 표본 검증에서 달성 가능성을 확인한 뒤 첫 학습 전에 고정한다. 기존8mm gate를 무조건10mm로 늘리기만 하는 실험은 아니다. 손가락은 전 구간에서 움직일 수 있으므로 전환 미달이 굽힘 금지로 이어지지 않는다. 이미 실제 clean 접촉을 만들었다면 높이2mm 하한 때문에 정렬로 되돌리지 않고 압현 구간으로 인정한다.

A/B/C 모두 준비3초·목표2.5초·말미0.5초의 고정 곡 시계를 유지한다. 정렬이 늦어져도 음 시계를 멈추거나 목표 창을 뒤로 미루지 않는다. 3초 시점의 정렬 미완료를 별도로 기록하고 기존 종료 조건이 발생하지 않으면 손가락 압현 시도는 계속 허용한다. 준비 실패도 평가 분모에 포함한다.

압현 구간에서 팔 지지는 정렬 때의 적용 목표를 기준으로 한다. 작은 수정은 허용하고 큰 이동보다 손가락 굽힘으로 누르도록 역할을 분리한다. 팔을 다시 넓게 움직일 필요가 있을 때의 동작은 별도 재정렬로 관측에 표시한다. 전환 시 목표와 제어 이득을0.2초 동안 부드럽게 연결하며 숨겨진 latch·hold target은 관측에 포함한다.

최종 정식 평가에서는 단계 기반 팔 제약도 해제한 원래 J33 조건의 성과를 별도로 확인한다. 단계 기반 제약이 남아야 성공한다면 ‘제약 지원 조건 성공’으로 분류하고 채택을 보류한다.

## 5. 정책과 관측

새 정책은 처음부터33축 출력 형상을 유지해 A→B→C에서 동일 가중치를 이어 쓸 수 있게 설계한다. 학습 대상 마스크와 물리 실행의 유지 목표를 명시하고, 실제 표본화·logp·entropy·KL에 같은 마스크를 사용한다. 마스킹한 실행 행동을 원래 분포의 표본처럼 취급하지 않는다. 엄격한 새 계약을 사용하며 구형 checkpoint를 암묵 변환하지 않는다.

추가 관측은 단계 one-hot, 단계 경과·남은 준비 시간, 패드 접선 오차/높이/법선, 각 준비 조건 충족 여부, 손목 유지 기준이다. 기존 관측에 이미 있는 값은 중복 추가하지 않고 이름과 축/단위를 검수한다. 단계 전환에 이력을 사용하면 그 상태도 actor/critic 모두 관측하게 한다.

A→B→C 전체에서 정책 출력의 물리적 정규화 목표각 의미는 v9 기준으로 동일하게 유지한다. 팔 유지 지원은 그 각도를 표현하는 별도 실행 명령으로 명시하고, 같은 가중치를 이전하면서 행동0의 의미를 중간에 바꾸거나 기준각을 다시 설정하지 않는다. A에서 동결하는 팔 출력부는 유지 명령과 일치하는 초기 출력을 갖도록 준비하고, B에서 해제할 때 출력 불연속이 없는지 확인한다. 활성 손가락의 직접 목표각 방식과 native 가동범위는 유지한다.

## 6. 단계별 실행 예산과 통과 기준

대표 목표는 앞선 연구와 같은 검지3줄4프렛·중지3줄6프렛·약지2줄7프렛·소지3줄9프렛이다. 우선 4목표를 분리해 학습해 어떤 손가락이 막히는지 드러낸다.

| 항목 | 최초 예산/판정 제안 |
| --- | --- |
| 공통 | large·64환경·H32·seed7, 목표별100업데이트마다 독립 평가 |
| A 최대 예산 | 목표별300업데이트, 614400전이 |
| A 통과 | 정렬 조건32평가 중 안전 달성24회 이상(75%)을 연속2회; 목표 전부가 아닌 각 목표별 통과 |
| B 최대 예산 | A에서 목표별 추가300업데이트 |
| B 통과 | 오차 포함32평가 중 안전 달성22회 이상, 실패≤1회, 연속2회 |
| C 혼합 비율 승급 | 고정 v9 평가에서 안전 달성16/32 이상·실패≤1회를 연속2회 확인한 목표만 다음 비율로 승급 |
| C 최대 예산 | 세 비율마다 최대300, 목표별 추가900업데이트. 각 비율의 최소 통과 예산200에 미달 평가100의 여유를 둠 |
| 최종 확인 | 도움 없는 v9·J33에서32평가×4목표, seed17 재학습으로 재현 확인 |

연속2회는100업데이트 간격의 별도 checkpoint 평가를 뜻한다. 같은 checkpoint를 두 번 평가해 승급하지 않는다. 예산을 다 써도 기준을 못 넘으면 해당 목표는 보류하고 원인을 분석하며 무한 연장하지 않는다. 표본수가 작은 기술 판정 기준이며 통계적 유의성이나 곡 전체 일반화를 뜻하지 않는다.

학습률과 탐색은 이번에 구현이 확인된 보정값을 출발점으로 고정한다: actor3e-5, KL0.02, 재시도0.5, 바닥7.5e-6, 안정10회·KL<0.005일 때1.25배 복구. 목표 손가락 초기 latent std0.15/하한0.10, 나머지 학습 축은 기존0.049787로 시작한다. 이 숫자의 일반적 우월성이 입증된 것은 아니며 구조 비교 중 요인이 다시 바뀌지 않게 고정하는 선택이다.

최종 성능을 이전 구조보다 낫다고 주장하려면 누적 학습 전이 수·seed·평가128환경·최종 v9 초기 분포가 같은 J33 대조군을 함께 실행한다. A/B의 지원 조건이나 더 큰 총 학습 예산을 기존100회 연구의 개선으로 직접 비교하지 않는다. 첫 구현의 목표는 A에서 능동 압현 가능성을 확인하는 것이며, A 미통과 시 B/C 장기 학습은 시작하지 않는다.

## 7. 필요한 진단과 중단 판단

- 정렬 실패 이유를 접선 거리·높이·법선·손목 영역별로 따로 기록한다. 총 정렬 체류율만 남기지 않는다.
- 목표 손가락의 MCP/PIP/DIP 요청·실제 각도, 추종 오차와 패드 이동을 기록한다. 마지막 관절만 움직이는지도 따로 확인한다.
- 현재 단계와 각 단계에서 활성인 축, 실제 팔 유지 목표와 정책 행동을 남긴다.
- 단계 체류는 실제 선택된 평가 에피소드만 집계한다. 이전처럼 H32 끝을 채운 다음 에피소드 일부가 섞이지 않게 한다.
- 100회 평가에서 접촉 경험이 계속0이면 반복을 늘리기 전에 초기 정렬·측정·행동 대응을 점검한다.
- 기존 물리/손목 종료를 끄지 않는다. 도움 있는 진단과 정식 평가의 종료·시계 차이는 별도 열로 표시한다.
- 학습 성공과 자연스러운 손가락 사용은 구분한다. 영상으로 능동 굽힘과 오압현·손 전체 밀기를 함께 검토한다.
