# 수정 참조 동작 CPU 결과

- 변경 허용: 왼팔 12축과 중지 4축. 다른 관절의 q는 기준값 그대로이다.
- A: 중지·표준 3번 줄·6프렛. B: 동일 손가락·줄·7프렛.
- press: 같은 적격 패드 표본을 셀 중심의 압현면 -0.5mm에 맞춘 요청. 해당 셀만 기하 후보로 인정되며, 다른 프렛은 기하 후보가 아니다.
- hover: 패드를 압현면 +10mm에 정렬. 접촉 기하 후보가 없다.
- 다른 세 손가락의 끝마디 패드: 모든 endpoint에서 압현면 최소 약 6mm 간격. 엄지·전체 메시 접촉은 이 CPU 검사만으로 판정하지 않는다.
- 각 경로는 A 1.5초 유지 → 이륙/이동/하강 → B 1.5초 유지 → 이륙/이동/하강 → A 1.5초 유지이다.
- 휴지 0.5/0.75/1초의 최대 요청 속도는 각각 1.280/0.866/0.651rad/s로 팔 3rad/s·손가락 4rad/s 범위 안이다. 실제 제어기의 평활화와 하중 추종은 native replay에서 별도 확인한다.
- CPU 테스트 3개 통과: 유지 구간 보존, 미등록 휴지 거부, 연결 곡선 끝점 기울기.

유한한 FK 탐색 결과이며 물리 도달 가능성의 증명이 아니다. native_verified=false로 남겼다. 실제 물리에서는 첫 hover 상태만 reset하고 이후는 기존 제어기에 요청각을 전달해야 한다. 성공 판정은 하중·수정된 오압현·손목 및 물리 종료·처음 실제 상태 일치·자원 정리까지 확인한 별도 native report를 따른다.
