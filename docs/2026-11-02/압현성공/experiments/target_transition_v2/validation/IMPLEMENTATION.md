# 구현·사전 검증 기록

동일 손가락의 높은 프렛 간섭을 누락하던 판정을 보정했다. `contact.py`의 `wrong_press_sources.v3`은 같은 줄의 높은 유효 끝마디 패드가 있으면 낮은 목표를 차단한다. 낮은 접촉 잔류 자체는 높은 목표를 막지 않는다. 다른 줄·동시 운지·다른 손가락·준비 구간·음별 감점 예산은 유지했다. 기존 소스2개와SHA는 before/에 보존했다.

접촉 관련CPU59검사, 최종0.75초 번들을 사용한 실험CPU19검사와 독립 검수를 통과했다. 시간표·현재/다음 목표·부분 reset·16축 제어·공장함수 복원·엄격한 optimizer/RNG 재개·미관측 음 분모·동시 후보 재발 검출·240Hz 누락 검사를 포함한다. 활성 학습 구현의 변경은 접촉 판정과 회귀검사2파일에 한정했다. 새 전환 도구는 본 실험tools/에 모았다.

## 실제 GPU 참조 검증

초기catalog의 기존 native 성공을 상속하지 않고 현재144입력의SHA와 복사한FK 데이터를 새로 기록했다. Native 참조의 최초 상태는 실제 학습 initial_catalog의q/state/hold와 일치한다. 이후 직접 목표각만 보내며 자유 기타·중력·기존 PD/하체 제어를 유지했다. 물리 중 reset이나 상태 덮어쓰기는 없다. 최초 준비1.5초 이후 각 음1.5초의6→7→6 경로를 재생했고 휴지 마지막0.20초는 요청 press 목표를 유지해 정착시켰다.

|휴지|6프렛 유지|7프렛 유지|6프렛 복귀 유지|시작 준수·전체 유지|
|---|---:|---:|---:|---|
|0.5초|1.5초|0초|1.5초|미충족|
|0.75초|1.5초|1.5초|1.5초|통과|
|1초|1.5초|1.5초|1.5초|통과|

이번 경로에서0.5초가 실패한 것은 모든0.5초 동작이 불가능하다는 증거가 아니다. 검증된0.75초로 먼저 학습한다.0.75초 재생의 기타 위치 변화 최대4.25mm·회전0.0124rad, 물리·손목 실패0, 중간 reset0, 소스 동일·장면 종료를 확인했다. 시각 판정 해상도는240Hz(약4.17ms)다. 개별 줄 접촉력이나 음향 측정이 아닌 현재 모델의 기하·몸체 하중 후보 기준이다.

검증 중 관절 표면 부수 접촉, 보고서 NumPy boolean 직렬화, helper 이름 가림 오류를 발견해 수정하고 원문·실패 출력을 보존했다. 이전 baseline은 초기 자세와 경로가 달라 정착 시간만의 통제 비교로 해석하지 않는다. 채택 근거는 같은 학습 초기 상태를 사용한 reference_gap_*_v5 결과다.90% 유지의 느슨한 native_verified와 별도로 AB/BA/ABA_on_time_full_hold_verified를 검사했다.
