# 중지 두 프렛 전환 실험

중지가 3번 줄의 6프렛(A)과 7프렛(B)을 A→B→A→B로 전환하는 가상 음열을 학습한다. 단일 목표에서 확인한 준비 동작이 목표 전환에도 도움이 되는지 검사한다. 곡 연주 성공을 검증한 실험은 아니다.

본 비교1,200회·12평가는 완료됐다. 평균 행동 평가는 모든 조건에서 A만 달성했고 B 전환은 실패했다. 같은 최종 E4 모델의 확률 행동 추가 진단에서는4음 달성3/32를 관측했다. [최종 분석](runs/comparison_v1/review/ANALYSIS.md)에서 실제 접촉 시간축과 학습·평가 차이를 설명한다.

추가 관찰에서 같은 중지의6·7프렛 동시 유효 후보를 확인했다. 확률 행동3/32를 실제 전환 성공으로 해석할 수 없으며,0.5초 휴지의 물리적 충분성은 아직 미확정이다. [물리 실현성 추가 점검](runs/comparison_v1/review/PHYSICAL_FEASIBILITY.md)을 현재 판단 기준으로 읽는다.

- [계획과 체크리스트](PLAN.md): 고정 조건·예산·판정 기준
- [사전 검증](validation/): CPU 기하, B의 실제 GPU 물리 유지, 소규모 학습·재개·평가
- `runs/comparison_v1/진행상황.md`: 본 실험 시작 후 현재 작업·완료 반복·예상 종료
- `runs/comparison_v1/RESULTS.md`: 평가가 끝날 때마다 갱신하는 음별 성과
- `runs/comparison_v1/summary.json`: 위 표의 상세 수치와 근거 파일
- `runs/comparison_v1/blocks/`: 조건·seed·반복별 체크포인트와 원본 로그
- `runs/comparison_v1/renders/`: 실제 시뮬레이터 영상의 생성 과정과 자세 기록
- [공개 영상](../../video/virtual_transition_v1/): 생성 완료된 MP4만 보관

두 조건 모두 large·64환경·H32, 팔12축과 중지4축을 학습한다. E0는 기존 준비 보상, E4는 첫 목표 노출·준비 중 목표 손가락 대기 보상 해제·표면 위 준비 영역 접근을 함께 적용한다. 압현 성공 기준과 다른 보상은 같다. 초기 상태는 A 정렬 자세이며, 이후 목표가 바뀔 때 관절 상태를 강제로 옮기지 않는다.

전체 11초: 준비3초 → A1.5초 → 쉼0.5초 → B1.5초 → 쉼0.5초 → A1.5초 → 쉼0.5초 → B1.5초 → 말미0.5초. 평가마다 실패를 포함한 최초32에피소드를 사용한다. 음128개·전환96개가 분모이며, env0의 자세 궤적은 별도 대표 사례다.

기존 단일 목표 비교와 GPU를 동시에 사용하지 않는다. 사전 검증에 통과해야 본 학습을 시작하고, 조건별 seed7·17을 각각100/200/300회에서 평가한다. 실행 실패는 숨기지 않고 기록하며, 실패한 블록에 의존하는 연장만 건너뛴다.
