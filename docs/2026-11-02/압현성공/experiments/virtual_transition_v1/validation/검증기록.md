# 본 실험 시작 전 검증

- CPU25개 검사 통과: 실제 시간표, 원본 보존, 팔12축만 사용한 B 기하, partial reset, 현재 목표 우선 선택,16축 학습 권한, strict checkpoint와 RNG/optimizer 재개, 필수 trace, 실패 포함 분모, 추가/누적 반복수 구분, 비유한 오류 전체 중단.
- 독립 검수: B hover 도달/유지 진단·CPU 기하·실행기·큐·분석기 검수 완료. 발견했던 누적 전이수 검사, 최초 접촉 집계 누락, 비유한 실패 감지 문제를 수정한 뒤 재검수했다.
- GPU2초 B hover 유지 검사를 통과했다. 높이8.73~9.91mm이므로4~8mm 준비 영역 유지나 학습된 전환 성공으로 표현하지 않는다.
- large64환경으로2회 학습하고 저장한 모델을2회 추가 학습해 총4회로 엄격 재개했다.32환경 모두 전체11초를 평가했고 물리/손목 실패0, 마지막 음과 대표240Hz trace를 확인했다.
- 실행 검증 모델의 음 달성은0/128이다. 매우 짧은 실행 검증이며 성능 비교 결과가 아니다. 이 모델은 본 학습의 초기 모델로 재사용하지 않는다.
- 실제 평가 자료로 그래프 생성도 확인했다. 해당 그림은 `smoke_plot_v1/`의 실행 검증 자료이며 본 비교 결과와 분리한다.
- `preflight.json`에 검증 결과와 실행 입력·근거472개 파일의SHA를 기록했다. 큐는 본 학습 전에 이를 재검증한다.

본 학습과 평가는 별도 `runs/comparison_v1/`에 기록한다. 실행 중 소스·목표·기하가 바뀌면 중단하고, 실패 블록과 의존 연장은 결과에서 숨기지 않는다.
