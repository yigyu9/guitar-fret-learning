# 중지의 두 목표 전환 가상 음열 실험 v1

## 목표와 시간표

A=중지·표준3번줄·6프렛, B=같은 중지·3번줄·7프렛. 준비3초 뒤 A3.0~4.5/B5.0~6.5/A7.0~8.5/B9.0~10.5초, 음 사이0.5초·말미0.5초로 전체11초다. 무음 WAV는 시계만 제공하며 음향을 생성하지 않는다. B는 CPU 관절범위·유효 패드 기하와 별도 GPU 도달/유지 진단으로 먼저 점검한다. 미검증을 성공으로 처리하지 않는다.

## 학습 조건

- 현재 실험과 분리한 새 버전·출력·소스SHA를 사용한다. 실행 helper는 tools/에 모으고 활성 학습 패키지는 import해 재사용한다. 기존 봉인 Python을 import하지 않는다.
- E0/E4 모두 large/64환경/H32/목표각 직접제어/현재std·학습률·물리·성공판정을 고정한다.
- 팔12축+중지4축=16축 학습. 다른17축은 초기 유지 명령이며 실제 관절을 매 tick 고정하지 않는다. 단계별 팔 clamp와 손가락 잠금은 없다.
- 초기 상태는 검증된 A 정렬 자세, 이후 목표가 바뀔 때 상태를 덮어쓰지 않는다. 손목 안내·기하 focus·목표 선택·phase 진단은 현재 음/다음 음에 맞게 전환한다. 팔의 고정 IK 요청으로 목표 전환을 대체하지 않는다.
- 첫 reset부터 전체 ABAB를 실행한다. 기존 구간 노출 일정이 중간 음을 생략하거나 목표별로 에피소드를 나누지 않게 한다.
- 보상은 E0/E4 현행 정의 그대로다. 새 조기접촉 비용이나 추가 손가락 비용을 넣지 않는다.
