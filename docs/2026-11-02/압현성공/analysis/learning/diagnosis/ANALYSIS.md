# 실제 단음 PPO 압현 실패 분석

## 압현을 시도한 과정

각 목표마다 새 large 정책을 만들고 실제 GPU 왼손 J33 환경에서 64환경·H32·100회(204,800전이)를 학습했다. v9로 초기화하고 3초간 준비한 뒤, 3.0~5.5초에 지정 손가락으로 목표 줄·프렛을 누르도록 가상 악보를 제시했다.

손목 이동→손가락 정렬→압현을 순서대로 강제하는 제어기는 없다. 매 60Hz에 정책이 팔·손목·엄지·네 손가락 33축을 함께 선택한다. 행동을 목표각으로 변환하고 속도를 제한한 뒤 PD 제어와 240Hz 물리로 움직인다. 손가락의 행동 0은 v9 기준각, ±1은 native 가동범위 양끝이며 같은 행동을 반복해도 각도가 누적되지 않는다. 학습에는 독립 Gaussian 잡음을 추가하고 최종 평가에서는 평균 행동을 사용한다.

접근·최초 접촉·clean 유지·연속 clean 1초 달성이 보상으로 연결되지만, 단계를 순서대로 강제하지 않는다. 목표 손가락의 준비·압현 구간에는 B 대기 보상을 주지 않는다.

## 로그에서 확인한 사실

| 지표 | 결과 |
| --- | --- |
| 최종 결정적 평가 | 16목표×16환경=256회, 달성 0 |
| 최종 목표 접촉·clean 시간 | 모두 0초 |
| 에피소드별 최소 패드 거리 중앙값 | 초기 57.46mm → 최종 67.73mm |
| 목표 손가락 4축 중 최대 실제 각변화 대표값 | 약 0.94도 |
| 목표 손가락 요청각 추종 RMS 대표값 | 약 0.047도 |
| 손가락 성분·팔/지지 성분 경로 대표값 | 약 1.95mm·72.88mm |
| 잡음을 포함한 학습의 완료 에피소드 | 11,398개 중 11개만 clean 경험, 달성 0 |
| 학습 중 최장 연속 clean | 0.204초, 필요 조건은 1초 |
| actor 학습률 | 3e-5 → 7.5e-6, 목표별 14~29번째 갱신에서 KL 재시도 후 감소 |
| 탐색 latent 표준편차 | 활성 33축 기하평균 약 0.04979로 처음과 끝이 거의 동일 |
| 최종 평가 조기 종료 | 기타 이동 12/256, 손목 실패 0 |

각변화·경로·추종 대표값은 목표별 16환경 중앙값을 다시 16목표에서 중앙값 낸 것이다. 관절각은 해부학적 각도가 아닌 모델 입력축이다. 경로는 6초 동안 기록된 성분별 경로 길이 합이며, 성분 길이를 더해 인과적 분담 비율로 해석하지 않는다. 학습 통계는 완료 에피소드만 포함한다. 거리 통계는 전체 256평가의 에피소드별 최솟값 중앙값이다.

## 원인 해석

가장 강한 증거는 정책이 손가락에 큰 움직임을 요청하지 않았고, 요청한 작은 각은 잘 따라갔다는 점이다. 적어도 이번 비접촉 수행에서 관절이 끼이거나 PD가 명령을 막은 것이 주된 병목이라는 근거는 약하다. 실제 접촉 하중 아래에서 충분한 힘을 내는지는 별도 미검증이다.

초기 자세에서 목표까지 거리가 큰 상태로 33축을 함께 탐색했다. 직접 위치 제어의 작은 독립 잡음은 기준각 주변 변동으로 끝나기 쉽고, 큰 굽힘으로 누적되지 않는다. 잡음을 포함한 학습에서도 목표 손가락 최대 축변화의 대표값은 약 4.12도였다. 접촉 경험이 11,398회 중 11회뿐이어서 접촉→유지→달성을 배울 신호가 매우 드물었다. 이 조합이 유력한 원인이지만 대조 실험으로 인과효과를 분리한 결론은 아니다.

최종 평가의 접촉·유지·달성 보상 평균은 모두 0이었다. 대기 자세는 +0.1024, 엄지 안내는 +0.0202, 수행 부족은 −0.0992였다. 보조 양성 신호는 있었지만 이것만으로 실패를 설명할 수는 없다. 접근 보상 평균 −0.1578은 거리 자체가 아니라 할인 잠재함수 차분이며 정상 종료 시 다음 잠재값은 0이다. 덜 음수인 총보상을 접근 개선으로 해석하면 안 된다. 실제 최소 거리도 개선되지 않았다.

학습률은 성공을 배우기 전에 1/4로 줄어 갱신을 둔화시켰을 가능성이 있다. 그러나 탐색 분산은 붕괴하지 않았으며 학습률 감소만을 실패 원인으로 단정할 수 없다. 100회를 더 길게 돌리는 것만으로 해결된다는 근거도 없다.

다음 대조에서는 먼저 손목을 압현 가능한 영역에 정렬한 조건에서 손가락의 능동 굽힘을 확인하고, 탐색 크기·시간 지속성·학습률 유지를 하나씩 비교하는 것이 적절하다. 실제 물리와 접촉 판정은 유지하고 진단용 제약과 정식 J33 조건은 별도로 기록해야 한다. 이번 분석에서는 구현이나 기존 학습 산출물을 수정하지 않았다.
