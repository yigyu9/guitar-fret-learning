# 왼손 약지·소지 반전 검사 결과

**검사한 준비 자세와 정책10초 자세에서는 약지·소지가 반대 방향으로 움직이고 복귀했다. 소지에는 실제 접촉합력이 있었지만, 기저부 방향을 바꾸면 검출된 접촉합력이 사라졌다. 빠져나올 수 없는 고정 끼임이라는 근거는 확인하지 못했다.**

이는 두 자세에서의 작은 국소 운동 검사 결과다. 모든 자세에서 끼임이 없다는 인증이나 곡 학습 성공을 뜻하지 않는다. 모델·native PD·effort·관절 범위·물리·안전 기준은 바꾸지 않았다.

## 실제 검사

- 준비035/v14에서 바로 검사, 같은 최종100회 정책을 실제10초 진행한 뒤 검사하는 두 조건을 사용했다.
- 각18환경: 약지/소지8축×양·음16개, 목표 유지1개, 8축 동시 준비목표 복귀1개다. 양방향 pulse는0.2rad/s1초→정지0.5초→처음목표 복귀1초→정지0.5초다.
- 비시험 손가락 목표는 누적 행동0으로, 팔·손목 등의 목표는 기존 절대위치codec 역변환으로 유지했다. 실제 비시험 목표 오차는 두 조건 모두0rad였다. 하체·상체 지지 제어는 정상 적용했다.
- 실제GPU GDB 정상종료/exit0, 준비180tick·학습후780tick(10초prefix+3초probe), 두 조건18행 모두 검사 완료·안전 조기종료0이다. 검사 종료는 곡 완주가 아니다. PPO0, 모델·3331값 curriculum 불변, 두 simulator 정상close를 확인했다.
- 실제240Hz q/qd/목표105와 모든native68몸체 접촉합력 norm,60Hz 전신106몸체 자세를 저장했다. 이전881파일 봉인과 활성435Python을 변경하지 않았다.

## 핵심 측정

아래 실제 이동은1초 pulse와0.5초 정지 후 q에서 시작 q를 뺀 값이다. 목표 이동은 native 한계로 잘린 실제 목표 변화다. 부호는 모델의 관절 좌표이며 해부학적 굽힘/펴짐으로 일괄 해석하지 않는다.

| 정책10초 뒤 검사 | 목표 변화(rad) | 실제 q 변화(rad) | 정지끝 q−목표(rad) |
|---|---:|---:|---:|
|약지2 · 반전|-0.20000|-0.19958|+0.00042|
|소지 기저1_z · 반전|+0.20000|+0.13982|+0.03664|
|소지3 · 반전|+0.20000|+0.19904|+0.00025|

소지 기저부 반전(case10)에서는 끝마디 `pinky3` 접촉합력이 직전0.5초 평균 약1.75N에서, 이동 후 정지0.5초의120개 실제 물리 표본 모두0N이 됐다. 같은 조건을 원래 목표로 되돌리자 접촉합력이 다시 생겼다. 목표를 그대로 유지한 대조행은3초 내내 약1.74N을 유지했다. 이 조건에서 국소적으로 접촉을 풀 수 있었다는 근거다. 충돌 상대가 기타인지 다른 손가락인지는 몸체합력만으로 확인할 수 없다.

학습후16개 단일축 시험 전체에서 약지의1·2·3마디의 접촉합력 norm이0이었다. 준비자세의 약지 기저1_x 양방향 중+방향 시험에는 일시적 접촉합력(최대2.431N)이 있었지만 되돌림도 가능했다. 순합력0은 서로 상쇄되는 모든 접촉의 부재를 인증하지 않는다.

각 조건16방향 중12개는 허용 목표 이동이0.05rad 이상이었다. 이12개 모두 요청 방향으로 실제 이동했다. 나머지는 native 한계 때문에 실제 목표 변화가 작거나0이므로 끼임 판정 대상으로 쓰지 않는다. 학습후 pulse들의 복귀끝 실제 q는 시작 q에서 최대 약0.01530rad(0.877°) 차이가 남았고, 준비자세에서는 최대0.000429rad(0.025°)였다. 목표가 돌아오는 것과 실제 q의 완전 복원을 구분한다.

## 남은 추종 오차와 한계

소지 기저1_z의 준비자세 +방향 목표 이동0.2rad에 실제 q 변화는0.10078rad, 정지끝 q−목표는−0.09922rad였다. 따라서 모든 축이 목표를 완벽하게 따른다고 할 수 없다. 해당 시험의 소지1·2·3마디 접촉합력은0이었으므로 검출된 접촉합력만으로 이 추종 오차의 원인을 확정할 수도 없다.

반면 학습후 같은 방향 시험은 시작부터 q−목표가+0.09682rad였고, 정지끝에는+0.03664rad였다. `q이동0.13982/목표변화0.2`를69.9%라고 계산해 그때 절대 목표에 미달했다고 해석하면 안 된다. 시작 오차가 줄어든 결과를 함께 본다.

8축을 동시에 준비목표로 되돌린 행은3초 안에8개 목표 모두 준비 reference에 도달했다. 그렇지만 다른 손가락·팔 목표는 정책10초 값을 유지한 상태이므로 전체 준비 자세 복원이 아니다. 이 행의 소지 접촉합력은 후반에 다시 나타났으며, 동시 복귀가 항상 무접촉 자세를 만든다고 주장하지 않는다.

기존1024평가 영상의10초 자세와 이번18환경 대조행10초 자세는 같은 checkpoint지만 완전히 같지는 않다. 최대105축 q차이0.000810rad, 검사8축 q차이0.000218rad,106몸체 위치차이0.216mm였다. 조건18행 사이 최대 q차이는0.001830rad다. 고정 환경ID·미세한prefix·폐루프 물리 차이와1초0.2rad/s 운동 범위의 한계를 유지한다. [시작 자세 대조](prefix_comparison.json).

## 영상과 재현

손 움직임을 잘 볼 수 있도록 원본 실제 자세를 왼손 중심으로 확대해 재생했다. 60Hz의 실제3초 검사4개를 연결한12초 영상이다. 방향은 실제 결과/접촉력 대신 검사 시작 목표의 native 여유가 큰 방향으로 사전 선택했다. 순서는 약지2, 소지기저1_z, 소지3,8축 동시 복귀다. 영상의3~6초 구간이 소지 접촉합력이 풀린 반전 조건이다. 새 물리·자세 보간·추가 학습은 없다.
