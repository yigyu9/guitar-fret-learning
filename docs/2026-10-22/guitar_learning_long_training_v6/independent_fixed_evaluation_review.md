# 고정 체크포인트 평가 독립 검수

검수일: 2026-10-22. 요약 판정: **문제없음(PASS)**. 평가 결과와 저장 증거의 정합성에 대한 판정이며, 학습 수렴·안전성 향상·자연스러운 연주를 인증하는 판정은 아니다.

## 확인 범위와 방법

- 닫힌 `evaluation_recovery_{initial,update_0500,update_1000,update_1500,final}_1024`의 보고서, 첫 종료 원장, 67개 목표 및 음별 집계, 입력 핀, lifecycle/scene, 캡처 메타데이터와 NPZ를 CPU 읽기로 확인했다. 각 정책의 1024개 고유 환경 ID와 전체 첫 원장을 음별 집계에 독립 대조했다.
- 원장 clean/contact 문턱, 목표 ID/손가락 배정, 완료·안전·실패 분모, 실제 단계 0, 시계와 물리 스텝의 4배 관계를 확인했다. 음 성공은 기존 GPU loaded-body geometry 판정이며 실제 접촉 쌍·압력·음향을 뜻하지 않는다.
- 각 평가의 602개 입력 핀을 현재 파일 SHA와 대조했다. source436, 모델 경로/업데이트, 544 상태·8개 우선 슬롯·24 토큰·3331 curriculum 및 저장 posture 정의/실제 body 인덱스를 확인했다.
- 각 정책의 사전 지정 env0..7 캡처는 모두 t0를 포함한 1970프레임이었다. 전체 40개 NPZ의 SHA, shape, 유한값, quaternion norm, 시계, 첫 프레임과 종료 음 집계의 대응을 확인했다. 실제 q105/body106/action39 배열을 사용했으며 새 물리 실행은 하지 않았다.
- CPU 체크포인트 로드에서 초기 모델 56개 텐서, 각 학습 모델 56개 및 actor Adam 54개/value Adam 57개 텐서가 모두 유한했다. 초기 optimizer 상태는 비어 있었다. CUDA 초기화 없이 확인했다.
- combined의 5개 결과 객체를 각 개별 `report.json`과 정확히 대조하고, 선택 점수를 원장의 전체 1024 분모로 다시 계산했다. 검사 중 도구 main, native/GPU/GL, 렌더러, 학습 중단이나 원자료 변경은 수행하지 않았다.

## 선택과 해석의 경계

- combined는 완료된 5개 평가와 요청 완료를 모두 명시한다. 초기 0회를 제외한 **평가한 네 학습 모델**에서 전체 첫 곡 평균 → 안전 환경 수 → 최신 업데이트 순의 사전 규칙을 그대로 재현하면 best=500, latest=2000이다. 모든 저장 체크포인트 중 최적이라는 주장은 아니다.
- best500의 평균은 초기보다 높지만 안전 완주는 1024에서 414로 감소했다. 최종2000의 전체 평균은 초기보다 낮다. 평균 향상 하나로 안전성·학습 안정성·자연스러움·전반적 연주 개선을 주장할 수 없다. 고정 평가의 비단조 결과를 혼합 정책 학습 수집 통계와 구분해야 한다.
- 각 모델은 자기 저장 curriculum을 고정해 평가했으며 이번 5개는 모두 progress=0이었다. 같은 seed/곡/준비 자세의 1024환경은 독립 seed 반복이나 일반화 검증이 아니다.
- env0..7은 사전 지정된 캡처이며 이번에는 모두 안전 완주했다. 영상 선택은 이 캡처 중 가장 낮은 안전 ID인 env0이다. best500 영상의 env0은 4음이며 전체 평가의 610개 실패를 대표하지 않는다. 캡처가 안전하다는 사실을 전체 1024의 안전성으로 확대하면 안 된다. 이후 제작될 실제 영상·posture 분석·최종 문서는 본 검수의 완료 대상에 포함하지 않았다.

## 복구·보존 경계

평가의 모든 training chain은 저장된 fresh prefix1300 + strict resume700의 유효 2000업데이트 경로와 일치한다. 재개 시 물리 에피소드가 새로 준비되므로 연속 단일 프로세스 fresh2000이 아니다. 원래 외부 run의 native 최종 보고서는 없고, 선택 prefix 이후 old1300..1361 파일 62개는 제외된다. 최초 13회 중단 및 별도 5회 재개 중단도 유효 2000에 합산하지 않는다. 제외 파일 수가 해당 raw의 완전성이나 commit을 인증하지 않는다.

외부 복구 사본 봉인은 1387개 실제 파일 집합과 총 4,499,049,842bytes, 각 실제 크기, 기존 relocation manifest의 전 파일 SHA/bytes 매핑, 원 프로젝트 alias의 실제 대상이 일치했다. 이번 검수에서는 이미 복사·선행 검수에서 확인한 전체 4.5GB를 다시 해시하지 않았다. 봉인은 제외된 옛 분기 파일도 보존하며, 옛 native 정상 종료나 전체 gzip EOF를 새로 인증하지 않는다. 현재 source436 SHA와 이전 세 봉인의 manifest SHA는 보존 기록과 일치했다. 과거 봉인 내부 전체 재해시는 반복하지 않았다.
