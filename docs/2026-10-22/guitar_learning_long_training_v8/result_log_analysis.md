# v8 장기 학습 로그 분석

**학습·저장·엄격 재개 검산은 정상 완료했다. 훈련 수집에서는 약지·소지 달성이 늘었지만, 검지·중지 유지가 부족하고 마지막100회 소지 성과가 급락했다.** 전체67음 성공과 단계 진급은 없었다. 이 보고서는 학습 중 수집을 분석하며, 별도로 수행한 고정 checkpoint 평가의 점수나 대표 모델 선정 결과를 섞지 않는다.

구간 번호는0부터 시작하는 **episode 종료 update index**다. 한 곡은 여러 PPO 업데이트와 서로 다른 정책을 거치므로 그 구간의 고정 모델 시험이 아니다. H32 경계에서 곡·물리를 reset하지 않는다. 서로 다른 구간의 안전곡도 동일 환경/episode를 짝지은 비교가 아니다.
