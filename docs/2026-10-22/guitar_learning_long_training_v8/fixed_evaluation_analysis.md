# v8 고정 정책 평가와 실제 자세 분석

**평가한 학습 모델 중 최고는1500회이며, 최종2000회는 그보다 낮다.** 초기 평균3.8633/67음에서 최고7.8262음, 최종6.7383음으로 증가했지만, 모든67음 과제 성공은 모두0곡이다. 최고 모델은 약지·소지에, 최종 모델은 거의 약지에 편중됐다. 실제 자세40캡처에서는 끝관절 집중과 비사용 손가락의 큰 굽힘이 남아 있어 자연스러움 개선을 인증하지 않는다.

학습 중 바뀌는 정책의 확률적 수집과 구분한, 동일 곡·seed7·035/v14 초기자세·1024환경의 **결정론적 각 환경 첫 종료곡** 평가다. 저장된3331값 커리큘럼을 strict 복원했고 다섯 모델의 실제 progress는 모두0이었다. 강제0 덮어쓰기나 평가 중 진급·PPO 갱신은 하지 않는 동결 평가 경로를 사용했다. 모델/입력파일 SHA와 업데이트·커리큘럼 보존 검사를 확인하는 범위이며, 평가 전후 전체 메모리 모델/optimizer tree를 새로 비교한 분석은 아니다.

## 비교 조건과 분모

- 전체 집단은 모델당1024개 첫곡이며 물리 종료도 포함한다. 모든 곡에서 원67음을 분모로 유지한다. 안전 집단은1969틱·32.8167초 시간축을 마친 곡이다. `안전`은 모든 음 달성이나 실제 연주 성공을 뜻하지 않는다.
- 음의 달성은 원래 지정 손가락·현·프렛의 기하/몸체 하중 후보가 audible 구간에서 누적 clean 조건을 채운 기록이다. 접촉 pair·실제 현 압력·진동·음향 인증이 아니다.
- 손가락별 목표 수는 검지25·중지18·약지12·소지12다. 손가락 비율의 분모는 해당 집단 곡 수×그 손가락 목표 수다. 기존 `67/(4×목표수)` 양성 보상 균형화는 이미 적용돼 있다.
- 실제 입력 원문·모델·source438·원장/targets/report·캡처를 포함한665경로 SHA를 CPU 분석 전후 대조했다. 모든 평가가 normal GPU close,1024환경,실제 물리수=평가tick×4를 기록했다. 재학습·정책 추론·GPU/GL/새 native 물리는 실행하지 않았다.

## 해석의 범위와 근거

- 이번v8 내부의 초기 대비 최고/최종 달성음 증가는 확인했다. v6/v7은 다른 보상·정책·PPO 계약이므로 이번 실행의 인과 대조군으로 사용하지 않았다.
