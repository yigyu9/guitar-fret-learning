# 손가락 추종 개선 작업 상태

2026-10-22. 사용자가 추가 개선의 구현·검증을 승인했다. 계획은 `docs/plans/guitar_learning_finger_tracking_fix_20261022.md`다.

현행436 Python 소스는 기존435에서 실제 자세 로그와 검사만 보강했다. 기존 press-control/ring-pinky 결과와 실행 도구는 수정하지 않았다. 실제 N6 기본/반복16 두 실행은 root가 수행했고 모두525/2100tick·조기종료0·정상종료했다. 첫 종료 때 전 환경을 멈추고 reset하지 않는 도구였다. 두 실행이 닫힌 뒤에 활성 소스를 수정했다.

현재 관측에는 target−q와 직전 적용 행동이 실제로 들어간다. 누적 목표 누락 가설은 원자료로 기각했다. 준비 자세 소지1_z의 약0.1rad 정지 오차는 남아 있다. 손가락 굽힘과 오차의 cos² 패턴은 경험적 관계이며 SDK 내부 원인을 확정하지 않았다. 상대 몸체 회전에는 qx/qz로 보고되지 않은 y 성분도 생긴다. 단순 gain 증가나 경험식 목표 증폭은 아직 적용하지 않는다.

반복16은 소지 잔차를 개선하지 않아 기본4를 유지했다. 활성 변경의 관련 CPU73개 및 독립 리뷰를 통과했고 실제 저장 자세6×525끝점의CPU/CUDA 누적기 결과를SciPy와 대조했다. 현행436소스·과거881/109개 결과·native586/587개 입력과CPU/CUDA 각599개 입력·보관본·문서 링크의 최종 무결성을 확인했다. 결과는 self-excluded manifest로 봉인한다. 새 진단은 제어/연주 성능 개선이나 native 내부 원인 해결을 뜻하지 않는다.
