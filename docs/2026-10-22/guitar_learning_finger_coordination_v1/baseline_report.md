# 최종 정책의 손가락 관절 배분 진단

**저장된 최종 2000회 정책에서 네 손가락의 중간관절(PIP)이 거의 펴지고, 검지·약지·소지는 끝관절(DIP) 굽힘에 쏠리는 실제 자세가 확인됐다.** 다만 뿌리관절(MCP)까지 전부 펴진 것은 아니다. 중지·약지는 초기 굽힘의 반대 방향으로 이동했고, 검지·소지는 뿌리 굽힘을 유지했다. 명령 목표 자체의 쏠림과 소지 벌림의 물리 추종 잔차를 구분해야 한다.

이 문서는 봉인된 `long_training_v4`의 최종 영상 대상 env0과 사전 지정 env0..7, 비교용 1500회 env0의 실제 저장 자료만 CPU로 읽었다. native 물리·GPU·GL·정책 추론은 실행하지 않았고 활성 코드나 과거 원자료를 수정하지 않았다. 개선 구현이나 인과 확정 보고서가 아니다.

## 관절 방향과 실제 자세 검산

- 평가 입력 핀과 일치하는 자산 `guitar_learning/assets/tab2body/assets/smpl_mpl_hands_body.xml`을 확인했다. `1_x`는 기저의 x축, `1_z`는 z축이며, `2/3`은 x축 힌지다. 네 손가락의 각 마디 중심선은 원래 국소 −y로 이어지고 별도 정지 회전이 없다. 이 **모델 기준**에서 양의 x회전은 중심선을 −z 쪽으로 굽힌다. 실제 손의 중립 자세나 의학적 과신전 여부를 q=0만으로 판단하지 않는다.
- native 범위는 `1_x` −40..90.0002°, `2` 0..90.0002°, `3` −5..90.0002°다. `1_z`는 검지 ±30°, 중지·약지 ±20°, 소지 −20..40°다. 저장된 39행동 계약의 실제 rad 범위와 자산의 degree 범위를 16축 모두 대조했다.
- PIP/DIP는 q뿐 아니라 실제 `finger1→finger2→finger3→tip` 중심선 사이 각도로 독립 검산했다. env0 전체에서 |q2|/|q3|와 중심선 굽힘각 차이는 최대 0.00046° 미만이었다. 따라서 이번 중간마디 펴짐·끝마디 굽힘은 표시용 q만의 해석이 아니다.
- MCP는 palm 대비 finger1의 **실제 상대 SO(3)**와 근위 중심선도 계산했다. 아래 signed bend는 palm 좌표의 근위 중심선에서 `atan2(−z,−y)`로 정의한 투영 방향각이다. 완전한 MCP 각도 한 개로 간주하지 않는다. 상대 회전벡터의 y성분을 별도로 보존했다.

기준 초기 자세는 같은 실제 캡처의 t0(035/v14 복원 직후)다. 기본 통계는 t0를 제외한 1969개 제어 끝점이며, 아래 안정 구간은 **끝점 시각 10초 이상 1370개**다. 240Hz 극값이나 연속 전구간 관측으로 확대하지 않는다.

네 PIP의 행동은 곡 전체 1969tick에서 모두 음수였고, 검지·약지 DIP는 모두 양수였다. 끝점 목표가 한계 근처일 때도 같은 방향의 요청이 이어졌다. 예를 들어 10초 이후 검지 PIP/DIP, 중지 PIP, 소지 PIP는 끝점 목표가 해당 한계 2° 이내이면서 바깥 방향 명령인 비율이 각각 100%였다. JSON의 `target_within2deg_outward_action_fraction`은 **끝점 목표의 2° 근접+외향 요청** 진단이다. 직전 목표가 정확히 경계에 있었는지, 그 tick에 실제 clamp가 일어났는지, 실제 관절이 한계 밖으로 움직였는지를 판정한 값은 아니다. 기존 에피소드의 정확한 직전 경계 outward 지표와 동일시하지 않는다.

중간/끝관절의 실제 q와 목표 RMS 오차는 작다. 10초 이후 검지 PIP/DIP는 0.00008°/0.00068°, 약지는 0.3693°/0.4100°, 소지는 0.00185°/0.4697°다. 따라서 이 관절들의 곧은 중간마디·굽힌 끝마디를 물리 추종 실패만으로 설명할 수 없다. 반면 **소지1_z**는 목표 평균 39.91°에 실제 14.56°, RMS 오차 25.36°로 기존 추종 잔차가 남았다. 이 축은 명령과 실제 자세의 문제를 분리해야 한다.

변화율도 저장했다. JSON의 `q_speed_deg_s`는 인접 60Hz 끝점의 실제 q 차분, `target_speed_deg_s`는 명령 위치 차분, `native_endpoint_qd_deg_s`는 해당 끝점의 native qd다. 서로 대체하지 않는다. 아래는 10초 이후 실제 각도 범위와 목표 추종 RMS다.

## 현재음·준비음이 없는 구간도 같은 방향 요청

‘비사용’은 접촉 여부로 단정하지 않고 악보/보상 helper의 선택 역할로 나눴다. 행동 구간 시작 시각에 손가락별로 현재 들려야 할 음(`onset<=t<end`, 겹치면 earliest end)을 우선하고, 없으면 `press−2<=t<end`의 준비음(earliest onset)을 고른다. 원순서로 동률을 푼다. 둘 다 없으면 **선택 목표 없음**이다. 이 구간에도 놓기·다음 운지·충돌 회피를 위한 움직임은 유효할 수 있으므로, 움직임 자체를 오류로 부르지 않는다.

frame k의 행동은 직전 네 물리 step에 적용된 값이다. 역할은 그 구간 시작 시각 `(clock[k]−4)/240`에 분류하고 q는 끝점에서 읽었다. 구간 중간의 목표창 경계까지 나눈 240Hz 분류는 아니다.

현재음/준비음/선택 목표 없음 모두를 합하면 각 손가락 1969tick이다. 네 PIP의 전곡 음수 행동과 검지·약지 DIP의 전곡 양수 행동은 ‘선택 목표 없음’에서도 유지된다. 역할에 맞는 반전·관절 배분이 충분히 나타나지 않는 **정책 행동의 관측 근거**다. 이것만으로 별도 휴식 자세 강제나 비활성 손가락 고정이 정답이라고 결론 내리지 않는다. 접촉 후보 원장은 곡 끝 누적치이므로 이 자료로 각 순간의 손가락 접촉력·물리적 끼임을 복원하지 않았다.

## 해석과 검증 범위

확인된 것은 (1) PIP 신전과 일부 DIP 끝 굽힘의 실제 기하, (2) 악보 역할에 무관하게 이어진 일부 행동 부호, (3) 대부분 PIP/DIP에서 그 명령 목표를 실제로 따른 결과, (4) 소지 벌림축에 남은 별도 추종 잔차다. 학습 목표가 손끝 후보만 만족하는 해법을 허용하거나 관절 간 협응·반전 신호가 부족했을 가능성은 후속 가설이다. 이번 자료만으로 확정하지 않는다.

초기 자세와 다른 관절 배분 자체가 잘못은 아니다. 후속 변경은 손끝 목표 수행·현재음/준비음 전환·실제 중심선 굽힘·비선택 구간의 자유로운 이동·관절 한계 지속 요청을 함께 비교해야 한다. 초기 각도 강제 복원이나 손가락 자동 고정을 이 분석에서 시행하지 않았다.
