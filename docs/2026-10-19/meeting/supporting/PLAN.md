# 미팅 자료 정리

범위는 이 meeting 폴더 안의 완성 자료와 제작 보조 파일이다. 원본 실험·코드·진행 중 학습은 수정하거나 이동하지 않는다. 새 시뮬레이션과 학습은 수행하지 않는다.

- [x] 완료된 미디어와 결과 기록 확인 및 서로 다른 물리 조건 구분
- [x] result에 영상·이미지·발표 설명 배치
- [x] supporting에 조립 스크립트·출처·관련 결과와 제작 근거 보관
- [x] 복사 SHA 대조·영상 decode·이미지 열기·문서 링크·목록 확인

학습 baseline은 Root 고정/하체 유한 제어이며 오늘의 왼손 잡기 진단은 Root/하체 고정이다. 단음 좌우 합본은 별도 시험 편집, 초기 자세 정면 영상도 두 시험 편집이다. 전곡 결과는 보상 개선 전 완료된 8업데이트 시험이며 진행 중 후속 연구를 대표하지 않는다.

검증 완료: 35개 원본/사본 SHA 일치, 영상6개 전체 decode 통과, PNG7개 열기 통과, 작성한5개 문서의 로컬 링크 오류0. 기준 자세와 새 자세 네 장면은 직접 시각 확인했다. 결과 폴더에는 MP4·PNG·Markdown만 있으며 원본은 이동/수정하지 않았다.
