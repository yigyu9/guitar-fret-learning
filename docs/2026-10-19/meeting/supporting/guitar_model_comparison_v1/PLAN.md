# 기타 모델 비교 이미지

사용자 요청에 따라 초기 기타와 현재 OM v3 기타를 같은 Isaac Gym 환경에 나란히 놓아 촬영한다. 앞선 자료 수집 계획의 새 실행 제외 조건은 이번 명시적인 촬영 요청에 한해서 갱신한다. 학습이나 기존 실험은 변경하지 않는다.

- [x] 초기 자산과 최신 자세 실험의 실제 OM v3 자산 확인
- [x] 원본 XML·전체 선언 메시를 해시로 기록하고 두 actor를 같은 환경에서 촬영
- [x] 두 모델의 화면 내 표시, 원본 불변, 이미지 열기를 검증하고 발표 목록에 추가

왼쪽은 tab2body/assets/guitar_asset.xml, 오른쪽은 stability_adapter_2/assets/om_body_geometry_v3/guitar_asset.xml이다. 양쪽 모두 원래 크기를 유지하고 같은 방향·높이로 배치한다. 비교 촬영에만 base를 고정하며 물리 시간은 진행하지 않는다. 이 이미지는 형상 비교이며 자유 기타의 지지 안정성 시험이 아니다. 입력·로그·재현 스크립트는 이 폴더, 완성 PNG와 설명은 result에 둔다.

검증 완료: 실제 native 실행 종료 0, 한 환경에 기타 actor 2개, 두 모델 모두 영상 경계 안에 표시, 1920 × 1440 PNG 열기 통과, 전체 입력 SHA 실행 전후 일치. 시각 geom 로드 메시지 12개는 보존하고 설명에 표시했다.
