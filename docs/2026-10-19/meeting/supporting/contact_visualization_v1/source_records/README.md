# 앞·옆·위 전신 시점과 실제 접촉점

최신16초 왼손 잡기·놓기 테스트를 전신 앞·오른쪽 옆·위 시점으로 시각화했다. **초기값, 저장된60Hz 전체 상태 궤적,240Hz 접촉 기록이 원래 테스트와 정확히 같았다.** 물리·제어·모델은 바꾸지 않고 카메라와 접촉점 표시만 추가했다.

## 읽는 방법

왼쪽부터 앞, 휴머노이드 오른쪽 옆, 위 시점이다. 각각 머리와 발을 포함한 전체 자세를 보여준다. 위 카메라는 수직 특이점을 피하기 위해 약1.2° 기울였다. 원형 표식은 실제 기타–인체 contact feature를 native body pose로 월드 좌표에 옮겨 투영한 것이다.

|원 색|인체 부위|
|---|---|
|청록|가슴 Chest|
|주황|오른 위팔 R_Shoulder, shoulder→elbow 블록|
|보라|오른 허벅지 R_Hip|
|파랑|왼 허벅지 L_Hip|
|빨강|왼 엄지|
|노랑|왼손 나머지 손가락·손바닥|
|회색|그 밖의 인체 부위|

**채운 원**은 양의 raw lambda가 있는 contact, **빈 원**은 접촉 목록에는 있지만 lambda가0인 feature다. 원 크기는 고정이며 접촉 면적·압력·힘 크기를 나타내지 않는다. raw lambda를N단위 힘으로 바꾸지 않았다. 손 전체의 초록·분홍은 기존 모델 재질색이며 접촉 표시는 원 모양뿐이다.

모든 점은 **X-ray 표시**이므로 몸에 가려진 접촉점도 보인다. 위 시점에서 머리 위에 겹쳐 보이는 원도 실제로는 뒤쪽 가슴·위팔·허벅지 위치일 수 있으며 색과 다른 두 시점을 함께 확인해야 한다. 같은 부위의2mm 격자 안에 있는 feature는 표시만 병합하고, 모든 원시 행은 보존했다. 병합은 실제 접촉 면적을 추정하는 과정이 아니다.

## 장면별 관찰

|시각|해당 프레임의 관찰|
|---|---|
|0.5초|가슴·위팔·오른 허벅지와 일부 왼손 접촉|
|3.5초 A 잡기|엄지·검지 접촉과 위팔·오른 허벅지 접촉, 가슴 접촉은 없음|
|5.333초 A 해제 중|오른 허벅지 접촉이 사라진 반면, 왼 엄지·검지/소지·왼 허벅지·위팔의 양의 lambda가 남음|
|6.5초 A 놓기|왼손 접촉 없이 가슴·위팔·오른 허벅지 접촉|
|10.5초 B 잡기|왼손과 가슴·위팔·오른 허벅지 접촉|
|14초 B 놓기|왼손 접촉 없이 가슴·위팔·오른 허벅지 접촉|

이는 해당 순간의 관측이며 어느 접촉이 움직임의 원인인지 단정하는 결과가 아니다. 첫 해제 과정에서 지지 접촉이 달라지는 모습을 확인할 수 있다. 영상의 점은30fps 프레임 시점의 접촉이고, 전체 잡기·놓기 판정은 원래240Hz 기록을 따른다.30fps에서 합친7912개 원시 행을 독립된 접촉 사건7912회로 해석하지 않는다.
