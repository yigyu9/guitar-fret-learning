# 기존 접촉점 시각화 자료 수집

- [완성 PNG 6개](../../result/images/contact_visualization)
- [미팅용 설명](../../result/documents/01c_contact_visualization.md)
- `collect.py`: 기존 이미지·설명·접촉 요약 복사 코드
- `manifest.json`: 9개 사본의 원본 경로·SHA256·크기·이미지 해상도와 검증
- `source_records/`: 원결과 설명, 정정된 이미지 설명 V2, 접촉 요약 사본

기존 파일을 그대로 복사했으며 새 렌더·물리·이미지 편집은 수행하지 않았다. 원본/사본 바이트 동일 대조와 PNG 열기를 확인했다. 다시 수집하려면 새 버전 경로를 사용한다. 원문 문서의 내부 링크는 원프로젝트를 가리킨다.
