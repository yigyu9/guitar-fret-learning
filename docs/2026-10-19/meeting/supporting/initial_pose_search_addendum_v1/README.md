# 오른쪽 기울임·둥근 허리 자세 추가 수집

[결과와 설명](../../result/documents/01d_right_tilt_and_rounded_spine.md)에 PNG 5개를 추가했다. 기존 PNG 4개는 바이트 동일 복사이며 오른쪽 기울임 초기 이미지는 기존 native 영상의 0번 프레임을 추출했다. 새 시뮬레이션·렌더·크롭·덧그림은 수행하지 않았다.

- `collect.py`: 원본 복사와 저장 영상 첫 프레임 추출/픽셀 대조 코드
- `manifest.json`: 원본·사본 경로, SHA256, 추출 시점, 해상도와 검증
- `source_records/`: 직립 교정 결과·기존 비교표의 검증·둥근 허리 결과 V2와 이미지 설명 사본

모든 원본 불변, PNG 열기와 복사 SHA 일치, 추출 PNG와 MP4 첫 프레임의 디코딩 픽셀 일치를 확인했다. 재실행은 새 버전 폴더를 사용한다. 보존 문서 내부의 옛 절대경로는 현재 archive 정리 전 경로이며 원문 그대로 두었다. 최신 실제 원본 위치는 manifest에 기록했다.
