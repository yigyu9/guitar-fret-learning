# 연구 미팅 자료

교수님께 보여드릴 완성 자료는 [result 안내](result/README.md)에서 연다. 제작·출처·검증 파일은 [supporting 안내](supporting/README.md)에 있다.

- `result/videos/`: 발표에 사용할 MP4 사본
- `result/images/`: 자세·접촉·학습 결과 이미지 사본
- `result/documents/`: 설명 문서와 미디어별 관찰 구간
- `supporting/scripts/`: 자료 조립 스크립트
- `supporting/source_code/`: 원 제작 코드 참고 사본
- `supporting/source_records/`: 근거 결과·보고서·CSV 사본
- `supporting/provenance/`: 원본 경로·SHA·복사 목록
- `supporting/qa/`: 이미지·영상·문서 확인 결과

이 폴더는 완료된 자료를 모은 미팅용 묶음이다. 원본 파일과 진행 중인 별도 실험·학습은 수정하지 않았다.
