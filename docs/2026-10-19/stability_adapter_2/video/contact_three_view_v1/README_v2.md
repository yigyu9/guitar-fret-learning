# 접촉 표식 native 3-view 영상

네 영상은 같은 초기 상태와 제어로 다시 수행한 16초 물리 실행이다. Pose playback이 아니다. 저장된 60 Hz state trace와 240 Hz contact log는 원 실행과 exact하게 일치한다. 영상은 481프레임, 30 fps이며 전면·오른쪽 옆면·위 순서다. 원형 점만 접촉을 표시한다. 초록·분홍 손 표면은 원래 재질색이며 접촉값이 아니다. 채움은 양의 raw lambda, 빈 원은 lambda=0이다. 점은 X-ray처럼 항상 보이고 크기는 힘을 나타내지 않는다. 해석과 실제 프레임은 [한국어 요약 V2](/home/ajou/yigyu/3/docs/2026-10-19/stability_adapter_2/results/contact_three_view_v1/artifacts_v1/README_v2.md)에서 확인한다.
