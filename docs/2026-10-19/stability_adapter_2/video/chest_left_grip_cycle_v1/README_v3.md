# 왼손 잡기·놓기 사이클 native 영상

16초 native Isaac Gym 실행의 세 영상은 기존 바이트 보존본을 직접 연결한다. 오른손 타현은 꺼져 있다. 수정된 quaternion 정규화 기반 기타 자세 그래프와 전체 240 Hz 표는 [V2 요약](/home/ajou/yigyu/3/docs/2026-10-19/stability_adapter_2/results/chest_left_grip_cycle_v1/artifacts_v2/README.md)에서 확인한다. V1 quaternion 기반 그래프/CSV는 자세 계산 오류 때문에 superseded 됐으며 native 실행과 영상은 영향받지 않았다.
