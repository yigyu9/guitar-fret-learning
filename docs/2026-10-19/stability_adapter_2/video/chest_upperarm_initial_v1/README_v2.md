# 가슴·오른쪽 위팔 초기 자세 비교 영상

4개 영상 묶음은 각 5초, 30 fps, 151 frames의 실제 native Isaac Gym 캡처다. 캡처에는 비물리적 6개 string endpoint 선 표시가 있다. Hold는 정지 관찰, 나머지 세 run만 EW6 가상 피크 타현을 한다.

Near는 root가 우선 검토안으로 추천한 왼손 넥 준비이고, Far는 5초 전체에서 왼팔·왼손 접촉이 0인 분리 영상이다. Far의 후반에는 Chest 접촉이 끊기고 오른쪽 위팔·오른 허벅지 및 왼 허벅지 접촉이 남는다. 상세 지표와 한계는 [한국어 요약](/home/ajou/yigyu/3/docs/2026-10-19/stability_adapter_2/results/chest_upperarm_initial_v1/artifacts_v1/README_v3.md)에서 확인한다.
