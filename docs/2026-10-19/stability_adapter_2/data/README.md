# 추적용 원자료 복사본

이 폴더의 JSON·Markdown·manifest는 지정된 완성 원자료의 bytes 그대로 복사한 것입니다. JSON 내부에 기록된 기존 절대경로는 원 실험 추적을 위해 유지했으며, 이 복사본은 새 실행 설정이 아닙니다.

- `guitar/`: OM 바디 형상 manifest, 출처 노트와 깊이 표본
- `posture/`: native 11/12 초기값·설정·report, 검증·비교 자료, 후보 검색 설정
- `video_source_manifests/`: 10-12 영상 archive의 manifest v1–v3

파일별 원본·사본 SHA-256 및 byte 수는 [provenance_v1.json](/home/ajou/yigyu/3/docs/2026-10-19/stability_adapter_2/provenance_v1.json)에 있습니다.
