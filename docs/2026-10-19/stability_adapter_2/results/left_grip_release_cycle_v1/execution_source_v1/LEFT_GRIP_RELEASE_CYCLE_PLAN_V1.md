# 왼손 잡기·놓기·넥 이동 진단

사용자 요청: 현재 +10mm 오른쪽 배치에서 왼손 지지가 바뀌어도 자유 기타가 유지되는지 실제 Isaac Gym으로 확인한다. 다른 스레드의 fresh_learning_v1 학습 구현은 수정하지 않는다.

## 조건과 제어

- 기존 config_v1/candidate.json의 초기 자세·자산·질량·마찰·PD·오른쪽 상완 지지를 유지한다. Root/하체 고정, 자기 충돌 ON, 스트랩 OFF이다.
- 오른손 타현 궤적은 이번 분리 진단에서 OFF이다. 오른팔은 준비 목표와 기존 유한 토크 지지를 유지하며 실제 상태를 고정하지 않는다.
- 왼팔12 목표는 현재 기타 좌표계의 손목 위치/방향에 맞춰 IK로 계산하고 원래 3rad/s 제한을 적용한다. 작은 유한 손목 임피던스는 사람 왼팔12 토크에만 합산한다. 기타 힘·강제 부착·상태 덮어쓰기는 금지한다.
- 왼손21은 기존 자세에서 네 손가락 굽힘을 최대0.18rad 추가한다. 놓기에서는 굽힘을 되돌리고 손목을 넥 아래 방향으로45mm 물린다. 손목 자세를 유지하므로 엄지도 함께 물러난다. 모델 한계와 기존 손가락1.5rad/s 제한을 적용한다.
- 지점 B는 지점 A에서 기타 local +Y(넥 방향)40mm이다. 이동은 손을 물린 상태에서 한다. 이는 압현 학습·음 정확도 성공 진단이 아니다.
