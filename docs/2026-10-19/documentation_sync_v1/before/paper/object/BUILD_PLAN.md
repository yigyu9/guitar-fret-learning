# Object 자료 정리 계획

범위는 현재 OM v3 기타와 fixed-lower 휴머노이드의 모델 사양, 원본과의 차이, 실제 XML·메시 사본이다. 메인 실험의 실행·설정·원본 파일은 변경하지 않는다. 2026-10-13에 확인한 자산을 정리하며, 날짜가 붙은 과거 결과는 그 실행의 근거로만 쓴다.

1. 자산·의존 메시·확정된 native 물성 자료를 수집한다. → 원본과 사본 SHA-256 일치 확인.
2. 기타·휴머노이드 사양, 관절/형상 목록, XML 선언과 실행 설정의 차이를 문서화한다. → 수치와 실제 XML/JSON 대조.
3. 사본의 상대 경로, 문서 링크, 원본 보존을 확인한다. → 검증 결과를 verification.json에 저장.

서브에이전트는 이 별도 대화에서 사용하지 않는다. 사양 정리는 기존 저장 자료만 읽고, 새 물리 실행이나 시뮬레이션 상태 변경은 수행하지 않는다.
