## 1. 악기 기하

- 6줄. 표준 튜닝, 굵은 줄부터: **E2 – A2 – D3 – G3 – B3 – E4**.
- N번 프렛을 누른다 = **N번 프렛 막대 바로 뒤(너트 쪽) 공간**을 눌러 줄을 막대에 밀착시키는 것. 진동 길이가 짧아져 반음×N 상승. 개방현(0) = 그 줄의 최저음.
- 프렛 간격은 등비 감소(**18의 법칙**: 매 프렛마다 남은 현 길이의 1/17.817 제거 = 매 칸 ÷1.0595). 12칸마다 폭이 정확히 절반.

## 2. 음이름 체계

- 알파벳 C D E F G A B = 도 레 미 파 솔 라 시. 사이에 #(반음 올림)을 끼워 **12반음이 한 바퀴**:
  `C C# D D# E F F# G G# A A# B → (다시 C)`
- **E→F, B→C는 사이에 #음이 없어 바로 반음(1프렛) 관계**. 나머지 이웃 음 사이에는 #이 하나씩 끼어 온음(2프렛) 관계. (오답 주의: A→B 사이에는 A#이 있다.)
- 숫자 = 옥타브 번호. 12반음 = 옥타브 = 주파수 2배. **번호는 C에서 증가** (… A2 → B2 → C3 → …). 기준음 A4 = 440Hz, 가운데 도 = C4. E2 ≈ 82Hz, E4 ≈ 330Hz.
- **변환 공식: 음(줄, 프렛) = 개방현 음 + 프렛 수(반음)**. 예: 6번줄 3프렛 = G2, 8프렛 = C3, 12프렛 = E3.
- **5프렛 법칙**: 각 줄의 개방현 = 바로 아랫줄(번호+1)의 5프렛과 같은 음. 예외: 2번줄 개방(B3) = 3번줄 **4프렛**. → 같은 음이 지판 여러 위치에 존재하는 이유이자, "운지 선택" 문제의 근원. 단 **탭은 위치를 이미 지정**하므로 우리 파이프라인에서 음→위치 문제는 없음.

## 3. 소리 규칙

- 왼손은 음높이만 정하고, **소리는 오른손이 그 줄을 튕겨야** 난다. 눌러만 두면 무음.
- **한 줄에서 여러 프렛이 눌리면 가장 높은(브리지 쪽) 프렛이 이긴다** — 낮은 쪽 접촉은 소리에 무관. (GPS `freedom` 완화 규칙의 음향학적 근거.)
- 반드시 **누른 다음에 쳐야** 한다(순서 반전 = 잡음). 예외: 해머온/풀오프(왼손만으로 발음 — 노트 포맷에서 별도 이펙트).
- 뮤팅도 연주의 일부: 안 울릴 줄 관리(왼손 살짝 대기, 오른손 팜 뮤트).

## 4. 왼손 — 운지

- 손가락 번호: **검지 1, 중지 2, 약지 3, 소지 4**. 엄지는 넥 뒤 받침(반작용 지지대).
- **엄지 압현(thumb-over)은 드묾**(6번줄 저프렛 베이스음 한정, 전체 압현의 한 자릿수 % 이하) → 모델링은 **검지~소지 4개만** 사용. 단 G1/G2(자유 기타)에서는 엄지의 **force-closure(넥 뒤 반작용 지지)** 역할이 물리적으로 부활함 — 스트랩 설계와 같은 묶음으로 검토.
- **포지션 주법**: 검지가 놓인 프렛 = 포지션 P. 1프렛 1손가락(검지=P, 중지=P+1, 약지=P+2, 소지=P+3)이 기본.

### 사람의 운지 판단 순서

1. **코드면 사전 조회** — 암기된 폼(셰이프) 그대로. 코드 차트에 손가락 번호까지 관례로 박제 → "일반적 운지"의 문서화된 원천.
2. **멜로디면 포지션 유지** — 포지션 안에서 소화, 안 되면 포지션 시프트(비용 큼, 미리 계획).
3. **앞뒤 문맥(선행 준비)** — 다음 코드에 필요한 손가락을 미리 비워두고, 전환 시 **공통 손가락 유지(앵커 핑거)**. GPS·Xu 공통 한계 = 이 층위 부재.
4. **생체역학 제약** — 손가락 교차 금지, 스팬 한계(통상 4프렛, 스트레치 5), 약지·소지 독립성 낮음, 바레는 사실상 검지 전용.
5. **울림 유지** — 아직 울려야 하는 줄의 손가락은 못 뗀다.
6. **기법 예약** — 벤딩·비브라토용 손가락 배정(현 단계 무시 가능).

같은 악보에 복수의 타당한 운지가 존재 — "사람이 할 법한 운지"는 분포이고, 교본 운지는 최빈값.

## 5. 코드(chord)

- 이론: 근음+3도+5도 등 3음 이상의 화음. 기타는 6줄에 구성음을 중복 배치 (Am = A·C·E → x02210).
- **연주자에게 코드의 실체는 "셰이프(폼/그립)"** — 왼손 모양을 통째로 암기하고, 폼↔폼 전환을 연습한다. 매번 구성음을 계산하지 않는다.
- **코드 = 왼손의 상태(state), 노트 = 오른손의 이벤트(event)**. 왼손이 폼을 유지하는 동안 오른손이 리듬을 만든다.
- 사용 형태:
  - **스트럼**: 폼을 잡고 오른손으로 여러 줄을 한 번에(한 방향 스윕으로) 쓸기.
  - **아르페지오**: 폼을 유지한 채 줄을 하나씩 차례로 튕기기.
  - **파워 코드**: 3도를 뺀 **근음+완전5도(+옥타브 근음)** 축약형. 검지=근음, 약지(+소지)=두 줄 아래 +2프렛. 예: A5 = 6번줄 5프렛(A) + 5번줄 7프렛(E) [+ 4번줄 7프렛(A)]. 3도가 없어 장/단 중립 → 디스토션에서도 깨끗 → 록/메탈 리듬 표준 (코퍼스의 master_of_puppets, come_as_you_are가 이 부류).
- **이동 불변성**: 바레 코드 = 검지로 전 줄을 눌러 "이동식 너트"를 만들고 폼을 얹은 것 (F = E폼@1프렛). 개방 폼 5개(C·A·G·E·D)가 바레화되어 지판 전체를 덮는 체계 = **CAGED**. → 셰이프 사전이 작아도 되는 이유, Xu의 "코드 패턴 유지 지판 시프트" 증강의 근거.

## 6. 오른손 — 탄현

- **피크**(엄지+검지로 쥠, Xu) vs **손가락**(GPS): 손가락 관례는 클래식 PIMA — 엄지(P)=6·5·4번줄 베이스, 검지·중지·약지(i·m·a)=3·2·1번줄.
- 다운/업 피킹. 속주 기본 = 얼터네이트(교대). 코드 여러 줄 = **한 방향의 빠른 연속 스윕**(위→아래 또는 아래→위, 건너뛰기 = 오처리).
- 스트럼하는 오른손은 메트로놈처럼 **계속 흔들리고 닿을지만 선택** — 리듬 유지의 비결 (모션 = 주기 운동 + 접촉 게이팅).

## 8. 연구 매핑 — 개념 → 베이스라인 코드 → tab2body

| 기타 상식 | GPS / Xu 코드 대응 | tab2body 반영 지점 |
|---|---|---|
| 소리 = 그 줄의 최고 프렛 | GPS `freedom` / Xu `press = max fret` (env.py L1573) | fret 보상의 오누름 완화 규칙 |
| 눌림 판정 | GPS 힘센서 임계 0.2 vs **Xu 기하 판정 0.006m** (L1562) | base.py에서 방식 선택 (DIGIT 교훈: 힘센서는 비영 출력 검증 필수) |
| 포지션·1프렛1손가락 | GPS `arrangeFinger` hold position P | 운지 prior(선택) — 유일해 아님 |
| 교차 금지·스팬≤4 | Xu availability 마스킹 (L1614-1651), `load_notes` span>4 축소 | 스팬 제약 — 개선 여지: 프렛 수 대신 **절대 거리·포지션 의존** 한계 |
| 개방현 = 닿지 말 것 | Xu 식5 `r⁰=(d/0.007)²` / tabproc AVOID(≥7mm) | 개방현 클리어런스 보상 |
| 코드 = 암기된 셰이프(상태) | 양쪽 다 미모델링. Xu `effects.chords` = 수동 주석 채널 | **그립 추론 모듈**(effects.chords 자동화) = 신규 기여 |
| 스트럼 = 한 방향 스윕 | Xu `r_pick` 순서 규칙 (r⁺/r⁻/r^×) | strike 보상 |
| 누른 뒤 친다 | Xu TwoHands `ready` 게이팅 (L2195-2199) | combine 협력 조건 |
| 엄지 = 받침(force-closure) | 양쪽 다 기타 고정이라 회피 | **G1/G2에서 부활** — 스트랩·엄지 접촉 설계 |
| 프렛 사용 저프렛 쏠림 (91.8%≤12) | Xu 랜덤 지판 시프트 증강 (`random_pitch_rate`) | 커리큘럼·증강 유지 근거 |
