## 1. 악기 기하

- 6줄. 표준 튜닝, 굵은 줄부터: **E2 – A2 – D3 – G3 – B3 – E4**.
- N번 프렛을 누른다 = **N번 프렛 막대 바로 뒤(너트 쪽) 공간**을 눌러 줄을 막대에 밀착시키는 것. 진동 길이가 짧아져 반음×N 상승. 개방현(0) = 그 줄의 최저음.
- 이상적인 평균율 기타의 프렛 간격은 등비 감소한다(**18의 법칙**: 매 프렛마다 남은 현 길이의 약 1/17.817 제거 = 매 칸 ÷1.0595). 12프렛에서 진동 길이가 절반이 된다. 현재 모델의 실제 위치 계산에는 아래 XML 좌표를 사용한다.
- 현재 기타는 **OM 바디·22프렛·6현 마커**로 구성된 자유 강체다. 현은 시작·끝 마커를 잇는 비평행 유한 선분으로 다룬다. 표시용 캡슐은 현의 탄성·진동·소리를 구현하지 않는다.
- 기타 로컬 좌표 G에서 **+X는 6번줄→1번줄**, **+Y는 브리지→너트**, **+Z는 현이 놓인 앞판 쪽**이다. 기타가 움직이면 이 좌표계도 함께 움직인다.
- 바디 길이 491.957 mm, 최대 폭 380.632 mm, 기타 전체 외형 길이 1,004.328 mm다. 현 마커 사이 길이는 줄마다 약 620.0~625.6 mm이며, 하나의 648 mm 실물 스케일로 치환하지 않는다.

## 2. 음이름 체계

- 알파벳 C D E F G A B = 도 레 미 파 솔 라 시. 사이에 #(반음 올림)을 끼워 **12반음이 한 바퀴**:
  `C C# D D# E F F# G G# A A# B → (다시 C)`
- **E→F, B→C는 사이에 #음이 없어 바로 반음(1프렛) 관계**. 나머지 이웃 음 사이에는 #이 하나씩 끼어 온음(2프렛) 관계. (오답 주의: A→B 사이에는 A#이 있다.)
- 숫자 = 옥타브 번호. 12반음 = 옥타브 = 주파수 2배. **번호는 C에서 증가** (… A2 → B2 → C3 → …). 기준음 A4 = 440Hz, 가운데 도 = C4. E2 ≈ 82Hz, E4 ≈ 330Hz.
- **변환 공식: 음(줄, 프렛) = 개방현 음 + 프렛 수(반음)**. 예: 6번줄 3프렛 = G2, 8프렛 = C3, 12프렛 = E3.
- **5프렛 법칙**: 각 줄의 개방현 = 바로 아랫줄(번호+1)의 5프렛과 같은 음. 예외: 2번줄 개방(B3) = 3번줄 **4프렛**. → 같은 음이 지판 여러 위치에 존재하는 이유이자, "운지 선택" 문제의 근원. 단 **탭은 위치를 이미 지정**하므로 우리 파이프라인에서 음→위치 문제는 없음.

## 3. 소리 규칙

아래는 실제 기타의 일반적인 발음 원리다. 현재 환경에서는 현 진동·음높이·음향을 계산하지 않으며, 압현 접촉 후보와 피크의 기하학적 교차를 측정한다. 이 측정만으로 실제 발음이나 음향 품질을 입증하지 않는다.


- 왼손은 음높이만 정하고, **소리는 오른손이 그 줄을 튕겨야** 난다. 눌러만 두면 무음.
- **한 줄에서 여러 프렛이 눌리면 가장 높은(브리지 쪽) 프렛이 이긴다** — 낮은 쪽 접촉은 소리에 무관. (GPS `freedom` 완화 규칙의 음향학적 근거.)
- 반드시 **누른 다음에 쳐야** 한다(순서 반전 = 잡음). 예외: 해머온/풀오프(왼손만으로 발음 — 노트 포맷에서 별도 이펙트).
- 뮤팅도 연주의 일부: 안 울릴 줄 관리(왼손 살짝 대기, 오른손 팜 뮤트).

## 4. 왼손 — 운지

- 손가락 번호: **검지 1, 중지 2, 약지 3, 소지 4**. 엄지는 넥 뒤 받침(반작용 지지대).
- 실제 기타에서는 엄지가 넥 뒤를 받치거나, 일부 주법에서 6번줄을 누르기도 한다. 현재 `FretTarget`은 압현 손가락으로 **검지·중지·약지·소지**만 허용한다. 엄지는 별도의 넥 지지·접촉 역할로 구분하며 압현 손가락 번호 1~4에 포함하지 않는다.
- **포지션 주법**: 검지가 놓인 프렛 = 포지션 P. 1프렛 1손가락(검지=P, 중지=P+1, 약지=P+2, 소지=P+3)이 기본.

### 사람의 운지 판단 순서

1. **코드면 사전 조회** — 암기된 폼(셰이프) 그대로. 코드 차트에 손가락 번호까지 관례로 박제 → "일반적 운지"의 문서화된 원천.
2. **멜로디면 포지션 유지** — 포지션 안에서 소화, 안 되면 포지션 시프트(비용 큼, 미리 계획).
3. **앞뒤 문맥(선행 준비)** — 다음 코드에 필요한 손가락을 미리 비워두고, 전환 시 **공통 손가락 유지(앵커 핑거)**. GPS·Xu 공통 한계 = 이 층위 부재.
4. **생체역학 제약** — 손가락 교차 금지, 스팬 한계(통상 4프렛, 스트레치 5), 약지·소지 독립성 낮음, 바레는 사실상 검지 전용.
5. **울림 유지** — 아직 울려야 하는 줄의 손가락은 못 뗀다.
6. **기법 예약** — 벤딩·비브라토용 손가락 배정(현 단계 무시 가능).

같은 악보에 복수의 타당한 운지가 존재 — "사람이 할 법한 운지"는 분포이고, 교본 운지는 최빈값.

### 현재 프렛 간 거리와 손 벌림 해석

사람의 손 벌림 100·130 mm나 ‘4프렛’ 경험칙은 현재 휴머노이드의 도달 가능성 판정 기준이 아니다. 같은 프렛 수 차이도 위치에 따라 거리가 다르다. 현재 XML의 와이어 중심 사이 −Y 거리로 계산하면 다음과 같다.

| 와이어 구간 | 거리(mm) |
|---|---:|
| 1→4프렛 | 93.307 |
| 5→8프렛 | 74.063 |
| 12→15프렛 | 49.428 |
| 19→22프렛 | 32.990 |

이 값은 지판 길이 방향 거리의 예시다. 손가락의 실제 3차원 벌림, 줄 간 폭, 손목·관절 가동범위, 넥·바디와의 충돌을 포함하지 않는다. 로봇의 도달·압현 가능성은 현재 자세와 접촉 측정으로 확인해야 한다. 높은 프렛에서는 작은 칸 간격과 바디 간섭도 함께 확인한다.

## 5. 코드(chord)

- 이론: 근음+3도+5도 등 3음 이상의 화음. 기타는 6줄에 구성음을 중복 배치 (Am = A·C·E → x02210).
- **연주자에게 코드의 실체는 "셰이프(폼/그립)"** — 왼손 모양을 통째로 암기하고, 폼↔폼 전환을 연습한다. 매번 구성음을 계산하지 않는다.
- **코드 = 왼손의 상태(state), 노트 = 오른손의 이벤트(event)**. 왼손이 폼을 유지하는 동안 오른손이 리듬을 만든다.
- 사용 형태:
  - **스트럼**: 폼을 잡고 오른손으로 여러 줄을 한 번에(한 방향 스윕으로) 쓸기.
  - **아르페지오**: 폼을 유지한 채 줄을 하나씩 차례로 튕기기.
  - **파워 코드**: 3도를 뺀 **근음+완전5도(+옥타브 근음)** 축약형. 검지=근음, 약지(+소지)=두 줄 아래 +2프렛. 예: A5 = 6번줄 5프렛(A) + 5번줄 7프렛(E) [+ 4번줄 7프렛(A)]. 3도가 없어 장/단 중립 → 디스토션에서도 깨끗 → 록/메탈 리듬 표준 (코퍼스의 master_of_puppets, come_as_you_are가 이 부류).
- **이동 불변성**: 바레 코드 = 검지로 전 줄을 눌러 "이동식 너트"를 만들고 폼을 얹은 것 (F = E폼@1프렛). 개방 폼 5개(C·A·G·E·D)가 바레화되어 지판 전체를 덮는 체계 = **CAGED**. → 셰이프 사전이 작아도 되는 이유, Xu의 "코드 패턴 유지 지판 시프트" 증강의 근거.

## 6. 오른손 — 탄현

- **피크**(엄지+검지로 쥠, Xu) vs **손가락**(GPS): 손가락 관례는 클래식 PIMA — 엄지(P)=6·5·4번줄 베이스, 검지·중지·약지(i·m·a)=3·2·1번줄.
- 다운/업 피킹. 속주 기본 = 얼터네이트(교대). 코드 여러 줄 = **한 방향의 빠른 연속 스윕**(위→아래 또는 아래→위, 건너뛰기 = 오처리).
- 스트럼하는 오른손은 메트로놈처럼 **계속 흔들리고 닿을지만 선택** — 리듬 유지의 비결 (모션 = 주기 운동 + 접촉 게이팅).

## 8. 현재 구현과 연주 개념의 연결

현재 실행 조건은 **휴머노이드 root 고정·하체의 유한한 자세 유지 제어·기타 자유 강체·중력 ON·스트랩 OFF**다. 정책 출력은 왼팔·왼손 33개와 오른팔꿈치·손목 6개, 총 39개다. 예전 G1/G2·스트랩 설계를 현재 조건으로 해석하지 않는다. 조건과 결과는 [현재 상태](../CURRENT_STATUS.md)와 [학습 안내](../guitar_learning/README.md)를 따른다.

| 연주 개념 | 현재 코드와 의미 |
|---|---|
| 줄·프렛의 위치 | [geometry_v1.py](../guitar_learning/core/geometry_v1.py): 매 물리 샘플의 기타 로컬 좌표에서 6개 유한현·너트·22프렛을 측정한다. 손가락 말단 body 원점은 보정된 손가락 패드가 아닌 대리점이다. |
| 압현 위치·손가락 | [fretting_v1.py](../guitar_learning/core/fretting_v1.py): 지정 손가락의 접촉 body·목표 프렛 칸·가장 가까운 현·높이·유한현 범위를 함께 검사한다. 접근 목표와의 거리 진단은 접촉 후보 판정과 별도다. 접촉 후보는 압력·발음 인증이 아니다. |
| 높은 프렛이 음을 결정 | [fretting_quality.py](../guitar_learning/quality/fretting_quality.py): 단일 압현 목표의 품질 판정에서 같은 줄의 더 높은 프렛 접촉을 금지하고, 목표 접촉과 공존하는 낮은 프렛은 허용한다. 음향 시뮬레이션으로 확인하는 규칙은 아니다. |
| 개방현 | [task_measurement.py](../guitar_learning/core/task_measurement.py): 압현 목표 없이 해당 유한현에 손가락의 방해 접촉 후보가 없는지 확인한다. 음향적 개방현 품질을 직접 측정하지 않는다. |
| 타현·방향·중복 방지 | [strike.py](../guitar_learning/core/strike.py): 연속 240 Hz 샘플 사이의 상대 피크 선분과 현 선분의 교차, 속도·깊이·허용 영역을 검사하고 재무장 조건을 적용한다. 기하학적 이벤트이며 현 충돌·소리가 아니다. |
| 누른 뒤 치기·음 유지·해제 | [task_measurement.py](../guitar_learning/core/task_measurement.py)와 [music_task.py](../guitar_learning/music_task.py): 교차 앞뒤의 접촉 후보, 목표 줄·방향·시각(50/100 ms), 목표별 유지 시간과 해제를 기록한다. |
| 코드·운지 선택 | [music_task.py](../guitar_learning/music_task.py): 곡 번들의 줄·프렛·손가락 목표를 받는다. 일반적인 셰이프 설명을 현재의 자동 그립 추론이나 모든 코드 연주 성공으로 해석하지 않는다. |
| 엄지·몸을 이용한 지지 | 자유 기타의 물리 접촉과 자세 제어 문제다. 압현 목표·타현 이벤트와 구분하며, 현재 기준에서는 스트랩을 사용하지 않는다. |

### 타현(strike) 영역: 실제 판정 범위와 XML proxy의 구분

`TaskMeasurement`는 기본 `StrikeDetector()`를 사용한다. 현재 판정 계약은 다음과 같다.

- 로컬 **Y = −385~−255 mm** 구간에서 현을 가로지른다.
- 교차 시 피크가 현보다 **1~15 mm 아래**에 있어야 한다(`depth = string_z − pick_z`). 현재 현 마커 Z=12.300 mm이므로 피크 Z 범위는 **−2.700~11.300 mm**다.
- 현을 가로지르는 속도의 절댓값은 **0.05 m/s 이상**이다. 성공 교차 후에는 최소 2물리 step 및 현과 3 mm 이상 분리 조건을 충족해야 재무장한다.
- X 방향의 단일 직사각형 범위 대신 **각 현의 실제 비평행 유한 선분과 교차**하는지 검사한다. 영역 안에 있는 것만으로 타현 이벤트가 되지 않는다.

XML의 `G:pluck_range`는 중심 `[0, −328, 6.3] mm`, 반폭 `[28, 86, 7.5] mm`인 별도의 상자 proxy다. 따라서 Y 범위는 **−414~−242 mm**, Z 범위는 **−1.2~13.8 mm**로, 위 실제 strike 판정 범위와 다르다. 기준 실행에서는 이 proxy를 물리 접촉 대상에서 제외한다. 시각화를 해석할 때도 이 상자를 실제 허용 범위로 대신 사용하지 않는다.
