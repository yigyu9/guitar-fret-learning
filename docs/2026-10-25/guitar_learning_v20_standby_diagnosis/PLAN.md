# v20 손가락 꼬임·대기 구간 진단

사용자 요청에 따라 기존 500회 최종 모델 영상의 손가락 꼬임과 대기 진입 구간을 분석한다. 영상과 같은 repeat1/env0의 원래 저장 자세를 우선 기준으로 한다. 학습 코드와 기존 결과는 보존한다.

- [x] 영상과 원래 60Hz 자세 프레임·관절각·벌림·B 대역 비교 → 1969프레임 대응 및 각도 재구성 대조
- [x] 손가락별 악보 고정 대기창·실제 B 보상 집계·미저장 정보 분리 → 17개 창과 기존 진단 일치
- [x] 기저 관절·손가락 3D 방향과 대기 진입 선후 관계 분석 → 근접 지표·관절 임계 시각·정책 명령 대조
- [x] 새 진단 재생 계획과 정확 gate 보존 방법 결정 → 독립 검수·CPU 3검사 통과 후 GPU 실행
- [x] 새 재생의 실제 240Hz 시계·gate 구간·보상 원장 대조 → 8×7876 표본, 617개 입력 SHA 유지, native 보상 최대 오차 2.48×10⁻⁷
- [x] 최종 시간표·그림·보고서·독립 검수 완료 → `RESULTS.md`, `review_results.json`, Critical/Warning 없음

원래 NPZ에는 몸체 자세·q·target·action·시계 및 누적 후보/달성 개수만 있고, 개별 접촉 후보의 240Hz 시계열은 없다. 원영상은 복원 가능 범위를 명시하고, 새 진단 재생을 원영상의 누락 정보 복원으로 취급하지 않는다. 악보 대기창·시간 gate·접촉/근접까지 적용된 실제 gate·B 자세 도달을 구분한다. 두 손가락 위치 근접이나 투영상 교차를 실제 메시 침투로 확대하지 않는다.

독립 검수에서 원영상의 1/60초 프레임 오프셋 문구를 수정했고, 대기 허용 중 B 대역 시간과 전체 60Hz B 표본을 구분했다. 관절 임계 시각을 실제 꼬임 시작 시각으로 해석하지 않는다.
