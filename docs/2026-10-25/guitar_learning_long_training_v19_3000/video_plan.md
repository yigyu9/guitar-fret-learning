# 최종 체크포인트 결과 영상

사용자 요청으로 최종3,000회 checkpoint를 고정 평가하고 전신·왼손 영상을 저장한다. 현재 학습 원문·원래 결과는 보존한다. 기존 v17 도구의 기록·정적 렌더 방식을 새 v19 결과 폴더의 support에 맞춰 사용한다.

- [x] 학습 계약·소스459·GPU 유휴 확인, 별도 평가·렌더 경로 준비
- [x] 같은1024환경·seed7·035/v14 초기화·결정론적 정책으로 첫곡 평가, PPO/단계 갱신 없음 확인
- [x] 사전 지정env0..7 실제 자세 기록에서 안전 완주한 최소ID(없으면 최장→최소ID) 선택, 달성음 기준 선택 안함 (env0,26/67음·32.8167초)
- [x] 저장한60Hz 실제 자세를 전신·왼손 근접60fps 영상으로 렌더, 새 물리 적분 없음·방향·프레임/길이 검증 (각1969프레임·32.816667초)
- [x] 독립 검수와 결과 문서 갱신, 영상 제공 (analysis/video_review.json, 실제MP4 decode·SHA·전체프레임 자세/화면범위 확인)

최종 정책의 같은곡·같은초기자세 평가이며 최고 정책 선정·다른seed 일반화 검증이 아니다. 정적 MuJoCo 렌더는 실제 GPU 동작을 그대로 시각화하며 물리는 GPU PhysX 기록을 사용한다.
