# 최종 영상의 손가락 펴짐 진단

범위: 최종3000회 고정 정책의 env0 영상 한 곡, 저장된 실제60Hz 자세/행동/목표와 같은 에피소드의240Hz 진단. 추가 GPU 실행·학습/보상/제어 변경 없음.

- 약지:19.1167→19.6167초에 실제 기하 MCP가48.59→19.35도로0.5초간29.24도 펴졌다. 같은 구간 명령 목표도 감소했고 평균 행동은MCP−0.2470/PIP−0.1913이다. 둘 다 굽힘을 줄이는 명령이므로 외력에 밀린 현상만으로 설명할 수 없다. 저장된 명령을 실제 관절이 따라간다.
- 약지 마지막 음의end는30.0048초다.30.1548초 이후에는 모든 본인 음의end를 지나 시간gate1, 관련목표0이므로 접촉/근접veto도0이다. 대기 보상이 활성화되는 구간인데도 마지막32.8167초에 실제MCP−39.31/PIP4.12/DIP3.08도로 펴져 있다. gate 누락만으로 설명할 수 없다.
- 검지:5초에서 실제MCP−5.88/PIP0/DIP90도, 마지막MCP20.98/PIP0/DIP90도다. 둘째 관절은 펴지고 끝관절은 한계까지 굽힌 패턴이다. 원래motion 진단에서PIP 행동 음수95.18%, DIP 행동 양수100%이며 명령 한계 밖으로 향한 비율도 각각87.25%,90.86%다. 이 비율은 명령 목표 기준이며 실제 접촉력 판정은 아니다.
- 소지:실제MCP는 약90도에 머무르고, 마지막PIP0/DIP−5도다. 손가락 전체의 자연스러운 신전과는 다른 관절 편중이다.

대기 보상은 제거되거나 완전히 꺼진 것이 아니다. 실제 한 곡 총보상은0.0345636, 추종은28.4125다. 손가락별 대기gate 가중 시간은 검지9.13/중지8.34/약지11.11/소지19.64초이며, 보상 가능 구간 평균B품질은0.135/0.762/0.382/0.101이다. 검지와 소지는 보상이 가능한 때에도 B와 거리가 멀다. 이는 원래240Hz 기록이며60Hz 자세에서gate를 추정한 값이 아니다.

현 구현의 해석: 손가락은목표_next=목표_previous+행동×4/60을native한계로제한하며행동0은현목표유지다. B로 자동 복귀하는 제어는 없다. 지속적인작은정책명령도누적되어한계에도달한다. B는한손가락최대0.0025/s의양성권고이며모든양성항의합을학습하므로대기자세를지킬보장은없다. 압현 중 B/관절분담을 강제하지 않도록 coordination항도0이다. 정책은이자유도에서비자연스러운관절배치를사용하고있다.

따라서 직접 원인은 정책의 지속적인 신전/한계 방향 명령이며, 개선되지 않은 학습 문제는 약한 대기 복귀 신호와 관절 분담이다. 각 보상항의 상대적인 원인 기여도를 분리 비교 학습 없이 확정하지 않는다. 움직임 비용을 다시 넣어 해결됐다고 주장하거나, 손가락이 자유롭게 움직일 수 없다는 결론으로 확대하지 않는다.

검토 방향은 손가락 움직임 비용0을 유지하면서 압현과 무관한 대기 구간의 B복귀 신호·과신전 신호를 재설계하고, 압현 구간은 실제각도/목표/음 달성으로 별도 진단하는 것이다. 이번 요청에서는 분석만 수행했다.
