## 현재 적용된 구조

처음부터 같은 67음 전곡을 실행한다. 단계는 곡을 교체하거나 손가락을 잠그지 않고 보상 가중치만 바꾼다. 단계 0에서도 접촉·유지·달성 보상이 작동한다.

최종 reward는 **13개 합산슬롯(기본coordination0·선택shape 포함)**이며 safety cost는 별도 신호다. 로그의 component 키는 공용 오른손 항 5개가 0으로 포함되어 18개다. 손가락 LH21에는 엄지를 포함해 행동 변화 비용이 없고, 추종 보상에도 실제 속도·요청 행동에 따른 감쇠가 없다. 기본관절분담은0(명시shape비교군만≤.004/초)이고B대기권고는본인의 임박한 준비창 또는 시간상 관련 목표의 접촉/근접에서 그 손가락만 꺼진다. 물리안전은유지한다.

접근 potential과 추종 보상은 같은 손가락별 현재 목표 선택기·finger3 패드 거리를 사용한다. PBRS에는 법선/하중 gate가 없고 추종만2cm 이내의 약한 법선 품질을 곱한다. 검지·중지·약지·소지마다 최대 한 음을 선택한다. PPO는 reward/cost advantage를 각각 정규화하고 결합한 뒤 다시 정규화하며 GAE λ는 0.98이다.

~~~text
악보와 현재 시각 → 손가락별 추종 목표 선택
  ↓
정책 60Hz → 관절 누적 목표 → 실제 물리 240Hz × 4
  ├─ 손가락 표면과 몸체 하중으로 candidate/wrong 계산
  ├─ 접근·접촉·audible clean 시간과 일회성 달성 기록
  ├─ 추종·자세·손목 보상 및 안전 cost 적분
  ↓
60Hz 경계 → potential 차이·실패 억제·단계 가중치 → reward와 cost
  ↓
H32 수집 → 개별 정규화 PPO → commit → 완료곡 기반 단계 갱신
~~~
