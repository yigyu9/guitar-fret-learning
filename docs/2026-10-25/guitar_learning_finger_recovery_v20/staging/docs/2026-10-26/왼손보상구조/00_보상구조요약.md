**2026-10-25 현행: GPU 왼손 보상 v20·B 대기 복귀 개선(A 기본).** B±15° 평탄대역 밖 품질을 `1/(1+Σ(excess/30°)²)`로 바꾸고, 고정4분모·손 전체 최대0.02/초(손가락당0.005/초)를 사용한다. `--finger-standby-rate 0.04`는 별도 비교 옵션이며, `--finger-shape`를 명시한 비교군만 추종 중 DIP−PIP 50° 초과를 완만하게 낮추는 전체 최대0.004/초 선호(B)를 추가한다. 기본 B분담항은0이며 자동 복귀 제어 C는 미구현이다. 실제 B gate 4열을 `standby_gate`로 관측하며 상태544·손가락별 직접입력20·토큰24열·우선8·단계3331은 유지한다. v19 이하 저장본은 거부하고 계수·옵션까지 같은 v20 전체 계약만 strict resume한다. v19 최초접촉 분할·clean/성공·LH21 움직임 비용0·PD/힘·누적제어·자유 기타·035/v14·PPO를 유지한다. **검증 진행 중이며 효과는 미확인**이다. ## 한 음의 흐름

목표 확인 → 표면 접근 → 준비 접촉 → onset 이후 clean 유지 → 연속 달성 → 다음 목표로 전환한다. 준비 창은 press−2초, 접촉 진단 누적과 연속 streak는 press부터, audible clean은 onset부터다. 달성은 onset~end의연속clean `min(음 길이,max(50ms,40%×음 길이))`이며끊기면streak는0이다. clean/held진단과유지보상은누적이다. 40%는학습용중간달성이며음끝까지완전유지조건이아니다. 달성 뒤 오압현이나 누락이 생겨도 달성 플래그는 취소되지 않는다.

## PPO와 최근 확인된 한계

물리 240Hz·정책 60Hz·H32를 사용한다. reward/cost advantage를 각각 정규화한 뒤 결합하고 다시 정규화한다. GAE λ=0.98, reward γ=0.99, cost γ=1이다. 손가락 범위·독립 누적제어·PD·안전 기준은 유지한다.

이전 v8의 최고 1,500회 모델의 평균 달성은 7.83/67음이지만 안전 완료곡의 목표 발음 시간 중 오압현 판정 비율은 60.36%다. 엄지 뒷면 근접도 사전 지정 8환경의 10초 이후 표본에서 3mm 이내 1.71%, 최종 모델은 0%였다. 오압현은 하중+기하 proxy이고 엄지 수치는 유한 표면 샘플의 거리이므로 압력·음향이나 전체 환경 접촉률로 확대하지 않는다.
