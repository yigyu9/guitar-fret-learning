# 중지 6→8프렛 탐색·학습률 비교

손가락 초기 탐색0.35는 공통으로 유지한다. 팔 초기 탐색0.15/0.20과 학습률 기존/복구 정책을 조합한 네 조건을 각각 새로400회 학습한다. 같은100·200·400회 평가를 비교하고, 대표 영상용 최선 모델은 따로 표시한다.

학습률 복구 조건은 매 반복 시작에서 최소1.5e-5로 복구한다. KL 재시도 중에는 더 낮은 값을 허용하며 과도한 정책 변경을 통과시키지 않는다. 보상·압현 시간표·초기 자세·물리·종료 조건은 같다.

- [실험 설계와 체크리스트](실험계획.md)
- [실행 상태](진행상황.json): 현재 작업, 시작 시각, 오류와 출력 경로
- [결과와 대표 영상](결과.md): 조건별 동일400회 평가와 최선 영상
- `분석/`: 실제 학습률·탐색·학습 중 성공과 평균 정책 결과의 비교표 및 그림
- `동영상/`: 조건별 손 확대·전신 대표 영상만 저장
- `실행/`: 체크포인트·원시 학습·평가·렌더 로그
- `검증/`: 입력·CPU·독립 검수·GPU 연결·실제 native 재생·SHA 봉인

이전 실행 속도를 기준으로 준비를 포함한 예상 종료는 2026년11월3일 오후1시~1시30분(KST)이다. GPU 경합이나 안전 중단이 발생하면 실제 상태에 기록한다. 네 조건은 seed7의 조건부 비교이며 여러 학습 시드에 대한 일반적 우위 검증은 아니다.
