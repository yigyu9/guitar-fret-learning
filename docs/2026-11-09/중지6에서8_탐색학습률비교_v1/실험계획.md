# 중지 6→8프렛: 탐색과 학습률 비교

사용자 승인: 손가락 초기 탐색0.35를 유지하며 팔 탐색 확대, 학습률 감소 완화, 두 조합을 비교한다. 기존 구현과 야간 원문은 보존하고 새 연구 폴더에서만 구현·학습한다.

## 고정 조건

같은 A0 입력: 중지3번줄6프렛3~4.5초 → 8프렛5.5~7초. 같은 준비 snapshot,1초 휴지,613관측,9보상,직접 목표각,물리·PD·속도·종료·KL 제한을 유지한다. large/64환경/H32/K1/seed7,각 fresh400업데이트,100/200/400회 평균정책16환경 평가. 손가락0.35는 초기 latent std이며 trainable이다. 활성팔12축은 왼흉곽·어깨·팔꿈치·손목 각3축이다.

학습률 복구는 KL 재시도 중 하한을 강제하는 방식이 아니다. update 시작 시만 max(current,1.5e-5)로 복구하고, 같은 update 안에서는 기존 KL rollback·일시 감소·재시도 상한을 그대로 적용한다. 실제 수용 LR은 일시적으로1.5e-5 아래가 될 수 있으며 시작 LR/수용 LR/복구 여부를 구분해 기록한다. 과도한 KL을 허용하거나 실패를 성공으로 숨기지 않는다.

새 schema와 설정 identity를 사용한다. 모드/탐색을 바꿔 기존 저장본을 강제 재개하지 않는다. 각 조건은 같은 seed로 새 모델을 만들고 동일한400회까지 비교한다. 소형 GPU 학습·엄격 재개·평가·렌더와 같은 A0 native 참조의 새 물리 재생을 먼저 확인한다.
