# root 고정 해제 안정성 진단

현재 준비 자세·자유 기타·의자·중력·기존 관절 제어를 유지하고 인체 root의 고정 여부를 비교한다. 학습 정책을 사용하지 않는 짧은 교란 실험이다. 생산 소스·자산·체크포인트는 수정하지 않는다.

- [x] 고정/해제 각각 정지·오른팔 흔들기·왼팔 흔들기, 총6조건을12초씩 실행.
- [x] 팔꿈치와 손목에만 동일한 매끄러운1Hz 목표각 입력. 손가락은 초기 목표 유지.
- [x] floating Jacobian의 root6열을 제외한 joint105열만 기존 제어기에 전달. 발 FK는 현재 pelvis 변환을 반영. root 외력·상태 고정 없음.
- [x] 최초 장면 생성 이후 중간 reset 없이 전신 영상·native 궤적 저장.
- [x] pelvis 이동·기울기·높이, 머리 높이, 기타 이동, 관절 속도와 제어 유한성 비교.
- [x] 독립 검수, 영상 프레임 검증과 결과 보고.6조건 모두720제어tick·360영상frame,입력변경0.

이 검사는 root 해제 직후의 가능성만 확인한다. 장시간 연주·새로운 접촉·전신 균형 학습의 성공을 보장하지 않는다. 진행 중인 학습은 유지하며 진단은1환경씩 실행한다.
