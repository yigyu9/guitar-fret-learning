# root 해제와 팔 동작의 단기 안정성 검사

후속 재실험(`../root고정해제_초기겹침보정_v2/결과.md`)에서 초기 root 명시 복원과 의자8mm하강만으로 즉각적인 큰 튐이 재현되지 않았다. 따라서 본 초기 진단을 root 해제 자체의 실패로 일반화하면 안 된다. 원문 기록은 당시 초기화 조건의 결과로 보존한다.

후속 접촉 분리 검사에서는 관절 구동과 중력을 꺼도 큰 초기 충격이 남았고, 의자를 치우면 골반 접촉력이 크게 줄었다. 원본 형상에서 골반-의자 약6.1mm 겹침도 확인했다. 초기 접촉 충격이 유력한 원인이며 상세 근거와 한계는 `초기접촉_추가분석.md`에 정리했다. root 해제가 본질적으로 불가능하다고 해석하면 안 된다.

## 첫 프레임의 발 들림 추가 확인

영상은 t=0이 아니라 물리8step 뒤인0.0333초부터 시작한다. 사용자가 지적한 대로 해제 영상 첫 프레임에서는 이미 양발이 들려 있다. 저장된 native 몸체 자세와 원본 발 충돌 상자의 밑면 꼭짓점으로 높이를 계산하면, 왼발 최저점27.46cm·오른발21.11cm다. 반면 준비 snapshot과 고정 조건 첫 프레임은 양발 밑면이 지면 약0cm다. 원시 계산은 `기록/발바닥높이_추가검사.json`에 저장했다.

따라서 이 영상만으로 처음부터 정상적인 정적 접촉 상태였다고 주장하면 안 된다. 준비 snapshot에서는 발이 지면에 있지만, 해제 장면의 최초 실제 물리상태와 첫1~8step의 변화는 별도로 확인해야 한다. 초기 상태 불일치·접촉 충격·제어 반응을 분리하기 전에는 이를 일반적인 균형 제어 실패로 단정하지 않는다. source 형상 밑면 높이는 native 접촉력 측정을 대신하지 않는다.

현재 준비 상태와 지지 제어를 그대로 사용해 root 고정만 해제하는 것은 이 진단에서 실패했다. 정지 상태에서도 0.05초에 root 이동18.91cm·기울기36.87도가 나타났다. 최대 기울기는0.217초, 최대 이동은1.067초에 발생했다. 팔 입력 시작은2초이므로, 이번 결과로 팔 흔들기의 독립적인 영향을 판단할 수 없다.

해제 조건들의 초기2초 root 궤적은 동일했다. 따라서 팔 동작보다 앞선 초기 상태·접촉·지지 제어를 먼저 점검해야 한다. 실제 native 초기 root13성분과 초기 body 상태 전체를 별도로 보존하지 않아, 준비 snapshot과 native 초기 상태의 정합성 및 초기 접촉 충격은 원인 후보로 남긴다. 원인을 일반적인 균형 부족이나 특정 제어 버그로 단정하지 않는다.
