# 초기 겹침과 접촉 충격 분리 검사

root 해제 직후 날아가는 현상을 일반적인 균형 실패로 설명하기 전에 초기 접촉 충격을 검사했다. 기존 학습·자산은 수정하지 않았다. v1 기록은 보존했고, v2에서는 의자·기타의 실제 분리 위치와 CUDA 동기화를 추가 검증했다.

모든 조건에서 인체 root를 해제하고 모든 관절의 driveMode=NONE, stiffness=damping=0, 입력 effort=0으로 했다. 초기 관절 속도는 준비 상태를 유지했다. 각 조건을240Hz로60step,0.25초 실행했다. 이는 안정성·연주 학습 실험이 아닌 접촉 원인 분리 검사다.

| 조건 | 최대 인체 몸체 순접촉력 | root 최대 이동 | 최대 root 속도 |
|---|---:|---:|---:|
| 기존 물체 배치, 관절 구동 해제 |44,780N|0.947m|6.39m/s|
| 의자만 아래로 이동 |21,177N|0.125m|1.52m/s|
| 의자·기타 모두 아래로 이동 |1,781N|0.141m|1.70m/s|
| 기존 배치, 중력까지 해제 |44,819N|1.169m|7.22m/s|

기록된 첫 물리step(0.00417초)에서 골반 순접촉력은 기존 배치44,780N, 의자 분리35.84N이다. 의자·기타를 모두 분리하면 첫step 인체 순접촉력은0N이며, 위 표의1,781N은 이후0.229초 발 접촉에서 발생했다. 의자만 분리한 조건에서는 R_Hip·LH:palm·L_Wrist 쪽에 큰 초기 힘이 남는다.

독립 검수에서 시작 시점의 native root도 추가로 대조했다. 명시적 측정 루프에 들어오기 전부터 full 조건 root 선속도는 약2.72m/s, 의자 분리 조건은 약0.973m/s였고 높이도 각각0.5487m·0.5993m로 달랐다. 따라서 이 측정은 동일한 정지 상태에서 최초 충격을 관측한 순수 비교가 아니다. 초기화 단계의 영향이 섞여 있으므로 접촉쌍·침투 깊이 및 초기화 정합성을 확정하지 않는다.

준비 snapshot과 원본 충돌 상자를 대조하면 골반 box의 밑면은 z=0.44990m이고 의자 윗면은 z=0.45600m다. 이 배치에서는 골반과 의자 상자가 수직으로 약6.10mm 겹친다. 원본 두 상자는 해당 자세에서 축이 정렬되어 있으며 XY 범위도 겹친다. 이것은 원본 형상 계산이며 native 접촉쌍·실제 침투 깊이의 직접 측정은 아니다.

관측 결과는 능동 관절 구동이나 중력만으로는 초기 튐을 설명할 수 없고, 의자 주변 초기 접촉이 큰 충격에 기여한다는 해석을 지지한다. 골반-의자 초기 겹침에 따른 밀어내기가 유력한 원인이다. 기타 주변의 초기 접촉도 추가 후보다. native 몸체 초기 버퍼의 FK 정합성과 실제 접촉쌍은 별도 확인해야 하므로, 특정 접촉 하나가 모든 현상의 원인이라고 확정하지 않는다.

다음 실험은 실제 human root13과 DOF 상태를 동일한 초기 경계에서 명시적으로 정렬하고 정지 상태를 검증해야 한다. 그 후 의자를 단순 제거하는 대신 초기 겹침을 완화하면서 정상적인 착석 지지를 유지하고, 작은 접촉력으로 정착하는지를 확인해야 한다. 이후 팔 흔들기를 재검사한다. root 해제가 원천적으로 불가능하다는 결론은 현재 결과로 뒷받침되지 않는다.
