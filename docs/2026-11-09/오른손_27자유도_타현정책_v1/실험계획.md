# 오른손 전체 손가락을 포함하는 타현 정책

기존 타현 팔꿈치·손목 6축에 오른손 손가락 21축을 더해 27축을 학습한다. 진행 중인 왼손 연구의 봉인 소스는 수정하지 않고 별도 right27 실행 경로를 제공한다. 기존 타현 목표·접촉 판정·보상은 유지한다.

- [x] 자산·native 관절 목록 대조: 등록105축, 가동97축, 영범위8축.
- [x] 별도 제어기·환경·GPU 풀 구현: RH21 POSITION 목표각 직접 제어, 4rad/s 제한.
- [x] 27축 정책과 새 실행 진입점 연결, 기존 체크포인트와 identity 분리.
- [x] CPU 정책·관절 범위·초기화·PPO 저장/재개 검사: 관련17개 통과.
- [x] 실제 GPU 관절 명령과 물리 응답 검사:21축 전부 응답, 학습·재개 각각1업데이트 통과. 기존 왼손 연구와 동시에 실행하지 않았다.
- [x] 별도 검수 및 사용법·검증 결과 기록. 입력 봉인 보완 후 검수 차단사항 없음.

39칸 수집 컨테이너 중 앞12칸은 비활성, 다음21칸은 오른손 손가락, 마지막6칸은 오른쪽 팔꿈치·손목이다. 정책 우도와 엔트로피는 실제27축만 계산한다. 기존39축 모델의 슬롯을 재해석하지 않는다.

인체 자유도: 양다리24중16가동, 몸통·목·머리15, 양팔24, 양손42. 합계105중97가동이다. 현재 root는 고정이고 기타의 자유 강체6축은 인체 관절 수에 포함하지 않는다.
