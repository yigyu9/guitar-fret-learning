# 변경 결과

타현 정책의 제어 범위를 기존 오른쪽 팔꿈치·손목6축에서 오른손 전체 손가락21축을 포함한27축으로 확장했다. 엄지5축, 검지·중지·약지·소지 각4축이 모두 정책에서 독립적으로 움직일 수 있다. 오른손 손가락은 준비 기준각 중심의 직접 목표각 제어이며4rad/s 제한과 기존 native POSITION 모드를 유지한다.

기존 왼손 장기 연구의 소스 봉인을 보존하기 위해 별도 진입점을 만들었다. 기존 `train_legacy --hand right`와 다른 연구의 `right_strike` 명령은6축 경로다. 새27축 학습은 다음 명령을 사용한다.

```bash
python scripts/tab2body.py run -m guitar_learning.tool.experiments.right27 train \
  --size large --num-envs 1024 --horizon 32 --updates 100 \
  --out runs/right27_01
```

위1024환경은 실행 예시이며 이번 타현 검증에서 처리량·최적 환경 수를 측정한 것은 아니다. 검증은4환경·small 모델로 수행했다. 전체 사용법과 파일 역할은 [구현 안내](/home/ajou/yigyu/3/guitar_learning/tool/experiments/right27/README.md)를 따른다.

## 검증

- CPU17개 검사 통과: 기존 타현 환경12개와 새 정책·제어기5개. 관절 한계·4rad/s·행별 reset·비활성12칸·활성27칸 확률·PPO 업데이트·엄격한 모델 identity 거부를 확인했다.
- `GPU관절검사`:4환경·60tick,21축 모두 목표각 및 실제각 변화. 실제각 변화폭은0.131~0.437rad, 최대 목표각 변화는0.06666673rad/tick 이하다. 최초 버전의 입력 봉인은 Python 소스만 포함했다.
- `GPU관절검사_입력봉인보완`: 검수 의견을 반영해 공용 학습기와 같은 준비 상태·자산·곡·소스 입력 봉인을 적용한 최종 재검사다. 최종 유효 여부는 이 디렉토리의 `report.json`을 따른다.
- 최종 재검사는 `completed=true`,479개 입력 SHA(Python 외147개), 변경 입력0·미봉인 import0이다. 독립 검수자가479개 SHA를 다시 확인했으며 차단사항은 없다.
- `GPU학습연결검사`:4환경/H8/1업데이트, 실제 GPU 수집32전이·PPO 갱신·initial/final 체크포인트 저장 완료. 소스 변화·미봉인 import·정리 오류 모두 없다.
- `GPU재개연결검사`: 위 모델을 복원해1업데이트 추가, 저장·재개 연결 정상. 구형 left/right6 모델과 잘못된 슬롯 배치는 새 정책 identity 검증에서 거부한다.

GPU학습·재개 검사는 입력 봉인 보완 전 probe 소스를 포함한 당시 소스 기준이며 학습 동작 검증 기록이다. 기존 기록과 봉인 파일은 수정하지 않았다. 관절 검사와 짧은 학습 연결 성공은 연주 성능·수렴 검증이 아니다.

타현 목표24열·피크 교차 판정·보상은 유지했다. 오른손 손가락이 행동 변화 비용에도 참여하며 기존 계수는 그대로다. 현재 피크는 검지의 고정 자식이므로 검지와 함께 움직인다. 다른 손끝으로 직접 줄을 튕기는 성공 판정이나 동적인 피크 파지는 이번 변경에 포함하지 않았다.
