# 중지의 줄·프렛 전환 장기 학습

사용자 요청에 따라 같은 중지로 3번 줄 5프렛에서 4번 줄 8프렛으로 전환한다. 손가락 지정은 기존 중지 연구를 이어가는 것으로 해석했다. 기존 목표 전환과 비교할 수 있도록 보상·제어·물리·판정·악보 시간은 유지하고, 목표와 학습 규모를 바꾼다. 현재 승인된 실행 작업이며 추가 승인 대기 없이 준비·검증·실행한다.

## 과제와 설정

- A: 중지, 3번 줄 5프렛, 3.0~4.5초.
- B: 중지, 4번 줄 8프렛, 5.5~7.0초. 전환 간격 1초, 전체 7.5초.
- 두 단음의 기존 실제 도착 기록을 검증해 A 준비 상태에서 시작한다. B 정답 자세는 실제 물리 참조 검사용으로 분리하며 학습 정책에 주입하지 않는다.
- large, H32, seed7, 손가락 초기 std0.35, 팔 초기 std0.15, 정책 학습률 시작3e-5와 반복 시작 하한1.5e-5 복구를 사용한다.
- 정책·입력 schema를 새로 만들어 fresh 학습한다. 이전 모델을 새 목표에 강제로 이식하지 않는다.
- 기준은 원장 달성 외에도 음 전체 clean 시간, 오압현 union, 시작·해제 시각, 물리·손목 실패를 포함한다.

## 환경 수와 학습량 결정

1. 기존 실패 원문을 보존하고 새 입력·참조·학습기를 만든다. 후속 연구의 FileExistsError는 새 복사에서 원인을 수정하고 CPU 회귀 검사를 한다.
2. GPU 연결 검사와 두 목표 실제 물리 재생을 수행한다. 중간 q/state 덮어쓰기, 힘 보조, 압현 기준 완화는 하지 않는다.
3. 256/512/1024환경에서 동일 large/H32의 짧은 실제 학습을 순차 실행해 수집+갱신 속도, GPU 여유, 실패·비유한·물리 경고·저장/정리 상태를 비교한다. 작은 검증 이후 1024가 안전하고 가장 효율적이면 우선 사용한다. 여유 부족이나 실효 속도 저하가 있으면 낮춘다.
4. 측정된 속도로 약 4시간의 실제 학습 예산을 채울 총 업데이트를 사전 확정한다. 총 샘플 수와 이전64환경400회 대비 규모를 함께 기록한다. 환경 수 증가만으로 수렴 속도가 보장된다고 해석하지 않는다.
5. 새 정책으로 장기 학습하고 엄격 재개 가능한 구간 경계에서 중간 평균 정책 평가를 수행한다. 모델·Adam·RNG·원래 노출 계약을 보존하며, 재개 시 물리 에피소드는 공식 준비 상태로 새로 시작한다는 범위를 명시한다.
6. 중간/최종 모델의 평균 정책 평가와 동일 체크포인트 확률 평가를 분리해 수행한다. 최선 모델과 최종 모델을 구분하고 대표 손 확대·전신 영상만 저장한다.

## 실행 안정성과 저장

새 학습 소스·입력·실행 계약을 독립 검수 후 SHA로 봉인한다. 부모 터미널에 의존하지 않는 분리된 프로세스로 실행하고, 원자 상태 저장·중복 실행 잠금·제한된 재시도·작업별 원문 보존을 적용한다. 학습 원문·checkpoint가 손상되면 검증을 우회하지 않는다. 단기 GPU 연결과 장기 학습 성능은 구분한다.

디렉토리는 `도구/`, `입력/`, `검증/`, `실행/`, `분석/`, `동영상/`으로 나눈다. `동영상/`에는 MP4만 두고 제작 근거·로그는 다른 디렉토리에 저장한다.
