# 중지 3번 줄 5프렛 → 4번 줄 8프렛

같은 중지로 줄과 프렛을 함께 바꾸는 전환을 충분한 샘플로 학습한다. 기존 보상·제어·물리·판정은 유지하며 새 목표의 실제 준비 상태에서 새 정책으로 시작한다. 이전 과제 모델을 강제로 이식하지 않는다.

A는 3~4.5초, B는 5.5~7초이고 전환 간격은 1초다. 손가락 초기 탐색은 0.35, 팔은 0.15이며 정책 학습률은 초기 3e-5, 반복 시작 복구 하한 1.5e-5다. large/H32/seed7을 사용한다.

GPU 실제 연결과 참조 전환을 확인한 뒤 256·512·1024환경의 처리량과 GPU 여유를 비교한다. 안전한 범위에서 빠른 설정을 선택해 약 4시간의 학습량을 정한다. 4시간은 학습 목표 예산이며 준비·벤치·평가·영상 시간은 별도다. 시작한 학습 구간은 정상 저장 후 평가하도록 하고 전체 작업에는 별도 안전 제한을 둔다.

- `진행상황.json`: 현재 작업, 환경 수, 학습 계획, 누적 업데이트, 예상 종료, 평가 결과.
- `분석/분석.md`: 학습 중 관측과 동일 모델의 평균·확률 평가를 구분한 요약.
- `분석/결과수치.json`: 원시 대조 수치와 읽은 로그의 SHA.
- `동영상/`: 선택 모델과 필요시 최종 모델의 손 확대·전신 MP4.
- `실행/`: 학습·평가·영상·벤치 원문과 작업 로그.
- `검증/`: CPU 검사, 독립 검수, 코드·입력 봉인, 실제 물리 참조 기록.

원장 달성은 각 1.5초 음에서 연속 0.6초가 기준이다. 음 전체 유지·시작/해제 시각·오압현과 별도로 본다. 학습 중 확률 동작의 성공을 평균 정책 성공으로 대신하지 않으며, 최종 모델은 평균16환경과 확률64환경을 같은 체크포인트로 평가한다.

이전 후속 실험의 snapshot 중복 저장 오류는 새 학습기에서 시각별 고유 파일과 최종 manifest 한 번 저장으로 수정했다. 과거 소스·실패 원문·봉인은 보존한다.
