# 비교 실험 이후의 동시 압현 연구

현재 진행 중인 중지 6→8프렛 탐색·학습률 비교가 완전히 종료된 뒤 시작한다. 현재 비교의 코드나 실행은 변경하지 않는다. 사용자가 승인한 약 4시간의 후속 작업 마감은 2026-11-03 14:08(KST)이며, 새 학습은 13:40 이후 시작하지 않는다.

후속 대상은 중지 3번 줄 6프렛과 약지 2번 줄 7프렛의 동시 압현이다. 기존에는 약지의 옆 줄 접촉 후보가 중지의 올바른 압현을 차단했다. 새 참조 자세는 이 간섭을 피할 수 있는지 검사하며, 실제 물리 재생을 통과한 뒤에만 새 정책을 학습한다. 참조 동작을 정책에 주입하는 실험은 아니다.

- 진행 상태: `진행상황.json`
- 간단한 결과: `결과.md`
- 평가·학습 관측과 한계: `분석/분석.md`, `분석/결과수치.json`
- 실패 원인과 후보 자세: `분석/사전진단.md`, `검증/참조/참조선택.json`
- 대표 손 확대·전신 영상: `동영상/` 아래 MP4
- 실행 원문과 로그: `실행/`
- 실행 전 CPU 검사, 독립 검수, 입력·코드 SHA: `검증/`

현재 비교는 네 조건의 같은 400회 평가로 설정을 선택한다. 유의미한 우위가 없으면 팔 탐색 0.15와 기존 학습률을 유지한다. 시간이 충분하고 같은 200회 평가에서도 유망한 조건이면 추가 seed 확인을 먼저 진행할 수 있다. 후속 동시 압현은 남은 예산에 따라 100회 또는 200회를 수행한다. 물리 재생 실패·학습 성능 미달·시간 부족은 구분해 기록한다.

자동 실행은 `도구/run_study.py`, 읽기 전용 요약은 `도구/analyze.py`가 담당한다. 기존 체크포인트를 새 학습기로 이식하거나 SHA 검증을 우회하지 않는다.
