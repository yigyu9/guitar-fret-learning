# 동시 압현 후속 실험 사전진단

검증된 주원인은 약지 끝마디 ring3의 인접 S3F7 접촉 판정이다. 중지의 S3F6을 더 높은 프렛에서 막고 있다. 보상·제어·오압현 판정·하중 기준을 바꾸지 않고 grip 자세만 비교한다.

| 실제 native 기록 | 첫 C1 | 이후 N01 |
|---|---:|---:|
| 중지 clean | 0초 | 0초 |
| 약지 clean | 1.29583초 | 1.5초 |
| 중지 담당 말단 하중 | 0초 | 1.5초 |
| 중지 geometry / facing | 1.4875초 | 1.5초 |
| 중지 other_higher | 1.30417초 | 1.5초 |

이후 N01에서는 중지 하중도 확보됐으므로 현재 실패를 하중 부족으로 단정하면 안 된다. 원시 wrong 원장은 ring3, S3, F7, other_higher만 양성이다. 담당 패드 표본 145/273이 실제 방해 표본이라는 뜻은 아니다.

3.5초 native의 중지/약지 선택 패드 높이는 각각 약 +2.800/+2.336mm, 방향 cosine은 0.900/0.918이다. 이상 FK가 목표로 둔 약 -0.5mm와 약 3mm 차이가 보인다. 전신 q와 기타 body 원문이 없어 같은 표본·같은 자세의 오차로 확정할 수는 없다. 손가락 요청/적용 차이, 실제각 추종 통계는 JSON에 별도로 보존했다.

## 바꾸는 한 변수

G0는 이전 N01의 요청각·시각 exact 복사 대조다. G1은 깊이 -1mm/인접줄 회피 여유1.5mm, G2는 깊이 -2mm/여유3.5mm를 목표로 새 grip을 탐색한다. 팔12축과 두 담당 손가락8축만 허용하며 비담당 검지/소지 각은 초기 그대로다. 양쪽 담당 패드·전체 virtual 오압현·손가락 source 교차·비담당 넥 source 교차·실제 관절한계와 quintic 속도를 검사한다. 원래 발음3~4.5초, 준비0.5~2.5초, 해제4.5초 이후를 유지한다. A0는 이전 T1 요청 경로 그대로 복사해 seed17 재현용 입력만 준비한다.

+0/+1.5/+3mm 평행이동 검사는 높이 민감도 검사다. native 팔/기타 움직임의 복원이나 부하 인증이 아니다. 넥과 담당 끝마디의 source 교차는 접촉 후보로 기록하고, 비담당 마디의 넥 교차 및 손가락 간 source 교차가 있는 후보는 선택하지 않는다. 경로 source 검사는 명시된 이산 시점이므로 연속 충돌 부재 증명이 아니다.

## 확정할 수 없는 것과 다음 확인

body netforce는 접촉 상대나 실제 줄 압력을 구분하지 못한다. 하중 있는 몸체의 전체 표면에 가상 줄 접촉을 적용하는 보수적인 현재 판정은 그대로 유지한다. 이전 raw 전신 q/body 부재 때문에 약 3mm 차이 원인을 추정으로 단정하지 않는다.

새 native 재생에서 0/2.5/3/3.5/4.4초 실제 q105·qd105·body·contact force·요청각·적용각·목표별 geometry/load/facing/wrong source를 저장한다. G1/G2 정적 통과는 native 성공이 아니다. 새 재생에서 두 음 clean·잘못된 접촉·유지/해제·안정성까지 통과해야 후속 학습을 허용한다.

입력 exact 비교와 변조 거부는 검증/입력CPU검증.json, 후보별 실패/성공 CPU 수치는 검증/참조에 있다. 원문·기존 모델·기존 실행 자료는 수정하지 않았다.
