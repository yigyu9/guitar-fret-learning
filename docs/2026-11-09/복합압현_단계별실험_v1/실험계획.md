# 탐색 0.35 기준 복합 압현 실험 계획

작성: 2026-11-02 KST. 사용자가 선택한 0.35를 앞으로의 비교 기준으로 사용한다. 이 문서는 설계이며, 새 학습이나 활성 코드의 기본값 변경은 아직 실행하지 않았다.

## 1. 출발 근거와 이번 목표

최근 비교에서 정렬 출발·팔 유한 유지·중지 담당4축·601관측 조건은 초기 탐색0.35/0.4/0.45 모두 50·100회 평균 정책16환경에서 목표 음1.5초 전체를 유지했다. 학습 중 누적 오압현은 각각34.146/51.915/61.765초였다. 따라서 추가 실험은0.35를 기준으로 한다. 한 목표·한 시드의 동일 초기 입력 재현 결과이며 전환이나 J33 성공의 증명은 아니다.

이전613관측 J33 공통 초기 자세 실험은 단일 대조군까지 압현0이었다. 이 상태에서 복잡한 목표만 추가하면 준비 실패와 전환 실패를 구분할 수 없다. 먼저 성공 조건에서 팔 이동을 허용하는 연결 실험을 통과시킨다.

최종 질문은 다음과 같다.

1. 팔 이동을 허용해도 손가락으로 압현할 수 있는가?
2. 한 손가락이 다른 프렛과 다른 줄로 이동해 다시 누를 수 있는가?
3. 손가락을 교대할 때 기존 손가락은 해제하고 다음 손가락은 제때 누르는가?
4. 한 손가락이 누르는 동안 다른 손가락이 준비·진입·해제할 수 있는가?
5. 두 음을 동시에 유지한 뒤 다음 조합으로 전환할 수 있는가?

## 2. 고정할 조건과 분리할 변수

- 모델 large,64환경,H32,K1,정책60Hz/물리240Hz,seed7부터 시작한다. 100업데이트=204800전이다. 환경 수는 먼저 고정하여 노출량과 학습 효과를 혼동하지 않는다.
- 각 과제에서 사용되는 검지~소지 관절의 초기 latent std는0.35다. 이것은 각도 단위·최소 탐색값이 아니며 손가락 std 하한exp(-3)는 유지한다. 팔의 하한은 현행 core의exp(-5)를 유지하고 초기값만exp(-3)이다.
- 팔12축의 초기 탐색은기존 exp(-3)를 유지한다. 엄지까지0.35로 올리거나 모든 J33축에0.35를 일괄 적용하지 않는다. 정확한 축 번호·초기 실효std·mask를 실행 전 원장에 기록한다.
- 직접 목표각, 전체 관절 범위,4rad/s,PD/힘 상한,9보상,손가락 움직임 비용0,물리·손목 종료 기준을 유지한다. 학습률 규칙도 바꾸지 않으며 실제 LR/entropy/KL/std를 기록한다.
- 기타를 직접 고정하거나 에피소드 중 상태를 덮어쓰지 않는다. reset은 경계에서만 한다. 기존 알려진 압현각은 물리 가능성 재생에만 쓰고 정책 정답 행동으로 주입하지 않는다.
- 과제는1~14프렛 내에서 고른다. 최초 비교는 기존 단일 압현 근거가 있는6~8프렛을 사용한다. 끝점 성공만으로 이동 경로나 동시 압현 가능성을 인정하지 않는다.
- 새 조건은 독립 새 정책으로 학습한다. 601 모델을613 모델에 강제 재개하거나 다른 mask·목표의 저장본을 strict resume하지 않는다. 동일 run의 연장은 같은 입력·identity·원래 노출 예산 계약을 유지한다.
- 기존 초기 구간25%→전곡 노출 규칙은 유지한다. 실제 전곡 노출과 목표별 활성 기회 수를 별도 기록하고 평가에서는 모든 목표를 포함한 전체 과제를 사용한다.

## 3. 구현을 먼저 확인할 연결 실험

현재 검증된 정렬 학습기는601관측·한 담당 손가락4축 전용이다. 아래613·팔/두 손가락 mask 실험은 별도 버전 도구 구현과 실행 검증이 필요하다. 기존 도구가 이미 지원한다고 가정하지 않는다.

| ID | 목표 | 정책 제어 | 검증하려는 차이 |
| --- | --- | --- | --- |
| 기준 | 중지·3번줄·6프렛 | 정렬 출발,601,담당4축,팔 유지 | 완료된0.35 결과를 참조하고 원문 보존 |
| B1 | 동일 | 동일 정렬 출발,613,담당4축,팔 유지 | 새 관측/어댑터에서도 성공이 유지되는지 |
| B2 | 동일 | B1과 같은 입력·관측,팔12+중지4축 | 팔을 정책에 맡긴 것의 영향 |

B1은 관측 인터페이스 연결 시험이므로601과613의 정책 구조까지 완전히 동일하다고 주장하지 않는다. B1→B2에서는 관측·초기상태·목표·보상·모델 규모를 고정하고 행동 mask와 그에 따른 likelihood만 바꾼다. 나머지 왼손 관절은 기존 유한 유지로 두고 오른손6축 잔차는0이다.

B2가 실패하면 아직 복잡한 목표로 확장하지 않는다. B1 대비 손목 범위 이탈,실제 손가락 각도 변화,접촉 전 팔/손가락 기여,rate 제한,목표 패드 거리,접촉/최초접촉 완료 여부를 비교한다. 추가 보상·강제 단계 전환은 이 비교에 섞지 않는다.

목표 손가락 집합은 과제 전체에서 고정한다. 아직 자기 음이 시작하지 않았다는 이유로 다음 손가락을 정책에서 숨기거나 행동을 강제로 잠그지 않는다. 대기·접근·압현은 손가락별 상태와 기존 보상에 따른다. 두 손가락 과제에서는 팔12+손가락8=20축,단일 손가락 과제에서는16축을 사용한다. 이 결과도 자유 J33과 구분한다.

## 4. 단계별 목표 목록

B1/B2 이후 다음 순서로 진행한다. 아래 순서는 기본 시드7의11개 학습 조건(B1/B2 포함)이다. 이전 단계에서 막히면 해당 분기만 멈추며, 그 실패를 긴 학습으로 숨기지 않는다.

| ID | 과제 | 목표와 순서 | 주요 판정 |
| --- | --- | --- | --- |
| S1 | 먼 프렛 단일 | 중지·3번줄·8프렛 | T1 끝점B의 독립 성공 |
| T1 | 같은 손가락 프렛 전환 | 중지·3번줄·6→8프렛 | 실제2프렛 이동,이전 접촉 해제,후속 음 유지 |
| S2 | 다른 줄 단일 | 중지·1번줄·8프렛 | T2 끝점B 독립 성공 |
| T2 | 같은 손가락 줄/프렛 전환 | 중지·3번줄·6→1번줄·8프렛 | 줄 횡단과프렛 이동의 추가 난이도 |
| S3 | 다른 손가락 단일 | 약지·2번줄·7프렛 | T3 끝점B 독립 성공 |
| T3 | 손가락 교대 | 중지·3번줄·6→약지·2번줄·7프렛 | 앞 손가락 해제와 다음 손가락 진입 |
| O1 | 시차 중첩 | 중지·3번줄·6 유지 중 약지·2번줄·7 진입 | 한 손가락 유지+다른 손가락 준비/압현/해제 |
| C1 | 동시 압현 | 중지·3번줄·6 + 약지·2번줄·7 | 두 음의 공통 clean 구간 |
| C2 | 동시 압현 후 단음 전환 | C1 조합→중지·3번줄·8 | 두 음 유지 후 약지 해제·중지 이동 |

S1/S2/S3은 각 목표의 실제 준비 도착 상태에서 시작하는 끝점 확인이다. 해당 끝점에서 성공해도 A에서 그곳으로 갈 수 있다는 뜻은 아니다. T1/T2/T3/O1/C1/C2는 공통 A 준비 상태 하나에서 시작하며 B가 시작될 때 reset하지 않는다.

조건부 대조 D1/D2를 별도로 예약한다. T3 또는 O1에서 실패하면 D1은 B2의 중지 단음1.5초에 약지4축도 정책에 개방한20축 조건으로, 제어 차원 증가 자체의 영향을 확인한다. O1 유지 실패에는 D2를 추가한다. D2는 O1과 같은20축 mask·관측·중지3~5.5초·총6초를 사용하고 약지 목표만 제거한다. D2가 실패하면 중첩 간섭으로 단정하지 않고 긴 단음 유지/추가 탐색축의 영향부터 D1과 비교한다. 둘 다 새 정책·동일 탐색0.35이며 단독 조건끼리 비교한다. 기본11조건에 포함하지 않는 최대2개의 조건부 진단이다.

C1의동시기하검사에서 같은 손목 자세로 두 목표에 도달하지 못하면 해당 조합을 물리/기하 부적합 후보로 기록하고 C1/C2를 학습하지 않는다. 새 조합으로 바꿀 경우 별도 ID와 원문을 보존한다. 엄지 지지 개선은 이번 독립 변수에 넣지 않지만 실제 위치·넥 후면 간격은 추적한다.

## 5. 목표 시각과 노출량

- 단일음: 준비0~3초,음3~4.5초,말미4.5~5초.
- T1/T2/T3/C2: 첫 이벤트3~4.5초,휴지4.5~5.5초,다음 이벤트5.5~7초,말미7~7.5초. C2의첫이벤트만2음 동시다.
- C1: 두 목표 모두3~4.5초,말미까지5초. 시작·끝 시각과 동시 목표 집합을 명시한다.
- O1: 중지3~5.5초,약지4~5초,말미까지6초. 중지의 전 구간 유지와 공통1초 유지,약지가 끝난5~5.5초의 중지 유지·약지 해제를 별도 판정한다.
- 첫 탐색에서는 휴지1초를 고정한다. 전환이 통과한 뒤에만 휴지0.5초,이후0초를 순서대로 별도 비교한다. 휴지를 줄이면서 목표 거리나 보상을 동시에 바꾸지 않는다.
- 미래 목표 노출은 기존 악보 관측을 유지한다. CPU fixture로 다음목표ID/줄/프렛/손가락/시간과손가락별진행상태가 실제 정책 입력에 담기는지 확인한다. 부족하면 그 상태에서 학습하지 말고 관측 개선을 별도 실험으로 분리한다.

1차는 조건당100회,50/100회 평가다. 다만7.5초 과제는5초 단음보다 같은 전이 수에서 완료 에피소드가 적다. 목표별 정상 음 끝까지 노출된 기회 수와 전곡 노출량을 반드시 함께 비교한다. 100회 결과만으로 서로 다른 길이의 과제 수렴 속도를 직접 비교하지 않는다.

후속음까지 정상 노출된 기회가 목표별320개 미만이면 성과와 무관하게200회까지 연장해100/200회를 함께 제시한다. 기회가 충분한 경우에도 미달성 과제는200회까지 한 번만 연장하여 학습 길이의 영향을 확인한다. 200회에도 달성0·접촉0이면 해당 분기를 중단해 원인을 분석한다. 연장 전에 원래 노출 문턱을 재계산하지 않는지 확인한다. 단계별 준비·구현시간은 학습시간과 분리한다.

## 6. 실행 전 물리 가능성과 구조 검사

1. 원본 소스·입력·자산·모델 SHA와실제initial std/활성축/관측열 검사를 통과한다.
2. B1/B2 정렬 reset의첫 native tick에서 기타/팔/손가락 위치의 급격한 이동이 없는지 확인한다.
3. 새 목표 단일 끝점,동시조합의공통손목영역,전환의유한속도경로를 새 native 장면에서 재생한다. 학습 정답을 만들기 위한 검사가 아니라 현재 물리에서 가능한지 분리하는 검사다.
4. 전환 재생의 음 시작 준수·B까지 도달·기존음차단해제·물리/손목안전을 검사한다. 알려진 제어 재생 성공과 정책 학습 성공은 별도 원장에 둔다.
5. 같은 줄6→8에서6과8이동시에clean으로 인정되지 않는지,높은프렛접촉이낮은목표를차단하는지 확인한다.
6. 동시음에서는 각 손가락 진행상태가 독립인지,중지가유지중일때약지의준비가중지를대기로바꾸지않는지 확인한다. 손목안내/종료영역의현재 집계가서로모순되는지도기록한다. 충돌한다면 종료기준을느슨하게하지않고 그 입력을해결한후 별도판본으로 진행한다.
7. 작은 GPU학습→동일계약엄격재개→평균평가→영상→정리상태 검사 후 본실험을 시작한다.

## 7. 평가는 어떻게 통과로 볼 것인가

각50/100/필요시200회 체크포인트를 평균 정책16환경에서 전체 과제로 평가한다. 안전 실패·무효도 분모16에 포함한다. 이번16환경은 같은 초기입력 재현이며16독립학습시드가 아니다.

- 단일/전환: 목표별 안전달성,모든음 안전달성,누적clean과최장연속clean을 분리한다. 달성 문턱은 기존 연속0.6초를 유지한다.
- 다음 분기로 넘어갈 잠정 기준: 전체 과제 안전달성≥15/16이며 각 목표의clean/음길이 평균≥90%,평가 물리·손목종료0. 이는 연구 진행 기준이며 구현 보상·종료 문턱을 바꾸는 것이 아니다.
- 동시/중첩: 음별 성공 합계 외에 공통구간에서 두 목표가동시에clean인시간 비율≥90%를 요구한다. O1은약지해제후중지유지, C2는후속단음도위기준을충족해야한다.
- 오압현은 음당시간과출처손가락/줄/프렛으로 보고한다. 정상 목표 이외의유효오압현시간 비율은평가활성음시간의5%이하를잠정 기준으로 한다. 동일한시간/목표를중복합산하지않도록 분모정의를원장에기록한다.
- 실행 전 연결시험 범위를 명확히 한다. B1/B2/S1/S2/S3/D1/D2의 단음 대조는 기존 근거와 같은 압현 진입·유지의 연결 검사다. 이 조건에서는 내부 시각 기준(진입 및 과제 중 필요한 해제)을 gate에 사용하고, 마지막 음 종료 뒤 tail의0.10초 해제는 측정·보고하되 다음 분기를 막는 기준으로 쓰지 않는다. 기존0.35 근거에는 빠른 마지막 해제의 검증이 없기 때문이다. 이는 GPU 결과 확인 전 정한 범위이며, 최종 해제까지 성공했다고 주장하지 않는다. T1/T2/T3/O1/C1/C2 복합 과제는 tail을 포함한 엄격 시각 기준을 그대로 사용한다.
- 시각 통과 기준도 사전에 둔다. 각 목표 음 시작 후0.10초 이내에 첫clean이 발생해야 한다. 목표가 끝나 더 이상 담당음이 없는 손가락은0.10초 이내에 유효 압현 후보를 해제해야 한다. 두 기준 모두 전체 과제 기준≥15/16에서 만족해야 다음 분기로 넘어간다. 이는 평가 기준이며 보상/종료 조건은 바꾸지 않는다.
- 같은 손가락의6→8 전환은 낮은 프렛의 부수 접촉만으로 해제 실패라고 하지 않는다. 실제 유효 프렛 변화,높은 프렛의 이전음 차단,새 목표 clean과 오압현 판정을 함께 본다. 정상 미래목표 준비 접촉도 현재 구현의 유효/오압현 분류와 분리해 기록한다.
- 음 시작 후첫clean 지연,의도한해제시각후이전접촉잔류시간,시각오차를 원시240Hz 시간으로 제시한다. 기존 원장에 정확 시각이 없으면 이 부분만 로그를 보강한 뒤 평가하며 종료된 에피소드를 정확시각검사에서 임의 제외하지 않는다.
- T1,T3,C2가통과하면seed17/27로각각새학습2개를추가한다. 시드별결과를모두제시하며좋은seed만선택하지않는다. 통과하지못한분기에대해서는재현성실험대신원인분석을우선한다.
- 정방향성공뒤의역방향 B→A,ABA반복과휴지축소는후속독립실험이다. 이번AB성공으로왕복성공을주장하지않는다.

## 9. 실행 시간과 자료 배치

최근 조건당100회 학습 약9분,평가2회와 대표영상 약3분이었다. 첫11조건을 모두100회로 실행할 때 GPU 기준 약132분이다. 실제 시간은 같은 컴퓨터의 첫 두 조건 측정으로 보정한다.

기본11조건은100~200회에따라GPU약2.2~4시간,주요3과제의추가2시드는약1.2~2.1시간을예상한다. 새도구·CPU/native물리확인·검수1~2시간을별도로잡으면전체약4.5~8시간범위다. 앞단실패시뒤단학습을하지않아더짧아질수있으며고정완료시각은구현검증후제시한다. 조건부 D1/D2가 필요하면100~200회 기준 약24~42분을 추가한다. GPU동시학습은하지않고한조건씩진행한다.

- 실험계획.md: 승인 전 설계와 진행 기준.
- 도구/: 새 버전 실험 도구. 기존 봉인 도구는 덮어쓰지 않는다.

- 분석/: 비교표·그래프·원인분석·판단 근거.

## 실행 전 확인 및 병행 범위

GPU 연결5단계(재생·학습2회·엄격재개1회·평가2환경·영상1환경)를 완료했다. C1 최초 참조재생은 약지 끝마디의 인접3번줄7프렛 부수압현으로 중지3번줄6프렛을 차단했다. 이 원문은 검증/C1_replay_v1에 보존하며 성공에 포함하지 않는다. 새 기하 후보는 별도 도구/결과판본으로 개선한다.

학습 소스·입력·제어·평가 기준은 본실험 시작 전에 고정한다. 학습에 정답으로 쓰지 않는 native 참조만 조건별로 별도 선택·출처SHA봉인하며, 이로써 다른 과제의 CPU 기하 개선과 현재 과제 GPU 학습을 병행할 수 있다. 선택한 참조 원문과 사용한 출처는 이후 수정하지 않는다. 각 조건이 참조의 실제 시각·속도·유지·동시 판정을 통과해야 학습을 시작한다.
