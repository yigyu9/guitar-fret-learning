영상 상단은목표/정책실제시각/활성목표색,하단은실제240Hz의손가락별진행상태다. 캡처 첫 프레임은물리시각1/30초에해당하므로표시시계에이를반영했다. 편집표시의근거는검증/영상표시/에둔다.

B1/B2와단음대조는압현진입·유지의연결시험으로마지막tail해제기준을별도로보고한다. 복합과제는최종해제까지포함한엄격기준을사용한다. 같은초기입력의16환경평가를16개독립학습시드의재현성으로확대하지않는다. 평가분모에는실패·무효도포함한다.

새조건의native참조가실패하면기존단일성공을대신인증하지않고해당분기를보류한다. `검증/C1_replay_v1`은원래동시기하후보의실제오압현실패기록이고,개선후보의정적검사와native검증은별도판본이다.
