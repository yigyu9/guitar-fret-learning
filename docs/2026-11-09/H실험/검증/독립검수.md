- 현재 봉인 검사 통과: snapshot_valid=true, design_valid=true, active_matches=true, 9,338개 입력 항목.
- 봉인 식별자: `743caaacf661c5b32c0072fb9c132149b4bf35949db4baf45e2d838affe6ce49`.
- H32/H64/H128의 학습·평가 5개·렌더 각 1개, 총 21개 argv를 공식 press_sequence parser로 처리하여 모두 통과.
- 조건별 총 전이 16,777,216, 업데이트 512/256/128, 저장 간격 128/64/32와 공통 1/4 전곡 전환을 공식 실행기와 대조했다. 초기·주기별 3개·최종 저장 이름이 공식 저장 규칙과 일치한다.
- 이동 후 경로 재생성, 입력 변경·외부 링크·설계 변조·동시 변경 거부, 출력·캐시 제외는 신규 테스트에서 검증한다.
