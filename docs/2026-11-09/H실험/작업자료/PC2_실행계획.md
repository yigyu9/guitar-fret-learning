# PC2 H 비교 실행 계획

기준은 전달된 설계·봉인과 다른PC_실행프롬프트다. 신규학습3개는 C1/V5 corrected/seed7/1024환경, 동일16,777,216전이이며 H32/64/128만 순차 비교한다. 출력은 이 연구 폴더 안에서 로컬 생성하고 공유 H실험에 SHA를 대조해 전달한다. 상대 폴더 날짜2026-11-09는 지정 경로를 그대로 유지하고 실행 시각은 실제 KST로 기록한다.

H128 메모리1update검사는 통과했다(본성과 제외). 실제사본·설계는 기준봉인9338항목으로 검증했다. 처음 rsync 링크17개누락은 원문과봉인link를대조해정확히복원했고첫실패로그도보존했다. 재봉인/소스대체/조건축소는 하지않았다.

순서: H32학습512 → H64학습256 → H128학습128 → 각조건5시점 전곡32환경 최초episode평가 → 분석 → 각조건대표 손확대/전신영상. Actor/Critic LR·탐색·보상·제어·물리·배치4096·epochs2는 변경하지 않는다. 설정의 의도된 차이는 horizon/updates/checkpoint_every뿐이다.

주비교는 최종경험량이다. 모델선정은 음별 strict 전체유지와 필요한해제를 함께 만족한 비율 → 물리/손목실패가 적음 → clean 시간 순이다. 완료된노트의 성취와 전체episode의 안전완료는 따로 집계한다. P1~P9별 전체선택목표 분모에 미노출/중단도 남기고, 준비관측·발음시작·끝까지관측·실제실패 분모를 함께 보고한다. 모든기준동률이나수치가불명확하면final을 고른다. 기존판정문턱은 변경하지 않는다.

새GPU실험이나 대형후속연구는 추가하지 않는다. 공유·로컬 봉인/체크포인트 SHA·source clock 불일치나NaN은 전체중단사유다. 복구는 명확한일시장애를 진단한경우에만 새attempt에서 엄격재개하고, 조건을 완화하거나 손상모델을 반복재시도하지 않는다. 감독 소스는 실행전에SHA기록하고 실행중수정하지 않는다.

분석 사전 검수 보완: ledger.exposure_time은실제준비토큰관측이아닌[press−2,end]기하진단창적분이다. 이를기하진단창으로라벨하고,발음구간도달/끝관측을분리한다. 전환경정책goal mask이력이없어실제관측노출수는미기록으로남긴다. 선택scope와관측노출을같게간주하지않는다.

모델선정 동률의 엄밀화: 상위3지표의 최고후보가여럿이면final이그최고집합밖이어도문구대로final을선택한다. clean누적초의1e-9이내차이는부동소수표현동률로취급하며원시값·성공문턱은그대로보존한다. 최고후보가유일할때만중간모델을선정한다.
