# 손가락 자세와 학습 원인 분석

목표는 최종 영상의 비정상적인 손가락 자세를 실제 관절·정책 출력·보상 로그로 설명하는 것이다. 학습 소스, 물리 설정, 원문 로그와 모델을 보존하고 분석 산출물만 이 디렉토리에 만든다.

- [x] 검증된16환경 평가와 대표 환경0의 전체 자세 기록을 확보하고 시간·관절 매핑을 확인했다.
- [x] 실제각, 적용 목표각, 정책 행동을 비교했다. 비유한 값·정확한 관절 한계 포화는 없고, 굽힘축은 잘못된 목표를 대체로 추종했다. 약지 벌림축의 추종 오차는 별도로 명시했다.
- [x] E4 실제 지급 gate를 재구성하고 최초2400개 trace와1.11e-16 오차로 검증했다. 중지 오압현의 발음 시간 원인을 분해했다.
- [x] 학습57,205개 완결 에피소드와1,427개 갱신 지표·6개 checkpoint를 대조했다.
- [x] 확인된 사실, 원인 가설과 후속 단독 비교안을 REPORT.md에 구분했다.
- [x] change-reviewer가 분석 코드·집계·그래프를 독립 검수했다. 환경별 RMS 평균과 초기/후기 분포 차이 등 해석 제한을 반영했다.

독립 분석을 입력·제어 경로와 보상·손가락별 실패 양상으로 나누고, 주 분석에서는 시간별 관절·정책·학습 경향을 맡는다. 새 학습과 보상·제어 수정은 이번 진단에 포함하지 않는다.
