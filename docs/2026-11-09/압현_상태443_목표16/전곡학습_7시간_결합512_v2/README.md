# 상태443·목표16·결합512 전곡 약7시간 재학습

2026-11-04 완료: 1,427회·6시간32분 학습, 최종 평가 평균4.25/67음, 물리·손목 조기 종료0/16, 전곡 성공0/16이다. [결과 분석](결과검토_20261104/REPORT.md)과 [최종 결과](최종결과.json)를 우선 확인한다. [손 확대 영상](동영상/hand.mp4)·[전신 영상](동영상/fullbody.mp4)은 같은 최종 모델의16환경 중 사전에 정한 환경0이며6/67음을 달성했다.

후속 [손가락 자세 진단](손가락자세진단_20261104/REPORT.md)은 실제각·정책 목표·57,205개 학습 에피소드와 E4 실제 대기 보상을 대조한다. 수치적 폭주보다 어색한 목표각의 학습 편향이 확인됐으며, 약지 벌림축 추종 오차와 기존 대기 gate 진단의 한계를 별도로 기록했다.

최초 촬영 중 새 타현 파일2개가 바뀌어 `진행상황.json`에는 원래 자동 감독의 실패 기록이 남아 있다. 학습과 평가는 정상 완료했으며, 별도 재촬영은 기존 엄격 검증을 모두 통과했다. 기존 실패 원문을 성공으로 바꾸지 않았다.

새 신경망 구조로67음 전체 곡을 학습한다. 기존 학습 소스는 수정하지 않고, 별도 실행driver에서 처리량 측정→시간 제한 학습→최종16환경 평가→환경0 대표 손/전신 영상을 순서대로 실행한다.

- [실험계획](실험계획.md): 곡·입력·초기 탐색·예산·보존 기준.
- [진행상황](진행상황.json): 현재 작업·학습상태·PID·남은 용량·학습 종료 예상unix시각.
- `실행설정.json`: 처리량 측정 후 결정되는 반복 수와 시간 한도.
- `로그/처리량.log`, `로그/학습.log`, `감독.log`: 원문 실행 출력.
- `학습/J/learning_metrics.jsonl`: PPO 갱신·각 보상·학습시간.
- `학습/J/episodes.jsonl`: 목표별 수행·오압현·엄지·실패 진단.
- `학습/J/checkpoint_*.pt`, `학습/J/final.pt`: 주기 저장과 마지막 모델.
- `최종평가/`: 저장본과 입력 봉인을 검증한 평균정책16환경 평가.
- `동영상/hand.mp4`, `동영상/fullbody.mp4`: 완료 후 대표 영상 각1개.
- `최종결과.json`: 평가의 평균 달성 음 수와 결과 경로.

처음25%노출은 기존 구간 일정이며 이후reset부터전곡이다. 7시간은 학습프로세스 기준 목표로, 측정·평가·영상은 별도다. source/자산/identity가 바뀌면 실패 원문을 남기며 우회하지 않는다. 실행 중 공유 활성 소스와driver는 수정하지 않는다.

새로 학습하는33축에는 엄지도 포함된다. 기타는자유강체이고root고정은 유지한다. 새로운 구조의 성능·수렴 개선 여부는 이번 결과와 별도 비교군으로 판단한다.

이번변경은행동정책결합부만768→512→256→33으로확대한것이다. 가치망결합부256→256과상태/목표인코더폭,보상,물리,탐색초기값,학습률규칙은유지한다. 256구조에서처음부터재학습하므로이전37회는누적하지않는다.
