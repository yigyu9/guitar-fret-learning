# 신규 압현 구조 검증 결과

- CPU 신규·기존 회귀 검사37개 통과, 신규6개 Python 파일 문법 검사 통과.
- 실제 GPU PhysX에서443차원2환경·H4·2회학습과 저장 완료.
- 동일 checkpoint를 소스·입력·identity 검증 후1회 재개하여 누적3회 갱신 완료.
- 재개 모델로2환경 구간 평가2에피소드 완료.
- 골반 추가452차원도2환경·H4·1회학습과 저장 완료.
- 네 실행 모두 completed=true, failure=null, changed_inputs/missing_import_pins/cleanup_errors 빈 배열, lifecycle_verified=true.
- 독립 검수에서 발견한 환경 계약 위치 불일치와 기존 실행기 탐색 초기화 인터페이스 문제를 수정하고 실제 환경→정책→제어 통합 검사를 추가했다. 최종 검수 잔여 지적 없음.

이는 입력·물리 연결·PPO 갱신·저장·재개·평가의 실행 검증이다. 짧은 학습이므로 압현 성공이나 수렴 개선을 주장하지 않는다. GPU 영상 렌더는 이번 검증에서 실행하지 않았다.

기존 기본 진입점·환경·정책·학습 실행기 파일은 수정하지 않았다. 별도 신규 파일로만 연결했으며 과거 checkpoint와 새 모델의 호환은 지원하지 않는다. 입력443은 기존557과,452는443과도 서로 다른 계약이다. 골반 관측 옵션은root고정해제가 아니다.
