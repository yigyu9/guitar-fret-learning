# 손가락 초기 탐색0.25·0.3 비교

사용자가 승인한 비교다. 기존0.15·0.2 결과와 봉인 모델은 그대로 보존하고, 초기std만 바꾸어 각 조건을 새 정책으로 학습한다.

- [x] 기준0.2 체크포인트 strict입력·구조 검증. 0.25/0.3 설정의 차이가 finger_initial_std 하나인지 확인
- [x] 순차 실행 드라이버 문법·동작·독립 검수와 소스 봉인
- [x] 0.25 large64·H32·100회·seed7 학습,50/100회 평균16환경 평가,대표 손/전신 영상
- [x] 0.3 동일 조건 학습·평가·영상
- [x] 기존0.15·0.2와 함께 학습/평가 수치·그래프·원문SHA·독립검수 기록

중지·3번줄·6프렛 하나의 정렬 출발·팔 유지 지원·담당4축 진단이다. 출발 자세·보상9개·직접 제어·관절한계·PD·물리/손목 종료·노출일정·학습률규칙·std하한exp(-3)는 유지한다. 값은 Gaussian latent 초기표준편차이고 팔 탐색이나최소std를올리는작업이아니다. 활성학습패키지나기존봉인실행기를변경하지않는다.

50/100회평가의달성수를우선비교하고,동일하면음전체1.5초연속유지·누락·오압현·안전을비교한다. 학습중접촉수만늘어도평균정책이개선되지않으면우세라고판단하지않는다. 평가시점사이정확한최초수렴시점은알수없다. 한seed·한목표에서의후보비교이며전신/다른목표일반화는미검증이다.

예상시간은2개조건학습약18분,4회평가와2회영상·분석까지약25~30분이다. GPU는한조건씩사용하며중단되면완료산출물SHA를검사한뒤다음단계를이어간다. 실패/무효결과는숨기거나덮어쓰지않는다.
