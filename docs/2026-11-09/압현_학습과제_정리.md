# 압현 정책이 학습해야 할 과제

작성일: 2026-11-04. 목적은 가상 목표를 이용한 압현 학습과 평가의 범위를 정리하는 것이다. 아래는 **학습 과제 설계안**이며 모든 과제가 구현되었거나 성공했다는 뜻은 아니다. 기존 실행·정책·보상·물리 설정을 변경하지 않는다.

핵심 분류는 **단일/동시 목표를 수행하는 능력**과 **일부 목표를 유지하면서 나머지 목표를 바꾸는 능력**이다. 손가락 개수만 늘리는 것으로 전환 능력까지 학습됐다고 판단하지 않는다.

## 1. 모든 과제에 공통인 기본 동작

각 담당 손가락은 필요에 따라 **목표 접근·정렬 → 정해진 시각까지 압현 → 지정된 구간 유지 → 정해진 시각에 해제**를 수행한다. 팔·손목은 이 동작들이 함께 가능한 공통 자세를 만들어야 한다.

이 단계는 손 전체가 매번 동시에 거치는 순서가 아니다. 한 손가락이 압현을 유지하는 동안 다른 손가락은 접근하거나 해제할 수 있다. 해제도 목표각 명령만 바꾸는 것이 아니라 실제 접촉·하중 해소를 기존 측정 기준으로 확인해야 한다.

초기 범위는 검지·중지·약지·소지, 손가락당 하나의 목표, 서로 다른 줄의 동시 압현으로 둔다. 같은 줄의 서로 다른 프렛을 독립적인 두 음으로 세지 않으며, 한 손가락으로 여러 줄을 누르는 바레는 별도 확장으로 남긴다.

### 손가락은 목표 생성 시 무작위 배정

- 특정 과제를 특정 손가락에 고정하지 않는다. 매 에피소드의 목표 일정을 만들 때 네 손가락 중 필요한 수를 중복 없이 무작위 선택하고 역할을 배정한다. 필요한 수는 동시 압현 수만이 아니라 일정 전체의 담당 역할 수로 정한다. 단일 압현 유지는1개, 단일→단일 손가락 교대나 두 손가락 동시 과제는 서로 다른2개를 선택한다.
- 아래 F1·F2는 실제 손가락 이름이 아니라 그 에피소드에서 배정한 역할이다. 유지 역할·이동 역할도 무작위로 배정한다. 동일한 난이도의 허용 후보에서 손가락과 역할이 편중되지 않도록 추출 기회를 균형 있게 구성한다.
- 한 번 만든 목표 일정 안에서는 배정을 보존한다. 같은 손가락 이동·반복은 동일한 손가락으로 수행하고, 교대는 서로 다른 손가락으로 수행한다. 연속 유지 목표의 담당 손가락을 전환 중 다시 추첨하지 않는다.
- 무작위로 정한 실제 담당 손가락은 목표 입력에 명시한다. 이는 목표 생성의 무작위화이며, 정책이 담당 손가락을 스스로 선택하는 별도 운지 계획 문제와 구분한다.
- 줄·프렛과의 결합은 공통 팔 자세·손가락 배치 제약을 확인한다. 후보 미확보나 제외 이유를 기록하고, 실제 실행 후 실패한 사례를 무작위 후보에서 빼서 성공률을 높이지 않는다. 평가에는 고정된 seed와 목표 목록을 사용하고 손가락별·역할별·조합별 결과를 함께 보고한다.

## 2. 기본 과제 9종

아래 A·B·C·D는 서로 구분되는 `(줄, 프렛)` 위치다. `F1:A`는 무작위로 배정된 손가락 F1이 A를 누르는 목표를 뜻하며, F1과 F2는 서로 다른 손가락이다. 예시는 과제 관계를 설명하며 실제 수행 가능성은 공통 팔 자세와 물리 경로에서 확인한다.

| ID | 학습 과제 | 목표 예시 | 핵심적으로 익힐 능력 |
| --- | --- | --- | --- |
| P1 | 단일 압현 | F1:A 진입 → 유지 → 해제 | 한 목표에 정확히 접근하고, 지정된 시간 동안 누른 뒤 놓기 |
| P2 | 정적 다중 압현 | F1:A + F2:B 유지 | 공통 손목 자세에서 모든 담당 손가락이 함께 clean 유지 |
| P3 | 같은 손가락의 목표 전환 | F1:A → F1:B | 기존 목표를 해제하고 다른 프렛·줄로 이동해 다시 압현 |
| P4 | 다른 손가락으로 교대 | F1:A → F2:B | 앞 손가락의 해제와 다음 손가락의 진입을 시간에 맞춰 조절 |
| P5 | 기존 압현 유지 + 목표 추가 | F1:A → F1:A + F2:B | 누르고 있는 손가락을 방해하지 않고 다른 손가락 진입 |
| P6 | 일부만 해제 | F1:A + F2:B → F1:A | 필요한 손가락만 놓고 나머지는 계속 유지 |
| P7 | 일부 유지 + 나머지 목표 전환 | F1:A + F2:B → F1:A + F2:C | 유지 담당 손가락의 압현을 끊지 않으면서 이동 담당 손가락만 해제·이동·재압현 |
| P8 | 다중 목표 전체 전환 | F1:A + F2:B → F1:C + F2:D | 여러 손가락과 공통 팔 자세를 조정하여 다음 조합으로 전환 |
| P9 | 같은 목표 반복 압현 | F1:A → 실제 해제 → F1:A | 계속 누르고 있는 것과 구분되는 해제·재진입을 반복 |

P2는 두 손가락부터 시작해 세 손가락·네 손가락으로 확장한다. P5·P6도 1↔2뿐 아니라 2↔3 등으로 확장할 수 있다. P7은 한 손가락 유지·한 손가락 변경부터 시작해 두 손가락 유지·한 손가락 변경 등으로 넓힌다.

**P7과 P8의 차이가 중요하다.** P8에서 이전 목표와 다음 목표 사이에 휴지가 허용되면 모두 놓고 이동할 수 있다. P7은 유지 목표가 전환 중에도 계속 유효해야 하므로 모두 놓고 다음 조합만 성공하는 방식은 실패다. 같은 손가락 수라도 두 과제의 난도는 다를 수 있다.

같은 위치를 다른 손가락으로 넘겨받는 `F1:A → F2:A`는 P4의 별도 변형이다. 위치가 같아도 담당 손가락이 바뀌므로 자동으로 공통 유지 목표로 취급하지 않는다. 접촉 겹침과 무중단 인계가 필요한지 먼저 정의하고 별도로 검사한다.

## 3. 기본 과제에 붙이는 시간 조건과 종합 과제

| 조건 | 예시 | 평가할 내용 |
| --- | --- | --- |
| 동시 진입·동시 해제 | F1:A·F2:B가 같은 음 시작·종료 시각을 가짐 | 시작 시점의 준비 완료와 공통 유지 |
| 시차 진입·시차 해제 | F1:A 유지 중 F2:B 진입, F2만 먼저 해제 | 손가락마다 다른 유지 구간과 활성 목표 수 변화 |
| 휴지를 둔 전환 | A 종료 → 명시된 휴지 → B 시작 | 휴지 중 실제 해제와 다음 목표 준비 |
| 짧은 간격·연속 전환 | 같은 과제에서 허용 이동 시간을 단계적으로 줄임 | 시간 제한 안의 전환, 불필요한 조기 해제·지연 |
| 긴 유지·길이가 다른 음 | F1은 길게, F2는 짧게 유지 | 유지 손가락의 안정성과 선택적 해제 |
| 여러 단계의 혼합 | 단일 → 동시 → 일부 유지 전환 → 부분 해제 → 휴지 | reset 없이 전체 순서를 연속 수행 |

이들은 기본 과제와 독립된 정책이 아니라 목표 시각·구간의 변형으로 구성할 수 있다. 특히 피크가 같은 음을 여러 번 타현한다고 왼손도 매번 놓아야 하는 것은 아니다. 왼손 목표가 이어지는 구간에서는 압현 유지가 맞으며, P9는 **왼손 해제 자체를 요구하는 과제**에 사용한다.

혼합 과제는 처음부터 긴 곡으로 만들기보다 2단계 → 3~5단계 → 더 긴 구간으로 확장한다. 단계 사이에 물리 상태를 다시 주입하거나 reset하면 연속 전환 검증으로 인정하지 않는다.

## 4. 전환 목표를 명확히 쓰는 방법

각 전환은 다음 네 가지를 명시한다.

- **유지:** 같은 담당 손가락·줄·프렛의 목표가 전환 구간 전체에 걸쳐 이어짐.
- **해제:** 이전 목표 중 종료되어야 하는 것.
- **신규:** 다음에 진입해야 하는 목표.
- **시간:** 각각의 준비 허용 구간, 음 시작, 유지 종료, 해제 기한 및 전환 휴지.

예를 들어 `F1:A + F2:B → F1:A + F2:C`는 F1:A 유지, F2:B 해제, F2:C 신규 진입이다. 이때 F1:A는 처음과 끝만 성공해서는 안 되고 F2가 이동하는 동안에도 유지되어야 한다.

| 구간 예시 | F1: 유지 담당 | F2: 이동 담당 | 요구되는 활성 목표 |
| --- | --- | --- | --- |
| 0.0~0.6초 | A 유지 | B 유지 | F1:A·F2:B |
| 0.6~0.9초 | A 유지 | B 해제 후 C로 준비 이동 | F1:A |
| 0.9~1.5초 | A 유지 | C 유지 | F1:A·F2:C |

위 시각은 표기 예시이며 수행 가능한 이동 시간으로 검증된 값은 아니다. 실제 입력에는 별도의 최초 준비 구간도 필요하다. 같은 위치의 목표라도 중간에 해제를 요구하면 하나의 연속 유지 목표로 합치지 않는다.

동시에 허용된 다른 담당 손가락의 올바른 접촉은 오압현으로 세지 않는다. 미래 목표의 준비 접촉은 명시된 허용 구간에서만 인정하며, 현재 유지음을 방해하는 접촉까지 면제하면 안 된다. 예를 들어 같은 줄의 더 높은 프렛을 미리 눌러 현재 목표음의 의미를 바꾸는 경우는 별도 간섭 판정이 필요하다.

## 5. 성공 기준과 기록할 값

기존 물리·접촉 기준을 유지한 상태에서 아래 지표를 함께 기록한다. 정적 과제의 첫 비교는 기존 실험과 연결해 음 구간1.5초부터 시작할 수 있지만 모든 과제를 동일 길이로 고정할 필요는 없다.

| 항목 | 기록·판정 |
| --- | --- |
| 준비 | 공통 초기 자세에서 실제 이동했는지, 손목 도착·정렬 성공과 걸린 시간 |
| 개별 압현 | 목표별 clean 시간·유지율·최장 연속 clean·시작 지연 |
| 동시 압현 | 그 시각에 요구된 모든 목표가 함께 clean인 시간·유지율·최장 연속 구간 |
| 유지하며 전환 | 유지 손가락의 **계획된 전환 전체 구간** clean 및 이탈 횟수·최장 이탈 |
| 신규 목표·해제 | 다음 목표의 제때 진입, 이전 목표의 실제 해제와 조기/지연 해제 |
| 잘못된 접촉 | 오압현·현재 목표 간섭·명시된 휴지 중 불필요한 압현 |
| 실제 동작 | 손가락 관절 변화·추종 오차, 팔/손목 이동, 손 전체로 미는 동작 여부 |
| 안전·전체 수행 | 물리 실패·손목 이탈·검사 오류, 모든 목표·전환의 완료 여부 |

동시 유지율은 **동시 압현을 요구한 전체 계획 구간**을 분모로 둔다. P7에서는 유지 담당 손가락의 단독 유지 구간도 빠뜨리지 않고 따로 평가한다. 조기 종료·누락·실패 구간을 분모에서 제거하지 않으며, 일시적으로 성공한 짧은 구간만 골라 전체 성공으로 보고하지 않는다.

엄격 성공은 요구된 모든 목표의 유지 구간·전환·해제 조건과 안전 조건을 함께 만족하는 것으로 둔다. 학습 중 부분 진전은 별도 수치로 남긴다. 허용 시작 오차나 짧은 접촉 이탈 유예를 사용할 경우 값과 적용 구간을 실행 전에 정하고, 결과를 본 뒤 성공에 맞춰 바꾸지 않는다.

실패는 준비 실패 / 기하 후보 미확보 / 개별 압현 실패 / 동시 유지 실패 / 전환 중 유지 상실 / 신규 목표 지연 / 해제 실패 / 물리 실패 / 검사 오류로 구분한다. 유한 탐색에서 후보가 없다는 이유로 물리적 불가능을 선언하지 않는다. clean은 현행 표면 기하·접촉 합력 기준이며 실제 현 압력·음향 성공과 구분한다.

## 6. 권장 진행 순서와 난이도 축

1. **단일 기초:** P1의 진입·유지·해제를 먼저 확인하고 P9 반복과 P3·P4의 단일 전환으로 확장한다.
2. **두 손가락 조합:** P2 정적 동시 압현의 공통 자세를 확인한 뒤 P5 추가·P6 부분 해제를 검사한다.
3. **두 손가락 전환:** P7 일부 유지 전환과 P8 전체 전환을 각각 검사한다. 하나의 성공을 다른 과제의 성공으로 상속하지 않는다.
4. **시간·연속성 확장:** 시차, 짧은 휴지, 긴 유지, 여러 단계 혼합을 적용한다.
5. **손가락 수·범위 확장:** 세 손가락·네 손가락, 큰 위치 이동, 아직 학습하지 않은 조합으로 넓힌다.

이는 의존관계를 위한 권장 순서이며 모든 세·네 손가락 정적 과제를 끝내야 두 손가락 전환을 시작할 수 있다는 뜻은 아니다. 단일 전환과 두 손가락 정적 과제는 각각 확인 가능한 분기다.

| 난이도 축 | 쉬운 범위에서 넓히는 방향 |
| --- | --- |
| 동시 손가락 수 | 1 → 2 → 3 → 4 |
| 손가락 조합 | 해당 난이도에서 허용된 조합·역할을 무작위 배정; 인접/비인접 제한을 둘 경우 실험 조건에 명시 |
| 줄 간격 | 인접 줄 → 한 줄 건너뛰기 → 더 넓은 간격 |
| 프렛 배치 | 같은 프렛 → 인접 프렛 → 더 넓은 간격 |
| 전환 거리 | 손가락 중심의 작은 이동 → 공통 손목·팔의 위치 변경 |
| 변경할 요소 | 프렛만 / 줄만 / 담당 손가락만 → 여러 요소 함께 변경 |
| 유지 제약 | 휴지 허용 → 일부 목표 연속 유지·시간 여유 감소 |
| 일반화 | 무작위 담당 손가락·역할에서 여러 목표·초기 자세·독립 학습 seed로 확장 |

손가락 수가 적다고 항상 더 쉽지는 않다. 처음에는 대표 조합을 소수 선택하고 한 번에 바꾸는 난이도 축을 제한한다. 단일 성공은 다중 목표 후보를 고르는 참고이며, 두 끝점의 성공도 그 사이 전환 가능성을 보증하지 않는다.

## 7. 정책 구성과 이후 확장

과제마다 별도 신경망이 반드시 필요한 것은 아니다. 장기적으로는 **같은 목표 조건부 압현 정책에 여러 종류의 목표 일정**을 제공하고, 과제별 성공률을 따로 평가하는 구성이 가능하다. 초기에는 실패 원인을 분리하기 위해 과제별 실험을 수행한 뒤 혼합 학습을 검토한다. 현재·미래 목표를 관측에 넣을 때에는 유지 중인 목표가 슬롯에서 밀려나거나 해제 기한이 사라지지 않는지도 확인해야 한다.

바레, 같은 위치의 손가락 인계, 슬라이드·해머링·풀링오프 등은 기본 과제 이후의 별도 확장이다. 특히 소리를 이어 내는 주법은 접촉 성공만으로 검증할 수 없으므로 현재 과제의 통과 기준과 섞지 않는다. 타현·전신 정책과 결합할 때도 압현 준비 완료와 타현 시점, 기타 움직임에 따른 유지 안정성을 별도 평가한다.
