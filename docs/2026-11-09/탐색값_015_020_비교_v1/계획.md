# 손가락 탐색값0.15와0.2 비교

사용자가 승인한 단독 변수 비교다. 기존0.15 결과와 원본·모델·봉인은 보존한다. 신규 Python 구현 없이 검증된 정렬 출발 실행기를 재사용한다.

- [x] 기준0.15 체크포인트의 입력·구조·SHA 검증 및 새 설정과의 차이가 finger_initial_std 하나인지 검사
- [x] 초기std0.2, large64·H32·100회·seed7 학습. 기존std floor exp(-3) 및 적응 학습률 규칙 유지
- [x] 50/100회 모델 평균 정책16환경 평가. 음 수행 부족·오압현·연속 유지·물리/손목 종료 포함
- [x] 기준0.15의50/100회 평가와 대조. 최초접촉 발견시점·학습중접촉빈도·학습률·실효std 추적
- [x] 대표 손/전신 영상과 분석 저장, 원시입력·모델 SHA 재확인

목표는 중지·3번줄·6프렛 하나이며 정렬된 상태에서 팔을 유한 제어로 유지하는 담당4축 진단이다. 보상·제어·종료·출발 상태·학습 길이·난수는 변경하지 않는다. 탐색값은 관절rad가 아닌Gaussian latent 초기표준편차다. 같은16환경 재현검사를 다른자세·난수의 일반화로 해석하지 않는다. 초기표준편차 변경에 따른 적응학습률의 반응도 결과에 포함되므로 둘의 기여를 분리했다고 주장하지 않는다.

운영 학습의 기본값 채택은 이번 비교 뒤 판단한다. 비교 중 기본 학습 코드는 변경하지 않는다. 예상시간은100회학습약9분, 평가2회와영상까지약13~16분이다.

## 결과를 보기 전에 정한 판단 순서

1. 평균 정책의50회·100회 달성 수를 먼저 비교한다. 학습 중 우연 접촉을 평균 정책 성공으로 대체하지 않는다.
2. 동일 달성 수라면 연속 압현 시간·누락·오압현·안전 종료를 비교한다.
3. 학습 중 접촉 발견과 빈도, 학습률 유지, 움직임 크기는 원인 해석에 사용한다.
4. 0.2가 더 이른 평가에서 성공하고 최종 유지·안전이 뒤처지지 않으면 이번 단일압현 진단의 우선 후보로 삼는다. 두 시점의 성공 결과가 같거나 성능이 후퇴하면 이 한 번의 실행만으로0.15보다 낫다고 단정하지 않는다.
5. 다른 난수·손가락·목표·팔 자유도에 대한 기본값 일반화는 별도 검증 대상이다.
