# 손가락 초기 탐색0.35·0.4·0.45 비교

사용자가 승인한 세 조건의 단독 변수 비교다. 기존0.15~0.3의 모델·원문·봉인은 보존하고, 검증된 정렬 출발 학습기와 순차 실행 구조를 재사용한다.

- [x] 기준0.3 모델 strict입력·구조 검증 및 새 세 설정의 차이가 finger_initial_std 하나인지 확인
- [x] 복사 드라이버 문법·CPU 자체검사·독립 검수·소스 봉인
- [x] 0.35 large64·H32·100회·seed7 학습,50/100회 평균16환경 평가,손/전신 영상
- [x] 0.4 동일 학습·평가·영상
- [x] 0.45 동일 학습·평가·영상
- [x] 기존0.15~0.3과 7조건 종합 수치·그래프·원문SHA·최종독립검수

목표는 중지3번줄6프렛 하나이고, 정렬된 도착 상태에서 팔을 유한 제어로 유지하는 담당4축 진단이다. 출발·입력·보상9개·직접각 제어·관절한계·PD·종료·학습률규칙·노출일정·std하한exp(-3)는 유지한다. 탐색값은Gaussian latent초기표준편차이며최소std나팔탐색을올리는작업이아니다. 활성패키지와기존봉인소스는수정하지않는다.

비교는50/100회 평균정책달성을우선하고,같으면음전체1.5초유지·누락·오압현·안전을비교한다. 학습중접촉수뿐아니라오압현과속도제한부담도기록한다. 평가시점사이의정확수렴시점은미측정이며한seed·한목표에서의재현검사다. 전신J33·다른손가락·목표·난수의기본값일반화는별도검증한다.

GPU는0.35→0.4→0.45순서로한조건씩사용한다. 조건별학습약9분,평가2회와영상약3분,전체약36~42분을예상한다. 완료산출물SHA검증후다음단계로넘어가며실패원문은보존한다.
