## 수정 금지와 실행 순서

- 현재 기본 연구 `복합압현_단계별실험_v1`의 실행기·학습기·입력·봉인·모델은 수정하지 않는다. 그 드라이버가 정상 완료하고 GPU를 놓은 뒤 새 드라이버가 시작한다.
- 활성 `guitar_learning` 구현도 수정하지 않았다. 새 학습기는 새 입력·schema로만 fresh 학습한다. 다른 std나 과거 체크포인트를 강제 재개하지 않는다.
- 새 소스·검수·입력은 실행 전 SHA로 고정한다. 기하 참조는 최신 completed 선택 원장에서 고른 뒤 조건별로 고정한다. 사용한 참조를 후속 후보로 몰래 바꾸지 않는다.
- 학습·평가·렌더가 차례대로 실행되며 다른 GPU 프로세스와 겹치지 않는다. 작은 GPU 학습→동일 모델 엄격 재개→평가→렌더 검사를 먼저 수행한다.

12개 복합 입력 중 정적 참조 후보가 확보된 조건은 N01/N03/N07/N08/N09다. N05/N06의 동시 3음 등 나머지는 현재 기하 탐색에서 간섭이나 유지 경로 문제를 해결하지 못했다. 이 결과는 물리적 불가능의 증명이 아니다. 최신 원장은 `검증/기하/참조선택_v2.json`이고 SHA는 `099903481ac27cf11b99adea30bf0657f51481d61d1e83afcb94831ba4dd678a`다. 실제 native 재생의 엄격 기준을 통과해야 학습한다.
