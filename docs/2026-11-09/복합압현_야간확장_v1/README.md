# 오전 10시까지 복합 압현 연구

목표 종료 시각은 2026년 11월 3일 오전 10시(KST)다. 사용자가 지정한 저장 위치에 따라 결과는 `docs/2026-11-09` 아래에 모은다.

먼저 기존 기본 연구를 마친 뒤 GPU를 순차 사용한다. 새 연구의 손가락 초기 탐색값은 0.35로 유지하며, 팔 초기 탐색 크기만 비교한 후 동시 압현과 전환 조건을 진행한다. 시간 안에 평가와 영상까지 마칠 수 있는 조건만 시작한다.

- [실험 설계](실험계획.md): 비교 변수, 12개 복합 조건, 성공 기준과 중단 시각
- [진행 상황](진행상황.json): 현재 작업, 완료 여부, 원시 출력 경로와 오류
- [조건별 결과](결과.md): 완료된 평가와 대표 영상
- [비교 분석](분석/결과분석.md): 기본 연구와 야간 연구의 목표별 수치
- [비교 그림](분석/평가비교.png): 전체 달성, 가장 부족한 목표, 오압현과 엄격 시각
- `동영상/`: 조건별 대표 손 확대 영상과 전신 영상만 저장
- `실행/`: 원시 학습 로그, 모델, 평가와 렌더 원문
- `검증/`: CPU 검사, 독립 검수, 물리 참조 동작과 SHA 원장

과제 성능 미달, 참조 동작 미확보, 실행 오류, 시간 부족은 서로 구분한다. 기하 탐색 실패를 물리적 불가능으로 단정하지 않는다. 정렬된 출발점에서 같은 목표를 반복한 조건부 실험이며, 임의 초기 자세나 자유 전곡 연주 검증은 아니다.
