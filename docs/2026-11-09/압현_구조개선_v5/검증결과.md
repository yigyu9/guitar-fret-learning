# 압현 v5 구현과 검증

실행일: 2026-11-04. 구현, CPU 회귀 검사, 독립 검수, 실제 GPU 학습·재개·평가를 완료했다. 재검사 수치는 [검증요약.json](검증요약.json)에 기록했다.

## 검증한 변경

1. 실제 최초 모델의 팔·엄지 표준편차는 약 0.15, 나머지 손가락은 약 0.35였다. 공용 설정의 `initial_std=exp(-3)`는 후처리 이동을 0으로 만드는 중립값이다. 이 값만 보고 실제 탐색이 0.0498이라고 해석하면 안 된다.
2. 구간 밖 회복 목표가 대기 시점에 영향을 주는 반례에서, v4에는 없던 상태 차이가 v5의 12개 추가 입력에 드러났다. 목표 슬롯을 임의로 늘리지 않았다.
3. 전체 67음의 남은 감점 예산 16.75는 고정 분모 16.75로 나누어 1로 표현된다. 구간 선택에 따라 분모를 바꾸지 않는다.
4. `corrected`는 같은 입력 조건의 v4 combined 보상 계산을 보존한다. `preparation`은 대기 가중치 1에서 접근 품질의 10%를 남기고, `full_hold`는 달성·부족 정산·목표 필요 유지 시간을 함께 전체 길이로 바꾼다.
5. 오압현만 발생해 유효 압현이 꺼지는 반례는 새 해제로 인정하지 않는다. 실제 기준은 목표 패드의 기하·방향·하중 후보 소실이며, 접촉 쌍의 완전 분리 측정은 아니다.

## CPU와 독립 검수

- 기존 회귀 검사 **188개 통과**, 45.565초.
- 신규 환경 15개와 실행·정책 8개, 총 **23개 통과**, 12.365초.
- 총 **211개**. 기존 검사를 다시 작성한 수치가 아니라 기존 검사와 새 버그·계약 회귀 검사의 합계다.
- 부분 환경 reset, 수집 구간 경계, 종료 잠재값, 실패 시 중복 지급 방지, 잘못된 프렛·탐색값·구형 모델 거부를 검사했다.
- 신경망의 새 입력 기울기, 빈 목표 마스크, 행동망과 가치망 분리, PPO 갱신·저장·재개, 입력 SHA와 전체 신경망 계약 변조 거부를 검사했다.
- 별도 change-reviewer 검수에서 초기화 중복과 해제 판정의 위험을 검토했다. 해제 판정과 계약 설명을 보완한 뒤 미해결 사항 없음 판정을 받았다.

## 실제 GPU 작동 검사

장치: NVIDIA GeForce RTX 4070 Ti, 12GB. Isaac Gym GPU PhysX와 GPU 텐서 경로를 사용했다. 모든 신경망은 고정 폭이며 `large`로 기록했다.

| 검사 | 환경 수 | 수집 길이 | 반복 | 전이 수 | 실행 시간 |
|---|---:|---:|---:|---:|---:|
| corrected 새 학습 | 8 | H32 | 4 | 1,024 | 27.78초 |
| 위 모델 엄격 재개 | 8 | H32 | 추가 2 | 512 | 15.27초 |
| combined 새 학습 | 8 | H128 | 2 | 2,048 | 52.44초 |

위 세 실행은 `completed=true`, `failure=null`, 입력 변경 없음, 누락된 import 봉인 없음, 정리 오류 없음으로 끝났다. 샘플 수집·기록·학습 반영의 생명주기 검사도 통과했다. 재개는 최초 4회 학습한 모델에서 총 6회까지 진행했다.

최초·최종 모델 6개의 파일 SHA를 저장 manifest와 대조하고, 정식 reader의 입력·설정·전체 신경망 계약 검사를 통과했다. 최초 모델의 0.15/0.35와 재개 직전·직후 모델의 모든 가중치가 정확히 같음을 별도로 확인했다. 이는 재개 시 표준편차를 초기값으로 되돌리지 않았다는 검증도 포함한다.

학습의 무작위 탐색 중에는 기타 이탈로 인한 환경 종료가 있었다. corrected 새 학습에서 기록된 종료 4건, 재개 1건은 모두 기타 이탈이었다. combined에서 기록된 종료 12건 중 11건은 기타 이탈, 1건은 정상 시간축 종료였다. 짧은 검사는 진행 중인 에피소드가 많이 남기 때문에 이 숫자를 전체 시도의 실패율로 해석하지 않는다. 소프트웨어 실행 완료가 물리 실패 0건이나 압현 학습 성공을 뜻하지 않는다.

| 저장 모델의 결정적 평가 | 평가 수 | 안전한 시간축 완주 | 물리·손목 실패 | 압현 달성 | 실행 시간 |
|---|---:|---:|---:|---:|---:|
| corrected 6회 모델, 전곡 | 2 | 2/2 | 0/2 | 각 0/67음 | 310.98초 |
| combined 2회 모델, 선택 구간 | 2 | 2/2 | 0/2 | 각 0/2음 | 46.18초 |

두 평가 모두 실제 유지·해제·완료 성공은 0이었다. 아직 학습하지 못한 모델에서 시간축만 완주한 결과를 연주 성공으로 기록하지 않는 것을 확인했다. 전곡 평가의 두 에피소드는 각각 32.8167초의 시뮬레이션 시간을 진행했다. 새 `press_completion` 기록과 입력 봉인·종료 후 정리 검사도 모두 정상이다.

## 판단 범위와 후속 비교

이번 결과는 발견한 입력·초기화 문제를 고치고 보상 비교 조건을 정상 실행할 수 있음을 확인한다. 2~6회 업데이트로 장기 수렴, 손가락 자연스러움, 엄지 지지, 압현 성능 향상을 주장하지 않는다. H32와 H128 및 corrected와 combined는 샘플 수부터 다르므로 이 작동 검사로 우열을 정하지 않는다.

다음 성능 비교에서는 같은 초기 상태·악보·seed 집합·총 전이 수를 사용한다. corrected를 기준으로 preparation, full_hold를 따로 비교하고 유효한 변경만 조합한다. 탐색 중 기타 이탈이 준비 구간을 얼마나 소모하는지와 보상·종료 비용의 상대 크기도 함께 확인한다. 기존 학습률과 감점 계수를 추가로 동시에 바꾸지 않는다.
