압현 보상 구조
    기준
        2026년 11월 4일 확인한 compact press v4의 combined 설정 기준
        기존 v3의 압현 판정과 동시 압현 유지 구조에 대기 시점, 대기 자세 품질, 목표 접근, 줄 정렬 개선을 적용한 별도 실험 경로
        구현과 실행 검증은 완료했으며, 장기 비교 학습을 통한 성능 향상은 아직 검증하지 않음

    공통 기준
        물리 측정은 초당 240회, 정책 행동과 최종 보상 전달은 초당 60회
            지속 보상은 실제 경과한 물리 시간에 비례하여 적분하고, 물리 4회분을 한 제어 주기에서 합산
            목표 패드 접근과 행동 변화는 제어 주기마다 계산
        목표 패드 접근은 압현 시작 전 준비 구간부터 적용하며 실제 대기 가중치에 따라 조절
        압현 시작 시각부터 음 종료 시각까지는 최초 접촉의 연속 유지 시간을 평가
        음 시작 시각부터 음 종료 시각까지는 압현 유지, 달성, 오압현, 음 수행 부족을 평가
        음 길이 D는 음 시작부터 종료까지의 시간
        음별 가중치 b는 선택한 전체 목표 수를 등장 손가락 수와 해당 손가락의 목표 수의 곱으로 나눈 값
            목표 수가 적은 손가락도 학습에 기여하도록 균형을 맞춤
            목표 패드 접근, 최초 접촉, 압현 유지, 압현 달성, 오압현, 음 수행 부족에 적용
            아래 음별 점수와 예산에는 b를 곱함
        유효 압현은 지정 손가락 패드가 목표 줄과 프렛 셀의 기하 조건 및 하중 조건을 만족하고 오압현이 없는 상태
            지정 손가락 끝마디의 굽힘 방향 표면에서 128개 점을 측정
            같은 점에서 프렛 셀 안쪽 영역, 목표 줄 횡거리 3mm 이내, 압현 평면 기준 높이 마이너스 1mm부터 플러스 3mm까지, 표면 방향 코사인 0.1 이상을 확인
            해당 끝마디의 접촉 합력 크기 0.01N 이상을 확인
            실제 현 압력이나 소리를 측정한 판정이 아니라 표면 기하와 몸체 접촉 합력에 기반한 판정

    목표 패드 접근
        목적
            담당 손가락 패드를 목표 줄과 프렛으로 이동시키고, 표면 위에서 정렬한 뒤 압현 위치로 접근하도록 유도
        지급 방식
            매 제어 주기마다 접근 품질의 변화량을 지급
            보상은 0.99 곱하기 다음 접근 품질에서 현재 접근 품질을 뺀 값
            접근 품질을 잠재값이라고 하며, 가까이 머무르는 것만으로 매번 큰 양의 보상을 받는 구조는 아님
            실제 종료 시 다음 잠재값은 0으로 처리하고, 학습 자료 수집 구간이 끝나는 것만으로는 0으로 만들지 않음
        계산 대상
            손가락마다 선택한 목표 1개씩, 검지부터 소지까지 최대 4개를 사용
            목표가 없거나 표면 측정이 무효인 손가락은 기여하지 않음
            실제 대기 자세 가중치가 1이면 접근 가중치는 0, 대기 가중치가 0이면 접근 가중치는 1
        접근 품질
            거리 d에 대해 0.5 곱하기 exp(-d/0.08)과 0.5 곱하기 exp(-d/0.03)을 더함
            거리 단위는 m이며, 먼 거리와 가까운 거리의 접근 신호를 함께 사용
            표면 방향이 맞지 않으면 목표 근처 2cm에서 품질을 최대 20퍼센트 낮춤
            준비 위치는 목표 프렛 셀 안에서 압현 평면보다 4mm에서 8mm 위에 있는 영역
            압현 시작 0.2초 전부터 준비 영역의 품질을 표면 접근 품질로 부드럽게 전환
        목표 줄 정렬
            목표 프렛 위치에서 실제 인접 줄 간격을 측정
            횡방향 허용폭은 3mm와 인접 줄 간격의 4분의 1 중 작은 값
            허용폭 밖의 횡오차가 클수록 목표 근처 3cm에서 접근 품질을 추가로 낮춤
            추가 정렬 계수는 0.5부터 1까지이며 별도의 보상이나 강제 정지 조건을 추가하지 않음
        점수 해석
            가중치를 곱하기 전 목표 하나의 잠재값 상한은 1
            잠재값 상한 1은 해당 음에서 받는 누적 접근 보상의 한도가 1이라는 뜻은 아님
        로그 이름
            song_left_approach

    최초 접촉
        목적
            목표를 처음 유효하게 누르고 짧은 시간 연속으로 유지하도록 유도
        지급 방식
            압현 시작부터 음 종료까지의 구간에서 연속 유효 접촉 시간을 측정
            필요한 접촉 시간은 0.05초와 압현 시작부터 종료까지의 시간 중 작은 값
            지금까지 가장 길었던 연속 접촉 시간이 늘어난 만큼 점수를 지급
            진행률이 1에 도달하면 해당 음의 최초 접촉 보상 예산을 모두 사용
            접촉을 끊었다가 다시 눌러도 이전 최고 진행률까지는 추가 점수를 주지 않음
        점수
            음별 최대 0.25 곱하기 b
            최고 진행률 증가분에 비례하여 나눠 받으며, 완료 순간에 별도 보너스를 더하지 않음
        로그 이름
            song_left_contact

    압현 유지
        목적
            실제 음이 나야 하는 구간 동안 올바른 압현을 유지하도록 유도
        지급 방식
            음 시작부터 종료까지 유효 압현을 유지한 시간에 비례하여 지속 지급
            인접한 두 물리 측정 시점 모두에서 유효 압현일 때 그 사이 시간을 인정
            단일 목표의 보상은 1.0 곱하기 b 곱하기 유효 유지 시간 나누기 D
            음 길이로 나누므로 긴 음이라는 이유만으로 한 음의 전체 예산이 커지지 않음
        동시 압현
            두 개 이상의 목표가 겹치는 구간은 유지 보상 예산의 절반을 개별 압현에, 절반을 모든 목표의 동시 압현에 배분
            일부 손가락만 유효하면 해당 손가락의 유지 보상은 절반만 지급
            모든 목표를 동시에 유효하게 누르면 원래의 전체 유지 보상을 지급
            동시 압현이라는 이유로 총 예산에 추가 보너스를 더하지 않음
        점수
            전체 음 길이를 조건에 맞게 유지하면 음별 최대 1.0 곱하기 b
        로그 이름
            song_clean_hold

    압현 달성
        목적
            일정 시간 끊기지 않고 올바르게 누르는 데 성공한 사건을 보상
        지급 방식
            음 시작 이후 연속 유효 압현 시간이 달성 기준에 처음 도달하는 순간 한 번 지급
            접촉이 끊기면 현재 연속 시간은 초기화하며, 이미 받은 달성 보상은 다시 지급하지 않음
        달성 기준
            기본값은 음 길이의 40퍼센트와 0.05초 중 큰 값
            음 자체가 그보다 짧으면 전체 음 길이를 사용
        점수
            음별 0.25 곱하기 b
        평가 기준과의 구분
            이 보상은 전체 음 길이의 완벽한 수행을 의미하지 않음
            v3와 v4의 엄격한 곡 성공 평가는 각 음 전체와 동시 압현 구간 전체의 연속 유지를 별도로 요구
            해당 곡이나 선택 구간을 물리 및 손목 실패 없이 끝까지 진행해야 엄격한 성공으로 인정
        로그 이름
            song_left_success

    오압현
        목적
            현재 음을 방해하는 잘못된 줄, 프렛, 손가락 접촉을 줄임
        감점 방식
            음 시작부터 종료까지 오압현으로 판정된 시간에 비례하여 지속 감점
            담당 손가락의 잘못된 줄이나 프렛, 같은 줄에서 다른 손가락이 더 높은 프렛을 누르는 간섭 등을 판정
            원인이 여러 개 검출되어도 같은 목표의 같은 시간을 원인 수만큼 중복 감점하지 않음
            준비 구간 자체에는 이 항의 감점이 없지만, 다음 목표 준비가 현재 울리는 음을 방해하면 현재 음의 오압현으로 감점
        점수
            마이너스 0.15 곱하기 b 곱하기 오압현 시간 나누기 D
            음별 최대 감점 크기는 0.15 곱하기 b
        로그 이름
            song_wrong_press

    음 수행 부족
        목적
            목표 음을 누르지 못하거나 충분히 연속 유지하지 못한 정도를 하나의 항으로 평가
        감점 방식
            음이 진행되는 동안 누락 시간이 늘어난 만큼 먼저 감점
            누락은 유효 압현도 오압현도 없는 상태이며, 오압현 시간 자체를 누락 시간에 다시 더하지 않음
            음이 끝나면 누락 비율과 연속 유지 부족률 중 큰 값으로 최종 정산
            누락 비율은 누락 시간 나누기 D
            연속 유지 부족률은 1에서 최장 연속 유지 시간 나누기 압현 달성 기준 시간을 뺀 값
            각 비율은 0부터 1 사이로 제한
            이미 지급한 감점에서 추가로 필요한 차액만 청구
        점수
            최종 감점 크기는 0.10 곱하기 b 곱하기 두 부족률 중 큰 값
            음별 최대 감점 크기는 0.10 곱하기 b
            오압현 감점과 이 항은 함께 발생할 수 있지만, 누락과 미달성 감점을 별도 항으로 중복 합산하지 않음
        로그 이름
            song_performance_deficit

    대기 자세
        목적
            당장 압현할 필요가 없는 손가락이 사용자가 선택한 B 자세 근처에 머물도록 약하게 권고
        적용 대상
            검지부터 소지까지 손가락별로 독립 적용하며 엄지는 제외
            손가락의 실제 기하 굽힘각으로 평가하며 목표 관절각을 강제로 주입하지 않음
        대기 자세 기준
            손바닥과 연결된 시작 마디, 가운데 마디, 끝마디 순서의 굽힘각
            검지 약 25.49도, 35도, 12도
            중지 약 28.02도, 38도, 14도
            약지 약 31.03도, 41도, 16도
            소지 약 34.33도, 44도, 18도
            기준 각도와의 차이가 시작 마디는 30도 이내, 가운데와 끝마디는 10도 이내이면 동일한 최대 품질
            허용 범위 밖 초과각을 15도로 나눈 값들의 제곱 합에 1을 더하고 역수를 취해 품질을 계산
            시작 마디의 벌림 각도는 별도로 보상하지 않음
        적용 시점
            해당 손가락의 압현 시작부터 음 종료까지는 대기 보상 가중치 0
            음 종료 후 0.05초를 기다린 뒤 0.1초에 걸쳐 대기 가중치를 높임
            일반적으로 다음 압현 0.45초 전부터 대기 가중치를 낮춰 0.35초 전에 0으로 만듦
            이전 음 종료부터 다음 압현 시작까지의 간격이 0.25초 이하이면 대기 자세를 거치도록 유도하지 않음
            간격이 0.25초부터 0.6초 사이이면 대기 가중치를 부분적으로 적용하고 준비 시간을 간격의 40퍼센트로 조절
            선택한 구간의 가장 이른 압현 목표 묶음은 초기부터 각 목표 종료까지 준비를 보호
            이후 목표는 미리 관측할 수 있어도 노출됐다는 이유만으로 대기 보상을 즉시 끄지 않음
        지급 방식과 점수
            손가락별 초당 0.005 곱하기 대기 가중치 곱하기 자세 품질
            네 손가락 합계 최대 초당 0.02
            별도의 자세 벌점은 없으며, 자세가 벗어나면 받을 수 있는 양의 보상이 감소
        로그 이름
            song_finger_standby

    엄지 안내
        목적
            엄지 끝마디 표면이 넥 뒤의 적절한 영역으로 접근하고 가볍게 접촉하도록 유도
        안내 영역
            연주용 넥 뒷면의 폭 중앙 50퍼센트
            작업 프렛 중심에서 넥 길이 방향으로 앞뒤 4cm 범위를 사용하며 실제 넥 영역으로 제한
        지급 방식
            넥 뒤 표면과의 간격, 엄지 표면 방향, 안내 영역에서 벗어난 거리를 함께 평가
            표면 간격이 0mm부터 3mm일 때 거리 품질이 최대이며 멀어지면 감소
            과도한 관통은 품질을 낮추고 1mm 이상 관통하면 기하 품질 0
            기하 품질에 초당 0.01을 곱해 지급
            같은 표면 점이 접촉 후보 조건도 만족하면 기하 품질에 초당 0.01을 곱해 추가 지급
        접촉 후보
            표면 간격 마이너스 1mm부터 플러스 0.5mm까지, 안내 영역 안, 방향 코사인 0.1 이상
            엄지 끝마디 접촉 합력의 넥 뒤 법선 방향 성분이 0.01N 이상
        점수
            최대 초당 0.02
            더 강하게 누르는 힘 자체에는 추가 보상을 주지 않음
            이번 v4에서 계수와 판정 기준은 변경하지 않았으며 실제 지지 효과는 별도 검증 대상
        로그 이름
            song_thumb_support

    행동 변화
        목적
            손가락을 제외한 관절에서 정책 명령이 갑자기 바뀌는 것을 완화
        감점 방식
            매 제어 주기에서 이번 행동과 이전 행동의 차이를 비교
            정규화 행동 차이의 절댓값이 0.05 이내이면 감점 0
            0.05를 넘는 부분을 제곱하고 관절별 계수를 곱해 합산
            합산값을 39와 60으로 나눈 크기만큼 감점
        적용 범위
            왼손 엄지를 포함한 손가락 21축의 계수는 0
            왼손 손목 3축의 계수는 초당 0.0025
            나머지 활성 비손가락 축의 계수는 초당 0.01
            정책 출력은 33축이며 기존 환경의 39축 행동 공간에 넣어 계산하므로 정규화 분모 39를 유지
            실제 관절 속도, 힘, 손가락 이동 거리 자체에 부과하는 비용은 아님
        로그 이름
            action_change

    조기 종료와 별도 비용
        목적
            연주를 포기하고 일찍 종료하는 행동이 남은 음의 감점을 피하는 수단이 되지 않도록 함
        종료 조건
            기타 이탈, 발 위치 이탈, 지지 접촉 상실, 비정상 관절 속도나 상태, 지지 제어 무효 등 기존 물리 실패
            손목 허용 영역 밖 거리의 최대 축 성분이 3cm를 초과한 누적 시간이 1.5초에 도달
                일반 손목 감시는 초기 준비 3초 이후 시작
                2cm부터 3cm 사이로 돌아오면 누적 시간을 줄이고 2cm 이내에서는 초기화
            손목 허용 영역을 10cm 이상 벗어난 상태가 연속 0.1초 지속
                심한 이탈 감시는 초기 준비 구간에도 적용
        비용
            기본 5에 남은 에피소드 시간 곱하기 초당 2를 더함
            미정산 음에 남아 있는 오압현 예산과 아직 청구하지 않은 음 수행 부족 예산을 더함
            물리 실패와 손목 실패가 겹쳐도 에피소드당 한 번만 청구
            실패가 발생한 제어 주기의 양의 보상은 지급하지 않고 이미 관측한 감점과 종료 잠재 차분은 유지
        학습 반영
            종료 비용은 위 9개 보상의 합계와 별도 비용 채널에 저장
            PPO는 보상과 비용의 예상 이득을 함께 사용하며 기본 비용 가중치는 1
            따라서 보상 합계만으로 종료 비용까지 포함한 학습 신호를 해석하면 안 됨
        정상 종료
            곡이나 선택 구간을 끝까지 진행한 정상 종료에는 실패 비용을 부과하지 않음
            학습 자료 수집의 32스텝 경계는 에피소드 종료가 아니며 유지 시간과 대기 통계를 이어감

    별도로 더하지 않는 항목
        표면 접근과 손가락 추종을 각각 중복 지급하지 않음
        누락과 미달성을 독립 감점 항으로 다시 더하지 않음
        손목 안내의 위치 보상과 평상시 물리 안전 비용은 별도 지속 항으로 더하지 않음
        손가락 움직임 비용과 압현 중 자세 비용은 0
        과신전, 시작 마디 편중, 끝마디 편중 진단은 로그에 남기며 보상이나 종료 조건에는 사용하지 않음

    v4 비교 설정
        baseline은 기존 v3 보상을 기준으로 사용
        timing은 실제 대기 시점과 상보적인 접근 가중치만 변경
        posture는 대기 자세의 허용 범위와 범위 밖 품질 감소만 변경
        reach는 원거리와 근거리의 거리 품질 혼합만 변경
        alignment는 줄 간격 기반의 근거리 정렬만 변경
        combined는 위 네 가지 변경을 함께 적용하며 이 문서의 설명 기준
        모든 v4 설정에서 실제 대기 보상 기준으로 로그를 보정하며 무효 또는 비유한 접근 측정의 양의 잠재값은 0으로 처리
