# 압현 v5 구조 개선

구현일: 2026-11-04. 사용자가 지정한 실험 분류 경로인 `2026-11-09` 아래에 저장한다.

[v4 구조 점검](../압현_보상개선_v4/구조점검_20261104_1128/REPORT.md)에서 확인한 탐색 초기값과 관측 누락을 고치고, 보상 변경은 독립 비교할 수 있도록 구현한다. v4 코드·모델·결과는 보존한다. 이번 작업의 목적은 계약과 실행의 정확성 검증이며, 장기 학습 성능 향상의 증명은 아니다.

## 공통으로 적용한 변경

| 대상 | 이전 | v5 |
|---|---|---|
| 초기 탐색 | 모든 33축의 표준편차 약 0.0498 | 팔 12축·엄지 5축 0.15, 검지~소지 16축 0.35 |
| 대기 맥락 | 입력에 드러나지 않는 구간 밖 회복 목표가 대기 가중치를 바꿀 수 있음 | 실제 대기 가중치 4개, 다음 회복 목표의 압현 시작까지 시간 4개, 유효 여부 4개를 추가 |
| 남은 음 감점 예산 | 16.75가 관측 상한 10으로 잘림 | 전체 악보의 최대 음 예산 `0.25 × 목표 수`로 나눠 고정 척도로 표현 |
| 목표 속도 | 부호 설명이 불분명 | 기타 기준 선택 패드 점의 상대속도에 마이너스를 붙인 값으로 명시 |
| 프렛 범위 | 14로 정규화하면서 15 이상도 허용 | 1~14프렛 밖의 입력을 거부 |
| 완료 평가 | 전체 음 유지와 해제를 구분하기 어려움 | 전체 유지·해제·두 조건의 완료 성공을 별도 기록 |

탐색 값은 정규분포의 표준편차이고 관절각 단위가 아니다. 분포에서 뽑은 행동은 tanh와 기존 목표각·속도 제한을 거친다. 초기화에만 지정값을 사용하며 학습 중에는 표준편차도 학습한다. 재개할 때는 저장된 학습값을 그대로 복원한다. 공용 실행기의 추가 초기화 이동은 0으로 고정해 두 번 적용되지 않게 한다.

새 관측이 발견된 숨은 대기 맥락을 제공한다는 뜻이며, 모든 내부 상태가 완전히 관측되는 상태가 됐다고 주장하지 않는다. 다음 압현 시간은 전체 악보 길이와 1초 중 큰 값으로 나누며, 유효 목표가 없으면 시간과 유효 여부를 모두 0으로 준다.

## 보상 비교 조건

| `--improvement-profile` | 준비 접근 | 달성·연속 유지 부족 기준 |
|---|---|---|
| `corrected` — 기본 | v4 combined 유지: `1 - 대기 가중치` | 음 길이의 40%, 최소 0.05초, 음 길이 이하 |
| `preparation` | `1 - 0.90 × 대기 가중치` | 기본과 동일 |
| `full_hold` | 기본과 동일 | 음 전체 길이 |
| `combined` | preparation과 동일 | 음 전체 길이 |

`corrected`는 공통 오류 수정을 반영한 비교 기준이다. `preparation`은 미리 노출된 목표의 접근 신호를 대기 중에도 10% 남긴다. 목표가 없는 손가락에게 보상을 새로 주는 것은 아니다. `full_hold`는 달성 보너스·수행 부족·목표 입력의 필요 유지 시간을 함께 바꾼다. 각 항의 예산, 중복 지급 방지, 종료 비용은 유지한다. 기존의 엄격한 전체 유지 지표도 유지해 조건 간 비교에 쓴다.

두 보상 변경을 구현했다는 사실과 성능이 개선됐다는 결론은 구분한다. 먼저 corrected와 preparation을 비교하고, 같은 조건에서 full_hold를 비교한 뒤 combined를 평가하는 순서를 권장한다.

## 유지와 해제 평가

에피소드의 `press_completion`에 `full_hold_success`, `release_success`, `completion_success`를 분리 기록한다. 기존 `song.stage_success`는 v3부터의 전체 유지 기준을 보존하며 해제 포함 성공을 뜻하지 않는다.

해제는 음 종료부터 0.1초 안에 **목표 패드 접촉 후보가 사라지는 전이**를 관측했는지로 평가한다. 기하·방향·하중 조건을 만족하던 후보의 소실이며, 손가락과 기타가 물리적으로 완전히 떨어졌음을 보증하지는 않는다. 오압현 때문에 유효 압현만 꺼진 경우는 새 해제로 인정하지 않는다. 같은 줄·프렛·손가락의 연속 목표 사이에서 원래 악보가 중간 해제를 요구하지 않는 경우는 예외다.

음별 상태는 `not_required`, `released`, `pending`, `missed`, `aborted`로 기록한다. 아직 해제 기한이 지나지 않은 경우와 실패로 평가가 중단된 경우를 성공으로 처리하지 않는다. 유지·해제 성공 모두 선택한 시간축의 안전한 완주가 필요하고, 두 조건을 함께 만족한 경우만 완료 성공이다. 이 항목은 별도 평가이며 해제 보상이나 종료 조건을 새로 추가하지 않았다.

## 학습 구조

- 상태 464차원, 선택적으로 골반 9차원을 더하면 473차원. v4의 452/461차원에 대기 맥락 12개를 추가했다.
- 상태 인코더 256 → 256, 목표 26차원씩 8개에 공유 목표 인코더 64 → 64.
- 결합 입력 `256 + 64 × 8 = 768`, 행동망 768 → 512 → 256 → 33.
- 가치망은 행동망과 분리하며 768 → 256 → 256 뒤 보상·종료 비용의 두 출력을 사용한다.
- 왼손 33축 정책, 기존 유한 전신 지지 제어, root 고정·자유 기타 조건을 유지한다. 세 정책의 통합 학습은 아니다.
- 손가락 목표각 직접 제어와 이동 비용 0을 유지한다. 기본 수집 길이는 H32이고 H128 선택도 검증한다.

H32와 H128을 성능 비교할 때는 반복 수만 같게 두지 말고 총 수집 전이 수와 곡 노출 일정을 맞춰야 한다. 동일 반복 수이면 H128이 네 배 많은 샘플을 수집하기 때문이다.

v5 모델만 v5 실행기로 읽는다. 초기 탐색 설정·프로필·입력·코드·전체 신경망 계약이 다르면 재개를 거부한다. 기존 체크포인트를 새 구조로 자동 변환하지 않는다. `--size large`는 기록용 선택이며 이 경로의 신경망 폭은 위 값으로 고정이다.

## 실행

새로 만든 C1~C6 연속 합성 목표는 [v5 목표 연결 안내](../압현_v5_합성목표연결_v1/README.md)의 `press_sequence` 실행기를 사용한다. 원본의 동시 압현 시각을 보존하는 입력 연결을 포함한다. 아래 명령은 기존 곡 번들 실행 경로다.

다음은 기본 corrected 조건의 새 학습 예시다. 반복 수와 환경 수는 실험 계획에 맞춰 지정한다.

```bash
/home/ajou/miniconda3/envs/rl38/bin/python scripts/tab2body.py --cache-root .runtime/cache run -m guitar_learning.tool.experiments.compact_press_v5 train --out docs/2026-11-09/압현_구조개선_v5/실험/corrected --size large --num-envs 1024 --horizon 32 --updates 1000 --improvement-profile corrected
```

비교 조건은 `--improvement-profile preparation`, `full_hold`, `combined`로 선택한다. 재개 시에는 저장된 프로필과 초기 탐색 설정을 유지한다. 실제 검증 명령은 [실행 명령](검증/실행명령.txt)에 기록했다.

## 검증 결과

기존 188개와 새 23개, 총 **211개 CPU 검사** 및 독립 검수를 통과했다. GPU에서 corrected 4회 학습과 추가 2회 재개, combined H128 2회 학습, 전곡·구간 평가 각 2회를 완료했다. 모델 SHA·입력·신경망 계약·재개 가중치 보존을 확인했다.

결정적 평가 4회는 모두 물리·손목 실패 없이 시간축을 완주했지만 압현 달성은 0이었다. 이번 반복 수는 작동 검사 수준이다. 학습 중 탐색에는 기타 이탈 종료가 있었으며, 보상 조건의 성능과 안정성은 후속 비교 학습에서 확인해야 한다.
