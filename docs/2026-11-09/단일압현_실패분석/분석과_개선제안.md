# 단일 압현 준비·압현 실패 분석과 개선 제안

336조합 본검사 기준: 성공233, 준비실패90, 압현실패12, 검사오류1. 오류 재검사는 GPU 유휴 대기 중이다. 이 자료는 새 학습이 아닌 기존 로그·코드의 읽기 분석이다. 현재 실행 소스와 실험 입력은 변경하지 않았다.

## 준비 실패: 실제로 무엇이 실패했는가

- 준비 시간 초과61: 최종 준비 조건 미충족. 현행 조건은 패드 높이5~15mm, 접선오차5mm 이하, 방향cos0.1 이상, 손목속도5cm/s 이하를 경로 도착 후0.5초 유지하는 것이다.
- 준비 중 오압현17: 모두 검지 조합이다. 어느 손가락/몸체가 원인인지는 현재 요약으로 확정하지 못한다.
- 기타 이탈8: 실제 안전 판정 guitar_displacement. 충돌 경로와 끝 자세의 실현성은 구분해야 한다.
- 손목 보통 범위 이탈4: ordinary_outside 누적1.5초 기준.

90실패 중 최종 측정 높이15mm 초과73, 5~15mm 안17. 이 값은 종료 시점 관측이며 높이만이 독립적인 실패 원인이라는 증거는 아니다. 접선오차·방향·속도·ready 조건별 여유와 선택 표면점의 변화는 기존 준비 trace에 충분히 남지 않는다.

코드의 준비 탐색은 팔12축만 변경하고 손가락은 공통 준비각으로 둔다. 즉 손가락까지 조금 정렬하면 가능한 목표도 팔만으로 준비 영역에 넣지 못하면 실패한다. native 운반은 시작과 hover의 직접 경로 한 개로, 정적 끝 자세 충돌검사와 전체 경로 안전은 다르다.

## 압현 실패: 위치와 유지가 다르다

12실패 모두 timeline_complete이며 물리실패 종료가 아니다. 오압현 시간은 모두0이다. 소지10, 중지1, 약지1이다.

- 약지6번줄4프렛과 소지6번줄10프렛은 60Hz 음 구간 담당 끝마디 하중0/90이다. 패드 거리만 가까워도 현행 접촉 조건은 만족하지 못한다. 실제 접촉 상대는 net body force만으로 확정할 수 없다.
- 소지1번줄1프렛은 담당 몸체 하중90/90이지만 측정 패드 접선오차 중앙값5.34mm·높이5.12mm다. 하중만으로 목표 줄 압현이 인증되지 않는다.
- 소지6번줄12프렛은60Hz clean33.3%,240Hz 원장13.3%다. 일시 접촉 후 하중 유지가 부족하다.
- 중지1번줄1프렛은60Hz clean97.8%지만240Hz 원장85.0%, 소지6번줄5프렛은97.8% 대93.3%다. 60Hz 끝점 샘플을 연속 유지 성공으로 해석하면 안 된다. 성공 판단은240Hz 음별 원장을 유지한다.

현재 도착 실측으로 FK를 보정하고 후보3개를 탐색하지만, 관절각 변화가 가장 작은 후보1개만 실행한다. 압현 중 손목 피드백과 관절PD는 존재한다. 다만 손가락은 고정 목표각 램프이며 패드 높이·위치·하중 오차를 이용해 목표각을 재계획하지 않는다.

## 개선 순서: 원인별 단독 비교

1. 계측 보강: 준비의 조건별 pass/여유, 실제/목표 손목 자세·속도·관절각오차, 접촉 발생 몸체, 240Hz 유효 패드 기하·하중·wrong·clean·최장연속 유지·최초 유효 접촉 시각을 기록한다. net force를 실제 줄 압력으로 표기하지 않는다.
2. 준비 자세만 변경: 팔12축+목표 손가락4축을 함께 정렬하되 준비 중 무압현·안전 조건은 유지한다. 정확한 한 점보다 준비 영역 안에서 관절·충돌 여유가 큰 자세를 선택한다. 다른 조건은 유지하고 기존 실패 대표 조합과 성공 대조군을 비교한다.
3. 운반 경로만 변경: 검지 오압현17과 기타 이탈8의 대표에 넥 바깥 안전 경유점→최종 준비 영역의 경로를 적용한다. 끝점과 경로 모두 물리 검증하며 준비 단계 접촉 금지와 전환 중 유지해야 할 음을 구분한다.
4. 압현 후보 선택만 변경: 최소 관절변화 대신 목표 패드 허용영역·관절한계·비담당 접촉 여유를 평가한다. 후보 비교는 새 시도에서 독립 실행하며 최고만 남기지 않고 전체 분모를 보존한다.
5. 유지 보정만 변경: 최초 접촉 전 패드 위치, 접촉 후 기하+담당 하중에 따라 작은 범위의 손가락 목표각 보정을 비교한다. 위치만 보고 계속 더 굽히지 않으며 최대각·속도·충돌·오압현·안전 제한을 유지한다. 성공 임계값은 완화하지 않는다.

정확한 보정량·이득은 현재 로그만으로 정하지 않는다. 신규 native 진단에서 작은 유한 각도 변화에 대한 패드·하중 반응을 확인하고 결정한다. 진단용 보정기의 성공을 정책 자체의 학습 성공으로 합산하지 않는다.

## 복잡한 목표로 확장하는 조건

- 단일 목표의 같은 초기 조건 반복과 작은 초기 변동에서 준비·유지 재현성 확인.
- A와B의 독립 성공뿐 아니라 A→해제/필요음 유지→이동→B의 경로와시간 확보를 검증.
- 중지3번줄6→8프렛(거리), 중지3번줄6→1번줄6프렛(줄), 이후 줄+프렛과손가락 변경 순으로 분리.
- 다중 압현은 손가락별 준비 상태를 분리하고 손목은 공통으로 계획한다. 현재 유지 중인 음을 깨면서 새 손가락을 정렬하지 않도록 충돌·유지 조건을 함께 검사한다.
- 단음 진단의 준비 무접촉 규칙을 전환 전체에 그대로 적용하지 않는다. 의도한 지속 음과 의도하지 않은 접촉을 구분한다.

원시 근거는 근거수치.json과 각 report/episode/trace를 참조한다. 준비 실패는 물리적 불가능 판정이 아니며, 전체 학습 구조나 보상 설계의 실패로 직접 확대할 수 없다.
