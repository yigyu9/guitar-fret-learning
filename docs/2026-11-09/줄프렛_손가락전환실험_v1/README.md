각 조건은 독립된 새 정책으로 large·64환경·H32·100업데이트·seed7을 학습한다. 마지막 모델을 평균 행동16환경으로 평가하고, 환경0의 손·전신 영상을 기록한다. 처음 비교는 한 난수이므로 안정적 수렴·다른 초기 상태 일반화의 증명이 아니다. 전환은 음당1.5초와 중간 휴지1초를 사용한다.

기존613관측·손가락별 진행 상태·E4·J33·직접 목표각·9개 보상과 물리/손목 종료를 사용한다. 모든33축을 정책이 제어한다. 공식 초기 구간25%→전곡 일정과 SHA·입력·PPO identity·엄격 재개를 유지한다. 별도 진단용 IK·패드 보정을 학습 정책에 숨겨 넣지 않는다. 가상 목표의 오디오는 시계용 무음이며 실제 소리를 생성하거나 측정하는 실험은 아니다.

6개 번들의 목표·줄 번호·시각·원본 단일 압현 근거는 `입력/manifest.json`에 있다. 네 끝점은 과거 native 단일 압현을 통과했지만 A→B 경로와 제한 시간 내 전환은 아직 별도로 검사해야 한다.

GPU 시작 전 학습2회→엄격 재개1회→평가2환경→실제 영상1환경을 검증한다. 첫 검증에서 초기 분산 속성 연결 오류가 발견되어 `검증/train2/`에 보존했다. 실험용 adapter에서 기존 core Parameter를 그대로 노출해 수정했고, 원래 정책 소스·저장 키는 바꾸지 않았다. 최종 실행 검증 근거는 `검증/GPU_실행검증.json`이다.

자동 실행기는 조건별로 학습→평가→영상 순서로 진행한다. 각 작업 전후 입력·소스 SHA, 완료 보고서와 물리 정리 여부를 확인한다. 실행 오류는 과제 성능 실패와 구분하며 다른 조건은 계속 진행한다. 연구 중 코드가 바뀌면 중단해 서로 다른 버전 결과가 섞이지 않도록 한다. 실행 중이던 작업이 중단됐을 때도 기존 산출물을 덮어쓰지 않고 새 시도에 보존한다.

목표별 안전 달성·전체 안전 달성·음 전체 길이 유지·240Hz clean/최장 연속 유지·오압현·물리/손목 종료·보상 항별 평균을 기록한다. 실패 환경도 평가 분모에 포함한다. 안전 실패 에피소드의 원시 달성 latch는 별도 값이며 안전 성공에 합산하지 않는다.
