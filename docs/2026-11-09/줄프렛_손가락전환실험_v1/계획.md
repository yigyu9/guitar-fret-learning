# 줄·프렛 변경과 손가락 전환 실험 v1

사용자의 실험 진행 승인에 따라 수행한다. 기존 학습·결과·봉인 파일은 수정하지 않는다. 모든 새 자료는 이 디렉토리에 기록한다.

1. 실행 검증: 새 native 기준/패드 보정 검사,613정책 소규모GPU학습·엄격재개·평가·영상 확인.
2. 단일 목표: 중지3번줄6프렛 대조, 중지1번줄8프렛, 약지2번줄7프렛.
3. 전환: 중지3번줄6→3번줄8프렛, 중지3번줄6→1번줄8프렛, 중지3번줄6→약지2번줄7프렛.
4. 각 경우 large64/H32/100업데이트/seed7의 독립 새 정책을 학습하고 평균 정책16에피소드 평가 및 손·전신 대표 영상을 저장한다. 첫 비교는 단일 난수이므로 일반화나 학습 안정성 인증이 아니다.

각 음1.5초, 전환 휴지1초, 처음준비3초/마지막0.5초. 총6개가설별번들;훈련204800전이씩, 합계1228800전이. 실제 수집·폐기·종료 상태는 보고서의 수치를 우선한다.

현재 공식613상태 J33·손가락별 E4 준비·직접각 제어·기존9보상/종료를 사용한다. 진단용 IK/패드 보정을 정책 행동에 숨겨 넣지 않는다. 목표마다 독립된 정책으로 비교하고 구형557/601 모델을 이전하지 않는다. 공식 초기구간25% 뒤 전곡 일정과SHA·PPO identity·재개 검증을 유지한다.
