# 준비·압현 진단 개선 계획

사용자의 개선 진행 승인에 따라 새 도구에서 작업한다. 기존 학습·검사·봉인 입력은 수정하지 않는다. 정책 학습이나 생산 기본값 변경은 범위 밖이다.

- [x] 팔12+담당 손가락4축 공동 준비 정렬 및 경로 검사
- [x] 준비 조건별 계측과240Hz 접촉 진단
- [x] 접촉·관절 여유 기반 압현 후보 선택
- [x] 유한 손가락 오차 피드백의 독립 비교 옵션
- [x] CPU 수학·범위·비담당 관절 보존·실패 조건 검사
- [x] 독립 검수
- [ ] GPU가 사용 중이면 경합 없이 GPU 검증을 대기하고 미검증 범위를 명시

단독 비교 조건: baseline / joint_prepare / safe_route / robust_candidate / pad_feedback. 조합 실험은 단독 변경을 검증한 뒤 별도 설정으로 실행한다. 기준 성공 임계값과안전 종료를 완화하지 않는다. 새 소스는완성후SHA를봉인하며현재package의파일을추가·수정하지않는다.

현재 상태: CPU12검사 및 독립 검수 완료. GPU가 다른 학습에서 사용 중이므로 native 실행은 미착수다. 운영 학습에는 아직 적용하지 않았다.
