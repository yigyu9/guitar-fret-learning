# 개선 구현 검증 결과

## 확인한 내용

- 기하·입력·제어 CPU 검사12개 통과. 신규 입력의 조건 identity와 원본 보존 확인.
- baseline의 준비 조건·팔 경유점·quintic 요청각과 저장된 실제 도착 자세에서의 압현3후보 재현.
- 공동 준비의16축/실제 native와행동한계교집합/비담당관절불변, 다른 손가락 변경 거부.
- 같은 유효 패드 표본의 접촉 여유, 관절 범위 여유와 기하 부적합 후보 제외.
- 실측 FK Jacobian의 미소 변위 예측과 실제 FK 이동이1e-8m 이내 일치.
- 패드 보정 총량·변화율·native한계·오압현 hold·비유한입력 거부.

CPU 결과 원문: CPU_통합검사.log. 최종 변경 후 다시 실행한 로그를 기준으로 한다.

## 실제 기하 예시

검지3번줄6프렛에서 팔+담당손가락 공동 정렬은 패드 높이 약19.22mm→9.72mm, 접선오차16.42mm→0.038mm로 개선했다. 그러나 약지3번째몸체와넥의 정적 source shape 간격 조건이 미해결이므로 candidate_valid=false다. 정렬오차 개선을 충돌 없는 준비 성공으로 해석하지 않는다.

## 아직 확인하지 않은 내용

GPU는 다른 채팅의 다중 압현 학습과 기존 오류복구가 공유한다. 이번 새 도구로 native 검증·정책 학습·성과 영상은 실행하지 않았다. 따라서 압현 성공률이나 전환 성공이 개선됐다는 결론은 아직 없다.

다음은 대표7조합·세난수·총60회 단독변경 비교다. 먼저 각 조건1회 실행과 종료 SHA·정리·원장을 확인하고 나머지를 진행한다. GPU를 사용할 수 있을 때 실행해야 한다.

## 최종 경로 검증

중지3번줄6프렛의 정적 경로는 새 명시적 초기근접 계약을 통과했다. 총8개 샘플이며 초기예외는엄지패드/넥 한쌍, 시작간격1.66254mm, 요구여유와실제간격차이의최솟값0이다. 전체연속경로·native물리성공인증은아니다. 초기음수거부와무이동끝점2mm검사도포함했다.

운영활성Python299개와원본진단소스는변경없음을SHA로확인했다. 최종생성입력4개의모든source pin이현재파일과일치한다. 검토기록은독립검수.md,동결목록은최종소스_SHA.json,원본보존검증은보존검증.json을참조한다.

## 후속 실제 GPU 검증

기준 middle_s3_f6과 pad_feedback pinky_s6_f12를 각각1환경/seed7로 실행했고 두 실행 모두 압현 성공·종료SHA·장면정리를 통과했다. 로그는 ../로그/실행검증_baseline_s7 및 ../로그/실행검증_pad_feedback_s7에 있다. 이는 단일 실행 검증이며 전체 개선 성공률이나 학습 성과가 아니다. 다른 조건 및 복잡한 전환의 성과는 후속 비교에서 확인한다.
