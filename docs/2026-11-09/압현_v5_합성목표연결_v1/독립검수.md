# C1~C6 합성 압현 목표 연결 독립 검수

검수일: 2026-11-04. 판정: **문제없음**. 현재 검수 범위에서 미해결 Critical 또는 Warning은 없다.

## 범위

- `guitar_learning/tool/experiments/press_sequence.py`

구현 파일·원본 입력·생성 번들은 수정하지 않았다. 이 문서만 작성했다. CPU 검사는 임시 복사본 또는 테스트 fixture를 사용한다. 기존 소스 전체 보존 감사와 native 실행 검증은 주 작업자가 별도로 수행한다.

## 확인 결과

신규 CPU 검사 21개를 독립 실행하여 모두 통과했다.


실제 C1~C6 번들의 `check_target()`도 각각 통과했다. 모든 번들은 20개 원음·20개 누름을 보존하고 정책 시간축은 47.25초, 60Hz 제어 2,835회다. 각 조합의 10개 음에서 운반용 canonical 시각과 원본 압현 시각의 차이를 보정하며 최대 차이는 약 3.5ms다.

- **줄 관례:** fingering 원본은 `0=low-E`를 유지한다. 최종 목표는 정확히 `5-source_string`으로 변환하며 20개 목표의 줄·프렛·손가락을 원본과 대조한다.
- **시간·식별자:** 기존 canonical/manifest/audio 검증 후 별도 압현 clock 계약으로 onset만 복원한다. 목표 ID·event ID·press·end는 보존하고 schedule의 onset도 함께 갱신한다.
- **구간 구성:** P1~P9의 20음 분할, P7의 한 손가락 연속 유지와 다른 손가락 전환, P9의 해제 후 동일 목표 재압현을 검사한다. 원본 CSV·fingering·chords 세 파일의 바이트 동일성도 검사한다.
- **원본 무결성:** 세 원본 중 하나를 변조하거나 등록 SHA 목록을 제거하면 거부한다. 실행 시 docs 원본 대신 번들 내부의 보존 사본으로 검증할 수 있다.
- **시계 연결:** 설정 생성과 GPU 환경 모듈의 두 task factory 참조에 동일 adapter가 적용된다. 정상 종료·예외·중첩 거부 후 기존 참조가 복원된다. 복원된 목표가 실제 v5 관측·구간 catalog·동시 압현 구간에 전달됨을 확인했다.
- **실행 분리:** 부모는 CPU 인자 처리·검증을 수행하고 native 자식은 Isaac Gym을 먼저 import한다. 쉘 문자열 실행을 사용하지 않으며 원래 v5 인자를 재사용한다.
- **재개·평가·렌더:** 원래 v5의 엄격 checkpoint reader를 먼저 실행한 뒤 등록 번들과 저장 목표를 확인한다. 압현 clock schema·bundle ID·clock SHA·onset mapping SHA를 별도로 요구한다. 조합 변경 및 일반 v5 clock checkpoint의 혼입을 거부한다.
- **봉인:** 기존 `_pins()`가 신규 wrapper·준비 도구와 선택 번들의 모든 파일을 포함하는 CPU 검사가 통과했다. 원래 checkpoint 검증을 약화하지 않는다.

## 한계

이번 검사는 데이터 변환·실행 연결·검증 계약의 정확성에 관한 것이다. CPU fixture가 실제 도달성이나 물리적 압현 성공을 증명하지 않는다. 학습 수렴·성능 향상·각 손가락의 모든 목표 도달 여부는 판단하지 않았다.

무음 WAV와 canonical 타현 계획은 형식과 시간축의 운반·출처 검증용이다. 원본 동시 onset으로 보정한 왼손 목표가 실제 피크의 동시 타현 가능성이나 음악 성공을 보장하지 않는다.

일반 v5 실행기를 직접 호출하면 전용 source clock adapter가 적용되지 않을 수 있다. 합성 목표의 학습·재개·평가·렌더는 `press_sequence` 전용 실행기를 사용해야 한다. 기존 공용 실행기 전체의 직접 호출을 전역 차단했다고 해석하지 않는다.
