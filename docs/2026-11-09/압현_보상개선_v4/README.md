# 압현 보상과 진단 개선

작성일 2026-11-04. 저장 위치는 요청한 실험 분류일 2026-11-09를 따른다.

7시간 compact v2 학습에서는 정책이 검지를 뒤로 펴고 약지 시작 관절을 많이 굽히는 목표각을 선택했다. 검지는 목표에서 멀었고 중지는 다른 줄 접촉, 약지는 다른 손가락에 대한 높은 프렛 간섭이 많았다. 대기 로그가 실제 E4 지급 조건과 다른 문제도 확인했다. [분석 근거](../압현_상태443_목표16/전곡학습_7시간_결합512_v2/손가락자세진단_20261104/REPORT.md).

이번 구현은 기존 compact v3의 상태452 또는 골반 포함461, 목표26×8, 결합768→512→256→33을 기준으로 보상 변경을 비교하는 별도 v4 실행 경로다. v3의 추가 관측과 동시 유지 보상을 고정한다. v2와 v4 결과의 차이를 보상만의 효과로 해석하지 않는다. 기존 구현·체크포인트·원문 로그는 보존한다.

## 비교 조건

v4 모든 조건은 같은 입력·신경망·동시 유지·물리·초기 자세·학습 일정을 사용하며 수정된 진단을 공통 사용한다.

| reward profile | 보상 변경 |
| --- | --- |
| baseline | 기존 v3 보상 그대로, 진단만 보정 |
| timing | 대기 적용 시점과 상보적인 접근 가중치 |
| posture | B 품질의 허용 구간과 감소 척도 |
| reach | 3cm와8cm 거리 품질 혼합 |
| alignment | 줄 간격을 고려한 근거리 정렬 |
| combined | 위 네 변경의 조합 |

단독 조건은 baseline과 비교한다. combined는 개별 결과 확인 후 조합을 평가할 수 있는 구현이며 성능 채택을 의미하지 않는다. 손가락 움직임 비용0, 직접 목표각, 전체 가동범위, 4rad/s, 기존 PD·힘 상한, 최초 접촉·유지·달성·오압현·음 수행 부족·행동 변화·종료 비용은 유지한다. 준비 시점 변경은 최초 음과 짧은 간격을 포함해 검사한다. 대기 품질 변경도 압현 성능에 영향을 줄 수 있으므로 학습 성과는 별도 검증한다.

## 구현된 계산

대기 시점은 기존 음 간격별 release 0.05초, fade 0.1초, 일반 준비0.35초와 짧은 간격의 가변 준비 시간을 재사용한다. timing 조건은 E4의 2초 목표 노출에 따른 추가 대기 차단을 없애고 최초 목표 묶음만 초기부터 보호한다. 접근 잠재에는 `1 - 실제 대기 가중치`를 곱한다. 이는 대기와 접근 적용 시점을 함께 바꾸는 하나의 실험 요인이다.

posture 조건은 B 중심에서 반폭 MCP30도·PIP10도·DIP10도 밖의 초과각으로 `1 / (1 + Σ(초과각/15도)²)`를 계산한다. MCP 반폭을 유지해도 밴드 바깥 점수 곡선은 달라진다. 자세 권고이며 목표각 명령을 주입하지 않는다.

alignment 조건은 목표 프렛 셀의 중앙에서 실제 인접 줄 간격을 측정한다. 압현 평면과 목표 줄에 수직인 방향의 간격을 사용한다. 허용폭은 `min(3mm, 인접 줄 간격/4)`다. 높이4~8mm·프렛 셀 내부 준비 영역은 유지한다. 허용폭 밖 횡오차의 품질은 `1 / (1 + (초과거리/허용폭)²)`이며 목표 근처3cm에서 부드럽게 반영한다. 기존 접근 품질에 곱하는 추가 정렬 계수는0.5~1이다. 줄 정렬에 실패했다고 제어를 멈추거나 새로운 별도 벌점을 더하지 않는다.

진단의 과신전은 MCP<-20도, 시작 관절 편중은 MCP>60도이면서 PIP<45도·DIP<30도, 끝 관절 편중은 DIP−PIP>50도다. 실제 강체의 상대 회전에서 계산한 기하 굽힘각을 사용한다. 문턱은 자연스러움의 검증된 해부학적 기준이 아니며 학습 비용·조기 종료·성공 판단에는 쓰지 않는다.

baseline은 유한 측정에서 기존 v3의 관측·보상·접촉·종료를 유지한다. 무효 또는 비유한 접근 측정의 양의 잠재를0으로 처리하는 방어는 전 프로필 공통 예외다. 종료 비용과 무효 상태 판정은 유지된다.

## 과거 기록을 이용한 확인

대표 환경0의 최초10초 실제 지급 trace2,400행을 재생했다. 교정한 가중 대기 시간은 검지2.469초·중지2.581초·약지0초·소지9.321초이며 원래 지급액은 변하지 않았다. 기존 로그에서 약지의 기회가6초 이상으로 보인 문제를 바로잡는다.

검증된 대표 영상의 강체 자세1,969개를 새 진단으로 확인했다. 검지 과신전97.51%, 약지 시작 관절 편중99.19%를 검출했다. 기존 진단에서 모두0이었던 문제를 재현 자료로 검사한 결과다. 새 학습으로 자세가 좋아졌다는 의미는 아니다.

같은 자세 전체에서 B 품질 평균은 검지0.623→0.297, 중지0.694→0.263, 약지0.894→0.677, 소지0.954→0.640으로 낮아졌다. 이 값은 대기 적용 시간을 곱하지 않은 순수 품질 평균이며 실제 지급액이 아니다. [재생 검증 수치](검증/과거기록_재생검증.json).

## 실행

프로젝트 루트에서 Isaac Gym용 Python 환경으로 실행한다. 새 실행의 기본 조건은 experimental combined이며 아래처럼 비교 조건을 명시하는 것을 권장한다. 층 크기는 고정이므로 size large를 지정해도 구조는 달라지지 않는다.

```bash
python scripts/tab2body.py --cache-root .runtime/cache run \
  -m guitar_learning.tool.experiments.compact_press_v4 train \
  --reward-profile baseline --size large --num-envs 64 \
  --horizon 32 --updates 100 --seed 7 \
  --out runs/compact_press_v4_baseline_01
```

비교할 때 baseline 대신 timing, posture, reach, alignment를 각각 지정하고 출력 경로를 바꾼다. 위100회·64환경은 실행 예시이며 수렴을 보장하는 예산이 아니다. 동일한 학습 표본 수와 seed로 단독 조건을 먼저 비교한다. 기존 v2 체크포인트를 새 보상에 직접 재개하지 않는다.

```bash
python scripts/tab2body.py --cache-root .runtime/cache run \
  -m guitar_learning.tool.experiments.compact_press_v4 evaluate \
  runs/compact_press_v4_baseline_01/J/final.pt \
  --num-envs 16 --out runs/compact_press_v4_baseline_eval_01

python scripts/tab2body.py --cache-root .runtime/cache run \
  -m guitar_learning.tool.experiments.compact_press_v4 render \
  runs/compact_press_v4_baseline_01/J/final.pt \
  --num-envs 16 --out runs/compact_press_v4_baseline_video_01

python scripts/tab2body.py --cache-root .runtime/cache run \
  -m guitar_learning.tool.experiments.compact_press_v4 train \
  --resume runs/compact_press_v4_baseline_01/J/final.pt \
  --updates 100 --out runs/compact_press_v4_baseline_resume_01
```

재개에서 reward-profile을 생략하면 저장된 값을 사용한다. 다른 profile·소스·관측·정책 identity는 거부한다. 원문 소스를 검증 없이 새 것으로 바꾸어 읽지 않는다.

구현은 [환경과 보상](../../../guitar_learning/gpu/compact_press_v4.py), [실행과 엄격 복원](../../../guitar_learning/tool/experiments/compact_press_v4.py) 두 파일이다. 기존 v3 정책을 재사용하며 신경망 구현 파일은 추가하지 않았다.

## 로그 읽기

완결 에피소드는 `J/episodes.jsonl`의 `episode.compact_press_v4`에서 읽는다. 평가 마지막의 live partial 진단을 전곡 결과로 사용하지 않는다.

오압현 출처는 기존 `left_note_ledger.wrong_press_sources`, 약지 벌림축 추종은 기존 `finger_control_diagnostics`, 엄지 간격·영역·접촉 후보는 기존 `left_episode_diagnostics.thumb_support`를 함께 읽는다. 관절별 목표각·실제각과 기하 굽힘각은 서로 다른 측정이다.

v4의 보상 정의는 `training_contract.json`의 `reward.compact_press_v4`가 우선한다. `authority.overrides`에 대체 관계를 명시했고, 상속된 v3 설명6개는 참조용으로 표시했다.
