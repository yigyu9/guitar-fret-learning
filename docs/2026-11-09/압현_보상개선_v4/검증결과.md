# 압현 보상 개선 구현 검증 결과

검증일 2026-11-04. 기존 구현을 보존하고 별도 compact v4 경로에서 대기 시점·대기 품질·목표 접근·줄 정렬을 비교할 수 있도록 구현했다. [수정 내용과 실행](README.md).

## 코드 검증

- 최종 통합 CPU 검사112개 통과, 29.674초. [원문](검증/CPU_통합검사.log).
- baseline은 유한한 동일 입력에서 v3 관측·잠재·항별 보상·종료가 일치했다. 비유한 잠재를0으로 처리하는 부분은 명시적인 공통 예외다.
- 처음 목표 묶음의 준비 보호, 손가락별 대기와 접근 가중치, 부분 reset과 H32 경계, 진짜 terminal의 nextPhi0, 실패 주기의 양의 지급 억제를 검사했다.
- 6개 프로필의 실제 CPU 환경·정책 연결과 PPO 갱신·저장·엄격 복원을 검사했다. 다른 profile·architecture·원문 소스 변경·v2/v3 저장본은 거부한다.
- GPU용 Python3.8 구문 검사와 CLI 도움말을 확인했다. 새 구현2개와 검사2개를 추가했고 기존357개 Python 파일의 SHA256은 동일하다.

## 과거 진단 재생

- 원문 trace2,400개를 실제 진단 함수에 다시 입력했다. 최초10초 약지의 실제 가중 대기 시간이0이라는 점을 확인하면서 기존 원시 지급액은 보존했다.
- 검증된 영상의 실제 강체 자세1,969개에서 검지 과신전97.51%, 약지 시작 관절 편중99.19%를 검출했다. 이는 신규 진단의 검출 확인이며 개선된 학습 결과가 아니다.
- 변경된 B 품질의 점수 차이를 같은 자세로 확인했다. 전체 자세 단순 평균이므로 실제 대기 지급액과 구분한다.
- [재생 수치와 입력 SHA](검증/과거기록_재생검증.json), [재생 방법](검증/replay_diagnostics.py).

## 실제 GPU 작동 검사

RTX4070Ti에서 combined 조건을 사용했다. 신경망·초기 자세·물리·손가락 움직임 비용0은 같은 기준을 유지한다.

| 검사 | 환경과 수행 | 결과 |
| --- | --- | --- |
| 신규 실행 | 8환경·H32·4회 갱신, 1,024개 전이 | 완료, 27.15초 |
| 저장본 재개 | 같은8환경·2회 추가, 512개 전이 | 누적6회 완료, 15.05초 |
| 전곡 평가 | 재개 후 저장본·4환경 | 4개 모두32.817초 곡 종료, 316.90초 |

신규 실행과 재개에서 입력·소스 변경0, 누락된 import 봉인0, 정리 오류0이며 lifecycle 검사가 통과했다. 9개 항별 보상 로그가 모두 저장됐다. 이 짧은 검사는 실행 경로의 정상 작동을 확인한다. 압현 성공률이나 자연스러움 개선을 판정할 학습 예산이 아니다.

평가에서도 입력·소스·정리·lifecycle 검사가 통과했고 물리 종료0·손목 종료0이었다. 4개 완결 에피소드 모두 새 actual_gate_s와 기존 진단의 교정된 gate_weighted_s가1e-10초 이내로 일치했다. 원시 대기 지급량은0.005×손가락별 품질 적분과1e-8 이내로 일치했고, 실제 손가락별 지급 합계와 에피소드 보상 항의 차이는 최대2.90e-6이었다. 보상과 새 진단 수치는 모두 유한했다.

총6회 갱신한 모델의 평균 달성은0/67이다. 이 결과로 개선 효과를 판단하지 않는다. [전체 검증 요약](검증/검증요약.json), [신규 실행](검증/native_train/J/report.json), [엄격 재개](검증/native_resume/J/report.json), [전곡 평가](검증/native_eval/report.json).

## 독립 검수

검수자가 새 실행·환경·검사·과거 기록 재생 방법을 검토했다. 상속된 v3 설명과 새 v4 공식이 혼동될 수 있다는 지적을 보완했다. `authority.overrides`와 참조용 표시를 연결했고, 실제 계산은 변경하지 않았다. 보완 후 미해결 지적은 없다.

## 후속 연구

baseline과 timing·posture·reach·alignment를 동일 입력·신경망·동시 유지·학습 표본 수·seed에서 각각 비교한다. 단독 결과를 확인한 뒤 combined를 평가한다. 기존 v2의7시간 결과와는 관측·동시 유지 조건도 다르므로 보상만의 효과로 해석하지 않는다.

압현 중 새로운 자세 비용, 엄지 후면의 물리적 도달 가능성, 약지 벌림축 추종 원인, 손가락별 출력부 비교는 별도 실험으로 남겼다. 이번 구현에서 강제 관절 결합·목표각 주입·움직임 비용·임의의 PD 변경은 추가하지 않았다.
