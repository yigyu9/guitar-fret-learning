# 압현 학습 속도 개선 방향

상태: 논의 정리. 이 문서에 적힌 개선은 아직 구현·실험하지 않았다.

목적은 환경 수를 늘리지 않고, 같은 실제 시간 안에 유효한 압현·전환 경험을 더 많이 얻는 것이다. 기존 보상·제어를 전면 재작성하기 전에 아래 후보를 개별 비교한다.

## 1. 현재 결과와 문제

중지 3번 줄 5프렛 → 4번 줄 8프렛 과제를 large, 1024환경, H32, seed7로 800회 학습했다. 수집한 환경 전이는 26,214,400개다.

| 학습 시점 | 평균 정책 A 유지율 | 평균 정책 B 유지율 | 두 음 안전 달성 |
| ---: | ---: | ---: | ---: |
| 500회 | 96.89% | 0% | 0/16 |
| 600회 | 96.93% | 0% | 0/16 |
| 700회 | 96.20% | 66.84% | 16/16 |
| 800회 | 97.24% | 84.18% | 16/16 |

유지율은 음 길이 중 올바르게 누른 시간의 비율이다. 두 음 안전 달성은 원장 기준의 연속 유지 조건을 만족했다는 의미이며, 정확한 시작·해제 시각까지 통과했다는 뜻은 아니다. 최종 평균 정책은 엄격한 시각 기준을 통과하지 못했다. 같은 모델의 확률 평가에서는 두 음 안전 달성이 28/64회였다.

500회까지 B 접촉이 없었고, 542회 확률 학습에서 약 0.18초의 첫 부분 압현이 관측됐다. 이후 평균 정책도 성공하기 시작했다. 현재 구조에서도 전환을 학습할 수 있지만, 성공 동작을 처음 발견하기까지 많은 경험이 필요했다.

학습률과 탐색값의 붕괴가 주원인이라는 근거는 없었다. 500회 기준 팔 latent 탐색 표준편차는 초기 0.15에서 약 0.149, 중지는 초기 0.35에서 약 0.342~0.349였다. 초기 상태가 A 근처이므로 A와 먼 B의 학습 난도도 다르다.

## 2. 환경 수만 늘리는 것의 한계

각 환경은 하나의 정책을 공유하면서 서로 다른 행동 잡음을 샘플링한다. 현재 과제에서 탐색하는 축은 왼팔 12축과 중지 4축이다. 매 제어 시점인 약 1/60초마다 잡음을 새로 뽑으므로, 1024환경이 각각 일관된 이동 전략을 탐색하는 구조는 아니다.

빠르게 바뀌는 명령과 속도 제한 때문에 탐색값이 커도 실제 손끝 이동은 작을 수 있다. 따라서 환경 수나 탐색 크기뿐 아니라, 성공 경험의 빈도와 탐색 동작의 시간적 일관성을 개선할 필요가 있다. 이것은 현재 결과에 근거한 가설이며, 별도 대조 실험으로 확인해야 한다.

## 3. 개선 후보

| 후보 | 기존 → 변경 방향 | 기대 효과 | 확인할 점 |
| --- | --- | --- | --- |
| 성공 모델 재사용 | 새 과제마다 처음부터 학습 → 호환되는 성공 모델에서 이어 학습 | 이동·압현 능력 재사용 | 새 목표 적응과 기존 목표 성능 유지 |
| 초기 상태·난이도 혼합 | A 근처에서 먼 B로 전환하는 과제만 반복 → B 가까운 시작과 원래 시작을 혼합하고 어려운 비율 증가 | 접촉·유지 경험을 초반부터 확보 | 쉬운 시작에서만 성공하는지 구분 |
| 시간적으로 일관된 탐색 | 매 시점 독립 잡음 → 일정 시간 지속되거나 상태에 연동되는 탐색 비교 | 팔·손가락의 일관된 이동 발견 | PPO의 행동 확률·우도 계산과 일치하는 구현 필요 |
| 어려운 구간에 경험 집중 | 잘하는 A 구간까지 매번 반복 → B 준비 구간부터 시작하는 에피소드도 혼합 | 같은 시간에 B 도달 시도 증가 | 원래 전체 전환 평가 유지, 물리적으로 유효한 상태에서 시작 |
| 참조 동작으로 초기 학습 | 성공 경로를 탐색으로만 발견 → 검증된 참조 동작을 먼저 모방한 뒤 강화학습 | 첫 성공까지의 탐색 부담 감소 | 실제 관측·실행 가능한 명령 사용, 참조 없는 평가와 구분 |
| 정체에 따른 탐색 조절 | 고정된 초기값과 학습된 표준편차만 사용 → 정체 시 제한적으로 증가 | 어려운 구간에서 탐색 재활성화 | 전체 보상 대신 목표별 거리·접촉·유지 개선으로 판단 |

성공 모델을 재사용할 때는 입력·출력 구조와 목표 표현, 자산·identity가 호환되는지 확인한다. 체크포인트 검증을 우회해 이식하지 않는다. 기존 모델을 쓰는 조건과 처음부터 학습하는 조건은 별도 결과로 보고한다.

시간적으로 일관된 탐색은 실행 행동을 임의로 평활화하는 것만으로 구현하면 안 된다. 실제 샘플링 과정과 PPO가 학습에 사용하는 확률 계산이 맞아야 한다. 참고 연구는 [Smooth Exploration for Robotic Reinforcement Learning](https://arxiv.org/abs/2005.05719)이며, 우리 환경에서의 효과는 미검증이다.

정체 시 탐색을 늘린다면 팔과 손가락을 구분하고, 일부 환경에 먼저 적용하며, 상한과 복구 조건을 둔다. 접촉이 없어도 접근 거리가 줄고 있다면 정체로 단정하지 않는다. 탐색 증가로 물리 실패·오압현이 늘어나는지도 함께 확인한다.

## 4. 제안 실험 순서

1. 다음 목표 학습에서 성공 모델 재사용 효과를 확인한다. 같은 새 목표를 처음부터 학습하는 조건을 기준으로 둔다. 이는 전이학습 효과이며, 처음부터 학습하는 속도 향상과 구분한다.
2. 처음부터 학습하는 조건에서 초기 상태·난이도 혼합만 바꿔 비교한다. 보상·제어·탐색·학습률은 유지한다.
3. 시간적으로 일관된 탐색을 단독 비교한다. 초기 상태 혼합 효과와 먼저 분리한 후 조합한다.
4. 필요하면 B 준비 구간 시작 비율 또는 참조 동작 초기 학습을 추가 비교한다. 초기 상태 혼합과 겹치는 효과가 있으므로 별개 개선으로 중복 계산하지 않는다.
5. 단독 효과가 확인된 방법만 조합하고 원래 전체 과제로 평가한다.

정확한 혼합 비율·지속 시간·학습 예산은 실행 전 별도 실험 계획에서 정한다. 이 문서는 실행 승인을 받거나 수치를 확정한 계획이 아니다.

## 5. 공통 평가 기준

- 첫 올바른 접촉, 첫 연속 달성까지 걸린 환경 전이 수와 실제 시간.
- 같은 평가 성공률에 도달한 실제 시간. 모델 준비·모방 학습 비용도 따로 기록.
- 목표별 패드 거리, 압현 유지율, 연속 달성률, 오압현 시간, 물리·손목 종료율.
- 시작·해제 시각까지 포함한 엄격 통과율.
- 고정된 동일 체크포인트의 평균 정책 평가와 확률 평가를 분리.

환경 수·모델 크기·하드웨어·평가 주기를 맞추고 한 번에 하나만 변경한다. 최종 평가는 쉬운 시작 상태가 아니라 원래 초기 상태·목표·시간 조건에서 수행한다. 단일 seed의 빠른 성공만으로 일반적 수렴 개선을 선언하지 않는다.

학습률, 수집 길이, 데이터 재사용 횟수 조정도 후속 후보지만, 성공 경험이 드문 문제를 먼저 해결하는 방향을 우선한다. 현재로서는 속도가 몇 배 빨라질지 확정할 수 없다.
