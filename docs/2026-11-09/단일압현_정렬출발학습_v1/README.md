# 정렬 출발 단일 압현 학습

**1차 검증 완료:** 탐색0.15·100회 모델은 평균 정책16환경에서 모두 압현을 달성했다(연속 유지 평균1.454초/1.5초). [최종결과](최종결과.md)를 먼저 읽는다.

이전 여섯 조건에서 평균 정책의 압현 달성이 모두0이었다. 먼저 중지·3번줄·6프렛 하나를 성공한 준비 위치에서 학습할 수 있는지 검사한다. 초기 위치, 팔 관측, 탐색 크기를 한꺼번에 바꾸지 않는다.

## 비교 순서

1. 실제 성공 기록의 준비 완료 상태를 에피소드 시작에서 복원한다. 손가락 행동의 기준각과 native 한계는 기존 v9를 유지한다.
2. 같은 환경에서 알려진 손가락4축 명령을 재생한다. 팔은 유한 제어로 유지하며 손목 보정기는 사용하지 않는다. 이것이 실패하면 학습 전에 복원·지지 조건을 점검한다.
3. 재생이 성공하면 중지4축만 학습한다. large·64환경·H32·100업데이트·seed7·초기 표준편차 exp(-3), 50/100업데이트 모델을 평균 정책16환경으로 평가한다.
4. 학습이 실패하면 다른 조건을 유지하고 초기 표준편차0.15만 비교한다. 평균 정책의 압현을 확보한 다음 팔 제어와 관측 확대를 따로 비교한다.

이는 정렬된 출발 상태와 팔 유지 지원을 받는 조건부 검사다. 기본 J33 전신 학습, 목표 전환, 곡 학습의 성공으로 해석하지 않는다. 알려진 압현 각은 재생 검사에만 사용하며 학습 초기 명령으로 주입하지 않는다.

## 파일

| 위치 | 내용 |
| --- | --- |
| 계획.md | 승인된 순서와 확인 항목 |
| 진행상황.json | 현재 단계와 다음 작업 |
| 입력/ | 실제 준비 도착 자세·속도, 단음 악보, 재생용 압현 각, 원본 SHA |
| 도구/inputs.py | 원본 기록 검증과 새 입력 생성 |
| 도구/learning.py | 에피소드 경계 복원, 담당4축 정책, 학습·재개·평가·렌더·재생 검사 |
| 검증/ | 입력 대조, 실행 검사, 실패 원문 |

보상9개, 압현 판정, 물리·손목 종료 기준은 유지한다. 기타를 고정하거나 에피소드 도중 위치를 덮어쓰지 않는다. 체크포인트의 입력·소스·구조 검증을 생략하지 않는다.

진행 단계와 실제 결과는 진행상황.json 및 검증 원장을 따른다. 입력에 기록된 과거 성공만으로 새 환경의 성공을 선언하지 않는다.

평가16환경은 같은 정렬 입력에서 시작하는 평균 정책의 반복 재현 검사다. 서로 다른 초기 자세·난수·줄·프렛에 대한 일반화나 성공률의 신뢰구간으로 해석하지 않는다. 물리 재생 성공과 학습 정책 성공도 구분한다.

입력 catalog와 모델 설정의 미검증 표시는 봉인 당시 상태를 보존한 것이다. 검증 후 그 값을 고쳐 입력 SHA를 바꾸지 않으며, 실제 검증 결과는 검증/GPU_실행검증.json 및 각 실행 report.json으로 별도 기록한다.
