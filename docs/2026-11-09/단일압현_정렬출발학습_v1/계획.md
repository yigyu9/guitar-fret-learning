# 정렬된 출발 위치에서 단일 압현 학습 재현

사용자가 승인한 순서의 첫 단계다. 성공했던 실제 준비 위치를 현재 학습에 연결해 단일 압현부터 재현한다. 운영 학습·기존봉인·원본모델을 고치지 않고 새 실험 버전으로 진행한다.

- [x] 중지3번줄6프렛의 실제 native 도착 snapshot/성공 원장·입력SHA 검증과 새 에피소드경계 reset 입력 생성
- [x] 같은 새 환경에서 알려진 압현4축 명령 재생(oracle)으로 실제 접촉·1.5초 유지 가능성 확인
- [x] 목표손가락4축만 학습, 팔·기타 안정화 지원을 명시. 원래v9 기준 직접각 codec은 유지하고 초기 평균은 새 출발각에 맞춤
- [x] std약0.05 기준과std0.15 비교: large64·H32·100회·seed7, 각50/100회 모델 평균16환경 평가와 성공 모델 손/전신 영상
- [x] 실제 GPU 학습·엄격재개·평가·렌더 사전 검사
- [x] oracle이 실패하면 학습부터 시작하지 않고 reset/안정화 조건을 진단
- [x] 기준학습이 실패하면 같은조건std0.15 단독비교 및 원인분석. 무조건 더 복잡한 목표로 넘어가지 않음
다음 단계: 평균 정책으로 단일압현을 재현했으므로 팔 제어 확대/패드오차 관측을 별도 비교로 진행한다. 이번1차 검증에는 아직 포함하지 않았다.

처음부터 초기자세·팔관측·탐색을 한꺼번에 변경하지 않는다. 첫 단계는 목표손가락 학습 가능성을 분리하는 지원 진단이며 전신J33·원거리출발·전환의 성과로 주장하지 않는다. 정렬상태 순간복원은 에피소드경계에만 허용하고 중간 위치/기타 상태를 덮어쓰지 않는다. 기존성공 임계값·물리/손목 종료·오압현 판정을 유지한다.

이전에성공한동작은실제팔운반뒤압현이었다. 이번reset방식으로도가능한지는반드시같은조건oracle로먼저확인한다. oracle성공은학습성공이아니다.
