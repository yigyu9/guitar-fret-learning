## 새 native reset의 첫 물리 스텝

기타 compound 원점과 COM 속도를 복원한 뒤 실제 첫 240Hz 표본을 읽었다. 원문 도착 논리 기타 위치에서 첫 native 논리 위치까지의 변화는 0.01868mm였다. 첫 스텝의 무외력 예측 대비 위치 차이는 0.03998mm다. 예측은 중력과 접촉을 무시하므로 이 값은 연속성 진단이며 정확도 인증이 아니다.

첫 60Hz 추적은 실제 물리 step4에서 시작했고 기타 이동은 0.0749mm였다. 5초 전체 최대 기타 이동은 0.3755mm, 회전은 0.000762rad였다. 상태 쓰기는 에피소드 경계에서만 허용된다. 기록된 reset 2회는 생성 경계 초기화이며, 추적은 step4부터 1200까지 4스텝 간격으로 연속적이다.

## 지원 팔과 손가락의 실제 움직임

60Hz 기록에서 팔 12축의 명령 변화량은 0이다. 실제 팔 관절의 reset 대비 최대 변화는 0.002489rad, 명령 추종 RMS 오차는 0.000800rad였다. 손목의 Gx/Gy/Gz 좌표 변동 폭은 각각 0.636/0.961/1.947mm였다.

| 손가락 축 | 실제 각도 변동 폭 | 마지막 명령−실제각 |
| --- | ---: | ---: |
| LH:middle1_x | 6.037도 | 0.005456rad |
| LH:middle1_z | 4.867도 | -0.010925rad |
| LH:middle2 | 2.011도 | 0.000661rad |
| LH:middle3 | 1.388도 | 0.000161rad |

네 축 모두 실제로 움직였다. 특히 시작 관절의 굽힘과 벌림 축에도 변화가 있었으므로 마지막 관절만 사용한 재생은 아니다. 다만 위 수치는 각도의 움직임이며 접촉 힘의 기여율을 뜻하지 않는다.

정책 시각 0.5초의 패드 거리는 9.532mm, 1.5초에는 5.271mm, 2.5초에는 0.408mm였다. 주어진 손가락 목표각이 실제 접근과 접촉으로 연결되었다.

## 이전 v9 무동작 평가와의 차이

같은 단일 목표의 이전 v9 평가 16회는 모두 실패했다. 평균 최소 패드 거리는 62.374mm, clean은 0초, 누락은 1.5초였다. 이전에는 손목이 공통 영역 안에 100% 있었지만 압현에 이르지 못했다. 이번 oracle은 공통 영역 안의 비율이 0%이고, Gx 초과량 평균 5.710mm, 최대 6.189mm에서 성공했다. 이는 3cm 손목 종료 한계보다 작다. 손목의 넓은 허용 영역과 실제 패드 정렬은 구분해야 한다.

이전은 공통 v9에서 613열 J33 정책을 평가했고, 이번은 실제 도착 snapshot에서 601열 goal4 실행기에 알려진 각도를 주었다. 따라서 초기 상태만 바꾼 학습 A/B로 해석할 수 없다. 확인한 것은 **이 한 목표의 정렬 reset·고정 지원 팔·손가락 명령·native 압현 판정이 함께 작동한다는 것**이다. 정책의 학습 능력, 다른 목표와 전환 가능성은 후속 학습과 평가로 확인해야 한다.
