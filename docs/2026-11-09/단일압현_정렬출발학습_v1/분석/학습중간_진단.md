# 정렬 출발 학습 중간 진단 — 43/100 업데이트 스냅샷

이 문서는 **100회 학습 완료 결과가 아니다.** 학습 중 확보한 업데이트1~43, 완결 에피소드256개의 고정 접두부를 분석했다. 실제 학습은 이후 더 진행됐을 수 있다. 모델·소스·원본 로그는 수정하지 않았고 GPU도 사용하지 않았다.

## 현재 확인한 변화

- 새 정렬 출발·goal4·고정 지지에서는 256개 모두 시간 종료했고 물리 실패와 실제 종료 비용은0이다.
- 목표 근접을 만족한 에피소드는248, 패드 위치 기하가 한 번 이상 맞은 에피소드는186개다. 그러나 담당 끝마디 하중은4개, clean 접촉은3개뿐이다.
- clean 누적 시간은 전체합0.016667초, 에피소드당 최대 누적0.008333초, 최대 연속0.004167초다. 최초 접촉 달성0, 음 달성0이다. 최초 접촉 기준0.05초에도 아직 못 미친다.
- 즉 기존의 큰 거리·지지 불안정 문제를 상당 부분 줄였지만, 현재 병목은 가까운 패드를 실제 하중 있는 연속 접촉으로 바꾸는 것이다. 서로 여러 조건이 함께 바뀌었으므로 초기 상태 하나의 순수 효과라고 단정하지 않는다.

## 탐색과 학습률

초기 표준편차는exp(-3)=0.049787, floor도같다. 실제 entropy에서 계산한 active4 표준편차의 기하평균은0.049789→0.049791로 거의 일정하다. 탐색이 학습 중 붕괴한 상황은 아니다.

학습률은 `learning_metrics.jsonl:18`에서 KL 재시도1회 후3e-5→7.5e-6으로 줄었고 43회까지 회복되지 않았다. 당시 시도 KL은0.021727로 기준0.02를 넘었다. 평균 KL=0.002050, 평균 clip fraction=0.021348, 평균 clipping 전 actor gradient norm=7.4943다.

이전33축 정책과 현재4축 정책의 entropy 합을 그대로 비교하면 안 된다. 각각 채널 수로 나눈 값은 약−1.581/축으로, 시작 탐색 폭이 비슷하다. 현재 목표4축은 매60Hz 독립 표본이고 장시간 같은 굽힘 요청을 유지하는 탐색은 아니다.

## reward/cost advantage 비율

각 업데이트의 RMS를 sqrt(mean²+std²)로 구한 뒤 업데이트 평균을 비교했다. 아래는 모두 동일한 처음43회 예산이다. 이는 실제 PPO에 들어가는 advantage 규모 비교이며, 보상 현금 합계나 인과관계의 확정은 아니다.

| 조건 | reward RMS | cost RMS × weight | cost/reward |
|---|---:|---:|---:|
| 기존 중지 S3F6 | 0.04256 | 0.65311 | 15.35 |
| 기존 중지 S1F8 | 0.02573 | 0.70772 | 27.51 |
| 기존 약지 S2F7 | 0.05489 | 0.76581 | 13.95 |
| 기존 같은 줄 전환 | 0.03758 | 0.59997 | 15.97 |
| 기존 줄 변경 전환 | 0.03472 | 0.53019 | 15.27 |
| 기존 손가락 전환 | 0.05668 | 0.83399 | 14.71 |
| 새 정렬 goal4 | 0.09247 | 0.00518 | 0.056 |

기존 초기 학습에는 비용 advantage의 규모가 보상보다 약14~28배 컸다. 현재는 약0.056배다. 새 실험의 실제 비용은0이며, 남은 작은 cost advantage는 비용 critic의 예측/TD 오차를 포함한다. 공동 정규화의 표준편차는 현재도 거의1이다. 따라서 현재 접촉 실패를 큰 물리 실패 비용만으로 설명할 수는 없다.

## 손가락은 얼마나 움직였나

완결256개 에피소드에서 중지4축을 집계했다. 아래 각도 범위는 에피소드 최대−최소의 평균이다. 누적 이동거리와 다르다.

| 중지 관절 | 실제 범위 rad(도) | 목표 범위 rad | 추종 RMS rad | 평균 행동 |
|---|---:|---:|---:|---:|
| MCP x | 0.08632 (4.95°) | 0.24041 | 0.03872 | +0.03400 |
| MCP z | 0.02506 (1.44°) | 0.08932 | 0.01841 | -0.00220 |
| PIP | 0.04944 (2.83°) | 0.17400 | 0.02804 | +0.02588 |
| DIP | 0.05886 (3.37°) | 0.19267 | 0.03371 | +0.01456 |

실제4축 모두 움직이지만 목표 요청의 전체 흔들림보다 움직임이 작다. 매tick 평균 |행동 변화|는4축 모두약0.056이다. 빠르게 바뀌는 작은 목표를 관절이 그대로 오가는 상황이며, 이것만으로 지속 압현 동작을 배웠다고 볼 수 없다.

이미 성공한 oracle의 한 목표는 MCP z=0.20094rad인데, 현재 완결 에피소드에서 관측한 이 축의 전체 최소는0.26330rad다. oracle과 같은 벌림/굽힘 조합 근처는 아직 탐색하지 못했다. oracle은 유일한 정답 자세는 아니므로 이것이 모든 압현 가능성을 배제하지는 않는다.
그 oracle 목표는 초기 latent 평균에서 약2.01σ, -3.02σ, 1.32σ, 0.44σ 떨어져 있다. 특히 MCP z는 약−3σ이고, 필요한 것은 한 번의 표본보다 연속된 물리 목표 유지다.

## 접근 보상과 대기 자세가 막고 있는가

대표환경0의 최초600제어tick=2400물리표본을 별도로 읽었다. 이는 초기 두 에피소드 관측이며 전체256개 에피소드 통계와 분모가 다르다.

| 구간 | 새 패드 높이 평균 | 새 접근 potential 평균 | 기존 같은 목표 패드 높이 평균 |
|---|---:|---:|---:|
| 0~2.8초 준비 | 8.24mm | 0.9696 | 51.67mm |
| 2.8~3.0초 하강 전환 | 9.15mm | 0.8497 | 53.20mm |
| 3.0~4.5초 발음 | 7.44mm | 0.7799 | 52.45mm |

준비 구간의 hover potential은 이미0.970 정도로 높고, 높이4~8mm는 높이 오차0인 평탄 구간이다. 이 구간에서는 더 누르는 방향의 높이 개선 신호가 없다. 2.8~3.0초에 압현 표면 potential로 바뀌고 발음 중에는 표면 거리를 줄이는 신호가 남는다.

표면 exp(-d/0.03)는3mm에서0.9048, 0mm에서1이다. 3mm→0mm 개선 여지는0.0952이고 거리 미분의 크기는약30.16/m라 수학적으로 gradient가0인 것은 아니다. 다만 접근 potential에는 실제 하중이 없다. 패드 위치 기하가 맞고 하중은 없는 상태를 접촉/유지 보상이 구분해야 하는데, 실제 접촉 경험이 현재 매우 희박하다.

접근은 양의 품질 자체를 매tick 지급하는 방식이 아니라 gamma×다음potential−이전potential이다. 높은 초기 품질·프렛 노출 종료·terminal nextPhi0 때문에 누적 접근 보상이 음수일 수 있다. 이를 곧바로 “손가락이 멀어져서 감점”으로 해석하면 안 된다.

중지의 실제 대기 보상 gate와 지급률은 준비·하강·발음 구간 모두 정확히0이고 추종 가중치는1이었다. `observed_standby_gate`는 준비 초기에1로 보일 수 있지만 이는 의도적으로 보존한 옛 관측값이며 실제 지급 gate와 다르다. 현재 활성 중지가 대기 자세 보상 때문에 못 움직인다는 근거는 없다.

## 수정 없이 제안할 다음 비교

1. 현재100회 완료 후 동일 초기·지원·목표·보상에서std만0.15로 바꾸어 비교한다. geometry→body load→clean 지속시간이 함께 늘어나는지 본다.
2. noise 폭만으로 부족하면 별도 실험에서 시간적으로 일관된 탐색을 비교한다. 현재 독립 표본의 작은 진동과 지속된 목표각 이동은 다르다.
3. 준비 시간/hover 평탄 구간을 바로 바꾸기 전에, 기존 발음 구간에서도 하중 전환이 생기는지 먼저 확인한다. 필요하면 다음 단독 실험에서 정렬 시작 과제의 대기 시간을 줄이거나 더 가까운 접촉 준비 분포를 비교한다.
4. LR 회복/floor 비교는 분리한다. 현재 감소는 보조 문제일 수 있지만 접촉 희소성이나 시간적 탐색 문제와 섞어 원인을 판단하지 않는다.
