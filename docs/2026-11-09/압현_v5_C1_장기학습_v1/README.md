## 분석 기준

평가마다 전체20음과32개 episode를 기준으로 비교한다. 조기 종료되어 도달하지 못한 음도 분모에 남기고 미노출로 구분한다. 학습의 구간 노출과 전체 노출은 따로 집계한다. 정상 완료한 episode만 골라 성공률을 높이지 않는다.

모델 선정 순서는 전체 압현·해제 완성률, 전체 유지율, 평균 달성 음 수, clean 시간 비율, 안전 완주율, 최신 업데이트다. 초기·1000회·2000회라는 평가한3개 중 선정이며, 모든 체크포인트를 평가한 전역 최고 성능이라는 뜻은 아니다. 물리 실패·손목 종료율을 성과와 함께 보고한다. 아무 목표도 수행하지 않는 초기 모델이 안전 완주율만으로 우선 선정되지 않는다.

압현 달성은 현재 corrected의 음 길이40% 연속 유지 기준이다. 전음 유지와 필요한 해제까지 마친 전체 완성은 더 엄격한 별도 지표다. 기하·하중 기반 접촉 후보는 실제 현 압력이나 음향 측정과 구분한다. 상세 trace가 환경0의 최초10초만 포함한다는 제한도 보고서에 남긴다.

재개가 발생하면 같은 전역 업데이트는 한 번만 집계한다. 보고서의 학습 반영 전이 수는 폐기·재수집된 계산량을 제외하므로 실제 GPU가 계산한 총량과 다를 수 있다. 마지막200회 구간의 성과 추세와 고정 평가를 보고 추가1000회의 필요성을 판단한다. 자동으로 예산을 늘리거나 실험 조건을 바꾸지는 않는다.

## 중단 방지와 검증

코드·자산·C1·Isaac Gym은 `작업자료/runtime/`에 실제 파일로 복사했다. 원본과 SHA가 같고 파일 inode를 공유하지 않으며 외부를 가리키는 파일 링크가 없는지 확인했다. 사본의 작업 디렉토리·전용 캐시·출력 경로를 일치시킨다. 설치된 Python·드라이버·ffmpeg는 같은 PC 것을 사용한다.

감독 프로세스는 터미널과 분리하고 중복 실행을 잠근다. 5초마다 진행 상황을 기록하며 소스·자산·목표·후처리 도구 SHA, 디스크8GiB 여유, 학습 진행 정체10분을 감시한다. 학습은 재시도를 포함해 최대18시간이다. 일시적인 중단에 한해 검증된250회 경계 체크포인트에서 남은 예산을 최대1회 복구한다. 원래2000회 노출 일정은 유지한다. SHA·입력·정책 identity·목표 시계 불일치, 비유한 값, KL 보호 중단은 조건을 완화해서 재시도하지 않는다.

본학습 종료 후 SHA 검증 → 동일 조건 평가3개 → 수치·그래프 분석 → 선정 모델 영상 순서로 자동 진행한다. 실패 시 원본과 오류를 남기고 이후 단계를 중단한다. 이번 실행 때문에 공유 v5 학습 코드·보상·제어를 수정하지 않는다.
