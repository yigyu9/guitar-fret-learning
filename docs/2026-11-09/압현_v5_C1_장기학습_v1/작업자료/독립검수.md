# 운영 도구 독립 검수

2026-11-04 change-reviewer 검수. 범위는 `도구/run.py`, `test_run.py`, `analyze.py`, `test_analyze.py`다. 기존 v5 학습·보상·제어 코드는 변경하지 않았다.

분석 입력이 실제 `attempt/J`를 가리키도록 수정했고, 정체 감시 후 정상 SIGINT의 KeyboardInterrupt만 제한된 복구 대상으로 인정하도록 수정했다. 일반 오류·SHA·identity·목표 시계 불일치에 대한 검증은 유지한다. 실행 사본뿐 아니라 실제 감독·분석 도구의 SHA도 감시한다.

최종 CPU 검사14개 통과. 고정1024환경·2000회·H32·large·seed7·초기 탐색0.15/0.35, 최초 노출 예산 보존, 최대1회 복구, 고정32환경 평가의 실패 포함 분모, 평가한 모델만 영상으로 선정하는 경로를 확인했다. 성과 우선 선정 반례 검사도 포함한다.

미해결 실행 차단 오류 없음. CPU 검수는 학습 성능이나 GPU 물리 안정성의 보장이 아니며 별도 실행 사본 GPU·렌더 검사 결과와 함께 판단한다. 재개 시 중복 제거 전이 수를 실제 계산 총량과 구분한다는 설명은 연구 README에 반영했다.
