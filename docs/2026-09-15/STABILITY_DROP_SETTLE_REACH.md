# StabilityAdapter 낙하·안정·접근 반영 결과

## 변경 목적

기존 환경은 리셋 직후 왼손이 기타 넥에서 약 1.8mm 떨어져 있었고 안정 대기를 건너뛰었다.
따라서 영상에서는 손이 움직여 넥을 찾아가는 과정 없이 즉시 그립하는 것처럼 보였다.

## 현재 episode 순서

1. 기타를 고정 해제 상태로 놓고 수동 스트랩과 중력으로 낙하시킨다.
2. 최소 60프레임을 기다린다.
3. 기타 선속도 0.10m/s 이하, 각속도 0.50rad/s 이하가 15프레임 연속 유지되면 정책을 켠다.
4. 왼손 팔·손목이 넥 아래로 접근한다. 목표 관절 속도는 최대 0.50rad/s이며 가까워지면 0.25rad/s까지 줄인다.
5. 손바닥이 넥에서 5cm 안에 들어오기 전에는 왼손 손가락 출력을 적용하지 않는다.
6. 아래 접근, 대향 그립, 접촉 운반, 목표 위치·회전 유지를 순서대로 판정한다.

초반 안정 판정에는 기타의 선속도와 각속도만 사용한다. 스트랩 장력·신장률은 물리 지지와
진단·최종 안전 판정에는 남아 있지만, 접근 시작을 막지는 않는다.

## 검증 결과

- GPU 2환경 리셋에서 첫 프레임 손바닥–넥 거리: 약 0.110m
- 첫 프레임 기타 운동: 약 1.25m/s, 11.89rad/s
- 60프레임 기타 운동: 약 0.0012m/s, 0.0042rad/s
- 정책 최초 활성 프레임: 76
- 정책 활성 시 손바닥–넥 거리: 약 0.111m
- 이 시점의 손가락 제어: 차단
- CPU Stability 관련 테스트: 284개 통과, 22개 GPU 선택 테스트 제외
- GPU 단계 순서·5cm 손가락 게이트·스트랩 비의존 안정 판정 테스트: 통과
- 8환경·48회 짧은 PPO 학습: 12,288샘플, 체크포인트·집계·종료 사유 로그 정상 생성

새 체크포인트 계약은 `tab2body.stability_adapter_checkpoint_contract.v8`이다. 이전 v7 체크포인트는
즉시 near-contact 리셋을 학습했기 때문에 새 환경에서 재개할 수 없다.
