# OM 무스트랩 오른상완 시험 영상 보관

완료된 네 trial의 원본 MP4 8개를 재인코딩 없이 복사했습니다. 원본과 보관본은 모두 manifest에 SHA-256으로 기록되어 있습니다. 이번 보관에는 다섯 번째 진행 조건이 포함되지 않습니다.

## 결과 해석

첫 두 파일럿에서는 왼팔이 기타와 접촉해 오른상완의 독립 지지를 확인하지 못했습니다. 다음 두 조건에서는 왼팔 접촉이 없었지만 기타가 넘어졌고 오른상완 접촉도 관찰되지 않았습니다. 어느 조건도 지지 성공으로 표현하지 않습니다.
