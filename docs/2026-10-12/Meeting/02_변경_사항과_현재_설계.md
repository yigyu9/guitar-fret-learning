# 연구 방향과 제어 설계의 변경 사항

| 항목 | 과거 접근 또는 진단 | 현재 방향과 확인 범위 |
|---|---|---|
| 연구 목표 | 기타를 운반하거나 초기 p/q로 정확히 복귀 | 자연스러운 연주 범위 안에서 기타 지지와 압현 및 타현을 함께 달성 |
| 시작 과정 | WAIT와 REACH 및 GRIP과 TRANSPORT 중심 | 운반 단계를 연주 필수 과정으로 두지 않음. 현재 연결 시험은 2초 준비 |
| 제어권 | 한 손 33축 또는 팔 목표 유지의 원인 진단 | 최신 학습은 상체 81축. 몸통과 머리 및 팔과 손가락의 보정 한도를 구분 |
| 하체 | 실제 하체 움직임과 충돌 문제를 함께 진단 | 현재 root와 하체는 물리적으로 고정 |
| 기타 | 고정 기타에서 개별 기술 학습 | 안정화 환경의 기타는 자유 상태이며 실제 접촉과 중력 및 수동 스트랩으로 움직임 |
| 손 접촉 | 초기 지지를 위한 손바닥과 엄지 배치 | 초기 지지는 활용하되 지속 손바닥 접촉을 음악 성공의 필수 조건으로 두지 않음 |
| 스트랩 | 길이와 초기 자세 후보를 함께 탐색 | ON/OFF와 길이 조건을 분리 비교. 원본 길이 1.1018469719600776m를 유지한 시험 존재 |
| 좌표와 범위 | 초기 오차의 단일 위치 및 회전 임계값 | actor root와 바디 중심 및 골반 상대 좌표 구분. 자연 범위와 회전 특이점 검토 |
| 기존 기술 사용 | 체크포인트 관절 목표를 바로 연결 | 동결 기준선과 현재 기타 기준 접근 보정 및 최종 action history 정합을 구분 |
| 학습 구조 | 기하 보정과 정지 hold 진단 | 825D→512→256→81 Actor와 별도 Critic의 제한 보정 PPO를 실제 실행 |
| 학습 안정성 | 큰 갱신과 정규화 변화 및 속도 안전 종료 | 전체 rollout KL 제한과 model/Adam 복원 및 RMS 고정 |
| 실행 자원 | 한 CPU 물리 환경과 GPU 정책 계산 | 4개 CPU 물리 환경의 spawn 병렬 수집과 GPU 행동 배치 계산을 검증 |
| 영상과 복구 | 짧은 5초 관찰 중심 | 연결 체크포인트는 준비부터 종료까지 녹화. 별도 평가 및 5분 복구 저장 |
| 평가 | 조용해지거나 영상이 완성되면 성공으로 보기 쉬움 | 초기 이탈과 후기 안정성 및 음악 이벤트 성공을 각각 보고 |

## 현재 학습 구조의 범위

Fret 관측 420D와 Strike 관측 303D는 원본 기술 계약입니다. 최신 공동 정책의 825D는 통합 물리 상태와 음악 판정 및 현재 목표 정보를 포함한 별도 관측 계약입니다. 공통 전신 named 제어 슬롯 105D, 유효 가동 97D, 현재 상체 학습 81D는 서로 다른 범위를 뜻합니다.

최종 PD 목표에는 모델 관절 한계와 부위별 보정 한도 및 변화율을 적용합니다. 물리 상태를 강제로 붙잡는 것과 PD 목표를 유지하는 것은 다릅니다. 관절의 실제 움직임은 별도로 측정합니다.

## 비교 자료를 볼 때 주의할 점

- source mesh의 정적 겹침 그림과 실제 Isaac Gym 물리 렌더를 구분합니다.
- 가상 pick의 줄 crossing은 음악 이벤트 판정이며 실제 줄 강체 충격이나 음향 합성의 증거가 아닙니다.
- 스트랩 선은 실제 계산 경로의 표시이며 천의 변형 mesh가 아닙니다. 선이 보여도 장력이 0N일 수 있습니다.
- 초기 기타 대비 SO(3) 회전거리와 사용자 자연스러운 회전 허용집합의 통과율을 구분합니다.
- 16.3667초 물리 구간과 492 frame의 MP4 재생시간 16.4초는 다릅니다.
- 동결 체크포인트 추론과 새로운 PPO 학습 갱신을 구분합니다. GPU 사용과 물리 backend도 따로 명시합니다.
