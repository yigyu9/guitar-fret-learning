# 전체 상체 공동 정책 학습 설계 v2

이 문서는 하체를 제외한 **상체 전체 81관절을 처음부터 하나의 정책이 제어하는** 설계 제안을 요약한다. 이전 v1 왼손 33관절·held48 초안은 이 버전에서 설계 순서상 대체되지만, 기록으로 그대로 보존한다. 이 산출물은 구현이나 실행을 뜻하지 않는다. 환경 코드 실제 변경 0, 물리 실행 0, 학습 0이다.

## 제어 범위와 동작

정책 행동은 torso/spine/chest 9관절, neck/head 6관절, 왼팔·손 33관절, 오른팔·손 33관절로 총 81관절이다. 관절 이름과 순서는 실제 native 실행의 `joint_names`에 따른다. root와 하체는 고정 상태이며 행동에 포함하지 않는다. 상체 전체를 한 Actor가 소유하고 단일 제출자가 81개 PD 목표를 한 번 제출한다. 상체 중 별도 고정 목표나 held 관절 채널은 두지 않는다.

몸통과 목·머리는 초기 자세 선호 및 작은 목표 변화 비용으로 작은 움직임을 유도하는 후보를 둔다. 이 선호는 관절을 행동에서 빼거나 각도를 고정하는 뜻이 아니다. 필요한 상황에는 움직일 수 있도록 하고, 실제 q/qdot와 목표-실제 오차를 측정한다. 자세 선호 강도와 관절별 변화율 한도는 행동 시험 뒤 정한다.

첫 pilot 조건은 root/하체 fixed-lower, self-collision, 자유 기타, 스트랩 OFF다. 기타를 고정하거나 손에 붙이거나 외력을 주거나, 실행 도중 pose를 덮어쓰지 않는다. 음악 과제는 한 음 압현·유지·해제부터 시작할 수 있지만 정책 행동 차원은 계속 상체 81이다. 압현부터의 curriculum은 과제 난이도를 뜻하며 정책 제어권 축소가 아니다.

## 관측과 정책 후보

관측 묶음 후보는 전체 native81의 실제 q/qdot와 직전 실제 제출 목표, Chest/Pelvis 상태, 기타 pose/twist와 허용범위 정보, 현재 기타 좌표계 G 기준 양쪽 손목·손바닥·엄지·손끝/피크 관계, 음악 event·압현/타현 detector·sustain tracker와 유효 마스크, 양측 native 접촉과 조회 유효 마스크다. 관측 의미 묶음은 제시되어 있지만 필드 순서·단위·마스크를 고정할 manifest와 최종 차원 D는 아직 미정이다. 회전 범위 판정 역시 경계·특이점·q와 -q 동치 검증 전에는 완성된 입력으로 취급하지 않는다.

Actor 기본 구조는 D→Linear 512→ELU→Linear 256→ELU→평균 81이며, 관절별 학습 가능한 log_std 81개를 둔 tanh 대각 Gaussian을 제안한다. Critic은 같은 D를 받아 512→256 ELU 층 뒤 value 1을 출력하고 Actor와 가중치를 분리한다. Critic은 PPO 학습 전용 경로이며 실행 제어기가 아니다. PPO 하이퍼파라미터와 보상 가중치는 미정이고, 이 설계의 성능은 검증되지 않았다.

행동 요청을 검증된 native 관절 한계로 변환하고 control 주기마다 관절별 변화율 제한을 적용한 뒤 81D `q_final`을 한 번 제출하는 구조를 제안한다. 다음 관측에 넣는 직전 목표는 실제 제출한 `q_final`이다. PPO 기록에서는 sampled action/log-prob, 요청 목표 `q_requested`, 제한 적용 후 `q_final`을 구분한다. 60 Hz 제어/240 Hz 물리 조건은 출발 설계 조건이며 control 주기당 제한 적용 후 네 physics step 동안 목표를 유지한다는 제안이다. 이번 작업에서는 이 조건을 실행하지 않았다.

## 기존 네트워크와 체크포인트

프로젝트 기본 ActorCritic 및 Fret-v2/Strike-v2 fusion MLP가 512→256 폭을 사용하는 점을 이번 기본 크기의 근거로 삼았다. 기존의 은닉층 폭이 같아도 새 정책의 입력·출력·encoder 구성은 다를 수 있으므로 기존 체크포인트를 자동으로 직접 load할 수 있다는 뜻이 아니다. 구조, 필드 의미와 순서, action 이름, layer shape가 맞지 않는 가중치·critic·optimizer·정규화 통계는 복사하지 않는다. 기존 Fret/Strike는 동결 비교 조건 또는 유효한 성공 구간의 조건부 교사/참조 후보로만 다룬다. 교사를 쓰더라도 최종 명령권은 공동 정책에 남고, 교사 의존을 0까지 줄일 수 있어야 한다.

## 그림 해석

관측 후보가 미정 차원 D로 모이고, Actor가 상체 81 목표를 생성해 native 관절 한계와 control 주기 rate 제한을 거친 뒤 단일 81D PD 목표로 자유 기타 환경에 제출한다. 환경 상태는 다음 관측으로 피드백된다. Critic은 D에서 갈라지는 점선 PPO 학습 전용 경로다. 도식에는 상체 held 채널이 없다.

그림은 설계 구조를 설명할 뿐 물리 결과나 성능 수치를 나타내지 않는다. 전체 상체 81 정책은 미구현·미실행이며, 512→256 구성과 PPO 효과도 미검증이다.
