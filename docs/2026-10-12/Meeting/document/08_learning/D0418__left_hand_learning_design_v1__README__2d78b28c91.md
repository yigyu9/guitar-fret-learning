# 왼손 공동 정책 학습 설계

이 결과물은 자유 기타에서 왼손 지지와 압현을 함께 다루는 정책의 **설계 제안**을 설명한다. 네트워크나 환경을 구현·실행하지 않았으며 학습 결과, 성능 향상, 물리 시험 결과를 담지 않는다.

## 확정된 설계 계약과 제안의 구분

원문에서 정한 제어권 계약은 첫 단계의 왼손 Thorax부터 손가락까지 33관절이 하나의 정책 소유라는 것이다. 엄지도 포함한다. 오른쪽 33관절, torso 9관절, neck/head 6관절의 목표는 유지하며, 이 관절들의 실제각을 고정하는 뜻은 아니다. 최종 native81 목표는 한 제출자가 조립해 한 번에 내도록 제안한다. 양손 통합 뒤 최종 양측 66관절을 사용할 수 있으며, 이번 33관절 범위가 최종 권한 제한으로 굳어지는 것은 아니다.

root/하체는 fixed-lower 조건이다. Torso·Spine·Chest의 9관절 목표는 유지하되 실제 움직임은 측정한다. 기타는 초기화 이후 자유 물리 상태로 두며 고정, 손 부착, 기타 외력, 실행 중 pose 덮어쓰기를 쓰지 않는다. 첫 pilot의 스트랩 조건은 OFF다. 현재 기타가 허용범위 안에 있을 때 초기 위치·자세 복원 비용은 0으로 둔다. 작은 흔들림은 허용한다. 지속적인 손바닥·엄지·다른 손가락 접촉이나 WAIT→REACH→GRIP→TRANSPORT 단계는 필수 조건이 아니다.

관측 입력의 **의미 묶음**은 원문에 제시되어 있지만, 전체 입력 manifest와 차원 D는 미정이다. 후보 입력은 native81의 실제 q/qdot 및 직전 실제 제출 목표, 기타 pose/twist와 허용범위 정보, 현재 기타 좌표계 G 기준 손·넥 관계, 음악 event와 압현·해제 detector/sustain tracker, 양측 native 접촉 여부와 유효 마스크다. 실제 차원은 구현 전에 필드 이름·순서·단위·마스크를 확정한 뒤 계산한다. 현재 world actor-root 기준 위치 경계와 팀원 Pelvis 상대 body-center 범위를 혼합하지 않는다. 회전 허용집합 거리 판정은 아직 구현되지 않았으므로, 경계·특이점 및 q와 -q 동치 검증 전에는 완성된 관측 신호로 간주하지 않는다.

Actor의 구조와 PPO는 **pilot 후보**다. 제안은 D→Linear 256→ELU→Linear 256→ELU→33 평균, 관절별 학습 가능한 log_std를 둔 tanh 대각 Gaussian이다. Critic은 같은 D를 입력받고 별도 가중치로 Linear 256→ELU→Linear 256→ELU→value 1을 출력하는 후보이며 PPO 학습 전용이다. Critic은 실행 제어 경로가 아니다. 256 폭과 PPO의 효과는 검증되지 않았다.

행동 후보는 왼손 33관절의 절대 목표 요청이다. tanh 출력을 검증된 native 관절 한계로 변환하고, 관절별 control 주기 변화율 제한을 적용한다. 남은 48개 목표와 합쳐 단일 native81D PD 목표를 한 번 제출한다. 현재 60 Hz control과 240 Hz physics 조건은 설계의 출발 조건으로, control 간격 1/60초와 네 physics step 동안 목표를 유지한다는 제안에 반영되어 있다. **이번 문서 작업에서 제어/물리 실행은 하지 않았다.** 팔 0.8 rad/s와 손가락 0.3 rad/s는 시험 출발 후보일 뿐 검증된 제한값이 아니다. 목표 도달 가능성을 이벤트 시간과 대조하고 행동 시험 후 정해야 한다. 속도 제한 뒤의 실제 제출 목표는 sampled action과 구분해 기록한다.

## 기존 Fret 체크포인트

기존 Fret은 고정 기타에서 학습됐고, 원문은 이를 자유 기타에서 검증된 전문가로 취급하지 않는다. 따라서 도식은 Fret 체크포인트를 새 Actor에 직접 load하거나 실행 경로에 연결하지 않는다. 동결 Fret과 제한 residual은 비교 조건으로 보존한다. 구조·입력 의미·순서·action 이름·layer shape가 맞지 않으면 `state_dict`, critic, optimizer, 정규화 통계를 복사해 warm start로 간주하지 않는다. 이후 성공 구간의 기하 목표·동작을 약한 교사 신호로 이용하는 방안만 조건부 후보이며, source 관측·profile이 유효할 때 별도 비교한다.

## 도식 읽기

왼쪽의 관측 후보 묶음은 확정된 최종 manifest가 아니라 원문에 적힌 입력 의미를 요약한다. 여러 관측은 차원이 아직 정해지지 않은 D로 모인다. 실선은 정책 실행 제안의 흐름이며, Critic으로 가는 점선은 같은 관측을 사용하는 PPO 학습 전용 경로다. Actor 출력은 native 한계와 control 주기 rate 제한을 거쳐 held48 목표와 합쳐지고, 81D 단일 PD 목표가 자유 기타 환경에 제출된다. 환경의 다음 상태가 관측으로 돌아온다.

그림의 네트워크 폭, 분포, PPO 구성과 실행 흐름은 제안이며 구현 검증을 통과한 시스템을 뜻하지 않는다. 그림은 새 물리 결과나 성능 데이터를 표시하지 않는다.
