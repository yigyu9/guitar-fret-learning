# 11. 현행 연구 결정과 미검증 항목

2026-10-10 정리. [전체 메인 계획](/home/ajou/yigyu/3/master_plan/README.md:14)에 반영된 사용자 조건·연구 방향과 미완료 설계를 구분한다. 이 문서 작성이 실행 계약 봉인·새 성능 검증을 뜻하지 않는다. [과거10 결정 원문](/home/ajou/yigyu/3/master_plan/10_open_decisions.md:1)은 그대로 보존하며, 해당 문서의 과거 StabilityAdapter DECIDED 항목을 자동 승계하지 않는다.

## 우선 확인할 미검증 항목

- 원본 고정 기타 source 자격·성능·자산 확보와 전이 환경 차이. 현재 CPU native 진단을 원본 재현/GPU 동등성으로 표시하지 않는다.
- 현재 기타 기준 왼손 손목/목표 프렛 접근, 손바닥·엄지·손가락의 접촉면, 단일 압현/유지와 타현/회복.
- 허용 회전 집합·q와-q 동치·경계 거리·시간 지표, 실제 접촉/관통 및 물리 설정 readback. 안전 기준의 구체 값은 측정 근거를 먼저 마련한다.
- 관절별 음악/보정 소유권·상충 처리·최종 목표/normalized history·EMA/PD 순서. 개별 bridge 진단과 중앙 양손 runtime 구현을 구분한다.
- Residual의 관측·action·cap·보상·종료·표본·학습 자원과 비교군. Source 자체 adaptation은 단순 bridge/접근/보정으로 해결되지 않는 실패가 확인된 뒤 검토한다.
- 단일 이벤트 → 전환 → 짧은 구절 → 곡의 공통 음악 시간축과 반복 재현성. 사람 동작 비교 없는 human-like, 미학습 곡 일반화, 실제 로봇 이전을 주장하지 않는다.

## 변경 기록 원칙

위 조건 변경은 현행 문서·파트 실행 계획에 근거와 검증 상태를 기록한다. 과거 결정/실험 원문을 새 조건처럼 다시 쓰지 않는다. 봉인된 입력·source·로그·영상은 보존하고 재시도/새 조건은 새 실행 경로를 사용한다. 상세 실행 책임은 [현재 PLAN](/home/ajou/yigyu/3/stability_adapter_2/PLAN.md:1), 기록 규칙은 [실험 workflow](/home/ajou/yigyu/3/stability_adapter_2/EXPERIMENT_WORKFLOW.md:1)를 따른다.
