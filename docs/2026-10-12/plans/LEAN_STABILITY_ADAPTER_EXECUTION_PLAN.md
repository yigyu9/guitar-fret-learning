# StabilityAdapter 환경과 학습 기준

2026-10-05 사용자와 합의한 새 설계다. 이 문서가 구현의 유일한 현재 기준이며,
같은 경로의 이전 계획서를 대체한다. 기본 환경·원본 스트랩·reset·초기 노이즈·3초 WAIT
구현과 검증을 완료했다. 접근·그립·학습 환경과 정책은 아직 구현되지 않았다.

확정값은 첫 구현·학습의 기준이지 성능이 검증된 최적값이 아니다. 미정 항목은
검증 없이 이전 코드의 상수로 채우지 않는다. 실험 보고서·로그·완료 이력은
계획서에 누적하지 않고 별도 실행 폴더에 기록한다.

## 과제 목표

스트랩이 연결된 자유 기타를 왼손으로 붙잡아 초기 기준 위치와 회전으로 복원하고,
그립과 자세를 유지한다. 이번 독립 학습에는 fret·strike 실행, Synchronizer 명령,
곡별 연주 이벤트를 포함하지 않는다.

## 기본 환경

- humanoid·기타는 `tab2body/assets/`의 공용 모델을 사용한다.
- 오브젝트 배치·관절 자세는 기존 스트랩 환경 기준이다. 공용 `seated_pose.json`과
  원본 환경 배치가 일치하는지 먼저 대조하고 출처를 명시한다.
- humanoid root는 위치·회전을 고정한다. 기타 root는 자유이며 중력과 실제 충돌을 적용한다.
- 기존 원본 스트랩을 기본 환경에 포함한다. 연결점·몸 주변 경로·길이·장력 계산의
  출처와 설정을 확인한다. 기타 고정·손 부착·목표 방향의 인위적 힘은 없다.
- 질량·관성·마찰은 공용 모델을 기준으로 시작하되 실제 로드 후의 값을 검증한다.
- 양손·몸통과 기타의 충돌을 유지한다. 정책에 유리하도록 충돌을 임의로 제거하지 않는다.
- 제어 60Hz·물리 240Hz를 시작 기준으로 하며 스트랩 힘 갱신도 물리 계산과 일치시킨다.

비제어 관절 자세 유지, PD·토크 제한은 공용 환경을 출발점으로 검증한다. 이전의
고정링크 bake·초기 자세 override·asset option을 자동 승계하지 않는다.

## 초기화와 노이즈

| 대상 | reset 설정 |
|---|---|
| humanoid | 확인한 기준 root·관절 자세 |
| 기타 위치 | 기준 위치에 각 축 균등분포 ±2mm |
| 기타 회전 | 각 축 회전 변화 ±0.5° |
| 왼팔·손가락·비제어 관절 | 노이즈 없음 |
| 모든 초기 선속도·각속도·관절 속도 | 0 |
| 복원 목표 | 노이즈 적용 전 기타 기준 위치·회전 |

회전 노이즈의 적용 좌표계와 합성 순서는 초기화 검증에서 명시한다. 축별 ±0.5°를
전체 회전각 ±0.5°로 묵시적으로 바꾸지 않는다. 환경별 독립 seed를 사용하고,
심한 관통·비정상 스트랩 상태를 만드는 초기 샘플은 제외한다. 노이즈 없는 평가·영상도 제공한다.

reset 관측은 관절과 rigid-body pose가 동기화된 상태에서 생성한다. 초기 속도 0은
첫 물리 진행 전 상태에서 검증하며, 진행 뒤 생긴 속도와 혼동하지 않는다.

## 제어 관절과 오른손 감지

왼쪽 `L_Thorax`부터 손가락까지 하위 가동 관절을 하나의 정책으로 제어한다.
공용 모델에서 확인할 33개 action 순서는 다음과 같다.

1. `L_Thorax_x`, `L_Thorax_y`, `L_Thorax_z`
2. `L_Shoulder_x`, `L_Shoulder_y`, `L_Shoulder_z`
3. `L_Elbow_x`, `L_Elbow_y`, `L_Elbow_z`
4. `L_Wrist_x`, `L_Wrist_y`, `L_Wrist_z`
5. `LH:thumb1_x`, `LH:thumb1_y`, `LH:thumb1_z`, `LH:thumb2`, `LH:thumb3`
6. `LH:index1_x`, `LH:index1_z`, `LH:index2`, `LH:index3`
7. `LH:middle1_x`, `LH:middle1_z`, `LH:middle2`, `LH:middle3`
8. `LH:ring1_x`, `LH:ring1_z`, `LH:ring2`, `LH:ring3`
9. `LH:pinky1_x`, `LH:pinky1_z`, `LH:pinky2`, `LH:pinky3`

root·몸통·하체·오른팔·오른손은 policy action에서 제외하고 기준 자세를 유지한다.
오른손 회피·운반·지지는 제어하지 않는다. 오른손·손목과 기타의 접촉 부위·힘·지속
시간을 측정하며, 5N 이상이 0.1초 지속되면 간섭 의심으로 기록한다. 감지 자체에는
이동·패널티·실패 종료를 연결하지 않는다. 실제 방해인지는 기타 움직임과 함께 분석한다.

## 행동과 물리 제어

관절당 하나의 `[-1,1]` 행동을 이전 목표각에 누적한다. 실제 관절각에 더하지 않는다.

```text
raw_target = previous_target + action * target_speed_limit * control_dt
target = clip(raw_target, joint_lower_limit, joint_upper_limit)
```

| 그룹 | 목표각 최대 변화 속도 | 60Hz 프레임당 최대 변화 |
|---|---:|---:|
| L_Thorax·어깨·팔꿈치 | 60°/초 | 1° |
| 손목 | 90°/초 | 1.5° |
| 손가락 | 120°/초 | 2° |

행동 0은 목표각 유지이며, 실제 관절은 PD로 목표각을 따라간다. PD·토크 제한은 공용
환경의 관절별 설정으로 시작해 자유 이동·접촉 시험으로 검증한다. reset에서는 초기
관절각으로 목표각을 설정하고, 단계 전환에서는 누적값을 유지한다.

접촉으로 관절이 멈춘 동안 목표각이 과도하게 쌓이지 않도록 목표각–실제각 차이를
제한한다. 제한값은 미정이며 필요한 그립 압력과 정상 이동을 막지 않는지 검증한다.
teacher·IK 경로·scripted action 보정·별도 행동 평활화는 추가하지 않는다.

## 접근 위치와 접촉 영역

넥–바디 연결부부터 너트까지의 넥 길이에서 헤드 방향 2/3 지점을 중심으로 사용한다.
공용 메시 기반 후보 중심은 기타 로컬 `(0,0.0637323,0.00065)m`, 축 구간은
`y=-0.241803..0.2165m`다. 이전 fret22 기준 중심과 혼용하지 않는다. 헤드스톡은 제외한다.

- 손바닥은 초기 자세에서 아래를 향하는 넥 측면으로 접근한다. 현재 후보는 `+X` 면이다.
- 엄지는 넥 뒤쪽 `-Z` 면, 나머지 손가락은 지판 쪽 `+Z` 면을 누른다.
- 선택한 면은 기타 좌표계에 고정한다. 기타 회전 때마다 아래쪽 면을 다시 선택하지 않는다.
- 손가락마다 한 점을 강제하지 않고 그립 중심 주변의 허용 표면 영역을 사용한다.
- REACH 목표는 표면 바깥, GRIP 목표는 실제 접촉면이다.
- 손바닥 충돌 표면 중앙 기준점과 안쪽 법선은 실제 모델에서 확인한다.
  손바닥 접촉면이 넥 측면을 향하도록 하며, 이전 중지 방향만의 정렬은 승계하지 않는다.

[접점 시각화](../visualizations/grip_proposal/grip_proposal_multiview.png)의 중심 ±2.5cm
영역과 접근 간격 2cm는 설명용 예시다. 영역 크기·접근 간격·REACH 거리/방향 허용 오차·
손바닥 로컬 기준점은 미정이다. 렌더는 스트랩 없는 정지 모델이며 자유 기타·접촉·
그립 성공 검증이 아니다.

## 입력 관측

| 묶음 | 필요한 신호 | 좌표계 |
|---|---|---|
| 관절 | 제어 관절각·속도·누적 목표각 | 관절 좌표 |
| 직전 제어 | 관절별 직전 적용 행동 | 정규화 행동 좌표 |
| 기타 | 위치·회전·선속도·각속도 | 고정 humanoid root 기준 |
| 복원 목표 | 목표 위치·회전 오차 | 고정 humanoid root 기준 |
| 팔·손바닥 | 팔 기준 상태, 손바닥 pose·상대 속도, 접근 목표 벡터·정렬 관계 | 기타 기준 |
| 엄지·손가락 | pad/손끝 위치·상대 속도·허용면까지 벡터 | 기타 기준 |
| 접촉 | 손바닥·엄지·각 손가락 접촉 여부·올바른 면의 힘·미끄럼 | 해당 표면 기준 |
| 오른손 | 오른손·손목의 기타 접촉 정보 | 크기·여부 |
| 단계 | 현재 단계·경과 시간·유지·그립 손실 카운터 | scalar·one-hot |

상대 속도는 기타 이동·회전을 반영하고 회전은 연속적인 6D 표현을 사용한다.
필드마다 이름·순서·단위·좌표계·스케일을 명시한다. 실제 pad와 손끝 기준점이 다르면
이를 기록하고 접촉 판정과 일치시킨다. actor·critic은 같은 단일 프레임 관측을 사용한다.

물리 스케일을 명시하고 연속 관측에 running mean·variance 정규화를 적용한다.
통계는 checkpoint에 저장하고 평가 시 고정한다. rollout 수집과 PPO 확률 재계산에서
같은 정규화 기준을 사용한다. flag·one-hot·counter 처리와 최종 차원은 구현 전 확정한다.
직전 적용 행동은 tanh 이후 목표각 누적식에 전달한 값이며, 관절 limit에 의해 잘린
실제 목표각 변화와 구분한다. reset·WAIT에서는 0, 정책 단계 전환에서는 이전 값을
유지한다. 행동 급변 비용 계산 전에 관측과 보상에 같은 직전 값을 사용한다.
이전 190D를 목표로 맞추지 않는다. frame stack·RNN·연주 이벤트는 없다.
스트랩 진행 상태처럼 다음 물리 동작에 영향을 주는 신호는 기본 환경 검증 후 필요한
것만 명시하며, 과거 진단 관측을 전부 승계하지 않는다.

## 네트워크

- actor·critic은 가중치를 공유하지 않는 MLP, 각각 `512 → 256 → 128`, ELU다.
- actor는 관절별 Gaussian 평균과 학습 가능한 state-independent 표준편차를 사용한다.
- 잠재 행동을 tanh로 변환하며 log-prob는 변환의 Jacobian을 반영한다.
- critic 출력은 상태 가치 1개다. 블록별 인코더·별도 손 정책·비대칭 critic은 넣지 않는다.
- 관측 의미·action 순서·행동 의미가 다른 checkpoint는 거부하고 이전 모델은 재사용하지 않는다.

## 단계와 그립 판정

`WAIT → REACH → GRIP → TRANSPORT`의 하나의 정책을 사용한다. WRAP·MAINTAIN과
REACH 내부 ALIGN/APPROACH/HOLD 제어기는 만들지 않는다. REACH 이후 모든 단계에서
왼쪽 전체 관절을 제어한다.

| 단계 | 수행 내용 | 전환 |
|---|---|---|
| WAIT | release 후 초기 손 목표각 유지 | 3초 후 자동 REACH |
| REACH | 넥 아래 접근 목표로 손바닥 위치·방향 정렬 | 거리·방향 조건을 0.1초 유지 |
| GRIP | 엄지·반대편 손가락의 실제 지지력 형성 | 진입 조건을 0.15초 유지 |
| TRANSPORT | 그립 유지·위치와 회전 복원 | 목표·그립 동시 1초 유지 시 성공 |

| 조건 | GRIP에서 운반 진입 | TRANSPORT 유지 |
|---|---:|---:|
| 엄지 뒤쪽 법선력 | 2N 이상 | 1N 이상 |
| 정면 손가락 수 | 최소 2개 | 최소 2개 |
| 해당 손가락 각각의 법선력 | 1N 이상 | 0.5N 이상 |
| 해당 손가락의 정면 힘 합 | 4N 이상 | 2N 이상 |
| 엄지·해당 손가락의 접선 미끄럼 | 0.1m/s 이하 | 0.1m/s 이하 |

force 합에는 허용면·개별 힘·미끄럼 조건을 만족한 손가락만 포함하고, 조합은 바뀌어도
된다. 손바닥 접촉은 필수 성공 조건이 아니다. 최대 힘 제한은 우선 없으며 기준 힘이
실제 운반에 충분한지는 별도 검증한다.

힘은 손가락–기타 허용면의 압축 법선력이다. 다른 물체 접촉이나 body 전체 합력으로
그립을 판정하지 않는다. substep 집계 방식을 측정 검증에서 정하고 관측·보상·전환은
같은 시간 경계의 신호를 사용한다. REACH 6·GRIP 9 control step 연속 조건을 사용한다.

단계 전환은 이전 단계 action의 post-step에서 판정하며 새 단계 action·reward는 다음
step부터 적용한다. 조건이 깨지면 해당 연속 카운터를 초기화한다. TRANSPORT 손실은
아래 유예로 처리하며 GRIP으로 되돌아가지 않는다.

## 보상과 종료

프레임 상태 점수 `S`는 `[0,1]`이다. 허용 범위에서 포화하며 밖에서는 가까워질수록
증가하고 목표 근처에서 더 가파르게 증가한다. 거리·회전의 무차원 점수는 산술평균으로
결합한다. 미터·각도를 직접 더하지 않는다.

| 단계 | 점수 구성 |
|---|---|
| WAIT | policy 호출·PPO 샘플 없음 |
| REACH | 접근 거리·손바닥 방향 |
| GRIP | 허용면 접근·실제 법선력·낮은 미끄럼 |
| TRANSPORT | 위치·회전 복원 우선, 그립 유지 보조 |

```text
action_change_penalty = coefficient * mean((action - previous_action)^2)
frame_reward = S - 1 - action_change_penalty
```

단순 이동·과압 자체의 패널티는 없고 필요한 힘 이후 힘 점수는 포화한다.
진행 차분·전환·성공 보너스는 없다. 점수 식·scale·가중치·급변 패널티 계수는 미정이다.
행동 차이는 tanh 이후 정규화 행동끼리 계산한다. 고정 행동에는 비용이 없고, 유한한
계수에서 비용 상한은 `4 * coefficient`다. 실패 종료 비용 검증에 이 상한도 반영한다.
전환 조건과 점수 포화 상태를 맞춘다. 음수 보상만으로 단계 지연이 사라진다고 단정하지 않는다.

실제 실패에는 남은 시간과 할인율을 고려한 종료 비용을 적용한다. 그 식·하한·horizon과
단계 간 가치 비교는 보상 구현 전 검증한다. 기존 양수 프레임 보상·전환 +1·성공 시
남은 보상 보전은 폐기한다.

| 종료·시간 조건 | 초기 기준 |
|---|---|
| 성공 | 위치 오차 2cm·회전 오차 5° 이내와 유지 그립 조건을 동시에 1초 |
| 그립 손실 실패 | TRANSPORT 조건 연속 0.3초 손실, 회복 시 카운터 0 |
| WAIT | 3초 후 전환 |
| REACH timeout | 10초 |
| GRIP timeout | 5초 |
| TRANSPORT timeout | 15초 |

목표 유지 중 조건이 깨지면 성공 유지 카운터만 초기화한다. 성공·실패는 terminated,
timeout은 truncated다. timeout은 reset 전 마지막 관측으로 bootstrap하고 다음 episode로
GAE를 연결하지 않는다. 단계 timeout 이후 bootstrap이 의미하는 계속 수행 상태와
실패 비용의 horizon을 명시해 보상 우회 여부를 검증한다.

NaN/Inf·심한 관통·물리 폭주는 안전 종료 대상이다. 과압만으로 종료하지 않는다.
바닥 접촉·root 높이·스트랩 장력·속도의 상한은 정상 자유 기타 WAIT를 측정한 후 정한다.
이전 높이 0.15m·장력 300N 등의 상수를 자동 승계하지 않는다. 동시 조건의 우선순위는
안전/그립 손실 실패, 정상 전환/성공, timeout이다.

짧은 학습에서 확인하되 근거 없이 값이나 네트워크 층을 먼저 늘리지 않는다.

## 검증과 산출물

산출물은 `docs/2026-10-12/`의 실행별 `runs/<run_id>/` 또는 검증 폴더에 묶는다.

- noisy 평가와 노이즈 없는 기준 평가를 분리하고 동일 조건으로 checkpoint를 비교한다.
- 단계 진입률·소요시간, 거리·방향, 접촉력·미끄럼, 이동량·목표 오차·성공률·종료
  원인을 기록한다. 오른손 접촉은 부위·지속 시간을 남긴다.
- 최신·최고 평가·최종 checkpoint에 policy·optimizer·정규화 통계·진행 번호·설정·
  관측/action 의미를 저장한다. 임시 파일 저장·검사 후 atomic 교체한다.
- 재개는 학습 상태를 복원하되 환경은 WAIT부터 시작한다. 물리 궤적의 정확 재현을
  보장하지 않는다. 평가·렌더는 학습 환경 상태를 변경하지 않게 분리한다.
- 영상은 무자막으로 WAIT부터 실제 종료까지 담는다. 단계별 시작 영상은 진단용이다.
- pair contact API의 버퍼 수명·복사·환경/body 인덱스·힘 단위를 검증한다.
  native crash를 추측으로 확정하거나 짧은 통과를 장기 안정성으로 보고하지 않는다.

저장·평가·렌더 주기와 best 선택 순서는 짧은 실행 비용을 측정한 후 정한다.
기존 매 update 전체 저장·복잡한 주기 규칙은 자동 승계하지 않는다.

### 대안 채택 게이트

- 모든 후보는 같은 asset·초기조건·noise profile과 같은 종료/성공 판정으로 비교한다.
- 비교 대상은 성공률만이 아니다. 단계 진입률·도달 시간, pose 복원, grip 지속·미끄럼,
  오른손 간섭, 물리 안전 실패, 유한성, 학습/평가 처리량을 함께 기록한다.
- PPO smoke나 짧은 WAIT 통과는 학습 성능의 근거로 인정하지 않는다. baseline과 후보의
  전체 episode 평가와 재현 가능한 산출물이 있어야 한다.
- 후보가 복원 성과를 높이더라도 초기 접촉 안전 또는 동작의 목표 적합성이 악화되면
  바로 승급하지 않는다. 먼저 병목의 원인을 분리하고 비교 계획에 남긴다.
- 물리 G0와 자유 기타 G1은 서로 다른 과제다. G1 단독 성공을 전체 기타 연주 완성으로
  해석하지 않으며, 결합 뒤 Fret/Strike retention을 따로 평가한다. 전체 흐름과 다른
  연구 선택지는 [기타 연구 전체 흐름 검토](../guitar_research_review/README.md)에 정리했다.
- 별도 S2 실험의 요약과 남은 한계는 [2026-10-08 세션 정리](../stability_adapter_2/SESSION_WRAP_UP_2026-10-08.md)를 따른다. 해당 pause를 이 표의 비교 제안만으로 해제하지 않는다.
