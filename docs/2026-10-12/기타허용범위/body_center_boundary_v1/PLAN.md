# 바디 중심 기준 허용 박스 제안과 시각화

이 작업은 미팅용 범위 검토와 그림 생성이다. 학습·환경·기존 계획서와 값.txt는 변경하지 않는다.

- [x] 값.txt의 actor-root 범위 X[-0.50,-0.15], Y[-0.13,0.13], Z[0.70,0.95]m 및 XYZ Euler 범위를 확인한다.
- [x] 기존 저장 Isaac Gym 수평 초기 배치의 바디 기준점과 카메라·depth를 확인한다.
- [ ] 기존 위치 범위를 같은 회전에서 바디 중심으로 변환한다.
- [ ] 바디 중심 world 후보 X[0.11,0.23], Y[0.015,0.105], Z[0.67,0.77]m와 비교 그림을 만든다.
- [ ] 수치·이미지·원본 해시를 검증하고 설명을 작성한다.

표시용 바디 중심은 기타 local [0,-0.4,-0.0217]m이다. 질량중심이 아니며 박스는 기타 몸통 전체의 외곽 경계가 아니라 이 기준점의 위치 허용 범위를 나타낸다. 기존 범위의 바디 중심 환산은 선택한 기타 회전에 조건부이다. 축소 후보는 사람이 검토할 제안이며 접촉·도달·연주 성공을 검증한 범위가 아니다. 새 물리 실행은 하지 않는다.
