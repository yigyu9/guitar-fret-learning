## 반영 내용

- 자유 기타의 허용 범위 유지와 음악적으로 올바른 압현·타현을 함께 최종 목표로 둔다.
- 접촉 형상·실제 적용 물리 설정을 먼저 점검하고 시각 외형 개선을 별도로 검증한다.
- 원본 기술 성능·계약 확인 → 필요한 형상/물리 점검 → 자유 기타 단일 동작 → 제한된 보정 학습 → 양손·곡 통합의 검증 순서를 기록한다.
- Fret·Strike와 접근/안정화 보정의 관절 제어권을 중앙에서 합성한다. 제어 가능66관절과 학습 action 차원은 구분한다.
- 음악·허용 범위·자연스러움/물리를 분리 평가하고 동결 기술·접근 보정·학습 보정 및 스트랩 요인을 비교한다.
- 다음 소단계는 현재 기타 기준 손목·목표 프렛 오차와 접촉면 시각화, 제한된 왼팔 보정, 한 음 압현·유지 검증으로 연결한다.
