# 손 지지점에 접근하는 초기 자세: 다음 소단계 제안

2026-10-06. 상태: 사용자가 최대 ±0.3rad 초기각 보정 폭 확대를 승인했다. 첫 ±0.025rad 비교의
원자료는 docs/2026-10-12/stability_adapter_2/results/pose_strap_v1에 보존한다.
정적 지지점 접근 탐색과 최대 3개 native 후보 시험부터 진행한다.

현재 왼손 source palm 중심은 대응 넥 단면 하단보다 82.533mm 낮고,
길이맞춤 기준에서 0.5초 동안 팔/손–기타 native contact row가 없었다.
왼쪽 Shoulder_x −0.025rad는 중심을 약 5.55mm 올리지만, 같은 길이의
0.5초 기타 오차 변화는 0.2mm 미만이다. 작은 초기각 민감도만으로
지지점에 도달하지 못했으므로 방향을 무작위 탐색에서 지지점 접근으로 바꾼다.

## 확인할 변경과 그대로 유지하는 조건

다음에는 양쪽 Thorax/Shoulder/Elbow/Wrist의 유효 관절만 현재 기준에서
최대 ±0.3rad(약 17.2°)까지 단계적으로 조정하는 초기 자세 탐색을 제안한다.
모델 한계와 이 범위의 교집합을 쓰며 손가락 초기각은 먼저 유지한다.
첫 실행은 왼팔 유효 12관절만 ±0.05/0.1/0.2/0.3rad의 절대 보정 그리드로
2회 좌표별 탐색했다. 오른팔과 손가락 초기각은 유지했다. 좁힐 구간은
이후 0.025~0.05rad 단위로 비교한다. 가장 가까운 source 형상 위치를 찾는다.
여러 관절을 함께 조정한 값은 입력 JSON과 시각화로 제시한다.

root, C02 하체 초기각, 기타 +5mm/초기 회전/고정 유지 목표, 몸통9 목표/gain,
baseline PD/solver와 원본 스트랩 경로·수식·300N cap을 유지한다.
실행 중 absolute rest length는 고정하며 기존에 측정한 길이 0/10/20N 후보를
같은 상체에서 비교한다. 하체 운동·접촉은 물리에 남고 하체 자세로 순위를 매기지 않는다.
기타/손을 고정하거나 상태를 지속 덮어쓰지 않고, 능동 스트랩·학습을 추가하지 않는다.

## 계획과 검증

- [x] 1. 첫 단위는 왼손 palm–넥 source convex-hull 거리와 witness points를 기록한다.
  finger–넥 및 오른손/팔–기타 body의 상세 근접 지점은 후속 항목이다. 기존 전체
  사람–기타 source pair 검사에는 해당 활성 형상도 포함된다. 다음으로 source witness points와
  간격을 기록한다. 왼손 법선 proxy +Z dot≥0, 유효 국소 단면 아래 조건을 유지한다.
  사람–기타 음수 source gap 후보는 제외한다. 가까운 양수 gap은 지지 후보의
  탐색 기준이며 native clearance/지지 힘 보증은 아니다. 거리를 새로운 필수 gate로 만들지 않는다.
- [ ] 2. 근접 후보 최대 3개의 초기 장면을 같은 시점/축척으로 시각화하고,
  0.1초 native 실행에서 실제 손/팔 접촉, 기타 p/q, 장력과 실제 상체 자세를 비교한다.
- [x] 3. 근접 후보의 자세·스트랩 조합 2개를 기준 대조군과 0.5초로 늘렸다.
  0.5초에서도 지지가 생기지 않아 이 후보의 1초 연장은 하지 않았다.
  양손의 연주 움직임 여유와 초기 자세의 자연스러움을 검토한다.
- [ ] 4. 성공 여부·한계·다음 수정 방향을 누적 문서에 넣고 별도 검수한다.

이 단위의 평가 목표는 지지 접촉이 생기면서 초기 기타 이동·회전이 줄어드는지 확인하는
것이다. 최종 수치 성공 기준과 작은 손/팔 동작 안정성은 합의·검증 전까지 미완료다.
실제 팔이 목표에서 크게 처지면 초기각으로 숨기지 않고 관절·접촉별로 기록한다.
이후 관절 feedback의 보정 범위/연주 제어권 또는 gain 변경이 필요하면 별도 제안한다.

## 실제 실행과 다음 판단

원거리 backend query의 cutoff 1m에서 같은 초기 palm–neck가 음수로 나오는
문제를 발견했다. 기존 20mm query는 원거리 결과를 잘라 반환하므로 음수 pair0이며,
cutoff0.1m는 +63.98mm였다. 잘못된 원거리 부호를 순위에 쓴 첫 검색/입력/소스를
`hand_support_v1/search`에 보존하고 native 후보로 실행하지 않았다.
source convex hull의 6변수 closest-point solve를 사용한 `search_v2` 159개를
검증했다. 3mm는 source 근접 탐색 목적이며 PhysX clearance/지지 보증이 아니다.
선택 지점은 독립 vertex-support 거리 범위와 비교했고, 최적성의 수치 오차도 남긴다.

초기 source hull 거리가 기준 64.026mm에서 3.139/3.270/2.388mm로 줄었으나
L_Thorax 경로가 17.706mm 늘었다. 기존 절대 LA를 유지한 3개 후보는 첫 적용
장력 106.236N과 0.1초 약24.215mm/8.612° 오차로 악화됐다.
이에 같은 자세의 절대 LA를 명시적으로 1.101080132m(초기 계산 장력0N),
1.099413465m(10N), 1.097746798m(20N)으로 비교했다. 실행 중 길이는 고정했다.
정적 검색 중 통과한 0.800mm 근접 자세 1개도 0N 길이로 대조했다.

조합 0N의 0.1초 오차는 6.874~6.878mm/1.520°였다. 0.5초에는 두 조합 모두
약61.483mm/8.876°이며 LH–기타 native contact row0이다. 실제 main 관절 raw
편차는 약18.314°, palm–neck source hull 거리도 약146.55~148.50mm로 커졌다.
가까운 초기 배치만으로 손 지지는 유지되지 않았다. 하체는 비교의 중단 사유로 쓰지 않는다.
