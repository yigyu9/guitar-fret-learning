# 새 기타 연주 학습 확인 사항

2026-10-15 사용자 답변을 반영했다. Q1·Q2는 확정되었으며 현재 추가 답변이 필요한 항목은 없다. 안정적인 초기 자세 연구가 마무리될 때까지 이 작업에서는 모델 파이프라인 설계에 집중한다. 세부 환경 구조는 이후 기존 fret·strike 환경을 참고해 새로 설계·구현한다.

## 그대로 적용하는 결정

- 기존 Fret·Strike·잔차 정책의 가중치는 새 학습에 사용하지 않는다. 과거 파일은 재현용으로 보존한다.
- 오디오에서 생성한 연주 계획과 현재 물리 상태를 입력받아 humanoid 관절 목표를 출력한다. 기타는 고정하지 않는다.
- 현재 실험은 root·하체 고정, 내부 충돌 ON, 스트랩 OFF다. 이 조건의 결과를 동적 하체 제어 성과로 설명하지 않는다.
- 사람 동작의 유사성보다 음악 시간 조건, 목표 줄·프렛, 악기 지지를 분리해 평가한다.
- 실제 줄 진동·음향 합성이 없는 조건에서 기하/접촉 기반 연주 판정을 실제 음향 재현으로 표현하지 않는다.

## 답변이 확정된 항목

아래 결정은 이후 설계와 평가에 적용한다. 이미 완료된 파일럿의 곡·조건·결과는 당시 기록으로 보존한다.

### Q1 최종 연주 평가의 시간 허용오차

기존 Strike 계약은 50ms를 기준으로 삼고, 이번 첫 음악 학습의 타현 후보 검사는 100ms의 넓은 창을 사용한다. **최종 결과는 50ms 기준을 주 지표로 두고 100ms 결과를 초기 학습 진단으로만 병기하는 방향**을 제안한다. 기존 기준과의 비교를 유지하면서 초기 학습의 진행도도 볼 수 있다.

**사용자 답변: 제안대로 확정.** 최종 주 지표는 목표 시각 대비 ±50ms, ±100ms는 초기 학습 진단으로 병기한다. 시간 창을 만족했다는 사실만으로 목표 줄·운지·접촉·유지까지 성공했다고 판정하지 않는다.

### Q2 우선 완성할 시연 구간

**사용자 답변: 우선 곡은 `05_BN2-131-B_solo`.** 복잡하지 않은 곡부터 진행한다는 방향을 적용한다. 이 곡을 파이프라인의 입력 예제로 사용하며, 구체적인 학습 구간과 순서는 환경 설계 시 정한다. 앞서 사용한 `00_SS1-68-E_comp`의 첫 단음·두 이벤트·8개 이벤트 조건을 새 곡의 확정 학습 일정으로 자동 승계하지 않는다.

기존 검사에서 새 곡의 B/C/D 선택 입력은 유효했고 관련 입력 SHA도 그대로다. 전체 66개 원본 이벤트 중 `event-000042`는 기존 컴파일러의 미지원 목록에 있다. 이는 곡 전체 지원을 완료했다는 뜻이 아니며, 이후 구간 선정 시 누락을 숨기지 않고 확인한다.

## 현재 작업 우선순위

1. 안정적인 초기 자세 연구는 별도 작업으로 계속한다.
2. 이 작업은 음악·물리 상태의 표현, 양손과 악기 지지의 정보 공유, 행동 출력의 소유권, 학습 단계와 비교 실험을 설계한다.
3. 초기 자세 연구가 마무리되면 fret·strike 환경의 목표·접촉·보상·종료 구조를 참고하여 새로운 환경을 상세 구현한다. 기존 정책 가중치는 재사용하지 않는다.

현재 모델 설계 초안은 [모델 파이프라인 설계](/home/ajou/yigyu/3/docs/plans/music_model_pipeline_20261015.md)에 정리한다. 이 작업에서 세부 환경 변경이나 추가 native 학습은 시작하지 않는다.

후속 요청에 따라 안정성·음악 목표 공동학습의 장애와 개선안을 [상세 근거 문서](/home/ajou/yigyu/3/docs/2026-10-12/stability_adapter_2/results/pipeline_learning_design_v2/README.md)에 추가했다. 선택 곡의 짧은 음·빠른 전환, 누락된 과제 진행 관측, PPO 갱신 크기를 근거로 설계를 보완했으며 추가 사용자 답변이 필요한 항목은 없다.

## 답변 이전 파일럿 결과

음악 이벤트 입력 → 현재 기타 좌표계의 목표 → 공동 정책의 54개 관절 목표 → native 물리 실행 → 실제 모션·연주 후보 평가를 연결했다. 과거 정책과 Stage A 가중치를 가져오지 않고 새 정책을 초기화해 16회 갱신·4,096개 전이를 학습했다. 이번 실행의 오류와 제외 전이는 0개다. 단음·두 이벤트·8개 이벤트의 입력 시간축도 실제 환경에서 검증했다.

**연주 성공은 아직 아니다.** 첫 단음의 발음 구간에서 손가락 marker와 목표 프렛의 평균 거리는 초기 154.19mm → 학습 후 154.10mm로 사실상 그대로다. 접촉·기하 조건을 함께 만족한 유지 시간은 0초다. 입력·출력과 학습 경로가 작동함을 확인한 첫 파일럿이며, 8개 이벤트 정책을 학습하거나 곡 연주를 완성한 결과는 아니다.

당시 초기 손 위치에서 첫 목표까지 약 15cm를 접근하는 문제가 남았고, 짧은 파일럿의 정책 변화량도 크게 나타났다. 이 결과만으로 네트워크 구조가 실패 원인이라고 단정하지 않는다. 현재 진행 중인 초기 자세 연구 이후 도달 가능성·접근→접촉→유지의 학습 조건과 정책 갱신 크기를 함께 검증한다.

실제 관절·기타 궤적과 전신·양손 영상은 [구현 및 실행 결과](/home/ajou/yigyu/3/docs/2026-10-12/stability_adapter_2/results/fresh_music_v1/README.md)에 모았다. 현재 root·하체 고정이라는 한계, 데이터 한 곡의 계획 파일 누락, 과거 실패와 재현성 사고도 해당 문서에 명시했다.
