# 엄지2 source 7조건의 root 확인 범위

v1은 thumb2의 자식인 thumb_pad까지 nonmoving identity 대상으로 검사한 구현 오류로 exit1 중단했다. v1 소스·로그·입력 사본·검수 기록을 보존하며 정상 7조건 완료로 취급하지 않는다. v2는 XML subtree의 네 body를 움직이는 대상으로 다루고 실제 collision mesh는 thumb2/3 둘만 변환한다. Finger1 다축 native 변환은 고정했다.

v2는 source 실행 exit0, 68입력·68사본의 저장 전후 SHA 일치, 8검사와 7조건을 기록했다. 각 조건에서 thumb2–guitar 교차만 남고 cross-hands/self1188은 clear다. 최소 LP 공통내접반경은 −0.2rad의 3.054823670mm이며 기준은 4.288364821mm다. Clear 후보가 없어 proposal과 native 실행을 만들지 않았다. 새 물리·actor·학습은 0회이고 5초 기타 안정성은 측정하지 않았다.

LP 반경은 PhysX 침투 깊이가 아니며 rear-patch source 거리도 실제 접촉 증명이 아니다. 이번 7표본은 thumb2 전체 가동범위의 불가능성을 증명하지 않는다. 그림은 저장 source 자료이며 재사용한 Gym 시작 이미지는 직전 손5관절 실제 0step 거절 장면이다. 이번 새 Gym 렌더로 표현하지 않는다. 기존 영상 모음 144개는 그대로 유지한다.

소비된 v2 코드의 미실행 selected 분기에 v1 trial 경로가 남아 있다는 검수 Warning을 보존한다. selected=null이라 해당 분기는 실행되지 않았으며 이후 후보 생성에는 재사용하지 않는다. 다음 기저부 계획은 별도 새 코드·결과 경로를 사용한다.

다음 작업은 source 범위 안의 thumb1_x−.05/−.1 또는 thumb1_y+.05/+.1rad 네 초기각을 순서별 실제 native 직접 형상 검사로 확인하고, 첫 통과 조건만 같은 초기화에서 5초 기록하는 것이다. 이 문서 작성 시에는 미실행이다. LA·기타 초기 p/q·root/하체·몸통9 목표·최종66 권한은 유지한다. 범위 호환과 초기 형상 필요조건을 자유 기타 안정화·자연스러운 연주 완료로 확대하지 않는다.

최종 감사는 저장 로그·입출력·현재 SHA와 source 사본·문서 prefix·이전 봉인 inventory·영상 모음을 검사한다. Geometry solver/physics/분석 producer는 재실행하지 않는다.
