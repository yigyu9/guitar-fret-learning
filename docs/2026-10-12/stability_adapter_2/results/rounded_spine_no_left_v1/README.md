# 척추 분산 굽힘·왼손 없는 초기 유지 — 첫 비교 완료

Torso·Spine·Chest에 굽힘을 나눈9°/12° 자세를 구현하고 실제 Isaac Gym에서 네 조건을각5초시험했다. **왼손이없는조건은33–36cm·83–88° 움직여 초기 기타 유지에실패했다.** 더 둥글게 굽힌 자세만으로 왼손 지지를 대체하지 못했다. 세 비지지 조건에서 모든 왼팔·왼손과기타접촉은300개 native query 모두0이어서, 왼손이 다시받친 결과는 아니다.

## 조건과 제어

원래3°전경의왼손철수, 분산9°의왼손지지/철수쌍, 분산12°의왼손철수를비교했다. 분산9°는 원기준대비Torso2.25°/Spine5.625°/Chest9°누적 world전경,12°는3°/7.5°/12°다. 세관절구간으로 상부에굽힘을더분배하며각 native DOF scalar 변화는원기준±5°/모델한계 내다. 이는공용모델의분절자세변경이며연속척추형상이나새자산을추가한것이아니다.

왼손철수는기존 palm 위치에서 Pelvis앞8cm·world아래3cm의초기IK다. **왼손을처음부터떼어시작하며,2초뒤놓는동적release시험은아니다.** 손가락·머리초기각은유지하고왼팔만움직였다. 오른팔±0.3rad·왼팔±0.6rad/모델한계의이번초기진단범위를사용했다. 원본스트랩ON·길이법칙,기타초기p/q,고정root/하체,PD속성·solver는동일하다. 원본스트랩이있으므로스트랩없는유지로해석하지않는다.

각 초기q_ref를5초내내일정한PD목표로제출하고실제상태는물리에맡겼다. 음악·Fret/Strike·체크포인트·안정화정책·학습·초기노이즈·preload/PI/실시간IK·기타나손부착·추가인위적힘·제어중state덮어쓰기를사용하지않았다.
