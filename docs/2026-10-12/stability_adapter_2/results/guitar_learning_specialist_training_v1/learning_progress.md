# 손별 실제 학습의 확정 분석

왼손·오른손 독립 학습은 정상 종료했으며, 활성 Actor와 Critic의 갱신을 확인했다. 이번 예산에서는 왼손 접근 거리가 약 1mm 줄었지만 실제 목표 압현 접촉·유지와 오른손 유효 현 통과는 한 번도 발생하지 않았다. 전문가 결합으로 승격할 근거는 확보하지 못했다.

| 항목 | 왼손 | 오른손 |
| --- | ---: | ---: |
| 완료 업데이트 | 28 | 29 |
| PPO에 반영한 60Hz 전이 | 14,336 | 14,848 |
| 완료 에피소드 | 160 | 168 |
| 손별 단계 성공 | 0 | 0 |
| 목표 압현 후보 60Hz 끝점 | 0 | 0 |
| 240Hz 누적 목표 접촉 획득·유지 | 0회·0초 | 0회·0초 |
| 유효 기하 현 통과 | 0 | 0 |
| 원래 양손 음악 매칭50/100ms | 0/0 | 0/0 |
| 물리 실패 에피소드 | 0 | 0 |
| 버린 부분 수집 전이 | 0 | 0 |

각 실행은 새로운 seed7 초기 모델,4환경,H128,medium,actor_lr3e-5,초기 정규화 Gaussian 표준편차 약0.049787을 사용했다. 다른 손의 정규화 행동은 전 구간0이고 해당 Actor 인코더·출력층17개 tensor 및 비활성 log_std는 초기값과 정확히 같았다. 양손을 서로 다른 초기 모델로 단독 학습한 결과이며, 기존 동시 학습과의 통제 비교가 아니다.

## 초기5개와 마지막5개 업데이트

아래 거리 값은 물체 좌표계에서 계산한 marker 접근 지표다. 손가락 패드의 표면 간격이나 압력은 아니다. 전체 시간·구간별 전이 통계는 해당5개 업데이트의 전이만 사용했다. 에피소드 보상은 그5개 안에서 종료된 에피소드의 전체 반환값이며, 이전 업데이트에 속한 시작 구간도 포함할 수 있다.

| 지표 | 왼손 초기5 → 마지막5 | 오른손 초기5 → 마지막5 |
| --- | ---: | ---: |
| 해당 전이 수 | 2,560 → 2,560 | 2,560 → 2,560 |
| 종료 에피소드 수 | 28 → 28 | 28 → 32 |
| 에피소드 평균 보상 | −0.333742 → −0.325450 | −0.413075 → −0.413897 |
| 전이 평균 보상 | −0.00357326 → −0.00347542 | −0.00447211 → −0.00449619 |
| 전이 평균 안정성 비용 | 1.97693e−5 → 1.13887e−5 | 1.41175e−6 → 1.48523e−6 |
| 학습 중인 왼손의 전체 거리 | 20.856 → 19.781mm | 해당 없음 |
| 왼손 press~onset 거리 | 20.805 → 19.771mm | 해당 없음 |
| 왼손 onset 직전 거리 | 20.939 → 19.841mm | 해당 없음 |
| 오른손 guide 거리 | 해당 없음 | 50.561 → 50.789mm |
| 오른손 sweep 구간 거리 | 해당 없음 | 55.170 → 55.326mm |

왼손 onset 직전 표본은 각 구간28개다. 왼손 press~onset 표본은224→244개이고, 오른손 sweep 표본은280→280개다. 오른손 마지막5개에서 종료32회와 onset 직전28표본이 다른 것은 업데이트 경계가 에피소드와 일치하지 않기 때문이다. 수치의 분모와 경계는 원자료대로 유지했다.

왼손은 접근 보상과 거리에서 작은 개선을 보였다. 오른손은 이번 비교에서 거리 감소가 없었다. 둘 다 실제 성공을 경험하지 못했으므로 학습 완료나 기능 확보로 설명하지 않는다. 탐색·목표 접근·성공 판정과 제어 가능성의 검토가 우선이며, 이 결과만으로 망 용량 부족이나 목표의 물리적 도달 불가능성을 결론 내릴 수 없다.

## 안정성 및 PPO 확인

60Hz 끝점에서 전체 지지와 양발 접지는 두 실행 모두100%였다. 세 지지 부위의 동시 양성 비율은 왼손88.392857%,오른손99.986530%였다. 이는 전체 지지 소실과 구분한다. 기타 변위/회전 최댓값은 왼손1.993mm/0.006556rad,오른손0.573mm/0.001980rad였으며 발 이동 최댓값은 각각0.319mm/0.0833mm였다. 기존240Hz 통합 물리 실패 판정은 모두0이었다. 이 값은 이번 짧은 단음 학습 구간의 검사이며, 과거 초기 자세 V3 정밀 감사와 동일한 인증이 아니다.

최종 모델은 모두 유한하며 활성 Actor 인코더·출력층과 공통 Value 인코더가 실제로 변경됐다. 최대 analytic KL은 왼손0.008048,오른손0.002166으로 설정 한계0.02 이내였고 재시도는0회였다. 기록된 actor gradient norm은 각 업데이트의 마지막 minibatch에서 clipping 이전 값이며, 전체 minibatch 최댓값이 아니다.

최종 활성 Gaussian 표준편차의 평균/최솟값/최댓값은 왼손0.04978707/0.04975496/0.04981669,오른손0.04977968/0.04976357/0.04979163이었다. 이는 tanh 이전 정규화 행동 분포이고 관절각 rad가 아니다. 비활성 채널의 forward 표준편차 exp(−3)은 KL 계산을 위한 placeholder이며 실제 탐색 잡음을 샘플링하지 않는다. optimizer의 비활성 log_std 모멘트도0이었다.

## 수집 경계·독립 검산

왼손은 종료 시 worker당64tick,오른손은 worker당16tick의 미완료 에피소드가 남았다. 이256/64개 전이는 완료된 rollout에 포함되어 PPO에 반영됐으며, 버린 부분 수집이 아니다. 완료 에피소드 수에는 넣지 않았다. 완료 에피소드 중 업데이트 경계를 가로지른 것은 왼손100회,오른손104회였다.

첫 rollout의 실제 행동과 저장 latent의 tanh 최대 오차는 두 실행 모두1.49e−8이었다. 초기 모델 CPU 재계산과 저장 log probability의 최대 차이는 왼손7.63e−6,오른손1.91e−6이었다. native float64 에피소드 보상과 float32 누적 로그의 최대 차이는 왼손2.98e−8,오른손1.49e−8이었다. 허용오차는 보상 절대1e−6·비용 절대1e−8과 상대1e−6이며 실제 차이를 별도 기록했다.

최종 분석은82개 입력의 SHA를 분석 전후 비교해 무변경을 확인했다. 분석 helper를 가져오지 않는 별도 scalar/gzip 재독해로 초기·마지막5개 평균 보상,왼손 onset 직전 평균,완료 에피소드 수,성공·실패·후보0을 다시 계산해 JSON과 일치함을 확인했다.
