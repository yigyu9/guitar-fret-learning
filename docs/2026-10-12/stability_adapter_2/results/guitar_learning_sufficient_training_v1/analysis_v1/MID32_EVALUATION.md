# B32와 추가 32회 모델의 고정 조건 평가

**중간 모델의 평가다. 본 학습의 최종 결론이나 일반화 검증이 아니다.** 학습 전 B32와 추가 32회 모델(optimizer 누적 64회)을 같은 seed 순서로 각각 결정적·확률적 20회 평가했다. 네 평가 모두 실제 종료된 case만 집계했다. 생산 코드·입력·원자료를 변경하지 않았고, 이 분석에서 native·GPU·새 평가를 실행하지 않았다.

`mid32_evaluation.json`에 모든 paired case·수치·SHA를 기록했다. parent/case/runtime 완료 기록, policy 행동·teacher 개입 없음, seed 순서·mode·checkpoint load 뒤 seed 적용·checkpoint SHA를 검사했다. 각 case result의 parent pin과 trace·NPZ·계약·설정·초기 상태·seed 등 원자료 파일 SHA도 모두 일치했다. root의 별도 native 원자료 재감사는 이 저장 기록 검사를 대신하지 않으며 별도로 확인해야 한다.

## 실제 관찰

| 지표 | B32 결정적 | 추가 32회 결정적 | B32 확률적 | 추가 32회 확률적 |
|---|---:|---:|---:|---:|
| 성공 | 20/20 | 20/20 | 8/20 | 11/20 |
| 목표 접촉 유지율 평균 | 100% | 100% | 45.7083% | 67.9167% |
| 준비 clean 시간 평균 | 176.667ms | 198.750ms | 60.417ms | 77.708ms |
| 오압현 시간 평균 | 0 | 0 | 125.000ms | 25.000ms |
| 미압현 시간 평균 | 0 | 0 | 145.833ms | 133.229ms |
| 목표 접촉 해제 통과 | 20/20 | 20/20 | 20/20 | 20/20 |
| 물리 실패 | 0 | 0 | 0 | 0 |
| 평균 reward | 2.92239 | 2.94313 | 1.15657 | 1.73555 |
| 평균 cost | 0.050634 | 0.050942 | 0.045708 | 0.049905 |

결정적 정책은 성공률과 음 구간 유지율이 이미 기준 모델에서 포화되어 있다. 추가 32회에서는 준비 접촉 시간이 평균 22.083ms 늘었지만 성공 횟수는 같다. 확률적 정책은 이 20조건에서 성공이 3회 늘고 유지율이 평균 22.2083%p 증가했으며, 오압현·미압현 평균도 줄었다. 평균 안전 cost는 약 0.004196 늘었다. 모든 평가에서 물리 종료 실패는 0이지만 비용까지 동일하다는 의미는 아니다.

## 같은 seed끼리 비교하면 판정이 많이 바뀐다

확률적 평가에서 **8개는 실패→성공, 5개는 성공→실패**하여 순증 3개다. 20개 중 13개 조건의 성공 판정이 바뀌었다. 기존 성공을 모두 유지하면서 실패만 해결한 결과가 아니다.

| 전환 | 개수 | seed |
|---|---:|---|
| 성공 → 성공 | 3 | 127, 131, 179 |
| 실패 → 성공 | 8 | 103, 107, 109, 163, 167, 181, 193, 197 |
| 성공 → 실패 | 5 | 101, 137, 139, 149, 191 |
| 실패 → 실패 | 4 | 113, 151, 157, 173 |

원래 seed 순서는 `[101,103,107,109,113,127,131,137,139,149,151,157,163,167,173,179,181,191,193,197]`다. 각 seed의 성공·hold·ready·wrong·missing·release와 변화량은 JSON의 `paired.stochastic.rows`에 같은 순서로 남겼다. 결정적 평가는 모든 seed가 성공→성공이다.

## initial_state SHA 차이의 실제 내용

두 모델의 initial_state 파일 SHA가 같은 것은 각 mode에서 case0 한 쌍뿐이다. 그러나 이를 초기 자세가 달라졌다는 뜻으로 해석하면 안 된다. `mid32_initial_state_leafdiff.json`에서 **두 mode의 20쌍 전부**를 비교한 결과, 다음 블록은 값이 정확히 같다.

- humanoid 관절 위치·속도 105개
- 기타 body들의 위치·회전·속도
- target/last_target 105개와 codec target 81개
- previous action 39개와 controller history

차이는 전부 `contact_history` 내부의 raw 접촉과 측정 접촉 특징에 있다. 예를 들어 결정적 case1의 raw 접촉 수는 32→30개, 목표의 contact feature 수는 14→12개다. 확률적 case1은 각각 29→32개, 11→14개다. case2는 결정적 31→32개·13→14개, 확률적 34→32개·16→14개다. uncertain evidence ID와 raw 접촉의 lambda·localPos·initialOverlap 값도 달라진다. 경로 문자열이나 episode index만 달라져 생긴 SHA 차이가 아니다.

예시로 결정적 case1의 저장된 raw 배열 index8 lambda는 16.29754→17.00214다. 다만 raw 접촉 배열은 특징 identity로 대응시킨 목록이 아니므로, 같은 index의 수치 차이를 물리적으로 동일한 접촉점의 힘·위치 변화라고 바로 해석하지 않는다. 실제 초기 자세·명령 블록은 같지만 접촉 측정 이력은 동일하지 않다는 수준까지 확인했다. 그 원인이 reset 시점의 cache·solver history·접촉 목록 생성 중 무엇인지는 이 JSON 비교로 확정하지 않는다.

따라서 이 비교는 **같은 준비 자세와 seed/reset 절차의 paired 조건 비교**이며, hidden PhysX 상태와 초기 접촉 측정까지 완전히 동일한 결합 실험이라는 주장은 하지 않는다.

## 현재 판단

이 중간 고정 평가에는 확률적 수행이 나아진 지표가 있다. 동시에 상당수 조건의 성공·실패가 바뀌고, 학습 자체의 첫/뒤 16업데이트 성공률에는 일관된 상승이 없어 아직 탐색에 강한 정책이 완성됐다고 보기는 어렵다. 모델을 중간 평가 결과로 선택하는 단계이므로 최종 독립 검증처럼 다루지 않는다.

20개 seed는 한 학습 계보의 정책 RNG와 같은 준비 자세의 persistent reset 조건이다. 독립된 20개 학습이나 초기 자세 다양성 표본이 아니며, 8/20→11/20만으로 통계적 유의성·확실한 일반화 개선을 주장하지 않는다. 전곡·양손·접촉 회복·음향을 검증한 결과도 아니다. 해제 20/20 역시 목표 접촉을 먼저 획득했다는 보증이 아니다. 전체 학습과 마지막 평가가 끝난 뒤 결론을 갱신한다.
