# 같은 BC 관측에서 B32 → 최종 정책 출력 비교

가중치 변화와 실제 출력 변화를 구분하기 위해 B32와 추가 128회 최종 모델을 같은 고정 관측에 입력했다. **CPU 결정적 forward만 수행했으며 native·GPU·새 시뮬레이션·학습·optimizer step은 없다.** 최종 정책의 실제 수행 평가는 아직 별도 진행 중이다. 결과는 `actor_output_final.json`, 재현 도우미는 `actor_output_final.py`다.

두 모델의 identity가 같고, 봉인 `frozen_execution_view_v2/guitar_learning`의 정책 코드만 import했다. 구성된 architecture를 정확히 대조하고 모든 state tensor를 strict load했다. 관측은 중간 32회 분석과 동일한 핀된 teacher BC 궤적 `single_a_contact_v1/case_000/demonstration.npz`에서 index `0,4,…,236`의 60개를 고정 선택했다. 0–3.933333초이며 준비 30개·음 구간 8개·음 종료 뒤 22개다. 선택 input은 state 60×500, events 60×64×24, mask 60×64, priority events 60×2×24, priority mask 60×2다. state 범위 −1–1.25, 원자료 observation/action 계약은 모델 계약과 정확히 같다.

NPZ SHA는 `de54a0cd416a903cab0d9fbaa5f99970401bd8ca0675df8a51aed827cd8e2b6d`, 최종 checkpoint SHA는 `ae9770470cdbd7141bf47c277a4a81757a753841beab18419c60de31f2e9a7e6`다. 모든 읽은 소스·데이터·checkpoint는 분석 전후 SHA가 같다. 전체 경로·pin·shape·선택 시각은 JSON에 있다.

같은 관측에서 왼손 출력은 실제로 달라졌다. 중간 32회 때의 결정적 행동 차이 RMS 0.000067734보다 최종 값이 크다. 그러나 이는 이 teacher 궤적의 관측에 한정된 비교다. tanh(μ)는 정책의 결정적 명령이며 확률적 행동의 기댓값 `E[tanh(z)]`가 아니다. 수치는 정규화된 행동이고 관절각 단위가 아니다.

각 축 기준 σ로 나눈 latent 평균 차이 `Δμ/σ`는 RMS **0.117694σ(약 11.77%)**, 최대 **0.864612σ(약 86.46%)**다. 기준 σ는 0.002963385–0.003037399이다. 전체적인 평균 이동은 탐색 표준편차보다 작지만 일부 관측·축의 변화는 상당하며, 모든 차이를 무시할 수 있다고 말할 수 없다. tanh 이후의 잡음은 상태별로 압축되므로 정규화 행동 차이를 σ≈0.003과 그대로 나누어 같은 의미로 비교하지 않는다.

이 표는 전체 학습 상태나 실패·회복 상태의 대표 표본이 아니다. 고정 입력의 한 번의 출력 차이로 rollout에서 누적되는 상태·관절 목표·기하·접촉 변화를 측정한 것도 아니다. 작은 명령 차이가 접촉 경계에서 큰 결과 차이를 낼 수 있고, 출력 변화가 있다고 연주 성공을 보장하지도 않는다. 최종 평가와 함께 보되 정체 원인·일반화·회복 성공의 인과 근거로 확대하지 않는다.
