# B32 학습 전 평가 집계

집계 대상은 `baseline_deterministic_v2`와 `baseline_stochastic_v2`다. 실패한 v1 실행은 포함하지 않았다. 두 실행은 각각 실제 20회로 완료되었고, 저장된 parent/case/runtime 종료 기록의 오류·입력 변경·금지 호출 검사는 통과 상태다. 이 문서는 저장된 요약의 집계이며, root가 별도로 수행하는 원자료 재감사 결과를 대신하지 않는다.

| 지표 | 결정적 정책 | 확률적 정책 |
|---|---:|---:|
| 왼손 단음 유지·해제 성공 | 20/20 | 8/20 |
| 실제 목표 접촉 유지율 평균 | 100% | 45.7083% |
| 준비 구간 clean 접촉 시간 평균 | 176.667 ms | 60.417 ms |
| 목표 접촉 해제 통과 | 20/20 | 20/20 |
| 오압현 시간 평균 | 0 ms | 125.000 ms |
| 미압현 시간 평균 | 0 ms | 145.833 ms |
| 물리 실패 | 0/20 | 0/20 |

확률적 평가 실패 12회는 모두 준비 clean 접촉 시간이 0이었다. 그중 9회는 음 구간 목표 유지율도 0이고, 나머지 3회는 각각 8.3333%, 44.1667%, 61.6667%로 현재 90% 조건에 미달했다. 따라서 학습 전 B32는 같은 준비 자세에서 평균 행동을 실행할 때는 성공하지만, 현재 탐색 분포로 행동을 표본 추출하면 준비 접촉 확보가 흔들리는 상태다. 이것은 탐색에 대한 취약성을 시사하며, 이번 평가만으로 그 원인이 보상·관측·제어 중 하나라고 확정할 수는 없다.

해제 20/20은 접촉을 먼저 획득했다는 뜻이 아니다. 현재 판정은 지정 손가락의 목표 접촉 증거가 해제 창에 없는지를 따로 검사하므로, 한 번도 누르지 못한 실패에서도 해제는 통과할 수 있다. 이 실행에는 R1/R2 보상 변경이나 접촉 획득 latch가 적용되지 않았다.

20개 seed는 두 평가에서 동일한 `[101,103,107,109,113,127,131,137,139,149,151,157,163,167,173,179,181,191,193,197]`이다. 이는 정책 난수와 같은 장면의 반복 reset을 비교하는 조건이다. 초기 자세·악보·기타 배치가 다양한 일반화 검증이나 서로 독립된 20개 학습 seed가 아니다. 결정적 정책은 난수 행동 표본 추출을 사용하지 않으므로 seed 개수를 결정적 정책의 다양성으로 해석하지 않는다.

수치 원자료: `baselines_v2.json`. 재현 도우미: `analyze.py`(출력 JSON에 도우미 SHA 기록). 본 학습 `training_long_v1`은 원 B32에서 별도로 출발하며, 연결 검증 `training_smoke_v2`의 1업데이트는 학습 계보에 합산하지 않는다.
