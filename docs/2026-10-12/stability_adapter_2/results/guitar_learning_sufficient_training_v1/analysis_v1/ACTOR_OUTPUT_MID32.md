# 고정 BC 관측 60개에서의 B32 → 추가 32회 정책 출력 차이

가중치 변화와 실제 정책 출력을 구분하기 위해 **같은 고정 관측**을 두 checkpoint에 입력했다. 본 분석은 CPU의 결정적 forward만 수행하며, 시뮬레이션·GPU·학습·optimizer step은 실행하지 않았다. 결과는 `actor_output_mid32.json`, 재현 코드는 `actor_output_mid32.py`다. 전체 학습과 중간 native 평가는 여전히 진행 중이다.

## 출처·모델·관측 범위

모델은 `PARAMETER_MID32.md`의 B32 봉인 복사본과 `training_long_v1/checkpoint_000031.pt`(추가 32회, 누적 64회)다. 두 identity가 정확히 같으며, 봉인 `frozen_execution_view_v2/guitar_learning`의 정책 코드로 모델을 구성했다. 구성된 architecture의 정확 동일성과 모든 state tensor의 strict load를 확인했다. 현행 개발 코드나 archive·native 모듈은 import하지 않았다.

관측은 같은 실행에 미리 pin된 `single_a_contact_v1/case_000/demonstration.npz`의 **teacher BC 궤적 한 개**에서 골랐다. 원본 240행 중 index `0,4,...,236`을 고정 선택하여 60행만 사용했다. 원본 60Hz 궤적을 15Hz 간격으로 보며 시간은 0–3.933333초다. 준비 구간 30개, 음 구간 8개, 음 종료 뒤 22개다. 학습 중 정책이 방문한 전체 상태나 실패·회복 상태의 대표 표본이 아니다.

| 입력 | 선택 shape | dtype |
|---|---|---|
| state | 60×500 | float32 |
| events | 60×64×24 | float32 |
| mask | 60×64 | bool |
| priority_events | 60×2×24 | float32 |
| priority_mask | 60×2 | bool |

선택된 state 수치 범위는 −1–1.25다. 원자료 observation/action 계약은 모델 계약과 정확히 같음을 확인했다. NPZ·계약·원 capture result의 SHA는 봉인 manifest의 pin과 일치하며, 정책 소스·checkpoint를 포함한 모든 읽은 파일은 분석 전후 SHA가 같다. 정확한 절대 경로·SHA·선택 index와 시각은 JSON에 기록했다. 원 capture의 완료·성공 기록은 출처 확인용이며 이 CPU 분석에서 native 감사를 반복한 것은 아니다.

## 출력 비교

`μ`는 tanh 이전 latent Gaussian 평균, 결정적 행동은 `tanh(μ)`다. 여기서 결정적 행동은 확률적 행동의 기댓값 `E[tanh(z)]`와 같은 의미가 아니다.

| 출력 | scalar 수 | 차이 RMS | 평균 절대 차이 | 최대 절대 차이 |
|---|---:|---:|---:|---:|
| 왼손 33축 latent 평균 μ | 1,980 | 1.13285e-4 | 6.80853e-5 | 0.00161862 |
| 왼손 33축 결정적 행동 tanh(μ) | 1,980 | 6.77341e-5 | 5.24629e-5 | 0.000373006 |
| 오른손 6축 latent 평균 | 360 | 0 | 0 | 0 |
| 오른손 6축 결정적 행동 | 360 | 0 | 0 | 0 |

같은 관측에서 활성 왼손의 출력이 실제로 달라졌으므로, 가중치만 바뀌고 출력은 전혀 그대로라는 설명은 맞지 않는다. 비활성 오른손은 두 모델 모두 출력이 0이며 차이도 정확히 0이다.

기준 모델의 각 축 latent 표준편차 σ는 0.00296339–0.00303740이다. `Δμ/σ`를 축마다 계산하면 RMS **0.037685σ**, 최대 **0.540517σ**다. 즉 이 제한된 관측 집합에서 평균 이동의 전반적 크기는 탐색 표준편차의 약 3.77%지만, 가장 크게 바뀐 한 관측·축은 약 54.05%다. 모든 출력 변화가 탐색 잡음보다 무시할 정도로 작다고 일반화할 수 없다. tanh 이후의 잡음 크기는 상태와 축에 따라 줄어들므로, 행동 차이를 σ≈0.003과 그대로 나누어 같은 의미로 비교하지 않았다.

| 관측 구간 | 관측 수 | 왼손 latent 차이 RMS | 왼손 결정적 행동 차이 RMS | 행동 최대 절대 차이 |
|---|---:|---:|---:|---:|
| 준비(2초 전) | 30 | 1.44648e-4 | 6.95603e-5 | 0.000373006 |
| 음 구간(2–2.5초) | 8 | 7.85203e-5 | 7.14116e-5 | 0.000154981 |
| 음 종료 뒤(2.5초 이후) | 22 | 6.50188e-5 | 6.37176e-5 | 0.000253588 |

## 결론의 범위

이 BC 관측 60개에서는 추가 32회 뒤에도 결정적 행동 변화가 작게 측정됐다. 이는 `MID32.md`의 접촉 성공 정체와 양립하지만, 정체의 원인이라는 인과 증거는 아니다. 같은 입력에 대한 한 번의 출력 차이는 실제 rollout에서 누적되는 상태 변화·관절 목표 변화·기타 상대 기하·접촉 차이가 아니다. 특히 접촉 경계에서는 작은 명령 차이도 결과를 바꿀 수 있다. 학습 전체 관측·실패 상태·다른 초기 자세·전곡·회복 능력에 대한 주장으로 확대하지 않는다.
