# 관절 자세 유지 보정과 연주 제어권: 다음 소단계 제안

2026-10-06. 상태: 설계 검토·사용자 확인 대기. 제어 구현/ON trial/학습은 없다.
초기 humanoid·strap 탐색의 원자료는 pose_strap_v1/hand_support_v1에 보존했다.

가까운 초기 왼손 배치와 그 자세에 맞춘 고정 LA에서도 0.5초에 손–넥 source 거리가
0.8~3.1mm에서 약147mm로 벌어졌고 native LH–기타 contact row는 없었다.
상지 actual−target raw 편차가 약18.3°였다. 초기 각도만 계속 바꾸기 전에,
약한 기본 관절 PD에서 팔이 처지는 것을 목표각 보정으로 줄일 수 있는지 분리해 검사한다.
기타 오차 feedback을 이미 구현한 것으로 부르지 않는다.

## 제어권과 물리 전달

향후 연주 제어가 66개 주 관절의 기준 `q_play`를 제공하고 안정화가 제한된
보정 `delta_q`를 더해, 최종 목표각 하나만 native PD에 전달하는 구조를 제안한다.
이번 연주 없는 시험의 `q_play`는 선정 초기 자세다. fingers42의 목표는 유지하고,
양쪽 Thorax/Shoulder/Elbow/Wrist 24개 목표에만 관절 자세 유지 보정을 적용한다.
이는 해당 관절을 영구 안정화 전용으로 빼는 제안이 아니다. 몸통9 목표는 계속 유지한다.

보정 입력은 실제 관절각 `q`와 기준 목표의 오차다. 각 관절에
`delta_q = clip(e + 2 * integral(e dt), -0.15, +0.15)` rad를 출발 후보로 두며
`e = q_play - q`, 60Hz update를 사용한다. native PD의 gain은 변경하지 않는다.
최종 목표는 모델 한계와 C02 기준 ±0.3rad의 교집합 안에서 제한한다.
포화 방향으로 적분이 계속 쌓이지 않도록 막고, trial reset 때만 적분기를 초기화한다.
이득·0.15rad·2/s는 아직 검증되지 않은 제안값이며 raw 목표/보정/포화를 모두 저장한다.

root·하체 초기각/목표·기타 +5mm/초기 회전/유지 목표·원본 물리/스트랩 수식을 유지한다.
LA는 실행 중 고정한다. 상태를 덮어쓰거나 손을 부착하지 않는다. 초기 기타 목표를
직접 힘으로 복원하지 않는다. 현재 주석의 +/− 관절 오차는 native scalar 값 기준이고,
각도 wrapping 또는 실제 link orientation 차이는 별도로 관측한다.

## 계획과 판정

- [ ] 1. 보정 없는 현재 `p08_load00`과 같은 초기 조건의 OFF/ON을 0.1초 비교한다.
  변경되는 것은 양팔 목표 보정뿐이다. 상태 읽기·목표 compose가 root/기타/관절 상태를
  쓰지 않는지, 몸통9·손가락42·하체 목표/gain과 LA가 유지되는지 검사한다.
- [ ] 2. 실제 관절/손 형상 움직임·접촉·기타 p/q·장력·보정 포화/적분값을 대조한다.
  왼손 proxy upward 조건과 관절 실제 범위 위반도 관찰하고 잘못된 자세는 채택하지 않는다.
  적분기는 측정된 feedback이며 동일 native 초기 상태의 OFF가 기존 결과를 재현해야 한다.
- [ ] 3. 개선된 경우 0.5초/1초로 늘려 목표 유지·손의 실제 지지 여부를 검증한다.
  포화 때문에 자세를 유지하지 못하면 이를 보고하고 임의로 보정 폭/gain을 넓히지 않는다.
- [ ] 4. 실제 지지가 생긴 뒤 기타 p/q 오차를 손/팔 관절 보정으로 연결하는 다음
  feedback과 연주 우선권·제약 투영을 설계한다. 작은 손/팔 동작 안정성을 그다음 검증한다.

후속 연주 결합 때 `q_play`를 최우선 목표로 보고, 안정화 보정의 관절별 한계와
충돌 시 우선권을 별도 합의한다. 현재 무연주 hold 결과를 운지/strike 호환성으로
일반화하지 않는다. 제어 구조가 확인되기 전 학습 구조를 결정하지 않는다.
