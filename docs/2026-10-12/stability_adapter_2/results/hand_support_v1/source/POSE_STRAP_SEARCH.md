# 상체·양손 초기 자세와 스트랩 길이 탐색

2026-10-06. 사용자가 하체를 우선 다루지 않고 초기 자세·스트랩으로 기타를
안정화하도록 방향을 변경했다. 하체 진단·관절 표현 비교는 진행하지 않는다.
최근 기타 오차가 작았던 C02의 하체 초기각을 비교 기준으로 유지한다.
실제 하체 운동과 접촉은 그대로 물리에 남기고, 후보 순위의 하체 자세 항목을 제외한다.

고정 root, 기타 초기 Z +5mm/회전/유지 목표, Torso·Spine·Chest 9개 초기
목표/gain, baseline PD/solver, 원본 스트랩 경로·수식·300N cap은 유지한다.
상지66 초기각을 조정하며 몸통 보정·하체 추가 변경·동적 스트랩·학습은 추가하지 않는다.
기타 고정/손 강제 부착/매 step state·pose 덮어쓰기를 사용하지 않는다.

1. C02 상체를 유지한 스트랩 길이부터 비교한다. 기존 길이와 시작 장력
   0/5/10/20N에 해당하는 절대 rest length를 생성해 0.1초 native 시험한다.
   → 실제 첫 적용 장력·기타 p/q/속도·접촉·상체 목표 보존을 확인한다.
2. 측정한 좋은 길이에서 Thorax/Shoulder/Elbow/Wrist의 작은 초기각 후보를
   만들고 한 번에 한 관절의 ±0.025rad부터 비교한다. 모델 한계 안의 후보만 쓴다.
   → 초기 source 사람–기타 음수 gap 없음, 왼손 법선 +Z dot≥0, 손 위치에
   대응하는 넥 단면 아래 조건을 먼저 검사한다. 법선은 기존 proxy 정의이며
   해부학적 면 부호·cooked clearance 보증은 아니다. 손가락은 이번 첫 단위에서 유지한다.
3. 같은 초기 조건에서 기타 위치·회전 최대/RMS·후반 오차를 기준으로 순위를 정한다.
   장력 cap 도달·상체 실제 한계 이탈·손 방향/접촉도 따로 기록한다.
   초기 길이는 실행 중 고정하며 자세별 route 차이를 절대 길이로 자동 상쇄하지 않는다.
4. 좋은 상체 후보 최대 2개를 기준 대조군과 함께 0.5초로 늘려 검사한다.
   초기 장력 후보는 짧은 오차와 속도의 경향이 달라 기존 5/10/20N 입력을
   0.5초에서도 비교한다. 개선이 남은 스트랩 후보 최대 2개와 기준 대조군은 1초로 늘린다.
   → 짧은 과도 응답만 좋아진 후보를 유지 성공으로 표시하지 않는다.
   성공 허용오차와 연주 호환성은 별도 확인한다. 하체 문제를 재개 조건으로 삼지 않는다.
5. Sol이 후보·다음 방향을 판단하고 Luna가 이미지/설명을 누적하며 별도 검수한다.

## 첫 단위 실측과 연장 근거

33회 native 실행: 0.1초 스트랩 5개·상체 17개, 0.5초 7개, 1초 4개.
길이 1.083374167m에서 0.1초 최대 오차 6.845mm/1.520°로 기존
7.174mm/1.591°보다 줄었다. RMS 회전은 1.027→1.035°로 소폭 증가한다.
이 길이의 상체 ±0.025rad 차이는 작았다. L_Shoulder_x +/− 두 후보를
위치·회전 각각의 소폭 개선 때문에 0.5초에 연장했고, 기존 길이와 길이맞춤
기준 2개도 대조했다. 상체 두 후보의 효과는 0.5초에도 작아 1초 후보로 고르지 않았다.

0.1초에 초기 장력을 올리면 회전은 커졌지만 끝 속도가 낮아졌으므로,
기존 5/10/20N 입력 3개를 0.5초에 추가 대조했다. 10/20N은 0.5초에
길이맞춤 기준보다 위치·회전 최대가 모두 낮아 스트랩 후보 2개로 1초에 연장했다.
기존 길이/길이맞춤 기준 2개도 1초 대조했다. 신규 자세·gain 범위를 추가하지 않았다.

1초 최대 오차는 기존 길이 218.603mm/36.360°, 길이맞춤
253.897mm/52.862°, 10N 241.875mm/61.609°, 20N
200.537mm/75.128°다. 모두 유지 실패이며 최종 채택하지 않는다.
초기 왼손 source 형상 중심은 대응 넥 단면 하단보다 82.533mm 낮다.
초기 gate를 통과해도 지지는 보장되지 않았고, 0.5초 기준에는 팔/손–기타
native contact row가 없었다. 다음 단위는 손의 지지 가능한 초기 위치를 먼저 다룬다.
[후속 소단계 계획](HAND_SUPPORT_INITIAL_POSE.md)의 최대 ±0.3rad 초기각 탐색을
사용자가 승인했다. 양손 지지점 중 왼손–넥 접근을 첫 단위로 진행한다.
