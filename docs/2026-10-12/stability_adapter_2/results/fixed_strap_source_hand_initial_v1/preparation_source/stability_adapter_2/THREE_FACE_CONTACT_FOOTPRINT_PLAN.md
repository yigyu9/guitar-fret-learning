# 엄지 후면·손바닥 옆면의 접촉 영역을 중심으로 초기 자세 재설계

## 측정에서 바뀐 판단

저장된 세 조건의 실제 접촉 feature 15,511행을 기타 root 좌표로 대조했다.
손바닥의 양의 raw lambda feature는 요청 옆면 패치에 투영되는 점이 없었고,
유한 패치 거리는 기준21.105~22.783mm, half24.390~29.806mm,
zero25.996~28.382mm였다. 넥에 닿는 body명만으로 원하는 옆면 지지를 판정하면 안 된다.
엄지3은 후면 높이에 가깝지만 G의 X≈−23mm 가장자리에 몰렸고, 후면 내부 여유를
확보한 표본은 없었다. 검지3/중지3의 양λ는 주로 fret4/fret5에 있었다.
약지3/소지3의 실제 기타 접촉 기록은 없었다. 현재 배치를 완성된 세 면 grip으로 채택하지 않는다.

근거는 [feature 진단](/home/ajou/yigyu/3/docs/2026-10-12/stability_adapter_2/results/three_face_native_feature_map_v1/analysis_v2.json)이다.
SDK 문서 방향으로 변환한 normal은 전면/옆면 source outward과 반대였다.
법선 부호를 접촉면·힘 방향의 통과 조건으로 사용하지 않는다. Source와 native cooked
형상, 접촉 feature와 해부학적 손바닥/손가락 pad는 구별한다.
