# 손·기타 결합 응답을 이용한 작은 목표 보정 검증

## 측정 근거

접촉 구간의 12축 .005rad probe와 .001rad 조합 heldout을 측정했다.
heldout 예측차이는 손 위치.030036mm/법선 회전벡터.002525°,
기타 위치.024734mm/world 회전벡터.003647°다. formal 성공 기준이 아니다.
L_Elbow_y +.005rad에서는 손과 기타 오차가 줄지만 손바닥 양의 raw lambda가
사라진다. 이탈을 줄이는 것과 지지 유지가 같은 목적이라고 가정하지 않는다.
source 법선 평행은 부드러운 선호로 유지한다.

## 다음 소단계

- [ ] 1. 동결된 palm_coupled_response_v1 입력을 읽기 전 봉인하고 저장 행렬로
  작은 constant PD 목표 보정 후보를 만든다. 초기 q/기타 p/q/절대 LA/PD와 다른 관절
  목표는 유지한다. 새 실시간 feedback 구현은 이 단계에 포함하지 않는다.
- [ ] 2. 보정 δ는 처음에 각 축 ±.001rad∩기존 initial±.3rad∩native 목표 범위로 제한한다.
  .025rad는 이전 계획의 상한이지 이번 후보의 탐색 폭이 아니다. 실제 float32 명령으로
  예상 출력과 보정 폭을 다시 계산한다. 양방향/조합 응답은 새 검증 대상이다.
- [ ] 3. 기타 위치와 회전의 예상 종료 norm을 각각 기준 norm으로 나눈 제곱합을
  줄인다. 이 정규화는 단위 균형용이며 허용 오차 기준이 아니다. 손 위치 norm이
  기준보다 커지는 예측 후보는 제외한다. 법선은 기존 .08 task scale의 작은 soft항으로
  선호하며 필요한 기울임을 강제로 없애지 않는다. 구체적인 soft항 계수는 fit 실행 전에
  기록한다. solver 결과와 포화 축, 예상 손/기타 변화, 실제 전달 target을 저장한다.

  이번 fit의 목적함수는 정규화한 기타 위치/회전 제곱합 + .01×정규화한 손 법선
  회전벡터 제곱합 + .0001×sum((δ/.001)^2)다. 기타 위치/회전과 손 위치의 예측 norm은
  각각 기준 이하로 제한한다. 법선 정렬은 제약이 아닌 작은 soft항이다. 이 비교 한계는
  성공 기준이 아니며 실제 native 결과가 선형 예측보다 우선한다. float32 변환 후 각
  배율의 예측을 다시 계산하고 목표 범위·±.001rad와 위 세 norm 비교를 확인한다.
- [ ] 4. 같은 기준 초기상태에서 δ의 1/4·1/2·전체를 각24step으로 실제 검증한다.
  계획3init/72steps이며 기존 기준 저장자료와 비교한다. 위치·회전의 전체 궤적/max,
  손 추적 오차/법선/source 간격, 접촉 시점/양의 raw lambda 지속시간과 몸통 drift를 읽는다.
  적어도 손/기타의 개선이 확인되기 전 후기 연장·새 feedback·gain·strap·finger 변경을
  함께 하지 않는다. 작은 종료 오차만으로 지속 지지나 연주 성공을 선언하지 않는다.
- [ ] 5. 실제 결과를 독립 검수하고 Luna가 이미지와 설명을 정리한다.

행렬은 고정 초기 상태의 .1초 유한시간 응답이다. mixed-unit SVD나 작은 heldout 차이로
실시간 Jacobian의 정확성·장기 안정성을 인증하지 않는다. 특히 접촉 모드가 바뀌는
후보는 새 raw 결과를 우선한다. 유지 제어는 이후 기타 p/q와 손의 피드백을 합성하고
연주 목표 제어권을 남기는 별도 단계에서 검증한다.
