# 감싸기 지지의 작은 목표 응답: 방향과 결합 근사 확인

seed2_guitar_response_v1에서 기준과6개 +0.002rad probe, 결합heldout까지
실제8init/9600step·각5초·두뷰151frame를 완료했다. 초기q/기타/LA/PD는 같았다.
heldout의 최대p/q는26.774777mm/8.124454°이고 기준26.772807mm/8.323296°다.
최대이동의 미세증가0.001970mm와 회전감소0.198842°를 별도로 기록한다.
종료p/q도23.108978mm/7.388837°로 소폭줄었지만 손바닥 지속지지는 달성하지 못했다.

last1s의 선형예측 잔차는 위치벡터0.789333mm·회전오차벡터0.155463°다.
이것은 예측이 실제 변화량보다 크게 틀린 결과이며 runtime 역행렬 보정에 쓰지 않는다.
0.1초 샘플행렬은rank0, last1s는잠정rotationlever.1m 가중rank6/조건수56647이다.
rank6만으로 제어 가능한 잘조건화된 mapping이라고 판단하지 않는다.
현재 결합보정은 작은 회전개선 후보로 보존하고, 원seed2/full/currentLA를 진단 기준으로 둔다.
최종 연주66축과 지지bias+stabilization residual 관계는 그대로 유지하고 학습은 결정하지 않는다.
