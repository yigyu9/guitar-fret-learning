# 검지·중지 초기각을 포함한 세 면 지지 배치

직전 근접 후면 지점 네 후보는 모두 source 검사에서 거절됐다. 지점1462·0.3mm 조건의 엄지/손바닥 목표 오차는7.524248/1.985673mm이고, 중지3–프렛4의 source 겹침과 후면 패치 밖의 엄지 지점이 남았다. 선형 접근성 계산만으로 겹침 없는 배치를 만들 수는 없었다.

## 다음 소단계

1. 소비된 근접 지점 검색 소스와 입력을 SHA로 대조·복사하고 새 variant에서만 구현한다.
2. 기존 팔12(±0.05rad)·엄지5(±0.20rad)에 왼쪽 검지·중지8의 초기각을 추가한다. 검지·중지는 저장 half 초기각 대비 ±0.10rad, native 한계, 8월19일 손가락 한계, 기존 절대 목표와의 ±0.30rad 차이의 교집합을 사용한다. 총25좌표이며 나머지56초기각은 유지한다. 검지·중지를 먼저 조정하는 이유는 직전 반복의 실제 source 겹침 쌍이 이 두 손가락에 집중됐기 때문이다.
3. 지점1462·0.3mm 조건부터 검사한다. 검지·중지의 선택 source 지점은 넥 전면에 접근하고, 손바닥은 옆면, 엄지는 후면에 접근하도록 부드럽게 선호한다. 저장 source 전면의 바깥 높이11.230006mm를 사용하며 프렛을 무시한 평면접촉으로 인증하지 않는다. 서로 다른 초기 추정값은 별도 후보로 기록한다. 첫 batch는 최대3개 source 후보다.
4. 전체 humanoid–기타/양손/비인접 왼손 교차 검사, 손바닥 위쪽 반구, 유한 후면·옆면 패치 여유와 source 거리 하한/상한 검사를 유지한다. 초기 목표81개와 절대 LA1.1018469719600776m는 이번 배치에서 유지한다. 통과 후보 최대2개만 fresh Isaac Gym에서 실제5초와 초기값·전신/손 영상151frame을 저장한다.
5. source와 실제 접촉/기타 이동·회전을 구분해 검토한다. 통과한 초기 배치가 생기면 손가락 PD 목표도 별도 조건에서 비교하여 초기각과 이후 제어의 효과를 구분한다. 기존 목표를 유지한 시험만으로 그립 제어가 완성됐다고 주장하지 않는다.

## 유지 조건과 검증

Root·하체는 별도 모델의 물리적 고정, 몸통9 목표는 PD 유지다. 최종 양쪽 Thorax부터 손가락66 제어권은 유지하며25좌표는 이번 초기 배치 진단의 일시적 범위다. 기타는 자유 중력·접촉과 수동 스트랩으로 움직이며 기타 고정·손 부착·반복 pose 덮어쓰기·목표 기타 외력은 사용하지 않는다. 초기 기타 world p/q, 오른손/팔, gain/solver/material은 그대로 둔다.
