# 감싸기 지지 초기각 비교 실행 설계

동결 계획 SEED2_SUPPORT_POSE_WARMSTART_PLAN.md를 따른다. 엄지–후면, 다른 손가락–전면, 손바닥–옆면 접근을 기존 기타 local 면 패치로 측정한다. 표면별 실제 지속 지지는 아직 미검증이다.

- [ ] 왼쪽33 초기각 .25/.5 보간, 두 후보 모두 거절되면 .125만 추가. source 겹침·상향·자기교차 검사.
- [ ] 허용 후보 최대2개와 baseline을 실제 Gym에서 각각5초 실행. 초기값과 전신/손151frame 영상 저장.
- [ ] 실제81각/33·48 목표 분담, G p/q, 접촉, 수동strap 법칙을 원자료로 재계산.
- [ ] 이미지 설명·영상·실제줄 문서화 및 독립 검수·원본 SHA 보존 확인.

변경은 왼쪽33 초기 관절 좌표에만 적용한다. 관측 종료 body pose와 속도를 재생하지 않는다. 시작 속도0, 기타 목표/초기 p/q·절대LA·PD gain·solver·몸통/오른쪽 초기값은 유지한다.

새 초기각 대비 offset을 float64로 빼고 더한 뒤 최종81 목표만 native float32로 제출한다. float32 중간 offset 합산의 반올림으로 절대 PD 목표가 달라지지 않도록 하며 전체81 제출목표를 저장 -.016 조건과 exact 대조한다. 최종66 제어 인터페이스를 유지하고 숨은 clipping을 하지 않는다. 왼쪽33은 저장 절대목표, 나머지48은 초기목표를 유지한다. PD setter는 기존 왼팔12 범위로 gain1을 그대로 읽기검증한다.

기존 run_seed2_guitar_feedback.py와 봉인 snapshot의 bytes 및 알려진 SHA를 대조한 후 새 runner로 복사했다. 기존 파일은 수정하지 않는다. 새 control 로그는81 목표 및 other48 기록으로 구성되므로 이전12 목표/feedback 필드 로그와 schema가 다르다. baseline raw5개 배열 및 영상 exact는 관측값으로 남기고 성능 통과조건으로 삼지 않는다.

새 자세에 따른 strap 경로 길이는 측정한다. 절대LA만 고정하며 경로 길이 일치를 가정하지 않는다. fresh native FK/형상 검사를 거절하면 t0/부분 영상과 오류를 보존한다. source 형상은 PhysX cooked 관통 인증으로 사용하지 않는다.
