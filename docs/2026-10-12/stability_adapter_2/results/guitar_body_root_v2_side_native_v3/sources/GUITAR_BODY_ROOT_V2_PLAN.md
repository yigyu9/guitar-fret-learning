# 바디 중심 원점을 가진 두 번째 기타 자산

별도 대화의 사용자 요청: 직관적인 root를 가진 기타 오브젝트2를 만든다.
기존 공용 기타와 실행 환경 설정은 수정하지 않는다. 새 자산은
`/home/ajou/yigyu/3/stability_adapter_2/assets/guitar_asset_body_root_v2.xml`이다.

1. 원본 `G:body`의 중심 `[0,-0.4,-0.0217]m`를 새 원점으로 선택한다.
   root의 직접 geom과 직접 child body 위치에서 이 값을 뺀다.
   이름·축 방향·자식 내부 좌표·형상·재질·마찰은 유지한다.
2. 원본/새 자산을 정적으로 대조하고, 격리된 CPU Isaac Gym에서 로드와
   동일 world 배치의 body pose/질량/관성·COM 변환을 검사한다. 물리 적분은 하지 않는다.
3. 변환 규칙·메시 경로·검증 결과를 새 문서/결과 폴더에 저장한다.

좌표 계약: `p_new=p_old+R(q)*c`, `q_new=q_old`, `point_new=point_old-c`.
새 root는 바디의 기하학적 중심이며 기타 전체의 질량중심을 의미하지 않는다.
사이드 대화에서 메인 대화의 문서/구현/시뮬레이션을 변경하지 않고 서브에이전트를 사용하지 않는다.
