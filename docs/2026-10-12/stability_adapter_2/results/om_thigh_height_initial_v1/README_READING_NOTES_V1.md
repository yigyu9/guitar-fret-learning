# 접촉 결과 해석 보완

결과 README의 ‘실제 받침은 주로 양 허벅지’는 접촉 로그에 근거한 해석이며 **힘·모멘트 분담을 측정해 확정한 결론은 아니다.** 검토에 소비된 원문은 보존한다.

직접 확인한 사실은 추천 후보의 바디–양 Hip 양의 raw lambda292/294표본, 바디–Chest/상완0표본, 일부 손가락–바디 이외 기타 부품 접촉이다. 따라서 ‘양 허벅지와 빈번한 바디 접촉이 형성됐고, 가슴·상완의 지속 접촉은 관측되지 않았다’로 읽는다. 손가락의 지지 기여를 제외하거나 전체 지지력을 허벅지에 귀속하지 않는다.

양 Hip 최소3mm/오른 Hip11.667mm는 source 최근접 거리이고, 수직 여유 높이·cooked 형상 간격·허용 관통 깊이가 아니다. 종료 이동29.993mm/회전7.202°와2초 이후 거의 정착한 경과는 관측했지만, 반복 재현성/왼손 철수/실제 연주 성공은 미검증이다.
