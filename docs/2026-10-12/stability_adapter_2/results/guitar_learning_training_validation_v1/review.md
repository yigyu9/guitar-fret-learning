# 독립 최종 검수

**검수 판정: 문제없음. 연구 결과 판정은 README의 ‘부분 통과’가 타당하다.** 제한 학습과 검증 절차는 완료됐지만, 왼팔/복합 행동의 기타 위치 안정성 실패와 음악 수행 개선 없음이 실제 결과다. 성공 정책이나 기본 행동 범위 전체의 안정성을 승인하지 않는다.

검수자는 구현·입력·원자료를 수정하지 않았고 새 물리 실행, 렌더링, 전체 테스트 재실행을 하지 않았다. 소스 검토와 저장 자료의 읽기 전용 재계산을 수행했다. 소유 파일은 이 검수 기록뿐이다.

## 제어 경로와 검증 구현

- `NativeSession.submit_policy_target`은 하체 유지 제어가 상체 목표를 바꾸지 않았음을 확인한 뒤 최종105채널 목표를 제출한다. 오른팔꿈치/손목의 SO3 피드백은 **현재 제출 목표**를 같은 목표의 child-frame 회전 오차로 변환한다. 준비 자세 목표로 되돌리지 않는다.
- 상완 지지의 world-tangent 항은 몸통/척추/가슴/오른쪽 근위15축에 적용된다. 오른팔꿈치/손목6축을 직접 상쇄하는 지지 항은 없다. 기존 저장 effort 진단에서도 SO3 target과 실제 제출 목표가 정확히 같고 해당6축 support task가0임을 대조했다. 왼팔은 scalar effort, 왼손은 native POSITION 경로다.
- 역할별 정현파의39행동 순서, 체크포인트의 엄격한 환경 계약, deterministic mean 평가, 평가 예산과 학습 계약의 분리, 에피소드별 새 준비, 입력 전후 핀, policy 모드의 실제 카메라 녹화가 정합하다. CPU89개 PASS 로그를 확인했다.

## 원자료와 분석 대조

- 9개 실행의 report는 절차 완료이며 예외·import 핀 누락·원본 source parity 오류·변경 입력이 없다. 실행 입력 union **1,568개 SHA**를 현재 파일에서 직접 재계산해 모두 동일함을 확인했다.
- 학습 rollout4개는 각각192전이다. terminal의 구간 내 index는 `[87,175]`, `[71,159]`, `[55,143]`, `[39,127]`이고 그곳의 reward/cost bootstrap은 모두0이다. truncation은 없으며 checkpoint updates는1→4, 모델 값은 모두 유한하고 KL은 전부0.02 미만이다. 마지막64단계 부분 에피소드를 완주로 세지 않았다.
- 학습 전/후 각각 두 반복의 **88개 전이 전체**를 직접 비교했다. action, native 상태/접촉, music/safety 측정, 보상/비용이 정확히 동일하다. 각 실행의 물리481–832 step 연속성과 마지막 전이의 terminal도 확인했다. 동일 조건 재현이며 다른 seed/곡 일반화 증거가 아니다.
- 왼팔은 step803에서 기타 이동80.9657mm로 최초 초과하고 tick 끝804/정책1.35초에84.2541mm로 종료했다. 복합도 `terminal_failure`이며 실패 보상−2가 적용됐다. `report.completed=true`를 이 두 조건의 안정성 성공으로 읽으면 안 된다.
- 오른팔/손가락/복합의 **2,620개 물리 표본**을 독립 재집계했다. 기타 최대 이동, 삼중 지지/접지 비율, 비영범위 q 제한 초과, 명목 영범위 실제 편차, 전체/오른말단 effort cap 비율이 `analysis.json`과 `joint_effort_audit.json`에 일치했다.
- 손가락 시험의 최대 비영범위 q 초과0.001038588rad, 복합 시험의 명목 영범위 편차0.000102978rad를0으로 처리하지 않는다. 외부 제출 effort 포화 없음은 native POSITION 손가락 실제 토크의 포화 없음이나 토크0을 뜻하지 않는다.
- 정책 전후 onset proxy 거리는19.028334→19.029027mm이고 매칭/유지 성공은 모두0이다. 발음 구간 최소거리의 극소 감소만 선택해 학습 개선으로 표현하지 않은 해석이 적절하다.

## 영상·안내 문서

- 네 평가 에피소드의 capture 기록420개는 물리 step0–832/stride8이며 모두 `render_preserves_states=true`다. 저장 PNG840개 및 MP4 8개의 SHA를 직접 확인했다.
- MP4 8개를 별도 ffprobe로 검사했다. 모두1280×720, 30fps, 105프레임, 3.5초다. 준비2초와 정책1.466667초를 양 끝 프레임까지 포함해 MP4 길이가 한 프레임 길어진다는 안내가 정확하다. 영상 형상 자체의 시각 검토는 root가 수행한 범위이며, 검수자가 독립 재렌더하거나 전체 영상을 사람처럼 재생한 것은 아니다.
- 결과 README와 `media_index.md`를 원자료와 대조하고 로컬 링크28개가 모두 존재함을 확인했다. 조기 종료의 미도달 목표, 후보 소실과 완전 비접촉, 왼손 하중 의존 원인 미확정, 작은 학습량/한 seed, 원한계 보존과 실제 q 편차, visual geom 경고의 범위를 구분한다.
