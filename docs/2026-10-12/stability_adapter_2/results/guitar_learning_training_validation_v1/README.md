## 해석과 다음 검증 순서

1. **기본 행동 범위 전체의 안정성을 승인할 수 없다.** 왼팔과 복합 큰 조합의 실패가 실제로 재현됐다. 역할별 범위·넥 주변 접근·압현에 필요한 도달성을 함께 검토해야 한다. 범위를 줄이기만 하면 해결됐다고 가정하지 않는다.
2. **첫 음악 성공을 확보해야 한다.** 현재 지정 목표 접촉 유지와 시간 조건을 만족한 타현이 모두0이다. 압현 접근/후보 유지와 피크 접근/유효 타현을 각각 목표에 맞춰 먼저 확인하고 결합하는 검증이 우선이다.
3. **탐색·보상은 원인 후보이며 아직 확정 원인이 아니다.** 초기 정규화 표준편차는 exp(−3)≈0.0498이고, 4업데이트 후 결정적 행동도 최대0.002271에 그쳤다. 실제 사용할 수 있는 반범위와 학습 중 주로 탐색한 영역의 차이가 크다. 안정성 비용/희소 음악 보상/접근 보상의 시간 창도 함께 점검할 필요가 있다.
4. **망 크기나 장기 수렴을 이번 짧은 시험으로 판정하지 않는다.** 먼저 목표 도달·양성 음악 피드백·허용 접촉 변화 조건을 확인한 후 학습량/seed를 확대한다. 이번 체크포인트를 성공 정책으로 선정하지 않았다.

전체 곡의 미지원 alternate_restrike, 자동 단계 승급·병렬 수집·하체 정책 출력, 실제 현 압력/진동/음향은 기존 남은 범위다. 검증을 통과시키려고 기타를 고정하거나 직접 힘을 가하거나 지속 상태를 덮어쓰지 않았다.
