# 저장 접촉 지도 — root 검증

## 범위와 실제 이미지 확인

새 물리 실행 없이 기존 어깨+0.008rad의 저장 자료를 분석했다. 실제 생성된3325×2850 PNG를 열어 네 panel의 손가락 색/이름·동일 축 범위·유한 참조면·현재 접촉 수0/2/0/1을 확인했다. 범례와 설명은 데이터 panel 밖에 있으며 잘리지 않았다. 실제 Isaac Gym 5초 손 카메라와 별도로 대조했다. 원본 native PNG는 바꾸지 않았으며 좌표 그림을 native 렌더로 설명하지 않는다.

1198개 양의 왼손 SDK 접촉행의 이름/ID와 post-step pose 변환을 대조했다. 양쪽 feature의 최대 잔차0.000082033mm, pre-step 변환 잔차0.639182476mm다. 이 자료는 post-step body-origin 해석을 지지하지만 cooked 표면 간격/관통깊이·힘을 측정한 것은 아니다. 손가락 연결선과 빈 삼각형은 body 원점이며 해부학적 패드가 아니다.5초 검지 top 원점과 실제 feature는 약5.80mm 떨어져 있다.

## 설정 확인 보완

최초 분석의 single_substep 검사는 저장 physics_parameters에 키가 없는데 기본값1을 사용했다. 소비된 분석본은 보존했다. 별도 configuration_clarification.json의5검사로 소비 source/preset의 설정1을 확인했으며 최초 필드를 대체한다. Native SimParams readback은 하지 않았다. 그림 producer와 최종 감사는 이 구분을 따르며 설정 확인을 실제 native 조회로 확대하지 않는다.

## 해석과 다음 단위

중지 body 원점 경로 합은 약99.64mm, 검지는88.47mm지만 특정 굽힘각의 필수성을 증명하지 않는다. 중지2/3의 큰 유지 목표가 현재 모양의 직접 원인이다. 접촉 지도만으로 자세가 자연스러워지지는 않으며 관측 분포 기반 soft 자세 선호와 실제 접촉 평가가 필요하다. 모든 손가락의 동시 접촉은 요구하지 않는다.

다음 물리 후보는 고정LA의 관절18 baseline에서 middle3 유지 목표만−0.05rad 줄이는 한 시험이다. 초기각은 같게 두며 다른 어깨 목표를 동시에 바꾸지 않는다. 이번 지도는 어깨+0.008rad 조건이라 다음 baseline과 구별한다. Fresh 초기 형상 gate와 실제0~5초 스트랩 영상은 다음 단위이며 이번에는 실행하지 않았다. 기존 손목y 후보도 미실행으로 보존한다.

8월19일의 분포·신규 한계 제안·현재 렌더 범위는 서로 다른 자료로 구분했다. 최종66 제어권·몸통 목표·고정 root/하체·자유 기타·고정LA와 기존 결과 보존 원칙을 유지한다. 새 actor 추론/학습/물리 step은0이다.
