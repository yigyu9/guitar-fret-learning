# 저장된 손가락 자세와 접촉 영역 지도

직전 finger_curl_diagnosis_v1은 실제 고정 손가락 목표와 접촉 기록을 대조한 progress다.
이번에는 고정LA 어깨+0.008rad 실행의 저장 자료를 사용한다. 물리/관절목표/스트랩을
변경하거나 재실행하지 않는다. 현재 중지 굽힘이 지속 지지로 이어지지 않는 이유를
다음 초기 자세·손가락 목표 변경에 앞서 위치 자료로 확인한다.

1. 기존 SDK local contact feature의 body/COM 및 시점 검증 기록을 먼저 확인한다.
   이름/인덱스를 모든 왼손 양의raw lambda 행에서 대조하고, 기타쪽 feature를 해당 body
   pose로 world 변환한 후 기타 root local로 변환한다. Pre/post pose 차이를 기록한다.
   두 feature의 거리는 SDK 지점 간 거리이며 cooked 표면 간격/관통깊이라고 부르지 않는다.
2. 저장 native 실제 body 원점으로 각 손가락1→2→3→top의 선과 이름을 그린다.
   이 선은 관측 body 원점 연결도이며 표면/해부학적 패드나 새 FK 예측이 아니다.
   원점 간 선분 길이 합은 기하 참고값으로 비교하고, 특정 굽힘각이 필수라는 인과로 읽지 않는다.
3. t0/step32(.1333초)/step56(.2333초)/step1200(5초)의 현재 접촉과 저장 참조
   전면/후면/옆면 유한 polygon을 같은 기타 local 좌표에서 표시한다. 전면의 source 외곽
   높이11.230006mm와 원 neck면9.3mm를 구분한다. 참조 polygon은 cooked 접촉면 인증이 아니다.
   손끝 원점 후보와 실제 SDK feature를 다른 표식으로 표시하며 임의의 패드 면을 만들지 않는다.
4. 원본 native PNG는 그대로 보존하고, 별도 과학 도표를 같은 결과 문서에서 비교한다.
   저장 depth가 없어 native 영상 위의 가림 판정을 새로 인증하지 않는다. 필요하면
   figure에 원본 PNG를 한 panel로 배치하고 좌표 지도 panel과 명확히 구분한다.
   표시만으로 제어나 자세가 달라진다고 주장하지 않는다.
