기본 native 정착2초 뒤 정책이5초 동안 동작한다. 이 안의 첫1초는 곡 시간이−1초에서0초로 진행하는 행동 가능한 pre-roll이며, 별도로 관절을 고정하거나 상태를 덮어쓰는 구간이 아니다. 원 목표의 press/onset/end는 실행 시간에서 정확히1초 이동했고 원 음악 시간과 50/100ms 정본 판정은 보존됐다.

## 학습과 제외 기록

새 PPO smoke_v2는 양손 각각1업데이트·300전이·확률적 완주1episode를 완료했다. 이후 결정적2episode씩을 별도로 평가했다. 단일 업데이트의 작은 오차 차이로 성능 개선·수렴을 주장하지 않는다.

기존505 Actor를 새 시간 조건에 직접 이식한 왼손 평가2회는 안전 실패로 보존했다. 초기 오른손 평가와 첫 CPU 검사는 소스 중간 변경의 영향을 받아 인증 대상에서 제외했다. PPO smoke_v1은 compact logger의 RecursionError로 update0에서 실패했으며, 새 실행기의 smoke_v2가 이를 대체했다. 이 실패들을 현재 성공 분모에 포함하지 않았다.

300ticks/1,200물리 표본의 연속성,2초 정착·곡 시각−1초 시작, 목표+1초 이동, 반대 손 행동0, 비용률/240 및 제어·에피소드 비용, 후보/기하 통과의 원래 조건을 확인했다. 인증 입력 pin과 현재 파일SHA도 교차 검사했다.
