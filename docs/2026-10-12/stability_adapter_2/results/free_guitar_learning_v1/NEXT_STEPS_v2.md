# 다음 구현 순서

1. 실제 압현 측정부터 연결한다. 할당 손가락의 distal 원점 접근은 기하 proxy이고, 유효 압현에는 같은 손가락과 넥/프렛의 실제 native 접촉·현재 목표·연속 유지와 해제를 별도로 확인한다. `_top` 비충돌 marker나 합산 body force만으로 접촉을 판정하지 않는다. 먼저 한 줄·한 프렛을 학습 없이 확인한다.
2. 현재/미래 음악 목표와 실제 기하의 대응을 연결한다. musical fret0(개방현), legacy Fret0(DONT_CARE), NO_PRESS(-1)을 명시적으로 변환한다. physical string1/high-E와 detector index0, string6/low-E와 index5를 구별한다. 목표를 reset-time world 좌표에 고정하지 않는다.
3. 기존Strike의순수sweep검출기를240Hz샘플에연결한다. 이전/현재기타좌표로변환한피크를사용하고각physics dt=1/240과subframe시각을기록한다. valid에zone가자동포함되지않으므로구역허용을별도적용한다. 최대깊이/관통과재무장조건도분리해검증한다. 끝점선형sweep는한physics구간의상대궤적근사다.
4. 실제 관측 벡터와 음악 토큰, reward/cost 반환을 정의한다. 현재 phase1 API는 native state·geometry를 반환하며 완성된PPO환경으로보지않는다. 음악시계는이번준비22초와인계시점에맞춰정의하고,예전환경의2초상수를그대로가져오지않는다. 준비지연으로원래음악onset을뒤로옮기지않는다.
5. 학습 수집과 단음 PPO를 연결한다. 작은 연결시험용0.002rad 범위가 프렛 도달에 충분한지는 검증하지 않았으므로 실제 도달가능성과 지지민감도를 확인한 후 별도 버전으로 결정한다. 공동 정책은 새 가중치로 초기화한다. 현재39출력을 먼저 검증하고 하체16축을 추가하는55출력은 별도 비교로 구현한다.

실제 초기화·0행동/비영행동 연결시험 통과가 음악성공이나 장기안정성을 뜻하지 않는다. 현재 자세의미검증요건(재접촉후왼손하중독립·전체연속실행·엄밀관절좌표원인·현힘/음향)은별도보존한다.
