# 1104 커밋 전 프로젝트 정리

사용자 요청에 따라 기존 V5 정리·타현/전신 구현·논문 framework·입력·확정 결과를 점검한 뒤 Git에 반영한다. 원격은 기존 `origin`의 `main`이며 커밋 메시지는 `1104`다.

## 이번 추가 정리

- 활성 코드의 재생성 가능한 Python 캐시37개,672,861바이트를 제거했다. native 빌드 캐시·봉인 runtime·자산·실행 프로세스는 건드리지 않았다.
- 원시 손가락 진단255개와10MiB를 넘는 생성 보고서1개, 합계141,791,579바이트는 **삭제하지 않고 로컬 보존**한다. 공유용 분석·요약과 구분하여 Git 제외 규칙에 추가했다.
- 실행 잠금과PID 파일은 로컬 운영 상태이므로 Git에서 제외한다. 파일 자체는 보존한다.
- 없어진 전신 검증 문서를 가리키는 현재 안내 링크를 실제 전신 실행 안내로 연결했다.
- 정리 전 압현 compact/v3/v4 파일을 가리키던 framework 링크는 현재 단일 V5와 공용 인코더로 연결했다. 정리 전 코드 스냅샷은 역사 기록으로 유지하고 현행 위치 안내를 추가했다.
- CSV의 기존 CRLF 형식과 진행 중인 실험 출력을 임의로 다시 쓰지 않는다.

대규모 코드 삭제·통합은 앞서 승인된 [V5 정리](../v5_project_cleanup_20261104/REPORT.md)이며 변경 전 SHA·대체 경로·동등성 검사·원문 보존 기록을 함께 확인한다. 이번 추가 정리에서 기존 연구 결과를 임의로 더 삭제하지 않았다.

## 검사 기록

- [정리 목록](cleanup.json): 제거한 캐시와 로컬 보존 원시 보고서의 경로·크기·SHA.
- [관련 CPU 회귀](cpu_regression.txt):26개 모듈191개 검사, 전부 통과. GPU 장면은 새로 실행하지 않았다.
- `validation.json`: 현재 문서 링크·문법·공유 패키지·staged 파일 정책과 독립 검토 결과.

Git에 포함할 변경과 실제 커밋·푸시 결과는 Git 기록으로 확인한다. 실행 중 연구의 상태·결과 요약은 커밋 뒤에도 계속 갱신될 수 있으며, 그 이후 변경은 해당 연구의 새 진행 기록이다.
