## 전체 문서 목록과 접근 한계

프로젝트의 Markdown/RST/README 문서를 경로별로 조사해 [전체 문서 목록](document_inventory.json)에 현행 안내·역사 실험/계획·원문·외부 참고자료로 분류했다. 목록은 디렉토리 심볼릭 링크와 `.git`을 따라가지 않는다. '읽기 가능'은 파일 본문 접근 여부이며, 모든 과거 실험 주장을 새로 재현했다는 뜻이 아니다. 현행 안내의 실제 변경·검증 범위는 변경 전 원문과 검증 결과로 확인한다.

**외장 저장소를 가리키는 문서162개는 I/O 오류로 본문을 확인할 수 없었다.** 해당 링크와 외장 원본은 삭제·수정하지 않았다. 따라서 외장 자료까지 모두 최신화되었다고 선언할 수 없다. [접근 불가 문서 목록](unreadable_documents.json)에 경로·외장 대상·오류를 남겼다. 연결 복구 뒤 이 목록만 추가 점검하면 된다.
