# 현재 왼손 학습 보상 구조

2026-10-30 코드 대조 기준. 현재 기본은 **GPU 왼손 finger-skill v3·J33·목표각 직접 제어(position)**다. R/F 단계와 누적 제어는 현행 기본에 없다. 실행 명령은 [학습 안내](/home/ajou/yigyu/3/guitar_learning/README.md)를 따른다.

## 현재 읽을 문서

보상9항의 계수·계산·오압현 판정·손목 종료·단일 실패 비용은 [12 현재 J33 보상과 조기 종료](12_v25보상단순화와종료.md)에 모았다.

| 보상 | 역할 |
| --- | --- |
| 목표 패드 접근 | 지정 패드의 목표 접근 진행도 |
| 최초 접촉 | 연속 접촉 진행도 증가 |
| 압현 유지 | 음 길이로 정규화한 clean 유지 |
| 압현 달성 | 연속 clean 문턱 최초 달성 |
| 오압현 | 목표 수행을 방해하는 audible wrong 감점 |
| 음 수행 부족 | 누락과 연속 유지 부족의 통합 감점 |
| 대기 자세 | 해당 손가락이 준비·접촉하지 않을 때 약한 B 선호 |
| 엄지 안내 | 연주용 넥 뒷면의 거리·방향·접촉 후보 |
| 행동 변화 | 손가락 LH21을 제외한 명령 변화 감점 |

손목 이탈·물리 실패는 종료 조건과 한 번의 실패 비용으로 처리한다. GPU 왼손은 v9에서 시작하며 B 대기는 MCP±30°, PIP/DIP±15° 허용대를 사용한다. v9 reset과 B 보상은 서로 다르며, 사용 중인 손가락을 B로 강제 복귀시키지 않는다. 로그 키·시간 단위·추적 방법은 [LOGGING](/home/ajou/yigyu/3/guitar_learning/docs/LOGGING.md)을 따른다.
