# 문서 정리·최신화 기록

2026-10-30에 현행 안내와 코드 해설을 정리했다. 실행·보상·제어 코드는 변경하지 않았다.

- 프로젝트 진입/현황/맥락/문서 색인에서 중복된 성과·실행 설명을 줄이고 대표 문서로 연결했다.
- 초기035/v14와 GPU왼손v9, 과거 RFJ와 현행 J33, 누적 제어와 position, 과거검증과 현재문서검증을 구분했다.
- 재개계약v4, 관측557, B허용대MCP±30/PIP,DIP±15를 실제코드와 맞췄다.
- AST기본의존성33개(구현25+초기화8)·정의553개·archive제외활성Python292개를 재조사하고 코드해설의 SHA/함수행/대응표를 갱신했다. 정적 연결은 실행 추적 파일 수가 아니다.
- 구형 학습·병렬·계보 설명은 원문을 보존하고 현행 문서에서 분리했다.
