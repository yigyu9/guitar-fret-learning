# 현재·재현용·폐기 가능 자료 구분

사용자 승인: 앞서 제안한 역할별 프로젝트 정리 진행.

- [x] 대표 문서·계획·실험·자산 역할과 경로 제약 조사
- [x] 참조 없는 로컬 완료 계획만 기존 보관 영역으로 이동
- [x] docs 진입점·계획/실험/자산의 역할 안내 정리
- [x] 이번 검증용 중복 복사본 등 명확한 임시 자료 정리
- [x] 이동 목록·보존 기준·전체 분류표와 삭제 근거 기록
- [x] 새 링크·실행 입력 SHA·현재 저장본 검증·독립 검수

실행 코드·자산·곡·봉인 입력·과거 실험 원문은 유지한다. 외장 저장소 링크의 대상은 읽거나 변경하지 않는다. 봉인되었거나 다른 로컬 문서/코드에서 참조한 계획은 그대로 둔다. 원문 바이트를 바꾸지 않고 이동 경로와 SHA를 남긴다. Git 인덱스·commit·push는 변경하지 않는다.
