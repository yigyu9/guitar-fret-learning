# 문서 안내

문서는 [목적별 문서 색인](DOCUMENT_INDEX.md)에서 찾는다. 현재 연구 상태는 [CURRENT_STATUS](../CURRENT_STATUS.md), 학습 실행은 [학습 안내](../guitar_learning/README.md)를 기준으로 읽는다.

날짜별 디렉토리는 실험 당시 기록이다. 현재 코드와 다른 명령·초기 자세·상태 차원·검증 결과를 현행 안내로 해석하지 않는다. 과거 자료의 삭제·보존 범위는 [최근 저장공간 정리 기록](maintenance/storage_cleanup_20261030/result.json)에 남겼다.

현재 압현 연구의 최신 완료 결과는 [목표 전환 v2](2026-11-02/압현성공/experiments/target_transition_v2/README.md)다. 이번 삭제·보존 범위와 문서 대조 결과는 [프로젝트 정리 기록](maintenance/project_cleanup_20261031/REPORT.md)에 모았다. 날짜별 원래 결과와 봉인 입력은 역사 근거이며 현재 값으로 고쳐 쓰지 않는다.
