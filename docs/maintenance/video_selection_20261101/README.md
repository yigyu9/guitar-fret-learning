# 공개 성공 영상 정리

사용자 요청에 따라 실험 유형별 대표 모델의 손 확대1개·전신1개를 선정했다. 성공 여부는 보고서·원시 원장으로 확인하고 기하 재생, 팔 지원 학습, 실행 해석 진단을 구분했다.

- 공개 `압현성공/video`: 60→30개. 성공5범주의40개를10개로 줄였고 실패 진단20개는 보존했다.
- `압현실험/동영상`: 35→29개. 번호16 학습률 비교8개에서 보수 조건 최고 모델의 한 쌍만 남겼다. 나머지 번호별 카테고리는 기존 한 쌍을 유지한다.
- 합계36개 삭제. 선정된6범주에는 각각2개씩, 총12개의 대표 파일이 있다. 이는 두 모음의 전체 영상 수가12개라는 뜻은 아니다.
- 기존 원본 영상의 SHA는 전후 동일하다. 진행 중 연구·공유본·모델·로그·봉인 JSON 원문은 수정하지 않았다.
- 관련 Markdown47개 링크를7문서에서 정비했다. 같은 영상 원본이 남아 있으면 그 경로로 연결했고, 유일한 공개 파일을 삭제한 경우에는 삭제 사실을 표시했다. 다른 동작의 영상으로 바꿔 연결하지 않았다.
- 하드링크 원본이 남는 파일은 데이터 블록이 회수되지 않는다. 실제 마지막 링크가 제거된 파일의 할당량 합계는15,224,832바이트(약14.52MiB)다.

과거 영상목록과 검증 JSON은 당시 원문으로 보존한다. 현재 공개 목록은 대표 영상 문서와 실행 결과의 삭제 원장을 함께 기준으로 한다.

현재6→8 연구에는 별도 CPU 감시기를 시작했다. 학습·영상·차트와 소스 검증까지 완료된 뒤에만 공개 영상을 한 쌍으로 축소한다. 실제 렌더 원장의 성공 여부를 봉인 보고서와 대조하고, 같은 모델의 평균128환경 반복 평가를 선정에 반영한다. 원본 렌더·모델·학습 상태는 수정하지 않는다. [감시·정리 상태](active_video_cleanup.md). 누락·변조·경로 이탈·미완료·실패 학습에서는 삭제하지 않으며 관련 CPU12검사와 독립 검수를 통과했다.
