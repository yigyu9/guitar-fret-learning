# GPU 왼손 최초 압현: 연속 접촉 v11

최초 압현 보상을 받는 조건을 **누적50ms → 연속50ms 정상 접촉**으로 변경했다. 짧은 접촉을 여러 번 합쳐 보너스를 받는 것을 막고, 올바른 끝마디 접촉을 잠깐 안정시키도록 유도한다. 이번 작업은 보상 구조 개선이며 학습을 실행하지 않았다.

## 동작

- 물리240Hz에서 직전·현재 정상 후보가 모두 유효한 구간만 인정한다. 기존 패드 위치·방향·지정 끝마디 하중·오압현 배제 조건을 사용한다.
- 압현 준비 시점 `press_s`부터 음 종료 `end_s`까지 겹치는 시간만 `contact_streak`에 더한다. 정상 후보가 끊기거나 시간창 밖이면0으로 초기화한다. 한 표본의 접촉 소실도 연속성을 끊는다.
- `contact_streak >= min(0.05초, end_s−press_s)`를 처음 채우면 보상 `0.5 × 손가락별 비중 × 접촉 단계 비중`을 한 번 지급한다. 더 짧은 압현 창의 기존 문턱 축소는 유지한다.
- GPU 왼손은 길이가0 이하인 압현 창을 초기 단계에 거부한다. 0문턱의 무접촉 보너스와 관측0나눗셈을 막으며, 공용 작업 정의와 오른손·CPU 입력 계약은 변경하지 않는다.
- `contact_done`은 음별로 유지되므로 손을 뗐다가 다시50ms 접촉해도 재지급하지 않는다. 같은 프렛의 다음 별도 음은 독립 목표다.
- PPO 수집 경계에서는 연속 시간을 유지한다. 에피소드 reset은 선택한 환경의 모든 음별 상태를 초기화한다.

진단 `contact_time`은 기존 누적 시간을 그대로 보존한다. 예를 들어20ms 접촉→이탈→30ms 접촉이면 누적은50ms지만 현재 연속시간은30ms라 최초 보상을 받지 않는다. 인접 유효 표본의 시간만 세므로 재접촉 첫 구간은 보수적으로 제외된다.

## 관측·버전

GPU 왼손 상태506열의 이름은 `left_curriculum.focus_contact_streak_fraction`이며 현재 연속시간/문턱을0~1로 보여준다. 접촉이 끊기면0으로 돌아가며, 별도 달성 flag는 유지된다. 상태544·event24·priority8·커리큘럼3331값은 그대로다. 음별 원장은 `surface_note_ledger.v4`로 바꾸고 `contact_streak`를 추가했다. 이것은 현재 연속시간이며 최대 연속시간 기록은 아니다.

보상 계약은 `gpu_tensor_song_reward.v11`, 표면 보상 묶음은 `surface_fretting.v5`다. v10 이하와 관측·보상 의미가 달라 strict resume를 거부하며 동일v11 전체 계약만 복원한다. 보상량·하중 문턱·패드/프렛 기하·누적clean에 의한 음 달성·손가락 움직임 비용0·물리·제어·PPO·CPU 왼손·오른손은 유지했다. 후반 타이밍 차등은 추가하지 않았다.
