평가 뒤 전체 학습 로그를 분석하고 마지막 모델의 전신·손 영상을 저장한다. 선정된 대표 모델이 마지막 모델과 다르면 그 모델의 영상도 저장한다. 영상은 평가에서 기록한 실제 자세를 재생한다. 모든 후처리가 성공하면 `RESULTS.md`와 분석·평가·영상 경로를 생성한다. 오류가 발생하면 `pipeline_status.json`에 실패 단계와 원인을 남기며 완료로 표시하지 않는다.

현재 문서는 실행 구성을 설명한다. 학습 성능 및 결과물은 아직 확정되지 않았다.
