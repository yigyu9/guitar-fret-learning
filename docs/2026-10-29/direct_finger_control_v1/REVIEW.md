# 직접 위치 제어 전환 독립 검수

요약 판정: **문제없음**. 현재 변경 범위에서 추가 수정이 필요한 문제를 발견하지 않았다.

## 검수 범위

이번 `gpu/control.py`·GPU 환경·설정/rollout·단음 도구·접촉 진단 도구와 관련 검사 변경을 검토했다. 과거 진단 결과 문서의 기존 변경은 코드 검수 범위에서 제외했다. 소스는 직접 수정하지 않았다.

- LH21은 준비 기준각에 대한 부호별 native 전체 범위의 직접 위치 요청이다. 행동0은 준비 기준 복귀 요청이고 ±1은 native 끝각 요청이다. 같은 행동을 반복해도 목표각에 더하지 않는다.
- 이전 목표각은 4rad/s 변화 제한에만 사용한다. 손가락 평활화 alpha1·부분 reset·다른 환경의 상태 보존을 유지한다. B 대기 자세 자동 복귀를 추가하지 않았다.
- 활성 누적 손가락 codec 구현·선택 옵션을 제거했다. 남은 `incremental`은 구형 입력 거부 검사·안내 또는 별도 보상/로그의 누적 의미다. 팔·손목 DLS 보정은 손가락 행동 누적 제어와 구분하여 유지했다.
- 오른손과 다른 행동 채널의 제어 법칙, PD/힘 및 보상 계산 변경은 없다. 구형 누적 설정과 서로 다른 행동 계약의 checkpoint를 거부한다.
- 새 공용 `trajectory_actions()` 실행 의존성이 접촉 도구의 SHA 목록에서 누락됐던 지적은 해결됐다. 실제 `physics_source_paths()` 반환값에서 해당 소스 포함을 확인했다.
- 코드해설09의 남은 현재형 누적 codec 설명은 직접 위치·alpha1 설명으로 수정됐다. 현재 문서의 행동 의미는 구현과 일치한다.

## 확인 근거와 한계

검수자가 실제 rl38/CUDA 비활성 환경에서 관련 5개 모듈 **47개 검사**를 독립 실행하여 통과했다. `git diff --check`도 통과했다. 이후 추가된 진단 기대값 변경(`limit_outward_command_fraction=0`)은 위치 요청이 범위 밖 방향의 누적 명령을 가지지 않는 현재 계약과 일치한다. 최종 관련 7개 모듈 62개 통과 로그를 확인했다.

전체 최종 검사 로그와 `cpu_comparison.json`은 917개 실행 중 변경 전부터 존재한 failure1/error23이 남고 새 실패가 없음을 보고한다. 전체 검사가 모두 통과했다고 해석하지 않는다. 기존 문제를 이번 작업에서 계약 완화로 숨기는 변경은 발견하지 않았다.

보관 manifest의 **310개 파일(281개 Python)**을 검수자가 실제 읽고 SHA를 재계산하여 전부 일치함을 확인했다. `active_sources_before_gpu.json`의 현재 활성 Python **281개 SHA**도 전부 일치했다.

실제 GPU 원자료의 보고서를 읽어 다음 실행 완료를 확인했다. 검수자가 GPU 실행을 별도로 반복하지는 않았다.

- hand probe: 8환경·960 제어 tick·환경당3840 물리 step, 완료/장면 정리 정상, codec 오차0, reset 목표/준비 q 복원 오차0, 변경 입력 없음.
- 공개 기본 학습: large·128환경·H32·8업데이트 완료.
- 동일 직접 제어 checkpoint의 추가 2업데이트 재개 완료.
- 재개 저장본 별도 평가: 4환경·4에피소드·phrases 완료, `failure=null`, 물리·손목 실패0. 평균 압현 달성0이므로 학습 성능 향상의 근거로 사용하지 않는다.

최종 `verification.json`의 GPU 보고서4개와 CPU 근거3개 SHA를 검수자가 재계산하여 모두 일치함을 확인했다. 평가 완료 후 현재 활성 Python281개 SHA도 다시 확인하여 변경0이었다. 최종 결과 README와 보관 안내는 실제 실행 범위와 기존24개 검사 문제를 구분하고 있다.

이는 직접 제어의 실행·저장·재개·평가 기능 검증이다. 학습 수렴, 압현 성공률 향상, 손 모양 자연스러움, 장기 안정성을 입증하지 않는다.
