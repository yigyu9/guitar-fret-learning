# Stability Adapter: drop-settle-reach 구현 계획 (2026-09-15)

## 목표

`--task stability-adapter` 하나에서 기타가 먼저 낙하하고 안정된 뒤, 왼손이 넥 아래에서 점진적으로 접근해 그립하고 목표 자세로 이동·유지한다.

## 전제와 성공 기준

- 리셋 직후 손과 넥이 접촉한 상태를 사용하지 않는다.
- 기타 선속도·각속도가 기준 이하로 일정 시간 유지되기 전에는 정책 출력을 관절에 적용하지 않는다.
- 단계 순서는 WAIT_SETTLE → UNDERHAND_REACH → GRASP → TRANSPORT → MAINTAIN이다.
- 접근 단계에서 먼 거리의 손가락 조기 폐쇄를 막고, 팔·손목 이동 속도를 제한한다.
- 종료 사유와 단계별 진단 값은 기존 episode 로그에 유지한다.
- 새 환경은 이전 체크포인트와 계약상 호환되지 않도록 버전을 올린다.
