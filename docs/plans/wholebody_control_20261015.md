# Root 고정 전신 관절 제어로의 확장 계획

사용자 최신 지시: root를 제외한 전신 관절을 사용하며, 초기 자세 유지 역할도 포함한다. 앞으로의 음악 환경에서는 하체 관절을 제거한 fixed-lower 자산 대신 하체 관절이 존재하고 유한한 관절 제어로 자세를 유지하는 구성을 목표로 한다. 과거 하체 완전 고정 지시와 실행은 과거 조건으로 보존한다.

- [x] 원본 자산과 기존 제거된 하체 관절을 확인한다. 원본은105 scalar joint, 하체24개이며 그중8축은 원래 range=0이다.
- [x] 새105목표/39정책출력 계약과 전신 유한 PD 명령 계산을 별도 모듈에 구현한다. 실제 상태를 매 step 덮어쓰지 않는다.
- [x] CPU 회귀 검사로 이름 대응·하체 목표 유지·교란 복원 토크·포화·입력 검증을 확인한다. 자산 검사는 XML 구조 검사이며 native 물리 검증과 구분한다.
- [x] 독립 검수, 사용자 결정·논문 표현·후속 native 연결 조건 기록과 입력 보존을 완료한다.

가정: 정책 출력의 개수와 제어되는 전신 관절의 개수는 다르다. 학습된 연주 목표39개와 자세 유지 목표66개를 합쳐105채널의 feedback 제어를 구성한다. 하체의 새 기준각과 gain/effort는 추정하거나0으로 채우지 않고 외부105차원 reset 계약으로 받는다. 원본 관절 한계가0인 해부학적 축을 자유롭게 움직이도록 변경하지 않는다. 기존 fixed-lower 자세의 링크 변환은 baked되어 있으므로 원본 자산에81개 각도를 복사하는 것만으로 같은 초기 배치가 재현된다고 보지 않는다.

초기 자세 연구와 상세 새 환경 구현의 순서는 유지한다. 이번 범위는 CPU 제어 계약과 문서이며 현재 native 환경·초기 자세 연구·정책 가중치를 변경하거나 장시간 학습을 시작하지 않는다. 원본 자산은 이미105관절을 보존하므로 이 단계에서 새 mesh/자산 복사는 필요하지 않다.
