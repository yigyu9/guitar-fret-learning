# finger-skill 기본 학습 경로 정리

사용자 요청: finger-skill을 기본 구조로 하고 기존 구현을 별도 보관. 사용자 실행 지시를 작업 승인으로 따른다.

- [x] 변경 전 활성 Python/문서 원본을 archive/20261026_before_finger_skill_default에 SHA와 함께 보관.
- [x] 기본 train은 GPU 왼손 finger-skill v2로 직접 연결. 기존 song/v24는 별도 재현 도구로 분리.
- [x] 공유 물리·접촉·제어·정책·저장/평가 코드는 실제 의존성을 보존. 이전 실험 도구는 명시적 구형 진입점으로 갱신.
- [x] 현재 README/학습 흐름/작업 규칙을 기본 경로와 일치시킴.
- [x] 기본 설정과 이전 명시적 v25 설정 동등성, 구형 설정 보존, CLI/분기/회귀 검사 및 독립 검수.

범위: 실행 구조 정리이며 보상·종료·제어·정책 학습 수식은 변경하지 않는다. 공유 base class는 사용 중이므로 보관본만 남기고 삭제하지 않는다. 과거 checkpoint는 소스 SHA의 엄격 검증을 계속 적용하며 변경된 소스에 자동 재개시키지 않는다. 장기 학습은 시작하지 않는다.

검증: 63모듈596검사 중594통과·2외장자료 읽기 오류. 현행 GPU 입력655개 SHA/활성 Python510개 문법 및 기본경로 검사는 통과. 외장자료 미완료와 native 학습 미실행을 결과 문서에 구분했다. 결과: docs/2026-10-26/guitar_learning_finger_skill_default/README.md.
