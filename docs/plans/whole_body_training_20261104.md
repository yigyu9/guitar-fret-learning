# 타현 확인 및 전신 37축 학습 구현

요청: 기존 타현·전신 학습 코드를 확인하고 미구현 영역을 구현한다. 사용자의 구현 지시에 따라 진행하며 GPU 물리 실행과 장기 학습은 이번 CPU 구현 검증에 포함하지 않는다.

## 범위와 성공 기준

- [x] 타현 환경·정책·PPO·학습/평가/렌더 경로와 CPU 검사 확인: 63개 통과.
- [x] 전신 37축 전용 관측·보상·환경 구현. 음악 목표 없이 준비 자세와 기타 지지 유지부터 시작한다.
- [x] 기존 유한 지지 제어 위에 독립적인 37축 잔차 목표각을 연결. 기존 PD·힘·관절 범위·물리·접촉·실패 문턱은 유지한다.
- [x] 별도 Actor/Critic 및 기존 PPO 연결, 엄격한 저장·재개, 평가 진입점 구현.
- [x] CPU 합성 표본, 실제 작은 PPO 업데이트, 제어 소유권·잔차 비누적·부분 초기화·SHA 변경 거부 검사.
- [x] 독립 검토와 명령·한계 문서화.

## 설계 결정

- 압현·타현의 기존 소스는 수정하지 않고 새 전신 모듈만 추가한다. 봉인 입력·실험·모델·로그는 변경하지 않는다.
- 상태는 원안 480 + 지지/좌우 발 접촉 상실 시간3 + 남은 시간1 = 484다. 숨겨진 종료 타이머를 정책과 가치망에 제공한다.
- 출력은 37축이다. 공용 PPO의39차원 인터페이스에는 마지막2개를 고정0으로 전달하고, 확률·엔트로피·KL에는 실제37축만 사용한다.
- 기존 지지 명령을 독립적으로 계산한 뒤37축에 최대±0.10rad 잔차를 더한다. 기존 속도·native 범위를 적용하며 실제 물리 상태는 초기화 경계에서만 복원한다. 발 보정 기준 메모리와 정책 적용 목표를 분리해 같은 잔차가 누적되지 않게 한다.
- 초기 자세는 왼손 v9를 사용하고 양손 정책은 실행하지 않는다. 전신 지지의 첫 학습 경로이며 세 정책 공동 학습이나 연주 중 지지 성능을 입증하지 않는다.
- 인간Root고정·자유기타 조건을 유지한다. 자유 균형·실제 현 압력·음향 성공을 주장하지 않는다.
