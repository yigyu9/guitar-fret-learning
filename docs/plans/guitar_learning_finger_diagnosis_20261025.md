# 최종 v19 손가락 관절 편중·대기 진단

사용자 요청: 마지막 관절만 굽고 나머지가 펴지는 현상과 대기 시간이 짧다는 가설을 기존 로그로 검증하고, 부족하면 진단 도구를 추가한다.

진단 범위는 기존 v19 final3000 고정 정책이다. 보상·제어·PD·관절 한계·물리·기준 곡·성공 판정·학습 원문을 바꾸지 않는다. 원래 학습/영상 평가 자료도 보존하고 새 산출물은 `docs/2026-10-25/guitar_learning_finger_diagnosis_v1`에 저장한다.

1. 기존1024개 평가와8개 자세 기록에서 손가락별 실제 대기 가능 총량·각도·한계 명령을 집계한다. → 분모·실패 구분, 실제240Hz 기록과60Hz 재구성 구분.
2. 시간창·보상·관측·누적 제어 경로를 대조한다. → 대기 부족/보상 활성화 후 미복귀/압현 중 DIP편중/제어 추종 문제의 근거를 분리.
3. 기존 요약에 없는 연속 대기 구간 길이와 시점별 보상·선택 목표는 별도 관찰 도구로 고정 정책을 재실행해 기록한다. → 같은1024환경·seed·final·원문SHA, observer 반환/입력 불변, PPO/단계 갱신 없음, 첫곡만 기록, 원래 영상env0 자세와 대조.
4. 도구 CPU검사·실제 기록 회계·독립검수 후 원인별 판정과 남은 불확실성을 문서화한다. 보상 변경·재학습은 이번 범위가 아니다.
