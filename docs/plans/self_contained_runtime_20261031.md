# Git 정책 정비와 프로젝트 내부 실행 입력 검증

사용자 승인: 개별 파일명 나열 대신 확장자·디렉토리 기반 .gitignore 정비, /3 내부 자료만으로 학습·평가 실행, 팀원 요청 진단·초기 자세 파일의 현행 경로와 기록 정리.

- [x] .gitignore·staged hook의 위치/확장자 정책 통합, 실제 필수 자산 예외 검증
- [x] 실행 입력·심볼릭 링크·누락된 진단 파일의 로컬 원본 조사
- [x] 필요한 최소 수정 후 외부 프로젝트 자료를 읽지 않는 입력 검사 강화
- [x] 프로젝트 내부 캐시·출력으로 짧은 학습·재개·평가·영상 검증
- [x] 팀원 전달 문서·원본 파일 위치·검증 결과 정리
- [x] 독립 검수

코드·자산·진단 원본은 의미와 SHA를 유지한다. 과거 절대 경로 식별자는 기록으로 보존하며 실행 경로와 구분한다. Python 패키지·운영체제 라이브러리·GPU 드라이버는 설치 환경으로 구분하고 프로젝트의 외장 데이터 의존을 제거한다. 팀원에게 메일을 전송하지 않고 프로젝트 내 전달 문서를 작성한다. 과거 봉인 checkpoint 호환을 무조건 유지하기 위해 검증을 우회하지 않는다.
