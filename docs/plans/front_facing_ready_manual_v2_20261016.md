# 사용자 보완 조건의 추가 검증 계획

기준 요구문서는 [REQUIREMENTS_v2](/home/ajou/yigyu/3/paper/initial_pose/lower_body_release_v1/front_facing_ready_v1/REQUIREMENTS_v2.md)다. 기존 REQUIREMENTS/9개 leaf/32개 구현과 v1~v6 소비 입력·원자료·판정은 수정하지 않는다. 현재 v6 baseline28/repeat28은 기존 기준 통과이고 release34는 진행 중이다. 아직 전체 후보 채택·재접촉·연속·재시작 성공이 아니다. 이번 문서는 최종 후보 평가 전의 추가 기준이다. 사용자 자율 실험 승인에 따라 필요한 검사와 진단을 진행한다.

## 확인된 공백과 해석

- 기존 기타 변위/회전은 world 초기값 기준이다. Torso/Chest 상대 6D 변화, 주기마다 남는 이탈을 추가한다.
- 발 전행 PTP3mm·속도·sole tilt2도는 이미 중간 미끄러짐도 검사하지만 접촉 연속누락 길이·전체회전을 별도 표시하지 않는다.
- RH 손가락은21축이다. 목표는 실제 타현 중 고정이지만 유한 native POSITION drive에서 미세 실제응답은 발생한다. 원pick은 index2의 무geom 고정자식 marker이며 실제 충돌피크/현힘은 없다.
- 초기reset 직후 t0 접촉은 현재pose freshness 미확인이다. 첫 simulate→fetch가 끝난step1부터 fresh로 분류한다. raw0은 삭제하지 않으며 기존 금지접촉 veto도 소급 바꾸지 않는다.
- actual q의 제한 초과를 eps0으로 별도 집계했다. baseline에서 큰 다섯 축 초과 중 네 축은 준비5초 전 종료, 준비 후 엄지 축은 sub-microradian 잔차다. zero8도 실제q/dq가 정확한0은 아니다. 크기만으로 원인을 확정하거나 임의epsilon으로 성공 처리하지 않는다.
- 현재 LHindex2/3–fret5 접촉은 넥그립 근거이며 지정현 압현 완료가 아니다. 실제 선택현·프렛 압현/현힘 제어는 구현돼 있지 않다. 준비 배치·접근 가능성을 별도 확인하고 주장 범위를 구분한다.

## 추가 측정과 수치 기준

기존 core/feet/media 기준을 모두 AND로 유지한다. 접촉 분담의 짧은 변화 허용이라는 사용자 보완이 있어도 기존 실패의 삼중지지95% 문턱을 사후 완화하지 않는다.

1. **기타 상대 이동**: 실제 정규화 quaternion으로 `T_Torso^-1 T_G`, `T_Chest^-1 T_G`를 계산한다. 실제16초를 기준으로 준비5..T 전행의 이동≤30mm/회전≤5도. 기존 world 초기값30mm/5도도 유지한다. 전행/각 단계 최대·최종값, 각 왕복 끝 잔류변위·회전, 세계/몸통 좌표 누적 경로길이를 함께 기록한다. 경로길이는 작은 왕복·수치잡음을 합하므로 순이탈과 구분하며 독립 성공 문턱으로 쓰지 않는다. 같은 범위의 전행 최대가 지속 누적 이탈을 제한한다.
2. **발**: 기존 전행4sole 높이−1..+3mm·tilt2도·위치PTP3mm·속도.02m/s·각속도.2rad/s를 유지한다. 추가로5..T에서 각 Ankle/Toe의16초 대비 전체회전≤2도, 발별 양성 ground접촉 연속누락≤.1초를 요구한다. 접촉누락은 실제 기하적 lift-off와 구분한다. raw/positive 누락 길이, sole높이·회전·총/순미끄러짐을 모두 기록한다. 표본 지속시간은 samples/240을 보수적 상한으로 쓰고 endpoint span도 함께 남긴다.
3. **RH 파지**: 16초 이후 RH21 requested/final이 기존2396 latch와 exact. 실제 개별축 peak-to-peak≤.01rad(손가락 길이 약.1m에서 약1mm급 변화에 해당하는 파지 유지 기준; 관측최대에 맞춘epsilon이 아님). pick–index2 실제 상대변환의16초 대비 변화≤10µm/.01도, pick–palm≤1mm/1도. 원XML local offset은 그대로 유지하며 '추가 인위 offset0'과 원local offset0을 혼동하지 않는다. index2 자식 marker의 무관절 정의·실행 중 별도 변환 쓰기 부재도 검사한다.
4. **상완/타현**: 기존 Rprox6 목표 고정과 각 왕복 실제 부모–자식 회전변화≤1도,6→1/1→6·깊이1mm·최소현통과속도.05m/s·원4초왕복/지정횟수 gate 유지. 각 주기 속도·시각·순서·실제 이벤트 수와16초 대비 누적 상완변화를 공개한다. 팔 왕복·marker 현통과·실제 현힘을 구분한다.
5. **LH와 재접촉**: 기존 완전해제 raw0/15초·실제형상2mm·손목60mm/재파지5초·손목2cm·동일고정축 닫힘/넥접촉95%를 유지한다. 추가로 주요 동작창에 L_Thorax/L_Shoulder/L_Elbow/L_Wrist/손바닥의 기타 양성접촉이0인지 별도 측정해 다른 왼팔 지지로 대체하지 않는지 확인한다. 원손모양의 fret5 검지 접촉과 현측 접근 형상을 준비 증거로 별도 보고한다. 선택현 압현 동작/현힘은 별도 구현·검증 전 미검증이다.
6. **물리 상태 건강**: 모든105 q/dq/목표·명령·가용 nativeDOF 센서를 분리한다. actual제한 초과는 eps0으로 축별 최대·부호·발생시각·표본수·최장연속·준비전/5초후/11초후로 기록한다. 원XML/native lower/upper/ref 및 FK좌표 의미를 대조하고 원zero8을 별도 표로 남긴다. 원속도한계100rad/s와 runner 안전중단50rad/s도 별개다. 2초창의10Hz 초과 관절각 RMS·최대 q/dq·초기/후기 진폭을 진단한다. 스펙트럼의 상대비율만으로 작은 수치잡음을 고주파 불안정으로 판정하지 않는다. 제한/진동의 미설명 잔차 또는 과도한 실제겹침이 남으면 최종 채택하지 않는다. 독립 근거 없이 새허용오차를 관측값에 맞춰 정하지 않는다.
7. **재시작**: 같은 config·원105초기조건·모델·gain/cap·실제절대일정으로 continuous58을 별도새출력 경로에서 다시 실행한다. 두 실행 각각 모든 core/feet/media와 추가 검사를 통과해야 한다. 두 실행의 시간은 합산해 연속성공으로 표현하지 않는다. 실제traj 차이·support event·G/발 drift도 나란히 기록하며 bit-exact를 미리 보장하지 않는다.
