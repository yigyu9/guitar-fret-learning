# GPU 배치 접촉 회귀 원인 분리와 수정

사용자 승인: 이전 조사에서 이어서 접촉쌍·초기 복원 경로를 분리하고 원인에 맞춰 수정한다. 기존 안정성 기준과 자유 기타·중력·관절 제어 계약을 유지한다.

- [x] 원문 보존 후 사람↔기타/사람↔의자/기타↔의자/자기접촉을 독립적으로 분리 → 동일 힘 1/1024환경 비교
- [x] 결과에 근거한 최소 수정 후보 확인 → 실제 충돌 형상89개를 유지한 단일 강체, 동일 힘·무행동·reset 검증. 두 비물리proxy의 의자/지면 충돌 제외는 새 계약에 명시
- [x] 확인된 완화 수정만 현행 적용하고 관련36개 검사·실제 GPU 학습/저장/재개 확인, 독립 변경 검수 및 결과 기록

접촉 제거 자체는 해결로 채택하지 않는다. 확인되지 않은 원인을 단정하거나 실패를 성공으로 분류하지 않는다. GPU 실행은 root가 순차로 소유한다.

결과: `docs/2026-10-21/guitar_learning_gpu_contact_fix_v1/README.md`. 1024환경2초 최종 실패8회/8환경(이전1781회/817환경),128환경2초0회. 별도128환경10초 진단에서 느린 기타 이탈6개가 남았다. 이번 완료 범위는 원인 분리·수치 폭발 완화·실행 검증이며, 장기 안정화와 권장 환경 수 확정은 미완료다.
