# 정면 정렬 새 자세 실행 v1

기존 정면 정렬 계획을 이어간다. 현재 사용자 요청이 실행 승인이다. 기존 봉인된 코드·입력·실패·영상은 수정하지 않는다. 정면 기준은 고정 Pelvis local −Y의 XY 투영이며 world +Y다.

1. 새 source에서 발4 body와 Torso/Spine/Chest/Head heading 절댓값2° 이내, 원105범위/영범위8축, Root/좌석/기타 불변, 양손 world pose와 활성 충돌 감사 확인.
2. 원 K/D/cap을 유지한 유한 제어에 발 heading 잔차만 추가한다. 기존 오른팔 작은 world affine 및 Hip bias는 동일 숫자를 시작 가설로 재사용하며, 새 자세에서 관측된 보상/하중 또는 이전 성공 인증으로 부르지 않는다. 새 candidate에 묶인 spec/report로 별도 발행한다. 실제 원자료에서 유한성·cap·stablePD 산술·고정 Root·free guitar를 검증한다.
3. 준비0..5초+정지5..10초 실제 실행. 전체 기타30mm/5°/넥3°/좌우20mm/몸통5°/우측3°/Spine5°, 유지구간 가슴+오른상완 접촉95%·양발95%, 마지막1초 네 발바닥 기존 height/tilt/speed/slip 기준 및 실제 유지구간 heading5°를 모두 요구한다. 실패는 새 버전에 근거를 기록하고 재시도한다. 통과 후 같은 설정을 반복한다.
4. 실제 영상과 source 자세 경로, 관측값·실패·미검증 범위를 한국어로 기록하고 독립 검수 및 이전자료 보존 감사 후 봉인한다. 새 자세의 압현·타현·해제 성공을 이전 결과로 대체하지 않는다. 새 PPO는 실행하지 않는다.

정리 이후에도 디스크를 절약하기 위해 native 영상5fps/240Hz 원자료/60Hz 목표를 저장한다. 상태 주입·기타 직접힘·강제부착 금지를 유지한다. 이 문서는 source/runtime/native에 소비한 뒤 수정하지 않고, 진행 체크리스트는 새 phase WORK_STATE.md에서 갱신한다.
