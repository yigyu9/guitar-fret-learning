# 팔꿈치·손목 회전 오차 좌표 교정 검증

## 근거와 한계

native_strike_v5는14초를 완료했지만 동작 삼중지지64.203954%와 내려치기[4,3,1]로 미달했다. 올려치기6줄·하체/발/기타 안정성·6축 목표권은 통과했다. frozen upper_ball_coordinate_diagnosis_v1은 실제960행에서 native qd가 자식 관절 좌표의 상대각속도임을 확인했다(Elbow/Wrist 최대오차5.319e−5/3.093e−4rad/s). 기존 scalar 목표차와 같은 좌표의 SO3 오차는 방향이 최대58.45°/53.02° 다르다. 목표변경 clamp는0, 움직이는 오른손 FK도 기존10μm/.01° 이내다. 목표 FK 오차 최대.799mm에 비해 실제 추종은6.478mm다. 따라서 gain 증가 전에 오차의 좌표를 바로잡는다. 진단은 원인 전체나 개선 성공의 증명이 아니다.

## 실행·검증 체크리스트

- [ ] 새 runtime_v5에서10초 이후 Elbow/Wrist6축 위치오차만 기존 lower rotation_error로 교정한다. 원basis에 대해 Bᵀlog(Exp(Bq)⁻¹Exp(Btarget))를 사용한다. 원K60/20, D3/1, effort cap100/60Nm를 유지하고 scalar항 대비 K*(새오차−기존오차)만 더한다. 목표·motion_v2/source4의4mm/G-Y−15°·Chest0.5mm·하체는 동일하다.
- [ ] 10초 이전 출력/row exact, 이후 다른99축 출력 exact, 상태불변·원cap/float32·실제 최종합산을 CPU검사하고 독립검수한다. 기존 scalar 진단과 이전 raw/submitted를 보존한다. 분석에서는 회전항 복원→원상체/추가Chest 검사→기본Chest 복원 순서를 지키고 새항을 실제 원자료에서 독립 재구성한다.
- [ ] 모든 소비 코드/계획/입력/원XML과 선언mesh/이전실패 원자료를 사전SHA로 보존한 뒤 새 baseline_v6 14초를 실행한다. 원5초 정지와14초 대조의 모든 gate 통과 후에만 strike_v6를 실행한다.
- [ ] 기존 physical gate, 실제6줄 내림/올림·양측 준비·근위 실제상대1°·원105채널/zero8·하체16유한·Root고정·기타free/중력ON/strapOFF를 모두 동일하게 검사한다. 기타힘/부착/고정/매step상태주입/PPO는0이다.
- [ ] 실제 결과와 실패를 같은 phase에 보존하고 독립 검수한다. SO3 교정으로 충분하지 않으면 성공으로 채택하지 않고 다음 원인을 구분해 기록한다.

## 범위

오른어깨/쇄골의 새 타현 목표는 허용하지 않는다. 기존 유한 지지 feedback에 따른 실제 수동 움직임은 기존1° 기준으로 따로 검사한다. 피크/현은 비충돌 표식이므로 실제 손 움직임에 따른 기하적6줄 왕복을 검증하며 현 힘/진동/음향을 주장하지 않는다. 새 정면 자세의 왼손 해제·결합 압현은 별도 미검증이며 이전 왼검지 strict FK 실패를 보존한다. 기존 모든 소비 소스·계획·실험은 수정하지 않는다.
