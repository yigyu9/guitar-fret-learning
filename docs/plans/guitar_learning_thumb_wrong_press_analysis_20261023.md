# 엄지 뒷면 지지와 오압현 분석

사용자 요청: 최근 v8 장기 학습에서 엄지가 넥 뒤를 가볍게 지지하도록 하는 보상의 필요성과 오압현 여부를 분석한다. 이번 범위는 원자료를 읽는 분석이며 학습 코드·보상·기존 봉인 결과는 수정하지 않는다.

- [x] 현행 GPU 엄지 제어·관측·보상과 오압현/성공 판정의 정확한 범위를 확인한다.
- [x] 고정1024 평가의 오압현 원장과 실제 자세 표본을 재계산한다. 압력·실제 접촉 파트너가 없는 저장값의 한계를 명시한다.
- [x] 별도 읽기 전용 검토와 대조해 현재 문제와 개선 우선순위를 설명한다.

검증 기준: 기존 입력 SHA 대조, 평가 원장 합계/분모 재계산, 실제 source mesh와 저장 quaternion의 좌표계 일치 확인. 기존 장기 결과 디렉토리는 변경하지 않는다.
