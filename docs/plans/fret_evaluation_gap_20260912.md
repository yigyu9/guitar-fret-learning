# Fret 학습–평가 격차 개선

기준: 20260911_1710 run. 학습 F1 96.7%, 마지막 전체곡 평가 F1 21.2%.
이전 실험: FRET-015/016의 균형 표집·복구, FRET-017의 무보조 평가.

- [x] 평균 행동 / 샘플링 행동과 seed를 명시하는 평가 옵션 추가.
- [x] 진단 영상 이름 분리, 평가 조건을 JSON에 저장.
- [x] 자동 평가 후 조건별 최상 완료 checkpoint 경로 기록.
- [x] 초기 자세 / 캐시 자세, 목표 직전 / 이전 음 시작 비교 구현.
- [x] GPU 비교 평가로 초기화·행동 분포 가설 검사(단일 목표 예비 실험).
- [ ] 확인된 원인에 한해 초기화·실패 직전 구간 표집 수정.
- [ ] 같은 checkpoint에서 2,000 iteration 비교 실험.

보상과 승급 기준은 아직 변경하지 않는다. 평가 결과가 없는 상태에서
RSI 비중이나 실패 구간 가중치를 임의로 정하지 않는다.

## 실행

기존 record_fret_rollout.py 커맨드에 `--action-mode mean --seed 42` 또는
`--action-mode sample --seed 42`를 추가한다. seed 43, 44도 반복한다.
goal과 hand-targets는 원래 checkpoint 입력을 사용한다.
옵션 지정 시 출력 파일명에 행동 방식과 seed가 붙는다.

자동 영상 생성은 `videos/evaluation_summary.json`을 갱신한다.
기존 결과는 `python -m tab2body.tools.summarize_fret_evaluations <videos 경로>`로
집계한다. seed·입력·평가 방식·준비 시간이 다른 결과는 따로 묶는다.
최상 경로만 기록하며 checkpoint 복제나 삭제는 하지 않는다.
완료한 평가 중 sustain 성공률, F1, 낮은 오압현율 순으로 선택한다.
단일 rollout 기준이며 안전 검증이나 통계적 우월성 판정은 아니다.

## 구간 진단 옵션

- `--start-frame 499`: 원본 곡의 499 frame부터 끝까지 실행한다.
- `--initial-pose cached`: 해당 목표의 성공 캐시에서 제어 관절을 초기화한다.
  비제어 관절은 고정 자세를 유지한다. 캐시가 없으면 명시적으로 실패한다.
  hard limit·물리 안정화는 유지하며 reset 전용 soft clamp만 우회한다.
  학습 RSI 전체 상태의 완전한 재현이 아니라 캐시 관절 자세 비교다.
- `--extra-preparation-frames 120`: 원래 준비 시간에 2초를 더한다.
  종료 시간도 늘린다. 보상과 학습 설정은 변경하지 않는다.
- 구간 진단은 오디오 동기화를 지원하지 않으며 전체곡 평가와 따로 묶는다.

검증: CPU 테스트 7개 통과. 리뷰 지적 3건(시간 제한, reset clamp,
reset 관측 속도 일관성) 수정 후 재검수 통과.
수정 전 시험 파일 `fret_035000_rollout_mean_seed42_from499_*`는 비교에서 제외한다.
공식 비교는 `diagnostic_v2_*.events.json`만 사용한다.

## FRET-018 결과: 2026-09-12

35,000 checkpoint, seed 42, 중지 event 1의 499~514 frame(16 frame)을 비교했다.
네 조건 모두 같은 평가 코드 hash로 실행했고 suffix를 끝까지 완료했다.

| 시작 조건 | 평균 목표 거리 | 실제 압현 frame | lateral 품질 |
|---|---:|---:|---:|
| 499, 일반 자세, 준비 1초 | 3.94mm | 0/16 | 0.023 |
| 499, 캐시 관절 자세, 준비 1초 | 3.08mm | 0/16 | 0.036 |
| 499, 일반 자세, 준비 3초 | 4.23mm | 0/16 | 0.012 |
| 447, 이전 두 이벤트부터, 준비 1초 | 24.99mm | 0/16 | 0.021 |

이후 중지 네 이벤트 합계도 모든 조건에서 0/73이었다.
목표 직전 세 조건의 longitudinal/normal/arch 품질은 1이지만 lateral 품질이 낮다.
품질은 점수이며 압현 힘이나 접촉 그 자체를 증명하지 않는다.
캐시 초기화 후 준비 동안 정책이 움직이므로 캐시 저장 순간의 성공 재현 검사는 아니다.
결론: 준비 시간 확대나 캐시 비중 확대만을 처방할 근거는 없다.
다음 우선순위는 목표 줄에 대한 signed lateral 오차와 후보 접촉점 선택,
캐시 자세의 준비 전후 변화, 학습의 성공 집계 기준과 동일 목표 무보조 판정 비교다.
원인이 확정되지 않아 보상·샘플링을 바꾸거나 장기 학습을 시작하지 않았다.

결과 위치: `fret/training/runs/20260911_1710_02_Jazz1-200-B_solo/videos/diagnostic_v2_*`.
영상 4개와 events/stability JSON을 저장했고 인코딩 후 임시 프레임은 자동 삭제됐다.

## FRET-019: 준비 중 접촉 추적

같은 35,000 checkpoint/499 시작/cached/seed42 조건에서 정책 준비와
초기 settled 관절각을 고정 PD 목표로 유지하는 준비를 비교했다.
`--hold-preparation-pose`와 준비 60프레임+이후20프레임 trace를 추가했다.
중도 종료 trace의 관절 편차는 자동 reset과 혼동하지 않도록 null 처리한다.

| 조건 | 준비 중 precise 성공 | 준비 종료 최대 제어각 편차 | 목표 이벤트 압현 |
|---|---:|---:|---:|
| 정책 실행 | 3/60 | 42.80도 | 0/16 |
| settled 자세 PD 유지 | 0/60 | 1.73도 | 0/16 |

최대 편차는 제어 관절 30개 중 최대이며 중지 한 관절의 편차가 아니다.
캐시 q와 settled reset q의 최대 제어각 차이는 두 실행 모두 4.87도다.
정책 실행에서 준비 frame 1~3에 precise 성공이 나타났지만 유지되지 않았다.
정적 유지도 실패했으므로 단순 자세 고정을 해결책으로 적용하지 않는다.
기하학적 접근 거리는 최소 패드 거리이고 fine 정렬은 별도 후보 품질이므로
3mm 접근만으로 올바른 줄 정렬·접촉이라고 해석하지 않는다.

코드 경로 확인: `press_success = physical_press & position_inside`이고
학습 F1 집계의 `correct`도 같은 값을 사용한다. 캐시는 이에 chord_ready,
엄지·품질 조건을 추가한다. 준비 프레임은 공식 누적 성공률에서 제외된다.
이는 동일 물리 상태의 학습/평가 전체 runtime parity를 검증한 것은 아니다.

결론: 단순 mean/sample 차이나 초기 캐시 비중 문제만으로 설명되지 않는다.
캐시 q만으로 안정 접촉을 재현하지 못하며 정책도 잠깐의 접촉을 유지하지 못한다.
후속 작업은 cached action/PD target·관절 속도·접촉 상태까지 포함한 복원 비교와
이미 성공한 접촉의 연속 유지 학습 검증이다. 이번에는 보상·학습을 변경하지 않았다.
GPU 두 평가 완료, CPU7개 통과, 리뷰 종료 trace 지적 수정.
결과: 같은 videos 디렉터리의 `diagnostic_v3_cached_policy/hold` mp4 및 JSON.
