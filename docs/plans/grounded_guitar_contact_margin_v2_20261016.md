# Hip 보상 후 남은 Chest 접촉 여유

실제 native15는19기준 중 Chest/상완 동시접촉95%만 실패했다. 1..5초91.57128%,마지막1초89.21162%이고 상완은100%다. 기타 이동5.46444mm/회전1.60517°,Spine4.69177°와 양발·네 발바닥 조건은 통과했다. Hip 보상 값은 외부하중 직접 측정이 아닌 명령−계산 중력 잔차 가설이다.

마지막240행을 같은 state/contact 시점으로 대조하면 Chest 접촉 없는26행의 source gap은0.010891..0.011434mm(평균0.011110), 접촉 있는214행은0.007565..0.011201mm(평균0.008442)였다. 두 분포가 겹치므로 gap만으로 물리접촉을 인증하지 않는다. 정상 virtual 요청은 약−17.98N이며 원20N cap에 여유가 있다. 과거 cap에 도달한 조건을 확대 재사용하지 않는다.

1. native15의 모든 설정을 유지하고 기존 Chest virtual depth7→9mm 일정에만0→0.25mm를 같은 .75..1.25초 smoothstep으로 추가한다. K2000/D30/cap20, Hip bias3, 인간 world 목표·초기105각·모델·발·Root/cube·자유기타/중력ON/strapOFF를 유지한다. 원7→9mm 필드는 legacy 기준으로 남기고 새 chest_extra_goal_depth_m=.00025를 분리 기록한다. 최종 명목 힘 추가는0.5N이며 상한은 그대로다. 새 runtime18/run18/analyzer18과 static5_v16.json을 만들고 실제 task force/Jᵀ/원cap 재구성을 독립 검수한다.
2. native_static_v16 실제5초의 전체19기준을 그대로 검사한다. source 깊이는 제어 preload이며 실제 관통 깊이나 성공이 아니다. 원자료의 물리접촉95%로 판단한다. 실패하면 같은 방향의 반복 확대보다 실제 접촉·힘·형상 응답을 재진단한다.
3. 전체 통과 시 동일 설정 반복 → 압현·타현 → 왼손 해제15초 순서로 진행한다. PPO는 시작하지 않는다.
