# 기타 넥에 접근하고 손바닥 방향을 유지하는 제어와 학습 구조

이 설계는 실제 물리에서 손의 위치와 방향을 함께 맞출 수 있는 기준 제어기를 먼저 검증하고, 필요한 경우 작은 보정을 학습하는 구조를 제안한다. 지금까지의 구현과 실패 결과를 근거로 만든 다음 작업의 설계안이다. 이후 승인에 따라 기본 제어와 물리 진단을 구현했다. 실제 도달 검증은 실패했으며 성능 개선으로 채택하지 않았다. [구현 검증 기록](../2026-10-12/회의/results/reach_feedback_control_20261003/implementation_report.md).

핵심 결정은 손의 목표 위치와 회전을 관절 움직임으로 연결하는 책임을 명확하게 두는 것이다. 접근 과정은 실제 손의 추종 상태를 보고 진행하고, 학습 초기 상태는 원래 물리 동작을 거쳐 생성한다. 성공 판정은 현재 기타에 붙은 원래 최종 목표를 사용한다.

## 현재 증거와 설계 가정

| 관찰한 결과 | 설계에 반영할 내용 |
|---|---|
| 기존 정책의 목표 2cm 이내 116프레임에서 위치와 간격은 모두 충족했으나 두 방향 조건은 한 번도 충족하지 못했다 | 위치와 방향을 함께 교정하는 제어를 별도로 검증한다 |
| 마지막에 흉곽 두 축과 어깨 및 손목 한 축이 한계에 닿았고 정책은 한계 밖을 향하는 명령을 계속 냈다 | 목표 자세를 고를 때 관절 여유를 확인하고 추종 불가능 상태를 명시적으로 기록한다 |
| 누적 목표 제한만 적용하면 최소 거리는 줄었지만 최대 접촉력은 6.87N에서 26.51N으로 커졌다 | 제한 작동을 접촉 안전의 증거로 사용하지 않는다 |
| 새 정책은 새 가중치에서 512개 샘플만 학습했다 | 새 구조의 학습 성능에 관한 결론을 내리지 않는다 |
| WAIT 이후 기타 위치에서 계산한 손 자세와 원래 기타 reset을 조합하면 충돌했다 | 관절각만 복사해 가까운 초기 상태를 만들지 않는다 |
| 원래 reset에 맞춘 흉곽 가동 IK는 스트랩 연장률 1.081%로 안전 한계 1%를 넘었다 | 원래 스트랩 기준 길이와 물리 시간 및 안전 한계를 유지한다 |
| 흉곽 고정 초기 자세는 안전했지만 WAIT 후 목표와 27.54cm 떨어졌다 | 학습 시작 시점의 실제 근접 여부를 검사한다 |

흉곽을 유지하고 어깨·팔꿈치·손목의 9관절만으로 실제 WAIT 종료 위치의 목표에 도달할 수 있다는 것은 아직 검증되지 않은 가정이다. 먼저 이를 검사한다. 9관절로 불가능하면 허용된 흉곽 움직임을 추가하는 경로를 별도로 검증한다. 학습량 증가나 정책 출력 변경으로 도달 가능성 문제를 해결했다고 간주하지 않는다.

## 선택할 구조

```text
실제 손과 기타 및 관절과 접촉 상태
                 ↓
기타 좌표계의 최종 목표와 접근 경로
                 ↓
실제 추종 상태를 확인하는 과정 관리
                 ↓
기본 손 위치 및 회전 목표 ← 선택적으로 학습한 작은 보정
                 ↓
위치와 회전 오차를 교정하는 관절 제어
                 ↓
관절 및 추종 한계 검사 → 현재 물리의 관절 목표와 토크 적용
                 ↓
실제 위치와 방향 및 속도와 접촉 재측정
```

처음에는 정책 보정을 0으로 두고 이 경로만 검사한다. 기본 제어가 충분하면 그 결과를 기준으로 채택하고 정책 추가의 필요성을 다시 판단한다. 정책 학습은 마찰·접촉·모델 오차 때문에 기준 제어의 성공률이 제한될 때 진행한다.

현재 33관절 정책은 비교 기준으로 보존한다. 최초 진단은 별도 runner와 제어 모드로 만든다. 6차원 정책을 현재 33차원 출력에 조용히 끼워 넣거나 남는 축을 의미 없이 학습하지 않는다. 학습 구조를 채택할 때 REACH 전용 정책과 계약을 분리한다.

이 역할 분리는 기본 피드백 제어와 학습 보정을 결합하는 [Residual Reinforcement Learning for Robot Control](https://arxiv.org/abs/1812.03201)의 접근과 관련된다. 해당 연구가 이 환경에서의 성공을 보장하는 것은 아니다.

## 목표 자세와 경로

최종 목표는 지금 사용하는 넥 충돌 형상 아래 1cm의 제어점, 손바닥 법선의 기타 +z 정렬, 손의 길이 방향의 기타 +y 정렬이다. 위치 제어점과 회전 제어 프레임은 같은 손바닥 강체에 붙어 있으며 정의를 계약에 저장한다. 보상·관측·기하 검사·성공 판정은 같은 방향을 사용한다.

준비점은 현재 최종점에서 아래로 5cm 떨어진 후보로 시작한다. 이 수치는 샘플 형상 검사에서 가능한 후보이며 물리 경로가 검증된 값은 아니다. 필요하면 더 멀리 물러나는 점과 옆으로 이동하는 점을 후보로 검사한다. 특정 준비점을 고정한 채 모든 초기 팔 자세에서 접근할 수 있다고 가정하지 않는다.

경로에는 실제 WAIT 종료 상태에서 준비점까지의 이동도 포함한다. 손·손목·전완과 기타의 교차, 팔과 몸의 자기 충돌, 관절 여유, 스트랩 조건을 함께 검사한다. 준비점에서 최종점까지의 기하상 샘플 경로만으로 전체 접근 가능성을 판정하지 않는다.

가능한 목표 관절 자세를 여러 후보에서 찾고, 관절 한계에 여유가 남는 후보를 선택한다. 팔꿈치나 손목을 한계로 몰아넣는 최단 거리 경로보다 이후 방향 교정이 가능한 자세를 선호한다. 여유의 수치 기준은 진단에서 정하고 계약에 기록한다.

목표 위치와 회전은 매 제어 시점의 실제 기타 자세를 따라 변환한다. 목표 속도에는 기타 선속도, 기타 회전에 따른 목표점 속도, 접근 경로의 진행 속도가 모두 들어간다. 기타의 초기 위치를 기준으로 만든 정적인 세계 좌표 목표를 계속 추종하지 않는다.

## 위치와 회전을 관절 움직임으로 연결하는 제어

첫 후보는 감쇠 최소제곱 방식의 미분 역기구학이다. 실제 손의 위치 및 회전 오차에서 원하는 손 선속도와 각속도를 구하고, 관절의 작은 움직임이 손을 어떻게 움직이는지 나타내는 Jacobian으로 9개 팔 관절의 명령을 계산한다. [robosuite 공식 문서](https://robosuite.ai/docs/simulation/controller.html)는 미분 역기구학으로 생성한 관절 목표를 관절 위치 제어에 연결하는 구성을 설명한다.

프로젝트의 Isaac Gym 예제 `isaacgym/python/examples/franka_cube_ik_osc.py`에도 Jacobian 취득과 감쇠 역기구학 계산이 있다. 이는 구현 참고이며, Franka의 관절 순서나 제어 이득을 현재 humanoid에 그대로 적용하지 않는다.

첫 구현에서 확인할 항목은 다음과 같다.

- 실제 제어점은 손바닥 원점에서 떨어져 있다. 원점의 선속도 Jacobian에 회전으로 생기는 제어점 이동을 반영한다.
- humanoid의 관절 이름과 실제 simulator의 Jacobian 열을 대조한다. 여러 회전축을 가진 관절의 좌표 규약은 실제 작은 움직임과의 비교로 검증한다.
- 회전은 회전 행렬이나 quaternion에서 계산한 회전 오차로 교정한다. Euler 각을 직접 빼지 않는다.
- 관절 속도, 다음 목표의 관절 한계 여유, 실제 관절에 비해 목표가 앞서는 양을 제한한다. 제한 후 실제 손의 추종 오차가 줄어드는지 측정한다.
- 관절 여유를 회복하는 자세 보정을 작은 값으로 사용한다. 감쇠된 역기구학에서 이 보정이 손의 목표 추종을 방해하는 정도도 검사한다.
- 목표가 추종되지 않으면 경로 진행을 멈춘다. 계속 명령을 누적해 접촉으로 오차를 줄이는 동작을 허용하지 않는다.

기존 관절 위치 이득·토크 한계·PhysX의 암묵적 감쇠는 초기 기준으로 유지한다. 역기구학 계산의 감쇠는 수치적 역행렬을 안정화하는 값이며 새로운 물리 감쇠 토크가 아니다. 매 시점 목표를 실제 관절각으로 무조건 덮어써 기존 유지 토크를 없애지 않는다. 목표 상태의 보존과 누적 억제를 함께 정의하고, 0명령에서도 중력 아래 자세를 유지하는지 검사한다.

관절 제한만으로 충돌 방지가 보장되지 않는다. 손의 실제 추종 오차와 전체 충돌 형상, 접촉력, 스트랩 상태를 별도로 검사한다. 초기에는 복잡한 전신 최적화 제어기를 추가하지 않고 이 계산과 제한 및 실패 기록으로 원인을 분리한다.

## 실제 손의 상태로 진행하는 과정

| 과정 | 수행할 동작 | 다음 과정으로 넘어갈 조건 |
|---|---|---|
| 준비점 이동 | 넥과 거리를 유지하며 관절 여유가 있는 경로를 따라간다 | 실제 준비점 오차가 줄고 충돌·스트랩 조건이 안전함 |
| 정렬 | 준비점에 머물며 손바닥 법선과 손의 길이 방향을 맞춘다 | 준비점 위치·두 방향·상대 속도 조건을 8step 유지 |
| 접근 | 정렬된 자세를 유지하며 최종 목표 쪽으로 진행한다 | 현재 활성 목표의 위치·방향·속도 추종이 확인될 때만 진행률 증가 |
| 유지 | 움직이는 기타의 최종 목표를 추종하고 정지 상태를 유지한다 | 원래 여섯 최종 조건을 8step 유지해 GRIP에 인계 |
| 복귀 | 접근 진행을 중단하고 확인된 준비 경로를 따라 실제 손을 물린다 | 실제 간격·방향·접촉·관절 여유가 회복됨 |

정렬과 접근의 방향 전진 기준 20도, 정지 구간 20~30도, 복귀 기준 30도는 현재 값으로 시작한다. 접근 진행은 방향만으로 결정하지 않는다. 실제 활성 목표의 위치 오차와 상대 속도가 허용 범위를 벗어나면 목표가 손보다 앞서가지 않도록 정지한다. 준비점 및 중간 추종의 수치 기준은 최종 기준과 구분해 진단에서 확정한다.

작은 일시적 오차는 접근 정지로 처리한다. 지속되는 오차, 반복되는 관절 한계 작동, 잘못된 면의 접촉은 복귀 후보로 처리한다. 복귀는 목표 좌표를 바꾼 시점에 성공으로 판단하지 않고 실제 손이 물러나는지 확인한다. 복귀 경로에서도 안전 위반이 발생하면 기존 안전 종료를 적용한다.

현재 REACH의 300step 제한은 초기 비교 실험에서 유지한다. 접근 지연이나 복귀를 자주 사용해 시간이 부족하다면 필요한 단계별 시간을 측정한 뒤 제한 변경을 별도 실험으로 비교한다. 시간 제한 변경만으로 성공률이 좋아진 결과를 제어 개선으로 섞지 않는다.

## 접촉과 GRIP 인계

REACH는 손바닥이 넥을 세게 누르는 것을 목표로 하지 않는다. 손 전체의 관통과 잘못된 접촉을 확인하면서 외부 목표에 정렬해 도달한다. 접촉력은 손과 기타의 실제 pair에서 측정하고, 순간 최대값과 지속 시간 및 상대 속도를 함께 본다.

힘의 허용 범위는 숫자를 임의로 정하지 않는다. 정상 무접촉 실행의 잡음과 제어기로 성공한 접근에서 관찰한 접촉을 기준으로 정한다. 과도한 힘이 지속되면 접근을 멈추고 필요하면 물린다. 성공 판정을 위한 원래 위치·간격·방향·속도 기준과 기존 안전 한계는 유지한다.

GRIP 인계 시 팔의 목표와 스트랩의 시간을 보존한다. 팔은 기타의 목표 프레임을 계속 추종하고 손가락 제어가 연결된다. 팔의 유지와 손가락 닫기는 서로 다른 책임을 갖는다. 같은 시점에 두 제어기가 같은 팔 관절 목표를 쓰지 않는다.

현재 GRIP 정책의 33관절 출력에는 팔도 포함되므로 그대로 병렬 실행하면 제어권이 충돌한다. 우선 팔 유지와 0 손가락 명령으로 인계 연속성을 진단한다. 실제 그립 학습 단계에서는 손가락 출력과 팔 출력의 소유권 및 새 정책 계약을 명시하고 재검증한다. 기존 checkpoint의 성공을 새 팔 제어에서도 보장한다고 간주하지 않는다.

## 실제 물리 동작에서 만드는 학습 시작 상태

첫 curriculum은 원래 reset에서 WAIT와 제어기의 안전한 접근 동작을 실제 물리로 실행한 뒤 학습을 시작한다. 가까운 시작 상태를 구성하는 데 사용한 이 앞부분의 동작을 prefix라고 부른다. 앞부분을 재생하면 기타 위치와 회전·속도, 전체 관절, 스트랩 경과 시간과 접촉이 함께 이어진다.

기본 제어의 성공 경로에서 학습 시작 시점을 여러 개 수집한다. 최종 목표 근처의 유지 직전부터 시작하고, 이후 시작 시점을 준비점과 먼 접근 구간으로 이동한다. 후보는 실제 거리·방향·속도·접촉·관절 여유·스트랩 조건을 만족하는 시점만 사용한다. 실제 근접 상태를 아직 만들지 못했다면 임의의 IK 관절각을 조합해 대체하지 않는다.

초기 구현은 매 episode에서 prefix를 다시 실행한다. seed와 설정과 action 경로를 저장하되 재생 후 실제 상태를 검사한다. PhysX 실행을 비트 단위로 재현한다고 가정하지 않는다. 상태가 후보 허용 범위를 벗어나면 폐기하고 실패 원인을 기록한다.

prefix는 정책의 PPO 샘플과 학습 episode의 보상 집계에서 제외한다. 첫 학습 샘플은 동기화된 실제 관측에서 시작한다. 학습 구간의 GAE는 prefix로 연결하지 않는다. prefix에서 성공 판정이 이미 끝난 후보는 학습 시작 후보로 쓰지 않는다.

스트랩의 물리 경과 시간은 계속 이어가고, curriculum의 학습 구간 시간과 보상은 별도로 시작한다. 가까운 자세에서 스트랩 기준 길이를 새로 보정하지 않는다. 최종 비교 평가는 항상 원래 reset의 WAIT부터 시작하고 prefix 시간도 전체 도달 시간에 포함한다.

prefix 실행 비용이 병목임이 확인된 뒤에만 snapshot 복원을 추가한다. 같은 제어 경계에서 전체 관절 위치·속도, 모든 actor root 자세·선속도·각속도, PD 목표, 과제 목표, 원래 스트랩 기준 길이와 물리 경과 시간, 단계와 진행률 및 카운터를 저장한다. 기존 reset은 속도와 스트랩 시간을 0으로 만들므로 그대로 사용하지 않는다.

PhysX의 접촉 캐시와 solver 내부 상태는 완전히 복원하지 못할 수 있다. 복원 후 물리 동기화와 짧은 안정화 구간을 거치고 실제 상태를 재검사한다. 접촉·속도·목표 오차가 바뀐 후보는 채택하지 않는다. 환경 원점, actor 및 관절 순서, 부분 복원의 독립성도 검증한다. snapshot 복원과 prefix 재생의 결과를 같은 것으로 취급하지 않는다.

## 정책의 역할과 보상

제어기만의 기준 실험이 통과하고 학습 필요성이 확인되면 REACH 정책은 기타 좌표계의 위치 보정 3개와 회전 보정 3개를 출력한다. 보정은 기본 목표 주변의 제한된 값으로 정의하고 계속 누적하지 않는다. 크기와 변화 속도를 제한하고 회전 보정은 회전의 합성으로 적용한다.

정책이 보정한 목표에 도착해도 원래 목표를 벗어났다면 성공이 아니다. 성공과 최종 평가 오차는 원래 기타 목표를 사용한다. 보정 크기, 실제 적용된 보정, 포화 및 제한 작동을 로그와 관측에 넣는다.

보상은 위치 오차, 두 방향 오차, 상대 속도, 허용 범위를 넘은 접촉, 불필요한 보정과 한계 체류를 구분한다. 방향 오차가 거리 점수에 곱해져 멀리서 거의 사라지는 구조는 첫 후보에서 사용하지 않는다. 큰 힘을 무조건 벌점으로 만들어 필요한 GRIP 접촉까지 피하게 하지 않고 단계별 허용 접촉을 구분한다. 보상 가중치는 정규화된 각 항목의 실제 분포를 확인한 뒤 정한다.

원래 여섯 조건을 8step 유지하는 완료 판정과 안전 실패는 계속 분리한다. 준비점의 성공, 일시적 최소 거리, 제한이 많이 작동한 상태를 최종 성공으로 대체하지 않는다.

관측에는 최종 목표 오차와 활성 목표 오차, 실제 상대 속도, 과정·진행률·카운터, 팔의 관절 위치와 속도 및 목표와 여유, 접촉, 이전 적용 보정과 제어기의 포화 상태를 명시한다. 제어기의 진행·복귀·필터 등이 이전 상태에 의존하면 그 이력도 policy가 볼 수 있게 한다. 관측 차원은 구현 시 필드 목록에서 계산하고 검사하며 현재 185차원과 조용히 혼용하지 않는다.

## 기존 정책을 활용할 범위

기존 정책은 비교 실험과 실패 자세의 수집에 활용한다. 성공하지 못한 방향 동작까지 새 제어의 교사로 채택하지 않는다. 필요한 경우 기존 접근 경로에서 실제 제어기가 자세를 회복할 수 있는지 검사한다.

33관절 정책을 유지해야 할 별도 요구가 생기면 검증된 제어 경로의 관절 명령을 모방한 뒤 RL로 적응시키는 안을 비교한다. 이 방식은 출력 계약을 유지하기 쉽지만 관절 한계·접촉에 대한 교정 동작을 다시 잃을 수 있다. 현재의 첫 선택은 기본 제어를 유지하는 작은 보정 정책이다.

6차원 정책에는 33차원 actor의 출력층을 그대로 복사하지 않는다. 기존 177차원 정책을 185차원으로 옮기는 것도 이름과 순서 및 정규화와 출력 의미가 일치하는지 확인한 명시적 변환 실험으로만 수행한다. 새 보상·action·초기화 계약의 critic과 optimizer는 기존 상태를 자동 재개하지 않는다.

## 구현 순서와 진행 기준

| 단계 | 구현할 범위 | 다음 단계로 진행할 증거 |
|---|---|---|
| 1 | 실제 WAIT 종료 상태의 도달 가능성, 관절 여유, 손 제어점 Jacobian 검증 | 물리 관절 좌표에 맞는 계산과 충돌 없는 자세·전체 접근 후보 확인 |
| 2 | 정책 0보정의 제어 runner, 실제 추종을 확인하는 접근 및 복귀 | 원래 자유 기타·중력·스트랩 조건에서 위치·방향·속도를 함께 만족한 실제 도달 사례 |
| 3 | 고정 seed 및 noisy 원래 WAIT 평가, 제어 ablation | 성공·실패가 재현되고 실패 원인이 분리됨; 접촉과 한계 체류가 허용 범위에 있음 |
| 4 | 성공 경로의 prefix 생성과 재생 검사 | 학습 시작 시점의 실제 근접·방향·속도·스트랩 조건이 충족됨 |
| 5 | 필요 시 REACH 전용 6차원 보정 정책 | 같은 제어기·평가에서 0보정 기준보다 성공률과 안전성이 개선됨 |
| 6 | 원래 WAIT부터의 전체 접근 및 GRIP 제어권 인계 | 인계 순간 목표·토크 급변 없이 기존 최종 조건과 그립 평가를 통과함 |

처음 성공 사례 하나는 가능성의 증거다. 개선 모델 채택에는 고정된 noisy 평가와 여러 학습 seed를 사용한다. 평가 환경 수·학습 샘플 수·prefix 사용 여부·episode 시간 제한·접촉 기준을 함께 기록한다. 2update smoke나 30update의 한 seed 결과로 구조의 우열을 결정하지 않는다.

학습 순서는 유지 근처 → 정렬된 준비점에서 접근 → 준비점에서 방향 교정 → 원래 WAIT 이후 전체 접근이다. 초기에 먼 거리 이동과 회전 및 접촉 대응을 한 정책에 동시에 요구하지 않는다. curriculum의 시작 시점을 앞당길 때 이전에 학습한 가까운 시작 상태도 함께 유지한다.

제어 비교는 목표 속도 보상 유무와 활성 목표 추종 확인 유무를 각각 구분한다. 목표 누적 제한은 제어기 기준에서 다시 검사하고 이전 실패 결과를 자동으로 뒤집어 채택하지 않는다. 기타 움직임은 동일한 물리 설정의 무접촉 기준과 비교하며 차이를 손의 순수한 인과 효과로 표현하지 않는다.

## 후속 보완 작업 — 2026-10-03

사용자가 다음 해결 대상의 보완·수정을 승인했다. 기존 물리와 성공 기준을 유지하며 작은 진단 묶음을 비교한다.

### 후속 진단에서 추가 확인한 항목

- 상위 Torso/Spine/Chest 운동을 포함하면 FK와 실제 손이 일치했다. 고정 PD 목표를 물리적 몸통 고정으로 가정할 수 없다.
- 오른손·몸통·골반·의자와 기타 접촉도 집계하고 스트랩 force의 정확한 입력 상태를 보관한다.
- 엔진 Jacobian은 실제 관절 속도의 좌표에서는 유효했고, 회전 좌표의 미분과는 다르다. 구면 관절의 복원 오차를 실제 body-local 회전 차이로 계산하는 비교를 추가하되, 물리 실패 때문에 기본 비활성으로 둔다.
- 관절 여유와 목표 오차 제한이 양립하지 않는 행은 진단 실패로 기록해 종료하고 다른 환경은 계속 검증한다. 일반 물리 안전 종료와 별도로 기록한다.

보완 결과: [구현·비교 기록](../2026-10-12/회의/results/reach_feedback_improvement_20261003/improvement_report.md).

## 단계별 추가 검증 — 관절 목표 가속도 제한

사용자는 한 번에 여러 개선을 적용하지 말고 중요 항목 하나를 구현·실험·검증한 뒤 부족하면 추가하도록 지시했다. 첫 항목은 관절 목표 가속도 제한이다.

1. 관절 목표 속도 이력을 두고 BVLS의 속도 범위를 가속도 범위와 교차한다 → 검증: 실제 적용 목표의 속도 변화가 상한을 지킴, 기존 관절·목표 오차·속도 제한 보존, 부분 reset 이력 독립성.
2. 동일한 원래 WAIT 및 설정에서 가속도 제한만 끈/켠 실행을 비교한다 → 검증: 토크 초기 포화 시점·몸통/스트랩 변위·접촉·원래 목표 조건·제약 실패를 함께 비교한다.
3. 고정 실행에서 효과가 있으면 같은 잡음 환경으로 확인한다. 효과가 부족하거나 제약을 양립시킬 수 없으면 실패 원인을 먼저 기록하고 그 근거로 다음 항목 하나를 정한다.

- [x] 가속도 제한 및 이력·경계 검사
- [x] 한 항목만 바꾼 물리 비교. 단독 제한의 추종 범위 충돌을 확인한 뒤에만 사전 감속 추가.
- [x] 독립 검수와 채택/보류 판단. 157개 검사 통과, 잡음 4환경 확인. 실험 후보로 보존하며 기본 비활성.

관절 목표를 강제로 투영한 점프를 가속도 제한 준수로 기록하지 않는다. 가속도와 안전 범위가 양립하지 않는 행은 명시적 진단 실패로 종료한다. 상체 운동 보상·회전 PD·추가 감속·상체 부하 보상은 이번 첫 비교에서 켜지 않는다.

첫 가속도 제한(1rad/s²) 실행은 196step에 실제 관절 추종 범위와 가속도 범위가 충돌해 종료됐다. 정적 관절 범위에 닿아서가 아니라 팔 목표가 실제 관절보다 앞서간 결과다. 이 실험 뒤에만 두 번째 보완으로 현재 관절/추종 허용 범위까지의 거리와 제동거리로 속도를 미리 낮추는 계산을 추가해 비교한다. 상체 보상·강성·토크 상한·성공 기준은 바꾸지 않는다.
