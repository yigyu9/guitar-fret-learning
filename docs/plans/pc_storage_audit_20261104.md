# PC 전체 저장 공간 점검 — 2026-11-04

사용자 요청: PC 전체 디렉터리를 점검해 추가 확보 가능한 용량을 확인한다. 이번 작업은 읽기 전용 점검이며 삭제·이동·패키지 제거는 수행하지 않는다.

## 계획과 검증

- [x] 파일시스템별 사용량과 주요 디렉터리를 조사한다. 서로 다른 디스크의 용량을 구분하고 접근 불가 범위를 기록한다.
- [x] 시스템 캐시·로그·임시파일, 개발 환경, 사용자 파일을 병렬로 점검한다. 심볼릭 링크 대상과 가상 파일시스템은 따라가지 않는다.
- [x] 후보별 실제 할당 용량, 재생성 가능성, 사용 여부와 기존 보존 요청을 확인한다. 하드링크와 중첩 경로를 중복 합산하지 않는다.
- [x] 근거와 정리 우선순위를 보고서로 작성하고 별도 검수를 받는다.

## 보존 기준

기존 보존 요청 자료, 실행 중 학습·모델·원본, 현재 사용 환경 및 Git/LFS는 자동 삭제 후보로 확정하지 않는다. 이전 점검에서 LFS 원격 누락 37개가 확인되었으므로 전체 LFS 캐시는 조건부 항목으로만 다룬다. 설치 환경은 디렉터리 크기와 실제 제거 시 확보량이 다를 수 있다.

## 완료 결과

[보고서](../maintenance/pc_storage_audit_20261104/REPORT.md)에 우선 후보9.03GiB, 서비스 로그·Docker를 포함한 조건부 상한11.66GiB를 기록했다. 개발 환경·Snap·개인 중복 영상·LFS는 별도 조건부 항목이다. 관리자 전용 경로의 접근 제한, 별도 데이터 디스크 EIO와 프로젝트 외부 데이터 연결 오류를 명시했다. 파일 삭제·이동과 시스템 변경은 수행하지 않았다.
