## 의자 초기 배치의 별도 교정 비교

왼 Hip만 ±0.03rad 조정한 source v3는 의자 간격1mm를 확보하지 못했다. 경계 후보는 허벅지–기타 source 간격을 최대8.221mm 바꾸어 미채택했다. 원래 각도와 지지 조건을 더 보존하기 위해, 다음 비교에서는 오른발 교정 v2의 인간·기타 상태를 그대로 두고 **의자의 초기 world-Y 위치만 −2.5mm** 이동한다. 이는 새 장면 조건이며 원래 의자를 쓴 결과와 구별한다. 숨은 geometry 수정이나 매 step 위치 덮어쓰기를 하지 않는다.

물리 담당자의 근거: 원 native L_Hip–chair 초기 겹침 약0.245mm, 접촉 법선은 주로 −Y 방향이고 접촉 여유 거리 합은 약2.1mm다. −2.5mm 이동은 source 형상에서 모든 의자–신체 쌍을 재검사하며, 부족하면 새 leaf에 명시한 −3mm 후보까지 검사한다. 실제 native에서 의자 접촉과 왼 하체 초기 속도·Jacobian 잔차가 함께 줄어드는지 확인한다. 의자 이동 없이 전신 안정성을 얻었다고 설명하지 않는다.

의자 source 검사는 모든 신체 쌍을 보고하되, 2.2mm 간격 판정은 **움직이는 신체 링크와 기타**에 적용한다. 고정 Pelvis와 고정 의자의 기존 source 겹침은 별도로 기록한다. 해당 고정 쌍을 숨기거나 장면 전체에 교차가 없다고 주장하지 않는다. 이 단계는 하체 동역학에 영향을 주는 초기 충격을 분리하는 비교다.

## 하체 유한 제어 방식 조정

의자 −2.5mm 조건에서 처음6step의 의자 접촉은 사라졌지만, 원래 native 위치 제어의 K/D를 외부 EFFORT PD에 그대로 사용한 하체에서 교번 증폭이 나타났다. R_Ankle_z 속도는 약3e−6→−3.45e−5→0.000544→0.0992→−1.2495→12.7539rad/s였고, 6step(0.025초)에서 검증 기준으로 중단했다. 초기 겹침 교정과 수치적 제어 안정성은 별도 문제로 기록한다.

최소 변경 비교는 하체24의 원 native 유한 위치 제어를 사용한다. 전체는 **72 POSITION + 33 EFFORT**, 하나의105관절 목표 API를 유지한다. 하체에 외부 중력보상·PD 명령을 중복 제출하지 않으며, native K/D와 effort 제한을 기록한다. 이는 관절 고정이 아니다. 새 leaf/코드/설정에서 같은 초기 자세와 의자 조건으로 정지5초와 왼손해제15초를 확인한다.

Native POSITION 원 gain 비교는55step(0.22917초)에 왼발목 Jacobian 진단 기준으로 멈췄다. 이때 BB 이동19.13mm, 하체 최대 관절각 변화0.2863rad였으므로 안정 자세로 채택하지 않는다. 하체 위치 모터는 외부 Jacobian을 제어에 쓰지 않고, 하체 Jacobian의 상체33개 EFFORT 열도0이다. 따라서 후속 버전에서는 제어에 사용하는 상체 Jacobian의 기존0.01m/s 검증을 유지하고, 하체 Jacobian 잔차는 모든 표본의 별도 진단으로 보존한다. 관절 속도·기타 이탈 안전 종료는 유지한다.

먼저 같은 원 gain으로5초 관찰하고 필요시 하체 native K×10, D×√10을 별도 조건으로 비교한다. 초기 자세·의자·상체 제어와 native effort 제한은 동일하다. 원 gain과 강한 유한 유지 조건의 결과를 섞지 않는다. 새 조건의 적합성은 실제5초 정지와15초 왼손해제 관측으로 판정하며, 안정성의 일반적 증명으로 확대하지 않는다.
