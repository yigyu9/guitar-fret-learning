# 기존 정책을 사용하지 않는 자유 기타 새 학습

2026-10-14 사용자 승인: 기존 정책을 폐기하고 새로 학습한다. 기존 파일의 삭제가 아니라 새 학습에서 Fret·Strike·기존 잔차 가중치를 사용하지 않는 것으로 적용한다. 과거 체크포인트와 결과는 비교·재현용으로 보존한다.

## 첫 실행 범위

현재 삼면 왼손 초기 배치의 자산·물리를 이용한다. 루트·하체 고정, 신체 내부 충돌 활성, 스트랩 OFF, 기타 자유 상태를 유지한다. 기타에 직접 힘을 가하거나 매 시각 위치를 덮어쓰지 않는다.

새 단일 Actor는 공유 관측으로부터 support15 / fret33 / strike6의 54개 관절 목표를 출력한다. 나머지27개는 준비 목표로 유지한다. 기존 정책의 nominal을 읽지 않는다. 물리 환경과 수동 신체 지지 제어의 재사용은 기록하고, 그 기반 위에서 실제 학습 행동이 적용되는지 검증한다.

첫 단계 A는 지지 상태에서의 작은 손 이동을 학습한다. 이는 압현·음악 성공이 아닌 준비 과제다. 실제 음악 과제는 이후 B 한 음 압현·유지·해제, C 공동 타현, D 전환, E 구절 순서로 진행한다. Stage A를 전체 연주 학습 완료로 표시하지 않는다.

보상과 악기 이탈 비용을 별도 Critic으로 추정하고, 공동 Actor를 PPO로 갱신한다. 첫 실행은 비용 계수1.0의 고정 패널티이며 비용 한도를 보장하는 알고리즘이 아니다. 비용 산정 기준과 관절 목표 범위는 실행 config·소스에 명시한다. 학습 seed와 평가 목표는 분리한다.

## 초기 조사

기존 parallel trainer는 과거 체크포인트와81D 행동에 의존한다. 현재 자세 viewer의 타현 경로도 입력 행동을 고정 준비값과 정해진 타현으로 바꾸므로 그대로 학습 환경으로 사용할 수 없다. 별도 명령 경로를 구현한다. 기본 샌드박스에서는 GPU가 보이지 않았으나 호스트 검사에서 RTX4070Ti(12GB)를 확인했다. 실제 native·CUDA 실행은 GPU 접근이 가능한 실행 환경에서 수행한다.

## 실행 진행

baseline_v1은 초기 물성의 비교 참조 오류로0스텝에서 중단했다. 실행 전 소스 사본과 실패 기록을 보존했다. 환경v2는 기존 OM 형상의 COM·관성을 유지하고 질량비로 관성을 조정한 요청값과 실제 readback을 대조한다. 기준 형상/물성 자체를 바꾸지 않았다.

baseline_v2는5초/300제어 스텝을 완료했고 기타 최대 actor-root 변위15.20mm·회전4.408°였다. smoke_v2는 기존 가중치 없이512스텝·2갱신을 완료했으며 가중치 변화와 저장을 확인했다. smoke_eval_v2는 별도 seed9001에서 저장 정책으로5초를 완료하고 native 전신·손 영상을 저장했다. 모든 완료 실행에서 금지 API 호출0·봉인 입력 변경0이었다. 독립 검수에서 긴 파일럿을 막는 결함은 발견하지 못했다.

pilot64_v3는 seed101·256스텝×64갱신으로 실행한다. v3는 환경v2를 유지하며 초기 native 물성/PD와 에피소드별 목표 기록을 보완한 runner다. 목표 위치는 t0 기준이므로 준비 후 약20mm의 정착 드리프트 회복을 포함한다. 비용0 결과나 손 위치 보상 개선을 음악 수행·안정성 제약 학습의 성공으로 확대하지 않는다.

2026-10-15 계속: pilot64_v3과v4는 각각23갱신에서 속도/Jacobian 검증의 잔차가 한도를 넘어 중단했다. 정확한 재생으로 시점 차이와 접촉 연관 잔차를 확인했으나 solver 내부 원인은 확정하지 않았다. v4의 시점 보정만으로는 충분하지 않았다. 새 환경v5는 요청 목표로20%씩 이동하는 조건으로 제어 변화 속도를 낮춘다. 기존 검사 한도·보상·비용을 유지하고 검증 오류를 PPO 전이로 넣지 않는다. 이전 실패 명령을 포함한4개 전체5초 native 실행을 통과한 뒤 pilot64_v5를 seed101로 처음부터 시작했다. 오류 시 동작·가중치·Adam·RNG·부분 진행량을 보존하고, 정상 저장 체크포인트와 오류 보존 체크포인트를 구분한다.

2026-10-15 후속: v5도27갱신에서 중단했다. 별도5초 평가에서 palm RMS가 기준20.438mm에서10.566mm로 감소했으나 한 목표의 결과다. 물리 검사 한도를 바꾸지 않고 별도 recovery64_v1에서 새 정책의27갱신을 이어 최대64갱신까지 수집한다. typed env.step 검증 오류가 난 미갱신 rollout 전체를 제외하고 보존·검사 후 새 seed로 재시작한다. 기존1회를 포함해 총8회 오류, 새 제어 시도11264개가 상한이다. 선택 편향을 명시하고 평가 오류는 재시도하지 않는다. 독립 검수 후 실행한다.

완료: recovery64_v1은37회 추가 갱신으로 누적64회, 총16384개 학습 전이를 확보했다. 최초·후속 검증 오류4구간의367개 전이는 제외·보존했다. 최종 seed9002 평가를 단회5초 완료했고 palm RMS20.438→6.772mm였다. Stage A의 첫 유한 파일럿 완료이며 실제 연주 학습은 다음 단계다.
