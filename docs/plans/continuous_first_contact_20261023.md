# 최초 압현의 연속 접촉 조건

사용자가 권장 개선 구현을 승인했다. 우선 권장한 GPU 왼손의 연속50ms 조건만 적용한다. 보상량0.5·하중/패드 기준·타이밍 창·누적clean 달성·물리/제어/PPO·CPU/오른손은 유지한다. 후반 타이밍 차등은 이번 범위에 포함하지 않는다. 새 장기 학습을 실행하지 않는다.

- [x] 변경 전 v10 코드·검사·관련 문서461개를 보관하고 SHA를 확인했다. 이전v10 보고서533개 파일도 그대로다.
- [x] 연속 contact_streak·단절초기화·최초1회·짧은양수창min을 적용하고 누적 contact_time 진단을 보존했다. 관측506·원장v4·보상v11로 의미를 구분하고v10재개를 거부한다. 길이0 압현창은 GPU왼손초기화에서거부한다.
- [x] 관련22모듈215개 CPU검사(새13개)와 독립61개검사·640표본 스칼라적분대조를 통과했다. 문서·검증결과를 갱신했으며 native/GPU학습은실행하지않았다.

완료 기준: 여러 번의 짧은 접촉 합계가50ms를 넘어도 보너스를 지급하지 않고, 한 번의 연속 유효 접촉이 문턱에 도달하면 원래 크기의 보너스를 한 번 지급한다. 실행 범위는 코드와 검사이며 학습 성능을 주장하지 않는다.
