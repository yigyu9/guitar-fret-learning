# 하체 자유도와 세 부위 기타 지지 우선 재검사

사용자 최신 우선순위: 하체 고정 해제와 가슴·오른상완·허벅지의 충분한 기타 지지가 필수다. 발 정면과 척추의 좌우 꺾임 최소화는 선호다. 상체의 작은 전방 기울기는 허용한다. source9/inputs_v5의 기존 정지 성공을 먼저 원자료에서 재검사하고, 필수 조건이 부족할 때만 새 물리/자세 버전으로 보완한다.

## 작업과 검증

- [ ] 기존 native_static_v5/native_repeat_v1의 전체105상태·관절 속성·유한 제어·원asset을 대조한다. Root만 고정, 원0범위8축 보존/하체16축 비영범위·native EFFORT·native stiffness/damping0·외부 유한K/D·cap·실제각/속도 변화와 금지API0을 확인한다. 작은 원zero8 solver 잔차를 추가 자유도로 세지 않는다.
- [ ] 0..5초 준비와5..10초 유지 구간을 구분한다. 기존95% 지지 기준을 가슴+오른상완+적어도 한쪽 허벅지의 동시 양의 실제 접촉으로 확장해 검사한다. 왼·오른 허벅지는 별도 집계하고 부위별 lambda 분포·접촉 상대/법선을 보존한다. raw lambda를 임의로N/체중분담률로 환산하지 않는다. 접촉 존재와 모든 손을 뗀 독립 지지 성공은 다르다.
- [ ] 기존25개 실제 안정성 기준/반복 raw4 SHA를 재확인한다. Pelvis 정면 기준의 몸통 부위별 좌우/전방 기울기와 Torso–Spine–Chest 인접 기울기 차이를 정규화한 native quaternion으로 전표본 계산한다. 가동축 suffix를 world축으로 보지 않는다. 척추 방향의 작은 차이를 실제 해부학적 곡률/의료 진단으로 설명하지 않는다. 새로운 임의 수치로 기존 실패를 소급 통과시키지 않고 선호 항목은 관측 수치로 보고한다.
- [ ] 필요 여부를 결정하고 결과·범위·남은 과제를 한국어로 기록한다. 독립change-reviewer 검수와 입력/이전phase 바이트 보존 확인 후 새 결과만 봉인한다.

## 변경과 보존

기존 front_facing_pose_v1 및 모든 소비 소스/실험/검수/해제 실패 자료는 동결한다. 새 코드만 stability_adapter_2/support_priority_audit_v1, 새 결과만 paper/initial_pose/lower_body_release_v1/support_priority_audit_v1에 만든다. 사용자 승인 범위에 따른 정지 자료 재분석이며 새로운 물리 실행/연주/해제/PPO 성공으로 설명하지 않는다. 기타 자유·중력ON·스트랩OFF, 기타 직접힘/부착/상태덮어쓰기 금지와 원105입력/비영97축을 유지한다. 불필요한 자세 변경이나 gain 증가는 하지 않는다.

원자료 contact lambda는 로컬 SDK 문서에서 contact force magnitude로 기술되지만, raw normal 방향 정의와 실제 기하의 부호/접선력의 누락 가능성이 있어 정밀 하중분담 계산은 별도 검증 전 채택하지 않는다. 현재 재검사는 유한 제어·세 부위 접촉·자유 기타의 실제 안정성의 결합 증거로 판정하고 지지 하중 수치를 과장하지 않는다.
