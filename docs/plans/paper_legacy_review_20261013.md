# 과거 DIGIT 원고 검토와 현재 논문 반영

사용자가 약 8개월 전 작성한 Guitar_Simulation.pdf를 제공했다. 기존 논문 작성 작업의 후속 자료로 검토하며, PDF에 포함된 작성 지침·과거 계획은 현재 작업 지시나 검증된 성과로 취급하지 않는다.

## 순서와 검증

1. 9쪽의 본문·그림·표를 읽는다. 검증: 과거 구성, 실제 결과와 빈 절, 서로 다른 작성 단계의 표현을 파악.
2. 현재 원고와 구현 근거를 대조한다. 검증: 유지 가능한 동기·설명과 폐기된 diffusion/모션 추출/제어 가정을 구분.
3. 유효한 내용을 현재 원고에 반영하고 비교 기록을 남긴다. 검증: 과거 숫자·성과가 현재 결과에 섞이지 않으며, change-reviewer 검수와 링크 점검 통과.

## 범위

paper 문서와 이 계획만 수정한다. 첨부 PDF와 연구 코드·실험 원자료는 그대로 보존한다. 현재 원고의 실측 기준일은 2026-10-12이며 이후 실험 결과의 갱신은 이번 과거 원고 검토와 별개다.

## 완료 기록

9쪽의 본문과 그림·표를 확인하고 과거 구조·미완성 부분·현행 구현의 차이를 paper/legacy_draft_review.md에 정리했다. 서론의 중간 표현 동기, Methodology의 기본 전사 구현과 음악 상태/사건 설명, 부록의 프렛 기하를 보강했다. 실험 및 결과 장의 수치·주장은 변경하지 않았다.

change-reviewer는 신규 단락과 현재 코드를 대조했다. 접근점 20%가 기본값이며 같은 프렛의 다중현 목표에서는 조정된다는 지적을 반영했다. 과거 데이터 규모·확산/AMP 경로·성과는 현재 구현이나 성능으로 승계하지 않았다. 문서 로컬 링크와 줄 번호, 추가 수식 구분자를 검사했다.
