# 압현 확인 뒤 타현하는 결합 동작

압현 유지 단독 V6는14초26개 기준을 모두 통과했다. 동시 결합 V6는13초까지 실제 검지 하강이 약1.80mm여서2mm 조건을 만족하지 못했고, 목표 포착 없는 재생 경로 종료 guard로 중단했다. 접촉 존재만으로 압현 성공 처리하지 않는다. 기존 소스와 원자료는 모두 보존한다.

새 결합은 프렛을 먼저 누르고 타현하는 순서로 수행한다. 초기·gain·cap·물성·Root·하체·기타 조건은 변경하지 않고 오른손 동작의 시작 시각만 늦춘다.
