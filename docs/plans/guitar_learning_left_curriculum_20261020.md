# 왼손 전곡 보상의 성능 기반 3단계

사용자 승인: 손목 위치 잡기 → 압현 → 곡 연결의 보상 단계를 구현한다.

설계: 같은 전곡·초기 자세·물리 안전·39행동을 유지한다. 현재 초기 자세의 손목–할당 손가락 상대 벡터와 손 방향을 측정해 현재 기타 프레임의 목표 영역을 만든다. 휴리스틱 hand_position_targets의 값을 검증된 손목 정답으로 사용하지 않는다. 왼손 관측에 목표 오차와 단계 비중을 추가한다. 오른손과 기존 전문 실험 계약은 유지한다.

최근 완료 에피소드의 도달·실제 clean 접촉 성능으로 단계 비중을 점진 변경한다. 부분/실패 궤적으로 진급하지 않고 음별 문턱으로 압현 보상을 끄지 않는다. 부모에서 두 worker의 에피소드를 모으고 PPO 갱신 경계에서 같은 비중을 적용한다. 단계/최근 이력을 checkpoint buffer로 보존한다. 새 계약은 기존500상태 모델과 strict resume를 구분한다.

검증 기준: 손목 접근만으로 압현/전곡 성공을 주지 않는다. 손가락 보상을 첫 단계에서도 유지하며 유한 제어/안정 비용·안전 종료를 완화하지 않는다. 각 전이에 사용된 비중이 기록되고 수집 동안 고정되며, PPO 경계에서는 물리 reset 없이 관측/비중만 동기화한다. 과거 task3파일 원문과 기존 기록을 보존한다.

실제 단기 실행: 왼손2환경512전이/PPO2, 재개40전이/누적2→3, 오른손20전이/PPO1, 모두정상종료와원물리/입력/지속감사통과. 짧은실행이므로전곡완주/단계진급/수렴을주장하지않는다. CPU검사는비영단계이력의정확한후속복원과PPO결과를검증한다.
