# StabilityAdapter 그립 병목 수정

목표: 기존 `stability-adapter` 단일 과제에서 기타가 멈춘 뒤 왼손이 아래에서 접근하고, 엄지와 두 손가락으로 실제 넥 접촉을 형성한 다음 기타를 옮기도록 학습 신호를 연결한다. 기존 v8 체크포인트는 변경된 보상·관측 계약으로 재개하지 않는다.

- [x] v8 로그·코드와 관련 테스트 확인: 11,400회 평가의 그립 획득 0/64, 손가락 힘 0, PPO 대부분 한 번만 갱신.
- [x] 그립 실패 진단 구현: 관절 목표/실제 오차, 손가락별 거리·힘·표면 좌표와 실제 PhysX 접촉 쌍을 분리 기록한다. → GPU 호스트의 단계별 진단 파일 확인은 남았다.
- [x] 단계별 보상 구현: 접근 중 손바닥과 엄지·손가락 진전을 독립적으로 보상하고, 그립 전 위치·회전 및 오른쪽 지지 비용을 낮춘다. 실제 대향 접촉과 운반 성공 조건은 유지한다. → 관련 CPU 테스트 통과.
- [x] PPO 과도한 KL 대응 구현: actor 학습률을 낮추고 활성 축당 KL 진단을 추가했다. → 실제 반복 갱신 여부는 새 학습 로그 확인이 필요하다.
- [x] CPU 문법·관련 테스트: Stability 289개 중 267개 통과·22개 GPU 의존 건너뜀, PPO 7개 통과.
- [ ] GPU 통합 검증: 작업 컨테이너에는 NVIDIA 장치가 없어 GPU PhysX smoke/접촉 probe가 불가능하다. GPU 호스트에서 실행 후 그립·PPO 지표를 확인한다.

판정 기준: 손바닥만 닿은 힘이 그립으로 세지지 않으며, 엄지·두 손가락의 거리가 줄면 그립 전 보상이 증가한다. 접촉 쌍이 아닌 몸별 순힘은 그립 힘으로 해석하지 않는다. 기존 전체 낙하·정지·접근 시퀀스와 97축 인터페이스는 유지한다.
