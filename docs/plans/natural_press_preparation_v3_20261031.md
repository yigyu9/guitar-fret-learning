# 자연스러운 압현 준비 동작 개선 설계 v3

작성일: 2026-10-31. 상태: 독립 설계 검토 반영 완료, 구현·학습 전.

## 1. 목표와 범위

원하는 동작은 **손목 이동 중 목표 손가락도 준비 → 목표 줄 위에서 여유를 두고 정렬 → 음 시작에 맞춰 손가락으로 내려 누르기 → 음 종료 후 다음 동작 준비**다. 손목 이동이 완전히 끝날 때까지 손가락을 잠그는 직렬 제어는 사용하지 않는다.

준비가 끝난 뒤 악보 시각까지 기다리는 것은 정상이다. 개선 대상은 목표에서 멀고 손가락도 펴진 상태로 기다리다가 뒤늦게 굽히는 동작이다. 모든 관절을 반드시 움직이게 하거나 손가락 움직임에 비용을 주는 방식으로 자연스러움을 만들지 않는다.

이 문서는 다음 구현의 설계다. 현재 학습 코드, 기존 체크포인트, 봉인된 실험 runtime, 완료된 결과는 변경하지 않는다. 구현 시 새 실험 버전을 만든다.

## 2. 관측 사실과 가설

[직전 로그 분석](../2026-11-02/압현성공/experiments/structured_press_v2/runs/seven_hour_v1/alignment_pause_analysis/REPORT.md)을 기준으로 한다.

| 확인한 사실 | 설계에 주는 의미 |
|---|---|
| 중지 시작 관절 실제각이 약26°에서3°로 펴지고 중간 관절도 약58°에서33°로 펴짐. 첫 요청부터 펴는 각도임 | 물리 반동만 수정해서 해결할 현상이 아님 |
| 손가락별 추종 목표가1초에 유효해지고, 검지 요청각에 추가 펴짐 약1.71°/1.42° 발생 | 목표 입력 전환을 연속적이고 일관되게 만들 필요 |
| 일반 악보 관측은4초 선행이라 초기부터3초 시작 음을 포함함 | “목표를 전혀 몰라서”라고 설명하면 부정확. 손가락별 목표·focus와 일반 악보 사이의 시간 불일치가 문제 후보 |
| 목표 패드 접근 가중치는2.55초까지0, 실제 음은3초 시작 | 손목 이동 중 준비를 유도하는 시기가 늦음 |
| 대기 자세 MCP 허용대는 넓고 초기 MCP도 이미 범위 안 | 대기 보상이 큰 펴짐의 유일한 원인이라는 증거 없음 |
| A 학습은 정렬된 시작, 영상은 추가 학습 없이 v9 이동 시작에서 재생 | 학습·사용 초기 상태의 차이를 분리 검증해야 함 |
| 해당 팔12축 정책 요청은 고정 IK 값, free_v9에는 단계별 팔 잠금 없음 | 현재 영상은 학습된 팔 이동 정책의 증거가 아님 |

목표 입력 전환, 준비 보상의 늦은 활성화, 초기 상태 차이가 주요 가설이다. 각 가설의 기여도는 대조 실험 전에는 확정하지 않는다.

## 3. 목표를 아는 시점·준비 시점·누르는 시점을 분리

| 상태 | 제안 |
|---|---|
| 목표 정보 | 첫 목표는 리셋부터 손가락별 추종 정보와 focus에도 제공. 일반4초 악보 문맥은 유지 |
| 준비 | 첫 목표는 리셋부터 준비 가능. 이후 음은 원칙적으로 시작2초 전부터 준비 |
| 실제 압현 | 악보의 기존 음 시작 시각부터. 첫 목표는3초 유지 |

현재 울리는 음의 유지가 미래 음 준비보다 우선한다. 같은 손가락에 현재 음과 다음 음이 있으면 현재 음을 유지하고, 다음 목표는 별도 다음 목표로만 보여준다. 목표를 바꾸는 기준은 안정적인 event ID·시작·종료 시각이다. 여러 줄을 같은 손가락에 배정한 경우는 기존 유효 배정 규칙을 보존하고, 서로 다른 목표점을 임의 평균하지 않는다. 화음의 목표 충돌은 별도 검증한다.

공통 event ID와 목표 선택 결과를 focus, 손가락별 관측, 접근 보상, 진단이 공유하되, 관측 노출 마스크와 보상 준비 마스크는 별도로 둔다. E2/E3에서 보상 준비가 일찍 시작되어도 E1의 관측 노출 변경이 암묵적으로 적용되지 않게 한다. 목표 정보가 있다고 곧바로 실제 음의 접촉·달성 판정을 켜는 것은 아니다.

## 4. 줄 위 준비 영역을 거쳐 누르기

### 4.1 준비 영역

기타 좌표계에서 **실제 압현 판정에 사용하는 손바닥 쪽 패드 표면점**을 기준으로 한다. 손끝 중심이나 손등을 기준으로 바꾸지 않는다. 거리·방향·높이는 같은 표면점에서 계산해 서로 다른 점이 각각 조건을 만족하는 오류를 막는다.

| 요소 | 첫 실험값 | 의미 |
|---|---:|---|
| 줄 표면에서 바깥쪽 높이 | 중심6mm, 허용4~8mm | 미리 줄을 누르지 않고 내려갈 공간 확보 |
| 목표 줄에 대한 가로 오차 | ±3mm | 옆 줄 위에서 대기하지 않도록 함 |
| 프렛 방향 | 기존 목표 프렛 셀의 유효 안쪽 영역 | 프렛 철선·셀 경계를 새로 정의하지 않음 |
| 패드 방향 | 기존 근접 방향 품질 사용 | 손등이나 옆면 접근을 좋은 준비로 평가하지 않음 |

범위 안의 위치들은 같은 최대 준비 품질을 받는다. 정확히6mm 한 점을 쫓으며 떨 필요가 없다. 기존 접촉 높이 상한3mm와 준비 영역4~8mm는 구분한다. 첫6mm 값은 설계 초깃값이며 실제 모델에서 도달 가능성과 간섭을 확인한 뒤 채택한다.

준비 진입 판정은 진단용이다. 손목 안내를 벗어났다고 목표 손가락의 행동이나 접근 보상을0으로 잠그지 않는다. 준비가 늦어도 손가락이 계속 수정할 수 있어야 한다.

### 4.2 음 시작 직전 내려가기

음 시작0.20초 전부터 준비 높이6mm를 실제 압현 목표면0mm로 부드럽게 옮긴다. 보상 기준 위치의 이동이며 관절 목표각을 강제로 재생하는 동작이 아니다.

`u = clamp((현재 시각 - (음 시작 - 0.20초)) / 0.20초, 0, 1)`

`기준 높이 = 6mm × (1 - (6u⁵ - 15u⁴ + 10u³))`

위 높이는 의도한 준비→압현 진행을 설명하는 기준이다. 실제 보상은 아래 potential 보간식으로 구현해 기존 항과의 끝점 일치를 보장한다. 실제 음 시작 이후의 보상·접촉 기준은 기존 것을 사용한다. 준비 영역에서 먼저 올바른 방향을 만들었으므로 마지막 순간의 큰 손 전체 이동보다 작은 손가락 굽힘으로 연결되도록 유도한다. 이 유도만으로 관절 분담이 보장된다고 가정하지 않는다.

현재 최초 접촉 보상도 이미 실제 음 시작 이후에만 지급된다. 이를 앞당기지 않는다. 기존 접촉 연속50ms 진행, 압현 유지·달성, 오압현, 음 수행 부족, 물리·손목 실패 판정과 점수 예산을 보존한다. 음 시작 전 접촉·부하를 별도로 기록해 일찍 누르고 기다리는 편법도 검사한다.

## 5. 보상은 하나의 접근 항으로 연결

준비 접근 보상과 실제 표면 접근 보상을 별도 가산하지 않는다. 기존 목표 패드 접근 potential 하나가 준비 영역에서 압현 목표로 연속적으로 연결되게 한다. 기존 거리 척도30mm, 손가락별 가중치·정규화, 방향 품질, 보상 예산을 첫 비교에서 유지한다.

정확한 연결식은 `Φ = (1-s)Φ_hover + sΦ_surface`로 둔다. 준비 중 s=0, 시작0.20초 전부터 위의 quintic 값 s, 음 시작 이후 s=1이다. Φ_hover는 같은 패드 표면점에서 높이4~8mm 밴드·줄 가로±3mm·기존 프렛 유효 영역까지의 초과 거리로 계산하며 기존 거리 척도와 방향 품질을 사용한다. Φ_surface는 기존 표면 접근 potential 원식 그대로다. 두 항을 각각 보상으로 지급하지 않는다. 시작 시각의 값은 기존 Φ_surface와 정확히 일치해야 하며 접촉 허용 높이[-1,3]mm를 새 표면 보상 plateau로 바꾸지 않는다.

시각과 목표 ID를 포함하는 동일 potential Φ로 `γΦ(다음 상태) - Φ(현재 상태)`를 계산한다. γ는 해당 보상 스트림의 기존 할인 규약과 맞추고 다른 보상 스트림의 할인율을 일괄 변경하지 않는다. 단계가 바뀌거나 목표가 바뀔 때 이전 값을 임의로0으로 초기화하지 않는다. 진짜 종료에서만 종료 potential을0으로 정산하며, 학습 수집 구간 절단은 진짜 종료와 구분한다. 시간에 따라 기준점이 움직이는 효과도 같은 식에 포함한다.

테스트는 고정 상태의 시계 진행, 목표 교체, 음 종료, 실패 종료, 에피소드 종료에서 할인합의 소거 관계와 최초 접촉 예산의 중복 지급 여부를 확인한다. 기준점 이동으로 개별 시점의 양의 shaping 항이 생길 수 있으므로 양의 항 자체를 오류로 판단하지 않는다. 음 시작 전후 potential 끝점 일치도 검사한다. 기존 구현의 계산 규약과 차이가 있으면 이를 별도 변경으로 기록하고, 준비 시기 변경 효과와 섞어 해석하지 않는다.

목표 손가락은 준비 중 대기 자세 보상을 끈다. 나머지 손가락은 현재의 약한 대기 권고를 유지한다. 목표 손가락도 음이 끝나고 다음 준비 목표가 없을 때만 기존 복귀 규칙을 따른다. MCP 허용대를 좁히거나 손가락 속도·행동 비용을 추가하지 않는다.

## 6. 학습 초기 상태와 실제 사용 상태를 맞추기

보상 시간 구조를 먼저 비교한 다음 초기 상태를 별도 실험한다.

1. 기존 A 정렬 시작: 이전 결과와 비교하는 기준이다.
2. v9 이동 시작에서 목표 손가락4축 학습: 팔은 동일한 IK 요청으로 이동하되, 손가락은 그 이동 중의 실제 관측을 보며 학습한다. 이는 팔 이동 학습은 아니다.
3. 팔12축+목표 손가락4축 피드백 학습: 앞 조건이 통과한 뒤 팔 출력도 학습 가능하게 한다. 조건2와3 모두 free_v9의 단계별 팔 clamp 해제 상태를 공통으로 고정한다. 조건3에서 새로 바꾸는 것은 팔12축 출력의 동결 해제·학습 활성화뿐이다. 기존 B의 압현 단계 팔 clamp를 다시 도입하지 않는다. 다른17축의 정책 평균 유지가 실제 관절 고정을 뜻하지 않음을 명시한다.

완전33축 학습과 전곡 적용은 이보다 뒤다. 첫 고정 목표의 자연스러운 압현이 확인되기 전에 전체 자유도를 한꺼번에 늘리지 않는다. 기존 목표각 직접 제어, 관절 물리 범위, 손가락 움직임 비용0은 유지한다.

관측의 phase나 latch가 남은 반전을 유발하는지는 별도 제거 비교로 판단한다. 필요할 때만 연속적인 준비 정도·실제 상태로 대체하며, 기존601차원 실험 체크포인트에 입력 의미를 조용히 바꾸지 않는다.

## 8. 한 번에 하나씩 검증하는 실험 순서

우선 초기 펴짐이 가장 컸던 **중지 S3 F6**을 사용한다. 다음은1초 반전이 뚜렷한 검지 S3 F4, 이후 약지·소지다.

| 조건 | 기준 대비 변경 | 확인하려는 것 |
|---|---|---|
| E0 | 기존 조건 재현 | 비교 기준과 재현성 |
| E1 | 첫 손가락 목표·focus만 리셋부터 일관되게 제공 | 1초 입력 전환의 영향 |
| E2 | 목표 손가락 준비 중 대기 보상만 끔. 기존 접근 활성 시점 유지 | 대기 보상의 기여 |
| E3 | 준비 시기부터 준비 영역 접근 potential 적용. 대기 보상은 기존 조건 유지 | 조기 준비와 안전한 준비 위치의 효과 |
| E4 | E1+E2+E3 | 개별 개선의 조합 |

E3는 ‘조기 활성화+준비 영역’이라는 목적이 결합된 변경이다. 두 효과를 독립적으로 증명했다고 주장하지 않는다. 필요하면 조기 활성화 시점만 달리한 추가 비교를 한다. 줄 표면으로 일찍 접근하도록 하는 위험한 조건을 필수 비교군으로 만들지 않는다.

E0~E4는 모두 동일한 A 정렬 시작 학습→동일 v9 이동 시작 free 평가를 사용한다. 초기 분포 개선은 이 비교 이후 별도 실험이다. large/64환경/H32, 목표각 직접 제어, 기존 학습률·탐색 설정·물리·성공 판정·업데이트 수를 맞춘다. seed7에서 각100반복으로 선별하고, 기준과 유망 조건을200반복까지 비교한다. seed17에서도 같은 예산으로 재검증한다. 100반복의 일시적 성공과200반복의 퇴행을 모두 기록한다. 배포 시 사용할 결정론적 평가를 주 지표로 고정하고 확률 평가와 평균각 변환 평가는 별도 진단으로 둔다.

이후에만 6절의 초기 상태 비교를 수행한다. 기존100반복 약8.4분을 기준으로 첫5조건 선별은 평가 포함 약1시간, 추가 반복·seed 재검증은 총2~3시간 이상을 예상한다. GPU 상태와 실패 여부에 따라 달라지며, 이 문서 작성으로 실행을 시작하지는 않는다.

## 9. 판정 기준과 필요한 기록

성공 횟수만 높아도 부자연스러우면 채택하지 않는다. 공통 집계는 사전 고정한 첫32에피소드 전체이며 실패도 포함한다. 압현 성공은 기존 판정의32/32 보존, 유지 시간2.4초는 별도의 품질 하한으로 구분한다. 각 조건의 유지 시간 최솟값·평균을 기록하고32회 모두2.4초 이상인지 확인한다. 초기 펴짐·1초 반전·나쁜 정체는 에피소드별 최대값/누적시간의 평균과90백분위수를 함께 보고하며 둘 다 기준 대비 악화하지 않아야 한다. 준비0.2초 충족률도32회를 분모로 하여100%를 목표로 한다. 간섭 회피에 필요한 펴짐 여부는 자동 분류하지 않는다. 정량 최대 펴짐을 모두 공개하고 별도의 영상 판정을 덧붙여 사후에 유리한 에피소드를 제외하지 않는다. 다음은 고정 목표 실험의 잠정 기준이며, 관절 제한이나 새 보상으로 넣지 않는다.

| 항목 | 판정 |
|---|---|
| 압현 성능 | 기존32회 기준 평가에서 퇴행 없음. 유지 시간 목표2.5초 중2.4초 이상, 물리·손목 실패0 |
| 불필요한 초기 펴짐 | 같은 목표에서 간섭 회피에 불필요한 MCP/PIP 펴짐50% 이상 감소, 목표5° 이내. 필요한 펴짐까지 금지하지 않음 |
| 1초 추가 반전 | 검지 기준 요청각 반전0.5° 미만 또는70% 이상 감소 |
| 준비 | 내려가기 시작 전에 준비 영역에서0.2초 이상 머물 수 있음. 안전한 준비 완료 후 기다림은 실패가 아님 |
| 나쁜 정체 | 목표가 유효하고 손목 속도5mm/s 미만이면서 준비 미완료인 시간 감소 |
| 타이밍 | 음 시작 전 접촉·부하·오압현 증가 없음. 기존 음 시작과 접촉 판정 유지 |
| 관절 분담 | MCP/PIP/DIP 실제각·요청각·적용각과 영상을 함께 확인. 고정 비율로 굽힘을 강제하지 않음 |

기존 per-step 로그를 확장해 event ID, 목표 유효/준비/실제 음 상태, 기준 높이, 실제 패드 높이·가로 오차·방향, 준비 품질, 대기/접근 가중치와 보상, 손목 오차·속도, 단계 전환 시각을 같은 시간축에 남긴다. 새 진단 파일을 불필요하게 여러 개 만들지 않는다.

평가는 사전에 정한 첫32에피소드를 사용하고 조기 종료도 분모에 넣는다. 전신과 손 확대 영상을 같은 실제 시간축으로 남긴다. 필요한 경우 도달 가능한 IK 리셋으로 손목 ±5mm/±2° 변동과 음 시작2/3/4초를 추가 검사한다. 음 시작을 바꿀 때는 악보·안내·안전 조건의 시계를 함께 맞추고 고정3초 가정을 먼저 점검한다.

단일 목표 통과를 전곡 일반화로 해석하지 않는다. 이 설계 후에도 관절 모양이 나쁘면 기하 접근만으로 해가 충분히 제한되지 않은 것이다. 그때 성공적인 준비 궤적을 이용한 약한 초기 학습 등을 별도 실험으로 검토한다. 곧바로 모든 관절의 각도 범위를 좁히지는 않는다.
