# 성공 궤적 초기화 후 손별 PPO 학습

사용자 요청: 학습 진행. 직전 결과에서 무작위 PPO의 결정적 성공이 없고 scripted 성공 궤적을 확보했으므로, 그 입력/행동으로 Actor를 먼저 초기화하고 native 재현을 확인한 다음 PPO를 수행한다. 이 순서와 필요한 새 연결 구현은 이번 학습의 범위다. 기존 실행/실패/소스는 덮어쓰지 않는다.

## 조건과 성공 기준

- 기존 첫 단음(물리2번줄/7프렛/약지/down), LHhold·RHcross, 상태505/행동39, 각4초, 준비2초를 유지한다.
- Root고정·하체유한·105/97/8·기타자유/중력ON/스트랩OFF·기존gain/충돌/의자/행동범위/평활화/속도·물리실패조건 유지. 기타직접힘/부착/연속상태쓰기 금지.
- LH는 실제 접촉후보와50ms 연속유지로 평가한다. 부정확한 distal원점 접근 shaping은0으로 하고 reach15mm를 선행조건으로 쓰지 않는다. 하중비의존·상완지지/V3정밀요구의 인증과 구분한다.
- RH는 검증된허용영역 guide(y−.36m/depth4mm/앞뒤8mm)를 사용한다. 타현의 기존 유한영역·깊이·속도/방향·재준비 gate는 그대로다.
- profile이 바뀌므로 기존 행동열을 새환경에 실제재생해505관측/행동데이터를 다시수집한다. 악보시간과원래music판정을보존한다.
- BC는 Actor해당branch만학습한다. Critic/상대손/PPO업데이트수는변조하지않는다. 별도명시BC초기화형식으로보관하고 PPO기록과혼동하지않는다. 초기 탐색std.02, BCactionMSE≤1e−6목표/최대2000step에서시작하며 필요시새버전으로확장한다.
- 실제결정적2회평가에서원래native손별성공+안전한4초완주를확인한뒤PPO를진행한다. 성공하지않으면그기록을보존하고원인을고친다. 단순trainingfit를정책성공으로쓰지않는다.
- PPO는비용1,작은탐색std.02/actor_lr1e−5, N2/H240/최대24updates/softwall1800초를기본예산으로한다. 양손을따로학습한다. 완료후각결정적평가2회를수행하고, 기능을잃은final을성공모델로승격하지않는다.
- 성공은현재단일목표·동일준비초기상태범위다. 사람motion/음악타이밍/음향·일반화·양손결합완성으로확대하지않는다.
