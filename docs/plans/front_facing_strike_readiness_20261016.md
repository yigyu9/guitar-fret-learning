# 타현 양쪽 사전준비 판정 명확화

기존 front_facing_strike_20261016.md의 양쪽 사전준비는 왼손 압현을 뜻하지 않는다. 타현만 평가하는 이번 실험에서 실제 피크가 두 타현 출발측에 준비되는 것을 독립적으로 검사한다. 기존계획/분석기/매체검사V1은수정하지않고새readiness_v1과media_audit_v2로보완한다. 실제producer/native이전사전고정기준이며사후결과에맞춰완화하지않는다.

- 내려치기전11.1..11.5초,올려치기전12.1..12.3초에서각각연속한두60Hz실제표본이필요하다. 해당방향첫실제검출이벤트보다이전이어야한다.

- 내려치기전에는피크X가모든줄X최솟값보다3mm이상바깥,올려치기전에는모든줄X최댓값보다3mm이상바깥이어야한다. 모든줄대비피크깊이는1mm이상이어야한다. 기준좌표는원source의타현G-X이며world축과구별한다.
