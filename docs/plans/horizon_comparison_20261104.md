# H32·H64·H128 비교 준비

요청: 다른 PC에서 실행할 실험 환경과 전달 프롬프트를 준비한다. 이 PC의 진행 중 C1 학습과 봉인 runtime은 변경하지 않는다. 사용자 요청으로 환경 준비까지 승인된 작업이다.

가정: V5 corrected·C1·seed7·환경1024를 공통 기준으로 한다. 실험 결과는 docs/2026-11-09/H실험 아래에 둔다. 목표는 H의 단독 최적값 확정이 아니라 동일 경험량에서 세 설정의 학습 효율을 비교하는 1차 검사다.

- [x] 설계: 총 16,777,216 전이/조건, 25%인 4,194,304 전이부터 전곡 노출. H32/64/128은 각각 512/256/128회 업데이트. 현재 장기 학습과는 별도의 공통 일정이다.
- [x] 환경: 프로젝트 내부 소스·자산·C1·native 패키지 사본을 만들고 SHA로 봉인. 상대 경로와 실행 중인 Python을 사용한다. 현재 PC에서는 CPU 준비·검증만 한다.
- [x] 실행 안내: 다른 PC의 최고 H 메모리 확인, 순차 학습·동일 전이 평가·영상·실패 복구·진행 기록을 명시한다.
- [x] 검증: CPU 목표/설정·예산·봉인과 오류 경로 검사, 독립 검수. 실제 GPU 실행은 다른 PC에서 수행한다.

통제: 보상·제어·네트워크·초기 탐색·PPO epoch/minibatch/LR을 유지한다. H를 바꾸면 한 업데이트의 시간 길이, 배치 크기, 업데이트 빈도가 함께 달라진다는 한계를 기록한다. 세 조건은 전부 새 학습이며 서로의 checkpoint를 이어 쓰지 않는다.

완료: 독립 사본9,338항목 봉인, 필수 입력213개 SHA/내부 경로 검사, 공식 CLI21개·설정3조건 CPU검사, 테스트8개·독립 검수 통과. GPU 실행은 하지 않았으며 다른 PC의 첫 단계다. 영상 경로 표기 제안은 반영했다.
