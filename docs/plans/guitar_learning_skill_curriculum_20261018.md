- 두 비용 비교에서 goal/단계/초기모델/RNG/수집예산·학습설정을 맞추고 cost_weight만 변경한다. 동일 관측을 다시 평가한 것과 실제 학습·물리 평가를 구분한다. 작은 파일럿 결과를 일반화하지 않는다.
- 실패·미성공도 보존한다. 실제 목표 성공이 없는 손은 성공 궤적 확보 미완료로 보고하며 결합 학습을 시작하지 않는다.
