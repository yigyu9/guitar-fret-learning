# 몸통 지지 실패 원인 분석과 검증

사용자가 원인 분석·검증을 요청했다. 제어 개선을 한꺼번에 적용하지 않고 진단만 수행한다.

가정: 300Nm 포화는 기록상 사실이나 팔 반작용·기존 자세 유지 불안정·스트랩/접촉 하중·좌표별 복원 제어 중 무엇이 주원인인지는 아직 미확정이다. 토크 포화만으로 출력 부족이라 판단하지 않는다.

1. 기존 제어·물리 계약과 시간 순서 분석 → 검증: 목표 고정 여부, 포화 전후 자세·속도·하중.
2. 같은 WAIT에서 팔 목표까지 고정하는 대조 실험 → 검증: 팔 목표 변화가 없어도 몸통이 흔들리는지.
3. 앞 결과에 필요한 작은 실험만 추가하고 독립 검수 → 검증: 원인과 추정을 분리한 수치 및 재현 자료.

- [x] 팔 목표 고정 물리 대조
- [x] 필요한 추가 실험·독립 검수·결론

실제 팔 움직임을 완전히 막는 고정과 목표만 고정하는 제어를 구분한다. 진단 ablation의 성공을 원래 도달 성공으로 해석하지 않는다. 학습·물리 설정 기본값은 변경하지 않는다.

결과: [원인 분석·물리 검증](../2026-10-12/회의/results/torso_support_diagnosis_20261003/diagnosis_report.md). 목표 고정/한 축 램프 안정, 큰 다축 접근 Torso만 92.67% 포화. 복원 좌표 대체는 효과 없음. 200step 뒤 팔 목표 갱신 중단은 Torso 오차 24.657→4.241°, 포화 92.67→7.50%로 감소. 실제 정지 제어 채택이나 도달 성공은 아니다. 다음 개선 후보는 Torso 여유 기반 팔 목표 사전 감속 하나이며 아직 미구현.
