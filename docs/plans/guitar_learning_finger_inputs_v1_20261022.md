# GPU 왼손의 손가락별 목표·실제 자세·거리별 요청 비용

사용자의 추가 개선 구현 요청에 따라 직전 제안의 우선순위1~3을 구현한다. 첫 슬롯은 기존 추종 보상과 동일한 현재음 우선/준비음 fallback, 둘째는 같은 손가락의 준비창 안 미래음 중 첫 슬롯과 다른 가장 빠른 onset이다. 순서는 index/middle/ring/pinky 각2slot이다. 기존 전체64×24토큰은 유지한다. 실제 MCP/PIP/DIP sin/cos24+finger valid4+idle4를 상태에 추가해 GPU왼손544상태/8×24priority로 분리한다. 요청 비용은 contact candidate 또는거리<=5mm에서1,거리>=20mm에서.25, 사이선형이며 자기4축sum/21계수에만곱한다. 실제 속도/성공/안전/물리/자유로운 독립제어는 유지한다. CPU/오른손/전문 경로는 기존2priority와상태를유지한다. 새보상v6·새입력계약·strict구버전거부로fresh시작한다.

앞서제안4의출력분리는성과소실재현후,5의native원인교정은원인증명후,6의H64/할인율/탐색변경은분리학습비교후선택하는후속항목이다. 이번엔장기학습을시작하지않고기능/저장/재개검증까지만진행한다. 계획은현재사용자의구현승인범위에서실행한다.
