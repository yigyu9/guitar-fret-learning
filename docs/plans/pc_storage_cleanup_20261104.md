# PC 저장 공간 후보 정리 — 2026-11-04

사용자가 [PC 전체 점검 보고서](../maintenance/pc_storage_audit_20261104/REPORT.md)의 정리 후보 삭제를 승인했다. 약11.66GiB 상한에 포함한 캐시·구버전 설치본·과거 시스템 기록·설치파일·XRDP 로그·Docker 이미지만 대상으로 한다.

## 계획과 검증

- [x] 승인 후보와 현재 사용 상태를 다시 대조하고 정확한 파일 목록 및 보존 목록을 만든다.
- [x] 삭제 helper와 관리자 작업을 독립 검수한다. 권한·활성 앱·서비스 조건이 충족되는 항목만 실행한다.
- [x] 삭제·보류 내역, 현재 버전과 앱 데이터 보존, 실제 디스크 여유 변화를 검증한다.
- [x] 결과 보고서와 체크리스트를 완료하고 독립 최종 검수를 받는다.

## 실행 기준

- 개발 환경·Snap·개인 중복 영상·Git/LFS·연구 자료는 이번 삭제 범위가 아니다.
- 앱을 강제 종료하거나 원격접속 서비스를 재시작하지 않는다. 활성 앱의 캐시와 현재 로그는 보존하고 사용하지 않는 후보만 정리한다.
- 심볼릭 링크를 따라가지 않고 파일 식별자·크기·수정시각 및 사용 여부를 실행 직전에 확인한다. 변경되거나 열린 파일은 건너뛴다.
- journal은 과거 기록1GiB와 활성 기록을 보존한다. XRDP는 서비스에 맞는 방법이 검증되고 관리자 권한이 있는 경우에만 최근 기록을 남겨 축소한다.
- 관리자 인증이 필요한 작업은 권한을 우회하지 않는다. 가능한 작업을 먼저 완료하고 미완료 이유와 검토 가능한 후속 작업을 남긴다.

## 후속 조건이 필요한 미완료 항목

- [ ] Chrome·로컬/원격 Code를 정상 종료한 뒤 해당 캐시의 사용 여부 재점검 및 정리.
- [ ] PC에서 관리자 인증 후 journal·APT 지정 설치파일·XRDP 로그 정리. 검토된 실행파일과 방법을 [결과 보고서](../maintenance/pc_storage_cleanup_20261104/REPORT.md)에 남김.
