# 기존 CPU 코드와 GPU 전환 구현 비교

사용자 요청: 기존에 거의 없던 기타 튐·안전 종료가 생긴 구현상 원인을 탐색한다. 과거 결과·준비 입력·생산 코드는 보존하고 런타임 진단 변형만 별도 기록한다.

- [x] 장면/속성/초기화·tensor 인덱스/API·원래 제어 수학을 나누어 원문 비교
- [x] 동일 힘 재생을 유지하며 구체적 변경 하나씩 원복하는 native 분리 시험: 문서상 상태 tensor 형태, human COM/관성 재설정, GPU 물리/CPU tensor 경로 등
- [x] 문제를 일으키는 조건과 배제한 가설을 증거로 정리하고 독립 검수

현재 확인: 같은 GPU에서도1환경 재생은 원래 궤적과 비트 단위 동일하고1024환경 재생은 크게 달라진다. 새 정책·피드백 수학을 다시 계산하지 않으므로 장면/초기화/입력/배치 물리 처리부터 분리한다. 시험 결과가 나오기 전 특정 코드 차이를 버그로 단정하지 않는다.
