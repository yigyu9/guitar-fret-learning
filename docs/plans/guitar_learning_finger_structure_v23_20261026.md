# 손가락 제어 구조 개선 v23

사용자의 구조 개선 승인(2026-10-26)에 따른다. 먼저 제어만 바꾼 비교를 수행하고, 결과 없이 B 계수·커리큘럼·PPO를 한꺼번에 바꾸지 않는다. 현재 전곡 계약의 67음과 준비 자세를 유지한다. 이는 새 제어 버전이며 보상 v22의 성과를 상속하지 않는다.

1. 원본 보관과 제어 교체 → LH21의 작은 일정 행동이 관절 한계까지 누적되지 않으며, 0은 준비 참조각, ±1은 native 전체 범위, 목표 이동 상한4rad/s임을 독립 계산과 검사한다. 엄지 포함 움직임 비용0·B 비강제·자유 기타·PD/힘·팔/손목·CPU/오른손은 유지한다.
2. 설정·저장/복원·진단 연결 → 기본 position/명시 incremental 비교 선택을 설정과 계약에 기록하고, 의미가 다른 checkpoint 재개를 거부한다. 손가락별 목표 한계 체류·행동 방향 지속·실제 추종과 B 복귀를 비교한다.
3. CPU 검사와 독립 검수 → 경계·역전·부분 reset·H32 지속·비대상 제어 동일성·strict resume를 검증한다.
4. 실제 GPU 구동/재개와 동량 짧은 비교 → 동일 초기 정책/seed/환경/전이 수로 position/incremental을 비교한다. 고정 첫 종료곡에서 실패도 포함해 달성음·손가락별 성과·B 복귀·극단 목표를 기록한다. 짧은 비교를 장기 수렴 증거로 쓰지 않는다.
5. 결과와 현행 문서 갱신 → 개선이 입증된 범위와 남은 문제를 구분한다. B 보상·손가락별 학습 기회 개선의 다음 조건을 구체화한다. 전곡 손가락 편중이 남으면 원본 곡 시간·노트·손목 안내의 일관성을 보장하는 별도 부분곡 학습 버전으로 진행하며, source-pinned 전곡 task를 임의로 자르거나 임계값만 낮추지 않는다.
