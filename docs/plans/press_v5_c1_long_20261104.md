## 고정 조건

- 전용 `press_sequence train C1`로 원본 압현 시각을 보존한다.
- v5 corrected, 상태464·목표26×8·행동33, 고정768→512→256 신경망, size large 표기, seed7, H32.

- 한 가지 조건에서 길이에 따른 변화를 본다. 실행 중 보상·학습률·탐색·소스를 바꾸지 않는다.
- 독립 처리량 pilot으로1024환경의 메모리·속도·저장량 확인. 자원 문제가 있으면 본학습 시작 전에512환경을 비교해 결정한다. pilot은 본학습에 합산하지 않는다.

- 실제 처리량 확인 뒤 예상 소요시간을 기록한다. 사용자 시간 제한은 없지만 장기 실행이 무한히 반복되지 않게 예산과 재시도 횟수를 제한한다.
