# 다음 단일 비교: 정책을 유지한 reward critic 사전 보정

상태: 계획만 작성. 구현·실제 비교·성과 입증 전이다. 기존 사용자가 승인한 실패 원인 진단과 필요한 추가 개선 범위의 후속이다. 앞 단계의 실제 결과·검수 완료를 확인한 뒤 실행한다.

## 근거와 한계

고정 V6 fit/50/100/300의 같은 seed7 확률128수행에서 세 음 달성은14/0/0/0이다. 마지막 A는 검지 끝마디의 own_wrong_fret/own_wrong_string 판정 시간비율각0.984375이며 출처표본프렛5·목표4를 확인했다. 기울기진단의 마지막 contact/hold cosine은−0.850288, 초기준비/첫음준비는−0.793090이다. 이 측정은 실제 과거 optimizer 단계의 인과증명이 아니다.

초기 fit 모델의 reward value와 실제 할인 반환값 비교에서 전체 RMSE0.605089, 초기준비 V−실현반환 평균−0.600439를 관찰했다. 300모델의 전체 RMSE는0.149546으로 낮아졌지만 압현은퇴행했다. 관측 반환값에는 확률 변동이 들어가므로 이를 조건부 기대가치의 정답이나 전부 critic오류로 단정하지 않는다. 초기의 미보정 가치 예측이 첫 학습의 bootstrap 신호에 주는 영향만 분리한다. 접근보상 삭제·초기준비 보상 차단·보상가중치 조정은 동시에하지않는다.

이 자료는 **기타고정·검지4축·원3음view 전체354tick**이다. 원곡67음 전체가 아니다. 기울기는 H32별 정규화와 마지막H2의 전이수 가중합이고 실제 H32훈련/Adam복원이 아니다.

## 사전에 고정할 구현

1. **fresh 재현과 원문 보존.** 새 진단 버전으로만 구현한다. V6의 fresh constructor/RNG·costhead0·배우 목표지도1000회로 생성한 초기 배우를 그대로 재현한다. 원V6 checkpoint검사를완화해새계약으로재개하지않는다. 기존 루프를 재사용하며 생산281Python과 봉인원문은변경하지않는다.
2. **현재 초기 수행만으로 MC 자료를 만든다.** 이미 수집한 V6 fit의12개buffer에서 실제 reward와실제 terminated/truncated를 확인한다. gamma=.99의354tick 할인 반환을 계산한다. 50/100/300 자료를 warmup학습에사용하지않는다. train환경0..95, 동일장면 holdout환경96..127을 사전에 고정한다. 이 분할을 다른장면·seed holdout이라고부르지않는다.
3. **가치망만1000회 학습.** 임시 Adam·기존 critic 학습률·기존 gradient상한, 배치512의 train행 균등샘플로 reward value MSE를 최적화한다. value_encoder와 reward_critic만 갱신한다. actor·표준편차·support/finger actor weights·costhead는 그대로다. 원래의 양의 failure cost 학습능력도 보존한다. 임시 optimizer는 버리고 PPO actor/value optimizer는 기존과같이 빈 상태에서 시작한다. 자료 샘플링은 별도 RNG로하며 원초기 정책·PPO 난수경계를 보존한다.
4. **변경범위와 초기수행 검증.** 원초기 actor 텐서·각 backend의 전후 분포 출력·Gaussian 표본·선택4행동이같은지검사한다. CPU와GPU 사이의수치차이는별도기록하고서로의bit동등성을요구하지않는다. 원엄격계약의 새metadata/version을사용하고 supervised1000+valuewarmup1000+PPOupdates를구분기록한다. 초기고정/확률128평가의 전체음원장/관절/목표/후보/NNgoal이V6와같아야한다. value예측과원MCtarget, train/holdout전체·구간별MSE/평균잔차를분리한다. holdout MSE가개선되지않거나비유한/동작동등성이실패하면PPO전중단·미채택으로기록한다. 예산/분할을뒤에서늘려통과시키지않는다.
5. **동일 PPO300과 평가.** 통과하면large128/H32/seed7/PPO300,50회간격6고정128+마지막확률128,마지막모델손/전신영상으로V6와비교한다. 보상9개·γ/λ·실패비용/cost_weight1·물리/속도/범위/힘상한·탐색·종료·악구일정을유지한다. KLretry와실제학습률의차이는개입이매개한결과로기록한다. 수용기준을낮추지않고원128/384와달성·유지·오압현·해제·동시성공을보고한다.
