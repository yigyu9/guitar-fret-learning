## 2. 최종 보상표 제안

기존 v24 초기 실효 계수를 가능한 한 유지하고 stage별 가중치 전환은 제거한다. b는 현재 선택된 과제의 기존 손가락 균형 계수다. 압현 유지와 압현 달성은 서로 다른 지표로 남긴다.

| 최적화 항 | 제안 규모 | 역할 |
| --- | --- | --- |
| 목표 패드 접근 | 단일 potential, 계수1 | 거리·가까운 곳의 방향 품질 |
| 최초 접촉 | 음당 최대0.25b | 기존 연속 접촉 진행도 증가분 |
| 압현 유지 | 음당 최대1.0b | clean 증가량/음 길이 |

| 오압현 | 음당 최대−0.15b | audible wrong 시간/음 길이 |
| 음 수행 부족 | 음당 최대−0.10b | missing과 압현 달성 부족 중 큰 부족률 |
| 대기 자세 | 손 전체 최대0.02/초 | 본인 idle의 약한 선호 |

| 행동 변화 | 기존 계수/무감점 폭 유지 | LH21은0, 손목은 나머지 팔의1/4 |

**활성 reward 항9개**로 정리한다. 손목 감점·별도 추종·별도 missing/missed·물리 실패 reward−2·기본0인 coordination 슬롯은 활성 보상표에서 빠진다. 오압현과 음 수행 부족은 각각 잘못 누른 상태와 과제 완성도를 다루며 분리한다.

최초 접촉/유지/달성의 문턱이나 음향 성공 정의를 바꾸지 않는다. b를 다시 곱하거나 그룹 계수를 이중 적용하지 않는다. 위 값은 최종 reward에 들어가는 실효 계수다.

## 3. 두 통합 항의 정확한 동작

### 3.1 목표 패드 접근

- 손가락별 현재 음 우선/다음 준비 음의 기존 단일 선택기를 공유한다.
- 지정 finger3 패드와 해당 압현 표면의 거리 d를 사용한다. 별도 손끝 중심점이나 손등 점으로 교체하지 않는다.
- 먼 거리에서는 거리만 안내하고, 가까운2cm 안에서 법선 품질을 최대20% 정도로 부드럽게 반영한다. 하중/접촉 여부를 접근 보상의 필수 gate로 쓰지 않는다.
- 기존 악보 기반 tracking weight를 적용해 본인 B 회복과 경쟁을 줄인다.

제안하는 단일 진행도:

```text
Phi(s) = sum_selected_fingers [ b × tracking_weight
             × exp(−distance / 0.03m)
             × (1 − 0.2 × near_weight × (1 − alignment_quality)) ]
r_approach = gamma × Phi(s_next) − Phi(s)
```

alignment_quality·near_weight는0~1이다. 같은 거리로 머무르는 별도 양성 추종 rate는 제거한다. 접촉 후 정지해 잘 유지하는 행동은 clean 항에서 보상한다.

같은 상태 함수로 목표 ID·시간·선택 mask를 포함해 Phi를 계산한다. 목표가 교체됐다는 이유로 과거 Phi를0으로 덮어써 새 보상을 만들지 않는다. 자연 종료와 실패 종료 모두 다음 Phi=0으로 정산한다. H32는 종료가 아니다. 목표 전환·왕복·idle fade·reset에서 potential 차분과 terminal 경계를 직접 검사한다.

### 3.2 음 수행 부족

한 음의 audible 길이 D, 누락 시간 M, 최장 연속 clean S, 기존 달성 문턱 T를 사용한다.

```text
missing_ratio = clamp(M / D, 0, 1)
streak_deficit = 1 − clamp(S / T, 0, 1)
final_deficit = max(missing_ratio, streak_deficit)
음당 최종 감점 = −0.10 × b × final_deficit
```

두 부족을 더하지 않고 큰 부족률 하나를 쓴다. 전혀 누르지 않은 음은 두 원인이 모두1이어도 예산0.10b 한 번이며, 문턱에 거의 도달한 음은 부족분만 반영한다. 달성을 했어도 나머지 시간의 missing은 남는다.

학습 신호를 음 끝까지 모두 미루지는 않는다.

1. audible 중에는 missing 증가분에 따라 예산 일부를 사용한다.
2. 정상적으로 음이 끝나면 최종 부족률에 필요한 차액만 한 번 정산한다.
3. 이미 지불한 감점을 다시 빼거나 음 끝을 여러 번 정산하지 않는다.

조기 종료 이후의 미관측 누락/미달성은 이 항에서 가상 시간으로 반복 감점하지 않는다. 남은 과제는 아래 종료 비용이 담당하고 평가에서는 고정 분모에 실패로 남긴다. 선택하지 않은 음은 이 예산에 들어가지 않는다.

원장에는 음별 지불액과 정산 여부를 둔다. 종료 비용은 이 두 상태를 기준으로 남은 예산을 계산한다. 음 끝과 실패가 같은 control tick이면 이미 관측한 missing과 정상 완료된 음의 정산을 먼저 반영하고, 아직 정산하지 않은 음의 차액만 남은 예산에 포함한다. 시간 비교만으로 그 음을 누락하지 않는다.

## 4. 종료 조건

### 4.1 기존 물리 실패: 유지

기타 변위8cm, 기타 회전0.35rad, 발 변위4cm, 기존 지지 접촉 상실0.25초, 관절 속도50rad/s 및 기존 제어 무효 조건을 현재 정의대로 유지한다. 몸체쌍을 알 수 없는 GPU 합력으로 새 손가락 충돌/끼임 판정을 만들지 않는다.

이들은 이미 종료 조건이다. 문턱을 다시 강화하는 작업과 중복 reward/cost를 정리하는 작업을 구분한다. 자연스러운 접촉 분담 변화가 기존 허용 범위 안에 있으면 종료하지 않는다.

### 4.2 손목 지속 이탈: 신규

현재 안내 상자 내부에서 감점은0으로 하고, 바깥에서도 손목 위치 reward를 부과하지 않는다. **안내 상자와 종료 경계를 구분한다.** 다음 수치는 검증 전 시작안이다.

| 항목 | 시작안 |
| --- | --- |
| 측정 | 실제 기타 좌표계 손목에서 현재 안내 상자까지의 축별 초과 거리 |
| 일반 이탈 진입 | 어느 축이든 안내 상자 밖으로3cm 초과 |
| 지속 기준 | 이탈 상태0.75초 지속 시 종료 |
| 재진입 | 모든 축 초과 거리가2cm 이하가 되면 이탈 상태/타이머 해제 |
| 초기 준비 | 일반 이탈 판정은 기존 준비3초 후 활성화 |
| 목표 전환 | 별도 유예/재시작 없음. 일반 이탈의0.75초 허용 시간이 이동 유예도 담당 |
| 심각한 이탈 | 상자 밖 초과 거리10cm 이상이0.10초 지속하면 종료; 초기 준비에도 적용 |

일반 이탈은3cm 밖에서 상태를 켜고,2cm 안으로 복귀해야 해제하는 방식으로 경계 떨림을 줄인다.0.75초는 이 상태의 지속 시간이다. 초기 준비3초 동안 일반 이탈 상태와 타이머를 지운다. 음/프렛이 바뀌어도 timer를 지우지 않는다. 별도 목표 전환 유예와 이벤트 cursor는1차 구현에 추가하지 않는다. 정상적인 큰 프렛 이동에0.75초가 부족한지는 shadow 측정으로 확인하고, 필요하면 지속시간 자체를 조정한다.

정확한 timer는240Hz 실제 표본으로 누적하고, 실제 환경 종료/비용 부과는 기존60Hz 제어 경계에서 수행한다. H32나 다른 환경의 reset이 이 timer를 초기화하지 않는다.

종료 timer를 숨은 상태로 두지 않는다. 일반 이탈 상태·일반 이탈 경과시간·초기 준비 유예 잔여시간·심각 이탈 경과시간의4열을 관측에 명시한다. 시간은 각각0.75/3/0.10초로 정규화한다. support/finger actor와 critic 모두 해당 정보를 받는다.

이번1차 정식 추가는 손목 이탈로 제한한다. 극단 자세·관절 한계 체류·손가락 충돌·접촉 정체는 진단으로 남긴다. 유연한 압현에 필요한 자세나 실패하며 배우는 시도를 즉시 종료시키지 않도록 측정과 회복 가능성을 확인한 뒤 후속 조건으로 검토한다.

### 4.3 에피소드 종료와 실행 중단

- 물리 실패·손목 이탈: 해당 환경의 에피소드만 끝내고 준비 상태로 reset, 다른 환경과 PPO는 계속한다.
- 자연 곡/구간 끝: 정상 terminal로 처리한다.
- 시간/반복 예산: 저장 후 정상 실행 종료다.
- 비유한값·깨진 제어 인증·저장 실패·입력 SHA 변경·자원 하한: 학습 자료로 삼지 않고 전체 실행을 보호 중단한다.
- R80% 미달 같은 숙련 관문은 전체 실행의 종료 사유로 쓰지 않는다.

손목 실패와 물리 실패는 원인 flag를 따로 기록한다. 둘이 동시에 발생해도 비용/종료는 한 번이다. 손목 실패를 실제 물리 붕괴로 집계하지 않는다.

## 5. 종료 비용을 한 곳에서 부과

현재의 reward−2, 기본 failure cost5, 남은 시간×5, 정상 연속 물리 cost를 여러 곳에서 더하는 구조를 정리한다. 제안안은 정상 연속 물리 cost를 없애고 **실패 종료 cost 한 항**만 남기는 것이다. 제어기의 PD/중력 보상/하체 유지 동작은 유지한다.

```text
C_terminate = 5 + 2 × remaining_local_seconds + remaining_negative_note_budget
```

- 기본5: 종료 자체의 비용.
- 초당2: 남은 시간을 버리는 비용. 시간은 실제 종료한 제어 경계 이후의 로컬 과제 길이다.
- remaining_negative_note_budget: 아직 관측하지 않은 선택 음에서 회피할 수 있는 최대 wrong/음 수행 부족 감점의 남은 예산.

음별 예산은 미관측 audible 비율에 대한 wrong 최대0.15b와, 수행 부족 최대0.10b 중 아직 지불하지 않은 부분이다. 종료 전 이미 끝나 정산된 음과 선택하지 않은 음은 제외한다. 정상 곡 끝에는 이 비용이 없다. 전체67음 시작점에서는 대략5+2×32.8167+0.25×67=87.38이며 짧은 구간은 실제 길이/선택 음으로 줄어든다.

남은 음을 원장에 가상으로 끝까지 진행하며 또 감점하지 않는다. 관측한 부분의 정상 감점과 미관측 부분의 종료 예산을 구분한다. 실패 control tick의 기존 양성 억제를 유지하며 접근 Phi의 terminal 정산은 접근 항의 경계 처리로 기록한다.

이 비용은 강한 초기안이다. 정해진 음별 상한과 정상 연속 물리 cost 제거를 전제로 합성 사례에서 조기 탈출의 회피 이득을 검사한다. 다른 연속 cost를 남기면 그 미래 상한도 다시 고려해야 한다. 모든 정책의 최적화/수렴을 보장하는 식이라고 주장하지 않는다.

기존 실패 cost는 전곡 시작에서5+5×32.8167=169.08이고 별도 reward−2도 있었다. 새87.38은 원시 숫자의 증액이 아니다. 중복을 정리하고 미관측 감점 회피를 비용에 반영하며 아래 합산 방식을 바꾸어 **실효 비중을 재설계**하는 안이다. 원시 수치만 보고 기존보다 더 강하다고 주장하지 않는다.

### PPO 합산

현재는 reward/cost advantage를 각각 표준화해 cost 숫자의 단순 확대 효과가 약해질 수 있다. 새 목적에서는 다음을 사용한다.

```text
A = A_reward − 1.0 × A_cost
A_normalized = normalize(A)
```

기존 `joint` 모드를 새 실행에 명시한다. cost multiplier는1로 고정하고 자동 증감하지 않는다. cost 채널·critic은 기록과 학습을 위해 유지한다. 기존 reward gamma/cost gamma·가변 d 수집/GAE·KL 가드는 보존한다. 서로 다른 할인으로 인해 두 채널이 같은 scalar return이라고 표현하지 않는다. 종료 비용5와10/남은 시간 계수를 바꿨을 때 상대 advantage가 실제로 바뀌는지, safe/fail이 섞이고 reward/cost가 비례하지 않는 고정 batch로 검사한다. 모든 표본이 같거나 두 advantage가 비례하는 특수 경우에도 정규화 후 변화가 반드시 생긴다고 주장하지 않는다.

## 8. 확인할 성공 기준

- 접근/추종은 최종 reward 한 항이며 같은 표면 측정/목표를 사용한다. 목표 교체·왕복·대기·terminal/H32 경계에서 중복 크레딧이 없다.
- missing/streak 모두 실패한 음도 감점≤0.10b이며, 음 끝 정산은 한 번이다. 짧은 음·동시음·달성 후 누락·부분곡/비선택 음·음 끝과 실패 동시 발생을 검사한다.
- 여러 종료 이유가 겹쳐도 비용이 한 번이다. 초기3초·목표 전환 시 timer 유지·경계 떨림·재진입·reset timer·관측561열의 대응을 검사한다.
- 실패 tail은 평가의 고정 과제 분모에 남고 관측 성공으로 채워지지 않는다. 정상 종료/예산 종료/물리 실패/손목 실패/실행 오류를 구분한다.
- 같은 batch에서 종료 비용의 상대 크기가 advantage에 반영된다. 즉시 종료로 남은 음 감점을 피하는 합성 경로와 안전하게 계속하는 경로를 대조한다.
- 처음부터 support/finger optimizer 모두 갱신한다. 결정론적 평균 명령·실제 목표각·관절각·패드 이동을 확인하고 잡음을 배운 동작으로 보고하지 않는다.
