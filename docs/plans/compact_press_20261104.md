# 압현 상태443·목표16 별도 학습 구현

사용자가 기존 경로 보존과 신규 구조 구현을 요청했다. 기본 상태443, 명시적으로 골반을 포함하면452로 구분한다. 공유 목표 인코더16→64→64를8슬롯에 적용하고 상태 인코더→256과 연결하여768특징을 만든다. 일반 lookahead attention과 기존 진행 branch는 신규 정책에서 사용하지 않는다. 결합부는256→256, 출력은 학습33축이며 공용 실행기의39축 전달 형식에는 오른손6개 고정0을 붙인다. 이 전달 형식은 학습 출력33과 구분한다.

- [x] 별도 관측 환경: 상태443/452, 목표8×16, 마스크8. 기존 보상·종료·물리 유지.
- [x] 별도 정책과 학습·재개·평가·렌더 진입점. 기존 기본 경로 및 과거 checkpoint 보존, 신규 계약 엄격 구분.
- [x] CPU 관측·마스크·독립 목표·PPO·저장 재개 검증, 가능한 GPU 연결 확인.
- [x] 독립 변경 검수와 사용법 문서.

성공 기준: 기존 경로 검사가 유지되고 신규 관측 각 필드가 실제 측정과 일치하며, 결합768/학습33축이 검증되고 신규 checkpoint만 엄격 재개된다. 장시간 학습은 이번 구현 범위에 포함하지 않는다.
