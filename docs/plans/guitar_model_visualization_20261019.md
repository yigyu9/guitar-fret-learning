# 현재 기타 기초 노트·Isaac Gym 시각화

사용자 요청: 기초 노트를 현재 OM 기타 규격으로 수정하고, Isaac Gym에서 줄·프렛·타현 영역을 시각화한 이미지를 만든다. 승인된 작업 범위에서 진행한다.

- [x] 현재 XML·측정·타현 판정 코드와 실행 환경 확인.
- [x] 기존 노트를 보존하고 실제 22프렛 좌표·현 번호·현재 판정 조건으로 현행화.
- [x] 원본 XML과 전체 mesh 입력을 사전 봉인하고 별도 표시용 자산으로 실제 Isaac Gym 카메라 촬영.
- [x] 실제 native 마커 좌표로 6현·22프렛·타현 판정 영역과 XML 보조 박스를 구분해 표시.
- [x] 이미지 시각 점검, 수치·링크·원본 SHA 대조 및 독립 변경 검수.

결과는 `docs/2026-10-12/stability_adapter_2/results/guitar_model_visualization_v1/`의 새 경로에 저장한다. 원본 공용 자산·과거 실행·checkpoint는 수정하지 않는다. 정적 표시 장면은 물리 적분 0회이며 연주·안정성·음향 검증으로 설명하지 않는다. 표시용 XML은 mesh 경로와 색상·투명도만 변경하며 실제 모델의 geometry와 마커는 유지한다.

실제 타현 계약은 기타 로컬 Y −385…−255mm, 현 아래 깊이 1…15mm다. XML `G:pluck_range` 박스는 Y −414…−242mm인 별도 보조 형상으로 실제 판정과 혼동하지 않는다. 두 영역을 별도 범례로 표시한다.

완료: native_v5 실제 카메라와 images_v2 권장 그림 4개를 제공했다. 표 22행, native 마커 35개, 원본 입력 SHA 73개·주석 입력 9개 및 문서 링크 37개를 확인했다. 독립 검수 Critical·Warning·Suggestion 없음. 정적 표시 장면의 범위와 native visual geom 경고는 결과 안내에 기록했다.
