## 논문 작성 방식에 맞춘 보관

사용자는 논문의 흐름을 먼저 정하고, 각 부분의 내용을 최대한 채운 뒤 덜어내는 방식으로 작업한다.
따라서 현재 실행에서 사용하지 않는다는 분류는 논문에서도 제외한다는 뜻이 아니다.
폴더 정리 단계에서는 자료를 보존하고, 논문 초안의 범위를 미리 줄이지 않는다.

사용자가 제시한 우선 작업 목차는 **Introduction → Related Work → Methodology → Experiment → Result → 부록**이다.
자료 색인에는 이 여섯 부분 중 어디에 활용할 수 있는지도 표시한다. 목차는 초안을 채워 가며 조정할 수 있다.

| 작업 목차 | 먼저 채울 내용 |
|---|---|
| Introduction | 연구 문제, 기타 연주 동작 생성의 어려움, 연구 목표와 기여 후보 |
| Related Work | 기타·악기 연주 동작 생성, 물리 기반 동작 제어, 기술 결합과 물체 지지 관련 연구 |
| Methodology | 전체 파이프라인, 연주 목표 생성, 양손 제어와 동기화, 자유 기타 지지·안정화의 연결 |
| Experiment | 환경·자산·데이터, 비교군, 평가 지표, 학습·평가 조건과 실험 절차 |
| Result | 실제 연주·안정성 결과, 비교, 실패 사례, 해석과 한계 |
| 부록 | 상세 수식·제어 계약·설정, 추가 결과·영상, 재현 자료 |

Experiment는 무엇을 어떤 조건에서 검증하는지, Result는 실제로 무엇을 관측했는지로 구분한다.
미실행 실험은 Experiment의 후보로 표시하며, 미측정 결과를 Result의 성과로 채우지 않는다.

중앙 색인에는 원문·실행 상태와 함께 다음 활용 후보를 표시한다. 하나의 자료에 여러 활용 후보가
있을 수 있으며 최종 본문 채택 여부는 초안을 채운 뒤 판단한다.

| 논문 활용 후보 | 남겨둘 내용 |
|---|---|
| 본문 설명 | 문제 정의, 설계 선택의 이유, 현재 방법으로 이어지는 연구 흐름 |
| 비교·실패 분석 | 대안 접근법, 실패 결과, 채택하지 않은 이유와 이를 뒷받침하는 측정 |
| 한계·후속 연구 | 미구현·미검증 아이디어, 적용 한계, 다시 검토할 조건 |
| 부록·재현 자료 | 상세 계약, 설정, 코드와 원자료 위치, 복원 절차 |

과거 조건의 결과를 현재 성능 근거로 바꾸지 않고, 아이디어·구현·측정된 결과를 구분한다.
폴더 정리와 논문에서 내용을 덜어내는 편집은 별도 판단으로 진행한다.
