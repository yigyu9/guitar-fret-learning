# 자유 기타 학습 환경 — 압현 측정 연결

현재 환경 기반에 실제 손가락–기타 접촉, 목표 줄·프렛 기하, 연속 유지와 해제 측정을 추가한다. 기존Fret의 기하적tip_contact와 native접촉을 구별하고 고정기타환경은 상속하지 않는다. 이번 단위는 단일 목표의 측정이며 PPO학습·실제현힘/음향·곡완주를 목표로 삼지 않는다.

- [ ] 원 코드의 압현 구간·기하·유지 계약과 현재 준비 자세의 실제 접촉을 확인한다.
- [ ] 순수 단일 목표 측정기와 유지/접촉 이탈 추적기를 구현하고 CPU 검증한다.
- [ ] 움직이는 기타 좌표계와 매240Hz 실제 native 접촉을 새 환경 adapter에 연결한다.
- [ ] 기존 release/regrasp 기록에서 접촉/해제 구간을 검증한다. 완성된 과거 물리실험을 반복하지 않는다.
- [ ] 검수 후 필요한 최소 새 native 시험으로 새 환경 연결을 확인한다. 원 구간·기준·실패를 보존한다.
- [ ] 실제 결과·사용법·설계 한계·다음 타현 연결 순서를 기록한다.

문턱값은 명시하고 현재 자세를 통과시키려고 사후조정하지 않는다. 실제 줄은 충돌하지 않으므로 지오메트리와 손가락–기타접촉의 결합도 압현 후보이며 실제 현 압력/음향을 보장하지 않는다. 짧은 음의 유지율은 실제 음 구간으로 계산하고 고정100ms를 요구하지 않는다. 순간 접촉 이탈과 음악 목표의 최종해제를 구별한다. Root고정·하체유한·105/97/8·자유기타중력ON·스트랩OFF 조건과 기존 목표 소유권을 유지한다.
