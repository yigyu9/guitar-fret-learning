# 왼손 손가락의 독립적·유연한 제어

사용자 승인: 손가락이 충분히 굽혀지고 펴지며 빠른 운지 전환과 접촉 순응이 가능하도록 구현한다. 현재 과제의 왼손21축에 적용한다. 오른손 피크 파지와 기존 전문 경로는 원래 제어를 유지한다.

새 고정 프로필: 왼손21축의 정규화 행동을 초기 기준부터 양쪽 native 관절 한계까지 허용, 목표 속도4rad/s·평활화0.45. 팔·오른쪽 활성축은 기존 범위·속도·0.2평활화다. native 초기 POSITION PD는 손가락12/1.5, 엄지8/1.25로 시작하고 effort cap·관절 한계·drive mode·자산·물리 안전은 보존한다. 수치들은 최초 제어 설정이며 압현 성공이나 자연스러움을 보장하는 결과가 아니다.

새 세션이 기존035/v14 상태 복원 후 실제 물리0step에서 LH21 PD만 한 번 적용하고 검증한다. 이후 reset은 파생된 정확한 PD 예상표와 상태·목표를 확인하며 속성을 다시 변경하지 않는다. 최종 native 목표 제출에서도 동일한4rad/s를 적용한다. 기존 native Scene 원문은 바꾸지 않는다. 새 계약은 같은512차원이라도 이전왼손 checkpoint와 strict 구분한다. 엄지는 B 정지각·넥 접촉점에 고정하지 않는다.
