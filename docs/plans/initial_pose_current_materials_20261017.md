# 최신 초기 자세 자료 정리

사용자 요청: 최신 035 설정·v14 개별 시험·실용 V3를 기준으로 paper/initial_pose에서 정확한 값·영상·근거를 찾기 쉽게 정리한다. 새 실험·제어 변경·학습은 수행하지 않는다.

- [x] 최신 요구조건·RESULTS_v2·WORK_STATE의 현재/이전 기록 구분을 확인한다.
- [x] 실제 영상의 주요 구간과 저장된 준비 자세 이미지를 확인한다.
- [x] current_v3에 원본과 연결되는 설정·이미지·영상·결과 안내와 출처 목록을 구성한다.
- [x] 이전 첫 안내를 이력에 보존하고 초기 자세 및 논문 자료 안내를 최신화한다.
- [x] 링크·사본 SHA·원본 불변성을 확인하고 독립 검수를 받는다.

완료 기준: 현재/과거 자세, 출발값/준비 후 실제 자세, 개별 시험/연속 시험, 기하 타현/실제 음향을 혼동하지 않는 안내를 제공한다. 기존 실험 트리와 실패·검수·원자료는 이동/삭제/수정하지 않는다. 대용량 영상은 원본을 가리키는 링크로 모으고 경로를 기록한다. 교체되는 안내 문서는 먼저 원문 사본을 보존한다.

검사 결과: 선택한 기존 원본 72개 SHA 불변, 사본 16개 일치(교체 전 안내 2개 포함), 영상 15개 원본 링크·저장 SHA·영상 정보 일치, 로컬 문서 링크 89개 존재. 전체 프로젝트를 재봉인하거나 물리 결과를 재평가한 검사가 아니다. 독립 검수 완료: 문제없음. 22초 상태 행의 압축 원자료 일치도 독립 대조했다.
