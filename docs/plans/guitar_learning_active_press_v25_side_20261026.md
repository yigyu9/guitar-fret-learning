# v25 동시 학습과 손목 목표 다각도 시각화

사용자 승인: R 관문 제거·초기부터 팔/손가락 학습·팔 탐색 크기/지속시간·손목 종료 유예·엄지 누적 편향 개선을 수행하고 곡 압현 목표별 손목 영역을 여러 각도 영상으로 보여 달라는 요청.

다른 대화의 파일을 건드리지 않기 위해 기존 파일을 수정하지 않고 `guitar_learning/tool/experiments/active_press_v25/`의 명시적 실행 경로로 구현한다. 기존 v24는 공유 기반이며 결과·소스·strict resume를 보존한다. 이전 버전 저장본을 새 제어 의미로 재개하지 않는다. 이 대화에서는 서브에이전트를 사용하지 않으며 수치 대조·회귀·직접 검수로 확인한다.

## 설계

- 새 실행은 준비 상태035/v14로 시작한 뒤 J 활성33축을 처음부터 학습한다. 인코더/출력부 분리를 유지하고 R/F ready 관문을 실행하지 않는다. 곡의 연속 구간을 균등 학습하고 전곡 평가는 원래67음 분모를 유지한다.
- 팔은 기존 참조각 위치 제어를 유지한다. 초기 latent 표준편차 첫 후보 .25는 기타 이탈이 많아 채택하지 않고 .10（기존약.05）으로 보정했다. 모든 활성 명령을 최대3tick 유지한다. press/onset/end와수집경계에서는 줄인다.240Hz 물리·60Hz 제어 유지. 기존 가변시간PPO 수식을 재사용한다.
- 엄지5축만 준비 참조각 기준 native 전체 범위 위치 요청으로 전환한다. 0은 참조 자세 요청,속도4rad/s·PD/힘/범위 유지. 손가락16축은 기존4rad/s 누적 제어·비용0 유지. 엄지 자동 부착/강제 상태 덮어쓰기 없음.
- 손목 안내 관측/진단은 유지하고 연속 손목 보상은0으로 한다. 기존 영역을각축3cm 확대한 종료 영역 밖에서 .75초 지속 시종료한다. 초기3초·영역중심이1cm이상 옮겨진뒤.35초 유예. 심한 이탈은각축10cm 추가초과 시준비3초 뒤 즉시종료. 수치는 시작 후보이며 도달성 인증이 아니다.
- 물리실패는기존조건, 손목종료는별도이유로기록한다. 실패의 양성억제/terminal처리/남은구간비용을재사용하고 생략음분모를줄이지 않는다.
- 영상은 초기 실측 자세를 고정하고 시뮬레이션 물리 진행 없이 원곡 시간만 진행한다. 현재 목표/프렛셀·현·안내상자/종료상자/초기손목을 3개 시점으로 표시. 실행과 같은 손목영역함수를 사용한다. 학습 동작 영상이 아니라 기하 검증 영상이다.
