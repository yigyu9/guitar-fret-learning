- [x] 손 전체의 여러 시점 비교와 추천B의 기존 기타/손목 맥락을 정적 렌더한다. 결과PNG만 docs/2026-10-26/시각화에, script·각도/변환/입력SHA·설명·manifest는 기존 생성자료에 모은다.
