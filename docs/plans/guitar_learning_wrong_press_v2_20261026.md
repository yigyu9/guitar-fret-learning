# v25 오압현 판정 변경

사용자 승인: 이 대화에서 제안한 담당 패드 오류 / 다른 손가락의 높은 프렛 방해 규칙 구현 요청.
범위: 현재 finger-skill GPU 왼손만. 다른 창의 기존 변경을 보존한다.

- [x] 기존 판정·계수·진단 경로 확인 및 변경 전 원문 보관.
- [x] 담당 패드의 줄·프렛 오류와 다른 손가락의 같은 줄 높은 프렛 방해 구현.
- [x] 판정·경계·적분·진단·기존 경로 회귀 검사 후 관련 설명 갱신.

계수 -0.15b 및 240Hz 시간 적분/60Hz 지급은 유지한다. 담당 손가락의 올바른 패드 접촉이 있으면 같은 패드의 부수 표본은 담당 오류로 세지 않는다. 다른 손가락의 높은 프렛 방해는 올바른 접촉과 무관하게 판정한다. 준비 중인 미래 음은 현재 음의 방해를 면제하지 않는다. 몸체 접촉합력 기반 후보이며 현 압력·음향 인증은 아니다.

별도 대화 제약에 따라 서브에이전트 없이 직접 변경 검수한다. 실제 학습 실행은 요청 범위에 포함하지 않는다.

## 검증 완료

- 새 오압현 수용 검사14개 포함 관련11모듈 CPU130검사 통과(28.468초).
- 담당 패드의 다른 줄/프렛, 동일 프렛의 다른 손가락 대체, 다른 손가락의 높은 프렛, 엄지 방해, 준비 목표 비면제, 동시 허용 목표, 하중·방향·경계 필터, 중복 감점 방지, 부분 reset, 원장 명칭을 확인했다.
- 음 시작·끝이240Hz 표본 사이에 걸릴 때 창 밖의 순간 기하를 미리 마스킹하면 가장자리 감점이 절반으로 줄어드는 문제를 발견해, 기하는 양끝에서 계산하고 audible 중첩 시간으로만 적분하도록 유지했다. 고정 오압현 전 구간은 정확히 −0.15b다.
- 기본song·v24 관련 기존 회귀 검사 통과. 변경 전4파일 보관 SHA·변경 Python4파일 AST/공백 검사 통과.
- 실제 GPU/native 실행·학습·영상·새 체크포인트 생성은 수행하지 않았다. 보상/접촉 계약v2는 이전 모델과 엄격 재개하지 않는다. 테스트의 기존 requires_grad→scalar 경고1건은 실패가 아니다.
