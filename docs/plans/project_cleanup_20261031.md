## 보존 기준

최신 target_transition_v2 전량, 이전에 보존 요청한 failure_diagnosis_v1·large_until0900·runs/failure_diagnosis_live_preservation, 실제 실행 코드·자산·데이터·실험 설정·입력 원본·각 실험 평가 로그·최종 모델·학습 지표·요약·그래프·공개 영상은 보존한다. 실패 run의 원시 로그는 원인 근거로 보존한다. 구형 연구 중 개별비교연구/무접촉종료실험의 `completed=true`인 완료 run만 학습 episodes/decisions/transitions 원시 로그를 제거한다. 삭제 후 해당 학습의 시점별 재분석은 불가능하며 모델 평가와 기존 요약은 유지된다.

역사 문서·봉인 manifest를 현재 수치로 다시 쓰지 않는다. 현행 진입 안내와 코드 해설을 갱신하고 전체 문서를 현행/역사/원본/접근불가로 분류한다. 외장 저장소 I/O 오류가 있는 링크와 원본은 삭제하지 않으며 외장 문서의 본문 검수는 미완료로 기록한다.
