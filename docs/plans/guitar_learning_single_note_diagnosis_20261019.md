# 단음 학습 정체 분석과 개선 방향

요청: 현재 결과를 분석하여 개선이 필요하면 그 근거와 다음 실험 방향을 정한다.

전제: 현 장기 실행과 성공 후 확장 watcher를 유지한다. 이번 범위는 진행 중인 실행의 고정 prefix를 이용한 진단·방향 설정이며 보상/정책/환경을 몰래 바꾸거나 성공 기준을 낮추지 않는다. 종료 전 자료를 최종2시간 결과로 설명하지 않는다.

- [x] 현재 상태·완료 episode·수락된 update 및 유효 checkpoint를 같은 고정시점에 모은다.
- [x] 역할별 실패와 reward/cost·PPO 신호·모델 실제 변화의 초기/후기 추이를 분석한다.
- [x] 코드 근거로 보상·관측·행동·할인/rollout·LR/탐색 원인을 분리하고 반증 가능한 다음 실험을 설계한다.
- [x] 관측/추론/미검증을 구분해 우선순위·진급 보류 조건·현 실행 종료 후 대응을 문서화하고 검수한다.

자료와 분석은 새 guitar_learning_single_note_diagnosis_v1 결과 디렉토리에 모은다. 현재 실행/모델/실패/원 소스는 보존한다. native 재평가·추가 학습·중단은 이번 진단에서 하지 않는다.
