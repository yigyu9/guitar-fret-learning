`deadline_corrected_curriculum`에서 baseline 세 조건 평가를 마치고 첫 교정 학습 3,000회를 완료했다. 첫 교정 모델의 단독 평가를 진행 중이다. 이후 두 차례 교정 학습과 평가가 자동으로 이어지며, 정상 완료 뒤 선택 후보의 32환경 스트레스 평가와 정면·측면 영상 생성도 연결했다.

현재 실행은 배경 프로세스로 동작하며 상태·명령·결과 파일을 남긴다. 실행 시간이 길다는 이유로 자연스러운 모션이 완성됐다고 판단하지 않는다. 마지막 영상 검토와 실패 조건 확인은 별도로 남는다.


## 04:02 확인한 성과와 남은 자동 실행

첫 교정 모델: 유지·외란·낙하 각각 32/32회 목표 성공, 물리 실패 0. 별도 정면 영상 평가 4/4 성공과 영상의 초기·마지막·정지 결과 화면을 확인했다. 두 번째·세 번째 교정 학습 및 후보 비교, 선택 모델의 32환경 평가·두 방향 영상은 자동 절차로 계속 진행 중이다. 현재 성과는 16환경 평가 조건이며 다양한 초기 자세·실제 지지 접촉·최종 자연스러움 인증을 뜻하지 않는다.

## 08:30 PPO 전환 구현과 대조 완료

위 교정 연속 실행은 완료됐다. 상세한 최신 계획·코드 범위·실험 결과는 [PPO 통합 계획](../2026-09-14/archive/README.md)에서 관리한다.

- PPO와 독립 train-only BC replay, RMS 고정, 시범 SHA/스케줄/RNG 재개, 같은 frame의 Full264D/43D controller를 구현했다. 관련 CPU55개·독립 재검수·실제 GPU 재개가 통과했다.
- 16환경·25 iteration·51,200 rollout 슬롯씩 두 PPO pilot을 완료했다. 보존을 강화한B는 유지·외란·낙하 각각32/32 목표 성공이며 낙하 최종1.66cm/5.14도다.
- 같은 seed의32환경에서는 BC13/64→B23/64 물리 실패로 나빠졌다. 최종 기준 모델은 BC round1을 유지하며1,024환경 장기 확대는 보류한다.
- 동일 행동과 실제 PD 목표를 모든 환경에 보내도32환경의16번 이후 실패가 재현됐다. 원인은 아직 확정하지 않았다.
- B 정면·측면 영상은 각각4/4 목표 성공·물리 실패0. 초기 및 종료 전 화면을 확인했다. 지지·손바닥·Full 연주 인증과 구분한다.
- 현재 시작했던 학습·평가·영상·재개 프로세스는 모두 완료됐다. Full용 별도 Fret/Strike checkpoint 경로·곡을 기다리며 실제 공유 backend와 연주 조건부 학습은 후속 단계다.
