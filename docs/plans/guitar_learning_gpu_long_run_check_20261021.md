# GPU 장시간 학습 전 점검

사용자 요청: 자연스러운 기타 이탈/에피소드 종료는 허용한다. 장시간 학습의 실행 오류·자원·저장/재개와 실제 GPU 진행 가능 여부를 확인한다.

- [x] 현재 GPU runner의 장시간 메모리/로그/체크포인트와 수치 오류 처리 검토
- [x] 필요한 최소 수정만 보관 후 반영하고 관련 검사60개 및 독립 검수
- [x] 실제 GPU1024/large/H32 지속 학습과512환경 추가 시험으로 종료/reset·자원 추이·저장 확인
- [x] 결과와 한계, 저장·재개 검증 기록. 네이티브 메모리 증가가 남아 긴 실행 명령과 권장 환경 수는 제시하지 않음

점검 결과: **장기 학습 준비 미완료**. 최종1024환경 시험은39회 업데이트 뒤 PhysX 메모리 할당 실패,512환경 시험은128회 계획 중94회에서 메모리 감소를 확인해 정상 중단했다.512환경의 업데이트 후 GPU 여유는9.1709GiB에서1.8252GiB로 줄었다. 정상 중단 저장본94의 실제 GPU 복구·추가1회 업데이트·95회 저장은 통과했다. 원인 추정은 네이티브/비Torch 메모리 증가이며 내부 누수 여부는 확정하지 않았다. 자연스러운 기타 이탈은 이번 준비 판정의 차단 사유가 아니다.

검사 출력은 docs/2026-10-21/guitar_learning_gpu_long_run_check_v1/에 새로 남긴다. 기존 봉인 결과와 원본CPU/native/자산·학습의 물리/음악/보상 계약은 변경하지 않는다. 실행 중 활성 소스를 바꾸지 않는다. 실제 학습에는 기존 strict checkpoint 계약과 물리 실패 시 reset을 유지한다.
