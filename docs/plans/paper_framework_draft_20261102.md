## 첫 전달본의 얼개

### Framework overview

오디오 → 음·시간 추정 → 현/프렛/손가락 배정 → 연주 목표 시간표 → 기타 로컬 관측 → 정책과 유한 관절 제어 → 물리 시뮬레이션 → 과제 평가의 관계를 설명한다. 입력·출력과 각 블록이 필요한 이유를 먼저 쓴다. 전처리 정확도와 제어 성능을 같은 결과로 주장하지 않는다.

### Model / problem formulation

휴머노이드·기타·피크·의자·접촉을 설명한다. 105입력/97가동축/8영범위축, Root 고정과 하체 유한 제어, 정책 출력과 별도 유지 제어를 구분한다. 현재 왼손 J33 학습과 과거 오른손 6축 경로를 혼합하지 않는다. 기타 로컬 좌표와 프렛 셀·실제 패드 표면·몸체 합력 판정의 의미와 한계를 정의한다.

목표는 현·프렛·손가락·압현 준비·발음 시작·종료를 포함한다. 곡 전체의 목표가 주어진다는 가정과 관측에 제공하는 미래 시간창을 구분한다. 상태·행동·목표 토큰·제어/물리 주기를 명시한다.

### Method

1. 오디오/탭/운지의 연결과 실제 등록 곡 입력의 역할
2. 움직이는 기타 기준의 상대 관측과 손가락별 현재/다음 목표
3. 손가락별 준비·정렬·압현·유지·해제 상태와 우선순위
4. 직접 목표각 제어·속도/힘 범위·물리 피드백
5. 준비 접근·접촉·유지·달성과 오압현·수행 부족·대기·엄지·행동 변화의 역할
6. 물리/손목 종료와 실패 비용
7. PPO와 rollout/episode 경계·저장·별도 평가
8. 기존 공유 손목 허용 영역과 아직 구현하지 않은 전곡 공유 자세 계획의 구분

단일 압현을 지원하는 팔 진단 teacher나 알려진 각도 재생을, 곡 정책이 학습한 동작으로 쓰지 않는다. 여섯 상태는 정책 관측·진단이며 모든 손가락을 동기화하는 행동 잠금으로 설명하지 않는다.

## 실험은 주장별로 구성

- 누를 수 있는가: 단일 조합의 준비/압현/유지를 분리
- 전환할 수 있는가: 가까운 목표와 거리가 있는 목표의 전환
- 시간이 겹쳐도 가능한가: 한 손가락 유지 중 다른 손가락의 준비·접촉
- 동시에 누를 수 있는가: 공유 손목 제약과 개별/전체 목표 달성
- 곡으로 확장되는가: 곡·난도·학습 seed·모델 선택 기준을 사전에 정의
