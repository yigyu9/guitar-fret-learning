# 손목 자유 영역 제안과 이미지

사용자 요청: 현재 손목 점 안내 대신 넥 아래 높이·압현 포지션 방향·앞뒤 깊이의 권장 영역과 영역 밖 패널티를 제안하고 이미지를 제공한다. 이번 범위는 분석·제안 그림이며 학습 코드/보상과 기존 점 안내 시각화는 변경하지 않는다.

- [x] 초기 손목·실제 neck source hull·현재 anchor 안내를 기준으로 범위/좌표와 초기 포함 여부를 검산한다.
- [x] 초기 몸체가 고정된 실제 넥 그림과 깊이를 구분한 투영 그림, 권장 수치/패널티 설명을 만든다.
- [x] 독립 검수, 수식·이미지·기존 파일 불변 검사를 완료한다.

제안 시작값: 포지션anchor프렛셀중심에서 기타바디쪽5~13cm, 해당 기준의실제넥아래테두리에서2~6cm,지판면뒤연주자쪽3~9cm. 모두현재모델의공학적후보로정의하며사람의의학적정상범위나영역전체의IK도달성을인증하지않는다. 자료는기존요청배치대로결과이미지는 docs/2026-10-26/시각화 상위,생성/수치/제안문서는 생성자료에둔다.

완료: 초기손목이 anchor5 영역 안에 있음을 확인했다. anchor9에서 초기손목→기존 만점 구간 최소7.6032cm, 새 영역 최소2.72176cm를 독립 검산했다. 3개 이미지의 방향·범례·단면과 패널티의 경계0/외부 단조성을 검수했다. 기존 시각화30파일·학습438소스의 SHA가 유지된다. 학습은 변경하지 않았다. 제안 설명과 검증·별도 manifest는 생성자료에 저장한다.
