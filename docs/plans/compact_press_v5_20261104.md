# 압현 v5 개선 구현

사용자 승인: 전체 구조 점검에서 발견한 사항의 개선 진행.

기존 v4 소스·모델·실험을 보존하고 별도 v5로 구현한다. 물리, 초기 자세, 직접 목표각, 손가락 움직임 비용0, PD·힘·속도 제한, 신경망의 특징 폭은 유지한다. 구현과 작동 검증을 수행하며 장기 성능 개선을 선언하지 않는다.

## 고정할 개선

- 팔12축·엄지5축 초기 표준편차0.15, 검지~소지16축0.35를 명시적 설정과 실제 최초 모델에 반영한다. 재개에서는 저장값을 유지한다.
- 기존 상태452에 실제 대기 가중치4, 회복 경계에서 다음 press까지 시간4, 해당 경계 유효 여부4를 더해464차원으로 만든다. 골반 포함473차원. 목표26×8과 인코더/행동망 폭은 유지한다.
- 남은 음 비용 예산은 전체 task의 최대 음 예산0.25×M에 근거한 고정 양의 척도로 정규화한다. 구간마다 분모를 바꾸지 않는다.
- 목표 속도 부호를 계약에 명시하고 목표 프렛1~14를 입력에서 검사한다.
- 전체 유지 성공과 필요한 해제 성공을 분리 기록한다. 해제 필요가 없는 연속 동일 목표는 예외로 유지한다. 실패·미완주를 성공으로 처리하지 않는다.

## 비교할 보상 변경

확정된 정보/설정 수정은 모든 조건에 공통으로 적용한다. 기본 `corrected`는 v4 combined 보상 수식을 유지해 새 입력과 초기화의 기준이 된다.

- `preparation`: 기존 접근 항 내부에서 대기 중인 준비 목표의 가중치를0이 아닌0.10까지 유지한다. 실제 가중치는 `1 - 0.90 * standby_gate`. 접근 예산 상한과 나머지 품질은 유지한다. 별도 보상·강제 행동을 추가하지 않는다.
- `full_hold`: 달성 보너스와 연속 유지 부족률의 기준을 음 전체 길이로 맞춘다. 양의 예산과 최초 접촉 기준은 유지한다.
- `combined`: 위 두 변경을 함께 적용한다. 성능 채택은 비교 학습 이후 결정한다.

H32 기본은 유지하고 기존 horizon 옵션으로 H128을 비교할 수 있게 검증한다. gamma·LR·실패 비용은 이번에 함께 바꾸지 않는다. 자동 best 선정과 출력부 분리는 후속 비교 과제로 남긴다.
