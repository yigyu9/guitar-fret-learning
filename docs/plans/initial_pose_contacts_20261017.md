# 초기 자세의 접촉 위치 시각화

요청: 기타가 떠 보이는 원인을 시각 형상·충돌 형상과 실제 접촉 기록으로 확인하고 이미지로 표시한다.

- [x] 원본 형상과 저장 접촉의 좌표 의미 확인. 검증: 실제 body 이름·시각·양쪽 접촉점 대응.
- [x] 정면 및 비스듬한 시점에서 접촉 표시 이미지 제작. 검증: 원표본 위치·그림 범례·가림 처리.
- [x] 독립 검수 후 원인과 한계 설명, 이미지 제공.

기존 실험과 영상은 보존한다. 새 물리 실험 없이 free_strike v14의 저장 기록을 사용한다. source 충돌 형상과 PhysX cooked 형상은 구별하고, 접촉점 표시는 원래 native 접촉 기록에 근거한다. 초기 검토 시점은 준비 후 17초와 타현 중 29초다.
