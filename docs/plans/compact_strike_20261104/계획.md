# 현재 프레임워크 타현 학습 구현

요청: 과거 고정 기타 Strike-v2의 보상을 거의 유지하면서 현재 상태·목표 인코더와 오른손27축 학습을 구현한다. 2026-11-04 사용자가 스트럼까지 목표 공간을 확장하도록 승인했다.

기존 진행 실험의 코드·입력·모델·출력 및 과거 봉인은 수정하지 않는다. 새 코드는 guitar_learning 아래 별도 경로에 둔다. 기존 오른손27축 제어와 자유 기타·중력·PD·힘 상한·240Hz native 교차 기준을 유지한다. GPU 학습/물리 실행은 이번 구현 검증에 포함하지 않는다.

기존 ScoreTask는 스트럼을 개별 음으로 펼치고 프렛 입력을 요구하므로 새 환경은 검증된 canonical 이벤트를 직접 사용한다. SHA·원 음표 identity·frame·계획 partition 검증은 유지한다. 발음 줄과 비발음 통과 줄을 분리하며, 왼손의 실제 뮤트/음향 성공을 주장하지 않는다.

목표는 현재/다음 이벤트 2슬롯을 유지하되 줄별 통과·발음 mask, 순서·offset, sweep 길이 및 수행 원장으로 확장한다. 준비·접근은 60Hz, 실제 교차와 회복은 240Hz로 기록한다. 목표 전환이나 PPO 수집 경계에서 원장을 초기화하지 않는다. 스트럼은 예정 순서의 모든 통과 줄을 승인해야 완료된다.

과거의 최종 S3 보상을 기준으로 한다. 과거 9단계 커리큘럼·고정 기타·그립 행동 강제 제한은 이식하지 않는다. 현재 물리 안전 비용은 별도 critic으로 유지한다. 검사 성공은 코드와 합성 snapshot 계약의 성공이며 실제 학습·타현 성공과 구분한다.

예상: 코드/CPU 검증/독립 검토 약 1–2시간. 실제 학습 시간은 GPU 확보 후 작은 실행의 처리속도를 측정하여 산정한다.
