# 학습 초기화 손 준비 2초

사용자가 학습마다 기존 22초 검증 절차를 반복하지 않고 손 준비 1~2초만 사용하도록 요청했다. 기본값은 2초로 정한다. 기존 경로에는 10초/16초 보정이 있으므로 상수만 22→2로 자르지 않는다. 이미 확보한 준비 완료 상태와 최종 관절 목표를 reset 초기값으로 사용하고, 실제 물리는 2초만 진행한다. 상태 설정은 reset 시 한 번뿐이며 이후 강제 유지/기타 직접 힘을 사용하지 않는다.

- [x] 저장된 준비 완료 상태와 최종 목표를 초기화할 최소 경로, 기존 유한 제어의 시간 의존성을 확인한다.
- [x] 새 버전의 짧은 준비 환경/압현 연결과 기본 실행 진입점을 구현한다. 이전 22초 소스는 보존한다.
- [x] CPU 계약 검사와 필요한 최소 초기화 연결 확인을 수행한다. 기존 전체 검증을 반복하거나 PPO를 시작하지 않는다.
- [x] 현재 기본값·한계·결과와 경로를 기록하고 별도 변경 검수를 받는다.
