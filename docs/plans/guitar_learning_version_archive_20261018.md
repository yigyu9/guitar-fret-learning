# 이전 버전 분리 보관

사용자 요청으로 새 버전을 작성할 때 이전 버전을 guitar_learning/archive에 먼저 보관하는 규칙을 적용한다. 현재 불필요한 구버전도 함께 정리한다. 기존 archive는 원 구현으로 향한 symlink이므로 실제 보관 디렉토리로 바꾸고 원 구현 링크는 하위에 유지한다.

- [x] 변경 전 현재 소스와 문서를 SHA와 함께 보관한다. 원 실험 자료와 외부 원본은 유지한다.
- [x] 현행 코드가 사용하는 공통 native 제어/기록 기능만 현행 모듈로 분리하고 미사용 구버전과 해당 검사들은 보관 위치로 정리한다.
- [x] 현행 검사, 실행기 진입점과 보관본 SHA를 확인하고 README/AGENTS/원본 대응표를 갱신한다.
- [x] 별도 검수 후 새 버전 작성·이전 버전 이동 규칙을 작업 기준으로 확정한다. 물리/PPO 재실행은 하지 않는다.
