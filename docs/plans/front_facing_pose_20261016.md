# 양발 끝과 상체의 정면 정렬

사용자 요청: 발끝과 상체가 같은 정면을 보도록 새 자세를 만든다. 정면은 고정 Pelvis의 local−Y를 수평 투영한 방향(world+Y)이다. 카메라 회전으로 대체하지 않는다. 이전 grounded_guitar_support_v1의 봉인된 코드·설정·원자료·문서를 보존한다. 결과는 paper/initial_pose/lower_body_release_v1/front_facing_pose_v1, 구현은 stability_adapter_2/front_facing_pose_v1의 새 버전이다.

1. 원모델 FK와 원 가동범위 내에서 양 발목/발끝 긴축 local−Y, Torso/Spine/Chest·Head local−Y를 정렬한다. 양발 평평한 접지·원Root/좌석·기타 중심/넥·Chest/오른상완 지지와 실제충돌 filter를 검사한다. 상체 회전 후 양손의 기존 world 위치/회전을 보존하도록 팔12축씩을 다시 맞춘다. 목표 형상은 실제 동역학 성공과 구분한다.
2. 새 유한 발 목표에서 yaw를 함께 유지하고, 기존 유한 제어/gain/cap으로 준비0..5+정지5..10초를 실제 검사한다. initial 및 target 정면오차2° 이내, 실제5..10초의 양발4body/Torso/Spine/Chest/Head 정면오차5° 이내를 요구한다. 기존 기타30mm/5°·넥3°·좌우20mm·몸통5°/오른3°/Spine5°·Chest+상완95%·양발95%와 마지막1초 네 발바닥 높이/기울기/속도/미끄럼 기준은 유지한다. 새 자세의 연주/해제 성공은 기존 자세에서 자동 상속하지 않는다.
3. 실제 렌더 정면·측면·발을 확인하고 새 자세·설정·실제 결과와 남은 검증을 기록한다. 코드 검수는 독립 change-reviewer에게 맡긴다. 반복 통과 전 동적 안정성 최종 성공으로 확대하지 않는다.

Root 고정/하체 유한제어/기타 자유·중력ON·스트랩OFF,105입력과 원영범위8축/97비영범위 구분을 유지한다. 기타 직접힘·고정·강제부착·매step상태덮어쓰기와PPO는 사용하지 않는다. 기존 Hip bias/오른팔 보정 수치의 재사용은 새 자세의 검증된 하중/기하학 추정으로 부르지 않고 초기 시험 가설로 밝힌다.

저장공간이 부족하므로 새 영상은 실제5fps(물리240Hz/목표60Hz/카메라행렬30Hz)로 기록한다. 필요시 기존 완료PNG의 byte-equal hardlink 저장만 새감사 로그에서 수행해 모든 경로/bytes/SHA를 보존하고 inode/mtime변경을 공개한다. 원자료/소비코드/입력/기존 문서 수정·삭제는 하지 않는다.
