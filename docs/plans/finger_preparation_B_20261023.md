# B 준비 자세의 약한 권고 보상

사용자가 B를 선택했고, 압현 준비·접촉 구간을 제외한 아주 약한 보상을 명시적으로 선택했다. 강제 자세·관절 목표·초기 상태 변경은 하지 않는다.

1. [x] 변경 전 원문 보관, B 참조와 차단 조건 구현 → 기존 helper 보존 및 필수 사례 검사.
2. [x] GPU 왼손 연결·계약/문서 갱신 → 준비·압현·근접/하중에서 전체 자세 보상 0, 진짜 휴지 구간에서만 최대 0.01/초, 기존 접촉/달성·자유 제어 보존 검사.
3. [x] CPU 회귀와 독립 change-reviewer 검수 → 결과/소스 SHA 보존, 새 계약 저장·재개 검사.

설계: B의 source 지오메트리상 MCP/PIP/DIP 굽힘을 중심으로 ±15°의 평탄한 허용 대역과 바깥 30° scale을 둔다. 벌림·엄지에는 보상을 주지 않는다. 기존 per-finger idle의 최솟값으로 손 전체 gate를 만들고, 어느 손가락이라도 press−2~end이면 0(경계 바깥 0.25초 fade), 비엄지 손가락 하중/접촉 후보·오압현 또는 어떤 곡 목표와의 패드 거리 4cm 이하에도 0으로 한다. 기존 상시 coordination 보상은 활성 경로에서 0으로 한다. B 통과 여부를 성공·단계전환의 조건으로 추가하지 않는다. 빈 곡에는 보상하지 않는다.

물리/제어/PPO/관절범위/초기035-v14 및 손가락 움직임 비용0은 유지한다. 이 보상이 압현 구간에서 직접 경쟁하지 않도록 차단하는 것이 검증 범위이며, 학습 정책의 간접 영향이 전혀 없다는 성능 보장은 아니다. 실제 학습은 이번 요청 범위에 포함하지 않는다.
